# 稳定/漂移信息指导交接与空间聚合：联合研发预实验

日期：2026-10-08。已完成两条路线，不是仅启动训练。原主模型未改动，当前不合并两个新增模块。

## 一句话结论

**两种用法都已实现并跑完，但本轮没有得到可直接并入主方案的净收益。** 交接路线基本持平，空间聚合路线退化。小幅优于普通对照的结果保留，但不把它包装成超过原方案的有效模块。

## 相同实验范围

六个预先固定的外层目标港为 Antwerp-Bruges、Jebel Ali、Port Klang、Santos、Singapore、Tanger Med。每港沿用原来的五组64标签，5%仅限制专家交接比例。两条路线均在六港策略全部冻结后才进行查询指标汇总。

结果先平均每港五组抽样，再对六港等权平均。这是已有24港数据上的六港开发预实验，不是完整23港均值，也不是独立新数据确认。

## 路线一：信息指导交接

基础分类器和专家保持不变。用源域同类跨港均值变化构造特征级扰动，查看两个分类器如何翻转或趋同，再据此学习净纠错收益。训练保留两者都错的零收益情况。

```text
源港同类均值变化
    -> 普通漂移方向 / 移除候选稳定空间后的漂移方向
    -> 查询R50特征的对称扰动；支持集与R18固定
    -> 两个模型的翻转、相互转向、一致性和间隔变化
    -> 源港任务训练的净收益门控
    -> 固定5%交接
```

| 方案 | OA | BA |
|---|---:|---:|
| 历史原主方案 | 44.5655% | 45.0082% |
| 同条件置信度净收益门控 | 44.4833% | 45.0417% |
| 普通漂移响应 | 44.4551% | 44.9576% |
| 保护稳定空间的漂移响应 | 44.4922% | 45.0396% |

候选响应相对同条件置信度门控，OA +0.0089个百分点、BA -0.0021个百分点，基本持平。相对普通漂移响应，BA +0.0821个百分点，六港中五港更好；这一点有记录价值，但还不足以确认新增信息改善了原门控。

### 已定位的失效表现

- 模块不是未接入：响应特征非恒定，真实查询特征扰动与解析读出变化一致，最大误差低于5.11e-7。
- 交接数相同：各方案均用满同一5%上限。
- 新排序平均换入、换出各26.4例。换入组少误改约1例，也少纠错约0.97例，收益几乎抵消。
- 源门控三组交叉验证也没有增加收益：保护响应比置信度控制低0.1531个BA百分点，不是到目标港才突然失效。

当前只能确定“这套响应读出没有增加前5%交接的净收益”。不能据此说响应信息完全无用，也不能认定换成更复杂门控就必然有效。

详细记录：[交接分支报告](../drift_response_handoff_pilot_20261008/FINDINGS_ZH.md)。

## 路线二：信息指导空间聚合

使用真实缓存的四个空间token。以基础源分类器预测的前两类选择判别方向，用局部判别证据给token分配权重；保留原均值特征通路，新增均值为零的注意力残差。

```text
四个R50空间token + 源基础模型预测前两类
    -> 普通判别方向 / 候选稳定判别方向
    -> token证据归一化与softmax权重
    -> 相对均匀汇聚的128维残差
    -> 源分类修正 + 新增空间适配核
    -> 用原64标签协调重拟合专家
    -> 四置信度门控与5%交接
```

| 方案 | OA | BA | 专家BA |
|---|---:|---:|---:|
| 历史原主方案 | 44.5655% | 45.0082% | 48.6416% |
| 同条件门控重拟合 | 44.4739% | 45.0519% | 48.6416% |
| 普通空间聚合 | 44.0577% | 44.7399% | 43.5238% |
| 稳定引导空间聚合 | 44.1415% | 44.7623% | 43.6568% |

稳定引导相对普通聚合，最终BA +0.0224个百分点、专家BA +0.1330个百分点；相对不新增聚合分支的同条件控制，最终BA -0.2896个百分点、专家BA -4.9848个百分点。两种聚合版本在六个目标港都低于匹配控制。

本分支沿用旧的非零收益二分类门控；路线一使用保留零收益的净收益门控。因此两条路线各自的匹配控制不是同一个训练目标，不能交叉挑选最有利基线。

### 最小拆解已找到主要退化环节

在外层 Antwerp-Bruges 的三个固定源域留港任务（Jebel Ali、Port Klang、Singapore）上，只拆两个因素，不查新目标结果、不调参数：

| 稳定聚合接入方式 | 专家BA | 相对原专家 |
|---|---:|---:|
| 原专家 | 44.8760% | 0 |
| 仅新增源分类修正，原核不变 | 39.0388% | -5.8372个百分点 |
| 仅新增空间核，原先验不变 | 44.6592% | -0.2167个百分点 |
| 两者一起接入，原预实验实现 | 39.3727% | -5.5033个百分点 |

**主要损失来自新增源分类修正，而不是小幅附加的空间核。** .25只乘在空间核上，新增源分类修正的系数为1，不能误以为整个新增分支都只有四分之一强度。

源分类修正确实降低了训练集和源留港集的分数回归MSE，但源留港分类BA反而下降；经过64标签适配之后，MSE和BA又都差于原适配专家。因此已经确认存在回归目标改进与分类/适配收益不一致，不能仅以回归损失下降判断该模块有效。

另外，三个源留港任务中，基础源分类器的前两类包含真实类别的比例只有54.16%。这提示方向选择可能受上游错误影响，但本轮没有证明它是唯一原因。

编码检查确认目标为-1/+1且类别列一致；残差头与独立sklearn Ridge解的系数最大差5.61e-15；原专家和完整分支分数/BA重放通过。未发现可确认的实现错误。分类特征、类别校准、正则化与适配结构的具体相互作用仍未完全分开，不直接宣布整个空间聚合方向无效。

详细记录：[空间分支报告](../stable_spatial_pooling_pilot_20261008/FINDINGS.md)；[源域因素拆解](../stable_spatial_pooling_pilot_20261008/source_factor_diagnosis_20261008/FINDINGS.md)。

## 本轮处理决定

1. 保留原主方案，两条新分支暂不加入正式联合版，也不把它们相互叠加后继续扩大实验。
2. 保留稳定引导相对普通引导的小幅优势，但与“超过不加模块”严格区分。
3. 不继续追问隐向量的物理名称；下一次若改空间路线，应针对已定位的源分类修正/分类收益不一致，而不是仅改注意力名称或继续放大稳定分量。
4. 本轮共13项针对性单元测试通过，另完成全部源/目标重放和预算隔离检查。原始负结果、源域诊断和新代码均已保存。
