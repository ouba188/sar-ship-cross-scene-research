# 船型相关方向融合：全量实验、根因定位与修正

日期：2026-10-09。状态：原始对照、内层几何留出修正、优化初值修正均已完成；原结果全部保留。

## 结论先说

不同船型的模型响应确实不同，但“按船型把原方向信息加回来”目前只有弱收益，尚不足以成为强创新模块。完成训练协议修正后，类别相关融合的完整模型 OA/BA 为 **61.4270%/53.6645%**，相对四方向平均的 **61.2884%/53.6353%**，增加 **0.1386/0.0292 个百分点**。值得记录，不夸大。

本轮发现并纠正了一个有实质影响的源港模拟问题：只留出分类头训练、仍共享外层源港几何，会误导原方向与四方向分支的相对价值判断。把 PCA、候选稳定空间及漂移空间也对模拟目标港留出后，源港分支排序与真实目标港更一致。真实外层目标港一直未参与这些源港模型拟合；不是发现了外层目标标签泄露。

此外发现类别＋几何门控对初值敏感。固定两个初值、仅按源港目标择优后，源港优化变好，但目标 BA 仍没有稳定收益。因此不继续无限调参。

## 本轮到底试了什么

沿用 23 个外层目标港、原有 5 组 64 个目标标签、5% 专家交接上限。原始方向基础模型、四方向基础模型及原专家均复用上一轮的冻结目标得分，不新增目标标签。

融合形式为 `s_c = s_C4,c + alpha_c(x) * (s_original,c - s_C4,c)`。

每个候选类别都有自己的得分与权重，推理时同时计算八类，不需要真实船型。权重表示两个已训练分类分支的组合比例，不是船舶的物理敏感性数值。

| 对照 | 想区分的解释 |
|---|---|
| 固定各一半 | 是否普通模型融合就足够 |
| 源港学习一个统一权重 | 是否需要学习，而不是固定平均 |
| 源港学习八个类别权重 | 是否确有类别相关的组合价值 |
| 根据预测质量选择统一权重 | 是否其实只需要看当前样本是否难判 |
| 类别＋预测质量 | 是否需要类别与样本状态交互 |
| 类别＋预测质量＋观测条件 | 入射角、相对角和缺失信息能否进一步帮助组合 |
| 只改八个类别偏置 | 是否只是一般类别校准，而非方向分支的价值 |
| 只重训练交接器 | 是否问题主要在原交接器没有适配新基础模型 |
| 交接器再加方向分歧 | 方向分歧是否真的有额外的交接价值 |

预测质量特征为：两个基础模型的第一、第二名得分间隔；去除类别共同偏移后的得分差 RMS；两个基础模型是否预测不同。

观测条件为：入射角标准化值及平方、入射角可用标记、相对角可用标记、二倍相对角的正余弦。不能把这些条件统称为“纯物理因果信息”，可用性和数据构成也可能提供统计线索。

权重训练采用源港任务/类别等权交叉熵及固定正则，不直接优化目标 OA/BA。类别偏置是单独的对照，不混入融合模型。分类头和目标适配仍使用原来的 ridge=1/8。

## 第一次完整实验

下表是完整模型，先每港每次计算指标，再对五次抽样和港口平均。所有负结果保留在本目录，而非被后续修正覆盖。

| 方法 | OA (%) | BA (%) |
|---|---:|---:|
| 四方向基础＋原专家 | 61.2884 | 53.6353 |
| 固定各一半 | 61.5233 | 53.4106 |
| 学统一权重 | 61.3464 | 53.1671 |
| 学类别权重 | 61.4353 | 53.3908 |
| 预测质量权重 | 61.2626 | 53.0928 |
| 类别＋预测质量 | 61.5328 | 53.3692 |
| 类别＋预测质量＋观测条件 | 61.5136 | 53.3852 |
| 类别偏置 | 60.7467 | 50.4014 |
| 仅重训练交接器 | 61.4225 | 53.7207 |
| 交接器再加方向分歧 | 61.3433 | 53.6562 |

最初的结论不是“类别差异没有价值”，而是融合普遍表现为 OA 小涨、BA 下降。普通各一半已能获得多数 OA 收益。复杂条件组合没有显示出独特优势。

交接器重训练有小正信号：OA 18 港升、4 港降、1 港不变；BA 17 港升、6 港降。五次抽样中四次双指标改善，一次小降。其收益比添加方向分歧更大，说明重新匹配基础模型比加入这个特征更有价值。该支线仍使用原共享几何的源港模拟，作为经验小增益记录，不作严格内层几何留出的机制结论。本轮没有把它与修正后的类别融合再叠加。

## 为什么原来的融合规则会失效

### 已查明的源港模拟偏差

原方案生成模拟源港任务时，分类头训练行和 64 个支持样本/查询集已经分开，但 PCA、Qs、Qd 和相关统计仍来自整个外层源港池，包含模拟留出港的信息。

这些表征在原方向特征上构建。因此它们在模拟源港任务中并不处于真正面对新港口的条件下。初步现象是原方向分支在源港任务中略占优，而在真正外层目标港上四方向平均占优。

为检验这一解释，本轮使用已有的双港留出 PCA/Qs 缓存，核对训练行相同，重新计算仅由内层训练源港得到的 Qd 和稳定坐标统计。源港融合训练共 23×22 个模拟任务，骨干保持冻结。所有八分类头和支持集适配都遵循相同算法、标签与正则。

| 基础模型比较口径 | 原方向 OA / BA (%) | 四方向 OA / BA (%) |
|---|---|---|
| 原共享几何的源港模拟 | 60.7001 / 53.7169 | 59.5935 / 53.4064 |
| 修正后的内层几何留出模拟 | 57.6958 / 50.0136 | 58.6006 / 52.0159 |
| 原来冻结的真实外层目标港 | 57.7777 / 50.0913 | 58.9130 / 51.7847 |

各行的训练集合和任务条件不同，不能用跨行绝对准确率当作单一模块消融；关键是同一行两个分支的相对排序。几何留出对照足以说明原模拟协议会改变分支排序，但没有分别确定 PCA、Qs、Qd 中哪一项贡献最大。

修正后 23 个外层任务的源港统一最优权重都选择 alpha=0，即四方向分支。此前源港任务引导模型给原方向较高权重，确实与部署时的相对优势不一致。

### 优化初值也有影响，但不是全部原因

当统一 alpha=0 时，条件门控从裁剪后的 alpha=0.001 初始化，且正则约束其不要偏离统一权重。单初值版本几乎退回四方向平均。

在 Callao 对应的源港任务上，仅把初值改为 0.5、目标函数及正则完全不变，类别＋几何模型的目标从 1.635043 降到 1.633184。随后对 23 港执行两个固定初值，依据更低的源港正则目标选择收敛解；22/23 港的类别＋几何模型采用中性初值结果。没有以目标港标签选择初值，也没有继续搜索正则强度。

这说明不能把此前近零条件权重直接解释成“条件信息毫无价值”。但优化修正后的目标 BA 仍未超过四方向平均，故不能反过来把更低源损失当作跨港成功。

## 类别权重究竟在做什么

修正后的八个权重在 23 个外层任务间的均值如下；权重越大，表示对该候选类别的原方向得分保留越多。

| 候选类别 | 原共享几何学到的 alpha | 修正后的 alpha |
|---|---:|---:|
| 散货船 | 0.1701 | 0 |
| 渔船 | 0.0296 | 0 |
| 普通货船 | 0.3324 | 0 |
| 成品油/化学品船 | 0.4957 | 0 |
| 集装箱船 | 0.7572 | 0.0188 |
| 原油轮 | 0.6727 | 0.1378 |
| 拖轮 | 1.0000 | 0.1556 |
| 海工补给船 | 0.9987 | 0.1546 |

这些系数作用于每张图的候选类别得分，不是“只有真实原油轮才启用原油轮权重”。更不能据此认为原油轮一定更需要原方向信息。

以下完整模型每类召回，先对每张图的有效抽样平均，再在该类图像上平均，与港均 BA 的权重不同。

| 船型 | 四方向 (%) | 类别融合 (%) | Δ百分点 |
|---|---:|---:|---:|
| 散货船 | 62.2831 | 62.4526 | +0.1694 |
| 渔船 | 91.5876 | 91.6180 | +0.0304 |
| 普通货船 | 60.7115 | 60.7530 | +0.0415 |
| 成品油/化学品船 | 37.5862 | 37.9735 | +0.3873 |
| 集装箱船 | 50.8431 | 51.0787 | +0.2355 |
| 原油轮 | 62.2017 | 61.8355 | -0.3662 |
| 拖轮 | 19.2670 | 18.9468 | -0.3203 |
| 海工补给船 | 42.7754 | 42.7883 | +0.0129 |

一个关键反例：化学品类别 alpha 在全部任务中都是零，其基础类别得分完全没加回原方向，基础召回却从 35.9645% 到 36.3952%。因为其他类别的得分变了，分类竞争关系改变，它更容易赢过拖轮、原油轮等候选。

逐图抽样平均的预测迁移中，真实化学品船“拖轮→化学品”约 23.43 个图像加权事件，“原油轮→化学品”约 16.45；反向“化学品→拖轮”约 7.10，“化学品→原油轮”约 11.03。这些是同图多次抽样平均事件，不是独立船舶计数。

因此，当前弱增益主要应描述为**类别竞争关系的重新分配**，不能描述成已识别了各船型的物理方向敏感性。原油轮和拖轮确实保留了更多原方向得分，但它们自身召回反而下降，这尤其需要保留而非隐去。

## 更广泛的判断

1. **不同船型响应不同**仍是合理研究假设，但本轮不能把它升级为物理结论。
2. **方向敏感不等于噪声，也不等于值得抑制**；原方向分支同样不是物理证据的纯载体。
3. **源港规则能否迁移**比增加权重维度更关键。模拟新港口时，应将用于判断分支价值的表征处理也留出，不能只留出最终分类头。
4. **低训练损失不等于更高 BA**。类别偏置的全部目标港平衡交叉熵下降，但 BA 大幅下降；严格八类子集的损失也会恶化，说明还叠加了域间迁移问题，不能用一个指标解释全部现象。
5. **观测条件还没证明有独立增益**。当前角度覆盖、编码方式、正则和分支设计都限制了解释；本轮负结果不等于角度从物理上无关。

## 本轮保留什么

- 主方案仍保留四方向平均基础模型＋原专家。
- 修正后的类别融合标为“弱增益候选”，不作为新的强创新模块；其得分已经冻结，方便后续固定设置跨数据集验证。
- 交接器重训练另记小正信号，不与类别融合叠加后再挑最好结果。
- 更值得追的问题从“每种船加多少原方向”收窄为“具体混淆类别对需要什么可验证证据”。例如化学品船—原油轮—拖轮的竞争关系；但不再仅凭系数大小赋予物理含义。
- 本轮止于两项有证据的修正，不继续调正则、增加门控输入或按目标港挑方案。
