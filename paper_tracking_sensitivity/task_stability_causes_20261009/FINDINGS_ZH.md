## 是否每港都有8类

不是。当前是共享8类标签空间的闭集跨港任务，源划分均覆盖8类，但目标数据可以只有标签子集。这是当前样本的覆盖情况，不代表真实港口只有这些船型。

- 完整 manifest：24港、38,091条；12港8类、2港7类、1港6类、9港3类。
- 已评估目标：23港、38,027条；12港8类、2港7类、1港6类、8港3类。Melbourne仅64条，在64支持标签设置下不剩查询样本，未进入当前23港目标结果。
- 全部23个实际 source_rows 划分均有0至7全部8类；逐类数量见 fold_draw_class_coverage.csv 的 source 行，逐源港数量见 fold_source_port_class_counts.csv。
- 8个三类目标港均只有0、1、2：Antwerp-Bruges、Busan、Fujairah、Hamburg、Ningbo-Zhoushan、Qingdao、Rotterdam、Shanghai。完整24港中另有Melbourne。
- Mombasa、Newcastle为0至6七类；Port Hedland为0、2、3、5、6、7六类。其他12个目标港均为八类。
- 115次64标签支持抽样：3/4/5/6/7/8类分别41/5/8/20/18/23次。只有23次支持集具备全部8类，不能把64标签理解为每类8条。
- 115次 query：3/6/7/8类分别40/7/8/60次。恰好12港在五次 query 中每次都具备8类，其余11港任何一次都不足8类。因此八类目标港名单跨五次抽样稳定。
- 只有Mombasa的 query 类集合随抽样改变，类别数依次7、7、6、7、6；其余22港 query 类集合固定。全部23港每次 support/query 类别覆盖及计数已保存。
- 52/115次 query 含有支持集未见类别；合计1,528条支持未见类查询记录，占重叠抽样累计182,775条查询记录的分母。这些不是源域未见类别，重复抽样记录不能视为独立样本。

run_generic_transfer.metrics 在固定8类混淆矩阵上计算 recall，仅对 query 真实标签中出现的类别取均值：`ba = recall[count > 0].mean()`。缺类 recall 输出 None，不以0计入BA；预测为某个目标缺失类别仍会造成真实类别的误分类。这是“八路输出、现存类平均BA”，不是固定八个召回率的零填充平均。函数原文和行号已保存为 BA_IMPLEMENTATION.txt。

## 统计口径

完全复用 pair_geometry 的源定义方向：每类在共同源港内取均值，再等港平均；每港每类至少5条，至少3个共同源港。实际源共同港数为9至23。Qs用 `bank[:,192:192+r]*stable_scale+stable_center` 还原原始坐标；普通对照为 `bank[:,:r]`，r为23至27。

源AUC在相同共同源港的样本上计算，每类总权重1/2、每个共同港在每类内等权，港内样本等权。它是包含跨源港样本比较的加权 pooled AUC。方向和表示使用了这些源样本，故源AUC是拟合内描述，绝非独立验证。

标准化间距 = 沿该源方向的类均值差 / sqrt(两类类内方差的均值)，总体方差使用ddof=0及上述权重。源类内总方差分解为港内类方差均值加同类港均值方差；两项均保存。目标间距保留比是有符号目标间距/源间距，方向不根据目标翻转。

目标AUC直接复用 parent 的 target_port_pair_means.csv，并重算核对。每港每对先平均有效抽样，再对该对有效港等权平均。源比较也只用同一批有效目标对应的外层源划分。全局对28对等权，不是八分类BA。表中比值均先逐划分计算再平均，不能用平均分子除平均分母重建。

0-1、1-4、1-5在源域已有很强的固定方向判别，目标仍保持较强排序。因此这些对的良好表现并非仅由候选“稳定性”独立解释；普通同秩空间也很强。

2-3在两个空间的源拟合内AUC就偏低，说明当前表示与固定方向读出已有较大重叠，随后目标进一步退化。2-7、6-7在Qs的源域表现明显好于普通同秩，但目标下降很大，不能只归结为“在源域本来就接近随机”。这两对兼有较小源标准化间距与较大的源到目标退化。

Qs的2-7、6-7目标间距仅保留0.322452、0.168050；方差比0.711375、0.668509。即使改用纯源港内类方差作分母，方差比仍仅0.769536、0.748281。因此均值对比收缩或翻转是直接观察到的重要变化，不支持把平均退化简单归为类内噪声膨胀。Qs的6-7共60个有效港-抽样中23个方向翻转；Houston、Jebel Ali、Port Klang、Singapore全部五次均翻转，Richards Bay三次翻转。其他港的负结果与正结果均保留。

这不能把全部AUC下降定量归因于间距：AUC依赖整个分布。源拟合内乐观性、样本构成和真实迁移效应尚未被独立拆开。这里的“源域较难”只指当前表示和读出中的重叠，不是图像固有难度，也不是船体形态或物理散射机制结论。

## 整体负结果与边界

28对等权，Qs源AUC0.840504、目标0.774647，变化-6.585699个百分点；普通同秩源0.810547、目标0.782538，变化-2.800956个百分点。Qs在23/28对有更高源AUC，却只在11/28对有更高目标AUC。Qs全部28对目标AUC低于源拟合内值；普通同秩2-4对有所提高。没有删掉普通空间优势或Qs失败的类别对。

Qs更低的源港均值变化/类别间距比0.200065，对照0.318503，没有换来更高的整体目标AUC。两种表示未匹配全部源判别属性，不能把差异说成稳定性的因果收益或损害。

源诊断1,288行；目标港-抽样-类别对3,614行；目标港-类别对736行，均含两空间。目标每类最低5条，部分小类估计不稳定；五次查询重叠、外层源划分重叠，不是独立重复。全部28对和逐港样本量均已保存；未进行目标白名单选择、超参数搜索或训练。
