# 候选类别局部频带支持对比：实现、结果与根因分析

日期：2026-10-09。

## 结论

模块已经实现。正式实验完成自建24港体系中的23个评估港、F_0921和OpenSARShip 2.0，每任务5次64标签抽样；随后完成一个源端限定的训练目标对照，以及另一组25×5的主频带对照。原主方案没有被覆盖。

**局部视觉对比有可测的作用，但目前不能作为稳定涨点模块并入。** 全频带局部对比相对整体频带相似度，在OpenSARShip 2.0上改善BA约0.0645个百分点，但仍低于当前主模型。F_0921则退化。重新约束到原模型源端选中的主频带后，F的退化减轻，24港出现小幅BA正信号，但OA仍下降。

本轮最具体的新发现：**原模型压低的频带，在比较器里经过分频带归一化和逐特征标准化，又可以成为主导证据。** 这改变了已有表征的使用方式，是一个需要处理的接入因素；对照并不支持它是唯一根因，更不能将这些低权重频带都称作纯噪声。

## 1. 模块如何工作

```text
同一SAR样本
    -> 已冻结的原频带编码器，四频带各16通道x2x2位置
    -> 对每个候选船型，与该类64标签支持集中的案例比较
       A. 四个频带的整体余弦相似度
       B. 四个频带的对应位置平均相似度
       C. 四个频带的双向最近位置平均相似度
    -> 新候选类别证据 - 旧候选类别证据
    -> 4维或12维线性比较器
    -> 保留完整新分数，或退回完整旧分数
    -> 原专家与最多5%的交接
```

这些位置是学习后特征图的粗粒度2×2区域，不是已经识别出来的船头、甲板或尾迹。四频带也是特征图上的Haar分解，不应称为物理雷达频段。

对每个频带，类内支持权重固定为：

`softmax(整体相似度 / 0.2 - 条件坐标平方距离 / 0.5)`。

同一组类内权重用于整体、对应位置和最近位置三种证据，避免把不同的支持选择混进局部结构比较。证据按类归一化，不直接让支持数量多的类占优势。

源端训练用“真实类 versus 原两模型中分数最高的其他可支持类别”。真实类和错误候选都至少有两个支持样本。25任务共有98,035个这样的任务内训练对；任务之间可能重复原始样本，不能称为98,035艘独立船。

线性比较器采用固定Ridge(alpha=10)、无截距、按源端训练权重计算的RMS缩放。候选交换时分数反号。它只学习4或12个系数，每一次选择都能精确分解到各项证据。分数不是概率。

部署只处理旧、新预测不同且两个候选都至少有两个支持的样本；否则维持原频带模型。对于可处理样本，比较分数小于0才完整退旧，不插值，也不改变标签预算。

## 2. 正式全频带实验

表中均为完整模型OA / BA（%）。24港按港等权，再对5次抽样平均；外部集按5次抽样平均。

| 方案 | 自建24港 | F_0921 | OpenSARShip 2.0 |
|---|---:|---:|---:|
| 当前频带主方案 | 63.2084 / 54.2383 | 31.1072 / 26.3593 | 35.3545 / 32.3724 |
| 仅整体频带相似度，4维 | 63.1343 / 54.2489 | 31.0872 / 26.3159 | 35.2241 / 32.2987 |
| 加入局部比较，12维 | 63.1615 / 54.2452 | 31.0684 / 26.2904 | 35.2296 / 32.3632 |
| 源端选择 | 63.1987 / 54.2337 | 31.0684 / 26.2904 | 35.3545 / 32.3724 |

源端选择为6个局部版、4个整体版、15个不变。不能按目标列挑选最优版本拼接结果。

相对原主方案，固定12维局部版的BA变化（百分点）：

| 环节 | 自建24港 | F_0921 | OpenSARShip 2.0 |
|---|---:|---:|---:|
| 基础分类 | -0.0580 | -0.0794 | -0.0230 |
| 固定原交接名单 | -0.1048 | -0.0841 | -0.0207 |
| 重新分配原5%交接 | +0.0069 | -0.0689 | -0.0092 |

24港完整系统的极小BA上升仍由交接变化补偿基础退化，不能说基础纠错已经更准确。原始逐港、逐抽样、逐类结果均保留。

## 3. 直接失效位置

### 3.1 仍然错误撤销了不少有效修正

以下为全频带12维局部版、基础分类、5次抽样累计事件，非独立样本数：

| 数据集 | 新旧分歧事件 | 支持充分、允许比较 | 撤销改判 | 修复误改 | 丢失有效纠错 |
|---|---:|---:|---:|---:|---:|
| 自建24港 | 7,775 | 6,724 | 1,835 | 542 | 653 |
| F_0921 | 29,074 | 25,731 | 11,408 | 2,420 | 2,713 |
| OpenSARShip 2.0 | 1,111 | 862 | 222 | 44 | 71 |

有足够支持并不等于证据可靠。在F中，比较器为了修复2,420次错误，也丢掉了2,713次原本正确的频带修正。

### 3.2 泛化落差仍在，但不像上轮树模型那样主要表现为训练记忆

在F对应源任务上，局部比较器的真实类对比准确率：拟合68.35%，留港65.89%，两者差距不大。针对实际新旧分歧事件的纠错/误改AUC：源端拟合0.658、留港0.634、目标0.531。

所以这轮不能简单归结为复杂模型记住训练集。低维视觉相似性本身尚未可靠区分目标端的有益和有害改判。该AUC只在支持充分且一个模型对、另一个错的事件上计算，不代表完整八分类准确率。

### 3.3 训练目标对照没有普遍修复问题

看见正式结果后，补了一个源端限定对照：保持相同4/12维视觉证据、Ridge10、权重、留港折，改为直接训练实际分歧上的`正确(S1)-正确(S0)`。

| 对应源任务 | 原12维类对比训练：留港BA变化 | 实际改判收益训练：留港BA变化 |
|---|---:|---:|
| 自建24港任务平均 | -0.0395 | -0.1531 |
| F_0921对应源端 | +0.5500 | +0.2701 |
| OSS2对应源端 | -0.1353 | -0.1347 |

它没有普遍改善，因此未继续拿该变体做目标端调优。该对照同时改变了训练对分布和数量，不能把变化全部归于损失形式，但足以否定“只换成正确目标就必然生效”的判断。

## 4. 分支重新放大的接入因素

原F频带模型的目标端平均门控权重，用float64累加为：

| 频带 | 平均权重 |
|---|---:|
| LL | 0.000815221 |
| LH | 0.999183564 |
| HL | 0.000000531 |
| HH | 0.000000685 |

全频带比较器先消除各分支门控幅度、独立归一化，再对比较特征做逐维RMS缩放。这样虽能读取各分支内容，却也取消了原模型对不同频带的抑制。

### 一个可以精确解释的错误

F数据清单第72629行、抽样0：真实是渔船，旧模型预测海工补给船，新频带模型正确改成渔船。新比较器却给出-2.7993，退回错误旧类别。

其中LL的“允许位置变化的局部匹配”一项贡献-3.0453，足以主导总分。这不是模糊的热力图解释，而是线性分数的精确加和，见`decision_cases.csv`。

但LL并非纯粹有害：第64319行真实为原油船，旧模型正确，新模型误改散货船；同样的LL证据帮助比较器退回正确旧类别。这说明低原门控权重不等于该分支完全没有判别信息。

## 5. 主频带对照：减轻退化，但没有彻底修复

固定规则：每任务读取原神经训练最后一轮、最后一源端批次的门控记录，取最大频带。该记录在最后一次参数更新前生成，不是目标端选频带。25任务中22个选LH、3个选LL。

只保留主频带的整体对比（1维），或整体+对应位置+最近位置对比（3维）；其余训练、选择、预算、专家和路由保持一致。这是看到正式结果后的机制对照，另有预先写定的对照协议，不称独立确认。

| 主频带对照方案 | 自建24港OA / BA | F_0921 OA / BA | OSS2 OA / BA |
|---|---:|---:|---:|
| 仅整体，1维 | 63.1361 / 54.2753 | 31.1021 / 26.3361 | 35.3002 / 32.3612 |
| 加入局部，3维 | 63.1368 / 54.2883 | 31.0906 / 26.3329 | 35.2839 / 32.3566 |
| 源端选择 | 63.1697 / 54.2574 | 31.0906 / 26.3329 | 35.3545 / 32.3724 |

源端选择为9个局部版、2个整体版、14个不变。相比原主方案，该选择的24港BA +0.0191、OA -0.0387；F的BA -0.0264、OA -0.0165；OSS2不变。

主频带3维局部版的基础BA变化为24港-0.0105、F -0.0351、OSS2 -0.0270；固定交接后分别-0.0470、-0.0368、-0.0274。仍不能把完整24港BA +0.0500解释成基础分类全面变强。

F的完整BA降幅由-0.0689减至-0.0264，支持重新引入弱分支是影响因素。但移除分支也改变了维度，且未恢复到原主模型水平，不据此声称唯一根因已被消除。

在上述具体案例中，主频带版仍误拒绝第72629行的正确改判，也失去了对第64319行的正确退旧。它改变了错误组合，并非简单清除了纯噪声。

## 7. 研究判断

已证实：

- 原频带信息确实被使用；新的比较器会产生可解释的正、负决策，不是模块没接上。
- 再归一化会取消原有频带幅度抑制，弱门控分支可以重新主导决策；限制到主频带能缓解部分数据上的退化。
- 仍有大量有效纠错被撤销，单纯改动作、改训练目标、抑制弱分支都未给出稳定提升。

尚未证实：

- 不能将低权重分支称作纯噪声，不能把损失全部归因于方向、背景或某个物理漂移因素。
- 不能由这些对照推导出局部视觉证据没有价值。当前比较器使用的是为带符号支持残差学习的冻结表征，其“与某类更像”不必等价于“支持该类的残差证据更可靠”。这是后续值得检验的机制差异，不是已完成的唯一因果解释。

当前决定：**不替换原主模型，不继续在同一批目标结果上调门槛。** 若再推进，应把候选类支持比较的监督接到表征训练中，让特征本身学会比较，再检验基础BA、固定路由和完整系统收益；不能仅把现有频带向量接一个更复杂后处理器就宣称新增核心能力。该联合训练尚未实施。
