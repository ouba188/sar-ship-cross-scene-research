# 近期研究进度与思路总览

截至：2026年10月11日。本次只整理已有记录，不启动实验、不替换模型。下文按研究问题的演进分阶段，并非每个阶段严格对应某一天。

## 一、先用人话概括

最初我们想解决：一艘船换到另一个港口，基础模型可能认不准，能否只把少量困难样本交给专家，既纠错又限制交接比例？

研究过程中，我们逐步把三个问题分开了：

1. **模型到底学到了什么有用信息？** 稳定候选坐标、成像角度、局部空间变化、SAR自监督表示，都在探索这个问题。
2. **这些信息怎样才能真正改变判断？** 通过源分类先验、与64个支持案例的关系，以及最后的融合来使用。信息有用，不代表接在哪里都有效。
3. **是否真的需要两个骨干和选择性交接？** 必须通过强单路、全量融合和实际计算成本来回答，不能由模型结构名称决定。

目前最清楚的进展是：已有可运行、可追溯的跨港少样本适配模型；旧双路存在实际互补收益；新的SAR自监督也存在真实收益。但选择性交接未胜过全量融合，双骨干并非已证明不可替代，新表征直接套旧读出还会退化。

**当前最值得继续的问题，是如何让学到的表征、支持案例关系和最终读出相互匹配，而不是继续凑模块。**

## 三、哪些工作已经形成实质积累

### 早期几天的关键转折，按日期补充

- **10月7—8日，先尝试让专家训练与实际用途一致。** 从一般的注意力/分类训练，推进到效用监督与通过64例支持残差求解器反传。BA有正信号，但存在OA下降的取舍。今天关注训练与读出匹配并非完全另起炉灶，而是在已有目标对齐工作上继续处理表征选模和模块间尺度问题。
- **10月8日，确认“更稳定”不等于“更准确”。** 匹配源端判别强度的候选空间对照中，精确经验W1漂移低5.19%，但两类诊断BA只高0.1614个百分点，22港11升、11降。这是类别对实验，不能当成完整八输出模型的收益。保护候选空间与激活的旧配对组合有约+0.3494个百分点BA，但单独漂移抑制为负，说明使用方式比“删除漂移”这个口号更重要。
- **10月9日，同船多时相分析限制了“纯噪声”解释。** 同船变化较大的方向也承载类别差异；直接抑制会伤害识别。入射角与这些坐标存在响应关联，但同信息对照中直接使用角度比复杂同船校正更有利，路线转向条件化而不是宣称因果去噪。
- **10月9日，方向研究转成了更可用的支持关系设计。** 发现画面朝向敏感，推动C4处理；随后原方向残差模块中，用平均表示替代方向残差更好，说明收益不能简单归给恢复方向信息。源头重拟合也并非总有利，后续始终需要匹配对照。
- **10月9日至10日早期，分频得到增量，但动态选择主张收缩。** 旧5%交接协议下，学习分频的BA增量为24港/F/OSS2的+0.4577/+0.0714/+0.4199。用平均频带权重替代逐样本权重时，两个外部集预测完全不变、24港只变一条，支持的是表示和近乎固定的频带偏好，不能据此宣称灵活动态注意力。之后全量融合胜过旧5%策略，模块增量也随评价位置改变。

上述旧阶段记录用于解释思路演变；旧交接模型、类别对诊断、当前完整融合和新配平试验分别报告，不能拼成一张累计涨点表。

### 1. 有了可运行的模型，而不是只停在想法

当前保留的既有主线可以用下面的话概括：

> 用源港建立初始判断，再参考新港少量已标注船舶进行校正；全局表示、局部空间表示和可选第二表示分别提供证据，最后组合判断。

模型的主要部分为：

- 基础表示：R50多旋转视图聚合，降低固定朝向对表示的影响。
- 条件支持关系：不仅看待测船和支持船的特征是否接近，也考虑已有形态/成像描述条件。
- 局部表示：在中间特征图上分解Haar子带，经轻量空间处理，保留局部变化及空间排列。这里不是雷达电磁频段。
- 专家表示：保留坐标与剩余信息提供补充，旧双路还利用R18表示。
- 少标签校正：基础与专家共享同一组64个目标标签，不是各用64个。
- 最终输出：当前主要参考是两个头的等权概率融合。统一头也比较过，但统一头不等于只有一个特征骨干。

24港历史版本还包含候选稳定坐标和入射角处理；外部版本并非从始至终与它完全同构。后续已补外部匹配接入，不能把所有版本混写成一个统一训练配方。

### 2. 旧完整模型的成绩仍然保留

下表是既有完整模型中源先验匹配重拟合版本，不是10月11日的新自监督配平模型。

| 数据 | OA（%） | BA（%） |
| --- | ---: | ---: |
| 24港数据：23个有效留港任务 | 65.574 | 55.987 |
| F_0921 | 35.053 | 27.723 |
| OpenSARShip 2.0 | 42.597 | 34.674 |

24港按任务等权汇总，不能当作把所有图片混在一起计算的总体准确率。这里保留既有预训练和任务训练条件，尤其历史无标签数据接触范围；不能与新的干净配平实验直接相减，声称某个新模块带来了那部分差值。

### 3. “双路有用”已经有数字，但“必须双路”仍未成立

在既有匹配完整读出中，相对R50单骨干，第二路BA增量为：24港+3.799、F+1.759、OSS2+4.423个百分点。

同时，我们确实做了更强的反问，而非只删除第二路看掉点：

- 补齐24港中的23任务及F，合计72个任务/神经种子训练组合；OSS2既有三种子结果另行复用。
- 用单R50加源端小映射重建第二路表示：24港追回约75.31%的既有双路BA增量，但跨数据集恢复不稳定。
- 增加R18单用、共同读出、多种单路参照及冻结SARCLIP等比较。冻结基础模型不冒充充分适配的公开方法复现。
- 发现历史冻结R50的特定双极化输入适配只保留两通道之和；改为保留差分后24港/F改善，OSS2退化。它是实际输入限制，但不是所有单路失败的共同原因。
- 实测额外提取成本，区分纯神经提取、完整裁片到预测、批量及峰值显存边界。

因此目前正确的认识是：**现有两种表示可以互补，但不能把全部互补归因于网络数量，也不能说一个网络原则上学不到。**

### 4. 可解释性已从“看热图猜”推进到“能核算改变了什么”

我们现在能把影响分为：

- 源先验：还没参考目标64例时，源模型原本怎样判断。
- 支持关系：当前船与哪些标注案例关联，这些案例支持或反对哪些类别。
- 系数重拟合：加入新信息后，原有支持案例的作用也会重新分配。
- 融合或交接：基础头被救回后，最终输出是否真的跟着变正确，还是被另一头抵消。

已记录救回、误伤、逐类贡献、真实案例及全部64个支持项。它解释的是模型的计算和决策机制，还不能唯一对应到某种散射结构或物理因果因素。

## 四、哪些方向被收缩了，为什么

### 预算和自适应交接

最新匹配自适应交接相对全量融合，BA变化为24港-0.085、F-0.026、OSS2-1.167个百分点。原因不是完全不会选择，而是避免的错误少于被拒绝的正确纠错。

所以当前不再把“只交接5%”作为必须保留的创新。若两路特征都已经算完，选择率也不是神经计算节省率。

### 分频与动态注意力

分频/局部表示对基础头有作用，但传到完整融合的净收益往往较小。许多基础头救回的样本，融合原本就已正确；另一些仍受专家反向分数压制。

在历史配对完整融合中，加入分频的BA增量约为24港+0.103、F+0.013、OSS2+0.006个百分点。不能拿旧5%交接版本的较大变化替代这些当前融合增量，也不能把“分频表示有用”写成“动态频带选择已经证明有效”。

### 稳定空间、方向和角度

候选空间含有判别信息，不等于其全部贡献都来自跨域稳定性。漂移也可能包含类别信息，不能默认越压制越好。

入射角在匹配版本上曾给24港和OSS2带来约+0.364/+0.581个百分点融合BA。F角度覆盖从36.25%恢复到99.56%，是已完成的数据工作，但直接接入仍未提升BA；主要直接负作用可定位到源角度先验路径。不能将覆盖恢复或成像知识可获取写成分类精度已经改善。

这些方向不必一概放弃，但都应按任务、类别与接入位置限定结论，不把它们串成已证实的因果定律。

## 五、10月11日的关键新进展

### 第一阶段：在简洁、配平的读出中，自监督确实有效

相同R50、相同输入方式，仅增加源港SAR自监督；主比较没有使用F/OSS2像素训练编码器。

| 紧凑读出 | F BA（%） | OSS2 BA（%） |
| --- | ---: | ---: |
| 通用R50 | 22.195 | 27.508 |
| SAR自监督R50 | 23.253 | 30.912 |
| 配对增量（百分点） | +1.058 | +3.404 |

OA也分别提高约2.667/4.971个百分点。五组支持抽取均有BA正增量，但仅有一个神经训练种子。

进一步发现：R18单独评价选出的较好检查点，搭配R50时未必较好。**“自己强”与“能补充别人”是不同目标。** 不能独立训练两路后，就默认它们会形成有意义的分工。

### 第二阶段：直接接完整读出，收益反转

两路输入权限配平，并重新拟合PCA、尺度、先验，重新训练分频模块。新单路也保留完整读出，未故意削弱。

| 新配平完整读出 | F OA / BA（%） | OSS2 OA / BA（%） |
| --- | ---: | ---: |
| 通用R50单骨干 | 30.466 / 26.547 | 31.986 / 29.503 |
| 自监督R50单骨干 | 26.830 / 21.365 | 33.784 / 29.127 |
| 通用R50＋自监督R18 | 30.210 / 25.666 | 34.127 / 31.565 |
| 自监督R50＋自监督R18 | 27.445 / 21.917 | 34.420 / 29.555 |

这不是旧主模型成绩被覆盖。新实验更改了预训练信息权限、输入和源池，也没有复现历史专家监督尾部训练。

第二路在自监督R50之上仍增加约0.552/0.428个百分点BA，神经提取成本约增7.5%/9.3%；但它补不回整条接入路径的退化，更未成为所有数据集上最强的配置。

### 第三阶段：定位收益在哪里丢了

我们区分了两个问题，不能把它们的答案混为一谈：

1. 同一完整读出下，G50换成D50，F的主要直接损失在源分类先验路径。
2. 同一D50从紧凑读出换到完整原视图基础读出，主要损失在支持度量处理路径。

统一重提特征后，紧凑D50仍保持优势，排除了“先前全部只是缓存数值差异”的解释。

最有说明力的固定诊断是：保持D50及其源先验不变，OSS2基础头仅将支持核非恒定部分调整到原紧凑协议的尺度，BA从27.712升至30.931。也就是说，**学到的线索还在，64个参考案例修正判断的力度没有匹配好。**

但同样处理会伤害通用R50，F也只部分恢复。因此核尺度是已证实的重要计算因素，不是全部问题的唯一根因；PCA截断、中心化、白化与任务差异仍需谨慎区分。此处是事后诊断基础头，不是完整模型已取得的新主成绩。

过程中实际修复了后端设置/缓存一致性与Haar训练推理精度差异，保留原尝试。实现修正不被包装为科学创新。

## 六、截至目前，该怎样看这项研究

### 已站住的部分

- 少量目标支持案例确实是模型利用信息的重要通道，不能只研究源域分类器。
- 现有双路存在可核算的互补收益，源先验和支持关系的贡献随数据变化。
- 部分互补可由单骨干已有表示恢复，两个骨干并非天然必要。
- SAR自监督在本轮受控紧凑读出上有效，而且不需要增加推理骨干数量。
- 表征变好不保证直接接入完整模型后变好；本轮给出了读出匹配失效及部分恢复的实验证据。

### 不该提前宣称的部分

- 没有发现绝对跨域不变量、纯噪声空间或物理因果定律。
- 没有证明两路分别专门对应轮廓和散射，也没有证明它们优于任何强单骨干。
- 没有证明动态频带注意力或自适应预算普遍优于简单固定策略。
- 没有完成所有强公开方法的充分适配比较，也不能仅凭模块数量认定顶刊级创新已经完成。
- 新实验仍主要是开发数据上的证据。近期未扩大FUSAR、OSS1或通用跨域任务；五次支持抽取不冒充五次神经训练。

## 七、接下来收敛到什么方向

研究目标保持不变：**在跨港、跨数据集变化下，用少量目标标注获得可靠的船型识别。** 可以调整的是达到目标的结构，而不是为保留原来的模块名称牺牲证据。

建议按下面的顺序推进，而非同时再开多条模块搜索：

1. 先把SAR自监督表示与实际支持校正读出配好。训练、源港选模、归一化和核尺度应面向同一部署流程；先在源港确定配置，不能看外部查询成绩选参数。
2. 建立修正后的强单路参考，再加入第二路。只保留能够带来稳定净纠错、且成本合理的补充；第二路按组合效用而非自身准确率训练/选择。
3. 固定有证据的模型后，再补必要的重复与外部比较。暂不重启普遍门控、因果命名或模块数量竞赛。

论文可以围绕“跨港少样本支持校正中的证据利用与迁移失配”组织问题和实验，再由最终有效的方法确定模块表达。这是当前写作建议，不是已经完成文献对比后的唯一新颖性结论。

## 八、向导师可以这样概括

> 我们最初研究跨港条件下的预算专家交接，后来发现真正的问题不只是决定让谁处理样本，还在于如何利用少量目标标注去纠正跨域偏差。我们已经建立了完整模型，在24港、F_0921和OpenSARShip 2.0上做了模块、单双路和交接比较，并能追踪每个支持案例如何影响决策。结果表明，双路有互补但不是天然必要，自适应交接也没有稳定胜过全量融合。最近进一步发现，SAR自监督可以改善单骨干，但收益可能被下游度量和读出处理削弱；通过固定干预已经定位了重要的失配环节。下一步不再盲目增加模块，而是先把表征学习与支持校正配好，再判断第二路是否值得保留。
