# 第二路为何形成互补：固定先验/支持关系交叉诊断

日期：2026-10-10。

## 结论先说

当前双路的价值不是“一个看轮廓、另一个看散射”，而是：**两种不同输入处理和训练经历形成的表示，对类别的源端判断、以及目标船与64个支持案例的关联方式不同。第二路带来的这些变化，在现有固定配方下有净纠错收益，且主要集中在单路决策接近边界的样本。**

本轮已完成25任务、原五组64标签、13种读出，共1625条任务/抽样/模式OA和BA记录。23港外留任务、F_0921、OpenSARShip2.0全部覆盖。没有新神经训练、没有置乱检验、没有查询标签选参数。

这轮把“哪里发生作用”解释到了源先验、支持关系和每个支持案例的有符号贡献。但还没有证明某种不可被单骨干学会的信息，也没有证明不同网络必然对应不同物理成因。单骨干能否重建第二路以及真实计算代价，由主线独立实验回答，本文件不代报完成。

## 严格匹配了什么

- 所有臂保留完全相同的最新基础头：C4、条件支持核和已训练分频分支均不变。
- 复用 `backbone_ablation_20261010` 中同源队列重新拟合后的两套源分类系数。不是旧未重拟合主模型的先验。
- R50-only专家保留R50 PCA128维和R50补空间2048维；dual额外保留SSL PCA64维和补空间512维。现有除数sqrt(192)、sqrt(2560)不变。
- 24港仍保留相同的稳定、漂移处理和入射角项；外部数据集没有偷偷换成后来探索过的知识版本。
- 每次只交换专家先验或专家核；64个支持样本、类别平衡权重、ridge强度8、等权融合比例都不变。
- RR与DD对角线以及基础头，在全部25任务/5抽样中精确复现上轮匹配实验的分类结果。没有以原未重拟合外部模型作为伪对角线。

记号：第一位是源分类先验，第二位是专家支持关系核；R表示R50-only，D表示dual。RR是单路对照，DR只换先验，RD只换核，DD两者都换。每个交叉臂都重新用同64个标签求解残差系数，并非只把测试端分数随意替换。

这些结论定位的是算法计算路径，不是对网络深度、预训练语料、输入极化或物理散射成因的分别归因。

## 2. 不是在所有样本上都同样有用

按匹配单路完整融合的top1-top2概率差分三档，阈值在本轮指标读取前固定：小于0.05为不确定，0.05至0.20为中等，大于等于0.20为较强。这是模型自身概率差，不是经校准的正确率。

| 数据集 | 不确定样本净纠错OA百分点 | 中等样本 | 较强样本 |
| --- | ---: | ---: | ---: |
| 24港 | +8.10017 | +1.53740 | +0.05783 |
| F_0921 | +5.12288 | +1.36223 | 0.00000 |
| OSS2 | +12.00654 | +6.05052 | +0.43956 |

这里是各档全部查询曝光次数的汇总，不是23港宏平均，不能直接与上一节BA相加或相互替代。

新增第二路主要改变本来难分的样本，对原来分数优势很大的样本影响小。它不是只会纠错：在不确定档中，单路原来正确的样本被误改的比例也不低，三套数据分别约20.04%、32.69%、31.08%；同时救回原来错误样本约25.89%、18.20%、27.95%，加上错误基数不同，得到上述净收益。保留这些误改是说明可靠边界的必要部分。

这提示“边界样本互补”是现有现象，而不是直接证明某个自适应交接策略已有效。本轮没有根据这些查询结果训练门控或选择预算。

## 4. 精确到每个支持案例的计算解释

令单路专家分数为 `eR = pR + KR aR`，双路为 `eD = pD + KD aD`，并定义新增关系核 `Kssl = KD - KR`。

则逐样本、逐类别精确成立：

```text
eD - eR = (pD - pR) + KR (aD - aR) + Kssl aD
             源先验变化     原有关系重新分配系数     新增关系直接项
```

第二路不只是向分类分数加一个独立常数。它改变支持集求解矩阵，使原有R50关系上的系数也跟着变化。在被最终融合救回的样本中，对“真类减去单路专家最强错误类”的平均logit变化如下：

| 数据集 | 源先验变化 | 原有关系重分配 | 新增SSL关系直接项 |
| --- | ---: | ---: | ---: |
| 24港 | +0.31900 | -0.04165 | +0.48896 |
| F_0921 | +0.27722 | -0.16105 | +0.64881 |
| OSS2 | +0.36116 | -0.19301 | +0.81499 |

这些是救回事件内、按查询曝光次数汇总的logit变化，不是百分点，更不是三条路径的独立因果贡献比例。以双路系数表达的直接项可以被原有关系系数变化部分抵消，因此F在这里的直接项很大，与第一节“只换核的总体BA提升小”不矛盾。前者是特定结果子集上的代数记账，后者是重求系数后的全样本受控干预。

最终融合是 `0.5 softmax(base) + 0.5 softmax(expert)`，所以：

```text
fusionD - fusionR = 0.5 * [softmax(eD) - softmax(eR)]
```

不能将上述三个logit项直接当成融合概率项相加。案例中额外提供按“先验、系数重分配、新增核”顺序逐步应用softmax的概率变化；顺序已明确标注，这种非线性分配依赖顺序，不被宣称为唯一归因。

所有样本代数分解最大绝对误差2.23e-14以内，最终概率变化核对误差1.12e-16以内。分块浮点投影与历史整块计算使系数末位最多变化5.40e-8，但所有既有对角线分类预测完全相同，未混称特征或系数逐位相同。

## 6. 两路到底有哪些已核实的不同

| 项目 | R50路 | SSL-R18路 |
| --- | --- | --- |
| 预训练 | ImageNet ResNet50 V2 | e206：本地SAR语料上的SimCLR/NT-Xent，从随机R18初始化训练 |
| 输入 | VV/VH双通道，RGB首层均值扩成两通道 | 部署读取VH灰度复制RGB，三个通道相同，不是彩色信息 |
| 归一化 | `(x/255 - 0.5)/0.25` | ToTensor，0..1，无ImageNet归一化 |
| 后续表征训练 | 本配对实验中的R50冻结 | 固定前缀至layer3，layer4经过源支持/查询残差目标训练；BN统计冻结 |
| 当前模型作用 | 完整基础头，并向专家提供R50保留坐标与补空间 | 向专家提供64维保留坐标与512维补空间，改变源先验和支持关系 |

源码依据：

- `E:/临时会话/visual_reliable_baseline/extract_full_six_spatial_features.py`：`build_encoder`中R50V2和双通道首层。
- `E:/临时会话/visual_reliable_baseline/e206_ssl_pretrain.py`：SimCLR、NT-Xent、随机R18初始化、裁剪/翻转/旋转/亮度对比度增强。
- `E:/Hermes/paper_tracking/sensitivity/oof_reliability_check/train_neural_complement.py`：`cache_prefix(channel=1)`，VH复制3通道、0..1输入。
- `.../sar_joint_completion.py`：公开数据目标提取读取`chip_path_vh`。
- `.../train_joint_residual.py`和`neural_complement.py`：layer4训练、冻结前缀和BN统计、支持残差目标。
- `.../backbone_ablation_core.py`、`dual_evidence_core.py`：实际单/双路源先验、核和保持不变的归一化。

因此两路并非“只是深度不同”。但本轮没有逐个分离预训练、深度、归一化、极化输入和训练目标的独立效应，只能说这些真实差异共同构成当前异质表示。F_0921原本进入过无标签SSL预训练语料，必须保留这一历史边界，不能把F称为编码器完全未见外部确认集。

两路都会接触船体结构、纹理、局部亮暗和环境信息。没有证据要求把它们人为拆成不同的物理感知器。

## 7. 现在可以说什么，不能说什么

**可以说：**在固定R50表示、相同源队列和同64支持标签下，第二路增量不是仅靠融合形式产生。源先验交叉和支持核交叉已经定位了增量入口，逐类、逐港、置信档和逐支持案例进一步说明它在什么情况下纠错或误改。这支持保留当前双路作为有效异质表示组合。

**尚不能说：**第二路包含原图没有的新物理信息；单骨干原则上学不到这些信息；因两个网络深度不同就必然互补；模型发现了因果不变量；源先验或支持核在所有数据集/类别普遍有益；当前双路必然比任何单骨干更划算。

本轮不增加无关训练，只把已有正负结果解释清楚。成本是否值得、单骨干能否用附加映射恢复相同证据，应与主线另两个配对实验一起判断。
