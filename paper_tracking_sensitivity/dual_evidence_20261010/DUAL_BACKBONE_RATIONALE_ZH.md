# 双骨干互补证据与待验证边界

日期：2026-10-10。本文合并本轮计算路径、单路重建、训练阶段和真实成本四组证据。正文精度均来自相同源队列重新拟合后的匹配对照，不与旧的外部数据源先验混用。

**后续决策修订：用户要求必须面对公平协议下的强单骨干，才能决定是否坚持双路。现有消融和重建未满足这一条件，双路暂为候选，不再据此确认为论文主方案。** 具体比较与保留/放弃规则见 `E:/Hermes/paper_tracking/sensitivity/strong_single_protocol_20261010/FAIR_COMPARISON_ZH.md`。下述历史数值全部保留，不把待做比较写成已完成。

## 结论先说

**当前消融证实模型利用了第二路，增量可以量化；但尚不足以据此坚持双骨干。** 不能解释成两个网络分别对应两种独占的物理机制，也不能解释成单骨干原则上不可能获得这些信息。

目前更合适的说法是：保持通用R50表示不变，引入具有不同输入处理和训练经历的SAR表示，补充源端类别判断及目标支持案例关系；源端残差训练进一步增强了这个补充作用。相同标签预算下，现有双路在三个数据集上均优于本轮两个单路重建替代，也有明确但不是免费的推理成本。

与此同时，24港的第二路收益已有约75%能由R50现有表示加小型映射追回。这说明“第二路全部提供第一路没有的信息”是错误的表述。双路目前只定位为有待强单比较的候选，单路任务导向压缩是已有正信号的效率方向。

## 一、两路不只是网络深度不同

| 项目 | R50路 | SSL-R18路 |
| --- | --- | --- |
| 初始化/预训练 | ImageNet ResNet50 V2 | 本地SAR语料SimCLR/NT-Xent，自随机R18初始化训练 |
| 输入 | VV/VH双通道 | VH灰度复制为三通道 |
| 归一化 | `(x/255-0.5)/0.25` | 0至1的ToTensor |
| 当前后续训练 | 骨干冻结 | layer3以前冻结，layer4接受源港支持/查询残差任务训练，BN统计冻结 |
| 模型内作用 | 完整基础分支，并为专家提供128维保留坐标与2048维补空间 | 向专家额外提供64维保留坐标与512维补空间 |

两路都能接触船体轮廓、局部亮暗和空间排列。本文不把其中一路命名为“轮廓专用”、另一路命名为“散射专用”。上述差异均有实现依据，但除后续残差训练外，没有逐项隔离其独立效应。

代码来源及九组真实案例，详见同目录 `FINDINGS_ZH.md`。

## 二、第二路具体补充了什么

把专家表示的作用拆为两条路径：

1. **源分类先验**：在看当前64个目标标签之前，这条表示如何评价各船型。
2. **目标支持关系**：当前船与64个标注案例怎样关联，这些关系如何修正类别分数。

固定完整基础分支，分别交换专家先验和支持核，每个交叉臂均用同64个标签重新解残差系数。最终融合BA如下，单位为百分比。

| 专家配置 | 24港：23个外留任务 | F_0921 | OpenSARShip 2.0 |
| --- | ---: | ---: | ---: |
| 单路先验、单路关系 | 52.18780 | 25.96470 | 30.25166 |
| 双路先验、单路关系 | 54.80819 | 27.40876 | 30.53641 |
| 单路先验、双路关系 | 54.33223 | 26.35161 | 33.29164 |
| 双路先验、双路关系 | 55.98728 | 27.72335 | 34.67442 |

- 24港：两条路径都重要，有部分冗余，单独增益不能相加。
- F_0921：主要经由更合适的源分类先验进入，单独换支持关系的提升较小。
- OSS2：主要经由支持关系进入；单独换先验只有0.28475个百分点，单独换关系有3.03998个百分点。

因此第二路不是统一地“增加某种物理线索”，而是在不同数据上修补不同的分类短板。逐类收益也会反向，不能把某个船型永久分配给某条网络。

## 三、为什么这些互补会被学出来：新增训练阶段对照

仅仅观察两个网络不同还不够。本轮增加了一个保持R18架构、输入方式、自监督初始化和当前部署算子不变的对照：用源端残差训练前的冻结R18特征，替换源、目标两侧的训练后特征，并重新拟合源分类头。没有只替换测试特征造成训练/部署错配。

| 配置，最终融合BA | 24港 | F_0921 | OSS2 |
| --- | ---: | ---: | ---: |
| 只有R50 | 52.18780 | 25.96470 | 30.25166 |
| R50加自监督R18，尚无后续残差训练 | 54.28468 | 26.70654 | 32.32652 |
| R50加源端残差训练后的R18 | 55.98728 | 27.72335 | 34.67442 |
| 后续残差训练的增量，百分点 | +1.70260 | +1.01682 | +2.34790 |

这个结果支持两件具体的事：

- 训练前的SAR自监督分支组合已经能补充当前R50。
- 同一个R18经过支持/查询残差任务训练后，补充作用进一步增强，不能把收益全部解释为多加了一个不同深度的网络。

它还不能独立区分“自监督目标、SAR预训练语料、VH输入、网络架构”分别贡献多少。尤其不能把第一步的收益全部归给SAR预训练本身。要回答这一更细问题，需要保持架构与输入一致、仅交换预训练方式的专门对照，本轮没有完成该对照。

## 四、在单骨干计算中能否得到这些信息

不是只删除R18观察掉点。本轮真正训练了两个不需要目标样本拟合的替代器：

```text
已经存在的R50原视图2048维 + C4均值2048维
    -> 源端标准化
    -> 固定线性岭回归，或4096-512-512的GELU映射
    -> 重建任务对应的R18的512维表示
    -> 原专家坐标、补空间与残差分类流程
```

映射只在每个任务允许的源样本上训练。小型MLP共有2,360,320个参数，固定8轮；没有目标选择检查点。部署输入不再需要运行R18，但训练仍使用R18教师。源分类头在重建特征上重新拟合，保持同一组5次64标签支持适配。

| 最终融合BA | 24港 | F_0921 | OSS2 |
| --- | ---: | ---: | ---: |
| R50-only | 52.18780 | 25.96470 | 30.25166 |
| R50加线性重建 | 54.26512 | 23.85217 | 32.12141 |
| R50加小型MLP重建 | 55.04905 | 24.65328 | 31.00523 |
| 实际双骨干 | 55.98728 | 27.72335 | 34.67442 |

**24港不是“学不到”。** MLP提高2.86125个百分点，追回当前双路增益的75.31%，距离实际双路还差0.93823个百分点。源端教师知识可以部分转成R50现有特征上的读出能力。

**跨数据集映射还不稳定。** OSS2线性重建追回42.28%的双路增益，MLP反而更少；F两种重建均比不加映射退化。不能挑每个目标数据集表现最好的映射拼成一个“主模型”。

标准化教师特征的目标方差加权R2如下。这不是分类准确率，也不代表物理信息比例。

| 映射 | 24港任务均值 | F_0921 | OSS2 |
| --- | ---: | ---: | ---: |
| 线性 | 0.50686 | -1.53419 | 0.01848 |
| MLP | 0.567995 | -0.86245 | 0.04192 |

源内标准化MSE约0.20至0.28，目标误差明显扩大，尤其在F。说明当前源端拟合好的跨表示映射没有稳定外推；但低特征重建误差也不保证更高分类收益，OSS2的MLP就是反例。不能用本轮两个失败替代器证明更强单骨干不可能实现同样效果。

F还有一个不能忽略的解释边界：其教师曾接触F的无标签SSL语料，而本轮映射只用允许的源港样本训练。没有重训完全未接触F的教师，因此历史语料暴露与表示差异尚未分离，不能把F重建失败全部归因于单骨干容量不足。

**F失败已做限定根因诊断，而非只报告掉点：**只换学生源先验时，线性/MLP的BA分别为22.74097/23.86311；只换学生支持核时为25.42085/25.52294，原单路为25.96470。主要直接退化落在源先验路径。源标准化输入坐标平均平方值由源端1.00变为目标44.74，说明当前映射面临明显外推条件变化。所有对角线预测精确回放，未发现源/目标接入错配；这些证据支持外推不稳，但不证明它是唯一成因。完整诊断在 `E:/Hermes/paper_tracking/sensitivity/dual_reconstruction_20261010/f0921_diagnosis/FINDINGS_ZH.md`。

## 六、决策解释如何接到表示互补上

单路专家为 `eR=pR+KR*aR`，双路为 `eD=pD+KD*aD`，则精确成立：

```text
eD-eR = (pD-pR) + KR*(aD-aR) + (KD-KR)*aD
          先验变化      原关系系数重分配       新增关系直接项
```

这不只是贴一张热图：每条支持案例到底支持还是反对哪个类别，都有数值记录；新增关系还会改变原R50关系的残差系数。最终softmax融合另按概率核对，不能把logit贡献直接当成概率贡献。

本轮给出九张真实案例卡，覆盖纠错、误改、双方都错，每例保留全部64个支持案例、8个输出类别的有符号贡献。图只展示绝对变化最大的四个支持案例，不隐藏反向贡献。

示例：`E:/Hermes/paper_tracking/sensitivity/dual_evidence_20261010/cases/oss2/dual_rescue/card.png`。该查询真类为成品油/化学品船，单路判为杂货船，双路救回。这说明模型怎样改变判断，不证明图中某个亮点对应特定散射机理。

## 七、论文里可以怎样说

> 我们不预设不同骨干对应互斥的物理线索，而将第二分支视为对固定通用表示的任务相关补充。通过匹配源分类先验与支持关系核的交叉实验，我们定位了第二分支在不同数据集中的增益入口；同架构的训练阶段对照进一步表明，源端残差任务训练能够增强该补充作用。单骨干重建实验显示，部分收益可由已有表示恢复，但当前固定重建器尚不能在三个数据集上一致替代实际第二分支。这些结果尚未证明双路优于公平训练的强单骨干；是否采用双路作为最终方案，应由该比较及相应精度-成本结果决定。

“两路为何形成互补”的解释现在有了训练干预和功能路径证据，但尚未达到对所有预训练、输入、架构因素的逐项归因，更不是物理因果发现。论文不应声称当前组合优于任何单骨干，也不应把网络数量本身当作创新。

所有数据均为研发使用过的数据。五组支持抽样不是五个网络随机种子；F历史无标签SSL暴露仍保留。这里没有将本轮对照包装成全新的独立确认。
