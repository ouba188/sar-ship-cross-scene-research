# 频带表征与候选支持比较联合训练

日期：2026-10-09。状态：训练、完整评估、匹配对照和解释诊断已完成。

## 一、结论

**联合训练已真正接入表征，并产生了小幅正信号，但新增比较监督尚未证明优于普通续训。**

固定联合版相对原模型：自建24港完整BA +0.0621个百分点，F_0921 +0.0144，OpenSARShip 2.0 -0.1228。相同训练步数的普通续训在24港反而更好，不能把所有涨点记到新监督名下。

本轮比“又一个负结果”更重要的定位是：在OSS2的实际改判难例中，比较损失下降主要来自**仍然判错的样本变得不那么自信**，不是更多样本被分对；两个少数类样本还因特征几何改变，跨过了原本很小的正确分类间隔。这两例与专家交接无关。

保留正负结果和所有检查点，不替换原主方案，不按目标结果拼接最优数据集版本。

## 二、这轮实际训练了什么

冻结R50主干和既有layer2特征图。可训练部分仍为原有35,876参数的频带处理器与门控，不是主干端到端微调，也没有增加一个更大的后处理网络。

从各任务原`selective.pt`出发，做匹配的三轮训练：

| 版本 | 训练内容 |
|---|---|
| `learned` | 原模型，不训练 |
| `continued_ce` | 仅继续原支持岭回归分类的类别平衡交叉熵 |
| `joint_kernel` | 相同交叉熵 + 0.1倍局部支持比较损失 |
| `joint_compare` | 使用联合模型，再以其视觉证据选择原/新完整分数 |
| `source_selected` | 仅在源端未参与神经训练的查询上，从上述版本选取 |

两训练分支的初始化、批次、轮数、学习率一致：AdamW，lr=0.0003，weight_decay=0.001，梯度裁剪5。复用原训练最初三轮的查询计划，没有新增神经训练查询；检查了它们与源端验证查询不重合。

### 比较监督

四频带各自保留16通道×2×2位置。针对每个候选类，比较：整体余弦、对应位置余弦、双向最近位置余弦，三项平均。类内支持attention由整体相似度和已有条件坐标距离确定。

这次重新乘回查询与支持的频带幅度乘积，保留原门控权重；不再用逐特征RMS把弱分支放大。它是可微的，梯度进入频带处理器和门控。

训练损失：

`L = 类别平衡分类CE + 0.1 × 类别平衡softplus((错误候选视觉分数 - 真实类视觉分数) / 0.1)`。

错误候选来自当前分类器分数最高的可支持错误类别。真实类和错误候选都至少有2个支持样本，否则不计比较损失，但仍参加原分类损失。

64个目标标签、5次支持抽样、原专家、最多5%交接均不变。所有25任务预测冻结后才读取目标评估标签。源端选择用了未被原六轮神经训练抽中的查询行，但表征见过对应源港的其他行，因此不是独立内层留港验证。

## 三、完整模型结果

数值为OA / BA（%）。24港体系有23个实际评估港，按港等权；外部数据集按5次支持抽样平均。差值单位为百分点。

| 方案 | 自建24港 | F_0921 | OpenSARShip 2.0 |
|---|---:|---:|---:|
| 原频带主模型 | 63.2084 / 54.2383 | 31.1072 / 26.3593 | 35.3545 / 32.3724 |
| 普通续训 | **63.2780 / 54.3294** | 31.1112 / 26.3697 | 35.3056 / 32.3284 |
| 联合表征 | 63.2666 / 54.3004 | 31.1036 / **26.3737** | 35.3274 / 32.2497 |
| 联合表征+比较决策 | 63.2495 / 54.2877 | 31.1063 / 26.3635 | 35.4034 / 32.3292 |
| 源端选择 | 63.2547 / 54.2850 | 31.1112 / 26.3697 | 35.3056 / 32.3284 |

源端选中了12个普通续训、7个联合表征、5个联合比较、1个原模型。外部两个任务均选普通续训，源端收益不保证外部目标端收益。

最关键的匹配对照：联合表征减去普通续训，完整OA/BA变化分别为：

- 24港：-0.0114 / -0.0290。
- F_0921：-0.0076 / +0.0041。
- OSS2：+0.0217 / -0.0787。

所以新比较监督目前没有一致的额外收益。F的BA微升伴随OA和固定8类macro-F1微降，需要并列保留，不能只取有利指标。

## 四、收益在哪个环节

相对原主模型的BA变化：

| 数据集与方案 | 基础分类 | 固定原交接名单 | 完整系统重新交接 |
|---|---:|---:|---:|
| 24港普通续训 | +0.0828 | +0.0127 | +0.0911 |
| 24港联合表征 | +0.0277 | -0.0123 | +0.0621 |
| F普通续训 | +0.0128 | +0.0071 | +0.0104 |
| F联合表征 | +0.0246 | +0.0184 | +0.0144 |
| OSS2普通续训 | -0.0875 | -0.0959 | -0.0441 |
| OSS2联合表征 | -0.1572 | -0.1686 | -0.1228 |

24港联合表征的基础分类有正信号，不是完全没学到东西；但被专家接管与未接管样本的收益分布不同，固定交接后转负。普通续训在三个环节均有更强的24港BA收益。

F联合表征的BA小幅收益在基础分类和固定交接下也存在，值得保留为正信号，但未形成OA同步改善或跨数据集一致提升。

联合版相对原主模型，24港BA在5次抽样中4次为正，F为3次，OSS2为1次。这是支持集抽样重复，不是5次独立神经训练。

## 五、确实学了，但学到什么

### 1. 梯度和特征都变了

11项独立测试通过，覆盖门控幅度保留、局部匹配公式、支持重排、类别mask、hard negative、类别平衡loss、查询/支持梯度以及频带blocks/gate梯度。

实际检查点参数发生变化；目标嵌入与原嵌入的平均余弦：联合版在24港/F/OSS2约为0.9725/0.9905/0.9799。不能把“不够涨点”解释成梯度断开或模块没有接上。

### 2. 目标端的比较能力并非完全没有改善

预先固定了两类诊断样本：每任务每抽样最多512个随机评估样本，以及最多512个原模型与联合模型实际分歧样本。选择不使用真实标签。所有模型比较同一真实类别与同一原模型错误候选；结果是二者之间的类别平衡比较准确率，不是完整八分类BA。

| 数据集 | 普通续训：随机样本比较准确率 | 联合版：随机样本 | 普通续训：改判难例 | 联合版：改判难例 |
|---|---:|---:|---:|---:|
| 自建24港 | 61.5127 | 61.5756 | 53.8452 | 54.1254 |
| F_0921 | 46.2373 | 47.3950 | 44.4441 | 45.0494 |
| OSS2 | 50.2080 | 51.5070 | 47.5987 | 45.7707 |

联合版相对普通续训，在随机样本上比较能力有所提升，但OSS2真正发生改判的难例反而下降1.8280个百分点。不能用总体相似度改善代替对关键决策的检验。

## 六、为什么loss下降，难例反而没有分得更准

OSS2改判难例上，联合版相对普通续训的比较损失从1.0212降至0.9020，但比较准确率从47.5987降至45.7707。

对同一批样本逐项核算，平均损失变化约-0.1193：

| 样本组 | 对总比较损失变化的贡献 |
|---|---:|
| 两版都判错 | **-0.1310** |
| 两版都判对 | +0.0155 |
| 原错、新对 | -0.0186 |
| 原对、新错 | +0.0148 |

**损失降低主要来自两版都错的样本。** 这一组平均真实类减错误类的视觉间隔由约-0.1156变成-0.0910，离零近了一些，但仍在错误一侧。与此同时，一部分原先正确的小间隔被推过零。

这不是说softplus无效，而是本轮训练证明了：降低连续比较损失，不足以保证保住原有正确边界或增加实际正确决策。该结论限于这里的匹配对照和诊断集合，不是所有任务上的普遍因果定律。

## 七、两个少数类错误的完整解释

OSS2抽样1中，海工补给船有52个评估样本、3个目标支持样本。联合版相对普通续训多错了两艘，都误判成成品油/化学品船。

这两次错误使海工补给船的平均召回下降0.7692个百分点，对8类平均BA贡献约-0.0962个百分点。其他类别的正变化抵消了一部分，最终完整BA净差为-0.0787。完整系统在全部样本上相对普通续训修复49次、弄错45次，OA反而略升；因此OA与BA相反并不矛盾。

对这两例，将分类间隔变化精确分解为：

`新分数 - 续训分数 = 旧核 × (新支持系数 - 旧支持系数) + (新核 - 旧核) × 新支持系数`。

| 样本ID | 普通续训正确类间隔 | 支持系数重拟合贡献 | 特征核变化贡献 | 联合版间隔 |
|---|---:|---:|---:|---:|
| pub2_opensarship2_002403 | +0.002961 | +0.004563 | **-0.011410** | -0.003886 |
| pub2_opensarship2_008931 | +0.001989 | +0.005721 | **-0.023351** | -0.015640 |

两例的系数重拟合项其实在帮助正确类，负向的特征相似关系变化更大，把原本很小的正确边界推翻。普通续训和联合版在这两例都未触发专家交接，所以不是路由造成的错误。

比较决策救回了第二例，未救回第一例。两例均保存了样本ID、各版本预测、支持数量和数值分解。这个分解解释模型内部的分数来源，不代表已经识别出具体雷达物理因素。

## 八、优化协调问题：已观测到，但不夸大归因

原比较loss系数0.1并不意味着梯度只有主任务的十分之一。对每个任务原始检查点的相同首批源样本，直接计算模型参数梯度：加权比较梯度/分类梯度的中位数为4.169，范围1.151至8.730。

在OSS2对应源端，门控参数的两项梯度余弦约-0.9973，加权范数比约25.95，方向几乎相反；F门控余弦约-0.9993，但加权比仅0.7067。频带blocks整体梯度在这些首批样本上则为正相关，不能说整个网络的两项梯度都相反。

门控梯度的绝对量很小，首批诊断也不能代表整段训练。**不能只凭“26倍”认定它是退化的唯一或主要根因。** 可以确定的是，存在局部优化冲突和明显尺度差异，后续应显式处理，而非把一个未经校准的固定系数视为天然协调。

## 九、下一轮的针对性方向

这轮不继续追加阈值或目标端调参。下一轮应优先修正联合训练约束，而不是再增加一个后处理门控：

1. 保留源端原模型已经正确的类别间隔，再学习新增比较证据，避免“损失下降但把正确边界推翻”。这是由两例分数分解与难例损失核算共同支持的设计方向，尚未实现。
2. 对辅助比较进入频带门控的梯度做隔离对照，并仅用源端梯度标定监督强度，区分门控冲突与表征学习本身的作用。不能把多个修改混在一起后直接归因。

普通续训在24港的OA/BA同时提升，保留为有效研发结果；联合监督在F的微小BA正信号也保留，但不包装成已验证的普遍创新收益。
