# 固定 joint 模型交接预算扫描

## 问题与口径

本报告比较原 5% 上限与 10%、20%、50%、100% 门控上限：放宽预算能否改善最终 OA/BA，新增交接带来多少纠正与伤害，以及收益是否集中在少数任务。0% 是 base 对照；全 expert 是独立对照。

模型与预测固定，不重新训练，不用 query 标签选择策略，也不按 oracle 排序。5% 与原 joint 结果的精确重放校验由主重放程序负责，本报告生成器不宣称独立完成该校验。

每个任务先平均 draw 0..4，再在各数据集内对任务等权平均；任务数依次为 self24ports 23、F0921 1、OSS1 1、OSS2 1、PACS 4、OfficeHome 4。不按 query 样本数池化，也不把五次支持集抽样当作五次独立神经网络训练。

100% 门控仅取消预算截断，仍要求 base/expert 分歧、observed-class 条件及 score > 0；因此实际交接率未必为 100%。全 expert 不使用 eligibility 或 score 过滤，selected=evaluated；changed 仅统计预测分歧，不能与 selected 混为一谈。

OA、BA、实际交接率以 % 表示，差值以百分点（pp）表示。纠正、伤害、净纠正、selected、changed、eligible 和 evaluated 均为“每任务平均计数”，即先平均五次 draw 后再平均任务，允许小数；evaluated 是每任务 query 标签分母的均值，不是池化总标签数，不能用平均计数之比替代平均准确率或交接率。

## 各数据集最终表现与累计效用

纠正=base 错而最终预测对；伤害=base 对而最终预测错；净纠正=纠正−伤害。累计纠正/伤害均相对 base，Δ5% 才是相对原预算的性能变化。

## 机会与边界

放宽上限提供释放已有 expert 纠错能力的机会。是否值得扩展，应结合相对 5% 的最终 OA/BA、新增纠正与伤害以及正收益任务覆盖来看；均值改善不保证每个任务或每个类别改善。

若预算继续增加而实际交接及指标不变，说明当前候选或正分筛选已饱和；若新增伤害抵消新增纠正，则扩大预算并不自动带来收益。BA 与 OA 反向时存在类别平衡权衡，这里没有逐类结果，不能把变化归因于某个具体类别。

该实验衡量固定模型与固定打分下的交接预算敏感性，不证明新的最优策略、统计显著性或盲测泛化。selected 与实际交接率仅刻画决策交接，不能解释为实际计算量、延迟或能耗下降；本报告没有开展计算节省测量。

task_means.csv 保留全部逐任务均值与相对 5% 差值；dataset_means.csv 保留数据集均值；summary.json 同时保存任务异质性、边际增量、单位和策略定义。
