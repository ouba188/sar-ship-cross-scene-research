# 当前模型管线与证据闭环

> 同日后续更新：下文保留补实验前的审计记录。C4、最新融合模块消融、单/双骨干、外部稳定/角度接入和稳定先验/核诊断已补；最新状态与数值见 [补实验汇总](../completion_20261010/CLOSEOUT_ZH.md)，不要把下文的待补项继续当作未开展。

日期：2026-10-10。范围：原双头等权概率融合与统一目标适配头。本文核对既有代码和实验，不新增实验、不覆盖冻结模型或论文。

## 1. 结论

当前模型不是完全不可解释的黑箱。能够追踪输入表示、支持案例关系、残差系数、类别分数变化和最终决策，也有表示替换、匹配训练和机制干预证据。但还不能说每个组件都在当前完整融合模型中完成了独立增益闭环。

关键缺口是版本口径：C4、条件支持和分频的若干模块实验采用旧5%交接输出；当前双头等权全量融合已经改变了最终输出机制。旧结果说明这些改进有价值，但不能直接充当新模型每个模块的消融，也不能将它们的增量相加。

论文应围绕“少量目标标注下，如何读取跨港可用的判别证据并校正源模型”组织，而不是给历史上所有尝试各安排一个创新模块。目前以BA为主时，保留双头等权融合更合适；统一头是有效的结构对照，不是已经失败的全部单模型路线。

## 2. 两种版本共用的设定

- 自建24港采用23个有效留港任务；另有F_0921和OpenSARShip 2.0。当前对照共25任务，每任务五次支持集抽样。
- 每次一共64个目标标注样本，两路共享，不是每路再标64个。支持样本从该次查询评估中排除。
- 始终输出八类，即使一个目标港实际不含齐八类。BA按查询中实际存在的类别计算；24港结果先按任务计算，再等权汇总。
- 源域阶段拟合表示、先验、几何与相应选择参数；目标阶段冻结神经网络，用64标签解残差适配系数。查询真值不进入该次拟合。
- 五次支持抽样不是五个网络训练种子，也不是五个独立数据集。数据已有反复研发使用，不称独立确认。
- 两路共用新接口，不等于所有数据集上游完全同构。24港保留候选稳定/漂移坐标和入射角处理；两个外部集采用原有外部PCA/源先验几何。不能将24港特有组件的收益自动推广到外部集。

## 3. 共同前端：两路分别看什么

### 3.1 基础路：平均信息与条件分频支持证据

```text
VV/VH配对裁片
  +-> 四个直角显示方向 -> 冻结R50 -> 全局特征平均
  |       -> 源域几何处理 -> 基础坐标phi、归一化平均坐标m
  +-> 图像条件代理 -> 细长程度、中心突出程度 -> 条件坐标c
  +-> 冻结R50中层空间图 -> Haar四子带
          -> 四个独立轻量编码器 -> 子带表示 -> 学习频带权重 -> z

phi的关系 + 条件化m的关系 + 条件化z的关系 -> 基础支持核K_B
```

C4平均处理的是同一幅图的0/90/180/270度显示旋转，不是获得四次真实雷达观测。平均表示对这组离散旋转有结构上的不变性，不等于整个分类系统的物理观测不变性。

条件是图像统计代理，不是真实长宽、船艏朝向或雷达相对观测角的完整测量。当前使用细长与中心突出代理的秩坐标。其作用是调整查询与支持案例之间的相似度，而不是直接由条件判类别。

分频支路读取512×16×16中层特征图，分为LL/LH/HL/HH。每路为1×1卷积降至16通道、归一化与GELU、3×3深度卷积、归一化与GELU、2×2池化，得到64维归一化表示。四路以权重平方根缩放后拼成256维。门控输入来自频带摘要与条件；这部分可训练参数共35,876。

“频带”在此是特征图空间子带，不是不同雷达载频。源端通过实际64支持样本残差求解器进行六轮情景训练，目标端不再训练该神经支路。

查询q与支持案例s的基础核为：

```text
R(q,s) = exp(-||c_q-c_s||² / 0.5)
K_B(q,s) = phi_q·phi_s
           + eta (m_q·m_s) R(q,s)
           + 0.25 (z_q·z_s) R(q,s)
```

eta沿用源端选择；外部两集为0.25。三个关系项一起进入一次基础路求解，不是三个分类结果相加。条件R可能压低一对案例的关系，但最终支持贡献还有正负系数，不能把它简单描述成同类近邻投票。

### 3.2 专家路：原有表示及压缩外的信息

```text
原图的R50特征 + SSL/R18特征
  -> 源PCA保留坐标 + 相对该子空间的补充坐标
  -> 分别规范化 -> 专家支持核K_E
  -> 24港版本另含候选稳定坐标及入射角项
```

外部专家的核为0.5×保留坐标内积 + 0.5×补充坐标内积 + 1。24港版本还加入0.25×稳定坐标内积和入射角条件项，具体公式见`unified_head_expert.py::_port_kernel`。

“PCA补充坐标”是线性投影意义上被压缩排除的部分，不是纯噪声，也不保证与基础路在语义上完全互补。专家的源端表示训练接入最终使用的残差适配算子，目标端同样冻结。

当前专家单独的总体指标高于基础路。因此，“基础路只负责容易样本、专家只负责困难样本”不是已证实的分工。更准确的是两路表示与适配结果不完全相同，融合后有额外净收益。

### 3.3 源先验与64标签如何共同起作用

每路保留源域类别分数f0，而不是用64标签从零学习全部知识。把支持样本的八类编码设为正确类+1、其余类-1；依据支持集中各类数量设置平衡权重W，拟合源先验的残差：

```text
A = W^(1/2) [W^(1/2) K(S,S) W^(1/2) + lambda I]^-1
    W^(1/2) [T - f0(S)]
f(q) = f0(q) + K(q,S) A
```

主固定对照lambda=8。A为64×8系数，64指支持案例数量。类平衡权重无法凭空补足稀少类的样本多样性；没有目标支持的类仍可由源先验输出。

## 4. 两条最终输出管线

### A. 原双头等权概率融合

```text
基础核K_B + 基础源先验 + 同64标签 -> 独立求A_B -> 八类分数f_B
专家核K_E + 专家源先验 + 同64标签 -> 独立求A_E -> 八类分数f_E
         -> 分别softmax -> 等权平均 -> 八类argmax
```

即p=0.5 softmax(f_B)+0.5 softmax(f_E)。softmax输出不代表已经做过可靠概率校准。所有查询使用两路，不再执行5%硬交接，也没有逐样本动态融合权重。

### B. 统一分类头，准确地说是统一目标适配头

```text
K_B和K_E -> K_U=0.5K_B+0.5K_E
两路源先验 -> f_U0=0.5f_B0+0.5f_E0
K_U + f_U0 + 同64标签 -> 一次求A_U -> 八类分数 -> argmax
```

统一头没有删掉条件核或分频信息。加权核等价于对相应特征映射进行平方根加权拼接后联合拟合。它让两路一起解释同一份支持残差；双头则让每路各自完成一份残差适配，再融合结果。

这仍保留两路提取器和两路已有源先验，只统一目标校正头，没有端到端重新训练一个单骨干网络。一次求解也不等于总算力减半。

## 5. 每一步是否形成“问题、方法、效果、解释”闭环

### 步骤一：减小显示方向依赖

发现的问题：同一图的显示方向会影响基础表示和分类，且这种敏感性不全是有利信号。

方法与理由：C4平均消除四种直角显示方向之间的任意选择，支持与查询匹配处理；不要求专家同时丢掉方向相关证据。

已有成效：24港历史C4对照完整BA提高1.4511个百分点；外部保留源头、只匹配支持适配的版本，F_0921和OSS2分别提高0.8023、1.1780。原图重提取对照与只改预测端对照支持增益不只是数值扰动或全部来自重新拟合。

边界：这些属于各自历史5%版本，不是当前全量融合的C4消融；24港与外部源头接入方式也不同。重新拟合C4源头在外部可能退化，真实SAR观测角差异并未消除。C4是基础处理，不宜单列为新理论贡献。

### 步骤二：在相似图像条件下使用支持证据

发现的问题：原支持校正还存在可利用空间；提出方向差补偿后，OA有正信号，但类别收益不均。

关键修正：同强度、同维度、同条件下，把方向差换成已有平均表示，三个数据集BA都更好。因此不能把收益归功于“恢复方向信息”。

方法：用平均表示关系乘条件RBF，加入原适配核，让外观条件影响支持关系，再联合拟合残差。

成效：平均条件支路相对C4基线，历史完整BA增量为24港+0.2065、F_0921+0.0538、OSS2+0.2180。真实条件与统一衰减对照在方向版本中仅显示约0.05至0.11个百分点BA优势。

闭环判断：支持校正整体有价值；条件确实超出普通衰减多少，以及这种优势能否在当前平均表示、全量融合版本保持，还不能完全下结论。支持稀疏类别更容易受损是诊断线索，不是已证明的唯一原因。

### 步骤三：补充分频局部证据

发现的问题：全局平均关系不足以利用某些局部变化、正负差分与排列信息；并非所有方向敏感线索都应删除。

方法：从中层空间图提取四个子带，以轻量编码器生成新支持关系；源训练通过最终残差求解器，避免仅在部署时拼接一个未经适配的新支路。

历史5%完整模型，加入分频后的OA/BA增量分别为24港+0.7755/+0.4577、F_0921+0.2141/+0.0714、OSS2+1.0160/+0.4199。

机制证据包括：

- 替换查询自身分频表示、固定其他项，完整BA下降0.3748、0.0061、0.4903个百分点。24港和OSS2的查询特定证据更明确，F_0921净效应很弱。
- 同源端训练计划下去掉局部差分正负，24港与OSS2的BA分别下降0.1602、0.4187个百分点；F_0921反而增加0.1152，且OA下降。说明它是有条件的判别信息，不是普适好信号。
- 参数匹配的未分频可训练支路较弱，支持收益不完全来自随便增加一个小网络；但F_0921的BA不支持所有分频选择都更好。
- 最终分频门控近乎固定。用样本群平均权重替换，两个外部集预测完全相同，24港只差一个最终预测。因此不能宣传已证明有效的灵活动态选频。

闭环判断：表示层和分数层解释较充分，尤其24港和OSS2；不是船首、甲板或散射因子的物理识别，也不是因果不变量。当前全量融合下的独立净增益仍需匹配消融。

### 步骤四：保留补充表示，并让训练匹配实际适配

发现的问题：PCA压缩外仍可能有判别信息，源端学习的表示也未必适合目标端实际采用的支持残差求解。

方法：专家同时使用保留坐标和补充坐标；源端直接通过部署使用的类平衡残差求解器优化查询分类。

证据：F_0921历史匹配2×2实验中，补充信息与适配对齐的联合专家相对原专家，专家自身OA/BA增加0.8186/1.1648个百分点。对应旧5%完整系统增加0.1243/0.3251。补充信息单独加入并不保证BA提高，说明不能把两个环节任意分拆后分别宣称普遍涨点。

闭环判断：有组合价值与训练接入证据；所有数据集、当前融合版本中各部分的单独作用未由这一实验解决。保留坐标/补充坐标应按实际机制合并叙述，不为增加模块数拆成多个独立创新。

### 步骤五：独立适配还是联合适配

问题：有两路信息，不代表一定需要两个独立分类头。

方法：保留完全相同的信息核、标签、先验和正则设置，仅比较两次独立求解与一次联合求解；另控制概率/分数读出差别。

成效：双头融合超过两条单路；统一头OA略高、BA略低，数值见前表。联合解与显式拼接解等价、支持目标更优，说明不能简单归因于统一求解没实现正确。

根因边界：在OSS2源选版本中，强正则64压弱目标校正，BA退化到27.9566；固定相同核权重、诊断性改回8可到34.1478，定位了过度收缩这一直接因素。但该诊断不是新的正式选参结果，也不能解释固定正则8时所有类别取舍。

闭环判断：结构必要性已做有效检验，有能力作有限结论；还没有证明独立双头在理论或所有设置上必要，更没有完成单骨干端到端对照。

## 6. 可解释到哪个层级

目前可解释“哪条表示、哪些支持案例、以多大有符号贡献改变哪个类别差值”。例如固定同一查询，加入分频的基础分数变化可以精确拆成：

```text
新基础分数 - 旧基础分数
  = K_old (A_new - A_old) + 0.25 K_freq A_new
```

第一项是加入新关系后旧证据权重的重新拟合，第二项是分频直接贡献。每项又可按64个支持案例拆开。已有F_0921例子中，集装箱船相对散货船的旧分数差为-0.01974010，旧路径重拟合贡献-0.00352291，分频直接贡献+0.03310102，最后变为+0.00983801，从错误跨过分类边界。

这不是纯正向故事：另有散货船被推向杂货船的错误案例，同样能定位分频与重拟合各自的有害贡献。案例说明代数决策过程，不代表类别物理含义已知。

该分解先解释基础分数，再检查专家与融合是否保留或撤销这一纠错。旧5%路由案例不能原样当作当前等权融合的最终决策解释。softmax融合是非线性的，不能将基础分数贡献直接当成最终概率或准确率贡献。

## 7. 论文如何组织，哪些不应硬凑

建议的总问题：中低分辨率SAR跨港识别中，在少量目标标注下，怎样结合较稳定的全局信息和仍有判别价值的局部变化，并通过支持证据校正源域模型。

方法章节可以分三部分，但不声称三部分都是独立原创算法：

1. 多视图与互补表示：C4平均、原专家及投影补充信息作为表示基础。讲清保留什么，不宣称纯噪声分离。
2. 条件化分频支持残差：条件关系、空间子带编码、源先验锚定及与适配一致的情景训练，作为主要可发展机制。条件和分频也可作为同一模块的两个子部件。
3. 两路适配与证据融合：独立拟合、固定等权输出和可追踪支持贡献。以统一头对照说明采用理由，不把简单平均本身称为新注意力算法。

这些是当前可用的组织方式，不应反推成研究开始前就完全成立的理论。候选稳定/漂移空间、入射角是24港特有上游或扩展；要升为跨数据集核心贡献，先解决结构和证据一致性。

不作为当前主贡献：未证明必要的逐样本动态选频、收益很弱的自适应融合、未经确认的物理因果不变量。5%交接可以保留为受限使用场景，但全量融合在三个数据集OA/BA都更高，且两路本已全量算特征，不能强行以它解释当前最高精度或95%计算节省。

## 8. 只补什么就能接近当前版本闭环

本次不启动新实验。后续最有用的补充不是继续增加模块，而是固定专家、64支持抽样和等权输出，在同一最终版本中对照：原平均基础、增加平均支持校正、使用真实条件、再增加分频。对条件同时给匹配尺度的无条件/统一衰减参照，避免把改核强度全部记为条件选择作用。

用完整模型OA/BA、逐类救回/误改及少量融合后案例回答：哪个环节有独立净收益，收益是否被专家覆盖，最终为何改变预测。不强求每项对每个类都提高；有真实收益范围、已查明的失效边界和对应数值，也是一种闭环。

需要的是这组同版本证据，而不是更多命名。若某个组件只能解释流程、没有独立贡献，就作为基础设施或实现选择；若去掉不损失，就简化主模型。公共强基线与独立确认仍是不同问题，不能由模块闭环替代。
