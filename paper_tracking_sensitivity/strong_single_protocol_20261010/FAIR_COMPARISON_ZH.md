# 双骨干必须通过的强单骨干公平比较

日期：2026-10-10。依据用户最新要求制定。

## 当前决定

**双骨干暂不确认为论文主方案，只保留为待比较的候选。** 既有删除分支、线性/MLP重建、先验/关系核交换与训练阶段消融有效，但不足以证明双骨干胜过训练充分的强单骨干。

本文件确定比较原则、实验构成与判定规则，不是已经完成的实验报告。具体可用权重见同目录 `LOCAL_CANDIDATES_ZH.md`；训练超参数与资源配置应在开始新比较前另存实际运行协议，不能声称现在已经冻结了尚未确定的配置。

## 一、现有结果为什么不够

1. 删除SSL-R18，只能证明当前模型利用了它，不等于强单骨干无法替代。
2. R50特征上的源内MSE重建不等于面向最终分类、支持关系和跨港泛化的充分蒸馏。
3. 既有全参数R50仅为OSS2上的单种子8轮源分类交叉熵试验，且使用较简化读出；不能用一次负结果排除充分训练的单骨干。
4. 双路R18接受了SAR自监督与源支持/查询残差训练，单路不能只获得ImageNet初始化和普通线性分类器后就称为公平。
5. F曾进入教师的无标签SSL语料。它是预训练信息差异，不能归因成骨干数量优势。公开基础模型也需核对OpenSARShip等数据的预训练重叠。
6. 当前24港部署的稳定/漂移/入射角算子与历史可微专家训练算子尚非完全一致。新单路若按不同任务目标训练，会继续混入训练目标差异。

## 二、最小有说服力的候选集合

| 对照 | 必须获得的能力 | 主要回答什么 |
| --- | --- | --- |
| 强R50单骨干 | 源端充分微调与支持/查询任务适配；可使用多层、多尺度读出及多个分类头 | 当前双路收益是否只是单路没有被充分训练或利用 |
| 单个SAR预训练骨干 | 经核实可用的SAR权重、正确官方输入流程、相同目标适配机会 | 收益是否主要来自额外SAR预训练，而不是双骨干 |
| 计算预算相近的较强单骨干 | 更强容量或更合适结构，在相同信息与预算下训练；实际测量费用 | 相近费用投入一个骨干是否更划算 |
| 任务导向单骨干蒸馏 | 学最终类别证据及支持关系，而不只是逐坐标MSE；推理真正只运行一个骨干 | 双路互补能否被压缩进一个模型 |
| 当前双骨干 | 与对应比较共享训练信息、模型选择预算与任务目标 | 双路是否仍提供实质净收益 |

这些是必须覆盖的比较问题，不要求机械训练四套互不相关模型：若一个经验证的单骨干同时覆盖SAR预训练、足够容量和任务适配，可合并重复对照。不能仅凭模型名字、参数更多或检查点存在，就称其为“强基线”。

**一个骨干可以有多层读出、多个头或频带分支。** 不为突出双路而把单路限制成最弱的单层线性头。骨干数量、分类头数量和图像前向次数分别报告。

## 三、公平性分为两类，不混成一个结论

### 架构归因比较

目标是判断“两个骨干”本身的价值。相同的源样本、标签、目标支持样本、无标签数据访问政策和可用知识；SAR预训练机会、任务训练及源验证调参机会应对称。若历史权重的语料暴露无法对齐，就不能把差异归给架构。

F可采用共同无标签适配协议，让各方法获得同一允许语料，明确写成允许无标签目标暴露；或者采用重新建立的源端预训练权重。未完成其中一种之前，当前F结果只能作为带历史暴露边界的性能观察。不能仅让单路短训几轮，就宣称历史预训练差异已被消除。

新核查还表明：现有e206训练池在港域层面覆盖24港中的Los Angeles、Houston、New York；这不是已确认的同船/同场景/同裁片交集，但共同无标签访问规则不能只针对F。后续有监督LOPO排除不能倒推为历史SSL也进行了目标港排除。具体证据与未知范围见 `LOCAL_CANDIDATES_ZH.md`。

### 实际竞争力比较

回答“现成强单骨干能否达到更好的精度与效率”。允许不同公开预训练模型采用各自合理、来源明确的预处理与训练配方，但完整记录预训练数据和重叠；这种比较不能单独证明某种架构因果机制。

两类结果都保留。不能用严格控制但刻意弱化的单路代替实际强基线，也不能用预训练信息不同的榜单结果代替架构归因。

## 四、运行时必须保持一致的内容

- 相同原始样本、类别映射、源/目标划分与身份排除。24港仍为23个有效外留任务，F和OSS2保持既有目标队列，不因结果删除港口或类别。
- 相同五组64目标支持标签，所有模块共享这64个标签。原始裁片内容、可用极化与元信息的访问对称；不同模型合理的输入通道适配不能偷偷引入额外信息。
- 单路和双路均获得与最终部署任务一致的训练机会。分别报告普通分类目标与支持残差任务目标，不能把二者的差异算作骨干数收益。
- 模型选择只使用源端验证任务；验证以港口/采集或身份组划分，相关有监督拟合不混入验证标签。需要选择的PCA、尺度、先验与训练检查点按实际内层训练范围拟合。
- 各方法使用预先分配、可比较的搜索次数及训练资源；可以使用各自合适的学习率和收敛轮数，不能把“同样8轮”当作都训练充分。先记录源验证曲线，未收敛或接入异常不能直接记成方法劣势。
- 主比较采用多个神经训练种子，最低3个；原五个支持抽样仍保留，两种随机性分开记录。历史单种子模型可以保留参考，但不能冒充新比较的多种子结果。
- BA为主要指标，同时报告OA、逐类召回、逐港结果以及误改。不得在看完目标结果后挑每个数据集最强单路拼成一个可部署方法。
- 查询延迟、吞吐、峰值显存、参数和实际图像前向次数单独报告。C4、预处理、支持集准备与训练费用明确计入或单列。等参数不代表等计算；等理论FLOPs也不代表等实测延迟。
- 至少给出“同训练信息下的精度比较”和“实测精度-成本比较”。当前短测的16条查询成本不能冒充全队列准确率或全部港口的平均成本。

## 五、必须解释什么样本被救回

先在源验证上确定单骨干配置，再在同一批目标查询上比较。不能按目标真值选择单路竞争者。

1. 双路正确、选定强单路错误：双路救回。
2. 双路错误、选定强单路正确：双路误改。
3. 双路正确、预先固定的所有强单路都错误：相对于已测试模型集合的共同难例救回。
4. 双路错误、至少一个强单路正确：对应反向证据。

第3项可以证明当前测试集合中存在独有救回，不证明任意未来单骨干理论上做不到；它取决于事先固定的模型集合。利用真值选择任意单路答案的oracle只用于分析，不作为可部署基线。

四项均按类别、港口和支持覆盖汇总，同时报告唯一查询数与跨抽样曝光次数，不能将重叠抽样当成独立样本。检查救回是否跨神经种子复现，而不是用一张好看的案例取代总体效果。

对一个固定查询队列，设第c类样本数为n_c，双路救回数为R_c，误改数为H_c。直接核对：

```text
OA增量 = 所有类别(R_c-H_c)之和 / 查询总数
BA增量 = 各个实际存在类别[(R_c-H_c)/n_c]的平均
```

24港在此基础上再按23个任务等权汇总。这样能避免用多数类的大量救回掩盖少数类受损，也能把最终精度差与样本层解释对上。

随后只对真实存在的差异进行机制分析：

- 来源是源分类先验、支持案例关系、置信度/校准，还是两路普通误差平均？
- 同一个骨干的多层/多头、合理尺度或任务蒸馏能否恢复这些纠错？
- 固定输入和训练信息后，改变相应计算路径是否同时改变预测与净纠错？
- 元数据、尺度或方向分层是否有跨港复现的规律？没有物理证据就只解释计算功能，不命名独占的物理机制。

现有逐支持案例的精确分数分解可以复用，但必须换成强单骨干对应的比较对象，不能继续只对删除分支后的弱对照解释。

## 六、保留与放弃规则

**可以保留双路为主方案：**面对源验证选定、训练正常的强单骨干，双路仍有跨种子与任务可复现的实质净收益；误改不能抵消收益；收益与额外计算对应，且没有被预算相近的单路替代。论文结论限定在实际实验范围。

**只能保留为可选精度配置：**精度有稳定收益但成本明显更高，形成明确的精度-成本权衡，不能宣称全面优越或不可替代。

**不坚持双路：**强单路达到相当或更高精度且更便宜，或者所谓优势主要来自预训练信息、调参机会不对称，或者净收益只靠个别种子/样本。转用单骨干，将有用的支持关系、分频或知识模块保留，不为网络数量维护论文叙事。

不以任意一个正数或一张独有救回图作为通过条件；也不追求证明所有可能单骨干都失败。所需证据是对预先确定、足够强且公平训练的实际竞争者成立的优势及其来源。
