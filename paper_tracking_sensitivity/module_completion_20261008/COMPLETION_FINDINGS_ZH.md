## 3. 新证据回答了什么

### 3.1 主数据集支持联合机制，但不是每个港均受益

23港等权平均中，联合相对参考增加0.307381 OA / 0.395702 BA个百分点；14港OA增加、9港下降，15港BA增加、8港下降，没有按结果删港。

只加M2时BA下降0.123776个百分点；只加M3时BA增加0.195318个百分点；联合相对M3仍增加0.204726 OA / 0.200384 BA个百分点。该组合在主数据集上优于两个单模块的平均结果，支持把M2与M3作为联合信息利用机制论证，而不是将M2独立包装成普遍有效的模块。

专家全查询OA从58.425285增至60.999502，BA从52.894549增至54.480111；最终交接系统对应的增量更小。与Base64相比，联合系统增加2.166870 OA / 2.237730 BA个百分点，该阶段差值不是M2/M3相对参考的独立增量。

float16前缀重放的匹配参考与旧缓存参考最终OA/BA相同；专家全查询OA/BA仅分别变化-0.000480/-0.000318个百分点。报告仍保留两个参考的工件，避免用“最终均值相同”替代逐行/逐得分相同的声明。

原始[23港匹配汇总](E:/Hermes/paper_tracking/sensitivity/module_completion_20261008/ports_projection/joint_summary.json)包含每个港的对照增量；[460条逐港逐抽样记录](E:/Hermes/paper_tracking/sensitivity/module_completion_20261008/ports_projection/matched_joint_metrics.csv)保留四臂完整结果。

### 3.2 OSS2是当前最清楚的联合正结果

联合相对参考的OA、BA在五次支持抽样中均为正。相对只加M3，联合仍增加0.255365 OA / 0.238337 BA个百分点。

每轮交接数同为184，查询3681。平均纠正基础错误数从86.2增至113.2，损害基础正确数从22.0降至21.2，净纠正由64.2增至92.0。这里固定的是预算和规则，不是固定选中同一批查询。

专家全查询OA/BA从34.947025 / 30.909838增至39.782668 / 32.608236。因此不仅有最终分流结果的提升，也有专家自身判别表现的提升。不过部分类别召回仍下降，不能称为所有类别均受益。

### 3.3 F_0921是幅度有限的正结果

本次复用同日已经完成的匹配四臂工件，不重复训练，也不把它写成第二次独立确认。联合比参考增加0.124286 OA / 0.325071 BA；与M3单独相比，主要是收回OA损失，BA近乎持平（-0.003211个百分点）。

因此更准确的表述是“改善该任务的OA/BA折中”，不是联合超过每个单模块的每个指标。

### 3.4 OSS1揭示OA与BA取舍

联合OA增加0.233463个百分点，BA下降0.572066个百分点；BA在五次抽样均下降。专家全查询OA提高1.603113个百分点，BA下降1.686168个百分点。按类召回可见大类和部分类别受益，而渔船、拖轮、海工支持船等类别下降；这是观察到的结果模式，不是已经独立证明的因果解释。

详见[公开SAR补测分析](E:/Hermes/paper_tracking/sensitivity/module_completion_20261008/SAR_EXTERNAL_FINDINGS_ZH.md)。

### 3.5 RGB负结果发生在专家本身，不仅是路由

PACS联合专家全查询BA下降6.074592个百分点，最终系统BA下降0.451192个百分点；Office-Home分别下降9.931260和1.127123个百分点。两个数据集的四个域均为联合BA负收益。

M2单独对这两个新参考的影响很小，明显退化主要伴随M3训练出现。但本次消融没有进一步分离训练目标、固定源几何、优化日程和类别覆盖等原因，不能把某一个猜测写成已定位的唯一原因。

结论是**当前固定配置的新增训练模块不支持通用RGB跨域增益**，而不是所有可微少样本求解器必然无效。原M1/M4框架的历史正结果保留，不被这些新模块的负结果覆盖。

## 4. 匹配关系与可复现边界

1. 每个目标任务共享同一组64个支持标签；支持抽样seed为0至4。五次支持抽样不是五次神经网络训练。
2. Base64、支持行、预算、输出类别与门控规则在各任务四臂间固定。交接上限为查询数的5%，不是专家计算量的5%。
3. 新tail仅用合法源行训练六轮，末轮checkpoint直接部署；AdamW学习率1e-5、weight decay 1e-4、梯度裁剪5，仅更新R18 layer4，BN统计冻结。未根据新目标查询结果换超参、挑轮次或挑目标港。
4. 逐港训练分别排除该目标港及既有MMSI/产品重叠；每个外层任务22个源港情景，共506个。不能用一个在所有源港训练的模型填满逐港表格。
5. OSS1/OSS2参考的原预测与交接掩码精确重放。24港采用与两种训练臂相同float16前缀的初始tail作为匹配参考，另报它与旧缓存的微小差异。
6. PACS/Office-Home旧源监督R18只保存了特征，没有checkpoint，无法从512维池化输出恢复layer4。因此八个外层任务重训12轮RGB源编码器并保存权重；四臂共享新参考，明确标记retrained_rgb_reference。RGB任务不用SAR权重。
7. RGB外层目标域未进入新源监督训练，但源内部只做head-OOF，并非严格嵌套encoder-OOF。SAR继承的基础SSL曾接触历史F_0921无标签池；新监督tail排除目标不等于基础编码器从未见过目标。
8. 数据曾用于历史开发，当前结果不是盲外部确认。港/域均值等权，非按样本量池化；原库24港中Melbourne只有64行，取完支持后无查询，所以23港可评估。
