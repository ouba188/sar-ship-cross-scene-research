# 候选稳定隐空间在现有模型中用在哪里

日期：2026-10-08。

## 结论

这部分候选空间并非等到新增模块后才进入模型。冻结现有联合模型的读出归因表明：它已经影响基础模型和专家的预测，主要使用位置是源域分类头/源域先验，而不是新接入的稳定空间分支。基础模型上的影响尤其明显。

本轮只查既有模型，不新增分类器、不训练任何模型、不更改主方案。对象是自建24港中的23个可评估外层目标港，原有5组64标签支持集。全部1035行屏蔽对照完成，原始预测和交接掩码精确重放。

## 1. 实际流向

```text
R50 原始2048维特征 h（含候选方向的信息）
  |
  +-- PCA保留128维
  |     |
  |     +-- 源域基础分类头 ------------------ 基础源域分数
  |     +-- 64标签适配读出 ------------------ 基础修正分数
  |     |                                       |
  |     |                                    Base64
  |     |
  |     +-- 与R18保留64维拼接 -- 源域专家头 --- 专家先验
  |     +-- 专家主成分核读出 ----------------- 专家修正之一
  |
  +-- PCA补空间 -- 与R18补空间组合 ----------- 专家修正之二
                                                 |
                                              接收专家

Base64与专家的分数 -> margin/entropy -> 门控打分
预测分歧、支持集已见类别、正门控分数 -> 排序 -> 5%交接
```

原模型里没有一个命名为“稳定隐空间”的独立层。所谓已经使用，是原分类权重对候选方向张成空间具有非零响应，该响应改变了部分样本的分类结果。候选投影只是把这种原先混在特征和权重中的响应显式分解出来。

## 2. 怎么定位

对每个外层划分，读取上一轮由源港发现的28个候选方向，用SVD取得其数值有效张成空间Q；相对奇异值阈值1e-6，有效秩23至27。记源统计标准化后的特征为x=(h-mu)/sigma，候选空间分量为xQQ^T。

固定既有源域头、64标签支持样本、支持特征、适配系数、R18特征、门控参数和交接预算，只在查询样本的指定读出路径中扣除该分量产生的分类分数。分别定位：

1. 基础模型源域分类头。
2. 基础模型64标签适配。
3. 专家源域先验中的R50路径。
4. 专家主成分核中的R50路径。
5. 专家补空间核中的R50路径。

之后重算真实门控输入、预测分歧、资格条件和预算排序。没有用查询标签拟合归因方向或重新训练分类器，查询标签只用于计算下表。

“查询读出屏蔽”不是删掉训练信息后重训；它回答既有模型是否使用这些方向，不回答一个重新训练的模型能否用其他相关信息补回来。屏蔽也可能产生偏离原特征分布的表示，因此降幅不能作为某种物理因果贡献。

## 3. 主要结果

指标先平均每港5次支持抽样，再对23港等权平均；所有BA都是当前八分类任务指标，不是前轮两类诊断BA。

| 冻结模型后的查询读出操作 | 基础模型BA | 专家BA | 最终交接模型BA |
|---|---:|---:|---:|
| 不屏蔽，原联合模型 | 48.5401% | 54.4801% | 50.7778% |
| 仅屏蔽基础源域分类头中的候选分量 | 33.8565% | 54.4801% | 37.7816% |
| 仅屏蔽基础64标签适配中的候选分量 | 48.5582% | 54.4801% | 50.7526% |
| 仅屏蔽专家源域先验中的候选分量 | 48.5401% | 53.0005% | 50.3768% |
| 仅屏蔽专家主成分核中的候选分量 | 48.5401% | 54.4408% | 50.7709% |
| 仅屏蔽专家补空间核中的候选分量 | 48.5401% | 54.4993% | 50.7853% |
| 屏蔽基础模型全部R50读出中的候选分量 | 32.9199% | 54.4801% | 36.8077% |
| 屏蔽专家全部R50读出中的候选分量 | 48.5401% | 53.0707% | 50.3881% |
| 同时屏蔽基础与专家中的候选分量 | 32.9199% | 53.0707% | 36.4989% |

- 基础分支全部屏蔽：基础BA下降15.6201个百分点，22/23港下降；基础预测平均50.5293%改变。
- 专家分支全部屏蔽：专家BA下降1.4094个百分点，22/23港下降；专家预测平均10.4882%改变。
- 两分支同时屏蔽：最终BA下降14.2789个百分点，23/23港均下降。
- 基础目标适配、专家主成分核和补空间核的单路径影响较小，某些平均指标在屏蔽后略有改善。不能将“存在非零响应”写成“各路径均有正贡献”。

屏蔽基础源域头与基础适配的影响不能相加，专家三个路径亦然：它们的分数可能抵消或补偿，且argmax和门控选择非线性。

## 4. 对应到功能模块

| 位置 | 本轮发现 |
|---|---|
| 源域基础头及M1源先验锚定 | 最明显的直接使用位置；信息已经随源域学习进入基础预测 |
| 专家源域先验 | 也有直接且有益的平均响应，R18相关路径在本轮保持不变 |
| M1少标签适配 | 有读出响应，但对这组方向的净收益有限，不能说完全未用 |
| M2主成分/补空间适配核 | 两处都存在通路；对这组候选方向的单独屏蔽影响较小 |
| M3 R18表征训练 | 本轮不直接归因。候选来自R50，R18可能另有相关/冗余信息，不能据此判定M3没有使用类似信息 |
| M4交接门控 | 不直接输入候选向量；通过两分支分数、margin、entropy、预测分歧及排序间接受影响 |

这意味着“已经用到”和“还可进一步利用”并不矛盾；本轮证实前者，尚未证明后者。此前再加一个投影核没有提点，与信息原已被使用相容，但不足以证明它已充分利用或完全冗余。

## 5. 数值验证和解释边界

五种解析读出分量均用直接特征扰动计算核对，每港每次支持抽样的17个样本，最大差异7.6125e-7。另逐港逐抽样重建完整专家分数（先验+核乘已存支持系数），最大误差1.3323e-15；基础读出重建相对历史缓存最大误差8.9407e-6。基准路由的预测及交接掩码与原模型一致。

原缓存生产脚本没有保存当时的原始PCA对象。归因使用主模型已有的重建PCA和原缓存主成分坐标；查询坐标重建相对L2误差均值5.8e-5、最大1.798e-4。因此这是“锚定缓存分数、使用近似恢复映射的连续读出归因”，不是原始历史流水线逐位精确的原图干预。坐标重放误差不是屏蔽效果误差的严格上界。专家先验原有float32取整也未纳入解析梯度。

本轮追踪的是候选方向的整个数值张成空间，不证明该空间的任意线性组合均保持前轮的一维稳定性。较稳定候选空间被利用，也不等于“跨域不变性”被模型作为显式机制使用，更不等于发现因果因素。

后续已于2026-10-08进行了源判别强度匹配对照：在均值间隔和总类内方差相同、源AUC/BA差异均不超过2个百分点的191个港口-类别对中，候选精确经验W1低5.19%，但两类BA仅高0.1614个百分点，22港11升11降。该结果支持更小漂移，不支持将本文屏蔽降幅解释为稳定性的准确率贡献。详见 `E:/Hermes/paper_tracking/sensitivity/matched_stability_probe_20261008/exact_w1/MATCHED_STABILITY_FINDINGS_ZH.md`；原屏蔽实验与主模型未变。

几何投影能量对坐标尺度敏感；保存的原始协向量主成分能量比例和分类梯度投影比例都不是“信息利用百分比”或“准确率贡献率”，不用于上述主结论。R18分支固定，不能排除其他表征对相同语义信息的冗余编码。
