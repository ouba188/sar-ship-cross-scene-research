# 论文主方案冻结与组件取舍

日期：2026-10-13。范围：整理已有证据、冻结参考配方与引用资产；本轮不训练、不重新预测、不修改稿件、不删除历史实验。

## 1. 收口决定

**主线收口为：跨港及跨数据集 SAR 船型识别中，利用互补视觉证据，在少量目标标注下进行源先验锚定的支持适配。**

保留有明确系统收益的双路组合、C4 编码、源先验与支持残差适配、简单等权概率融合。近期的支持方向重组作为有适用范围的可选研究结果，暂不默认叠加。动态路由、纯因果分离和不断增加的选择器退出核心贡献。

这不是认定其他方向永远无效，而是当前已经有足够依据决定哪些值得进入这篇论文。认可明确范围内可重复的净收益，不要求所有港口、类别、抽样均获胜；也不把小幅或不稳定的增量包装成成熟模块。

## 2. 冻结了什么

- 参考版本：`paper_reference_20261013`，既有模式 `dual_refit_late`，不按各数据集测试结果拼接最优分支。
- 任务：八类闭集识别；自建24港数据中的23个可评估港口任务，加 F_0921、OpenSARShip 2.0，共25任务。
- 参考工作点：64个目标标注支持案例，5次支持抽样；它们不是5次独立骨干训练。
- 输出：基础头与专家头概率各占0.5，全量融合。标注预算 B 与专家交接比例是两个不同概念。
- 冻结内容：协议、已存在的模型/预测资产路径、125个任务-抽样单元的索引及结果表。不是独立打包的模型副本，也不是新训练或已剪枝的网络。
- 精确复现仍保留原参考实现中的分频基础表示、专家 PCA 补充项，以及适用任务的稳定/漂移坐标、入射角处理；它们不因此自动成为论文核心创新。
- 没有新增独立数据确认。历史 SSL 编码器对数据的接触范围按原记录披露，不能称为所有层级均未见目标域的严格零接触实验。

机器可读记录：[参考版本](FROZEN_REFERENCE.json)、[组件取舍](RESEARCH_SCOPE.json)、[索引检查结果](FREEZE_VERIFIED.json)。本轮确认175个引用文件存在，并核对既有聚合结果；没有重新执行推理。

## 3. 主模型怎样组织

```text
SAR 图像
  -> C4 全局编码及两路既有编码器
       A: ImageNet R50 表示
       B: 当前 SAR 自监督 R18 表示
  -> 源先验 + 同一组目标支持标签的类平衡残差适配
       基础头：保留其既有读出
       专家头：利用两路互补表示建立支持关系并求解校正
       可选支线：仅重组支持坐标，再重算关系与支持系数
  -> 基础/专家概率等权融合
  -> 类别预测

解释与评价：支持贡献、救回/新增错误、逐港逐类、预算与抽样敏感性
```

这是功能分组，不是宣称每一项都是原创模块。精确实现以冻结代码和任务资产为准；图中省略的旧辅助变换仍存在，不能据此把参考成绩当作最简网络成绩。

可选支持方向重组的监督来自源域“同类但不同船”的均值目标，不是同船多时相因果监督。它变换支持坐标，保持查询表示和先验不变，随后重算支持关系和读出系数。已有变换只在各自任务坐标系使用，不跨任务直接移植。

## 4. 已经能支撑什么核心论点

### 论点一：当前两路证据具有实际任务互补性

同一源先验重拟合口径、相同目标支持与读出协议下，完整双路相对于对应 R50 单路的结果如下。OA/BA 为百分比，增量为百分点。

| 数据范围 | 单路 OA / BA | 双路 OA / BA | 双路增加 OA / BA |
|---|---:|---:|---:|
| 23港任务均值 | 60.108 / 52.188 | 65.574 / 55.987 | +5.466 / +3.799 |
| F_0921 | 31.423 / 25.965 | 35.053 / 27.723 | +3.631 / +1.759 |
| OpenSARShip 2.0 | 32.529 / 30.252 | 42.597 / 34.674 | +10.068 / +4.423 |

这说明第二路不是仅增加参数而没有可见价值：在现有配方下，救回的分类错误超过新增错误。对当前匹配对照，三组范围的5次支持抽样 BA 增量均为正，23港各港平均增量也均为正。

**可写：当前编码器组合提供了现有单路读出未充分利用的互补证据。不能写：双路必然优于任意充分优化的单骨干，或者两路分别对应唯一物理机制。** 强单路 MLP 已能恢复相当部分收益；新的匹配训练组合也出现过 F_0921 单路更优。第二路为何互补的物理层解释仍不完整，但不抹掉已测得的任务互补性。

来源：[结果表](FROZEN_REFERENCE_RESULTS.csv)、[匹配增量](MATCHED_SECOND_BRANCH_GAIN.csv)、[双路证据与反例](BRANCH_EVIDENCE_ZH.md)；原始目录 `E:/Hermes/paper_tracking/sensitivity/backbone_ablation_20261010/`。

### 论点二：支持适配的收益取决于案例关系与读出如何配合

支持方向重组 `initial` 相对原始支持适配 `raw`，在 F_0921 的 B=16 下有值得保留的信号：

| 支持抽样组 | 完整模型 OA 增量 | BA 增量 | BA 正收益次数 |
|---|---:|---:|---:|
| 原有5次抽样 | +0.218 | +0.868 | 4/5 |
| 新增5次抽样 | +0.953 | +0.917 | 3/5 |

不是独立新数据验证；新增组 BA 增量标准差为2.068个百分点。它支持“小预算下可重复观察到正的平均收益”，尚不足以变成跨数据集通用默认项。F_0921 的 B=64/128 增量约 -0.043/+0.054，OSS2 两组 B=16 均为负。

这里已有较具体的机制证据：F_0921 B=16 原组只改关系时 BA 为 -1.379，只改系数时为 -0.420，关系与系数一起改则为 +0.868。类别校正强度匹配对照可复现约 +0.656，因此不能把全部增益都归因于新的邻域几何。

更直接的案例解释是：该组渔船在支持集中没有样本，但其召回仍提高约5.854个百分点；校正后，其他类别支持案例对渔船源先验的压制减弱。**收益并非总是“找到了更相似的同类船”，也可能是“少量支持不再过度破坏已有正确证据”。** OSS2 渔船没有同样收益，正好界定了该解释的范围。

可写成有针对性的支持适配研究贡献。不要称为分离出纯因果因素，不要把新增抽样当成新增独立数据集，不要把 +0.868 加到上表 B=64 的 BA 上。

来源：[支持修正表](SUPPORT_CORRECTION_B16_GAIN.csv)、`E:/临时会话/support_mechanism_20261012/FINDINGS_ZH.md`、`E:/临时会话/joint_support_correction_20261013/paired_summary.csv`。

### 论点三：分层评价能解释“学到东西”为什么不等于“完整系统涨点”

保留表征/关系、适配读出、完整融合三个层次，结合先验与核交叉替换、支持预算/构成敏感性、救回与新增错误，建立问题到收益的证据链。OA/BA 保留为最终系统结果，Brier 等连续风险只回答其对应问题。

它是本研究有价值的评价与诊断组织方式，不宜仅改一个指标名字就称为全新评价理论。支持预算不固定为64；已有16/64/128结果用于说明范围，且当前各预算的正则/修正强度设置不同，不能把所有差异都归因于标签数量。

## 5. 组件取舍

| 组件 | 决定 | 依据及论文地位 |
|---|---|---|
| 当前 R50 + SAR-SSL R18 | 保留主方案 | 匹配完整读出下有明确净收益；讲任务互补，不讲唯一物理分工 |
| C4 全局编码 | 保留工程基础 | 原先验完整融合 BA 增量：23港 +0.735、F +0.338、OSS2 +0.713；不是原创机制，也不是单次前向成本 |
| 源先验 + 类平衡支持残差 | 保留适配主干 | 是已有工作点的实际读出；近期机制结果用于解释适配的收益与风险，不虚构其独立消融总增量 |
| 全量等权概率融合 | 保留默认输出 | 当前统一头 BA 更低；新路由还没有替代它的可靠收益 |
| 支持方向重组 initial | 冻结为可选研究结果，默认关闭 | F_0921 B16 两组平均收益；不做按测试结果选赢家的部署规则 |
| 支持贡献/删除敏感性 | 保留诊断，不默认训练门控 | 能解释支持案例作用；解释有用不等于选择器系统收益已经充分 |
| 分频表示/注意力 | 降级旧辅助项，第一剪枝候选 | 基础头有收益，完整融合增量很小；不能讲成已有效的灵活动态选择 |
| 稳定/漂移坐标、入射角 | 精确参考所需部分暂留，不扩展为统一核心模块 | 效果依任务与接入位置而变；不是纯因果分离，不默认追加到外部任务 |
| 专家 PCA 补充项 | 随参考配方冻结，非独立创新 | 原口径外部任务有收益，不宜未经匹配复核一刀切删除 |
| raw/initial 选择器、类别门控、计数保护、支持CV选择 | 从核心算法增量中移除 | 有局部正信号，但相对简单候选的净收益不足以支撑继续叠加；结果进边界分析 |
| 近期任务损失续训、预算隔离续训 | 从核心增量中移除 | 更广覆盖未显示足够的额外系统价值；不把初始化收益算给续训 |
| 因果空间抑制、蒸馏等探索路线 | 不进入当前核心算法 | 稳定或关系拟合改善未形成足够的分类增量证据；保存研究记录 |
| 强制5%交接、自适应基础/融合交接 | 不作为当前必要模块 | 当前全量融合更好；若两路已计算，交接比例不等于特征计算节省 |

关于分频的具体判断：原先验口径下，去掉分频后完整融合 BA 的损失仅约23港0.103、F 0.013、OSS2 0.006个百分点；基础头对应增量更大，为0.731/0.091/0.502。学到的权重又高度偏向固定频带。因此可保留“表示可能有用”的发现，但不值得把动态注意力列为论文主贡献。

入射角不是统一无用：共享核心上23港与OSS2有过正收益，F恢复后的匹配对照则轻微下降。不能用一处失败否定所有范围，也不能因此把知识输入包装成全任务必要组件。

## 6. 什么已经删，什么尚未删

**已完成的是方案和核心论点的删减，不是物理删除旧网络后重新验证。** 近期候选不自动叠入参考模型，相关核心宣称退出；所有原始结果保留。

若下一步确实要交付结构更简的网络，优先只做“去分频”的匹配完整读出验证。现有分频消融使用原外部源先验，而本次统一冻结的是重拟合先验版本，两者不是同一个模型。因此不能直接宣称上表35.053/42.597的 OA 是删分频后的成绩。其他旧辅助项不与它同时删除，避免失去归因。

这是一项未来的集成确认，不是本轮已经完成的实验，也不意味着继续开启模块搜索。没有用户新的研发指令时，维持当前冻结范围。

## 7. 论文可以怎么说

建议的核心表述：

> 面向少量目标标注下的跨港 SAR 船型识别，我们研究互补视觉表示与源先验锚定支持适配的协同作用。在匹配的支持集和读出协议下，当前双路表示取得了明确的完整系统净收益。进一步分析表明，少样本适配的有效性不仅取决于案例相似性，也取决于支持校正如何保留源先验中的正确类别证据；针对性支持重组在明确的小预算范围内获得平均收益。通过分层替换实验和支持构成分析，说明收益发生的位置及其适用边界。

目前足以形成一条连贯的、证据驱动的论文主线，但不是“已证明顶刊级原创性”或保证录用。双骨干、C4、岭回归和概率融合本身不逐个凑成新模块；新贡献应落在我们针对具体问题提出了什么改动，以及机制与收益证据能否对应。OpenSARShip 1.0 的紧凑/专家结果可作解释补充，不能伪装成与上述25任务同口径的完整模型结果；本次也不宣称已补齐六个数据集的统一主表。
