# 校正与融合接入小对照

## 问题与边界

上一轮：同一组64个标注样本更新专家线性先验，OpenSARShip 2.0先验OA/BA改善，但支持核校正抵消大部分分数变化；固定概率融合未保住识别收益。本轮检验是否是接入方式限制效用，不新增特征、不训练神经网络。

所有输出仅写入本目录；主线程模型与旧结果不变。公开数据采用已存在的更强 matched post-tail source-head 基线，不能退回弱旧基线。

## 冻结候选

记旧专家先验P、旧支持校正R、source-fixed 64标签头更新量D。仍用原核、强度8和原等权概率融合。

- original: E=P+R。
- resolve: 更新先验P+D，再用同一64样本重新拟合支持校正，与上一轮一致。
- retain_half: E=P+R+0.5D，原校正不重拟合。
- retain_full: E=P+R+D，原校正不重拟合。

保留旧校正可能重复使用同一支持证据，不能预设优于重拟合。半强度只设置这一个保守候选，不扫参。原核校正既非错误实现，也不能因为抵消而直接认定为无用。

源端公开集先验使用原FP32 sklearn拟合路径，头更新为FP64新旧头之差；不可用高精度重算替代原先验。首源任务诊断显示FP32与FP64拟合最大分数差0.000189，而FP64独立sklearn拟合与统计量求解相差2.8e-13，确认是数值路径差异。目标仍锚定既有保存头，不改变旧基线。已成功复现的57个港口任务可直接重用，避免无关重跑。

## 源端选择与目标评价

1. 使用既有frequency_preserve源港任务与固定64支持集、固定查询索引，共19+19+19+20个任务。各任务源读出训练排除对应留出港；复用已训练表征，故不称独立表征泛化验证。
2. 每个外层任务独立选接法。按港口等权平均完整模型OA选择，要求平均BA不低于original；数值同分优先BA、宏观NLL，最后优先小改动。无需每港都赢，不设显著性门槛。
3. 再按源港分组做留一港选择重放，报告选择波动；这是开发内部检查，不作独立确认。
4. 写出源端选择后才进入目标评价。四个候选全部预先冻结；主成绩是源端所选方案，其余为接入机制对照，不能拿目标最优替换主成绩。
5. 目标用原5组64支持集、原查询mask，以及5组公共查询交集；支持行不进入查询。沿用原完整模型行级协议，存在支持/查询同船重叠，不能改称未见船协议。

## 判断

同时报告OA/BA、概率损失、救回/误伤、先验/专家/融合层的变化、源端选择与目标表现。保留负结果。只做这轮预定小对照，不根据目标结果扩展参数或新增分支。
