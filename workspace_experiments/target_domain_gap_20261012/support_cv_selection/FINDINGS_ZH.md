# 同64例内部验证：能否选对更新接法

日期：2026-10-12。本轮完成。主线程模型、旧结果和论文未修改。

## 结论先行

**能在公开OpenSARShip 2.0上利用到一部分选择信号，但尚不是跨任务稳定有效的选择器。**

仅用原64个支持案例做内部交叉验证，预先固定的主选择规则使公开集完整模型OA/BA增加 **0.2934/0.2253个百分点**；相比固定全量更新的0.2119/0.0539，净效果更好。原源端选择在该任务一直保持原模型，没有获取这部分收益。

主要作用不是产生更强的新特征，而是识别部分支持集不适合强更新，减少散货船与集装箱船之间的误伤交换。三个自建港口仍未得到一致净收益；部分内部候选几乎给出相同预测，64例很难区分它们。

保留公开集的局部正收益，不要求所有任务获胜；也不将它升级为已经解决全部选择问题。

## 1. 协议与工作量

- 四种候选沿用上一轮：原模型original、更新先验并重算支持校正resolve、保留旧校正加半强度retain_half、保留旧校正加全强度retain_full。
- 三个自建港口和OpenSARShip 2.0，各原5组64标签，共20组支持；每组3次固定划分、每次4折，共240个折内拟合。无新增标注、无神经训练。
- 已知MMSI同船同折，未知身份各行独立成组。每个支持样本每次恰好被验证一次；三个划分共有192条预测-标签对，但仍只有64条标注，不是192个独立样本。
- 每折实际训练45至51条，余下作验证；基础分支的支持校正、专家支持校正和专家先验更新全部只用该折训练标签重新求解。
- 源统计、表征、源先验冻结。核岭强度保持8，分类头岭强度保持1，没有按查询结果调节。特征训练记录确认目标编码器标签为0，分频嵌入source_only。
- 主规则cv_oa：汇总三次留出结果，最大化完整融合OA，平均BA不得低于原模型；同分依次比较BA、macro NLL、小改动。
- 预定附加诊断cv_nll：选择内部micro NLL最低的接法。不把它事后替换成主规则，也不假设NLL最优必然OA/BA最优。
- 所有20组选择先保存，再用上一轮已冻结的每候选全64重拟合概率评价目标查询。复用的是完全相同的模型与支持集，不是跳过所需重拟合。

原查询排除支持行，另报五组公共查询交集。内部同船分组不将外部历史协议自动变成未见船验证；这些任务也已用于开发，不是新的独立确认。

## 2. 主结果：完整模型

OA/BA为原查询口径、五组支持均值。增量单位百分点。

| 任务 | 原模型OA/BA | cv_oa后OA/BA | OA增量 | BA增量 |
| --- | ---: | ---: | ---: | ---: |
| 洛杉矶 | 49.5568 / 43.2610 | 49.5568 / 43.0358 | 0.0000 | -0.2252 |
| 巴生港 | 52.0440 / 41.2347 | 51.9964 / 41.1347 | -0.0476 | -0.1000 |
| 桑托斯 | 43.4630 / 45.5343 | 43.5006 / 45.5112 | +0.0376 | -0.0230 |
| OpenSARShip 2.0 | 42.5971 / 34.6744 | 42.8905 / 34.8997 | **+0.2934** | **+0.2253** |

公开集采用较强matched post-tail source-head基线。不能将这些增量与更弱旧版本混用。

### 与源端选择、固定接法比较

公开集完整融合：

| 方案 | OA增量 | BA增量 | NLL变化 | Brier变化 |
| --- | ---: | ---: | ---: | ---: |
| 原源端选择 | 0 | 0 | 0 | 0 |
| 固定resolve | -0.0489 | -0.0868 | -0.001667 | -0.000627 |
| 固定retain_full | +0.2119 | +0.0539 | -0.016365 | -0.006146 |
| 内部cv_oa，主规则 | **+0.2934** | **+0.2253** | -0.004857 | -0.001726 |
| 内部cv_nll，附加诊断 | +0.2119 | +0.0539 | -0.016365 | -0.006146 |

cv_nll五组都选择retain_full：它更好地降低概率损失，却没有像主规则那样减轻类别间的交换。概率损失改善和top1改善仍不能混为一谈。

cv_nll在洛杉矶、巴生港、桑托斯上的OA/BA增量分别为+0.1541/-0.0450、+0.0060/-0.0765、+0.1004/+0.0021。这些诊断结果完整保留，不据目标成绩挑规则替换主结果。

### 公共查询交集

主规则cv_oa在四任务上的OA/BA增量分别为：洛杉矶0.0000/-0.2575、巴生港-0.0449/-0.1047、桑托斯+0.0295/-0.0472、公开集 **+0.2791/+0.1704**。公开集正收益不是仅由五组查询成员变化造成。

## 3. 公开集具体选了什么，为什么有收益

draw按原缓存从0编号。

| 支持组 | 选中接法 | 内部OA/BA增量 | 最终查询OA/BA增量 | 实际作用 |
| --- | --- | ---: | ---: | --- |
| 0 | original | 0 / 0 | 0 / 0 | 内部发现强更新有害，避免retain_full的BA -0.533；但也错过resolve的小收益 |
| 1 | original | 0 / 0 | 0 / 0 | 避免retain_full的BA -0.636，同时放弃它的OA +0.326 |
| 2 | retain_half | +0.521 / +0.430 | +0.326 / +0.076 | 保留一部分更新收益，不是该组查询的最优BA接法 |
| 3 | resolve | 0 / +0.449 | -0.081 / -0.064 | 仍选错了一点，但避免retain_full的OA -0.761；原模型其实更好 |
| 4 | retain_full | +2.083 / +2.211 | +1.222 / +1.114 | 内部确实识别到了值得强更新的一组支持 |

这不是五组都选对。它显示可用的支持内部信息能判断部分更新风险和机会，而不是只能依靠源港经验或目标查询标签。

每组平均：固定全量更新救回141.2、误伤133.4，净多判对7.8条；cv_oa救回42.8、误伤32.0，净多判对10.8条。**更少地动预测，反而得到略高的净收益。** 救回/误伤不包括错误类别之间互换，不能把它们之和说成所有预测翻转数。

事后用查询标签从四个候选里逐组挑最高OA，其平均可达+0.3912个百分点；cv_oa为+0.2934，相差0.0978。这个上限只说明剩余选择空间，不是可部署方案，也不保证更复杂选择器能获取它。

## 5. 结果是否依赖抽样与折划分

### 五组支持

公开集主规则OA/BA均为2组提升、1组退化、2组不变。配对增量标准差为0.5424/0.4995个百分点。

去掉收益最大的一组后，剩下四组平均仍为 **+0.0611/+0.0030**，但幅度很小。不能把完整均值描述成各组都很稳定；也不因这种波动删除已经存在的局部净收益。

### 三次内部划分

每次4折单独形成一个选择结果，再事后评价公开集五组均值：

| 内部划分种子 | OA增量 | BA增量 |
| --- | ---: | ---: |
| 20261012 | +0.3640 | +0.1961 |
| 20261013 | +0.3477 | -0.0013 |
| 20261014 | +0.0598 | -0.0176 |
| 预定三次留出汇总后选择 | +0.2934 | +0.2253 |

OA方向三次都正，BA没有同样稳定。汇总规则预先固定，不是看完查询后挑了最好的种子；三次划分仍共用同一64例，不能当成独立数据集重复。

## 6. 为什么自建港口仍选不好

目前证据支持以下限制，不预设都是实现错误或只有一个根因。

1. **候选差别太小，离散准确率不容易辨别。** 三次留出预测中，至少一个候选与原模型首选不同的比例，洛杉矶平均2.50%、巴生港0.73%、桑托斯1.25%，公开集为10.31%。巴生港draw2、桑托斯draw1的四个候选首选预测完全相同，只能由概率损失打破平局。
2. **类别覆盖不完整。** 公开集五组支持的类别数为8/7/7/8/7；三个自建港口部分组只有6或7类，部分已出现类别也只有1例。某折拿走稀有类之后，该折训练可能没有该类。已记录全部折内缺类情况；没有通过偷用留出标签补齐。
3. **内部BA护栏不是查询BA保证。** 它只能依据64例中出现的类别，目标查询还包含未被这些案例覆盖的类别与子群。即使内部BA不降，最终仍可能降。
4. **折内训练量与最终训练量不同。** 每折45至51例，最终64例；核正则保持原8。当前结果未独立分离这一差别和支持代表性/排序噪声的作用，不能声称已经唯一定位失败原因。

以上解释与观察相符，但不据此无限追加种子或强度扫描。尤其对候选在该任务本来就几乎没有净收益空间的情况，复杂选择器不一定值得开发。

## 7. 实现与核对

- 三个单元测试通过：同船分组和覆盖；训练/留出标签隔离及支持排列；主选择规则与NLL诊断规则。
- 20组缓存逐折同船隔离、概率归一、逐类召回贡献与总体BA核对通过。
- 公开集draw0把CV预测函数退回全64训练，四臂概率与上一轮冻结模型最大误差2.22e-16。证明本轮比较的确是相同接法，而不是CV实现换了模型。
- 所有选择在目标评价阶段之前保存；无目标查询标签参与折内拟合或选择。既有研究方向与候选当然已在开发数据上探索过，不称盲测。
- 当前环境读取历史sklearn模型仍有版本警告，未更改环境；实际概率复现已通过。

## 8. 本轮收口判断

保留为：**少量目标支持案例可以提供更新适用性的线索；在当前公开集开发协议下，内部验证选择减少误伤，得到可解释的小幅净收益。**

不升级为：跨任务稳定最优选择器、逐样本因果门控、已经解决所有跨港识别问题。暂不自动替换主模型。

后续若继续，优先固定当前候选与规则，做有限的新增支持抽样确认公开集收益和散货船损失是否重复出现；不要先增加网络模块或用查询结果重新挑选择规则。新增抽样仍是同数据开发确认，不会自动变成独立新数据验证。本轮未开展该追加实验。
