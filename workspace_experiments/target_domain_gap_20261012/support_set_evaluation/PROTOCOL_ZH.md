# 将64例支持集不确定性纳入评价

2026-10-12。沿用三港、OpenSARShip2、两个固定测试划分，独立输出，不改变主线程模型或旧结果。

## 要补的评价维度

原两个划分同时改变源采样、查询场景及支持案例，不足以单独归因支持集影响。本轮固定每个划分的源2048船、特征及PCA、分类器起点、查询船和场景，只更换64个支持案例。

## 固定实验

- 候选支持池为该划分原support与target_add的并集：洛杉矶220艘，其他任务320艘，每船一条。它们均不与源训练和查询共享身份，且不与查询共享产品。
- 本轮不训练S+T教师，不读其权重。未抽中的池内标签不进入模型。候选池是既有缓存的子集，不声称覆盖所有可能支持案例。
- 每个固定划分均匀无放回抽5组新支持集，固定seed1201..1205，不使用类别配额，不看查询选组。每次独立目标标注预算64，不累计合并标签训练。
- 原先那组64只作为历史结果，不纳入这5组新抽样均值。
- 两种实际方法：original_residual64（S先验+64残差）；global64_residual64（S+同64重拟合先验，再用同64残差）。特征和超参数完全不变。
- 同时记录不使用目标标签的source_prior，量化支持适配整体收益。该先验在同一固定划分中不随支持抽样改变。
- 每个支持集完全配对，不把两种方法各自最好的支持集相比较。
- 40组支持抽样、80个线性分类头拟合、0次神经训练；所有结果保留。

## 指标定义

1. 查询OA、八类BA、逐类召回，以及按船等权OA/BA；支持行不进入任何查询指标。
2. 每个固定划分内的支持抽样均值、样本标准差(ddof=1)、最小/最大值。
3. 同组支持上的方法增量Delta OA/BA、均值、支持抽样标准差、正/零/负组数。
4. 各次支持的类别计数、覆盖类数、缺失类；查询中的类不因支持缺类而删除，未抽到某类不是该类不存在。
5. 任务均值先在固定划分内平均5组，再平均两个划分。支持抽样SD取两个划分内方差的平均再开方，不把不同查询集合造成的波动混进去。
6. 最小值保留每个固定划分，任务表的最差值是两划分共10组中的最小值。支持SD不是标准误或置信区间，重叠支持及两个既有查询划分不当独立新数据。

本轮仅增加评价充分性。若旧正信号变弱或变负，如实更新结论，不挑有利抽样，不调超参数寻找恢复。
