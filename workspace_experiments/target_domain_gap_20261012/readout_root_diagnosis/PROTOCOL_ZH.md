# 判别适配根因：源重加权与目标案例信息拆分

日期：2026-10-12。侧线研究，主线程模型、脚本和论文均不修改。

## 问题与固定条件

回答同64标签联合读出增益主要来自源样本重新加权，还是目标案例的特征与标签，以及两者的相互作用。不是检验物理因果因素。

复用support_set_evaluation的全部40组：四任务、两个固定查询划分、每划分五组支持。读取已保存支持和查询索引，不重抽、不筛选。保持源2048、源拟合几何、两个特征头、岭参数1、支持残差参数8和等权概率融合。目标预算B=64只是本轮工作点。所有新拟合仍仅使用同64个目标标签。

## 拆分定义

H=[x,1]；Y为八类one-vs-rest编码(+1/-1)。源权重w0按源类频率平衡，总和2048。联合权重w1按S+T类频率平衡，总和2048。分别截取w1S、w1T，不再次归一化。

令G=H' diag(w) H，C=H' diag(w) Y，R=diag(1,...,1,0)。theta=(G+R)^(-1)C。最后一维不惩罚，重现现有带截距RidgeClassifier，而非增加新的正则化方法。

| 代号 | 源项 | 目标项 | 用途 |
| --- | --- | --- | --- |
| B | w0 | 无 | 原源读出 |
| R | w1S | 无 | 只替换源权重，保留其总量变化 |
| T | w0 | w1T | 源权重完全不变，只加入目标案例 |
| F | w1S | w1T | 原联合读出，重放已保存新方案 |
| U | w0乘以sum(w1S)/sum(w0) | 无 | 仅源总量变化，源内相对权重不变 |
| UT | 同U | w1T | 与F总权重相同，移除源内类别差异重加权 |
| G | 同R | 仅目标G | 目标二阶矩/法方程矩阵诊断 |
| C | 同R | 仅目标C | 目标特征-类别交叉统计诊断 |

B/R/T/F构成两因素干预，目标权重在两条含目标分支中相同。T总权重略高于F是“源权重保持原样”定义的结果，不隐瞒此变化；U/UT控制用于区分源相对权重与总权重/有效正则强度效应。

G包含均值和截距项，不等于纯中心化协方差。C含类别频率及特征均值，不等于纯语义证据。w1T使用目标标签定义，因此G臂不是无标签方法。G/C是固定坐标和编码下的代数干预，不是完整数据集上正常监督训练；单项结果不能直接相加，不据其事后表现选新部署方案。

## 计算链与输出

各臂均计算仅分类头(prior)及分类头+同64支持残差(residual)两种阶段，融合规则不变。主比较为residual阶段。所有预测先保存，再读取查询标签评分；当前查询是既有开发集，不是独立确认。

报告OA/BA、按船等权OA/BA、固定softmax概率下NLL/Brier、支持集标准差、逐组配对增量、获益/退化次数与逐类召回。BA保留八类，不因支持缺类删除查询类。支持自身不混入测试分母。

两因素贡献采用顺序平均：source=0.5[(R-B)+(F-T)]，target=0.5[(T-B)+(F-R)]。这只是指定计算干预下的分解，不是现实物理因果贡献。交互为F-R-T+B；不将重复支持抽样当独立数据集，不挑正结果、不展开超参数扫描。

## 必要核验及其用途

1. 小型非均衡合成数据上，增广法方程与现有sklearn加权岭预测一致，检出截距被误惩罚或标签编码不符；失败则先修实现。
2. 真实B、F融合预测与旧缓存一致，概率误差阈值2e-6且分类相同；失败则不解释新差异。
3. 验证thetaF-thetaR=(GS1+GT+R)^(-1) HT'WT(YT-HT thetaR)，确认统计拆分还原实际更新；失败则修正矩阵或权重接法。
4. 汇总配对增量与分解之和一致；检出报告把不同支持或阶段混合。

不重新训练骨干，不调用额外目标诊断标签，不启动与本问题无关的对照。根因若仍未分清，明确剩余候选解释，不强行认定唯一原因。

## 首轮结果后的有界追加诊断

首轮40组计算完成后，发现源重新加权不能解释公开集主要OA收益，C臂接近F，而G臂退化。为区分C中的类别组成/共同偏移与真正的特征-标签关联，追加两个代数干预，不调参、不改变样本或选择最佳臂。

固定联合正常矩阵GS1+GT+R，将CT精确拆为M+K：M=sum(wT) outer(weighted_mean(HT), weighted_mean(YT))；K=CT-M。M保留加权全局特征均值与类别组成，但去除其中心化关联；K为加权中心化特征-标签交叉统计。K不是原始图像因果特征，M也不等于纯类别偏置。

以G臂为共同起点，M臂仅加M，A臂仅加K，F臂两者都有。两项对分类参数的贡献严格可加，但残差、softmax和argmax后的指标需单独计算，不能直接相加。输出顺序平均贡献以及M/A各自和原B的比较。本追加是观察首轮后的机制定位，不是预先独立验证。
