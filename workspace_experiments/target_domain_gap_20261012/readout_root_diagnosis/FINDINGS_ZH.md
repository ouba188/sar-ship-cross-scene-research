# 判别适配的收益来自哪里：源重加权、目标统计与类别关联

日期：2026-10-12。已完成。仅此侧线实验，不修改主线程模型或论文。

## 结论先行

本轮把收益来源进一步定位到了分类头的目标信息使用方式，而不是源样本类别权重重算。对OpenSARShip 2.0，源权重不改、只加入同64例目标案例仍得到OA +3.17个百分点；只重算源权重没有相应收益。

更具体地说：联合读出利用的目标统计同时包含“整体特征均值与类别组成”和“中心化的特征-类别关联”。在当前固定联合正常矩阵下，两者配合才获得完整公开集收益。去掉关联、保留整体统计后，再补回关联，OA提高2.21个百分点、10组均提高；BA平均提高0.98个百分点、8组提高。不能把整体统计一概当成应去除的噪声，也不能把关联单独拿出来就称为有效因果因素。

同时，真实同64标签模型中也重复出现了集装箱/散货纠错。此前这一详细规律主要来自更多目标标签的诊断，本轮把该模式与实际64标签结果接上了。

这是算法计算路径的机制定位，不是物理因果发现，也尚未证明“源港与目标港的类别条件分布变化”是唯一数据层原因。

## 1. 范围与评价

- 自建24港中的洛杉矶、巴生港、桑托斯，以及公开OpenSARShip 2.0，共4个任务。
- 每任务两个固定查询划分，每划分复用上一轮5组支持，共40组；每组64条标注、64艘不同船。源训练2048艘，特征和源拟合几何不变。
- 所有臂共享相同源、支持与查询；不存在额外目标标签。支持集选择、查询船与场景隔离继承已有缓存。
- 主指标来自“分类头适配+同64例残差校正+原等权概率融合”。同时输出仅分类头阶段，用来区分全局读出与残差配合。
- 保留八类OA/BA、按船等权OA/BA、固定概率转换下NLL/Brier、支持抽样波动、逐类召回和误伤。NLL/Brier改善不被解释为已经证明概率校准改善。
- 冻结历史表征、紧凑双头模型、已反复开发的查询集，不是论文完整模型或独立确认。10组抽样可能重复船，不当作10个独立数据集。

## 2. 先拆源权重与目标案例

原源权重w0总和为2048；联合训练按S+T类别数量重算权重w1，总和仍为2048。w1的源部分平均总量约1987、目标部分约61，所以源类别权重变化与源总量变化需要分开。

| 臂 | 含义 |
| --- | --- |
| B | 原源分类头，作为原64例方案的读出 |
| R | 只把源权重换成联合训练中的源权重，不加入目标特征训练读出 |
| T | 源权重原样保留，加入与完整联合方法相同权重的目标案例 |
| F | 完整联合读出，源权重重算并加入目标案例 |
| U | 源相对权重不变，只缩放源总权重到R的量 |
| UT | 同U，并加入目标案例；与F总权重相同 |

注意：所有臂的后续支持残差仍使用真实64标签。因此R并不是“整个模型不使用目标信息”，而是“分类头新增适配只改变源权重”。

下表为相对原B残差方案的平均增量，单位百分点：

| 任务 | 只重算源权重R OA / BA | 源权重不变加目标T OA / BA | 完整联合F OA / BA |
| --- | ---: | ---: | ---: |
| 洛杉矶 | -0.38 / -0.12 | +0.08 / -0.51 | +0.08 / -0.53 |
| 巴生港 | -0.39 / -0.07 | +0.46 / +0.19 | +0.25 / +0.36 |
| 桑托斯 | -0.82 / -0.06 | +1.40 / +0.58 | +0.45 / +0.36 |
| OpenSARShip 2.0 | -0.14 / +0.01 | +3.17 / +0.59 | +3.09 / +0.64 |

判断：公开集主要OA收益不是源重加权造成的。桑托斯的重加权还抵消了部分目标适配收益；巴生港和公开集BA存在小的权重/目标交互，不能说源权重对所有指标都无影响。

等总权重的UT相对原B：公开集OA +3.20、BA +0.51；桑托斯OA +1.40、BA +0.58。这排除了“只是T总训练权重稍高”作为这些OA正信号的主要解释。单独源总量缩放U对OA/BA只产生很小变化。

顺序平均两因素计算归因，公开集OA源重加权贡献-0.110、目标案例贡献+3.198，合计+3.088；BA分别+0.036、+0.608，合计+0.644。这是指定模型干预下的分配，不是现实物理因果占比。

## 3. 目标案例究竟通过什么量起作用

令H=[x,1]、Y为八类+1/-1编码、W为样本权重、Lambda为不惩罚截距的单位岭惩罚。分类器满足：

`Theta = (H' W H + Lambda)^(-1) H' W Y`

目标贡献可拆为：

- GT=HT' WT HT：目标特征二阶矩及均值/截距项，不能简称纯协方差。
- CT=HT' WT YT：目标特征与标签交叉统计，包含类别组成和特征-类别关联。

先固定重加权源项，分别加入GT、CT及两者。公开集残差阶段：

| 分类头适配保留项 | OA | BA |
| --- | ---: | ---: |
| 原B方案 | 35.027 | 30.112 |
| R，仅源重加权 | 34.886 | 30.125 |
| G，仅加入GT | 31.539 | 28.289 |
| C，仅加入CT | 38.101 | 30.745 |
| F，同时加入GT与CT | 38.115 | 30.756 |

CT项在这一分解下保留了大部分公开集收益；仅GT不够，且会退化。但是G/C是代数干预，特别是C不是正常完整目标监督损失，不能据此把“删掉GT”选成新主方法。GT的权重使用目标标签，且残差仍用真标签，G也不是无监督对齐实验。

## 4. 不能把整体统计扔掉，只留下所谓纯关联

首轮结果提示继续分解CT；此追加已在PROTOCOL_ZH.md标明为看过首轮后的有界诊断，无调参、无重抽样。

加权目标均值记作meanH、meanY，目标总权重m。精确分解：

`CT = m * meanH * meanY' + sum_i wi (Hi-meanH)(Yi-meanY)'`

第一项M包含共同特征均值和类别组成；第二项K是中心化特征-标签关联。M不是纯类别偏置，K不是物理或因果因素。保持联合正常矩阵GS+GT+Lambda固定，构造：

- M臂：分类头只加入第一项；
- A臂：分类头只加入中心化关联；
- F臂：两项都加入。

这里“只加入”只指分类头的目标交叉统计；所有臂的源信息、目标正常矩阵和真实标签支持残差都保留。

公开集平均结果：

| 方案 | OA | BA | 相对原B的OA / BA增量 |
| --- | ---: | ---: | ---: |
| 原B | 35.027 | 30.112 | 0 / 0 |
| 只加整体统计M | 35.908 | 29.773 | +0.881 / -0.339 |
| 只加中心化关联A | 34.580 | 29.179 | -0.447 / -0.933 |
| 两者都加F | 38.115 | 30.756 | +3.088 / +0.644 |

保留整体统计，再补回关联(F-M)：

| 任务 | 平均OA增量 | 平均BA增量 | OA正/负/平次数 | BA正/负/平次数 |
| --- | ---: | ---: | ---: | ---: |
| 洛杉矶 | +0.690 | -0.073 | 6/3/1 | 5/5/0 |
| 巴生港 | +0.837 | +0.463 | 8/2/0 | 8/2/0 |
| 桑托斯 | +1.741 | +0.183 | 9/1/0 | 5/5/0 |
| OpenSARShip 2.0 | +2.207 | +0.982 | 10/0/0 | 8/2/0 |

公开集F-M的OA增量支持抽样标准差0.750、BA标准差1.005个百分点；标准差在固定外层查询划分内计算再合并，不混入两个查询群体差异。

40组的F-M均改善NLL和Brier。这是这部分关联改善真实类别概率预测的证据，但不保证每个港口BA都提高。公开集完整F相对原B的NLL平均降低0.03144、Brier降低0.01275，均10组改善。

关键解释：目标类组成/共同特征方向与类条件关联共同参与了有效更新。只抽出中心化关联不保证收益，因此不能继续沿用“把共同漂移一律去掉，留下更纯信息就一定更好”的假设。

注意，F-M +2.207不是在F已经获得的+3.088上再增加2.207；它是F内部成分干预的效果。

## 5. 数学上实际执行了什么

源重加权读出记ThetaR。联合目标更新具有精确恒等式：

`ThetaF-ThetaR = (GS+GT+Lambda)^(-1) HT' WT (YT-HT ThetaR)`

右侧包含“目标案例在现有源读出下的预测残差”，再通过源与目标的联合特征正常矩阵传播到分类参数。80个实际头的数值核验最大误差1.68e-14。

人话：不是凭空生成新视觉信息，而是根据当地已知船的判别误差，按照已有训练特征的几何结构调整如何读出这些特征。这是当前岭适配计算的明确描述，不应把标准岭更新恒等式包装为新算法。

## 6. 同64标签下的类别纠错与代价

公开集原B到完整F的10组配对中，“真实集装箱船原被判为散货”的纠错方向9组净收益、1组小幅负收益。该有向类别对平均贡献BA +0.778个百分点。累积184次救回、19次同真实类别方向的误伤；这些是重复抽样暴露次数，不是184艘互不相同的船。

同时，真实散货被改判为集装箱产生负贡献，平均BA -0.606个百分点。整个公开集全部类别的获救去重353艘、误伤去重206艘，均涉及14个查询场景；同一船可能在不同抽样下分别获救和受损，两个集合不能直接相减当成净获救船数。

公开集逐类召回率变化(F-B)：

| 类别 | 召回增量/百分点 |
| --- | ---: |
| 散货 | -3.210 |
| 渔船 | +6.017 |
| 杂货 | -3.343 |
| 成品油/化学品 | +3.455 |
| 集装箱 | +9.225 |
| 原油轮 | -0.089 |
| 拖轮/拖带 | -3.571 |
| 海工补给 | -3.333 |

因此OA增益不能表述为所有类别同时变好。BA小幅改善，是获益类别与受损类别抵消后的结果；少数类查询很少也会放大单个错误对BA的影响。以上用于解释收益分布，不因此否定已重复的OA效用。

## 7. 我们现在解释到了哪一层

已经支持：

1. 在本轮读出和融合设定下，源重新加权不是公开集主要OA收益来源。
2. 目标案例的特征-标签统计在原支持残差之外，能通过联合读出发挥额外效用。
3. 对公开集，中心化关联与整体统计配合有效；不是“去掉共同部分，只留纯关联”更好。
4. 同64标签的实际纠错重复涉及特定类别竞争，也存在对应误伤，OA与BA差异有具体事件来源。

尚未确定：

- M中的类别频率与共同特征偏移分别贡献多少。
- 这些差异究竟主要来自真实港口条件、船型内部子群覆盖，还是有限源样本代表性和读出训练目标。
- 冻结历史表征中具体的物理散射因素、以及完整主模型接入后能否保留这些收益。

所以可以解释“当前适配通过哪条计算路径起作用”，还不能宣称识别了跨港失配唯一的现实根因。

## 8. 下一步方向

优先保留完整的目标类别证据，以源判别结构约束更新；不把共同特征统计直接当噪声抑制。源相对权重保持不变、目标统计独立加入，是值得在完整模型检查的简洁候选，桑托斯已有受益信号；不是据此立即替换所有任务的主模型。

后续若进一步解释M，宜只拆类别组成与共同特征均值，而不是继续增加注意力或因果分离模块。每项开发仍以任务净收益为依据，不要求所有港口、类别和抽样都获胜，也不删除现存退化。
