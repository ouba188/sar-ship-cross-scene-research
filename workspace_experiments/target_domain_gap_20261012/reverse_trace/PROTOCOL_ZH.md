# 从纠错结果反推机制：固定分析方案

2026-10-12。复用上轮三港、OpenSARShip2、两个固定划分，仅分析冻结表征的S+U与S+T。原实验与主线程文件不变。

## 本轮问题

1. 哪些真实类别与错误类别之间的竞争被修正？是否重复发生在多船、多景、两个划分？
2. 变化是类别常数偏置、旧分类分数重组，还是旧分数未表达的特征权重变化？
3. 哪一路提供纠错，另一头及64例支持校正如何影响它？
4. 是否呈现低维、可进一步学习的修正结构？本轮不把有更多标签的老师当作64标签方法。

## 固定计算

- 同一查询四分组：救回、误伤、一直正确、一直错误；保留所有组、所有任务。
- 类别对按真实类与错误类统计，正救回、负误伤，按该类查询总量换算BA贡献。两个划分单列，不当独立总体推断。
- 以共同S的均值为固定特征原点，将分类器变化写成(x-mu)DeltaW + (Delta b + mu DeltaW)。偏置含义是该参考点处整体类别分数调整，不是坐标无关的物理因素。
- 对DeltaW产生的变化，使用S上旧八类分数的线性最小二乘投影，分为可由旧分数重组解释的部分和剩余特征部分。投影不读查询标签，但DeltaW本身来自额外156/256标签，只是事后机制分析。
- 固定比较：原始、仅偏置、仅特征权重、旧分数重组加偏置、剩余特征加偏置、完整变化、仅R50头变化、仅双路头变化，以及DeltaW的rank1/2/4加偏置。完整报告，不按查询挑最优。
- 偏置、R50特征权重、R18特征权重共三个计算因素，对全部8种组合重算原支持残差和最终概率融合。以原模型的最强错误类别固定竞争对象，计算精确三因素Shapley分配。这里是模型计算归因，不是物理因果效应。
- 分数确定程度用原融合top1-top2间隔表示，分组阈值来自共同S上分数间隔的25/75分位，不称为已校准置信度。
- 不更新骨干、不训练新增分类模块、不新增目标标签、不选择新的超参数。先从机制证据决定下一步64标签可利用性试验。

## 核查针对的具体失败

- 端点必须重放原保存预测，防止错误的行映射、漏支持更新或漏某一分支。
- 支持校正变化同时作用于查询与支持；不能只改查询分数后误称完整分类器替换。
- 合成纯偏置和纯旧分数重组检验，防止分解错误地制造新特征证据。
- 三因素归因之和必须等于实际融合竞争间隔变化；未满足则停止解释并纠错。

## 运行中有依据的追加诊断（不训练、不调参）

第一次完整分解后发现，特征权重变化比类别偏置和旧分数重组更重要。检查现有实现可知，线性核残差本身已等价于特征权重适配，不能将“开始调整特征权重”重新包装为新模块。

因此追加一个固定二分：在原核坐标[x,1]下，将目标经验DeltaTheta投影到64个支持行张成的空间及其正交补。后者必须在64个支持点上产生零分数变化，却可能改变未见查询。分别重算完整支持校正与融合，不选择查询最佳分量。此分解依赖现有特征度量，不是物理因素，也不证明所有64标签方法都无法推断正交部分。此项是针对已观察结果的事后诊断，不伪装成首次运行前的预注册。
