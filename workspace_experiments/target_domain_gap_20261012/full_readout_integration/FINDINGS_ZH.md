# 完整模型接入：有用信息在哪里生效，又在哪里失去识别收益

日期：2026-10-12。状态：本轮完成。原主模型、外部实验缓存与论文未修改。

## 结论先行

这轮同时完成了完整模型接入和类别统计拆分。结论不是“没有学到有用信息”，也不是“完整模型已经提升”：

1. 公开集上，目标类别条件均值比仅改变类别组成更能解释分类头改善。不是只学会猜当地哪类船多。
2. 在更强的既有完整双骨干版本上，保留源权重的适配使专家先验OA/BA +3.070/+1.432个百分点；经过原支持校正后，专家仍有+0.239/+0.150。
3. 进入原等权概率融合后，最终OA/BA为-0.049/-0.087个百分点；micro NLL和Brier在五组支持上都改善。因此保留专家与概率预测的正效用，不把它写成完整模型识别提升。
4. 已定位计算路径：重新解支持残差会抵消大部分先验变化；最后融合的BA负增量几乎全部发生在专家首选类别未变的样本。下一步应针对重复适配与融合配合，不宜继续堆叠特征模块。

这些小幅退化不证明方向无效，也没有被事后删除或预先归为纯随机。本轮不再加大更新、扫描强度或按目标结果选择诊断臂。

## 1. 接的是哪个完整模型

基础分支保留原C4/分频表示、条件支持匹配与已训练的分频嵌入；专家保留原R50/R18、保留与互补坐标、港口侧候选稳定坐标/漂移衰减/入射角算子及原支持核。两路最终等权softmax概率融合，不新增路由，不重新训练骨干。

本轮只适配专家先验分类头。基础分支完全固定，所有臂共享相同64支持标注。两个主候选：

- joint：按合并后的类数量重算源样本权重，并加入目标案例；
- source_fixed：源权重不变，加入与joint同权重的目标案例。

岭强度1、支持残差强度8不变。先用原源拟合坐标计算源头与适配头之差，再叠加到原先验；零增量严格保持原预测，避免把仅重拟合的数值差异当成适配收益。

### 公开集的版本核对

最初复现了unified_head_20261010中的原始专家版本，公开集基线OA/BA为40.766/33.915。历史backbone_ablation_20261010还保存了部署特征匹配重拟合的更强源分类头，其完整融合为42.597/34.674。本轮追加相同对照，主结论采用后者。

旧版本结果完整保留在full/oss2；匹配版保存在matched_full/oss2。不能将旧版上的+0.467 OA、+0.109 BA提升当成超过更强既有模型的证据。三个港口的两版源分类头一致，因此没有重复计算。

## 4. 对公开集，信息在哪一层有用

较强匹配版，source_fixed相对各阶段自己的原始参照：

| 决策阶段 | OA增量/百分点 | BA增量/百分点 | OA正/负 | BA正/负 |
| --- | ---: | ---: | ---: | ---: |
| 专家先验，尚无支持残差 | +3.0698 | +1.4318 | 5/0 | 5/0 |
| 专家加原支持残差 | +0.2391 | +0.1502 | 4/1 | 3/2 |
| 与原基础分支等权融合 | -0.0489 | -0.0868 | 1/4 | 1/4 |

不能把不同阶段增量直接相减解释为严格分配的准确率贡献，因为各阶段的原参照不同。它们清楚表明：分类头改善不自动等于完整系统改善。

概率预测仍有正结果：完整融合micro NLL由1.780327降至1.778660，Brier由0.782623降至0.781996，五组都改善；类别等权Brier平均也降低0.000351。概率风险、类别首选准确率和概率校准不是同一概念，不把风险降低表述为已证明校准更好。

## 5. 类别组成与同类特征均值的作用

固定源项、目标正常矩阵和目标总权重，只替换目标特征-标签交叉统计：

`CT(pi,mu) = m sum_c pi_c mu_c (2 onehot(c)-1)'`

pi是有效类别组成，mu是类别条件特征均值。源piS为类平衡训练的1/8；目标piT来自本组支持及其固定权重。缺少某类支持时，其目标均值以源均值填补并记为缺失，不能宣称测到了缺失类的目标分布。

- SS：源组成、源均值；
- TS：目标组成、源均值；
- ST：源组成、目标均值；
- TT/joint：目标组成、目标均值，精确恢复实际目标交叉统计。

所有臂后续残差仍使用真实64标签；这仅隔离先验分类头新增更新的信息，不是使整个模型完全失去目标标签。替换臂是代数机制诊断，不是重新采样的真实训练集，也不是部署候选。

### 简化模型公开集

| 交叉统计 | OA | BA |
| --- | ---: | ---: |
| SS | 31.635 | 28.369 |
| TS，仅目标组成 | 31.889 | 28.409 |
| ST，仅目标条件均值 | 36.946 | 30.199 |
| TT，两者均为目标 | 38.115 | 30.756 |

固定源均值时，改类别组成仅增加OA +0.254、BA +0.040。固定目标组成时，把源均值换成目标均值增加OA +6.225、BA +2.347，OA十组均正、BA九组正。这些差值的参照是统计替换臂，不是实际原模型，不能把+6.225称为新方法净增益。

### 较强完整公开集：先验阶段

| 交叉统计 | OA | BA |
| --- | ---: | ---: |
| SS | 24.233 | 20.116 |
| TS，仅目标组成 | 24.249 | 20.124 |
| ST，仅目标条件均值 | 25.868 | 21.156 |
| TT，两者均为目标 | 27.558 | 21.530 |

TS-SS仅+0.0163/+0.0079；TT-TS为+3.3089/+1.4067，五组均正。这个版本源和目标采用匹配的post-tail表征，因此这里的均值作用不只存在于旧版训练/部署表征不匹配的情形。

这支持“同类船在目标表征中的典型位置提供了有用证据”，而不是只依靠目标类别数量。类别组成也不是完全无用：有目标均值时TT-ST为+1.6898/+0.3742，存在配合效应。

完整融合之后，TT-TS仅+0.0435/-0.0117，说明上述先验效用未充分转化为最终top1收益。

边界：本实验识别的是固定线性读出下的类别一阶统计作用，不是完整类内分布、真实成像物理机制或纯因果信息。目标均值估计、船型子群覆盖与源训练代表性仍未完全区分。

## 6. 为什么先验涨点，最终却没涨

### 支持残差抵消了大部分先验变化

原支持核和权重固定时，改变先验会同时改变支持残差的拟合目标。残差重新求解后，不能把先验上的收益简单叠加到原系统。

对较强公开集source_fixed，查询样本上的中心化先验分数变化RMS平均0.112765，专家适配后变化RMS为0.021103；逐draw范数保留比例平均18.69%。新增先验变化与残差变化的余弦为-0.9828，说明计算上有强烈抵消。

这是分数变化幅度，不是“81%的准确率收益被抵消”。它符合两个阶段修正内容重叠的解释，不证明信息不存在，也不代表残差求解有实现错误。

### 融合发生在概率层，不只看专家改对了多少

较强公开集source_fixed每组平均专家救回32.2条、误伤23.4条；其中12.6条专家救回后，最终融合仍错误。完整融合平均救回21.6条、误伤23.4条。

按专家首选类别是否变化划分，最终BA增量为：

| 样本组 | 完整融合BA净增量/百分点 |
| --- | ---: |
| 专家首选类别发生变化 | -0.00137 |
| 专家首选类别没有变化 | -0.08540 |
| 总计 | -0.08677 |

固定基础分支后，最终正确类对竞争类概率间隔的变化，精确等于专家对应间隔变化的一半。逐事件重放已验证。因此末端负结果主要不是“专家自己多判错了一批”，而是专家概率变化改变了与基础分支的融合边界。这是具体计算原因，不是已经确认温度调整或门控一定能修复。

同一问题也出现在部分港口：洛杉矶专家BA +0.154，但融合BA -0.281。完整模型接入必须考虑最后的融合决策，而不能只优化专家单独表现。

## 7. 本轮如何收口

保留的正证据：目标类别条件均值有任务判别价值；同64例能改善先验和专家；完整公开集概率风险也改善。

不升级的主张：暂不能说简单追加这次适配改善了更强完整模型的OA/BA，也不能说保持源权重已经成为更优主模块。

下一步若继续，最有价值的是源端验证“以最终融合为目标、兼顾已有支持校正的更新”，先检查能否把已存在的专家收益转成最终收益。不要根据目标查询挑一个强度，也不要因先验正收益就再次堆叠模块。完整系统的小负增量保留，不作为对所有目标信息利用路线的一票否决。

本轮未开展该下一阶段的训练或融合参数选择。
