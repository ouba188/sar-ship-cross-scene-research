# 多港口类别原型与自适应区域匹配：总体设计第二版

日期：2026-11-20。阶段：思路设计。依据用户本轮总体方案、上一版DESIGN_ZH.md、已读ZoomViT/MSViT及现有代码/源端数据证据。只整理设计，不修改模型代码、不启动训练、不改正式论文。

## 1. 核心目标与证据边界

目标：当目标港口未参与训练时，利用多个源港口的类内外观多样性，为查询船舶选择合适的参考模式和局部比较粒度，改善类别判别。

核心张力：不能把同类跨港的所有差异都消掉，也不能把港口与船型的统计关联都当作判别规律。需要保留有助于类别识别的类内变化，同时降低不可迁移的证据依赖。

已有证据是同类尺寸/细类组成差异、尺寸匹配后的图像响应差异，以及当前固定参考的覆盖缺口。没有直接证明船体谱系、上层建筑或特定散射机制的港口差异。以“类内外观模式”命名初期原型，不预先给簇赋予物理船型名称。

暂用研究题名：**干预引导的多港口类别原型与自适应区域证据匹配**。这是工作题名，不是已完成贡献声明。

## 2. 三个研究假设

| 假设 | 需要解决的问题 | 有辨别力的支持证据 |
|---|---|---|
| H1 类内多原型 | 少量固定参考不能充分覆盖同类外观模式 | 同参考预算下，覆盖式多原型优于随机参考；改善集中在原覆盖不足样本而非仅多看了数据 |
| H2 条件化取证 | 注意力高或纹理复杂不一定值得细分 | 相同token预算下，先验条件选择优于内容选择和随机细分；干预监督优于对应错配监督 |
| H3 有约束局部对应 | 整体相似掩盖局部证据差异与错位 | 同信息、同参数/训练预算下，成对匹配优于聚合；几何/层级兼容确实改善而非只调类别偏置 |

Layer1D不是第四个必须兑现的核心贡献；作为独立研究变量，检验它是否在上述机制之外带来净增益。跨骨干兼容也是后续外部验证，不作为第一阶段的前提。

## 3. 模块分工：三个问题，不是多个注意力串联

| 部分 | 输入/职责 | 输出/作用边界 |
|---|---|---|
| 共享ResNet-50 | 原尺度双极化chip、有效像素 | 多层特征；主分类通路保留整张有效chip |
| M1 | 本图类别响应 | 更新本图类别相关特征，不负责检索参考或决定原型数量 |
| M2 | OBB相对的框内、侧向、轴端 | 本图区域池化/回写，不预测哪艘参考更可迁移 |
| CCREL升级 | 多层区域证据、源类别原型、极化条件 | 类内候选原型、候选类别区域先验、效应预测，不提前替M3做全部精细对应 |
| M3升级 | 查询/原型局部token、先验、几何/覆盖 | 粒度分配、逐对匹配、类别证据与特征回写 |
| Layer1D候选 | 早期特征 | 互补门控的两路表示；只可称候选判别分支与剩余分支 |

M1/M2/CCREL不是三个同义“增强器”。M1改变类别响应，M2组织本图空间信息，CCREL构造跨样本参考与取证条件，M3才执行对应与证据传递。

现有CCREL是类别响应区域读出，不是已经存在的多港口聚类库。现有M3已经有跨槽位、细↔粗、完整transport及正反船轴假设；新贡献不能写成首次摆脱固定同槽比较。

## 4. 输入和尺度约定

- 输入仍为完整有效chip及OBB，不改成只看框内。保留原生像素、裁剪/补齐记录和valid mask，不用拉伸大船/小船来消除真实尺度差异。
- VV/VH保留独立特征和可用性。跨极化局部交互先核对裁剪坐标；不同裁片尺寸/偏移时使用各自OBB相对区域，不默认同一数组位置指同一地理位置。
- OBB长轴是无向轴，不命名船首/船尾。几何处理仍保留整套正反轴假设；不将两端先逐点平均而丢掉排列。
- ell表示特征层：ell1浅层局部细节、ell2中层结构、ell3深层语义；g表示区域粒度coarse/medium/fine。原型编号k不是空间尺度。
- R50候选分别取layer1、含M1的layer2和M3回写前layer3。每层保留自己的stride和有效覆盖；投影对齐通道，不把上采样当成新增细节。

三层表示属于总体架构；第一可检验版用现有两层局部读出，第三层先保持原有主干作用。是否让第三层参与原型路由，属于单独扩展，而不是缺失就不能开工。

### 推荐接口（形状约定，不是新增代码）

在当前160像素输入下：`F1[B,2,256,40,40]`、`F2[B,2,512,20,20]`，扩展候选`F3_pre[B,2,1024,10,10]`；2为极化，不是合并后的图像通道。

- 局部描述：`Z_ell[B,2,N_ell,D]`，同时携带`region_id/position/extent/mass/valid`；D为共同投影维度，N由父子候选组织定义。
- 学生类别空间先验：首版`A[B,2,C,20,20]`，只在有效覆盖归一化；参考自身也生成同类先验。粗粒度的干预标签不被当成该网格的逐点真值。
- 学生干预效应：`E_hat[B,2,C,3,J]`，3为框内/侧向/轴端，J对应实际已测的操作与强度组合；训练仅对存在可靠标签的类别/操作项计算损失。
- 选择器：首版沿用8个父区域，`pi[B,2,8]`；它读取每个父区域的局部内容、所有类别先验及预测效应，输出共同分区，而非C套完整分区。
- 匹配器：保留查询、参考、极化、区域、方向假设和层标记；输出完整逐对T及回写量，不以只有类别摘要的接口替代局部token。

这里部署输入中的效应是学生`E_hat`，不是教师实测E，也不是在线计算的干预可靠性。教师可靠性只作为训练监督mask/权重。

## 5. CCREL-A：原型库究竟是什么

### 5.1 每个原型保存的信息

每项P[c,d,k]保存：类别c、源港口d、代表源船身份、成员规模/来源、不同极化与特征层的区域token、对应区域先验、OBB相对坐标和有效覆盖。身份只用于来源追踪和隔离，不进入分类特征。

重要区分：

- 全局描述用于聚类与粗检索。
- 局部token用于M3对应，不在船体尚未对齐时直接跨船平均。
- 原型离散程度描述簇内分布，不直接称为校准不确定性。

### 5.2 推荐第一版：聚类选代表，表示共同学习

采用源训练模型提取类内描述，在港口分组约束下进行聚类/覆盖选择，取靠近簇中心的真实船作为medoid。首版固定代表身份，随主干和投影更新其特征。

这比“中心向量自由更新+多样性损失”更贴合局部匹配：每个token仍能回到实际船舶位置；不会因为几个未对齐的亮点被平均，而制造并不存在的局部结构。

原型库可用P[c,d,k]保存来源，但不要求每个港口每个类别都有条目，也不要求相同K。设每类总预算B_c，按独立船舶与覆盖分配，不能因一个港口样本多就拥有无上限票数。首版B_c是受控超参数，不把“每港2–4个”当事实依据。

对照必须包括相同B_c的随机代表、跨港类别内聚类与分港构建；否则无法证明港口组织必要，而不仅是多取了几个参考。

### 5.3 更新与部署

初版bank规模有上限，训练时参与当前前向的代表船由当前编码器重新编码，查询与原型投影共同优化；不再把旧编码器缓存视作当前特征。计算不足时可分块编码，但不能改变比较信息或无意截断某条拟训练梯度。

源船身份与簇分配首轮固定，不每步重聚类。投影已能学习时先不另设自由原型参数和类内排斥损失；观察到明确的原型坍缩后再增加针对性约束。

部署时权重与bank均冻结，可预编码源原型。测试港口样本不更新bank，不加入伪标签适配。后续大bank粗检索另做成本设计，不作为首版必要组件。

## 6. CCREL-B：区域先验不是三张图直接相加

用户方案中三种来源表达不同量：类别响应是模型相关性，极化交互是信息条件，干预效应是某个指定操作造成的分差变化。直接归一化相加会丢失效应的正负与操作含义。

推荐一个共享学生、两类输出，再将极化作为条件输入：

1. **取证先验A**：非负、在有效范围归一化；回答某候选类别/原型的哪些区域值得读取。
2. **有符号效应预测e_hat**：预测指定极化、区域、扰动类型与强度的干预分差；它不是注意力概率。
3. **极化条件**：各极化特征、可用性和联合内容描述，进入上述预测。暂不把某个注意权重当作第三份独立监督真值。

教师在源训练数据上固定，计算：

`m(x,y)=z_y(x)-max_{j!=y}z_j(x)`

`e(x,a,y)=m(x,y)-m(I_a(x),y)`。

e>0表示本次干预削弱判别优势；e<0表示本次干预改善优势。a必须包括极化、区域、操作及强度。不同a的效应不能省略操作名称后解释为区域固有因果价值。竞争类既可记录完整向量，也可用重取最强竞争类的分差作为主目标，保持定义一致。

**教师判错样本不全盘丢弃。** 对其类别注意先验应降低信任或不蒸馏；但有效干预救回错误的样本可用于效应预测和原有判别优势保护。原图正确只作为某类监督的可靠性条件，不能作为所有干预监督的总入口。无有效效应监督的样本仍训练正常分类。

已有区域级效应只监督区域级输出，不能插值成精细patch真值。教师的类别空间图可以提供弱空间先验，但不是精确物理标注。

## 7. CCREL-C：无真实标签推理，但保留类别差异

推荐学生形式：`S(F_VV,F_VH,available,P_c,k)`，针对各候选类别/原型输出A和e_hat。源标签用于损失，查询前向不读取真值。

这解决用户草稿里的信息缺口：教师生成类别条件先验，而学生若被强制只输出一个类无关图，就可能再次把不同类别需要的区域混在一起。

部署不是先相信查询top1类别再看局部。先用共享粗区域证据评估全部候选类别，再对候选原型做精细匹配。分类器最终用所有类别证据决定答案。

为控制token预算，查询使用一套共同的空间分区；分区决策读取所有候选类别的先验及粗级兼容性向量，而不是每个类别各做一套完整分区。每类先验在该共同分区上保留独立匹配权重。

若后续实验表明类无关学生同样有效，可以简化，但不将这种简化先作为必须遵守的理论要求。

## 8. M3-A：动态粒度由“细分是否有收益”驱动

船体框内、两个轴端与两侧构成几何约束的父子区域树。最多三级不表示每块必须分三级；不跨区域边界任意混合。

`pi_r = eligible_r * sigmoid(h(local detail, A_all_classes, e_hat, prototype compatibility, OBB extent, coverage))`。

eligibility由实际原生格点覆盖决定。高亮、强纹理或高熵只可作为内容特征，不能直接解释为重要性。细分目标不是复制“重要就细分”的经验规则，而是由分类损失学习细分对判别的边际价值。

粗/细质量守恒：`mass(parent)=(1-pi_r)*sum_i a_i`，`mass(child_i)=pi_r*a_i`。不因多层、多粒度重复出现同一区域而给它多票。

首版维持现有软选择以便联合学习，不宣称已经减少实际计算。需要效率结论时另测硬选择及稀疏执行，不能用期望token数代替延迟。

## 9. M3-B：匹配、拒配与可靠性各有作用位置

各层独立投影到公共比较空间，候选对受区域身份、无向船轴几何和实际范围兼容约束。首版跨位置限于同一大区域内；不把船体token随意对应到另一船的海面。是否放松跨大区域对应须单独验证。

`C(i,j,ell,t)=-sim(Q_ell z_i,K_t p_j)+lambda_g*d_axis+lambda_s*d_extent+lambda_a*d_pairprior`。

- d_extent使用OBB归一化范围和实际覆盖，不简单将|ell-t|叫作物理尺度差。
- d_pairprior必须比较两端的关系，不能只是query先验加reference先验。
- 重要性改变区域内相对mass；区域间权重进入最终证据聚合。
- 保留现有Sinkhorn+dustbin；允许无法可靠对应的质量进入dustbin，不把所有局部响应硬匹配到某类原型。
- 完整成对transport直接参与value对齐和回写，不压成行列边际乘积。
- 方向仍逐参考比较正反轴假设再聚合，避免先平均两个相反结构。

第一版可靠性来自匹配质量、有效覆盖与拒配比例的联合条件，不额外堆一个“可迁移性网络”。低灰度不等于低可靠；没有校准验证时不把softmax尖锐程度称为真实置信度。

可用两级聚合：`E_c,d=sum_k pi_c,d,k*E_c,d,k`，`E_c=sum_d rho_c,d*E_c,d`。权重对当前查询归一化，缺失港口/原型mask掉；源港口样本量不直接乘入分数。不强制每港等权，也不输入查询港口名称。其价值需与同预算平坦聚合比较。

保留普通图像分类路径和有界残差回写：没有可靠参考时，回到本图证据，而不是强行从原型库选一个答案。

## 10. 计算顺序：避免循环依赖

首版两层路径：

`query与固定源代表 → layer1/2与M1 → 缓存未选择局部描述 → CCREL先验/源区域摘要 → selector → 后续PCEA/M2与layer3 → M3回写 → layer4与分类`。

现有PCEA保留作为极化条件处理，不再让它与新增先验头各自重复输出同一个区域权重。第一轮不同时重做PCEA。

三层扩展需要显式两段执行：

1. 查询/源代表先到layer2，建立当前前向所需源区域摘要，保存浅层描述。
2. 双方利用上述已就绪摘要运行至layer3的pre-M3状态；参考编码到此停止，不调用依赖M3结果的循环。
3. 使用pre-M3上下文完成先验/路由和selector，再让查询匹配源代表并回写，最后进入layer4。

参考计算不依赖查询预测，不做查询之间的信息传播。源侧参考自己的关联/重复船排除规则保持一致。加入第三层必须移动现有extract()中的提前选择调用，不是简单拼一个晚层张量。

## 11. 训练目标：首版不叠六组复合损失

设计的最小目标：

`L = L_cls + lambda_A*KL(A_teacher || A_student) + lambda_E*Huber(e_hat,e) + lambda_I*L_existing_margin`。

各项分阶段启用并有独立消融；effect loss只在有效源干预记录上计算，attention蒸馏有自己的可靠性mask。原有分差保护与新effect预测监督不同，不把二者都称为同一“因果损失”。

第一版不默认再加MSE+KL+Rank三套同目标先验损失；不默认原型排斥、跨尺度强一致和独立匹配约束。粒度选择、跨原型权重由分类梯度训练。预算优先通过相同候选/激活规模对照固定，需要可调效率时才另加预算项。

训练流程：源模型/源干预教师固定建监督 → 源原型代表初始化 → 先验学生预热 → 主分类路径与读出/匹配共同微调。教师使用源标签，但推理只使用正常图像、OBB、可用性与冻结源库。全量主干是否微调必须在比较组间相同，不回到只冻结主干然后宣判新模块无效。

Layer1D重组约束单独加入。当前证据不支持把剩余分支等同于纯环境或强迫保留分支与港口完全独立；那可能删除真实类内差异。首版核心机制先在已有较可靠的未门控起点上验证，同时保留门控候选接口与后续配对对照。

## 12. 新任务协议：未见港口，而非改名旧结果

本轮用户草稿明确采用LOPO，按新研究目标设计：外层留出港口不参与模型、教师、聚类、归一化统计、原型构建或参数选择，也不使用其无标签数据做适配。调参在剩余源港口的内层验证上进行。

初始化同样受此约束：不能直接加载训练过全部24港的现有完整checkpoint，再仅重建bank便称为LOPO。各折从不包含目标港任务训练暴露的共同预训练起点建立源端模型及教师；现有24港完整模型只用于开发分析或明确标注的有暴露对照。

同时隔离跨港重复船舶身份和重叠采集组，避免同船记忆或相邻切片渗漏。评估可用类别及各港口样本量在训练前声明；目标独有、源端没有标签支持的类别不能混入闭集准确率，另属开放集问题。

既有混合港口/采集的跨场景结果是开发依据，不作为新LOPO结果。此前已反复查看的全部港口也不能宣称从未用于研究开发；冻结方案后做新协议复验，并如实记录研究历史。

公开数据若无可信港口标识，只能作采集组或跨数据集验证，不能人为编造LOPO。第一阶段固定R50，ConvNeXt/Swin作为后续可迁移性验证，不同时改变主干和所有模块。

## 13. 核心对照与收口标准

顺序不是无止境追加模块，而是分别回答三个假设：

1. 同预算随机参考/覆盖原型；单中心、多个代表与港口分组的区别。数据量、源访问范围、每类参考预算匹配。
2. 同bank下，已有内容selector、类别先验selector、再加效应监督；增加错配效应和同预算随机细分作为关键对照。
3. 同bank/先验/token下，简单聚合、当前成对匹配、分层兼容匹配；验证匹配内部机制是否具有额外作用。
4. 收敛候选后再加入Layer1D或第三特征层；不将二者收益混入前三项归因。

报告OA/BA/宏F1、港口分布、paired救回/误伤、原型覆盖距离分层、有效极化和尺寸段，以及真实延迟/显存。独立重复以船舶/采集组/港口组织，不能将同船多次观测或多个支持抽样当独立样本。

每轮回看真实VV/VH及实际源原型，覆盖救回、误伤、持续正确、持续错误。用“原型是否改变、分区是否改变、transport是否改变、类别分差如何改变”建立证据链，而不从热图直接命名物理原因。

收口标准：在预先声明的跨港任务范围内，有可重复且成本合理的净收益，且同预算对照支持至少一个新增机制的贡献。不要求每港每类都胜，但不能仅凭更大bank/更多token取得收益就包装全部新增算子。

## 14. 设计决议

**当前确定：** 保留原尺度与双极化、现有M1/M2基本职责、多原型参考思路、类别条件但无真值输入的先验学生、源端干预监督、父子粒度、完整匹配与拒配、源端bank与新LOPO隔离。

**不作为首版硬性要求：** Layer1D必须有效、自由可学习局部原型、多样性排斥损失、三热图直接融合、三层×三级全组合、单独不确定性网络、同时跨四种骨干。

**下一份实现规格需固定：** 每类原型预算/源端选择规则、两层张量接口与先验输出维度、已有干预记录可监督的粒度、相同预算的比较组。此处尚不编造最佳K、阈值或损失权重。

本次设计相对上一版的实质变化：明确未见港口协议；将CCREL拆成原型存储/先验学生两项职责；将类别无关学生改成无真值输入的候选类别条件学生；将三源热图融合改成先验与有符号效应的分工；明确原型局部表示、训练刷新与三层执行顺序。没有改模型代码。
