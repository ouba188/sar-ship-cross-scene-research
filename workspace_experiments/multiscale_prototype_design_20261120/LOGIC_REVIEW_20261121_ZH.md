# 总体模型逻辑审查与接口收口

日期：2026-11-21。承接原会话最后未完成的问题：“整体现在模型所有设计逻辑上有没有问题”。本轮仅阅读、推导和完善设计；没有修改模型代码、启动训练或更新论文结论。

## 结论

**第二版的研究主线与前向顺序能够成立，没有发现需要推翻整个架构的根本矛盾。但不能说所有设计已经闭合：拒配强度在现有归一化中丢失，是一个具体实现与设计承诺的差距；候选类别效应监督和逐原型先验则有两个接口定义缺口。**

建议保留“源端多原型覆盖 → 查询侧证据选择 → 有约束逐对匹配”的主线，补齐下面三处。能否改善未见港分类仍是实验假设，逻辑通顺不等于已经有效。

本文件补充 `ARCHITECTURE_V2_ZH.md`，保留该文件2026-11-20版本供追溯。下面的接口收口是本轮建议，不表示相应实现已完成。

## 1. 必须落实：有dustbin不等于低可靠参考会少回写

V2 §9要求“没有可靠参考时，回到本图证据”。实际继承的 `paper_draft_20261108/m3_axis_coupling_20261118/axis_operator.py` 第108–128行先用真实匹配行质量归一化对齐value，再归一化参考与类别权重；第138–140行回写没有保留绝对接受质量。`m3_late_axis_evidence_20261118/model.py` 第17–21行的方向比较也归一化接受质量。

设真实匹配矩阵为T，某查询token接受质量为s_i=Σ_j T_ij，归一化对应内容为v_i=Σ_j T_ij V_j/s_i。在描述与相对对应不变时，把所有真实T同时乘ε>0，s_i也乘ε，v_i不变。现有方向及参考的相对权重在同样缩放下也不变，active仅检验是否非零。因此在数值下限以上，整体接受质量减少本身不会使这条回写趋零。

这是归一化的代数性质，不是本轮运行了新的错误样本实验。真实输入还可能改变对应结构、相似度和类别权重；不能据此说dustbin完全不起作用，更不能认定它已经解释历史退化。问题是现有路径不保证V2承诺的绝对回退，而未见港与参考不匹配正是目标任务中的合理情形。

**最小收口：分别保留“匹配了什么”和“接受了多少”。**

- 对应内容仍可按接受质量归一化，保留完整逐对transport和逐参考方向比较。
- 另外保留每token/区域真实接受质量与输入可用质量之比 `r=accepted_mass/input_mass`，分母采用进入当前transport的同一归一化约定；无有效质量时为0。
- 相对参考权重α仍可归一化，用于选择参考；残差采用 `ΔF=Σ α_k r_k ΔF_k`，不能随后再除以 `Σ α_k r_k`。所有r趋零时，整个参考残差必须趋零，包括其可能的偏置项。
- 类别参考证据也保留对应的绝对门，普通本图分类通路独立保留。r只是匹配接受比例，不宣称是校准正确概率，也不保证坏参考必被拒配。

未来实现只需一个有辨别力的检查：固定描述与相对transport，降低绝对接受质量，观察参考残差是否随之减弱；否则修正丢失质量的归一化或回写环节。当前不启动该代码修改或模型实验。

## 2. 必须定义：所有候选类别的效应从哪里监督

V2 §4的输出为 `E_hat[B,2,C,3,J]`，§7–8让选择器读取全部候选类别；但§6仅定义真实类别y的 `e(x,a,y)`。只监督每个样本的真实类别头，并不必然导致分类失败，其他值也可能经分类梯度成为有用隐变量；不过不能把那些值统一解释为当前样本上各候选类别已受监督的干预效应。

**建议统一为教师候选类别分差响应：**

`m_c(x)=z_c(x)-max_{j≠c} z_j(x)`

`e_c(x,a)=m_c(x)-m_c(I_a(x))`，对每个候选类别c计算。

e_c>0表示该操作削弱教师对候选c的相对支持，e_c<0表示增强；c不必是真实类别。真实标签用于正常分类损失及另行定义的可靠性判断，不输入学生前向，也不将非真实类别效应全部置零。

本地 `pcea_intervention_transfer_20261118/matched_run.py` 第45–75行已经保留完整 `clean/intervention_scores/control_scores`，`run.py` 第82–119行确认它们来自同一冻结教师与同一参考库。因此，对这些已测操作补全候选类别目标是重新读取完整logits的代数计算，不需为每个类别再跑教师。

**旧缓存仅可用于旧协议开发诊断。** 新LOPO折仍须以该折合法源教师重新生成，不能因目标计算方法可复用而复用见过目标港的教师缓存。干预有效性mask与注意蒸馏可靠性mask分开；教师判错不作为所有效应监督的统一排除入口。

还需固定两个已有接口细节：

- 旧代码记录的 `raw_margin_gain=m(intervened)-m(original)` 与V2的e符号相反。新效应头应从完整logits按上述定义构造，不能直接接入旧正增益截断/最佳操作字段。旧margin保护目标继续保留自己的正增益含义。
- 旧 `objective.py` 的区域顺序为 `body, ends, side`；V2文字采用框内、侧向、轴端。后续接口按具名区域映射，并统一为实际代码顺序，不能仅按三列位置连接。J须记录操作与强度；fine/middle表示当前频带削弱操作，不是直接测得的patch细分收益。

该效应监督告诉模型“教师对指定扰动如何响应”，本身不证明真实物理因果效应，也不等同于细分的边际收益。分类目标仍负责检验这些条件能否帮助取证。

## 3. 必须统一：类级先验与逐原型先验不能混称

V2 §4的A与E只有类别轴，§7却写成 `S(F,available,P_c,k)`，针对每个候选类别/原型输出。两种形式都可行，但监督对象、计算量、源原型预编码与共同分区的聚合方式不同。

**首版建议确定为类级A/E，多原型条件放在实际对应阶段：**

- 查询学生由正常VV/VH、可用性及候选类别条件，输出 `A[B,2,C,20,20]` 和 `E_hat[B,2,C,3,J]`；不增加k轴，不提前硬选查询top1类别。
- 每个真实源代表由同一个学生产生其自身空间图，并保留自身局部token。已知源参考类别可用于取其对应类图；查询仍同时保留全部候选类别。
- 查询使用一套共同分区，读取本图内容与全部类级先验/效应。逐参考兼容性在M3局部对应、参考权重和绝对可靠性处发挥作用。
- 首版不增加逐原型条件化的粒度头。未来若要增加，必须给出k轴、共同分区聚合及适合该条件的目标；不能复制同一张类级教师图后称为原型特有监督。

这保留多原型的实质作用：查询仍与不同真实代表逐对比较，不会退回一个平均中心。也没有要求把所有港口同类外观对齐。

## 4. 复核实际数据后，哪些假设仍未成立

本轮复读 `port_class_prototypes_20261120/FINDINGS_ZH.md` 并回看原尺度的 `chemical_actual_references_local.png` 与 `container_matched_local.png`，VV/VH分开。当前油化参考较紧凑，而已查看的较大查询存在更长的亮响应及外围延伸；相同申报长宽的跨港船舶也呈现不同响应。这支持保留外观多样性、不同极化和真实局部token，不足以将差异命名为上层建筑或特定物理散射机制。

本轮还发现晚于V2提交的已有诊断 `port_region_swap_20261120/FINDINGS_ZH.md`，已归档提交 `4e3f37eac2cde1a38840d37216ebc21fee9cbe32`：

- 冻结现有24港模型，100艘源侧查询（78油化、22集装箱），原库判对79；只替换一艘油化参考，两艘相同申报长度的新参考分别得到80、77。尺寸覆盖改善没有形成一致准确率收益。

- 该诊断既不是LOPO，也没有检验所有区域、全新先验或联合训练后的模型。它约束首版优先级，不是否定所有自适应粒度研究。
