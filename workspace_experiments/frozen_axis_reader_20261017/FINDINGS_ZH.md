# 冻结旧轴向读出器，只训练补充通道：完成结果

2026-10-17。预先固定方案见 [PROTOCOL_ZH.md](/E:/临时会话/frozen_axis_reader_20261017/PROTOCOL_ZH.md)。

## 结论先说

**冻结方案实现了“保护已有效轴向证据”的设计目的，并得到小幅、重复的概率风险改善；目前OA/BA接近保留版，但没有新增准确率净提升。**

可以保留为后续补充通道的候选接法，不把它写成已经涨点的主模块。当前以OA/BA为主要目标时，仍保留原margin版；不因这轮接近持平而否定通用局部信息，也不为找正结果继续扫权重。

## 1. 做了什么

从每个源折、每个种子的既有margin检查点出发：

```text
同一冻结的源域R18局部特征
  -> 旧轴向读出器：参数冻结，输出缓存 -> h_axis
  -> 独立通用读出器：只训练这一份参数 -> h_common
  -> K_old + h_axis h_axis^T + 0.5 h_common h_common^T
  -> 支持系数重新求解，ridge=8
  -> 原有双路等权融合，八类闭集预测
```

源任务、目标支持和查询使用同一套冻结旧表示。通用几何布局、极化输入、归一化、核权重和损失沿用上一轮，没有新引入海况/AIS或修改标签。

**旧表示不变，不等于最终预测不变。** 加入通用项后，支持-支持核、查询-支持核和求解系数变化，所以仍可能误伤旧正确样本；这轮实际检查了这一点。

范围为OSS1四个留采集折，199张不同查询，B16、五次相同支持抽样、三个读出器训练种子。同/跨采集分开。不是全OSS1遍历，也不是新增独立确认数据。各折查询有5/7/6/8类，输出仍是八类；表格按折、种子、支持抽样等权平均。

完成12次冻结补充拟合、12次单轴向追加训练；另重放旧margin、上一轮shared_additive，以及记录未训练补充读出状态。全部新增拟合为200步、每步2个原源任务，AdamW lr=.001/wd=.0001/clip=5，固定末步。损失为macro Brier + .05检索辅助 + .05最终分差。

## 3. 学习收益并不为零，但主要在概率风险

| 跨采集指标，越低越好 | margin | 未训练通用 | 训练通用 |
|---|---:|---:|---:|
| 普通Brier | 0.730428 | 0.730416 | **0.730232** |
| macro Brier | 0.737025 | 0.736917 | **0.736827** |
| NLL | 1.641035 | 1.640980 | **1.640498** |

相对margin，三个种子的跨采集macro Brier、普通Brier、NLL都改善；四个折的macro Brier也都改善。相对**未训练补充读出器**，三个种子的这三项概率风险同样都改善，其中macro Brier平均再降约0.000090。因此不能把全部效果归于随机初始化后的额外核，也不能说训练什么都没有学到。

但幅度小，且学习带来的macro Brier增量在四折中两正两负；这是重复使用开发队列上的有限证据，不是独立泛化保证。NLL/Brier改善也不等于已证明概率校准更好，或已经跨过top-1分类边界。

跨采集支持MAP@R从0.226521变为0.226309，略降；因此没有“跨类检索排序明显更好”的证据。同采集macro Brier下降约0.000306，NLL下降约0.000340。不能只看其中有利的一个指标。

源训练检索CE从1.347077降到1.225194，源验证从1.602410降到1.526875。源训练macro Brier从0.775830降到0.775620，而源验证从0.805560小幅升到0.805584。说明关系目标确实在优化，但源验证分类收益尚未同步兑现；不能把这一组小幅变化直接定性为唯一的过拟合根因。

## 4. 原始chip逐例解释

本轮实际读取并查看了11个不同查询/支持样本的22幅原始VV/VH显示chip。原尺寸分别标在图上，不旋转、不按结果重新拉伸；uint8显示亮度不当作物理后向散射值。以下是结果后选取的解释案例，不估计全队列质量比例。持续正确/错误指这一次配对上下文前后，而不是所有抽样都如此。

同类、竞争类支持选择当前实际支持集内对真类-竞争类分差贡献绝对值最大的案例。完整16条支持边也已保存，避免用一张好看的近邻图代替全求解解释。

### 4.1 救回1038：减弱竞争类误导，并补充同类关系

散货船1038，seed0/draw1，原本预测成product_chemical_tanker。实际支持中有6个散货船、4个该油船类别。

![救回及实际支持](/E:/临时会话/frozen_axis_reader_20261017/native_rescued.png)

**图像事实：** 1038与同类568的VV/VH都可见一个突出亮响应及向一侧延展的较弱响应；竞争类551呈多个沿另一方向排列的亮响应。不能仅凭它们断言船体结构或尾迹机理已经识别。

**模型证据：** 对568新增通用核+0.066057，对551新增通用核-0.136784。全支持合计，专家真类相对油船的分差增加0.037257，其中固定新系数下的新增查询核项+0.022086、系数重拟合项+0.015171。最终融合概率分差从-0.002283变为+0.002860，完成救回。

这里可确认的是：局部表示在此支持组合下同时加强了部分同类关系、减弱了误导性竞争关系。不是已经证明某种物理散射机制导致了收益。

### 4.2 误伤953：同类内部外观差异仍会影响局部关系

散货船953，seed1/draw3，支持中散货船与竞争油船各4例；并不缺同类支持。

![误伤及实际支持](/E:/临时会话/frozen_axis_reader_20261017/native_harmed.png)

**图像事实：** 953的57×57 chip呈弯折/分段的延展响应及一端较亮区域；同类1054的117×117 chip中响应更细长、在整张chip中占比更小；油船1080也有亮点与延展条带。类别不同不保证这些局部外观不同，类别相同也不保证位置/占比相同。原chip大小不同不能直接推出船只真实尺寸不同。

**模型证据：** 新通用项让它与同类1054的核关系再降0.065453，此边的直接分差贡献为-0.004706；但对竞争支持1080的直接变化反而有利，说明不能把误伤简单解释为“被这一张油船图吸引”。全支持直接项-0.007058、重拟合项-0.002360，专家分差合计-0.009417。最终正确优势从+0.001164降到-0.000346。

明确的问题是：**冻结保护了旧局部表示，但补充关系和共同求解仍可能把小分差样本推过错误边界。** 图像中可见的同类内部响应差异是合理线索，尚未通过尺度/区域替换干预证明是唯一物理或数据原因。

### 4.3 持续正确786：上一轮被破坏的旧关系被保住

![持续正确及实际支持](/E:/临时会话/frozen_axis_reader_20261017/native_persistent_correct.png)

特意选择上一轮出现退化的杂货船786，seed0/draw1，实际有2个同类支持。786与719都可见局部成组亮响应，但朝向和亮点排列不完全相同；竞争散货船689更细长。

本轮786-719的旧轴向关系保持原值，所有旧轴向输出逐项验证完全不变；通用项在此边新增+0.214698。全支持直接分差+0.023921、重拟合-0.013081，总计+0.010839。最终正确分差从+0.000283增至+0.001013。

这给出了冻结设计解决什么问题的直接证据：无需重学旧轴向关系，就能保留上一轮曾被联合优化削弱的有效证据。它不是“冻结后永远不会误判”的保证。

### 4.4 持续错误632：有可见响应，但该支持组合缺少真类参照

![持续错误及实际支持](/E:/临时会话/frozen_axis_reader_20261017/native_persistent_wrong.png)

632标注为渔船，原21×21的VV/VH都有中心亮响应及有限的纵向延展，不是空chip。该次支持中**没有渔船，只有1个拖轮支持226**；两种类别在小chip上都呈少量亮响应。不能凭这个外观断定标签错误或信息完全不可辨。

原模型预测拖轮，真类相对拖轮分差-0.011253；补充通道后-0.010437，略改善但仍判错。此例原轴向无效，旧预测实际走原完整模型fallback；诊断已按该真实路径重放，没有把未部署的轴向求解当基准。

可确认的边界是：缺同类目标支持、旧轴向不可用的这一上下文，当前通用核变化不足以跨过错误边界。源先验仍知道渔船类别，不能说没有同类支持就绝不可能预测渔船，也不能说补上一个支持就必然救回。

全部21个原轴无效查询、315个跨采集上下文，仍无top-1改变；平均最大概率变化0.001413，普通Brier平均改善0.000131。同采集该组Brier改善0.000123。覆盖和概率收益保留，不能写成稀有类识别已解决。

## 5. 成本与验证

- 两份读出器各11039参数，其中当前训练的通用读出器10973参数可更新；旧一份全部冻结。合计22078参数，不是两个新增骨干。
- 只测已有特征缓存后的局部读出+支持求解，四折每批16支持、37至84查询的中位耗时平均：margin 2.720毫秒，新版5.080毫秒，增加2.359毫秒。20次计时、5次热身，交替运行顺序；不含图像I/O、骨干、先验拟合、检测等，不能作为端到端速度结论。
- 12次补充训练及源端定点评价约73.36秒，12次追加训练对照约61.60秒；主运行163.21秒。既有骨干/旧读出训练和随后原图分析不在其中。
- 5项独立冻结/梯度/参数隔离测试通过；12个真实源任务的新通道初始梯度范数0.00254至0.01729。
- 所有旧参数和全量旧轴向输出在新训练前后误差均为0，旧梯度始终不存在；源任务顺序与上一轮相同。
- 旧margin及共享联合对照240个任务概率重放误差不超过9.72e-17；600个任务指标、29850条预测独立重算最大误差7.11e-15。
- 四类原图案例的旧/新概率与实际输出一致；核项与系数项逐例对上专家分差。无效轴向案例使用真实fallback基准。

## 6. 如何保留

保留这次**冻结旧读出器、独立学习补充核**的实现和机制证据，它比上一轮共享训练更符合保护旧证据的目的，并有小幅的连续风险收益。以OA/BA为主的现有模型暂不换成它；已有margin收益完整保留。

不追加动态门控或权重扫描。若后续再开发，应从已经落到原chip的两个实际问题出发：953这类同类外观/空间占比不同的小分差案例，为什么补充关系会变负；632这类同类支持缺失的案例，现有通道实际上能提供什么有效类别证据。不能把所有样本统一当作“补充得越多越好”。本轮没有继续训练新的解决模块。

全部训练和诊断已结束。原图选取依据、路径、支持边、逐样本预测、模型及训练曲线均保存在本目录。
