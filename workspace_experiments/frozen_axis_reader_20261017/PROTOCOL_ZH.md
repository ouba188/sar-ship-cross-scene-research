# 冻结有效轴向读出器，仅训练补充通道

2026-10-17，以下在本轮训练和目标评价前固定。

## 依据与改动

上一轮原始VV/VH与支持关系追踪发现，786等样本在联合训练后丢失了原有有效轴向关系；冻结替换旧轴向表示几乎消除了总体退化。因此本轮冻结已训练的margin轴向读出器及其所有参数，源训练/支持/查询均使用同一冻结表示。只训练独立的通用局部读出器，不再让其梯度改动旧轴向表示。

核保持`K_old + 1*K_axis_frozen + 0.5*K_common`；两个新局部块分别按合法支持中心化/有界归一化。SS/QS均更新，ridge=8重新求解，最后原有双路仍等权融合。冻结表示不等于冻结最终预测，公共支持系数仍可能变化。

## 对照与预算

- 原四个OSS1留采集折199查询，B16、5次相同支持抽样、3个读出器种子，同/跨采集分别报告。固定源域R18、原先验/C4/类别关系项和所有数据，不扩公共集/预算。
- 主候选`frozen_common`：旧margin读出器被冻结，独立通用读出器从与既有实验相同的种子初始化，训练200步、每步2个原源任务。
- `margin`：既有保留版，加载重放。
- `initial_common`：同一冻结旧读出器加未训练通用读出器，区分接入与学习贡献。
- `axis_continue`：从同一margin检查点出发，单轴向再训练200步。它与主候选具有相同新增优化步数/任务访问，检验只是额外训练是否已足够；不是参数量或完全相同目标人群的等价对照。
- `shared_additive`：上一轮共享参数的1轴向+0.5通用版，使用既有检查点/缓存，不再训练。
- 所有新增训练保持AdamW lr=.001, wd=.0001, clip=5，macro Brier + .05检索辅助 + .05最终分差损失，固定末步，不做目标选参或权重扫描。
- 主候选需已完成的旧200步加新200步；不能与只有200步的旧联合版混称总训练预算相同。旧/新读出器参数独立，报告新增储存和缓存特征后的计算；不声称新增骨干。

## 结论口径

主比较对当前margin，并同时对initial_common/axis_continue报告净增量。OA/BA、概率风险、支持检索、逐折/种子/抽样和21个旧轴无效查询分别记录。不会因为一个局部退化否定全部，但不能只报告有利子组。

完成后必须看原始VV/VH：持续正确、持续错误、救回、误伤，有哪些看哪些；同时查看实际同类与混淆类支持chip，将图像事实连接到核关系、支持重拟合和最终分差。保存选择理由和样本路径；图像看不出的机制明确标为未解，不凭外观认定物理原因。

验证针对冻结失效/接入漂移：旧参数与轴向输出前后完全相同，旧通路无梯度，新通路真实源样本梯度非零；旧概率和共享基线复现；支持任务顺序相同；逐样本独立重算指标。原始负结果与旧产物不覆盖。
