# 目标邻域、外围及显示依赖验证

2026-10-13。在运行新预测前固定此方案。用户问题: 两路更侧重什么, 第二路的额外纠错主要依赖目标区域还是背景与显示特征?

## 固定范围

- 既有 OSS2 八类侧线队列3745行, 原两套源模型fold2/3及五组B64支持与查询掩码。不是主线3440行目标缓存, 不混写样本分母。
- 冻结R50/R18编码器、源PCA/尺度/分类头及ridge8; 不训练新编码器、不调参、不替换主模型。
- R50采用原VV/VH输入与归一化; R18采用原VH灰度转RGB。二者输入、预训练、结构、数值路径和读出角色不同, 不单独归因于预训练。
- 只评估共享R50先验的单路R和双路T expert; 不混入C4 late/full-model融合。

## 干预及边界

采用公开XML船头/尾、中心坐标与原裁片的对应关系构造轴对齐邻域。头尾包围框每边加max(3 native pixels, .20*headtail length), 裁至图像内。加宽敏感性为.35*length。它不是船体分割, 包含近邻海面、可能的旁瓣和尾迹, 外围也不保证全是背景。

独立XML核查发现3744个方形裁片满足中心偏移映射; 唯一45x34场景边缘截断裁片pub2_opensarship2_003922不能直接使用该映射, 本轮保留原特征并排除其区域分析。另有头端点越界与1x1退化裁片, 按预先有效性规则排除。源文件没有修改。

原图之外固定九个条件:

1. target_flat / outer_flat: 将邻域内/外像素替换成该极化原图边缘中位灰度。两区域使用相同填充值, 保持尺寸、位置不变。
2. sham_flat: 把同大小矩形移到最远且不与目标邻域重叠的图像角落, 同法填平。找不到非重叠矩形则不处理且标记无效, 只在共同有效队列比较此对照。
3. target_shuffle / outer_shuffle: 在区域内同步重排VV/VH像素对, 保留该区域的联合灰度值集合, 打乱空间排列。固定每样本随机种子20261013+索引。不是纯纹理干预, 会改变频谱和邻接关系。
4. target_display / outer_display: 使用原图双极化128输入共同q01/q99确定同一个显示映射, 只在邻域内/外应用。两者合并等于全图显示映射。并非辐射定标。
5. wide_target_flat / wide_outer_flat: 加宽邻域重复内容削弱, 检查区域边界选择是否翻转结论。

记录区域比例、实际变化像素比例及RMS; 不能因两区域编辑像素量不同, 直接把掉点大小当作单位信息重要性。删去目标仍保留掩码形状和定位, 因此不能把剩余准确率称作纯背景分类能力。若头尾映射越界或无效, 保留原图、记录并从区域定位主分析排除; 支持集中的此类行保留原特征并单独计数。

## 两种互补读法

固定原图支持及T系数: A=R50先验+R50核贡献, B=R18核贡献。分别替换查询A、B、A+B, 保留原R作为共同参照。A包含先验而B只有核, 路径敏感性不等于编码器固有敏感性。

匹配支持/查询处理: R和T各自重新求支持系数, 比较同处理的T-R, 总纠错/误伤以及原T救回样本去向。只改查询与同时处理支持/查询分别报告, 源模型仍不重拟合, 不称为训练分布协调或最优特征可读性。

预先报告 full、GRDH、SLC、XML clean、整船未进支持、sham共同有效队列和逐类结果。十个上下文是两源折乘五支持抽样, 不是十个独立神经训练种子。均值与范围仅描述这些固定上下文, 不伪造总体置信区间。

## 验证与结论门槛

- 32个均匀索引原图特征复现检测编码器/预处理接错; 未通过则停止新提取。
- 抽样R50最大相对L2差异.0078, 在既有BF16复现容差内。为排除数值流程带来的分类变化, 在读新预测前追加完整原图重提取负对照replay_original, 使用相同批次和同一读出。此为技术对照, 不是根据标签结果增选干预。
- 四个既有R/T预测精确复现检测读出、索引或系数错误; 未通过则停止新解释。
- 合成像素测试检测改错区域、非目标区域变化、VV/VH被独立重排及显示映射不可组合。
- 检查实际区域预览、有效性和面积对照; 若定位不能支持目标邻域解释则降级为裁片空间敏感性, 不冒称目标背景分离。
- 若固定B路径干预能移除原纠错且在位置假对照中明显较少、对邻域边界不脆弱, 支持第二路纠错依赖该区域。匹配支持后的结果决定这主要是输入不匹配还是该剩余线索仍具有任务价值。
- 不预设第二路必然更看船体/纹理, 不以总体正增益替代具体线索证据; 反例和负结果全部保留。

## 方法来源

Xiao et al., Noise or Signal: The Role of Image Backgrounds in Object Recognition, arXiv:2006.09994 / ICLR2021; 作者仓库MadryLab/backgrounds_challenge。借鉴其把目标与背景分别改变的诊断问题, 不使用其自然图像分割数据、不称为论文原实验复现。本轮SAR粗定位、原值重排、固定读出路径和匹配支持对照是本地操作性定义, 不是完整成像因素解耦。
