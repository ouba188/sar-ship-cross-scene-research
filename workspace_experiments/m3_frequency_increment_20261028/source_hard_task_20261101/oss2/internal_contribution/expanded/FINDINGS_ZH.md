# M3 类别证据回写：冻结扩围结果

2026-11-01，已完成。没有新增训练、调参、挑选检查点、修改正式模型或同步 Git。

## 结论

类别判别证据回写 E 有真实、可重复的救回作用，但上一轮相对普通参考特征回写 R 的优势没有在全部新增数据延续。可以保留为有边界的研究候选，当前不能将其升级为普遍更优的默认模块。

重要的新定位：问题不在于模块完全没有参与计算，而在于它会把部分真实类别推向混淆类。原图与同权重路径消融能定位这种影响，但尚未证明它对应哪一种物理成像机制。

## 1. 本轮实际做了什么

- 冻结上一轮 E、R、none 的 seed17/29/43，全部使用固定第4轮 `last.pt`，不在扩围结果上选择检查点。
- 原源训练719条、固定32个源参考、四类映射和 R 的源端初始化增益保持不变。
- 原 development228 完整重放；新增 selection194 与 evaluation378，共572条、562艘船、10个过境。三种种子不是三份独立目标数据。
- 所有目标队列与当前源训练均无记录ID及MMSI重叠。selection 中69条来自源端也出现过的 S1A_010568 过境，其余125条与源端过境分离；evaluation378全部与源端过境分离。因此新增严格跨过境集合为503条。
- 同过境交集在本轮第一次推理前发现，按元数据补充严格子集报告，没有依据预测效果删样本。
- 这些是历史研发数据，当前 E/R 没用新增队列更新参数，但不能称整个研究的独立盲测。
- 重新提取冻结前端缓存，原 development 的15组模型/开关预测重放最大分数误差 7.63e-6；指标复现。缓存版与完整旧网络的比较检查也通过。

## 2. 分类结果

表中为三种子平均百分数；差值单位为百分点。完整均值/标准差见 `mean_std.csv`。

| 队列 | n | none OA/BA | R OA/BA | E OA/BA | E-R OA/BA |
|---|---:|---:|---:|---:|---:|
| 原 development | 228 | 58.63 / 50.02 | 58.77 / 50.12 | 61.26 / 53.51 | +2.49 / +3.39 |
| 新增 selection 全部 | 194 | 59.28 / 54.19 | 59.62 / 54.47 | 61.68 / 56.33 | +2.06 / +1.86 |
| selection 严格跨过境 | 125 | 65.60 / 61.66 | 66.13 / 62.12 | 66.67 / 62.71 | +0.53 / +0.59 |
| 新增 evaluation | 378 | 63.05 / 60.73 | 63.32 / 60.80 | 62.35 / 60.18 | -0.97 / -0.62 |
| 新增合并 | 572 | 61.77 / 58.27 | 62.06 / 58.41 | 62.12 / 58.54 | +0.06 / +0.14 |
| 新增严格跨过境合并 | 503 | 63.68 / 61.13 | 64.02 / 61.25 | 63.42 / 60.72 | -0.60 / -0.52 |

不能用572条合并后的微小正值掩盖378条退化，也不能因378条退化抹掉125条和原228条的实际收益。

严格125条的 E-R OA 三种子为 +0.8/+0.8/0，BA +0.787/+1.171/-0.192；378条的 OA 为 -1.058/0/-1.852，BA -0.090/-0.433/-1.343。不是所有差异都能笼统解释为一次偶然抽样。

概率质量与top-1区分报告：严格503条 E 的平均 NLL 为1.13968，R为1.18613；378条上E三个种子NLL均优于R，但OA/BA没有同步改善。这支持部分概率预测改善，不替代分类正确率结论。

## 3. 收益是否确实来自回写

各模型使用自己的同一套已训练权重，仅关闭 M3 写入，分类头不变：

| 队列 | E 开-关 OA/BA | R 开-关 OA/BA |
|---|---:|---:|
| 原228 | +1.75 / +2.16 | -0.15 / -0.66 |
| 严格125 | +1.07 / +1.05 | +0.53 / +0.46 |
| 378 | -0.44 / +0.01 | +0.62 / +0.51 |
| 严格503 | -0.07 / -0.05 | +0.60 / +0.40 |

因此125条上的收益有实际推理回写贡献；378条上E的OA误伤也发生在回写路径，不能只归因于训练后的分类头不同。

## 4. 数据层面的边界

严格125条类别数为42/10/11/62；378条为132/26/83/137，顺序为散货、普通货、化学品/成品油轮、集装箱。

378条中，E相对R平均正确数变化分别为 +0.33/+0.67/-4.00/-0.67。主要净损失来自化学品/成品油轮，但不能通过删掉该类重新宣称四分类成功。

该类83条，三个种子结果：

| seed | E正确 | R正确 | E关闭回写正确 |
|---|---:|---:|---:|
| 17 | 47 | 48 | 51 |
| 29 | 45 | 49 | 50 |
| 43 | 40 | 47 | 50 |

这不仅是两队列类别占比不同：同一个类别内部也出现实际误伤。另一方面，selection40条该类的E正确数为19/20/22，R均为19，因此不能推断该类天生不适合E。

378条中348条双极化齐全，E OA64.27，R65.04，差值仍为负；不能把总体退化全部归因于极化缺失。过境分层见 `subgroups.csv`，同一过境内也能同时发生救回和误伤。

## 5. 原始chip与路径诊断

已逐一查看12张查询的 VV/VH 原图和各自实际固定源参考。显示为 native160 裁剪/补零输入，不重新缩放船只。画廊展示原始池化余弦最近的两个同类、一个混淆类合法参考，不是声称它们为注意力最高的参考。

重点实例：

| ID / 真类 | 真实预测现象 | 可见图像事实与限定 |
|---|---|---|
| 000133 / 普通货 | E三个种子均正确；R、none、E-off均错误 | VV/VH都呈短小亮响应；展示的同类与混淆类参考也有相似亮斑结构，不能仅凭“亮/细长”确定船型 |
| 005580 / 集装箱 | E三种子均救回，E-off/R均错误 | 船轴上少量集中响应；参考在方向、长度、响应分布上不同，不能把同朝向当作分类依据 |
| 000673 / 散货 | E三种子均救回E-off；R仅seed43正确 | 查询轴向多点结构，同类参考也有细长轴向响应；错类集装箱也有强局部响应，形态相似不是唯一类别证据 |
| 005542 / 集装箱 | E三种子均误伤E-off，R均正确 | 查询及同类参考都存在轴向多个亮点；有看似相近参考也不保证类别证据回写正确 |
| 000295 / 化学品油轮 | E-off三种子均正确，E三种子均错为普通货 | 查询和普通货参考均为紧凑短轴响应；展示的两个近同类参考分别缺VV或VH，不能凭此认定缺极化就是原因 |
| 002803 / 化学品油轮 | 仅seed29被E直接救回，17/43仍错 | 查询与散货混淆参考都为一端亮、沿轴延展；同类参考也有相似结构。该例说明不是化学品类完全不能受益，但收益不稳定 |

另查看004710救回、005241误伤、000560/000145持续正确、000556/000132持续错误。004710来自源端共享过境，只作全部队列案例，不作为严格跨过境证据。000145框外有明显亮响应，但所有方案仍正确；不能据此把框外亮响应一概称为干扰。

为区别VV/VH写入作用，在上述12例上补做同权重仅VV写入、仅VH写入诊断。原图和基础双极化路径始终保留。`case_pathways.csv` 保存全部3种子36条结果；`pathways.html` 给出图表。

- 000133/seed17：E-off真类优势 -0.294，只开VV变 +0.085，只开VH -0.126，两者开启 +0.253。可直接定位该次救回主要由VV写入实现。
- 000673/seed17：E-off -0.420，只开VV -0.013、只开VH -0.147，联合 +0.260。两个单独不足以翻转，联合才跨过分类边界。
- 000295：seed17/29只开VV就会推错；seed43主要是VH写入推错。不能统一删除VV或VH解决。
- 005542/seed17：E-off +0.392，只开VV -0.099，只开VH仍+0.392，定位VV回写误伤；seed43则VH影响更大。
- 002803/seed29：E-off -0.559，只开VH +0.962，联合 +1.008；seed43的VH回写反而进一步推向散货。

当前两极化后续分支与线性分类头使两路对固定类别分差的改变可加；实际核对最大分数加性误差低于1e-5。普通“真类减最大错误类”分差因竞争类可能切换，不保证直接可加。上述诊断不用于按测试标签选极化或路由。

已证实的是模块路径及分类变化，不是“某种物理散射导致误判”。同一图像在不同初始化下写入作用不同，提示学习到的判别变换仍有不稳定性；究竟来自类别参照覆盖、距离编码或回写学习，尚未被本轮分别证明。

## 6. 保留什么，下一步做什么

1. 保留E的权重、原228与严格125的局部净收益，以及直接救回案例；同时完整保留378和503的退化。
2. 不恢复精细软匹配优越性论点，不把类别专属度量/竞争偏置重新包装成已经验证的核心。此前内部替换对照不支持它们的额外收益。
3. 不根据本轮结果只留下获益类别或给测试样本选择VV/VH。现有结果支持“类别证据回写可有效，但作用边界尚未充分可预测”，不是泛化提升已经全面成立。
4. 下一项最小外部验证可用OSS1已有921条四类队列：保持当前OSS2基座、32源参考和E/R权重，只重提取目标缓存。当前只读确认了入口，尚未运行。自建历史队列也可用，但须先排除源训练/开发同船记录，并使用当前冻结前端重提取，不能套用旧模型缓存。

本轮选择先完成扩围与可辨别的路径诊断，不继续追加调参。正式模型保持原样。
