# M3精细软匹配与简单参考聚合：冻结替换对照

日期：2026-10-31。结论：**在本轮历史开发队列中，精细软匹配没有显示出优于简单区域参考聚合的OA/BA收益。12457的救回不依赖精细局部对应。** 不重训、不改正式模型、不按结果调整参数。

## 1. 实验范围

- 历史候选 `N_level_pattern`，M3训练种子17/29/43；共同的基础模型为 `selected_s17.pt`。不是三个独立训练的完整骨干。
- 每个种子使用同一160张开发查询、固定16个源参考，每类2个；查询涉及158个MMSI、3个港口、3个过境组。480次预测不等于480个独立样本。
- 八类输出，查询实际覆盖七类：散货25、普通货船12、化学品/成品油轮70、集装箱22、原油轮16、拖船7、海工8，缺渔船；BA沿用原脚本，平均七个实际出现类别的召回率。
- 仅关闭历史M3的显式频域分支。其他历史模块不变，不能把结果写成当前正式版本的完整消融。
- 所有方案共享图像、参考、合法性掩膜、区域、投影层、回写层、gain及下游分类器；只替换聚合计算。参考不使用查询标签。
- 源参考排除同船及同过境等条件沿用历史程序；缺失极化与无有效区域不参与对应极化聚合。

## 2. 六个对照

记参考槽位值为v_kj，匹配矩阵为T_kij，行质量r_ki=sum_j T_kij，查询提供质量为q_i，参考权重为beta_ki。原始写回前消息为：

`h_i = sum_k beta_ki * (r_ki/q_i) * sum_j (T_kij/r_ki) * v_kj`。

| 方案 | 修改 | 回答的问题 |
|---|---|---|
| soft | 原精细软匹配 | 基准 |
| pool_keep_beta_mass | T替换为r_ki乘参考区域内面积比例，保留原beta | 固定注入质量和参考权重后，精细局部对应是否必要 |
| uniform_refs | 原T不变，有效参考beta均匀 | 原参考加权是否必要；有效总质量仍可能随权重改变 |
| pool_uniform_mass | 区域面积平均、参考均匀，保留原行质量 | 同时去掉局部对应与参考加权 |
| simple_region_mean | 独立区域面积均值、有效参考均匀、有效区域完整注入 | 不依赖原T和beta的简单聚合是否能替代；还改变了部分输运衰减 |
| m3_off | 完全不回写 | 整个历史M3的净作用 |

前三个替换组仍保留部分原匹配量，不能称其完全移除了匹配信息。`simple_region_mean`独立使用合法掩膜和区域面积，但仍使用原来学到的值投影/回写层，不是一个重新训练的均值模型。

## 3. 主要结果

均值±种子间样本标准差，单位%。这些标准差不包含参考重抽样或新场景变化。

| 方案 | OA | BA |
|---|---:|---:|
| 精细软匹配 | 42.083±0.361 | 33.748±0.118 |
| 区域平均、原beta和质量 | 42.083±0.361 | 33.748±0.118 |
| 原局部匹配、均匀参考 | 42.292±0.361 | 33.816±0.118 |
| 区域平均、均匀参考、原质量 | 42.292±0.361 | 33.816±0.118 |
| 简单区域均值聚合 | 42.083±0.361 | 33.748±0.118 |
| 关闭M3回写 | 45.625±0.000 | 33.395±0.000 |

- 精细匹配与保质量区域平均的**480次配对预测完全一致**。与独立简单区域均值聚合也完全一致，不只是总准确率相同。
- 均匀参考只改变了seed43的24470一例，且从错变对。不能据一例宣称均匀参考稳定优于学习权重。
- 连续分数并非相同。soft / 保质量平均 / 简单均值的NLL均值分别为2.637776 / 2.638280 / 2.641657，Brier分别为0.874306 / 0.874470 / 0.875224。soft有很小的连续评分优势，尚未转为分类收益；这些概率是固定softmax，并非另行校准。
- 相比关闭M3，原soft每种子救回4例，分别误伤10/9/10例；OA下降3.542个百分点，BA增加0.353个百分点。不能仅展示12457就说整个队列净受益。
- 数据组成解释了OA/BA方向分歧：化学品/成品油轮占70/160，平均召回60.00%降到49.05%；普通货船25.00%升到33.33%、集装箱22.73%升到31.82%，散货68.00%降到64.00%。不是所有类别同向变化。

## 4. 为什么复杂匹配和简单平均差别这么小

不是匹配矩阵完全没动。按有效连接/槽位统计再按查询、区域取均值，局部条件匹配分布与面积分布的总变差距离约VV=0.1146、VH=0.1322；参考权重与均匀参考的距离约VV=0.2057、VH=0.1909。

但**被送入回写的各槽位值很相似**。同一区域值向量相对区域均值的面积加权RMS离散度，除以区域均值范数，平均VV=3.46%、VH=5.69%。这里度量的是深层特征经过project后的值，不是原始像素差异。

实际结果：

| 替换相对原soft的回写差异 `||delta_new-delta_soft|| / ||delta_soft||` | VV均值 | VH均值 |
|---|---:|---:|
| 保质量区域平均 | 0.200% | 0.487% |
| 简单区域均值聚合 | 2.361% | 1.401% |

因此本轮支持的解释是：**比较权重变了，但被比较后送入网络的内容差异太小，复杂对应没有充分改变后续分类证据。** 数学上若同一区域的v_kj相等，那么固定r和beta后，任意归一化局部匹配与区域平均完全等价。

深层感受野、值投影、区域读出中哪一步造成了相似，尚未在本轮单独定位。不能直接归因为“频域无用”“局部像素没有信息”或“池化必然错误”。

## 5. 原始chip回看与案例

图库包含VV/VH、查询以及实际16参考库中的同类/混淆类参考。参考展示规则为对应类别在固定参考列表中的第一项，并非事后选最漂亮或权重最大的参考。图像保持实际输入的160像素画布、已有预处理和显示标度，不额外拉伸。绿色框内、蓝色侧向、橙色轴端。数值是正确类别相对最强错误类别的logit分差，不是概率。

### 12457，Jebel Ali，散货，seed17：救回仍在

- 关闭M3：-0.835981；soft：+0.137556；保质量区域平均：+0.139632；简单均值：+0.144237。
- 原图查询呈近竖向连续强亮船体，同类34478呈近横向，混淆类24527也有连续强亮细长响应；这些外观事实不足以唯一对应船型。
- 所有聚合版本都救回。能确认学到的参考值变换与回写路径有作用，**不能把此例归为精细位置匹配的独有收益**。本轮未拆分投影学习与区域回写各自贡献。

### 24470，Jebel Ali，化学品/成品油轮：误伤及参考权重边界

- 查询与同类参考24527都有紧凑细长亮响应；混淆类6913的VV周围更亮，VH外观又不同。仅凭外观不能归因于哪一类散射物理机制。
- 关闭M3分差+1.024972；seed43的soft为-0.010144，均匀参考为+0.012428，简单均值为-0.011562。
- 这说明参考权重可影响临界判断，但这一例的M3整体回写本来就在削弱正确优势。它不是M3整体救回的证据。

### 10502，Singapore，普通货船，seed17：持续判对

- 查询为斜向细长强响应；同类6913与查询的VV周围亮度明显不同；混淆类24527也有细长亮结构，肉眼不能据此确认逐槽对应优劣。
- 关闭M3分差约+0.174，soft约+1.348，简单均值约+1.354。即使top-1不变，参考回写增强了判断，但精细匹配不是必要条件。

### 104，Jebel Ali，原油轮，seed17：持续判错

- VV中目标周围有明显横向/纵向延伸的亮响应，VH中相应延伸较弱；同类29922和混淆类34478都呈较大连续亮船体。不能把亮延伸直接命名为船尾或某种因果散射成分。
- 关闭M3约-3.817，soft约-4.339，简单均值约-4.405。匹配与均值都没有纠正错误，且进一步降低正确类优势。

## 6. 可保留的结论与下一步

1. 保留“参考特征经过学习变换再回写，能改变判别证据，部分样本可获益”的路径证据，并同时保留误伤。
2. 撤回/暂不使用“12457证明精细软匹配优于简单聚合”的解释；本轮没有这个证据。
3. 正式模型不因这次历史诊断自动替换。若决定比较算法本身优劣，下一步才是在相同初始化、数据、训练步数下分别训练soft与简单区域均值，且在未用于本轮设计的评价队列比较。这轮没有做该训练比较。
4. 如继续改精细匹配，先定位值通道哪里失去局部差异，再决定是否需要浅层/多层值输入。不是先加更复杂的匹配器。
