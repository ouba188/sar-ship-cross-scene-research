# 全因素探索第一轮：实际结果与下一步依据

日期：2026-10-17。状态：本轮已完成，不是计划稿；无后台训练或下载。旧模型、划分、支持集、历史结果均保留。

## 先说结论

**不是只研究了海况。本轮把运动、尺寸/吃水、观测几何、极化、处理方式和环境接到真实图像上，并做了完整分类的小对照。**

目前较清楚的发现是：不同条件影响的图像量不同，VV/VH 的关系也不同；不能把它们统一解释成“需要去除的漂移”。尺寸与几何对部分响应有解释力；运动方向投影尚未优于简单速度；吃水没有稳定的独立增益。环境对 VV 对比度、速度对 VH 对比度出现可保留的跨采集预测信号，但这不是分类准确率提升。

**将固定局部读出直接加进分类支持核，没有取得净分类收益。** 负结果已追到具体留出折、查询、支持组合和分数变化。它不否定原有局部/环带候选，也不证明这些条件无用，而是说明本轮这种“直接变成额外相似度”的接入方式尚未有效。

## 2. 表里的各类因素怎么探索

| 因素 | 实际采取的做法 | 当前解释边界 |
|---|---|---|
| 航速/运动方向 | 恢复SOG、COG和时间差；根据带时标轨道计算地理LOS、飞行方向及速度投影；同船差分、留采集预测 | SOG是对地速度，不是对水速度；低速COG不代表船首；投影不是实测多普勒 |
| 尺寸/结构 | AIS长宽、SAR人工长度分别保留；控制类别后测试尺寸、尺寸与图像轴的交互 | 不能把尺寸当成应当去除的干扰；未把响应命名为具体结构散射 |
| 吃水/干舷 | OSS1恢复1133条编码有效吃水；加入吃水和入射角交互 | 更新时间未知；干舷没有可靠字段，不由吃水反推 |
| 静止/停船 | 低速分层；24港短轨迹的速度范围、记录数、空档 | 34/64窗口所有已观测记录低速，不等于持续停泊了该时长 |
| 雷达观测几何 | 图像检测船轴、入射角、升降轨、地理LOS/飞行方向分列；未用AIS艏向替换船轴 | 地理有向投影没有升级成完整chip地理配准 |
| 极化 | 同一个OSS1观测的VV/VH分别测量和建模 | 不混成一个平均通道，也不把差异自动解释为某种机制 |
| 系统/分辨率 | 核对平台、频率、采样、多视和产品类型；OSS2 GRDH/SLC分开记录 | 当前公开队列均S1A、约5.405GHz，不能凭它估计跨波段效应；采样间距不是有效分辨率 |
| 环境 | 复用已匹配ERA5风/浪及CMEMS表层流；与运动、几何分别和联合比较 | 粗网格/日均数据不是船旁瞬时海况，不计算“真实对水速度” |
| 图像处理 | 同观测比较幅度、定标sigma0、uint8显示图；额外半尺寸降采样再恢复 | 轻度平滑不是模拟一台新雷达，也不是实测多视变化 |
| 大气/电离层 | 本轮没有可靠可分离的观测量 | 不拿模型残差冒充传播因素 |

元数据详情：[公开集字段报告](E:/临时会话/all_factor_probe_20261017/metadata/FINDINGS_ZH.md)、[24港轨迹报告](E:/临时会话/all_factor_probe_20261017/ports_motion/FINDINGS_ZH.md)。

其中有一个真实数据问题被定位：OSS2一个产品282行的Ship.xml SAR时间晚于产品成像结束时间，已保留原记录并禁用这些行的运动投影，未猜测修正时刻。OSS1没有该问题；这不是本轮OSS1分类退化的解释。24港少数轨迹存在位置往返跳变，原始负结果保留，未当成真实加速度。

## 3. 从图像上测什么

使用原生坐标和当前检测船轴，分别测：

1. 框内最高5%像素占框内总响应的比例，描述响应是否集中。
2. 距离向、方位向、船轴方向、横船方向的加权展宽及90%响应跨度。
3. 框内与可见邻域的对比度。
4. 船轴两端与两侧邻域的响应差异。

不把第2项直接叫“散焦量”，不把第4项直接叫“尾迹”。这些量还会受船体方向、尺寸、分辨率、检测范围和邻近目标影响。

分类读出另构造船轴坐标下的18个无向配对单元，保留位置、VV/VH响应、可见覆盖和缺失掩码。两个相反位置配对，避免把180度轴歧义误当成船首船尾。**这只是固定诊断读出，不是新训练的Transformer或几何注意力。** 本轮没有宣称新的船轴—雷达联合模块已完成。

48个样本按每类低速/高速各3个不同MMSI选择，不使用分类结果选图。完整8页见 `figures/class_*_native.png`。定标图固定同一[-35,5]dB显示区间。

实际查看可见：高速船也可能仍有紧凑响应；低速船也可能出现外延亮响应；同一样本VV/VH的邻域亮度与局部结构可不同。例如散货船row602为13.4节且AIS相差3秒，仍不能仅凭其局部响应断言明显散焦。它们说明简单单因子视觉规则不够，不能单靠几张图断定物理成因。

## 4. 是否能跨采集预测这些变化

使用固定岭回归，正则系数10，不在目标采集上选参。逐采集留出，同时从训练侧排除该采集所有MMSI。类别作为**诊断控制变量**，不是未来分类模型的推理输入。

基本条件为类别、AIS长宽、图像船轴、入射角及尺度—方向交互，再分别加入速度、运动投影/交互、环境、吃水/交互。源折中位数填补加缺失标记；各方案在相同样本上比较。框内量1282样本；涉及邻域时固定可见覆盖不小于0.5，共1052样本。

下表是相对基本条件的**图像响应预测MSE降低率**，正数表示更好，不是OA/BA百分点：

| 新增条件 | 预测对象 | 按采集等权的MSE降低 | 产品bootstrap区间 | 改善采集数 |
|---|---|---:|---:|---:|
| 环境 | VV框内—邻域对比度 | +18.48% | [+0.92%, +40.13%] | 11/22 |
| 环境 | VV两端—两侧关系 | +6.88% | [+0.79%, +13.71%] | 见完整CSV |
| 速度 | VH框内—邻域对比度 | +2.96% | [+0.26%, +6.25%] | 12/22 |
| 运动投影及交互 | VH框内—邻域对比度 | +1.78% | [-0.92%, +4.69%] | 见完整CSV |
| 运动投影及交互 | VV方位/距离展宽比 | -0.62% | [-3.86%, +2.51%] | 见完整CSV |
| 吃水及交互 | VV两端—两侧关系 | +1.25% | [-1.42%, +3.78%] | 见完整CSV |
| 吃水及交互 | VH两端—两侧关系 | -0.92% | [-2.22%, +0.30%] | 见完整CSV |

另补了类别参照、加入尺寸、再加入几何的解释性对照。加入尺寸后，VH对比度预测误差降低7.61%，VV降低3.10%；再加入几何，分别降低12.55%、6.84%。这些是诊断量的可预测性，不能替代跨场景船型识别结果。

尤其要注意：几何对横竖展宽比的预测改善很大，但图像船轴和横竖展宽本来就共享图像的几何关系。**这属于几何一致性，不是发现了新的因果因素，也不是证明发生了散焦。**

![跨采集图像响应预测](E:/临时会话/all_factor_probe_20261017/figures/factor_prediction.png)

这些是探索性结果：1000次产品bootstrap作用于固定留出预测误差，没有重训模型，也未做多重假设校正。按采集等权与按类别等权结论不完全相同。环境项在VV对比度上按类别等权的MSE反而增加7.73%；速度项在VH对比度上按类别等权降低10.02%。因此可保留“明确评价范围内的预测价值”，不能写成所有类别都改善。

### 同船与时间差核对

OSS1同船差分中，风速变化与VV对比度变化的Spearman约-0.408，实际可用122船；速度变化与该量约-0.069，与VH对比度约-0.145。限制两端AIS均在60秒内后只剩25组邻域完整配对，速度与VV对比度约0.003。当前不能把缺少运动规律简单解释成“只是时间差太大”。

24港回接的精确运动配对中，按每极化每船一个组合，VV94船、VH86船。限定可见覆盖>=0.5、两端时间差<=60秒后各31船，速度变化与显示图对比度变化的相关分别为VV -0.480、VH +0.309。它们不与OSS1形成统一符号规律；24港是已拉伸PNG且极化窗口可不同，不能与OSS1定标对比度当同一物理量。保留这个边界，不拼成统一“去漂移定律”。

## 5. 接入完整分类模型后怎样

基线是原公开集完整C4、类别关系及双路全量等权融合。**本轮诊断项加在该基线上，不是在上一轮训练的joint local reader上叠加。** 没有恢复5%交接，也没有更改支持/查询。

新读出只使用SAR图像和图像检测框，外部AIS/环境不进入分类推理。源训练侧拟合标准化，支持侧中心化后构造PSD增量，同时更新SS、QS并重新求解支持系数。源验证任务在0、0.75、4中选强度，查询标签只用于评估。

| 跨采集，4折与5支持抽样等权 | OA | BA | 相对基线OA | 相对基线BA |
|---|---:|---:|---:|---:|
| 原完整基线 | 45.0028 | 43.7593 | 0 | 0 |
| 显示图空间读出 | 44.5974 | 43.4868 | -0.4054 | -0.2724 |
| 相同内容无固定位置读出 | 44.5974 | 43.2411 | -0.4054 | -0.5182 |
| 定标值空间读出 | 44.5974 | 43.4556 | -0.4054 | -0.3037 |
| 轻度平滑后空间读出 | 44.5974 | 43.4868 | -0.4054 | -0.2724 |

保留空间比无序内容的BA高0.2457个百分点，但仍低于基线。定标值没有取得平均优势；轻度平滑未改变空间方案的top-1结果。这不能证明局部空间/定标信息没价值，也不能用它们作为“信息恢复已涨点”的证据。

完整指标另保存OA、BA、NLL、Brier、类别宏平均Brier、支持集MAP@R及核替换风险收益。MAP@R的候选仅为实际16个支持，同类支持缺失的查询另报分母，不冒充大图库跨域检索。五次抽样是支持随机性，不是五个独立目标数据集或五个训练种子。

### 退化原因定位到了哪一步

1. **主要不是全面退化。** 显示图空间方案仅在 `S1A_011246_011040` 折启用非零强度；另外三折源端选0。该折平均BA变化-1.0897个百分点，折等权后是-0.2724。
2. **源端强度证据极弱。** 该折8个源验证任务中，alpha=0的宏Brier为0.7434151989，alpha=4为0.7434140202，只差约0.00000118。现有最小风险规则仍选择了4。这说明这个选择缺少实质优势，尚不能说它可稳定迁移。
3. **关系本身也未改善。** 该折支持MAP@R从0.176764降到0.170308；不能把问题全部归于最终argmax或融合权重。
4. **已落实到三个查询。** row995在draw1、row953和982在draw3由对变错，SOG分别0、0.1、0.1节。其余三个支持抽样无top-1变化。它们不是“高速船都需要补偿”所能解释的失败。
5. **分数变化可复算。** 对row982，真实类别相对其错误对手的专家间隔变化约-0.3013，其中查询—支持核变化贡献-0.5066，支持系数重求解补回+0.2053。记录了全部16支持的带符号贡献，不是用最近邻猜原因。

这证明退化在当前局部关系及支持适配中实际发生；**还没有证明其物理根因是背景、尾迹或某一散射机制**。不再加一层更复杂的门控来掩盖这个区别，也没有根据目标结果重新挑倍率。

定标方案有局部救回，例如row724在draw4、SOG15节、AIS差1秒。但其他样本有损失，不能把这一个案例包装成已验证的运动条件收益。

![实际退化查询与支持](E:/临时会话/all_factor_probe_20261017/figures/case_uint8_spatial_982.png)

图中的支持按绝对间隔贡献选出，是事后机制案例，不是代表性抽样。同类支持也可能有负的联合求解贡献；图中正负贡献不是相似度大小，更不是物理因果影响。

## 6. 保留什么，下一步依据是什么

**保留：** 真实图像与条件的对应表、分极化响应定义、尺寸/几何解释性对照、VV环境及VH速度的限定预测信号、24港短轨迹、精确支持分数分解。它们回答“变化在哪里、哪些关系值得继续用”，不是凑模块。

**暂不纳入主模型：** 本轮固定108维局部核、直接速度投影补偿、吃水补偿。原有有效组件不因这次负结果而删除。

下一轮更有针对性的方向是：

- 先验证“哪些局部证据在当前观测中更可辨认”，而不是把所有变化压成统一噪声，或直接把局部亮度关系当船型相似度。
- 几何用于组织位置与尺度；外部运动/环境只在源端提供有依据的条件监督。推理仍只依赖SAR及既定允许的产品信息，不能偷偷输入AIS或天气。
- 以船型支持检索/核风险为直接目标，同时检查图像响应预测；不能只因辅助MSE降低就宣布分类模块成功。
- 运动关系可优先在OSS2合法GRDH部分复核：当前GRDH有928个SOG>3节样本，比OSS1的205个多；先排除本轮确认的异常时间投影，并核对相同成像/数值处理。不是为了追求每个数据集全胜，而是增加确实有运动变化的材料。

这轮没有启动上述下一轮新模块。已有证据足以支持有边界的继续研究，不足以把“所有条件已被因果分离”或“完整系统已经涨点”写进论文。

## 7. 复现、验证与成本

- 主线5项测试通过：无向轴反转、边界缺失不当零、已知线响应、已知检索排序、标准化不读取目标数据。
- 元数据9项、24港运动5项定向测试通过，详见各子目录收据。
- 40个历史基线OA/BA完整复现，最大差约7.1e-15；alpha=0概率端点通过；所有改变案例的间隔分解通过。
- 新空间/无序读出内容多重集合一致；最终OSS1字段与已分析字段逐值一致；留采集预测记录源端MMSI重叠数均为0。
- 四折缓存分类准备和求解约2.17秒，单次增量求解中位约0.267毫秒。这不包含图像读取、检测、骨干提取，也不是端到端开销。
- 图像响应回归固定正则，无SGD新训练；没有新下载环境数据。24港只读54个相关AIS文件，约32.15MiB。

主要脚本：`measure_images.py`、`probe_classifier.py`、`analyze_factors.py`、`analyze_24port_pairs.py`、`plot_diagnostics.py`。使用当前ClearSAR环境运行。主指标见 `image_response_summary.csv`、`classifier/metrics.csv`；所有原始预测和负结果均保存。
