# 逐类更新效用模块：源端可行性协议

2026-10-12。先固定设计，再运行新结果。

## 问题与主张

数量规则不能区分源先验是否值得保留；少数类约束与多数类竞争都可能造成误伤。候选主张：在同一标注预算内，用按船留出的完整融合风险估计逐类更新效用，比统一缩放或各类只优化自身更能保留纠正、减少误伤。

证据链：已定位的有害更新 -> 支持集分组交叉拟合 -> 逐类联合风险约束 -> 留出船的更新收益与误伤 -> 完整OA/BA及Brier。支持集风险变好不自动等于查询受益。

## 固定算法

冻结骨干、特征、源先验和基础分支。专家原分数为p+r，改为p+gamma*r，gamma每类一个、范围[0,2]、初值1。同一gamma用于该任务所有查询，不是逐样本门控。

支持集采用三次四折StratifiedGroupKFold，同一已知船只不得跨折；源端一船一例，目标端仍按真实MMSI分组，未知身份逐样本单列。内折重新求基础/专家ridge残差，强度为内折训练样本数/8。验证预测不使用该折标签训练读出。拟合gamma仅使用支持OOF预测与支持标签，不新增目标标签。

联合损失：完整等概率融合的类均衡Brier + tau*mean((gamma-1)^2)。联合梯度包含对所有真实类别的影响。整体缩放对照只有一个gamma；自身对照每类只使用该真类验证行优化对应gamma，其他类别gamma固定1后合并。相同边界、起点、优化器与tau候选。

固定tau候选0.003/0.01/0.03；各方法仅在既有源FIT交叉拟合任务中按平均完整宏Brier选择一个跨预算通用tau，不用目标或源HELD结果选择。L-BFGS-B最多100步，解析梯度，CPU两线程，无新神经训练。源FIT内原基础/专家先验也使用原有按船OOF版本；源HELD用原冻结先验。

## 两层源端实验

- 选择集：三个几何context、三源折、三抽样、三预算，共81单元，复用原source-selection支持/查询与源OOF先验。
- 留出检验：三个几何context、三抽样、三预算，共27单元，复用418个共同查询观测及既有未见船划分。context复用同一批船，不能当三个独立港口。
- 所有候选和超参数预测先冻结，再评价选择集；冻结tau后再评价HELD。报告统一缩放、各类只顾自身、联合竞争三者，而非只对原模型。
- 源查询标签只能用于选择集设置选择和HELD评价，不进入gamma拟合。历史编码器/几何开发暴露保持原协议，非完全独立新数据。
- 先看是否有可利用净收益与逐类设计相对整体缩放的价值，再决定是否进入外部与23港。不要因支持训练风险下降直接全量推广。

本轮目的是开发和验证可解释的轻量候选，不预先宣称已有顶刊级新模块。文献近邻与差异单独记录；不把普通交叉验证命名成创新。

## 源端结果后的固定扩展

源FIT选定global/joint tau=0.03，self tau=0.003；源HELD128例联合版本OA/BA有净收益且BA高于整体缩放，64例结果较弱。以这一范围明确的信号进入既有23港和F_0921/OSS2扩展：全部B16/64/128与五抽样均保留，不只跑128例。设置按FROZEN_CHOICE.json保持不变，不根据目标选择tau、预算或方法。完整预测先冻结后统一评价。沿用各任务当前原模型与最新外部强先验；不重训骨干。来源任务仍是开发数据，不宣称新采集确认。
