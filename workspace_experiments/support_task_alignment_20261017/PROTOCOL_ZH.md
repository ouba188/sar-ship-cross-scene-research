# 支持任务组织与辅助目标：配对修正协议

2026-10-17，训练与本轮目标评价前固定。

## 问题与依据

上轮局部静态读出有小幅OA/BA正信号，动态门控替换不影响top-1；源端任务每个采集/模式只有一组支持，留出学习收益弱。图像与案例已见`local_evidence_reliability_20261017`：相同局部输入不保证在不同支持组合下有同样价值。此次只修正支持组织与损失，暂不新增门控、图像区域、骨干或外部知识。

## 冻结内容

- OSS1原四留采集折、199查询、B16、同/跨采集五次支持抽样。
- 原源限定骨干、C4/类别关系/源先验/支持求解及0.5全量融合。
- 上轮`static_no_quality`同架构：192维局部读出、静态区域偏好，新增10维定标统计在训练/预测均为零。不是去掉现有VV/VH信息。
- 三个相同初始化种子，200步，每步两个原查询任务；原优化器和增量强度1不变。
- 使用第200步，不按源或目标成绩挑检查点/倍率/种子。

## 四组训练

| 臂 | 支持组织 | 损失 |
| --- | --- | --- |
| fixed_aux | 原固定支持 | 宏Brier + 0.05检索CE |
| fixed_task | 原固定支持 | 宏Brier |
| diverse_aux | 五组支持组合的固定源端bank | 宏Brier + 0.05检索CE |
| diverse_task | 同一五组支持bank | 宏Brier |

支持bank第一组为原支持，其余四组独立重抽；允许因候选池小出现重复，按成员集合而非顺序统计真实多样性。查询、支持所属采集、每类支持数量、源先验训练行完全不变。候选支持只来自相应源TRAIN或源VALIDATION角色，并排除查询及原先验中的MMSI；不通过减少先验训练量或改变类别构成制造变化。即使某类不在原支持中，本轮也不自动补入，因此不声称解决支持缺类。

四臂每步访问相同原查询任务。diverse两臂访问相同bank索引，独立随机数发生器不改变查询任务序列。源选择集另建同规则bank用于诊断，四臂共同评价；不进入训练、不用于选择。

## 区分性评价

- 无训练的相同初始化读出为低成本对照；原完整模型为系统基线。fixed_aux终点应精确复现上轮static_no_quality，若不能则先定位实现差异。
- 记录0/50/100/200步完整固定源训练集、固定源选择集、扩展源选择bank的Brier/检索CE/OA/BA与原模型配对变化。不能再拿当步两个任务损失充当完整训练曲线。
- 目标仍只在初始化与固定终点报告：OA/BA、普通与类别宏Brier、NLL、支持MAP@R、逐折/类别/支持组合及训练种子。两因素效果用同种子的配对差，不按目标结果挑其中一臂当已确认赢家。
- 统计实际支持池/有效局部监督、不同支持成员集合数、训练中访问到的组合，区分增加组合与增加原图/独立采集。
- 正信号在声明范围内可保留，不要求全胜。若只有源训练改善而源留出/目标退化，优先报告泛化或目标取舍；不自动追加更复杂注意力。
