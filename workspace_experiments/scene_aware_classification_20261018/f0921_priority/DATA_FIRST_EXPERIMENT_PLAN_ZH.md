# 下一轮：从数据证据出发的实验计划

2026-10-18。状态：已制定，尚未开始本计划中的分类训练。依据本日动态裁片盘点、五景来源恢复和海陆掩膜原图复核；不把已有工程接入误写成新分类收益。

## 要回答的问题

目标是提高冻结检测之后、未见采集/水域上的船型识别。优先验证：目标周围响应混合了不同来源时，把它们显式分开读出，是否比现有不区分来源的补充方式更有效？

现有证据：1008个检测候选中763个全框地图水域、227个岸边/不确定、18个陆内过滤提案；15例VV/VH复核显示岸边设施与目标响应相邻，部分大框覆盖多种结构。这证明输入环境并不单一，但还没有证明这种混合造成分类错误，也没有证明分开读出必然涨点。

## 先限定数据与评价对象

1. 复用42.27万行已有动态库做细类与跨采集训练材料盘点；五景用于可追溯的局部图像/邻船关系验证。不能把五景990个保留候选直接当作990条可靠船型标签。
2. 保留有依据的细类标签，按独立MMSI、实际采集、类别与合法支持覆盖确定本轮类表，再冻结；不把100个字符串机械变成100分类，也不按结果挑类别。
3. 现有裁片有检测尺寸与AIS尺寸两种生成方式。纯检测部署比较中固定同一检测裁片，不把改变输入窗口得到的收益算成模块收益；旧AIS回退输入可另报，不混入同协议主表。
4. 区分目标身份可靠、可用于船型评价的记录，与仅能用作无标签上下文的候选；18个陆内提案和原唯一关联受影响例单独复核。用掩膜过滤不自动赋予真实身份。
5. 源/目标按实际产品采集隔离并排除同船泄漏；SAR自监督遵循同一源端限制。日期×UTM不是唯一采集。无法确认来源的记录不用于声称严格跨采集泛化。

本步骤只解决本轮样本与比较所需缺口，不重做全库审计，也不为追求完美标签无限拖延。

## 再定位现有模型在哪一步出问题

在固定查询、支持和输入上复用或生成基础模型预测，按可在预测时获得的属性分层：离岸/贴岸/地图不确定、孤立/多候选、目标占图比例与检测尺寸、VV/VH对应可靠性。地图水域与检测框区域只是可观测代理，不是纯物理海面/船体分割。

每层记录样本数、独立船数、采集数、类别/支持组成、OA/BA、真类与最强混淆类分差。只有几类或几艘船导致的总体差异不能直接归因于近岸或邻船；优先做同类、相近目标大小、相同支持抽样的配对/分层比较，并明确仍未控制的差异。

复用现有15例，再补充实际基础模型持续判对/判错与后续救回/误伤的查询及支持图。先回答：目标是否清楚、附近强响应来自什么可见结构、该结构是否确实进入所用特征/案例关系、输出分差如何变化。外观事实与物理解释分开写。

## 由现象决定改什么

| 观察到的证据 | 对应改动 | 不应混为一谈 |
| --- | --- | --- |
| 框指向陆上结构或身份关联错误 | 候选筛选与关联修正 | 不是分类表征创新 |
| 贴岸/多候选时补充读出被非目标强响应支配，且对应错误案例关系 | 分开目标框、邻船候选、地图水域及其余/不确定邻域的读出 | 分区只是归属代理，不宣称精确分离散射机制 |
| 相同类查询有用的邻域证据确实不同 | 再比较关系条件化权重与固定权重 | 不能仅因有四个区域就默认动态注意力有价值 |
| 目标本身证据薄弱，区域组织没有改变有效案例关系 | 优先检查尺度/极化/局部表示或支持覆盖 | 不继续堆上下文网络 |

优先候选是“区域归属分开的补充读出”，不是直接开发大图图网络。保持原有效读出器和基础模型冻结，只训练补充通道；通过已有支持适配入口加入候选关系，并评价完整融合后的输出。固定原分支参数并不保证最终决策不变，仍需检查支持求解与融合后的救回/误伤。

区域均来自同一原图、冻结检测和地图：先分配目标关联框，再分配其他候选框；剩余像元分为地图水域和其余/不确定区，并保留地图有效性标记。陆地及不确定区不是自动删除，邻船候选也不是确认真实船舶。无地图/无邻居时保留原模型路径。模型使用地图时属于SAR加地理辅助设定，不能继续称纯SAR预测。

## 紧凑对照

| 版本 | 目的 |
| --- | --- |
| A：当前冻结有效模型 | 固定同批输入上的基线，不用历史异协议分数替代 |
| B：同层、同范围、同容量的普通局部补充 | 判断收益是否只是增加特征或训练量；采用相同数量读出槽与投影维度的固定空间分区 |
| C：上述区域归属读出，固定融合方式 | 在原图、参数预算和训练步数匹配下，检验区域组织是否值得 |
| D：C再加查询—支持条件化融合 | 只有C及案例证据显示有条件差异时再加，不要求首轮必跑 |

地图标量先验作为单独的小对照：同一模型只增加水陆比例/距岸代理，而不改变局部读出。它用于区分地理先验信息与图像空间组织的作用。必要时只对确有作用的区域关系做替换或屏蔽，不默认全局置乱，也不把黑色涂抹造成的分布变化当纯因果干预。

先固定一个小范围、具有源端训练量且目标类别可评价的任务；精确样本数与支持预算依据数据覆盖表确定后保存，不在缺少覆盖证据时空填。学习组件采用3个训练种子；各方法使用完全相同的支持抽样、查询与模型选择口径。支持预算是实验变量，不默认必须64；第一轮先固定一个可行预算，后续才扩展。

## 怎样形成可解释的结果

- 信息层：目标是否更接近跨采集同类、不同船的支持案例；邻船/岸边结构对关系的贡献是否按预期变化。检索候选集合固定。
- 决策层：固定概率转换下NLL/Brier、类别分差、救回数与误伤数；屏蔽有用区域时的变化与合理替换对照一致，才支持相应机制解释。
- 系统层：完整模型OA/BA、逐类/逐采集收益、支持抽样和训练种子的波动，以及额外时间/内存。只在共同且身份可靠的查询上比较分类；掩膜保留率单列，不能通过剔除困难查询虚增分类准确率。
- 范围层：同采集有收益并不否定跨采集价值，分别报告；某类或某些场景的可重复、值得成本的净收益可以保留，不要求处处获胜。未涨点时先检查实现、目标、支持组织及信息利用链，而不是盲目更换模块或预设必有bug。

单个chip的响应图说明模型看哪里；配对替换说明这些证据是否影响决策；跨采集重复和任务收益说明是否值得使用。三者合起来支持机制解释，但仍不自动构成纯因果因素识别。
