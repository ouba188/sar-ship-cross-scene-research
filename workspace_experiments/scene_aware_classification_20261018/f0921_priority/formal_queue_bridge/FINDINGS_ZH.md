# F_0921：可追溯裁片上的池化前目标读出接入试验

日期：2026-10-18。状态：本轮计算、针对性测试和原图回看完成。没有继续搜索倍率或增加训练。

## 结论先行

**保留“池化前目标局部读出”作为有范围的小候选。** 在32个支持、两个留出日期、59张固定查询、五次支持抽样下，相对“全局特征+普通2×2网格”的双路支持适配基线，日期等权OA提升0.7564个百分点、BA提升1.1190个百分点。来自两个样本事件被救回、没有误伤；五次抽样两次改善、三次持平。

16支持总体近乎持平，64支持略退化；相对更简单的全局双路基线，32支持OA略升而BA略降。因此本轮不能宣布区域读出全面优于普通表示，也不能将32支持宣布为最优预算。

这次已走通“源先验 → 支持残差求解 → 双路概率融合”的最终分类路径，不再只是一个单路检索探针。但这是新七细类队列上的集成小验证，**没有复现历史八分类C4、类别参照等全部组件，不能替代旧完整模型主表。**

这属于**留日期、少量目标标注适配**，不是无目标标签的域泛化。目标支持与查询可以同采集，不能将本轮检索指标称为“严格跨采集检索”。

源TIFF实际为按日拼接图，采用first-nonzero合成，五个来源清单均有重叠像素。像素重放证实的是当前裁片与源版本的对应，不等于每个像素已归属到单一原始采集，也不证明AIS标签独立正确。按整日隔离避免同日拼接组成跨越有监督源/目标边界。89条记录尚无完整产品ID，保留unknown，不冒充已恢复。这一范围限制不用于解释所有历史识别失败。

## 二、改了哪一步

```text
成对VV/VH裁片 + 冻结检测器候选框
  ├─ 冻结R50：末层全局特征 + layer1局部特征
  │    └─ 2×2空间单元内，比较混合池化与先区分目标再池化
  │         └─ 构造支持-支持、查询-支持两个核
  └─ 冻结外部SAR自监督R18：原有全局表示保持不变
源端分别拟合七类先验
  → 使用同组目标标注求两路残差系数
  → 两路softmax概率各50%融合
  → 最终七类预测
```

R50输入128，R18输入112；R18使用已有24港外部SAR预训练，不是本轮F_0921源折专属SSL。其训练/选择记录与本队列MMSI、可比产品起始键、已知采集ID均无重叠；未恢复的完整ID不宣称全部验证。没有骨干重训。

原普通网格先把一个空间格中的所有响应平均。新目标槽位先在该格内仅聚合目标候选框覆盖的响应，再参与案例关系。普通网格和全局分支仍保留。这里的“目标”是冻结检测器与裁片锚点定义的候选，不是人工船体分割。没有候选的9张入选裁片没有被悄悄删除。

对照固定为：全局；全局+2×2网格；普通3×4网格；池化后复制为目标/其他/剩余槽位；池化前三种归属分别读出；仅替换目标槽位；降低原网格权重但不加新信息。后三类读出具有相同槽位数量。先验、R18、融合系数和求解强度均固定，支持系数随新核重新求解。

## 四、为什么救回，为什么又会误伤

已分别查看VV/VH、候选覆盖、实际同类与混淆支持，以及源拼接图原尺度窗口。报告区分图像事实与计算归因，不凭亮线命名尾迹、散焦或某种散射机制。

**救回1：row80，clean192146，MMSI538009246，原油船，2025-03-15/B32/draw0。** 查询呈近竖向长条亮主体。与其作用最大的异类支持85（集装箱船）呈斜向主体及交叉亮延伸。固定其他槽位、只替换目标槽位，相比postpool，该支持相似度0.145800→0.088699，其对真实类相对集装箱类分差的总贡献为+0.055528；全部同类支持贡献合计反而为-0.027037。**因此这例主要是削弱错误支持关系，不是同类整体更近。** 最近异类LPG支持也呈类似长条，外观不能独立证明船型。

**救回2：row236，clean195277，MMSI636021702，LPG，2025-04-01/B32/draw1。** 查询VV呈紧凑斜横向亮主体及交叉延伸，VH的外部延伸弱得多。同类支持223较集中横向，混淆散货支持214呈竖向主体及明显交叉结构。相对postpool，同类223相似度-0.254705→-0.147956、贡献+0.054378；散货214相似度0.412485→0.327928、贡献+0.051679。这例同时有同类增强与异类削弱。原尺度窗口为88×88，模型存储输入已缩放到224，不能把224像素当作原生空间分辨率。

两例查询其他候选覆盖均为0，不能据此说邻船传播或去除邻船解释了收益。相对postpool，两例最终正确类分差分别-0.001208→+0.003690、-0.002020→+0.003337，都是边界附近的小幅修正。

数值分解使用固定基线竞争类：新核直接项与支持系数重拟合项精确相加。两例R50分差改变量分别为0.058922-0.009262=0.049660、0.095910-0.039693=0.056217。系数重拟合抵消部分直接关系收益。该分解是计算路径证据，不是物理因果识别，也不等于最终融合概率的线性分解。

**误伤：row260，clean242713，顶推拖船，B16/draw1。** 查询、同类252和异类拖船261均呈小而紧凑的近竖向亮主体；原同类支持247为横向。新关系没有解决顶推拖船/拖船的外观混淆，最终由对变错。当前图像支持“细类证据重叠”这一待验证解释，不能据此修改标签。

**误伤：row161，clean192185，LPG，B64/draw3。** 同类149、异类原油船88与查询均呈斜横向亮主体。AP由0.04500升到0.05556，最终却错判为原油船，说明检索局部改善不保证分类获益。

**持续判对/错：** row134（化学品/成品油船）分差略升仍判对，实际同/异类支持外观都有接近部分；row195（LPG）分差由-0.067536到-0.065852，Brier改善但仍判顶推拖船。没有把连续指标改善记为救回。另看row12持续错例：一个同类支持无目标候选、边缘亮区进入other，属于可定位的缺失条件，尚未证明是该错误的根因。

案例图与逐支持贡献见case_review及postpool_case_support_contributions.csv。选中面板不等于全体比例；生成面板不等于逐张全部目视审核。

## 五、成本、验证与收口

现成特征/源先验缓存下，固定39查询、32支持任务，CPU单线程25次交替计时、丢弃前5次：普通网格适配融合中位1.846毫秒，新目标槽位26.926毫秒。这是读出及两路支持求解的参考实现成本，不包括检测、骨干、磁盘读取，也不能当作整景部署速度。

本轮冻结检测/准备约9.891秒、特征抽取约1.947秒。7项针对性测试通过：ridge原/对偶一致、查询不影响支持拟合、目标不改变源标准化、分差分解恒等式、真实任务身份/预算隔离，以及掩膜优先级/歧义处理。保存的翻转概率重放一致，空间分区重组误差上界1.91e-6。

**现在保留什么：** 目标局部读出能通过改变查询-支持关系在特定少样本任务带来最终分类净收益；该计算作用有具体案例支持。不是只降低置信度的描述。

**尚未闭合什么：** 相对最简单全局双路的双指标优势、独立更大覆盖、严格跨采集支持关系、细类物理判据、检测及邻船完整场景的净收益、旧全部有效组件接入。原图回看没有证明每种局部亮结构的物理含义。

下一步优先固定候选和全局/普通网格两种基线，在有足够源船和目标支持的新增日期覆盖上验证；若要回答严格跨采集关系，就单独限制支持与查询的采集来源，不能混用本轮口径。无需先增加动态权重、几何网络或邻船类别传播。先前正负结果、原模型均保留。
