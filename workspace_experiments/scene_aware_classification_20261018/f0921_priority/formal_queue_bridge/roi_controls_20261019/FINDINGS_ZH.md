# 普通ROI、前景/背景与空间目标读出的同协议比较

2026-10-19。全部计算和原图回看完成；没有新骨干训练、检测或特征提取，没有调整融合倍率。上一轮原始结果保留。

## 结论

**可以保留区域分开读出的收益，但目前不能证明四格目标组织是必要的核心创新。** 较简单的前景/背景两向量方案在B32上优于当前空间目标读出，适合作为下一轮冻结候选；不是据本轮目标结果建立一个部署时预算选择器。

此前重点解释的B32两例row80、row236，普通整框池化也都救回。因此它们证明了这些改动能改变判别结果，却不能单独证明空间格组织不可替代。当前空间格并非无用：在B16，相对同槽位整框重复对照仍有2次救回、0次误伤。但B32、B64没有一致优势，保留局部信号即可，不硬凑成强模块。

## 实际比较了什么

复用父目录同269观测、256船、7细类、同一源日期隔离、同一目标查询与五次支持抽样。B16覆盖四日期80查询，B32两日期59查询，B64一日期39查询。目标支持可以与查询同采集；不是严格异采集检索，也不是独立确认集。

所有补充方案均保持 `K = 0.5全局 + 0.25普通网格 + 0.25补充核`，R18、源先验、支持残差求解、双路各50%概率融合不变。

| 名称 | 实际读出 | 用途 |
|---|---|---|
| global_grid | 全局+普通2×2网格 | 原局部基线 |
| roi_global | 一个整目标均值/极化 | 普通框内信息是否足够 |
| fg_bg_global | 目标、非目标各一个均值/极化 | 简单区域分离 |
| roi_repeat_target | 同一整目标均值重复填四个目标槽，保留其余槽与有效位置 | 匹配槽位/上下文，去掉目标内部空间内容差异 |
| target_only | 四格各自的目标均值，保留其余槽 | 当前候选 |

普通ROI这里是**同一现成特征图上的掩膜池化**，不是重新裁图放大再送骨干，也不是旋转RoIAlign。非目标包括其他候选及其余响应，不是已确认海面。各方案按支持集中心化和有效槽归一化；简单方案维数不同，不冒充等维。重复对照匹配槽数和有效性，仍保留位置相关的缺失状态及中心化，不是绝对无位置信息。

整区域均值由已存四格均值按真实面积加权合并，避免把面积不同的小块等权相加。9个无目标候选样本保留。之前图像可见主体与外围亮纹不同，支持做这个比较，但不预设复杂方案必须赢。

## 最终分类结果

日期等权OA/BA，单位%。预算覆盖不同日期，不能从横向数值直接推断最优预算。

| 仅全局双路 | 41.9091 / 39.7530 | 44.2564 / 38.1786 | 40.0000 / 32.0159 |
| 原全局+网格 | 42.7873 / 40.8740 | 43.7692 / 36.8135 | 43.0769 / 33.3492 |
| 普通整目标 | 41.4091 / 40.0407 | 44.0256 / 37.8333 | 42.5641 / 32.5714 |
| 前景/背景各一次 | 42.2873 / 40.5407 | **45.0256 / 38.3492** | 42.5641 / 32.8492 |
| 整目标重复到原槽位 | 42.2873 / 40.5407 | 44.5256 / 38.0714 | 43.0769 / 33.3492 |
| 当前空间目标 | 42.6655 / 40.8026 | 44.5256 / 37.9325 | 42.5641 / 32.8492 |

B32前景/背景相对原网格：OA +1.2564、BA +1.5357个百分点，4救回/1误伤，五抽样2次正收益/3次持平。配对抽样标准差分别1.7791、1.8701个百分点，不是独立数据集标准差或显著性结论。相对仅全局双路：OA +0.7692、BA +0.1706个百分点，五抽样2胜2负1平；优势很小，不称稳定压倒所有基线。

B32前景/背景相对当前空间目标：OA +0.5000、BA +0.4167个百分点。按查询加权，也由当前43.7288/31.2299%提高到44.0678/31.6863%，没有只选有利汇总方式。

当前空间目标相对普通整目标：B16 +1.2564/+0.7619，B32 +0.5000/+0.0992，B64 OA持平/BA+0.2778个百分点。但这仍混合了局部槽位与上下文等区别。

**更干净的空间内容比较：当前空间目标减去整目标重复对照**：B16 +0.3782/+0.2619（2救回0误伤）；B32 OA持平、BA-0.1389（1救回1误伤）；B64 -0.5128/-0.5000（0救回1误伤）。所以不能把B32既有收益专门归功于目标内部的四格分解。

B32前景/背景MAP@R为0.298183，对比原网格0.291460、当前0.295618；Brier为0.787005，对比原0.787466、当前0.787435；NLL为1.742294，对比原1.743534、当前1.743377。连续改善较小，任务口径仍是可能同采集支持。

## 排除“只是前景减弱”的解释

这是看完主结果后增加的单个诊断，单独保存dose_*，没有改写预先固定的方案。保持前景/背景方案内的**前景核一模一样**，只移除背景核，再重新求支持系数。

B32为row102与row175两次救回、0误伤；B16为3救回/2误伤，B64为2救回/1误伤。三预算Brier五抽样均改善。本结果说明净收益不只是减少前景权重，背景核有条件贡献。增加核也改变正则化几何；尚未区分其具体语义、场景关联和泛化判别信息，更不能把它命名为海况或纯环境因子。

## 原始chip回看与边界

case_review中三种比较共56个事件面板，均含原存储224 VV/VH、实际同类/异类支持和源拼接图原尺度查询。选择采用固定分差中位规则，另保留旧row80/236和指定row188。生成的全体不等于全部人工目视审阅；主代理和子代理实际查看下列关键差异及持续正确/错误例。

- **旧row80、row236（B32）：** 三种新对照均正确。普通ROI的正确类分差分别0.006815和0.005562，当前为0.003690和0.003337。之前看到的长条主体、交叉亮纹仍是图像事实，但不能据此说分格独有地提取了它们。
- **row73，原油船，B16/draw3：** 空间目标分差+0.000338，重复整目标为-0.000373。查询斜向长条，实际同类支持89偏横向、异类114偏斜竖向。比较方法预测的集装箱类在该次支持中缺失，不能解释成某张集装箱支持把它拉过去；源先验仍参与最终结果。这例保留为空间内容有局部效用的案例，不认定朝向是原因。
- **row188，化学品/成品油船，B16/draw3：** 当前+0.001487、重复整目标-0.000655。查询和同类234都是紧凑近横向多亮部，异类LPG205也近横向但延伸不同。原尺度仅48×48，不把224展示尺寸或模糊亮部解释成已识别船体部件。
- **row97与row102，B32/draw4：** 前者化学品/成品油船被空间方案救回，后者LPG被空间方案误伤；两者都把LPG支持150作为相关比较对象。图像都有斜向亮主体，部分VV交叉延伸在VH较弱。相同支持可以在不同查询上有不同作用，不能从“看起来相近”推出统一规则；AP前者略升，后者从0.3333降到0.1667。
- **row175，原油船，B32/draw0：** 空间方案错为散货，前景/背景正确；分差-0.002647→+0.000241。查询与实际同类213都有近横向主体，散货235也为长条但外围纹理更强。原窗口88×88。固定前景剂量移除背景后分差-0.004424，加入背景后转正，给出该背景项实际生效的计算对照；外观仍不能证明是水域或某类散射机制。
- **row142持续正确、row203持续错误（B32）：** 空间与重复整目标的最近同/异类支持未变，分差均小幅改善。row203外观与同类支持234同样近横向且多亮部，仍判为顶推拖船；说明有可见相似性不等于已经得到足够分类证据。
- **row161，LPG，B64/draw3：** 空间方案误伤而重复整目标保持正确，前景/背景也正确。保留这个负例，不以其否决其他预算局部收益。

这些案例所选目标周围没有检测到其他候选，不是邻船类别传播的证据。粉色覆盖是检测候选，不是真实物理分割。源图为日拼接图，来源限制与上一轮相同，不拿它泛化解释所有分类错误。

3项新测试通过：非等面积小图直接池化对照、缺失目标保持零、查询不改变支持中心化。第一版测试图恰好等面积，修正为非等面积后才能检出错误等权合并；这是测试样例修正，不是数据/实验方案调整。四个旧方案全部最终概率重放最大误差9.72e-17；背景剂量诊断也复现完整前景/背景方案。适用的旧身份隔离与求解测试已有，不重复全量审计。

## 收口决策

1. 保留前景/背景简单读出作为下一轮固定候选；保留空间目标B16局部正信号及全部负结果，不悄悄删除。
