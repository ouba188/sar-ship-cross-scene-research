## 结论与需要限制的表述

本次审阅未发现使当前结果失效的阻断性计算错误。方向按检测 OBB 长轴定义，采用轴向而非有向船艏；雷达角来自明确映射，未借 UTM 轴填充未知值。读出在池化前改变空间权重，随后同时进入支持—支持和查询—支持核并重求解，计算链条成立。

但结果只支持保留一个很小的船轴相对读出信号，不支持替换主模型，也没有证明雷达组织优于相同维度、相同缺失策略的图像轴替代。单次条件核同样没有得到可推广的净收益；这不等价于几何信息无效。

需要在解释中保留以下边界：

- 原 `ship_radar` 是两套方向读出核的加和，没有显式船轴—雷达相对角交互，也完全没有把 `incidence_deg` 输入读出。不能将其称为已验证的入射角条件机制。
- 雷达有效仅 132/269 行；缺失行回退为船轴描述符，但仍可因支持端改变而获得不同预测。不能把“查询没有雷达几何”解释为“雷达臂对该查询一定无影响”。
- 原方案的已知—未知配对是在同一 token 槽位上比较雷达/图像坐标与回退船坐标。该混合映射仍给出合法 Gram 核，且 matched-image 对照使用同样策略；它却不是统一物理参考系下的纯雷达比较。此点是解释限制，不是这次要求追加配置的理由。
- 图像中的亮条、周边条纹和两极化差异不能独立证明尾迹、散焦、船艏或具体散射机制。每个 token 仍含冻结 CNN 的通道响应；没有旋转等变性保证。

## 为什么 radar 与 matched image 几乎相同

`readout.py:65` 的四窗口为 `exp(2*r*cos(2*(phi-theta-j*pi/4)))` 后逐像素归一化；`readout.py:74` 将它们与 fg/bg 相乘。四方向始终覆盖同一个完整 fg/bg 范围，改变参考角不会增加新的像素覆盖。窗口之间重叠；每槽均值再被支持集中心化、逐槽归一化和整体归一化，最终等权相加内积。

这里有一个精确对称性：若所有样本参考角共同增加 45°，四方向只会循环置换，fg/bg 各自仍对应相同角色。支持均值、逐槽归一化随之置换，最终核严格不变。任意小角度共同旋转不是严格不变，但有限个宽窗口可能产生高度相关的关系；需用实际结果确认，不能把所有共同旋转都当作等价。

独立合成检查直接调用从当前文件读取的 `angular_windows`、`token_descriptor` 和 `kernel`，使用固定种子 914、7 个样本、2 极化、21×21 非对称高斯加随机背景、6 通道、4 个支持；没有使用本队列图像或标签，也没有拟合模型：

| 检查 | 最大核差 |
|---|---:|
| 全体共同旋转 45°，并独立核对 token 循环置换 | 3.33e-16 |
| 每个样本使用不同的 45° 倍数旋转 | 0.201422 |
| 全体共同旋转 0.19 rad | 0.0302375 |

这排除了“方向分支无论输入什么都恒定”的解释，同时证明有限窗口的公共置换确实会被核消去。合成检查不证明任意角度旋转不变，也不证明实际近似等价完全由该对称性导致。

主任务 `geometry_by_date.csv` 的关键事实：4 月 1 日全部 66 行雷达几何可用，图像平面 range 角只有 -9.265° 至 -8.816°，而船轴—雷达夹角覆盖 0.657° 至 85.802°。因此这一日期内 radar 更接近对所有图像窗口施加同一个小旋转；缺失回退不能解释这个日期的全部近似等价，现有读出又没有直接使用变化很大的相对角。其余日期的支持覆盖与已知—已知配对见 `kernel_diagnostics.csv`，不把 132 个全队列有效行当成每次支持池的有效数。

实际局部核平均绝对差约 0.000161、相关性接近 1；`diagnostic_receipt.json` 给出最终概率平均绝对差 1.68339e-6、最大 3.48689e-5，top-1 全部相同。原公式进一步满足：

`K_R50 = .5*Kglobal + .25*Koldgrid + .125*F + .0625*S + .0625*R`。

所以 radar/image 的差异最终只有 1/16 的 R50 核系数，随后还有支持残差求解及原 R18 的 50/50 概率融合。这是明确的传递幅度限制，但不是建议事后增大权重；概率融合、重求解和 softmax 也不允许把概率差机械视为核差乘固定常数。

## 单次事后条件核的边界

已读取 `run_condition.py`、`condition_receipt.json` 和 `condition_paired.csv`；没有实施或重新运行。负例原图和完整带符号路径由主任务负责，本节不声称独立验证了该轮负结果的物理根因。

实际代码采用相对轴角差的圆周核 `exp(.5*(cos(2*(delta_i-delta_j))-1))`，乘入射角差尺度10°的 Gaussian 核；这等价于对二维 doubled-angle 圆周嵌入做 RBF，不是只用单个 `cos(2*delta)` 标量。已知块、未知块全1、跨块0组成 PSD 的分块核；与 PSD 的船轴外观核逐元素相乘仍为 PSD。记录最小特征值约 -1e-13，符合数值舍入尺度。有效集合同时要求可靠雷达和非零检测船轴，实际129行，未把缺船轴默认0当真角。

这个结构检验“优先使用条件相近的外观证据”，并不学习从一种观测条件补偿到另一种条件。`S` 是支持中心化后可为负的核，`S*G` 会将正、负关系都推向0，因此不能把它一概表述为降低不相似样本的相似度或保护真类；残差系数又可带正负号，最终类别 margin 必须结合主任务的带符号路径解释。

availability 对照保留完全相同的缺失分块，能隔离数值几何是否优于分块本身；`geometry_only` 只在新增的1/16 R50核项中去掉外观，整体仍有 F、S、global、grid、R18。因此它的正结果也不等价于“只靠几何就能分类”，不能独立排除场景/类别组成相关性。

已完成结果：B32 conditioned 相对 availability 为 OA -0.5、BA -0.2778个百分点，0救回/1误伤；相对 fg/bg 为 -0.7564/-0.5278，0救回/2误伤。geometry_only 相对 fg/bg 在 B16/64为正、B32为负，预算覆盖的日期/查询亦不同，不能拼接各预算最佳结果。conditioned 与 relative_angle 的 top-1 相同，所以没有证据把本次分类误伤特指为新增入射角项造成；其概率变化仍保留。

本次尺度与选择均为事后固定，保留原始输出和负结果，无需继续搜索配置。结论是当前固定关系策略尚未显示可保留的完整模型净收益，而非几何被证伪。保留船轴相对小信号、fg/bg既有基线及明确未知范围，不作新的主模型替换。
