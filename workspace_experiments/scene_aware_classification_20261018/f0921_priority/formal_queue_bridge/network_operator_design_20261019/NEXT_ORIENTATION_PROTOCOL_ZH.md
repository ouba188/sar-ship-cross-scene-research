# 下一轮：方向用于读取，而不用于类别捷径

2026-10-19。状态：实验设计，未实现、未训练、无新增精度结果。采用 experiment-design 技能；已复核本地任务协议、覆盖记录和197查询及真实支持VV/VH案例图，并完成一次独立设计审阅。

## 依据与目标

普通卷积相对匹配池化没有得到稳定优势。197误伤案例中，错类63关系增强、同类45关系减弱；图像中存在方向差异，也存在形态、尺度与背景差异。现有证据不能认定方向就是误伤根因。窗口mask统计说明新增卷积可读取区域外内容，但不证明这些内容有害。

本轮检验：在目标/其他候选/剩余邻域分别读取的前提下，以船轴和真实雷达参考组织局部内容，是否比图像参考更好地区分同类跨角和异类近角案例，并改善完整分类。

不追求抹除全部方向信息，不声称冻结旧系统整体旋转不变。图像坐标旋转与真实船雷达相对观测变化分开；旋转增强不是模拟后者。先只实现C卷积候选，保留现有池化和注意力，不同时新增P/A或方向损失。

## 数据与固定协议

- 沿用 learned_geometry_crosspass_20261019 的固定48查询、两个过境、同过境/跨过境支持银行。目标标签不用于改变银行、支持抽样或选择checkpoint。
- B16主实验，B32预算外推；五次原有支持抽样、三个训练种子。两个预算用同一查询，B16为B32前缀。保持船只身份与源/支持/查询隔离。
- 当前合法源70艘，拟合64、验证6；旧版拟合读出有效43、验证有效4。新设计的图像路径不再因缺雷达几何而关闭，实际各路径可用数量需由实现记录，不能直接宣称全64艘均有可靠OBB。
- 复用元数据，仅新增源端类别×采集×轴角覆盖及真实可用跨角/近角关系计数。图像轴角和船轴相对LOS角分别记录。稀疏格标为未覆盖，重复采样不充当新增独立船。
- 目标主表保持自然支持。方向分层仅在冻结预测后对已有QS连接计算，不按目标query标签重选更有利的支持。

## 最小算子与四个训练臂

共同实现：冻结骨干和旧读出，采用同一投影维度、区域软mask、采样点数、船体相对尺度和有界窗口。采样前mask、采样质量归一化；保留区域身份。两个方向参考模板采用相同参数结构，不增加角度向量到最终分类描述符。模板沿轴/横轴允许不同权重，正反轴共享或对称聚合；不能使用完全各向同性聚合后把坐标变化当有效方向设计。

| 组 | 两个采样参考 | 用途 |
|---|---|---|
| A 图像参考 | 图像轴与固定45度轴 | 容量/采样数匹配的无目标几何基线 |
| B 船轴参考 | 无向船轴与图像轴 | 用一个船轴模板替换固定图像模板 |
| C 双参考 | 无向船轴与真实LOS地面投影 | 在B上用真实雷达参考替换图像参考 |
| D 错配雷达参考 | 同B/C的正确船轴与错配LOS | 与C结构完全一致，从训练开始破坏雷达参考对应 |

旧完整模型以及已保存的普通卷积/池化结果作为背景基线；若与本轮覆盖/训练协议不同，不直接用旧数值归因。本轮A才是主要匹配对照。A不是声称最优的所有普通卷积，只检验当前相同模板结构下参考系选择。

所有组区域约束相同，因此本轮不声称证明区域隔离本身的独立收益。A/B/C的覆盖域大小、点数与相对半径相同，但实际采样位置按设计改变；不宣称读取完全相同像素。B-A检验船轴参考替换，C-B检验雷达参考替换，不表述为单纯多了分支或参数。

D对合法LOS施加与类别无关的预设随机方向扰动，按观测固定、训练/验证/目标均使用同规则；船轴、mask、图像、尺寸、有效性不变。它是信息错配对照，不模拟真实新的SAR观测。只做推理时错配不能替代D，后者需独立从头训练。无几何时C/D均回退为B对应的图像参考，缺OBB时各组用相同图像fallback。

初版不把入射角数值输入门控、不用角度相似度乘核、不增加动态模板路由；这样C-B不混入额外条件网络或门控容量。入射角先用于结果分层，待参考系确有价值再单独测试条件化。雷达横向不直接命名为精确方位向，船轴不命名为船首航向。

## 训练与接入

使用同一批自然源episode、同样初始化规则与优化预算；完整支持求解和最终融合NLL为共同目标。先沿用200步及现有优化器配置，主比较固定200步终点，不用仅6艘两类源验证集挑选四组各自最优点；源验证曲线作诊断。训练若出现数值失败先修实现，若普遍未收敛只在源端确定统一延长方案，不能看目标赢家改训练长度。

形成补充嵌入及Gram核，保持旧核和旧双路融合；新增权重沿用固定0.0625，不在目标集扫描。保证源/支持中心化规则一致、SS/QS均重解、旧路径不因无几何被删除。VV/VH分开读取后沿用既定组合，不同时改极化融合。

## 专门检查是否利用朝向捷径

1. 同类与异类、近角与跨角的关系分别报告。无向轴差用pi周期最小角差；图像轴角与相对LOS角各算一套，不能混成一个朝向变量。近角0-15度、中间15-45度、跨角45-90度作为预定描述分层，不据目标结果改边界。
2. 在同一query同一次既定支持中，存在同类跨角和异类近角时，计算同类关系与异类关系之差及其相对A的变化。按query先汇总，报告可用query/独立船/采集数量；缺同类支持的query保留在系统主表，不放进这项关系诊断。
3. 同时报告全体固定候选上的检索与类别分差，避免只在挑中的难关系上成功。分层是机制线索，不等于已隔离尺寸/类别/采集等混淆；能匹配的条件注明，材料不足则明确未分清。
4. OBB角加pi但保持真实几何不变，算子输出应符合正反轴等价，这是实现测试。全chip、mask、OBB和LOS联合90度旋转后重新过骨干，用来比较相对A的预测敏感性；不强制冻结骨干整体精确不变，不把该合成变化当跨观测验证。

仅kernel关系变近不等于分类被救回：继续检查实际支持系数、正负证据和完整分类分差。注意力热图不作为单独机制证明。

## 成功标准与下一步

主结果为相同查询/支持下完整OA、BA、Brier/NLL及救回/误伤数，按训练种子与支持抽样分别报告波动；补充参数/耗时。两过境不能支撑强跨场景总体置信区间，重复抽样不增加独立采集。

- B优于A且跨角同类/近角异类诊断改善：保留船轴读出，尚不宣称消除所有朝向捷径。
- C优于B和D：支持真实雷达对应的额外价值；若C与D相近，仅可保留计算结构或额外方向模板的作用，不能认领正确几何机制。
- 关系改善但总体持平：保留中间正信号并定位支持系数/融合是否阻碍兑现，不立即叠加P/A。
- 只在部分预算或类中有重复净收益：可以按该边界保留，不要求所有格获胜；若只是重复少数船或单次翻转则如实标为局部开发证据。

每轮结束查看救回、误伤、持续正确、持续错误的原生VV/VH与实际同类/混淆支持；区分可见事实、模型证据和未证实物理解释。保持当前开发集属性，之后冻结候选再做额外采集确认，不把反复使用的269条改称独立测试。

若仍有明确方向捷径且源数据关系充足，第二阶段再试方向组织训练：从同一自然episode出发固定query、预算、各类支持数与缺类状态，只在合法类内替换支持，无法替换时保留原episode并记录可行率和重复船数。若要宣称该训练与新算子协同，必须同时在A上做相同训练对照，而不是只给候选更好的训练材料。本轮暂不加入该变量。

本设计复用既有文献阅读与实验；不是新增文献综述，也不是三个算子均已实现的进度声明。
