# 原始轨道几何增量读出：重设计与固定实验结果

2026-10-19完成；旧结果保留。本轮代码、评价及原图分析已完成，无后台训练。

后续用户复核与重新统计：见[假设/任务对齐修订](../observation_alignment_20261019/FINDINGS_AND_NEXT_ZH.md)。现有有效QS连接仅1.51%跨过境；本页结果应限定为当前固定软分区适配实验，不能用于否定聚合前学习型几何内容交互。原数值与实验协议未修改。

## 一句话结论

已改为使用对应原始Sentinel-1产品的逐位置成像时间与轨道状态，区分朝雷达/背雷达的局部区域，并完整保留旧关系通道。但本轮新几何设计没有超过匹配的普通区域增量：三种增量的最终分类全部一致。B16有一个小收益，B32有一个误伤，均不能归因于几何。保留元数据恢复与可解释读出实现，不替换已有效的简单前景/背景主候选。

## 1. 这次真正改了什么

```text
原始产品annotation XML
  -> 目标位置对应的azimuthTime
  -> Earth Fixed轨道位置/速度插值
  -> target-to-sensor三维LOS及入射角
  -> ENU -> 当前UTM栅格 -> chip中的有向雷达方位

冻结检测OBB -> 无向船轴 + 中心 + 长宽
                      |
原始chip -> 冻结R50 layer1局部特征（VV/VH分开）
                      |
 船轴相对轴向/侧向软分区 x 朝雷达/背雷达软分区
                      |
             x target/non-target掩膜
                      |
            每个极化8个局部token
                      |
     仅支持集中心化 -> 新案例关系核
                      |
 完整旧核 + 0.0625新核 -> 支持残差重新求解
                      |
        保留R18适配与原50/50概率融合
```

不再用角度相似性去乘旧关系，不抹弱旧的负相似度，也不隔断旧known/unknown连接。新增描述可以有正负相似性，是否有用由完整支持求解与分类结果评价。保留旧核系数不等于保留旧预测：支持系数会重解。

局部坐标u/v按OBB半长/半宽归一化，使用绝对值避免猜船首船尾；有向雷达投影按半宽归一化并含sin(incidence)水平分量。这只是用可解释坐标组织已有图像证据，不是雷达散射仿真、运动补偿或显式因果分离。

没有旋转图像、扩大crop、训练骨干或重新检测。旧target掩膜仍是OBB包含区域，不是精确船体分割；non-target仍可能含其他目标，不能称纯环境。

## 2. 元数据是否确实更可靠

- 269行全部对齐；旧132个可用几何样本全部恢复为轨道几何，主读出还需可靠船轴，实际129行。
- 复用3份完整XML，新增13份原始annotation XML，共22,683,810字节；未下载整景，未读取凭据。原始XML在研究数据目录，GitHub只归档实现与来源记录。
- 用逐位置grid时间，不用产品起始时刻代替全部目标；轨道和实际采集时间都覆盖目标，禁止外推。
- 轨道水平投影与旧地理网格无向轴差：中位0.0852°、最大0.1773°。入射角中位差+0.0292°。

这说明旧轴近似在当前132行上没有明显方向错误。原始轨道恢复的价值是明确有向观测坐标与可追溯来源，不能把此前未涨点归因于“没用官网方向”。

137行未知是沿用旧覆盖/归属门槛，不是轨道计算失败，也不是断言剩余元数据永远无法补齐。本轮刻意不改变覆盖范围。h=0是椭球高近海平面代理，未使用独立精密轨道；详见METADATA_ZH.md。

同269观测/256船/7细类、同源日期隔离/MMSI排除、同查询支持。B16为4日期80查询，B32为2日期59查询，B64为1日期39查询；各5次既有支持抽样。不是5个训练种子，也不是5份独立测试集。

## 4. 为什么没有得到独立收益

已验证的链条：

1. 几何计算、坐标有向性、区域分区及完整模型接入通过针对性检查，旧基准全概率重放最大误差9.72e-17。没有发现能解释结果的接入错误。
2. 有效查询-支持对上，orbit与image新增核相关系数平均0.99819；与普通pooled为0.99102。并非完全相同，但新组织仍与已有案例关系高度相似。
3. orbit相对image最终类别概率平均绝对变化仅2.96e-6，最大0.0002484；相对pooled平均3.09e-5，最大0.0005433，均无分类翻转。补充信息不足以产生独立的决策改变。
4. 普通区域增量可复现全部救回与误伤，足以说明本轮这些分类翻转不需要雷达方向。不能据此认定几何在其他任务、表示或读出中一定无用。

尚未证实：方向信息没有价值、冻结骨干一定丢失物理证据、只要增加权重就能有效、或训练一个更大网络就能解决。未对这些解释追加无目标的实验。

## 5. 原始chip与实际支持回看

已实际查看73、236、142、228四组查询的原生尺度VV/VH、几何叠加图及同类/混淆支持，并额外查看236最大贡献的235/223支持原图、73的89原图。生成的14组代表图不等于14组均已逐图审阅。完整事件/实际支持/贡献都保存在selected_cases.csv、case_paths.csv、case_support_contributions.csv。

### 73：救回，但普通区域也救回

20250315，B16，draw3，原预测集装箱2，真类原油轮3。最终概率分差-0.0001933 -> +0.0002683。R50固定对手分差+0.0047392，其中新核直接项+0.0058247、系数重解-0.0010855。

主要支持89也是原油轮，相似度0.445291 -> 0.468192，贡献+0.0044355。原图73为112x112的斜向紧凑亮响应，89为80x80、方向更接近水平；混淆类114也有斜向强响应。方向不同没有妨碍同类支持贡献变大，但图像方向与普通池化都同样救回，因此不是“雷达对齐成功”的证明。本次支持没有集装箱类，旧集装箱预测可来自源先验，不虚构集装箱支持。

### 236：误伤来自对案例证据的重新加权

20250401，B32，draw1，真类LPG4 -> 散货0；最终分差+0.0008748 -> -0.0001510。R50固定对手分差-0.0108799，直接项-0.0172952、系数重解部分补回+0.0064153。

- 错类散货支持235：相似度0.448215 -> 0.481232，总贡献约-0.0070956。
- 同类LPG支持223：相似度-0.181912 -> -0.198094，总贡献约-0.0063764。

原图236为88x88，VV可见向外延伸的横纵亮纹，VH更斑块化；235为128x128、周边纹理较强；223为72x72、亮主体较紧凑。三者都有近横向亮主体，235与236的区域读出更相近，而223的关系进一步变负。**可见现象与模型证据相符，但未通过干预证明具体哪段亮纹造成相似性变化**，更不能直接命名为尾迹/旁瓣/海况。普通池化同样误伤，说明新模块仍可能强化已有混淆，而非提供类别特异的新信息。

### 142：持续判对，几何未知也有间接变化

20250315，B16，draw4，化学/油品船1仍判对，分差0.0049902 -> 0.0051413。该查询新通道为零；直接项严格为0，R50变化+0.0019469全部来自支持系数重解。原图64x64，同类104和错类91都存在紧凑长条亮响应，不能用这一提升证明未知查询获得了雷达信息。

### 228：持续判错，方向组织未解决类别混淆

20250401，B32，draw3，真类1仍判推船5，分差-0.0185869 -> -0.0187529。查询56x56、VV/VH均有横向亮主体及外延；同类234与错类原油轮213也出现相似整体形状。虽然同类支持合计贡献+0.0084555，其他类合计-0.0101301，最终仍变差。说明“同类关系有改善”与完整决策受益要分别评价。

原生图沿用父脚本的通用caption“非已验证单采集像素”；本轮是否产品唯一以geometry/orbit表为准：已恢复的是整窗口可能来源产品一致，不是精确源chip像素所有者或AIS关联真值认证。可视化颜色是几何软分区，不是注意力或因果归因。

## 6. 验证、成本与收口

12项测试通过；原layer1网格特征重放差0，软分区重组误差2.861e-6；全部支持直接项+重解项与分差变化闭合。独立支线限定审阅未发现影响结论的接入错误。

固定骨干的新读出提取3.08秒，35个支持任务的完整四臂评价13.12秒；这是本机本次运行耗时，不是部署增量延迟。未单独测量部署时延，未训练新的神经参数。首次抽取中对照掩膜Byte类型不支持CUDA area pooling，改为float32后重跑并通过；它发生在生成评价前，不是统计退化原因。

本轮收口：

- 保留原始产品轨道几何恢复、明确有向坐标和未知处理，这是后续可复用基础。
- 保留B16小正信号和连续风险改善，但归于区域增量候选，不包装为已有效的独立雷达创新。
- 当前主模型仍用简单前景/背景候选；本次几何分区不自动启用。
- 不继续在同队列搜索权重。若后续重启，应先检验真实观测条件不同的查询与支持是否存在可利用的对应证据；本轮支持允许与查询同采集，不能冒充该验证。
