# 学习型几何读出：完成情况与有效边界

2026-10-19。已完成元数据补充、固定任务、四组真实训练、完整双路预测、配对统计及原始chip回看。不是旧固定窗口结果的改名，也不是全F0921/独立确认结果。

## 结论先说

**可以保留“跨过境、16支持时改善部分类别决策”的开发候选，但暂不替换简单前景/背景主模型，也不宣称正确几何已形成稳定的独立优势。** 不要求所有条件都赢；本轮的具体限制是几何相对普通内容读出的增益主要集中在一个训练种子，且更好的同类检索并未同步出现。

从原来几乎没有跨过境同类关系，推进到真正的跨过境支持和可学习内容交互，是本轮确定完成的工作。少数类别的救回有价值，但需要按实际机制解释，不能都讲成找回同类的物理证据。

- 三月058308/073537、四月058556/073F16各固定24艘查询，共48艘不同MMSI。同/跨过境共用查询，B16/B32共用源集和支持银行并嵌套抽样；每组5次支持抽样、3个真实训练种子。

- 训练使用32个预生成源episode，16支持、最多8查询；其中一半同过境、一半跨日期。B32明确属于预算外推，不称训练与评价预算完全匹配。

数据表：capacity.csv、learning_coverage.json、tasks.json、source_episodes.json、relation_coverage.csv。以上改变未把开发数据变成独立确认集。

## 2. 四组模块与完整接入

共同输入为冻结R50 layer1局部特征，8x8小格分别读取框内和框外，共128个token；VV/VH分开、共享权重。位置为图像坐标、OBB归一化轴向/侧向坐标和区域身份。不是用AIS航向，也没有旋转原图。

| 组 | 实际操作 | 区别 |
|---|---|---|
| A | 内容+位置，内容摘要生成条件，聚合前门控混合 | 不输入雷达角度 |
| B | 先按内容/位置聚合，几何再调制区域摘要 | 几何不影响聚合前权重 |
| C | 几何与内容条件共同调制局部token，再学习区域内权重 | 聚合前条件化 |
| D | 同C，但从第一步开始使用源端供体的错配几何元组 | 检验正确对应的作用 |

四组都为10,981个有效可训练参数。B因混合在聚合后执行，真实计算略少，不用空算伪装相同成本。按线性层MAC估算，A/C/D约2.663M、B约2.405M每chip，不含骨干、归一化/非线性、支持求解；不是端到端实测FLOPs。

几何由原轨道恢复LOS与入射角，使用船轴相对角cos/sin和入射角cos/sin。不把无向OBB的正轴称为船首。D完整替换相对几何元组，不移植不同UTM中的原始地图方位；供体只来自43艘合法fit可读出船，不按类别挑选。目标测试记录中错配角差中位61.57度、平均68.08度，确实改变了条件，但这些包含重复接收样本。

旧全局+网格+前景/背景核不变，加0.0625新表示核；新表示按实际支持中心化，重新解SS和QS残差系数，再与冻结R18等权概率融合。R18是已有外部24港SSL模型，不是新训练的F0921源限定骨干。没有5%交接。

未知几何/无有效轴的新通道为0；旧系统仍预测。A同样采用这个门槛，是匹配对照，而非声称普通读出的最佳覆盖。没有新增纯几何类别分支。

三种子各组均训练200步，源验证NLL从0/50/100/200中选步，不接触目标标签选择。12次训练全部完成，共42.88秒；包含episode准备和评价的runner总57.71秒。骨干冻结、特征缓存后训练，不能把该时间当原景检测分类耗时。没有模型或权重倍率搜索。

## 3. 完整系统结果

先在每次支持抽样中计算结果，再按两个过境、五次支持抽样和三个训练种子等权平均。单位%。

| 评价条件 | 旧基线OA/BA | C组OA/BA | C−旧OA/BA百分点 |
|---|---|---|---|
| 跨过境，16支持 | 42.50 / 24.29 | 42.50 / 25.40 | 0.00 / +1.11 |
| 跨过境，32支持 | 43.75 / 27.74 | 42.92 / 28.46 | −0.83 / +0.72 |
| 同过境，16支持 | 46.25 / 28.83 | 46.25 / 28.83 | 0.00 / 0.00 |
| 同过境，32支持 | 44.58 / 34.09 | 44.31 / 33.85 | −0.28 / −0.24 |

跨过境16支持的匹配对照：

| C相对谁 | OA百分点 | BA百分点 | BA正收益训练种子 |
|---|---:|---:|---|
| 旧基线 | 0.000 | +1.111 | 2/3，另一为−0.278 |
| A普通内容读出 | +0.139 | +0.741 | 1/3，另两者持平 |
| B聚合后几何 | +0.278 | +0.833 | 1/3，另两者持平 |
| D训练即错配 | +0.139 | +1.204 | 2/3 |

C−旧跨过境16支持的BA种子标准差1.273个百分点；C−A为1.283。平均收益不能解释成三个种子都重复获得几何独立增益。完整配对见paired_seed.csv/paired_summary.csv。

C−旧在跨过境16支持有3救回事件、3误伤事件，涉及2个被救回行、1个被误伤行；48查询多次重复，不把事件数量当船数。OA抵消而BA改善，是类别权重不同，不是统计矛盾，也不能因此否认少数类别的价值。

连续风险与关系层：C−旧四个条件Brier均略降；同过境16支持三个种子风险均改善但top1不变。跨过境16支持C相对A的Brier反而增加0.000099，MAP@R下降0.001520；相对旧MAP@R下降0.007274。因此**没有证明普遍更好的跨过境同类检索**。支持缺类查询仍计分类，检索无同类时记NaN并单独报分母。

## 4. 原始chip与真实支持：哪里生效、哪里误用

已实际查看救回208、误伤197、持续判对65、持续判错156的VV/VH、原生尺度图及实际支持；另看基于支持贡献而非最近邻选出的70/92/84/161等。生成图数量不等于全部已人工观察。原图显示使用各自原裁片2/98拉伸范围，不代表校准RCS；沿用旧renderer的通用来源提示，具体产品归属以本轮ownership和恢复表为准。

### 推船208：支持没有推船，救回不是同类吸引

`1_cross_pass_B16, seed2, draw4`，真类5，旧预测原油3，新预测推船5。原生64x64，VV/VH均是紧凑横向亮响应，VH背景纹理较明显；仅凭图像无法命名其真实散射物理来源。该支持抽样中**没有推船**。

固定旧最终竞争类3，第一路分差改善0.028339，其中直接核变化+0.029280、支持重解−0.000940。支持92（原油）的相似性−0.27099→−0.33255，贡献+0.00599；LPG161相似性0.13035→0.18913，带符号系数使其贡献也为正+0.00773。原油84反而贡献−0.00530，净效应仍为正。

这说明**相似性增大不必是同类吸引，异类案例也可能提供排除或先验保护作用**。当前可确认的是残差校正对竞争类别的作用被重新分配，使保留的源先验/第二路信息能进入最终决策；不是从缺失的推船支持中学出推船特征。C相对A同一查询也有救回，但只有特定种子/抽样。

### 原油197：同类证据也增强，但错误关系增强更多

`1_cross_pass_B16, seed0, draw4`，真类3，旧正确，新误判集装箱2。原生88x88，VV/VH均可见倾斜主体及横纵延伸；同类92也有延伸，84则较紧凑纵向。不能把这种外观直接定性为运动或尾迹原因。

错误集装箱支持70的相似性0.09322→0.15352，对正确类相对错误类贡献−0.01568；同类92相似性0.11081→0.04946，贡献−0.01012。虽然同类84相似性0.25052→0.31242、贡献+0.01240，仍抵不过负项。总第一路固定竞争分差−0.018376；原最终正确分差仅+0.000095，因此发生翻转。

这里直接定位到**新局部表示对案例关系的错误重排**，而非推测元数据没接入。它为何学出这种重排仍未完全分清：源端判别监督、有限条件覆盖、支持组织及所学表示都有可能，不能仅凭这两幅图宣布物理根因。

### 持续判对65、持续判错156

65与同类174都有细长主体，原最终正确分差已约0.104；补充通道只产生微小变化，不是每张图都有可救回空间。

156原生72x72，同类支持214为136x136，后者背景及横纵延伸明显不同；实际draw只有1个同类支持。新模块仍判化学/成品油1。它说明类别相同不保证局部外观接近，当前条件化没有解决这类支持代表性不足。代表案例不是全体比例，也不是对所有大裁片的结论。

图与数值：case_review/row208_signed.png、row197_signed.png、case_paths.csv、case_support_contributions.csv。分解针对第一路类别分数；最终概率还经过softmax和双路融合，不能把这两种分差当同一个量。

## 5. 哪些解释已排除，哪些仍开放

- 不是旧固定分区直接复用：本轮新增可训练内容/位置门控、注意力和值读出，真实梯度训练。
- 不是完全没有跨过境联系：机制线全部QS跨过境、不同MMSI，旧1.51%限制已解决。
- 不是几何完全不起作用：C正常与错配的注意力、核和概率都有变化；但依赖几何不等于正确几何一定带来收益。
- 独立实现审阅未发现实际源/目标泄漏、归一化泄漏或SS/QS接入错误。4项模型/协议测试和3项恢复测试通过；原132元数据回放，局部特征对原grid回放最大6.20e-6。
- 尚未解决：源验证仅6艘两类、源训练仅两个日期、跨预算不完全匹配、查询无拖船、重复开发而无独立确认；这些是明确限制，不是已证明的退化根因。
- 尚未证明：几何条件化找回了不变船型证据、普遍改善同类检索，或其收益独立于源选择/读出非线性。

## 6. 收口决定

保留本轮代码、源几何恢复和跨过境16支持的BA正信号；标记为开发候选。默认主模型继续用原简单前景/背景方案，不按目标港后验挑A/B/C/D，也不追加倍率搜索。

下一次若继续，优先补**训练/验证端的独立采集与少数类代表案例**，冻结本轮结构再确认16支持边界；不把本轮32支持混合结果直接解释为更大预算无效，也不凭一次小正信号扩展为因果模块。所有后续实际任务是否可用，应先核对源端容量与原图，不承诺必然涨点。

GitHub仅归档代码、表格、报告及有限案例图。原始XML、NPZ、模型权重不上传。相关代码依赖本地冻结数据和旧模块，归档不是可独立下载数据的复现包。
