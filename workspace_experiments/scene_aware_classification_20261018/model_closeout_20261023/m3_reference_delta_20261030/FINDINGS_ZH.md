# M3短期修正：冻结扩围结果

2026-10-30。本轮训练和冻结评价均已完成，短期目标尚未达成。保留现有正式模型，不替换M3，不将小幅波动报告为新增收益。

## 目标与最终修法

目标是在自建数据与公开OSS2上，相对保存的完整原版及同预算对照，取得可重复、可解释的额外分类净收益。不要求每个港口、类别或抽样获胜。

最终候选 `joint_low` 不增加网络层：从原source_fit端点开始，在原干预指导适配中，除原来可训练的三个共享卷积外，允许VV/VH各自M3的32→1024输出映射共同更新，学习率均为3e-5。比较器、值投影、增益、M1/M2、分类头不变。新增可训练参数65536，但模型总参数和推理结构不增加。

该候选在development160上三顺序平均OA/BA与保存原版相同，概率指标略有改善；随后冻结配置，评价3075条及OSS2四类378条。没有根据这两组最终结果继续选择倍率或学习率。

## 本轮排除了什么简单解释

上一轮比较器关系改善未转化为分类收益，值回写的改变却重现误伤。本轮据此先保留旧路径，试图只学习补充信息，而非重写整套模型。

1. **参考差异回写**：将实际加权参考汇总减去合法参考均匀汇总，再训练独立零初始化映射。差异的RMS仅为总汇总约1.89%–6.86%，已用源数据尺度归一化避免仅因幅度小而学不到，但没有获得开发分类净收益。该比例不是信息量或能量占比，不能推断“只有这些类别信息”。
2. **保护旧路径，只训练总参考补充**：seed17出现局部正信号，扩至三顺序后OA下降；固定0、0.25、0.5、1更新强度，开发综合指标最优仍是0，故不扩围这一候选。
3. **显式参考类别证据**：利用已知源参考标签组织实际匹配概率，查询标签不进入前向。正确/打乱参考标签的小对照未支持分类收益；进一步使用任务化特征比较，也没有改善。
4. **联合适配M3输出与原卷积**：最终采用的最小优化修正。在开发集保住OA/BA，但冻结扩大到自建和公开集后仍没有额外净收益。

这些结果支持降低“继续调回写倍率、追加同类映射”这条路线的优先级。不支持宣称M3没有价值、频域无效、因果因素不存在，或错误已完全归因于数据。实现接通和梯度存在已经核实；参考证据内容及其组织是否不足，仍需针对性证据。

## 原图层面的解释

`CASE_NOTES_ZH.md`记录已实际查看的原始尺度VV/VH及真实参考。初期代表案例中，同一种改动既能救回也能误伤；不同类别参考之间存在长宽、亮点分布的重叠，不能用朝向或强响应位置直接代替类别。

例如持续误判样本31141的船体很长，而当前该类两个源参考13000/13276均较小，混淆类别参考中反而有长船。这构成“参考覆盖可能不足”的可检验线索，并不证明尺寸差异就是误判原因。样本31926在本轮seed17补充通道被救回，不能抹去其他轮次或其他顺序中被误伤的记录。

最后冻结候选的案例另见分析目录及补充记录。原图能说明输入中实际有哪些响应、比较对象是什么；仅凭图像或注意力不能命名唯一物理机制。
