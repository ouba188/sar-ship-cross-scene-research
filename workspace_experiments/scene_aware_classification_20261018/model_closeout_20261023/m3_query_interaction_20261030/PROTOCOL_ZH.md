# 查询相关参考消息交互：预设小验证

前轮18次排序实验降低共同偏移比例，但未产生两数据集分类净收益。前期值中心化、参考均匀差分、参考标签、source replay等均已尝试，不再重复其倍率扫描。

数据/图像依据：前轮真实31926/24863以及OSS2 000871/000491显示，同类有明显形态差异，异类也有紧凑点列的重叠；共同类别倾向能救回同时误伤。当前M3将匹配参考投影后加到查询特征，其消息只通过匹配和几何依赖查询。新假设是让参考消息和查询当前响应直接交互，而非再添加只依赖参考的通道。此假设未由图像单独证明。

文献基础：FiLM: Visual Reasoning with a General Conditioning Layer，arXiv:1709.07871。通过requests获取作者arXiv PDF并用PyMuPDF阅读PDF第3/6/7页，含§3、§4.3、表2/3。作者区分条件平移与条件缩放，在CLEVR消融比较gamma=1和beta=0；本文借鉴加法与乘法需要区分的实验组织，不搬用其准确率作为SAR证据，不把通道乘法本身宣称原创。Web工具未提供可核验引用输出，因此以原始PDF检索路径为查阅依据。

## 操作

保持原完整模型所有参数不变，M3之外不新增计算。M3原32维投影分别读查询像素局部特征q与原匹配消息m，新增零初始化32->1024输出，分别测试q、m、q*m。乘法是低秩逐通道交互，不是新的频域分解，也不宣称恢复物理因果因素。

q与m均沿用原M3的通道LayerNorm及同一冻结投影；q仅在实际可回写区域有效。每种输入的全局RMS仅由source_adapt估计，固定后除以该尺度，避免比较不同输入幅度而非内容。原输出完整保留，新增系数固定0.1，输出映射初始为零。两个极化各自参数，65536个新增可训练参数。该方案有额外参数，不能隐瞒成仅改一个无成本算子。

三臂query_only/ref_only/interaction具有同容量。源样本、每步8对16图的ID顺序、种子17/29/43、AdamW1e-4、weight_decay=.01、54/96步、CE+.1原正确KL完全沿用上一轮CE对照。因此可复用其CE训练端点，但CE可训练131446原M3参数，与本轮新增65536参数不相等；同容量判断由本轮三臂承担。不开启其他损失/比例扫描。

先跑两数据集17；若分类或风险有可用信号，固定配置扩29/43。目标未变：两数据集相对原完整模型和同预算CE的额外分类净收益。开发及源验证不是最终测试。

## 有辨别力的检查

- 新输出为零时与原版相同，训练首步梯度非零；全部旧参数保持不变，保存重载/原chip前向一致。
- 全部参考非法时新增回写必须为零；q-only不依赖参考内容，interaction需响应查询和参考内容变化。
- 训练后仅关掉新增通道应恢复原版；仅将新增通道的参考权重改成合法均匀分布，检查实际匹配选择是否必要。旧M3保持原匹配。该推理替换是诊断，不是完整重训消融。
- 分开报告原模型、同预算CE、同容量q-only/ref-only以及interaction；增加共同分数偏移诊断，并回看原尺度VV/VH和实际参考。候选若不胜对照，不强包装交互贡献。
