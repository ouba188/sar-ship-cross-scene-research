# M2同stage内前中末位置比较

2026-10-28，用户授权“先比较同stage前中末”。复用SE扩展版、GCNet的已核查消融思路，来源见上一轮 LITERATURE_DESIGN_ZH.md；不重新声称论文已经验证本任务位置。

## 数据和图像依据

扩围案例34733的散货救回依赖VV浅层更新，31166的集装箱误伤可由关闭框内更新恢复，26109持续正确但余量受损。说明区域回写确有正负作用，而不只是末端多一个向量。不同类别存在相似条状强响应，不能把方向/条纹当类别本体。本轮假设：更早回写给后续同尺度block更多加工机会，但也可能扩大错误更新；该竞争解释需要受控比较。

## 固定候选

| arm | 操作 | M2后还经过几个layer2 block |
|---|---|---:|
| baseline | 不增加本轮浅层M2，原完整模型保留 | 不适用 |
| stage | layer2输出后M2，旧E | 0 |
| block1 | layer2[1]，BN3后相加前 | 2 |
| block2 | layer2[2]，BN3后相加前 | 1 |
| block3 | layer2[3]，BN3后相加前，旧C | 0 |

这里前中末是三个非下采样block中的相对位置，并非整个stage首块。避开layer2[0]以控制下采样/通道改变。三个位置输入均512通道20x20，M2每极化一次，两套参数合计197328，区域、频带处理、初始化相同。前移后所有下游冻结卷积仍参与梯度传播，不得no_grad或旧raw2覆盖。

136源适配、16源参考、160历史开发查询不变；开发实际7类/3过境/3港，不冒充独立源验证或目标盲测。三训练顺序17/29/43、固定6轮54步、M2 lr3e-4、layer3.5三卷积lr3e-5；原干预选样101/136、损失、BN状态、M3保护锚点保持不变。查询与参考值均实时使用相同模型。

只新增block1/2共6次fit，baseline/stage/block3九个模型重放复用。不挑epoch、不调学习率、不改变次数、不启动3075扩围。报告全组均值/SD、配对变化、逐类和正负案例，BA主观察、OA与概率指标并列；不在此历史队列宣布最终最优默认。若差异很小，保留现有配置。

## 检查与成本边界

检查非零M2手工forward与原生整个layer2+BN3 hook一致、不同prefix缓存与现场计算一致、下游梯度连通、旧9模型重放、保存重放及冻结权重不变。成本仅同机器统一stage1入口至分类输出、16查询+16参考、禁用prefix缓存；不含前处理和共享stem/layer1，非端到端实测。早层传播本身是位置作用的一部分。

每轮结束查看原生VV/VH、同类/混淆参考及救回/误伤/持续对错；路径关闭不等于物理因果。正负结果保留，不改默认发布。
