# M2 内部化：位置与设计审查

## 结论范围

检查的是新写的骨干内区域池化反馈块，不是推翻已经保留的末端M2。原M1-M3系统及权重不改。当前试验只有M2与分类头训练，R50参数和BN冻结，VV/VH独立处理，单方向native160输入，不包含C4和参考匹配。

## 它实际如何工作

对特征图F逐像素作通道LayerNorm得Z。每个区域r按原像素掩膜的面积占比m池化一个token：

`t_r = sum_u m_r(u) Z(u) / sum_u m_r(u)`

区域值为 `v_r = W_value(t_r) R_r`。门权重与区域占比相乘，输出投影后残差回写：

`F'(u) = F(u) + gamma W_out(sum_r g_r(u) m_r(u)/max(1,sum_j m_j(u)) v_r)`

每个区域的token随图像改变，区域专属变换可学习。固定门只固定g=0.5，不是固定token或固定输出。输出投影零初始化，使初始网络等于无模块基线；第一步主要更新输出投影是这一初始化的预期行为，不能据此认定其他参数无法训练。

## 已确认的设计限制

1. **一个区域只保留一个token。** 同一区域的位置共享value方向，门主要改变写回强度。它不是局部响应的完整重建，也没有显式跨区域token交互。后续卷积能传播信息，但“船体和邻域关系已经被显式学到”不能仅凭结构宣称。
2. **原dot门可被投影幅度主导。** 输入LayerNorm不限制后续query/key的范数。旧训练已有近全关/全开现象；这证明门饱和存在，不证明它就是分类退化的唯一原因。新cosine门去除正尺度放大路径，不使用可学习logit尺度。
3. **固定残差结构不代表更新幅度有界。** gamma、value、output仍可改变总更新幅度。cosine门0.269至0.731的界限只适用于门，不是整个模块的稳定性保证。
4. **深层区域不等于纯船体/纯背景。** 掩膜表示空间格子的面积占比；卷积感受野已经包含周围响应。我们检查的是区域组织能力，不能把区域token直接称为纯物理因素。
5. **浅层不是自动更优。** 它有更多空间格，但语义、通道数、下游传播深度也改变。位置比较只能首先回答系统配置是否更有效，不能单独证明“空间分辨率是唯一原因”。

## 已修正的接入问题

旧`forward_from(start=2)`未检查早期M2。若调用者只改stages=(1,)而沿用旧缓存，会跳过stage1模块。原stage2实验没有受此问题影响。当前入口拒绝这种调用，stage1重新从原图提特征和掩膜；非零反馈完整前向/缓存前向一致性与梯度测试覆盖这条路径。

## 本轮能区分什么

- 同一位置：固定门与cosine门，检验内容选择是否比更简单的区域反馈有额外价值。
- 同一门方式：layer1与layer2，检验候选系统配置；同时报告参数、耗时，避免称纯位置消融。
- 固定训练权重，将cosine门替换为每张图/区域的占比加权平均：保留平均反馈强度，检验空间变化是否参与当前决策。这是推理干预，不是公平重训对照。
- 固定训练头禁用全部/特定区域/特定极化反馈：定位模型的实际依赖；不能替代与配套训练无模块基线的比较。
- 同时报告OA与BA、逐类及逐种子结果，回看救回/误伤/持续对/持续错原图。只要明确范围内有可重复净收益可以保留，不要求每类全胜。

若浅层更好但cosine不优于固定门，应保留浅层区域反馈，不包装成已证明必要的动态注意力；若cosine有局部收益，需用实际干预量说明其作用范围。分类结果见FINDINGS_ZH.md，不能用本审查代替实验结论。
