# M2位置与反馈方式：本轮结果

## 结论

**插入位置确实影响区域区分，但前移并未自动改善留出采集分类。归一化解决了旧门的极端饱和，却没有证明细粒度动态选择带来稳定净收益。**

保留原正式M1-M3及旧骨干M2结果，不默认替换。layer2固定反馈可保留为更简单、OA略有提升且BA接近基线的备选；layer1学习门保留OA方向的局部正信号，不包装成全面提升。源验证选中的layer1固定版本轮未兑现，不隐藏这个结果，也不事后用目标最好格替换源选择。

## 协议与完整结果

自建24港来源八分类：1205源训练、296源验证、485条历史留出采集评价。MMSI/过境划分沿用，三种子17/29/43，15次新拟合；固定8轮、lr0.001、同批次顺序/分类头初值，源验证J=(OA+BA)/2选轮。只比较一个M2放在layer1或layer2；没有C4/M1/M3/参考库，不是完整最终系统，也不是24个留港折。评价队列有历史开发暴露。

过境配对bootstrap2000次，layer2固定门OA差区间[-1.49,+1.95]pp，layer1内容门[-1.24,+2.74]pp，均跨0；是弱候选不是明确总体胜出。271次抽样缺类，故BA区间仅用1729次全八类抽样，明确为条件区间，不把缺类抽样改成另一种BA口径。见uncertainty.csv。

## 位置的问题：已有证据

源训练VV船体软区域质量由layer1的13.02格降至layer2的3.26格、layer3的0.81格；框内-侧向掩膜cosine由0.179升至0.507/0.842，对应token cosine由0.823升至0.888/0.990。VH同向。

所以细小区域越往后越难区分，这条依据成立。`resolution_examples.png`已实际查看，保持原图尺度，未把旧20x20格放大冒充浅层。但层间通道、语义和下游深度也变了；这些数值不能单独证明分辨率就是识别瓶颈。

## 门的问题：修了一部分，但不是全部根因

cosine门不再通过query/key范数放大logit，所有新cosine有效门的<0.01或>0.99比例都是0；不是靠提高温度后仍被范数抵消。检查见gates.csv和缩放不变性单元测试。

更重要的替换：固定模型权重，把每图/每区域的门换成占比加权平均。layer1三种子仅3/3/4张预测变化，OA变化0/+0.206/-0.206pp，平均为0；layer2仅2/0/2张变化，OA变化+0.412/0/-0.206pp。说明**当前空间细分门的独立贡献很小且混合**。门的统计值存在变化，不等于这些变化明显改善决策。

完全关闭反馈则不同。源选layer1固定版，固定同一个训练头，开启反馈分别救回47/47/48、误伤10/11/15，净+37/+36/+33。模型明显利用反馈，但配套重新训练的无模块基线更好。这表明新模型形成了对新增分支的依赖，不能把“关掉就跌”直接当成额外效用。两种比较均保留。

## 为什么源端提高，留出采集没保住

源选浅层固定版在源验证OA42.46→44.48、BA39.18→41.55；评价却OA47.70→45.98、BA36.04→35.50。

按同类比较：散货源召回43.88→44.30，评价49.90→46.55；集装箱源34.52→35.71，评价46.46→39.39。不是只有两组类别占比不同，同类收益也没有迁移。源验证渔船仅4条，提升1个seed中的1条带来该类平均召回+8.33pp，也影响BA选轮；评价有91条渔船，平均召回持平。源验证化学品98条、评价67条，源端该类改善幅度也更大。

这些是实际数据与决策差异，不等于标签或图像有错误，也不能唯一归因于过拟合、海况或某一种散射机制。已能排除“只因门饱和”和“只因层太深”这两个单一解释；源选择覆盖和回写后类别边界的迁移仍需区分。见source_gap_metrics.csv、source_gap_by_class.csv。

## 原图回看与真实作用

先按相对配套无模块基线的四种结果，选最大分差变化案例；再补固定头、直接开关反馈的两例。所有VV/VH面板均已实际查看，代表案例不是总体占比。

| 案例 | 可见事实与干预结果 | 能支持的结论 |
|---|---|---|
| 29356，化学品，seed17，救回 | VV有交叉线状亮响应，VH较紧凑；新头关闭反馈仍正确，真类分差2.101→2.722 | 反馈强化新头已有判断，不能把与旧模型的翻转全归因于反馈 |
| 6322，普通货，seed17，误伤 | 两极化均有细长亮体；关反馈仍判化学品，分差-1.610→-1.733 | 此例主要边界变化已存在于新头，反馈略加重错误，未定位物理原因 |
| 19216，渔船，seed29，持续对 | VV目标小且显示较暗，VH不可用；关VV反馈分差5.304→1.594仍对 | 仅VV就能提供置信分差补充，不能写成VH互补 |
| 365，海工，seed43，持续错 | 两极化细长亮体；关反馈分差-3.696，开启降至-10.864 | 反馈会显著加强错误证据，非所有强响应都该强化 |
| 37638，原油轮，seed43，直接救回 | VH可见船体旁的细长响应；同一头关闭反馈判散货(-0.807)，开启判原油轮(+3.227)；仅关VH反馈又错(-0.013) | VH反馈在当前模型里是该例救回的必要路径；不证明旁侧细线的物理身份或其独立因果性 |
| 26694，化学品，seed43，直接误伤 | 横向紧凑亮体，VV背景显示纹理更强；同一头关反馈正确(+0.106)，开启判原油轮(-2.544) | 相似形式的区域强化也可误导；不能把反馈作用概括成只增强正确船型证据 |

单区域关闭并非可加分解，因掩膜归一化和后续非线性存在交互。`no_vv/no_vh`仅关闭该极化新增反馈，原极化输入仍在。当前模型没有查询参考库，本轮不存在可以展示的实际检索支持案例。

## 设计判断与下一步

1. **可保留**：区域身份、极化分开、可插入骨干的残差反馈接口及局部救回证据。layer2固定门作为低参数备选留档，暂不自动部署。
2. **本轮不升级**：浅层固定门虽源端最好，但评价三seed OA均降；不能仅因区域更细就作为默认设计。
3. **不主张必要性**：cosine门是合理的数值/优化修正，但空间动态性尚无明显净收益，不作为已立住的新注意力创新。
4. **下一处值得改的不是继续挪位置**：目前每区一个token、同方向回写的表达限制仍在，而且会增强错误类别证据。优先比较“区域摘要用于调制原有局部内容”和当前共享value广播，保持区域、极化、源划分不变；这只是下一步假设，本轮未训练该新结构。不一口气叠多层、引入新卷积或M3，以免解释失焦。

实现、图像、训练、干预、统计均完整保留。整体仍是骨干内部化研发，不替代原末端M2已经取得的证据。
