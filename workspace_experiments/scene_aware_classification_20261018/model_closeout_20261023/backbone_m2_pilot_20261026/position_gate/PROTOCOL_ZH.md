# M2 插入位置与反馈设计的紧凑对照

在读取本轮评价结果前固定此方案。沿用1205条源训练、296条源验证、485条历史评价；船只及过境隔离不变。评价队列已反复用于研发，不称独立盲测。

## 数据依据与待验证解释

已有11062救回和31089误伤原图中，船体及外围线状响应在layer2后的20×20网格上只占少数格子。源训练船体区域质量中位数约3至4格。旧门在不同种子下几乎全闭或全开。两者提示位置分辨率和门控尺度值得分别检验，不证明它们是全部退化原因。

## 固定设计

- layer1后40×40与layer2后20×20，均只放一个M2；VV/VH分开实例化，hidden=32。
- 固定门：所有位置门值0.5，仍训练区域值变换、输出投影及残差增益。
- 归一化内容门：query/key归一化后计算cosine再sigmoid，温度固定1，无可学习logit尺度；门值在约0.269至0.731间。这只限制门饱和，不约束总更新幅度。
- 四组新候选，每组种子17/29/43。额外补layer1缓存路径的无模块基线3次，旧layer2无模块及dot门结果直接保留。
- AdamW lr=0.001、weight_decay=0.01、batch=24、8轮，与原pilot一致；同种子共享分类头初值与批次顺序。以源验证(OA+BA)/2选择轮数，平分保留更早轮。
- 全部15次训练与源验证完成，冻结选择后再打开评价标签。四组均报告，不以评价标签择优追加调参。
- layer1从原始等尺度crop/pad图像重新提取，区域从原像素掩膜降采样；禁止从旧20×20掩膜/特征上采样冒充浅层。
- 检查缓存与完整前向的误差，避免将缓存路径差异误当插入收益。报告每层参数量与耗时；不同层通道数/语义/下游深度不同，不把跨层差异全归因于空间分辨率。
- 固定门query/key不训练，其他参数初始化一致；其参数更少，作为更简单的对照，不称严格容量相同。

## 机制诊断与收口

训练前统计不同层的区域质量、掩膜重叠以及区域token相似性；统计不等于真实感受野隔离。训练后记录门值与相对更新量，配对OA/BA、逐类收益、救回/误伤，以及按过境聚类的区间。源验证均值选出一个候选供详细案例分析，保留旧版对照。

案例必须回看VV/VH原图，覆盖救回、误伤、持续对和持续错；固定训练好的分类头禁用反馈，区分直接反馈作用和不同训练模型差异。本轮不含M1/M3和C4，也不直接替换已收口完整模型。若门饱和消失但分类不涨，不能声称已找到全部根因。
