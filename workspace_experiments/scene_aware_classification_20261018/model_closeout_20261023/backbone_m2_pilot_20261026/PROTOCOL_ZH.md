# 骨干内 M2 单点小验证（预先固定）

## 问题与范围

旧模块主要在骨干之后读出/修正。已有原始chip显示同类与混淆类均可出现细长亮响应，区域组织有解释上的动机，但没有证明区域反馈能改善骨干特征。本轮检验：在layer2后分别池化船体/轴端/侧向，再以位置内容相关的门控反馈，是否改善其后layer3/4产生的分类表示。

只开发M2，不同时改M1/M3，不替换已保留完整模型。结果是骨干内算子小验证，不是完整M1-M3复现。

## 数据与对照

- 沿用ports24_aligned_20261026：1205 fit_train / 296 fit_validation / 485 evaluation；按MMSI/过境隔离，历史数据，非新盲测。
- 本轮不读3075队列成绩。644 utility_train及612 selection暂不参与本轮。
- 输入：原尺度160裁剪/补零，VV/VH分开；缺失视图遵循原valid，不凭图片路径恢复。
- 三组：none（冻结R50+新分类头）；merged（同样三组token/同参数量，但三区域使用相同联合范围）；regional（保持三区域身份）。merged与regional覆盖相同像素联合，不混入范围变化。
- layer2后单点插入，瓶颈32，VV/VH独立块；原R50参数及BN冻结，但layer3/4保留梯度通路；分类器为两极化末层池化+有效性标记后的8类线性头。
- 仅本次验证使用原方向单视图，不加C4；所有组一致。不能直接与旧C4完整系统的数值解释为增减收益，更不能声称分类旋转不变。
- 源训练以船只/类别权重CE；AdamW lr=0.001, weight_decay=0.01，batch=24，8epochs；种子17/29/43。所有组同head初始化、同batch顺序、同优化步数。
- 每epoch用296源验证的(OA+BA)/2选择checkpoint，平局取最早；不按485结果追加参数。
- 先完成全部九组训练并冻结checkpoint记录，然后统一读取485真值评价。

## 实现和验证

块输出F+gamma*Delta，gamma初值0.1，输出投影零初始化；避免两个乘因子同时为零而断梯度。区域token独立，反馈权重由当前位置和token的内容点积sigmoid决定，仍受该区域软掩膜限制。允许其他层重复实例化，但本轮只训练layer2。

前缀到layer2可缓存，因为前缀没有可训练块。缓存float16再转换float32；三组共用。先核对新旧native输入和全图/缓存前向误差。

汇报OA/BA/NLL、逐类、配对救回/误伤、过境bootstrap及成本。至少回看救回/误伤/持续对/持续错的原始VV/VH；结合门控与更新位置，不凭热图命名物理机制。源验证渔船样本少等已知组成边界保留。无收益亦保留结果，不自动扩大搜索。
