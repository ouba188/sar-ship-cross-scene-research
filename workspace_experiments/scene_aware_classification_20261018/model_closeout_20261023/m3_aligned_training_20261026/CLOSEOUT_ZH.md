# 当前候选的有限收口决定

2026-10-26。用户同意训练后保留有用小改动、转向收口。当前可以停止结构扩展，冻结已有候选与比较口径；这不是“全部数据集验证完毕”或“已证明顶刊创新”的声明。

## 保留什么

| 项目 | 处置 | 理由 |
|---|---|---|
| 原始区域特征＋类别响应摘要 | 保留公开集读出候选 | 相对同fit角色普通区域MLP，双向平均OA/BA均正；反向OA约+2.86pp，过境区间[1.42,4.37]；加宽对照未复现 |
| VV/VH分开、原生裁补与区域身份 | 保留已有处理路径 | 追踪具体极化、框内/侧向/轴端证据，不新增缩放或混合极化解释 |
| 原M3匹配与空间—频域融合 | 保留已验证版本及边界 | 正向对新基础小幅增益；反向尚损失OA，不声称在每个域都应启用或比ridge强 |
| 本轮metric适配、读出配套训练 | 保留代码与候选，不替换默认 | 仅metric小正信号；全配套OA升、BA降，存在具体收益与代价 |
| 总强度beta | 不列新增模块 | 源选结果与旧版精确相同 |

“保留候选”不表示按目标数据挑最优种子/方向。原三种子及所有负结果保留；不混合旧、新模型的最好单项成绩。

## 两条实际代码路径必须分清

### A：正式旧M123

原生VV/VH chip → 冻结骨干 → 原基础分数 → M1注意力修正 → M2区域证据修正 → M3匹配与极化融合 → 分类。

独立工程E:/临时会话/sar_m123_standalone以及原3075扩围、公开集及迁移记录继续保留。本轮没有覆盖其模型资产。

### B：公开集raw_summary修正候选

原生VV/VH chip → 相同冻结骨干/区域组织 → 以下信息并行读取：

- 1538维原始区域特征：两极化×三区域×256维，加两个有效标记。
- 104维辅助：72维layer1区域类别响应注意力摘要，24维quality与8维geometry。

源fit_train标准化后拼接1642维 → 128隐藏层MLP → 四类基础分数 → 原32源参考、每候选类top2 → PairMetric与可微匹配 → 分开VV/VH修正 → 源端alpha与空间—频域条件调权 → 分类。

**这里仍有区域类别响应的注意力汇聚，但没有原M1的mean3/hb3或M1修正分数，也没有原M1→M2相加链。** “原模型全部组件都不变，只加一层”不是准确表述。严格保留旧分数的anchored_raw_summary已做过，收益不稳定，不能冒充当前候选。

输入/基础实现：raw_region_bypass_20261026/run.py、readout_bottleneck_20261026/probe_compression.py；固定匹配版后端：raw_region_bypass_20261026/downstream/run.py。配套训练备选实现为本目录run.py。已有裸基础与原M3后端checkpoint仍是冻结记录，不把本轮新权重自动覆盖过去。

## 本轮可以怎样写研究结论

已有证据支持：将区域信息全部先压缩为少量类别响应，会丢失有用的分类信息；保留原始区域特征，并以类别响应摘要辅助判别，在本公开四类开发协议下相对匹配的普通MLP有收益。匹配器和读出如何使用这些信息仍存在跨域边界，训练端改善不保证每类目标收益。

不应写成：已经分离纯因果因素；频域模块在所有数据集必需；本轮新增强算法创新；原M1/M2分数链完整保留；新完整模型全面优于强简单对照。
