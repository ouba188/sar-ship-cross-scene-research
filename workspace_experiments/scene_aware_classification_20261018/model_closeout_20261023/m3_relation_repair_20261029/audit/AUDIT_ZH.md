## 2. 同类目标：均匀多正例并不等于同类总概率

关键位置：`sar_m123_standalone/sar_m123/current/training.py:40`—45。若同类合法参考集合为S、大小m，当前损失是：

`L_uniform = -(1/m) * sum_{k in S} log p_k`

它可严格拆成：

`L_uniform = -log P(S) + log(m) + KL(Uniform(S) || p(. | S))`

因此它同时优化同类总概率和同类内部均匀性。真实协议每类2个参考，前者并不能替代后者。若一艘同类船明显更有用，当前目标仍可能压低它的分数。

CPU四参考logit `[3, 0, 1, 1]`，前两艘同类：概率为 `[0.75731, 0.03770, 0.10249, 0.10249]`。当前目标对第一艘同类参考的梯度为 **+0.25731**，梯度下降会压低其logit；仅优化同类总概率的梯度为 **-0.19526**，会提高其logit。同类内KL为0.85544。无同类参考时原函数loss及梯度为0；只剩一个合法正例时两种目标相同。

**是否确有bug：没有证据表明实现违背原先的均匀多正例设计；确有额外目标约束，不能把关系CE下降直接解释为更好地选择有用参考。** 也不能仅凭此反例推断当前训练被均匀性项主导。

如后续真实样本证据要求放松该约束，最小替换只需把该行改为合法集合上的 `logsumexp(all) - logsumexp(same)`，保持无正例跳过、样本权重和极化平均；其含义是同类概率求和，不是类别内log-mean-exp。该方案仍偏好合法参考数较多的类，也可能集中于单个正例，故不是已证实的默认修法。本轮保持原目标以隔离metric作用是合理的，不应回头改正在比较的实验定义。

## 3. 关系读出与实际参考聚合不同

关键位置：`sar_m123_standalone/sar_m123/selective_matching.py:70`—80及85—87。

前向先对每个查询槽算匹配score，再跨参考softmax得到 `reference_weights`。关系logit则先按传输质量汇总槽内score，再对存活区域等权平均。fitting_loss对该最终logit再次跨参考softmax。**先平均再softmax不等于先softmax再平均**；区域质量、槽数、写回覆盖也不等同。

使用生产Sinkhorn的CPU三区域、两参考反例，区域score分别为 `[1.0,0.1]`、`[0.4,0.6]`、`[0.4,0.6]`，温度0.1：

- 关系监督分布：参考A/B为0.84113/0.15887。
- 实际每区域注意力再平均：A/B为0.41276/0.58724，排序相反。
- 再考虑真实传输质量的平均value系数：A/B为0.39996/0.55937，仍偏向B。

另外，score除以row_mass，但moved除以offered query mass，未匹配质量仍会衰减实际消息。单槽相似度-0.8/0/0.8时，实际传输质量为0.01756/0.5/0.98157。关系score不能完整描述消息幅度，更不能描述其类别方向。

**是否确有bug：归一化和dustbin保留有可解释设计目的，不能直接改除数或移除未匹配机制；但用reference_logits同类概率宣称writer已经有效利用同类证据是不成立的。** 此反例是数学可达性，不是实际SAR样本的发生率或最终类别预测。

最小处理首先是报告语义：分别报告关系概率、实际回写注意力和分类效果。主代理已完成的compare_only/value_only移植比直接改聚合公式更能定位本轮退化；无需为本审查再跑一轮。若以后改监督读出，应明确是监督实际槽级同类注意力还是最终分类效用，不能同时改目标和比较器再归因于单一原因。

## 收尾与可执行判断

1. 不修所谓“根本断梯度”：该假设已被CPU和历史真实梯度否定。不解冻冻结锚点，也不为追求首步全参数非零而修改初始化。
2. 保留本轮三臂及路径移植负结果。主代理提供的结果支持：比较器确实能改变同类关系，但本轮分类退化由值路径续训复现；它尚不能唯一确定是project、output、gain中的哪一项，也不能证明所有M3训练都会退化。
3. 当前最小处置是保留原模型作为端点，不把本轮M3-only续训候选自动升级。若继续修M3，应围绕既有路径移植与同类仅留诊断决定writer及冻结分类器的协调方式；不再以同类关系概率上涨代替分类效用，不扩metric搜索。
4. 类别总概率目标是后续可选的局部替换，不是本轮已证实修法。已有原目标/去目标旧消融及本轮compare/value移植已经提供必要区分，本审查不追加实验。
