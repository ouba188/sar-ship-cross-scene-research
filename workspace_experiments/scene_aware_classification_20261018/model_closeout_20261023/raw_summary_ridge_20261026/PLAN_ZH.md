# 原始区域 + 现有摘要：补齐读出对照

日期：2026-10-26。先冻结此方案再查看本轮目标结果。

## 问题与范围

现有区域 MLP 加摘要有小幅平均收益，但反向跨数据集仍落后于原始区域 ridge，主要差距在普通货船。先区分信息入口与分类读出，不重建骨干、不追加注意力或动态门。

本轮新增两方向 raw_summary ridge；原始区域 ridge 重新拟合并核对旧结果，原始/摘要 MLP 复用已完成的三种子缓存。四类，现有源 fit_train / fit_validation；所有标准化、常量屏蔽、正则选择仅用合法源数据。正则网格沿用 0.01/0.1/1/10/100/1000，源 J=(OA+BA)/2 选择，不用目标选值。

输入为原始区域1538维 + 既有摘要104维（72类别响应与32几何/质量）。这不是纯注意力的消融，也不保留原M1分数累加，尚非完整M1–M3改进。VV/VH及区域仍分别保留于输入。

两方向全部预测落盘后再评价。报告OA/BA、类别与采集配对、采集/MMSI分组重采样，不把确定性ridge重复运行当独立种子。固定源折，所以不声称新采集训练泛化已证实。

回看每方向救回/误伤/持续对/持续错的原始VV/VH。反向翻转优先普通货船，随后按观测ID选择；其余按观测ID。展示最近源训练同类/混淆类作为图像比较，不称为ridge实际检索支持。对固定类对分解原始通道系数重估、类别摘要、几何质量及截距贡献；这是线性分数的精确分解，不是物理因果证明。

结果决定下一步：若摘要在线性读出仍有净收益，保留为低成本入口候选；若退化，不据此否定全部摘要，也不强行换主模型。现有正式模型保持不动。
