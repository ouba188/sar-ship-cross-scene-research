# 原始区域＋摘要的 ridge 对照

日期：2026-10-26。训练、双向评价及8张原始VV/VH面板回看已完成。正式M1–M3未替换。

**结论：补齐四格对照后，摘要改善普通MLP的既有信号仍保留，但直接拼到ridge上没有明确净收益。这一候选不升级为主方案。结果不支持重建全部骨干，也不支持“换一个线性头就解决了瓶颈”。**

## 1. 这轮实际做了什么

冻结现有native160裁补、R50特征、VV/VH及区域组织。原始区域输入1538维；新增104维为72维类别响应摘要与32维几何/质量。新训练两方向的raw_summary ridge，并重训raw ridge作精确重放；既有三种子MLP只复用预测。

OSS1源fit_train405/fit_validation89，OSS2为478/228。采用原来类×船只权重、相同六个alpha、相同J=(OA+BA)/2源验证选择。两方向预测全部冻结落盘后才读目标标签。原始与摘要ridge分别在OSS1选100、OSS2选1000，选值没有变化。

这是**读出接口实验**，没有保留原M1分数累加、没有重训完整M3；不能报告成三模块完整改进。目标队列此前已用于研发，仍是固定折开发证据。

## 2. 四格结果

四分类：散货、普通货、化学品、集装箱。下表为OA / BA百分数。MLP三种子均值；ridge是确定性拟合，不复制成三个随机种子。

| 输入及读出 | OSS1→OSS2，1619条 | OSS2→OSS1，921条 |
|---|---:|---:|
| 原始区域 MLP | 53.78 / 51.08 | 60.08 / 50.81 |
| 原始区域＋摘要 MLP | **53.90 / 52.41** | 62.94 / 51.69 |
| 原始区域 ridge | 52.07 / 47.78 | 63.74 / **54.97** |
| 原始区域＋摘要 ridge，本轮 | 51.88 / 47.32 | **63.84** / 54.71 |

新增摘要ridge相对原ridge：正向OA -0.1853、BA -0.4615个百分点；反向OA +0.1086、BA -0.2683。正向救回39/误伤42；反向救回26/误伤25。不是完全不影响预测，而是正负抵消。

过境簇4000次配对重采样的95%区间：正向OA[-1.34,1.01]、BA[-1.68,0.87]；反向OA[-1.89,2.25]、BA[-2.24,1.78]，均跨0。MMSI分组结论相同。这只能说明当前固定模型/队列下未见明确净差异，不是证明两个方法完全等效，也不是源训练划分稳定性测试。

源内evaluation也未受益：OSS1原ridge69.84/59.18→加摘要66.67/56.71，OSS2为59.79/57.00→59.52/55.92。源fit_validation的J同样均低于原ridge；没有依据把新方案强制加入正式模型。

## 4. 有没有解释到具体样本

有。本轮读取实际原图和源训练同类/混淆类例子，并将线性分差拆成四项：原始通道系数重估、类别响应摘要、几何/质量、截距变化。分解相对同一个竞争类别，最大闭合误差正向5.54e-6、反向3.62e-6，为float32分组求和舍入。

- 反向普通货228：集装箱→普通货；固定分差-0.0677→+0.0440。类别摘要贡献+0.2179，抵消原始通道重估-0.0772等负项。其中VV框内+0.0688、轴端+0.0589、侧向+0.0605共同贡献。
- 反向普通货448：普通货→集装箱；分差+0.0661→-0.0482。类别摘要贡献-0.1005，主要负项包括VV框内-0.0661、VH轴端-0.0846，VH框内则正向+0.0655。不是一个统一的“VH无用”问题。
- 正向普通货149：原来正确，新增摘要后改为散货。摘要分差-1.4057，VH轴端项-1.4215占主要负向，其他项部分抵消。图像上同类和散货源例子均有短条亮响应；现有结果能定位错误用到了哪类统计，不能凭这些外观断定是哪种物理散射原因。
- 正向散货14被救回；化学品0分差改善但仍错；其余持续对/错同样留档。

见analysis/CASE_REVIEW_ZH.md、cases.json和8张面板。区域摘要顺序是框内/轴端/侧向，区别于原始M3槽位的框内/侧向/轴端。统计保存为均值、(高侧-低侧)/2、(高侧+低侧)/2，不误称三个独立的均值/高侧/低侧。

固定新头后屏蔽类别摘要，正向OA51.88→49.78、反向63.84→63.19，说明新头确实依赖摘要；但分别重训的原ridge仍有52.07与63.74。**“训练后的模型用到了摘要”与“加摘要优于不加”是两回事。** 屏蔽诊断没有用于选最终模型，也不代替配套重训对照。

## 5. 实现与可比性

原ridge源/目标四项重放误差均0；源标准化与前轮MLP完全一致，恒定列屏蔽、样本顺序和MMSI/过境隔离通过。独立只读审阅未发现本轮目标泄漏或ridge数学错误。

摘要reader和新头使用相同源fit/validation标签，没有增加独立标注样本；但摘要多了一次监督表征学习与源验证选择。拼接相关坐标还会改变ridge有效正则化。因此本轮评价的是整个摘要＋几何质量包，不能把它当纯注意力机制、纯信息量或者因果效应的单独检验。

本轮只新增4次确定性ridge拟合，沿用旧预测完成四格对照。分析阶段修正了float32闭合检查容差及新报告的区域/统计名称，不改训练权重或预测。

## 6. 对原模型怎么处理

1. **不大改骨干和输入。** 原始区域特征、VV/VH分开、区域身份仍是有用基础。
2. **保留已有raw+summary MLP为有范围的正信号，不把新ridge拼接版升级。** 摘要收益依赖读出与任务，并非一拼接就好。
3. **下一步的局部修改优先在已有强基础上的M3增量利用。** 固定已完成的raw+summary候选，检验源端选择能否限制整项修正幅度并允许0，复算分数依赖输入；与原M3配对，而非再寻找更复杂摘要。该实验本轮尚未开展，也不预设能涨。
4. 后续需要换源采集划分的配套训练，才能回答训练稳定性；本轮的目标bootstrap不冒充该证据。不按两个目标测试方向各自最优来部署模型。

当前最有依据的说法是：问题在“有用区域信息如何读出、如何避免后续修正抵消收益”的局部接口，尚无证据要求推翻全部M1–M3，也没有证据保证三个模块原样累加就是最优。
