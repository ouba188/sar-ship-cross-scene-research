2026-10-26。42组配置：2源方向×7输入臂×3种子，每组基础MLP、VV/VH读出及frequency门重新训练。骨干、类别响应读者、原生160裁补、区域单元、32参考和本轮选定PairMetric固定；不是42套新骨干。缓存特征上的训练/预测约73.54秒，不含原图特征提取及图像分析，不是端到端运行成本。所有预测保存后读取目标标签；本轮仍属历史开发任务。

## 1. 实现及协议

保持1642输入、128隐藏层和210820基础参数，删去字段在训练前置零，源端标准化及后端依赖输入全部重算。full在6组中基础与最终分数都精确重放保留版。raw_only多104个零列导致矩阵乘法舍入，最大分数差5.75e-5，但12项源/目标重放的分类和选中步数全相同。初次使用2e-5数值容差因此停止；检查后采用1e-4并同时约束分类/选点，而非忽略失败。

summary1由2极化×3区域×4类别×3统计构成72维：均值、(高侧-低侧)/2、(高侧+低侧)/2；另32维是质量与几何。下表attention_only并非只有注意力，而是“均值+双向注意力、不含质量几何”。raw_only/merged_raw/body_raw都不含104维摘要。

## 2. 基础读出对照

OA/BA百分数，3种子均值；OSS1→OSS2为1619观测27过境，反向921观测21过境。

| 输入 | OSS1→OSS2 | OSS2→OSS1 |
|---|---:|---:|
| 原始分区特征，无摘要 |53.78 / 51.08|60.08 / 50.81|
| 加均值，无质量几何 |53.80 / 50.75|60.37 / 51.36|
| 加均值+注意力，无质量几何 |53.84 / 51.22|59.97 / 50.47|
| 加均值+质量几何，无注意力 |53.59 / 52.01|61.82 / 50.85|
| full：完整辅助信息 |53.90 / 52.41|62.94 / 51.69|
| 所有区域合并池化，无摘要 |50.26 / 46.91|58.20 / 50.58|
| 仅框内池化，无摘要 |52.38 / 48.71|61.71 / 51.46|

**注意力不能独占整个摘要的收益。** 保持质量几何时，注意力正向+.31OA/+.40BA、反向+1.12/+.84，均为均值正信号但过境置信区间跨0。去掉质量几何后，注意力反向反而-.40/-.89。完整基础相对无质量几何的注意力版，反向OA+2.97pp，区间[1.69,4.37]，说明辅助字段与注意力的配合不能忽略；不是单独证明某个角度是因果因素。

**区域身份有更直接的证据。** 分区对合并的正向OA+3.52pp、BA+4.17pp，区间分别[2.16,4.77]和[2.44,5.90]；反向均值+1.88/+.24，区间跨0。实际是相同局部单元按mass加权合并，不是仅在已有摘要上换名字。

这不是笼统的“所有类别都涨”：正向按散货/普通货/化学品/集装箱的召回变化约+.37/+10.43/-.28/+6.18pp。目标类别数分别455/147/354/663，普通货只有147条仍有正信号；不只是最高样本数类别决定的OA变化。

**外围不是普遍有益。** 分区对仅框内正向+1.40OA/+2.37BA，BA区间[.38,4.55]；反向-1.63/-.64，区间跨0。分区正向普通货召回平均+9.07pp、集装箱+2.87pp；反向集装箱仍+5.50pp，但散货约-2.47pp、普通货约-2.82pp。可保留有边界的外围价值，不说所有船型都应加背景。

仅框内是对整chip冻结特征的框内池化，骨干感受野仍可能包含周围；不是把图像背景完全清除。合并/仅框内向量复制3份维持名义容量，但有效维数降低正是信息消融的一部分。

## 4. 原图证据与剩余缺口

已查看6张查询组合图(24案例位置)和4张实际参考图，均为VV/VH分别、原生裁补、固定灰度。case_seed预先17，每种救回/误伤/持续对错取最小obsID，非挑最大成功例。详见analysis/CASE_REVIEW_ZH.md及cases.json。

图像可见细条、多亮段、端部集中响应在多个类别中同时存在；注意力或分区改变确实影响类别分差，但不能从这些外观直接指定物理散射机制。支持式端点还核查实际同类及竞争参考；同一库下基础与读出改变能产生救回或误伤。

本批支持“保留区域身份、联合利用类别摘要和质量几何有任务化价值”，不支持“每个模块都必须开”“动态频域门已获独立证据”或“完整新版超越全部简单对照”。不据这些目标成绩临时改默认为body_raw/attention_only。下一步只完成预定M3替换、汇总报告，不继续扩结构。
