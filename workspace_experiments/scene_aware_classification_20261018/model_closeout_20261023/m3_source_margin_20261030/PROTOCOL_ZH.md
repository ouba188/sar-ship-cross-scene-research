# M3源端误伤约束修正

## 依据

上一轮类别分离M3在自建/OSS2完整队列BA略涨、OA略降。目标集只提供问题线索，不用于选新倍率。新增源端统计已证实：自建136源适配样本三顺序，aligned共10救回/5误伤，5误伤全部散货；原正确散货113次事件中106次分差下降，平均-0.11977。监督训练端也存在该取舍，不能只归咎于未知目标域。源端统计是训练内证据，不是泛化证据；同一船跨顺序不是独立样本。

当前CE+.1correctKL（T=1）允许错误翻转。不是发现实现bug，也未证明KL系数是唯一原因。复用已查看的散货误伤11223及普通货船救回/误伤002283/002401原图，进一步由源病例检查这一现象能否对应真实输入；不从外观构造方向规则。

核读Positive-Congruent Training: Towards Regression-Free Model Updates（CVPR2021）官方PDF第3-6页，§4、式4-9、表2/3。论文用原模型正确性加权蒸馏，降低更新后的negative flips；默认alpha1/beta5/lambda1，并报告只保护原正确样本及温度1的KL不一定足够。该论文也报告误伤降低可能伴随整体错误率升高，不将其当作必然涨点依据。web工具未返回可用文本，已通过requests+PyMuPDF解析官方PDF核读。

## 两个固定训练对照

算子固定为上一轮aligned类别分离M3，从原完整模型+零起点新writer重新训练；不从已看完整队列的新权重继续。M1/M2/骨干/分类头/旧M3冻结不变，只训练16384/8192个新回写参数。两数据集沿用原16/32参考、136/241源适配样本、相同schedule、batch16、54/96步、AdamW1e-4、wd.01、源RMS及gain.1。没有新增推理计算，和上一轮同算子相比只改训练目标。

1. fd_lm：CE + mean[(1+5*old_correct)*0.5*sum_c(new_logit-old_logit)^2]。直接借用论文FD-LM设定，不称原创损失；保留原始logit版本，不自行中心化改变论文公式。
2. margin：保留CE+.1correctKL，再加mean[old_correct*0.5*sum_c relu(old_true_minus_c-new_true_minus_c)^2]。只惩罚已正确源样本的类别优势下降，不惩罚优势上升，不将原来错误答案当目标。不设目标类别特例，不按散货单独加权。权重1预设，与FD-LM不是等梯度强度对照；step16记录两项梯度范数与夹角。

旧原完整模型、上一轮同算子CE+.1correctKL、同预算原M3 CE续训均保留。新两臂只是不同保护目标的成套配方比较，不声称隔离某一标量超参。标签仅用于源训练损失，预测时不需要查询标签或新元数据。

## 运行决策与验证

先两数据集seed17，共4fit300步；参数/损失不看结果改动。若出现一臂在某数据集OA或BA严格改善、另一数据集不同时OA/BA退化的可用分类信号，再固定该臂扩29/43。没有信号不因源保护改善而自动扩围。后续三顺序开发仍有值得保留的双数据集信号才考虑再次冻结完整评价，不能把保护得完全不改变预测当作成功。

检查损失初始化为零、原正确加权、margin方向与平移不变、原错误仍可通过CE学习、teacher无梯度；训练验证新writer梯度、其余参数不变、零起点/关闭恢复、保存重载/native-cache一致。复用旧算子已通过的局部对应测试，不重跑无关测试。结束后回看原始VV/VH与真实参考，记录救回、误伤和持续状态。所有结果保留；本轮不以少数类有收益或少数类退化作一票否决，只判断实际净收益及边界。
