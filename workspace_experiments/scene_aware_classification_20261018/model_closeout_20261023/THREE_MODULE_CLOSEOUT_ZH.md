## 1. 主线与冻结决定

任务是具有检测OBB的跨采集SAR船型八分类。当前研究以单chip及源端参考库为输入，不包含整景邻船类别传播、港口功能区或未知类拒识。

核心问题：已有分类路径虽然已经读取局部和上下文，但其聚合仍可能遗漏有用的类别响应分布、目标相对区域身份，以及具体查询与参考之间的局部判别关系。

保留三个方法模块：

|模块|回答的问题|当前保留实现|
|---|---|---|
|M1 双向类别响应分布读出|响应除均值之外，如何分布？|保留均值，分别聚合高、低侧相对类别响应|
|M2 目标几何引导的区域证据读出|这些响应位于目标的哪里？|OBB框内、无向轴端、侧向分区，分别读取类别证据|
|M3 空间—频率联合条件匹配|对这张查询与这张参考，怎样比较更有判别力？|联合共变描述生成通道度量，同时改变局部匹配及计分，即both版本|

M1的sigma/kappa版本保留为有效替代与对照，不与双向注意力重复叠加计作第四模块。M3固定T只改K保留为消融及有边界备选，不作为当前主方案。冻结普通局部匹配强基线，不抹掉简单方案的有效性。

## 2. 完整连接关系

```text
VV/VH原像素裁剪/补边 + 各自有效OBB
  |
  +-- 已有A轴向/五点采样 + D上下文 + 分数校准 --> B
  |
  +-- 冻结R50 layer3 --> 类别响应图
  |       --> M1：均值 + 双向分布摘要 --> 增量分数
  |
  +-- 冻结R50 layer1 + OBB区域
          --> M2：框内/轴端/侧向的类别响应摘要 --> 增量分数

上述基础与两模块组合 --> s12

查询与源参考的layer1局部内容 + 同区域空间/频率联合描述
  --> M3：成对度量K --> 可微局部匹配T(K)
  --> 分极化、分区域的匹配分数与有效匹配量
  --> 冻结局部分类头H --> s_final = s12 + H(local_new)
```

M3是在已接入M1/M2的上游分数上工作，不是三个分支从头联合训练。最新实验使用隔离角色后重建的上游版本，不能把早期4744队列的检查点与最新3075队列结果视为一张无缝累加表。

M3匹配对照为 `s_strong = s12 + H(local_old)`；新方法等价写为 `s_strong + H(local_new) - H(local_old)`。**不是再把旧局部头加一遍。**

当前同一套冻结ImageNet R50权重用于不同层的特征读取，不是历史SAR自监督R18双骨干；实现仍分阶段缓存，尚不能宣称单次前向已共享全部计算。VV/VH分开，C4读出汇总，原图160裁剪/补边而非强制缩放；特征读取中的插值另当别论。

## 3. M1：双向类别响应分布读出

**困难。** 相近均值可能对应不同局部响应分布，单个汇总分数不能显式保留这一区别。基础模型并非完全没有局部信息，本模块验证的是额外读出的增量。

**实现。** 源端类别方向将layer3特征映射为八类位置响应。保留各类均值mu；去除位置均值与类别共同响应后得到相对响应q。在有效区域上分别以 `softmax(+q/tau)` 和 `softmax(-q/tau)` 汇总高、低侧，形成q+、q-，再构造 `h=(q+-q-)/2` 与 `b=(q++q-)/2`。mu与h/b进入小型残差读出头。温度及训练选择来自源端。

**含义。** 同时保留响应起伏与偏向，而不是只盯最强响应。高低侧是模型类别响应，不直接等于物理强弱散射或正确/错误证据。该操作不是Transformer式双流交叉注意力。

**证据。** 早期4744观测队列，注意力版相对强B的OA/BA为+1.152/+0.724个百分点，包含均值支路贡献；双向相对仅高侧为+0.183/+0.261，相对仅低侧为0/+0.398。已有自身/替换摘要、响应干预及原图案例；并非所有救回都来自注意力。

**创新定位。** 类别坐标中的均值保留与双侧分布读出，是有针对性的算法改造。不是首次类别注意力或高阶统计；sigma/kappa与本模块属于同一贡献的替代实现。

## 4. M2：目标几何引导的区域证据读出

**困难。** 全图分布不明确区分相似响应位于框内还是外围。需要保留区域身份，不预设所有背景都应删除或都值得利用。

**实现。** 在layer1建立随OBB中心、长宽与无向轴变化的三个区域：框内；1.5L×W矩形减框内形成的两端；L×2W矩形减框内形成的两侧。两端合并、两侧合并，不伪造船首船尾标签。各区域分别读mu/h/b，结合有效性与质量，由区域头补充冻结M1分数。VV/VH分别处理。

**含义。** 不仅问响应强不强，还保留其相对于目标的位置。该设计是几何引导的区域池化/读出，不是自由形变卷积，当前新区域模块没有真实雷达轴条件化。

**证据。** 在同一早期4744队列，相对冻结注意力版OA/BA为-0.035/+0.483个百分点；相对固定尺寸模板为+0.246/+0.532；完整区域相对增量仅框内为-0.063/+0.289。原图中966侧向参与救回，也有2217外围参与误伤；支持有条件的区域补充，而非外围普遍有益。

**创新定位。** 将目标相对区域身份与源监督类别分布共同保存，并在跨采集任务验证其作用。单独OBB池化、方向采样并非首创，也不把手工区域范围称为已发现的最优物理边界。

## 5. M3：空间—频率联合条件匹配

**困难。** 同一参考对不同查询可能有相反效用；增强某区域相似性可能同时增强错误类别。固定局部余弦不根据这对图像的联合响应改变比较方式。

**实现。**

1. 查询和参考使用同一OBB局部组织：20槽，框内8、侧向8、端部4。读取冻结layer1、源PCA32并单位归一化的内容向量。
2. 原PNG上提取4/8/16像素波长的Gabor响应，四方向能量先平均，再做对数能量处理；这是显示图像域纹理频率，不是SLC相位或已校准RCS。
3. 每槽形成三尺度与32内容通道的联合描述：`C = E[eF] - E[e]E[F]`，共96维。每个C4视图先计算联合统计再汇总，不把独立平均误称共变。
4. 源标准化后96→4投影。成对输入为投影向量的均值及绝对差，8→32产生正、有界通道权重 `w=1+0.25*tanh(...)`。以归一化加权余弦构成K。成对交换保持对称，不将相同朝向直接作为同类判据。
5. K进入带未匹配出口的可微Sinkhorn，得到T；分别汇总匹配分数 `sum(T*K)` 与匹配量 `sum(T)`。同时学习版只有一个640参数度量网络，梯度经计分和T两条路径回传，**不是两个独立网络分别预测K、T**。
6. 每极化、每区域分别保留摘要，经原冻结头补充分数。未匹配出口使T还涉及接纳多少证据，不只是对应位置移动。

**参考组织。** 当前库是64个源端标注案例，每类8个；每张查询按旧船体池化相似度取每类2个，全部八类都比较。不使用查询真值选参考，不是新增64个目标标签，也不是5%交接预算。成对度量未改变这一检索规则。

**证据。** 在扩围3075观测、1950船、85过境、18港的历史隔离队列，both相对普通局部匹配strong，OA +0.596、BA -0.022个百分点，NLL/Brier改善，三配置净正确事件分别+1/+10/+44。收益主要来自成品/化学品油轮等，并非每类获益。原图回看有28072救回、32728固定T误伤但both保留正确，以及相同真类参考下22470持续正确、31655持续错误的相反区域效应。

**创新定位。** 当前最值得作为算法核心的部分是“区域内空间—频率共变描述 → 查询/参考对专属度量 → 匹配与计分共同改变”的连接。不能拆成协方差、注意力、最优传输三项首创；也尚未证明频率信息不可替代或发现纯因果因素。

## 7. 收口后的表述

可用贡献概括：**围绕跨采集SAR船型分类中的证据聚合，依次保留类别响应的分布形态、目标相对区域身份，并利用区域内空间与频率响应的共变关系，学习查询—参考专属的局部匹配度量。**

三者是“分布、位置、关系”三个互相关联的方法层次，不是为数量拼出的新卷积、新池化、新注意力。当前可以保留收益和模型级解释，进入论文方法与证据整理；不再为了模块名继续改结构。顶刊录用、全球首创、全部类别获胜、独立物理因果机制都不是本次收口所宣称的结论。

不恢复5%交接、稳定/因果空间、自由采样、邻船传播、地理功能区等未进入当前实现的分支。保留全部历史正负结果，不删除不利对照。未来再开实验须有明确问题，而非本轮自动续训。
