# 当前确定的 M1-M2-M3：流程、算子与代码

版本：2026-10-25。按用户选择收口：**M1 注意力版（含均值支路）、M2 池化版、M3 B 锚定的空间—频域条件化证据匹配与融合版**。这是当前研究版本，不代表三个模块所有子设计均已证明优于对照。

## 1. 先用一句话分清三个模块

| 模块 | 操作性质 | 主要回答 | 当前保留的实现 |
| --- | --- | --- | --- |
| M1 | 类别响应注意力读出 | 一张图中，对各类别有利和不利的响应如何分布，而不只看平均响应？ | 均值支路 + 高/低侧两向注意力支路 |
| M2 | 目标几何引导的区域证据池化 | 这些响应位于框内、侧向还是轴端？位置身份是否改变判别作用？ | 有效旧版 OBB 区域读出；各区域分别汇总均值与响应分布 |
| M3 | 条件化局部匹配与后期极化融合 | 查询与各类参考之间哪些局部证据可比；VV/VH 的补充分数如何合用？ | `pair_joint/both` + 独立 VV/新 VH 读出 + `anchored frequency` 调权 |

**不是“新卷积 + 新池化 + 新注意力”各凑一个名字。** 当前 M2 不保留尚未优于旧读出的新卷积/新软分配池化；M3 内的 Sinkhorn 也是现成原语，不能单凭使用它主张原创。

## 2. 整体数据流

```mermaid
flowchart TD
    I[检测 OBB + 原生 VV/VH chip] --> P[160画布裁剪或补零 + 有效区域 + C4处理]
    P --> U[既有强基础分类路径 s0]
    P --> L3[冻结 R50 layer3 类别响应图]
    L3 --> M1[M1 均值 + 两向响应注意力]
    U --> M1
    M1 --> S1[s1]
    P --> L1[冻结 R50 layer1 特征与 OBB 区域]
    L1 --> M2[M2 框内/侧向/轴端区域证据池化]
    S1 --> M2
    M2 --> S12[s12]
    L1 --> TOK[每极化20个区域局部单元 + PCA32]
    P --> F[Gabor三尺度能量 + 内容-能量共变描述]
    TOK --> RET[源参考库64张 每类检索2张]
    TOK --> KT[M3a 学习比较度量 K + 可微对应 T(K)]
    F --> KT
    RET --> KT
    KT --> E[每类: VV/VH x 3区域 x 匹配分数/匹配质量]
    E --> H[M3b 独立VV读出 + 零证据中心化VH读出]
    S12 --> H
    F --> G[M3c B锚定空间-频域极化调权]
    RET --> G
    H --> G
    S12 --> OUT[最终8类分数]
    H --> OUT
    G --> OUT
```

这不是串行的三个特征层：M1/M2 逐级补充分数；M3 另外从浅层局部特征和源参考构造关系证据，最后加到 `s12` 上。M3 没有直接把 M2 的三个汇总向量当作全部输入。

### 输入与基础路径

- 冻结检测器得到 OBB；分类研究使用离线裁片，不在本模块训练检测器。
- 当前原生分支使用160像素画布，大图裁剪、小图补零，记录真实偏移和有效范围，**不把每艘船缩放成相同大小**。这保持像素尺度，不自动统一不同数据集的米/像素。
- VV/VH 分别处理；缺失极化用有效性标记处理，不伪装成正常观测。
- C4 是0/90/180/270度旋转下的读出汇总，不是四个独立样本，也不保证对任意旋转或真实观测变化不变。
- 既有 `s0` 包含历史有效基础路径，不应把它的贡献算成新增 M1/M2/M3 收益。当前代码是冻结 R50 的多层/多缓存读出，不是正在使用两个新训练的独立骨干。
- 当前源参考库64张，每类8张；每个查询为**每个候选类别**检索2张，共16张参考。这不是使用64个目标标签。

## 3. M1：保留均值的两向类别响应注意力

### 为什么做

全局平均会把局部高响应与低响应混合。两个 chip 的平均类别分数接近，不代表它们内部的类别证据分布相同。M1保留均值，同时补充高/低侧的响应分布。

### 怎么做

1. VV、VH 分别通过冻结 R50，读 `layer3`（160输入时为1024×10×10）。
2. 将源端线性类别读出器的权重反投影到空间特征，得到每个位置的8类响应。它是分类器线性证据，不是像素级船型真值。
3. 在有效区域计算每类均值 `mu`；对局部响应去掉空间均值及共同类别分量，得到相对响应 `r`。
4. 对同一响应做两种注意力：

\[
a_c^{+}(p)=\operatorname{softmax}_p(\log w_p+r_c(p)/\tau),\quad
a_c^{-}(p)=\operatorname{softmax}_p(\log w_p-r_c(p)/\tau).
\]

\[
q_c^{\pm}=\sum_p a_c^{\pm}(p)r_c(p),\quad
h_c=(q_c^+-q_c^-)/2,\quad b_c=(q_c^++q_c^-)/2.
\]

5. 每个 C4 视图先做非线性读出，再汇总；均值支路和注意力支路一起给出类别残差，记类中心化为 `C(v)=v-mean_class(v)`：

\[
s_1=s_0+\mathcal C\big[f_\mu(s_0,\mu_{VV},\mu_{VH},valid)
 +f_a(s_0,h_{VV},b_{VV},h_{VH},b_{VH},valid)\big].
\]

**“高/低侧”是某类别相对响应较高/较低的位置，不是高频/低频，也不是船体左右侧。** 两向是对同一响应的正/负 softmax，不是 Transformer 查询—参考双向交叉注意力。

均值头7→12→1，注意力头11→12→1，合计266个参数；按候选类别共享读出。温度及标准化由源数据确定，不用查询真标签。当前注意力版自带重新训练的均值支路，不等于把旧均值模型权重原封不动搬入。

## 4. M2：区域身份保持的类别证据池化

### 为什么做

同样的类别响应，出现在框内或外围，不能默认等价。全图汇总丢失这种区域身份；但直接删除外围也可能丢掉有用信息。因此先分开读，再学习如何补充分类。

### 怎么做

1. 读冻结 R50 `layer1`，VV/VH 各256×40×40；使用这层自己的源端类别读出器，不能截取 M1 的 layer3 权重代替。
2. 根据 OBB 中心、长宽和无向长轴构造三个区域，`L/W` 为检测框尺寸：
   - 框内：`L×W`。
   - 轴端：同向 `1.5L×W` 矩形减框内。
   - 侧向：同向 `L×2W` 矩形减框内。
3. 按像素与特征网格的实际覆盖面积生成池化权重，排除补零；相反两端合并、相反两侧合并，不声称知道真船首尾。
4. **每个极化、每个区域分别计算均值和高/低响应摘要**，再将区域证据、有效性、几何质量与 `s1` 送入小读出头：

\[
s_{12}=s_1+\mathcal C\big[g(\mathcal C(s_1),\{\mu,h,b\}_{p,r},quality)\big].
\]

这是池化/证据读出，不是移动卷积核。其区域内有两向注意力式汇总，模块叫“池化”不代表只能做平均池化。当前动态区域头69→12→1，853参数。

**保留的是经过有效性验证的旧区域池化，不是后续失败的新卷积或最优传输分组池化。** 实际有效版使用船轴与 OBB；真实雷达 LOS 轴未成为这一版必需输入。OBB区域也不是精确船体分割，框内仍可能有水面，外围也可能有邻船。

## 5. M3：空间—频域条件化证据匹配与融合

M3有三段，不应只把末端的小门控称作整个M3。这里的 `B_fuse` 专指“旧VV读出＋新VH读出，源端选定固定比例”的融合基线；不与早期强基础模型B混用。

### M3a：空间—频域共同决定怎么比较、怎么匹配

对 VV/VH 分开划分20个局部单元：框内8、侧向8、轴端4。每个单元保留源端 PCA32 内容向量 `x`，不是只剩一个类别分数。

原生拉伸PNG上计算波长4/8/16像素的 Gabor 能量，各尺度先平均四个方向，再取 `log1p`。在同一局部区域，用相同有效面积权重计算内容与能量的共变：

\[
d_b=E[e_b F]-E[e_b]E[F],\qquad d=[d_1,d_2,d_3]\in\mathbb R^{96}.
\]

因此不是简单“拼接空间特征与频谱”：它记录**哪些局部内容与哪个尺度响应在区域内共同出现**。它也不是电磁频段、雷达多普勒频谱或定标RCS。

对查询单元 `i`、参考单元 `j`：

\[
h_i=P d_i,\quad h_j=P d_j,\quad P:96\to4,
\]
\[
w_{ij}=1+0.25\tanh\left(W\,\operatorname{GELU}
\left[\frac{h_i+h_j}{2},\frac{|h_i-h_j|}{2}\right]\right),\quad W:8\to32,
\]
\[
K_{ij}=\frac{\sum_k w_{ij,k}x_{i,k}x_{j,k}}
{\sqrt{\sum_k w_{ij,k}x_{i,k}^{2}}\sqrt{\sum_k w_{ij,k}x_{j,k}^{2}}}.
\]

640个参数，权重在0.75–1.25，初始为普通余弦。**这里调的是32个内容通道的比较权重，不是直接选一个频带。** 条件由查询和参考共同生成，交换两者不改变比较规则。

随后每个极化、每种区域独立求带空匹配节点的 Sinkhorn 对应 `T(K)`；区域间不互相替代。输出：

\[
\ell_{p,r,c}=\left[\sum_{ij}T_{ij}K_{ij},\ \sum_{ij}T_{ij}\right].
\]

第二项表示保留下来的匹配质量/质量总量，不是分类正确概率。丢弃空节点后不强行重新归一化；每类两个参考再取平均，得到 `8类×2极化×3区域×2统计`。

用户选定 `both`：训练改变 `K`，梯度也经过 `T(K)`，因此比较度量和对应关系同时改变。不是 `metric_only` 或 `transport_only`。

### M3b：旧VV读出＋新VH读出

每极化有6个匹配统计，拼接3个 `s12` 类别竞争量（当前类、最强其他类、二者差），形成9维输入。

- VV：保留已训练的独立读出，`delta_V = C(f_V(e_V,context))`。
- VH：采用零证据中心化读出：

\[
\delta_H=\mathcal C\left[f_H(e_H,context)-f_H(0,context)\right].
\]

两头各9→12→1、各133参数。`0` 是匹配证据原始量为零，在标准化空间用相应的非零坐标表示；不是把整张VH图减掉，也不是VV减VH。保持相同分类上下文，要求无局部VH证据时该头不额外改分数。

“分开处理”不是全系统彻底隔离两极化：两头共享已含双极化信息的 `s12` 和参考检索；只是局部匹配证据及补充读出分开。

### M3c：B锚定的空间—频域极化调权

先在源端选固定VV比例 `alpha0`，构成：

\[
B_{fuse}=s_{12}+\alpha_0\delta_V+(1-\alpha_0)\delta_H.
\]

每个查询、每个候选类别计算185维条件：

| 条件块 | 维数 | 信息 |
| --- | ---: | --- |
| 分数与可用性 | 11 | 当前分数、两路修正、类别分差、softmax、极化有效性 |
| 空间关系 | 30 | 两极化×三区域：查询与实际参考的内容相似度均值/波动、参考一致性、有效比例 |
| 频域与联合关系 | 144 | 两极化×三区域×三尺度：查询/参考能量、差异/波动、内容-能量共变相似度、覆盖率 |

185→12→1小网络在八个候选类别上共享，最后对类别输出取平均得到标量 `r_q`：

\[
\alpha_q=\operatorname{clip}(\alpha_0+0.25\tanh r_q,0,1),
\]
\[
s_{final}=s_{12}+a_V\alpha_q\delta_V+a_H(1-\alpha_q)\delta_H.
\]

只有两极化都有效时调整；否则保持 `alpha0` 并掩蔽缺失极化，不把剩余路重新归一成权重1。当前485张中416张双极化有效，69张缺VH。最终门控2245参数，初始化精确回到B。

**最终版不是等权融合，也不是逐频带开关。** 频域信息先参与 `K/T` 匹配，再作为末端条件帮助调VV/VH比例；末端每张查询只输出一个比例，对8类共用，而不是每类独立权重。它可能学成近似固定比例，不能凭结构名称宣称学会了有效动态选择。

## 8. 因果发现到底推动了什么

详细证据映射见 `CAUSAL_TO_DESIGN_ZH.md`。结论是：**干预分析推动了“保留极化/区域/尺度身份、分开读出、条件化使用”的设计；当前没有把实验发现直接写成可保证正确的物理因果规律。**

M1/M2不少结构先于相关发现存在，因此应写“发现支持保留并限定这些设计”，不能倒写成全由后来的因果发现推导而来。M3确实利用空间—频域联合描述，但当前门控没有接收逐样本真实干预标签，也未训练反事实一致性损失。
