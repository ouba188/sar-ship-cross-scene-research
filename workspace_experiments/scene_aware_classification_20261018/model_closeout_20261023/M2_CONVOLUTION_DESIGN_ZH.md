## 数据依据与待验证假设

本轮实际重看region_controls/review/case_966.png与case_1598.png，VV/VH分开。966有细长亮主体和不同强度的外围延伸，完整区域头救回而仅框内头未救回；1598也有长条亮主体及纹理外围，仅框内头救回、完整区域仍错。均为此前已报告案例，不是本轮新增推理。

这些事实支持“外围作用具有条件性”，但没有证明普通卷积混合是根因。新假设是：**除池化后保存区域摘要外，在局部特征生成时区分信息来自何种区域、传向何种区域，可能产生更适合分类的组合特征。** 原layer1感受野已混合多种输入，不能声称新算子分离了纯船体/背景。

## 1. 真正改变卷积，而不是给池化改名

输入为冻结R50 layer1特征F及现有软OBB区域图m。每个空间位置输出新特征F'，随后才进行原区域类别读出。既有M2只聚合F；新M2先学习局部特征变换。

以接收位置p、发送位置q=p+delta表示：

`F'(p) = F(p) + P_out [ (1/9) sum_delta valid(q) W(p,delta) P_in F(q) ]`

其中delta为固定3×3图像网格偏移，layer1上相邻中心相差4个输入像素；初版不改变采样位置、不旋转或缩放原chip、不声称重采样修复物理尺度。P_in将256通道压至16，P_out将16通道映回256。局部核W是可学习的、有符号的通道变换，不只是非负加权平均。

新卷积在特征网格上stride=1，输出空间大小不变；4是输入像素与特征中心间距，不是新卷积stride。P_in/P_out均无偏置，输出增量再乘接收位置有效掩膜。

选择固定像素范围是为了把“核如何融合”与“采样点如何移动”分开，不是断言3×3为最优范围。它主要作用于局部区域边界，未覆盖远距船体—外围关系；不将此前长距离区域收益直接作为该局部算子的证据。

## 2. 核怎样由目标区域关系产生

为body/end/side三种角色建立有序关系：

`R_rs(p,q) = m_r(p) m_s(q)`，r是接收角色，s是发送角色。

这里m是先按各点角色质量和归一化后的成员概率，不将软区域重叠造成的总质量变化混入角色关系。原角色总占用量单独作为有效性/质量，范围外m=0；发送和接收资格单独屏蔽，不按学习到的核权重和重新归一化。

因此“外围信息进入框内”和“框内信息进入外围”不是同一关系。软边界允许多种关系平滑参与，不由硬掩膜制造不连续跳变。

核由4个共享的、可学习深度卷积基核组合：

`W(p,delta) = sum_k a_k(p,q) diag(b_k(delta))`

`a = softmax(MLP([v_p, v_q, R(p,q), gamma(delta,u)]))`

v为压缩内容向量，MLP使用小隐层，输出4个组合系数；b_k是带符号的16通道3×3核，P_out负责通道交互。不同区域关系改变局部核的选择，内容决定在该样本上如何利用。**不是预设内容越相似越该传播，也不预设框外必须抑制。** 超参数为首个紧凑设计，不代表已经按实验选优。

gamma仅表示偏移相对无向船轴u的关系，例如沿轴投影平方、垂轴投影平方及二者乘积；u反向时同时改变两投影符号，gamma不变。区域端/侧也按无向轴合并。不要把绝对船轴角、港口ID或类别真值送入核生成器。

这保证的是OBB角度theta与theta+pi的参数化等价，不保证整图旋转不变，更不保证真实观测角改变时预测不变。继续使用既有C4流程；不宣称彻底杜绝朝向捷径。

## 3. 边界与学习细节

- VV/VH各自执行，使用各自框、有效窗口，不能直接拼像素当已配准。
- 补零和图外不作为发送证据；无有效区域的接收位置增量为0。保持固定1/9比例，不按剩余少数像素重新归一化放大边缘响应；原有效性/区域质量仍交给读出头。
- 区域联合范围之外不在本次新分支内传播；原基础路径仍保留全图。该取舍需在案例中说明，不称捕获了全部背景。
- P_in与核基非零初始化，仅P_out零初始化，使F'=F。首步P_out有学习机会，内层可能从第二步才收到梯度；不得再叠一个零标量门把整支锁死。
- 区域读出头初始化为原M2头，允许在源端配套训练；对照同样重训读出头，不能把额外训练收益归给卷积。
- 原layer1有效感受野已为35像素量级，新核不能撤销其中早已混入的背景；只能学习进一步组合。

## 4. 如何接入而不破坏已收口的M1/M3

首阶段M1与M3全部权重、M3内容token/共变描述/参考库不变。仅更新M2的新卷积分支及配套M2读出头。以原完整模型S_old为锚点：

`S_candidate = S_old + Delta_M2_new - Delta_M2_old`

新旧M2都使用同一个冻结M1输出作为分数上下文。原M3贡献按旧输入缓存保持不动，这一阶段检验的是完整系统上的M2增量替换，不声称M3也已经使用卷积后的新表示。

只有先确认新M2有收益，再另行检验新F'接入M3；届时查询和所有参考必须同时重建内容及共变描述，并在源端配套拟合，不允许只修改查询或直接沿用失配缓存。将新卷积输出同时接入M2/M3的统一特征版目前未实现。

## 5. 最少但有区分力的比较

固定源角色、查询/参考、预算与训练选择规则：

1. 原M2冻结版，以及原结构只重训读出头：区分重新训练本身的收益。
2. 同瓶颈普通3×3残差卷积：区分增加局部可学习层的收益。
3. 内容条件卷积、不输入区域关系/轴关系：与新方案保持相同核基、隐层及输入宽度，用常量占位，报告有效输入差异。检验目标几何关系的附加价值。
4. 完整区域关系条件卷积：检验新设计。

若完整卷积出现正信号，再匹配“共享通道变换、仅非负邻域权重”的聚合限制版，区分有符号、偏移相关滤波和单纯局部加权；不把门控池化自动当成新卷积的功能证据。

训练仅用合法源集；继续按既有分类目标和源选择口径，不添加未经论证的新损失。至少三配置，报告完整模型OA/BA、救回/误伤、实际参数与耗时。核系数图只表示内部操作，解释要结合原VV/VH、局部贡献替换、真实竞争类别；不将高权重当物理真因。零增量复现、theta+pi等价、补零屏蔽及梯度连通是实现必测项，失败应先修实现而非调参。

## 6. 与已有方法的差异及创新边界

本轮阅读PAC原文第3节公式1–3及其池化特例。PAC已经在标准空间核上乘内容相关核，不能把“内容自适应卷积”本身称为新发明。阅读来源：作者公开PDF https://people.cs.umass.edu/~elm/papers/PACnet.pdf （CVF直接访问403，作者PDF可读）。

SCRC-Net沿用已核验原文记录，其SCFM预测网格长宽、角度并改变采样。新设计当前不改变采样，而以**目标相对区域的发送—接收关系，条件化局部通道核，在区域汇总前组织跨区证据**。与PAC的内容亲和调制和SCFM的形状采样有明确设计侧重点差异，但尚未完成全面近邻检索/同协议比较，不能判定全球首创或强创新已经成立。

可用工作名：**目标区域关系条件卷积**。创新主张需落在区域关系如何改变特征生成及其实际净收益，而不是“新卷积”三个字。
