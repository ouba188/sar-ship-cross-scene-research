# 不大改原框架能否超过简单对照：局部成立，完整原路径尚未达到

2026-10-26。本轮完成两个公开源、三种子、18个主头训练，6个等量级参数普通头，以及12组固定匹配器的M3配套读出训练。旧模型和数据未修改。

**结论：保留原区域特征、把类别响应作为辅助，能改善同条件普通区域MLP；但固定保留旧M1/M2分数相加并没有稳定获益，接回现有M3后也未超过所有强简单对照。** 可以继续局部修正信息接口，不需要从头重做骨干；不能把“有局部正信号”报告成原完整模型已经达标。

## 1. 本轮只改什么

仍使用同一native160裁补、冻结R50、VV/VH分开提取、原框内/侧向/轴端区域。raw区域特征1536维加2个极化有效性标记；已有M2摘要72维加质量/几何32维。无新原图、外部知识、目标标签训练或检索参考。

- raw_only：原始区域特征→128隐藏层MLP，精确复现上一轮fit_only基线。
- raw_summary：原始区域特征与已有摘要拼接→128隐藏层MLP。保留区域读出和类别摘要，但不再把旧M1/M2分数加到输出中。这是信息入口/读出替换，不是全保留原M1注意力分数的模型。
- anchored_raw_summary：冻结旧M1+M2输出，叠加raw_summary网络预测的修正。该臂才是严格保留旧分数路径、增加旁路的方案。

三者fit_train训练、fit_validation选点、200步、种子17/29/43；共同raw部分初始权重相同，新增摘要列初始为0，两个有摘要的头初始参数完全相同。锚定臂允许源验证选择原路径而不启用补充通道。初始未训练的随机修正不冒充恒等初始化；零步指显式保留原路径的候选。

目标标签只在保存各候选预测后评价。raw_summary下游M3与加宽普通头在看到中间结果后追加，均固定规则，不作新盲测或目标调参证明。

## 2. 能否超过普通MLP

四分类，OA/BA百分数，三种子均值。正向1619、反向921张查询。表中各读出训练角色一致。

| 读出 | 参数量 | OSS1→OSS2 | OSS2→OSS1 |
|---|---:|---:|---:|
| 普通区域MLP，hidden128 | 197508 | 53.78 / 51.08 | 60.08 / 50.81 |
| 加宽普通区域MLP，hidden137 | 211395 | 53.33 / 51.15 | 60.08 / 50.33 |
| 原区域信息+类别摘要，hidden128 | 210820 | **53.90 / 52.41** | **62.94 / 51.69** |
| 旧分数锚定+原信息与摘要旁路 | 新增210820 | 52.81 / 49.79 | 60.95 / 52.10 |

raw_summary比原普通MLP正向+0.12 OA/+1.32 BA个百分点，反向+2.86/+0.88。参数略多的普通MLP未复现其平均表现，支持新增信息有作用，不仅是把头加宽；但这不是所有容量和优化超参数的穷尽比较。

三种子并非全胜：反向raw_summary净救回46、39、-6张；正向-4、23、-13张。按过境簇重采样、先平均种子配对差，正向OA区间[-1.23,1.34]、BA[-0.03,2.67]个百分点；反向OA[1.42,4.37]、BA[-0.84,2.71]。反向OA信号较清楚，其他指标保留为方向一致的均值信号，不宣称全部已稳定显著。

逐类raw_summary相对raw_only：正向化学品+4.71、普通货+3.63、散货-0.07、集装箱-2.97个百分点；反向散货+4.05、普通货+0.94、化学品+0.46、集装箱-1.94。不能把本轮解释为所有船型获益。

完整表在oss1/、oss2/、analysis/及wide_control/。相同训练角色区域ridge反向为63.74/54.97，仍高于新raw_summary的62.94/51.69。因此**尚未超过全部强简单方法**。上一轮pooled区域MLP使用更多源训练角色，正向55.92/53.20、反向66.52/54.10，也须保留作完整系统资源对照，不忽略它。

## 3. 接回M3是否保得住

固定原源端PairMetric、32参考和局部匹配缓存；在utility_train/selection上重训JointHead、VV、centeredVH、源端alpha和空间—频域gate。base相关输入及scaler全部重算。不是整个M3重新学习，也不是直接搬旧残差。

| 路径 | OSS1→OSS2 OA/BA | OSS2→OSS1 OA/BA |
|---|---:|---:|
| raw_summary | 53.90 / 52.41 | 62.94 / 51.69 |
| raw_summary + M3 | 54.11 / 52.56 | 60.88 / 51.97 |
| anchored_raw_summary | 52.81 / 49.79 | 60.95 / 52.10 |
| anchored_raw_summary + M3 | 52.85 / 49.86 | 60.91 / 50.94 |

正向raw_summary的收益接M3后保住且略增；反向OA损失约2.06个百分点，BA微增。这是后续利用的具体损失，不应否认前面已经获得的有用信息，也不应借前面的增益掩盖最终损失。

反向raw_summary+VV独立修正为63.41/51.75，B固定为60.80/51.94，最终60.88/51.97。源端选出的极化组合仍未充分保住VV路径的目标域OA；该观察只用于定位，不允许按目标结果改选VV。频域gate正向未新增top1收益，反向对B固定仅约+.07 OA/+.02 BA个百分点，不能宣称频域选择解决了瓶颈。

源内留采集没有同样的损失规律：raw_summary→M3在OSS1为62.43/58.38→65.61/59.72，OSS2为61.38/55.68→60.76/54.84。只看源验证最优不保证目标域组合最优；本轮未做进一步选择器开发。

## 5. 下一步应保留什么

保留“原始区域信息+类别响应辅助”的候选和已有区域组织，不立即推翻M1–M3。严格旧分数相加臂的负结果也保留，它说明“原模块全部输出必须固定相加”不应成为不可改变的约束。

下一步宜局部修改M1/M2到最终分类的接口，让原类别证据辅助原信息判别，而不是强制叠加旧分数；随后检验源端所学极化融合如何保住单支有效修正。具体新接口尚未实现，本轮不自动继续搜索模型。

当前可回答用户：**不大改骨干和区域机制，有小改动超过普通MLP的证据；严格保留原全链、稳定超过强简单对照，还没有做到。** 不要求处处获胜，但也不能以更弱MLP作为唯一比较掩盖ridge或更充分源训练基线。下一步改动可以继续围绕接口和配套训练，不需要重起整个研究方向。
