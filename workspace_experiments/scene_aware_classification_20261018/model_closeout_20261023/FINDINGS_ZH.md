# 当前模型管线、组件保留与创新定位

日期：2026-10-23。本轮为代码沿革、已完成实验与近邻文献的整合，没有新增训练、测试推理或超参数搜索。数值复用原始结果表，案例复用已完成的原图审阅；不把本轮整理写成新的实验证据。

## 1. 收口结论

可以保留已有有用组件。建议将论文主线集中到：**在跨采集 SAR 船型分类中，保留全局聚合未明确表达的类别响应分布，并利用检测目标几何保留局部类别证据的区域身份。**

当前有两个不能混写的版本：

- **V1，已有有效主候选：**冻结原分类路径与强校准，加入类别响应均值，以及分布幅度 sigma、带符号二次矩 kappa 的补充。保持其已有主候选身份。
- **V2，最新已验证组合候选：**以双向类别响应注意力替代 V1 的 sigma/kappa 读出，再加入 OBB 动态区域读出。V2 不是默认替换 V1，也不是每项指标更高。

双向注意力与 sigma/kappa 是同一信息问题的两种实现，**不是三个并列叠加的创新模块**。目前没有完成“V1 + OBB”的对应训练，不能将 V2 的 OBB 增益直接加到 V1 的数字上。

## 2. 统一的流程视图

```text
已有检测 OBB + VV/VH chip
    |
    +-- A：浅层轴向Ridge + 五点采样残差
    |       + D：剩余区域上下文残差
    |       --> 源端强校准 T(A+D) --> B：八类基础分数
    |
    +-- 冻结 R50 的 layer3 局部特征
    |       --> 源端学习的类别方向 W --> 各位置的八类响应
    |       --> 保留全局均值 mu
    |       --> 二选一：sigma/kappa 或双向注意力 h/b
    |       --> 小型类别修正头 --> V1 或注意力版
    |
    +-- V2 专用增量：冻结 R50 的 layer1 特征 + 各极化实际 OBB
            --> 框内 / 轴向两端 / 侧向两侧
            --> 各区域的类别响应均值与双向摘要
            --> 区域修正头 --> 加到冻结的注意力版分数
    |
    --> 对全部八类分数做最终决策
```

箭头表示分支连接。旧路径和新辅助读出使用同一套ImageNet R50预训练权重的不同层，而不是当前有一个SAR自监督R18第二骨干。现有实现分阶段提取/缓存，尚未实现一次R50前向共享所有旧新分支；不能据同权重推断已具备该计算效率。具体代码、缓存与骨干来源见同目录 `PIPELINE_CODE_AUDIT_ZH.md`，不套用历史“双骨干 + 64支持 + 5%交接”的旧描述。

### 基础路径也必须讲清楚

1. **A的第一部分：轴向分类。** 冻结R50的conv1/BN/ReLU得到64通道浅层特征，读取目标T、其他检测O、剩余区域R，以及沿船轴分段的响应摘要。796维描述经源标准化和Ridge产生八类分数。它已经不是纯粹忽略区域的GAP基线。
2. **A的第二部分：五点采样补充。** 同一浅层图上读取中心及两个参考方向的正负偏移，使用既有keep_refs残差头修正轴向Ridge；代码保留船轴/雷达参照入口。它不是64个支持案例，64是特征通道数；也不能把旧参照入口写成本轮新OBB已使用真实轨道雷达轴。
3. **D：剩余区域上下文。** R排除目标T和其他检测O；分开读取区域内相对响应与显示均值，双极化摘要经260→32→8小头补充A。该旧模块已在历史实验中接入，本轮随基线冻结，未重新验证它在最新组合中不可替代。
4. **B：强分数校准。** U=A+D；将U的类别中心化、源标准化分数输入8→16→8普通MLP，再把输出加回U。记为B=T(U)是整体映射简写，T不是单一温度，也不是把A/D拼成16维再融合。

新模块收益均在这个已有区域/采样能力的强B之上计算。不能把B描述成“完全不看局部或背景”，再据此夸大新增模块。

当前是单 chip 分类研究；OBB 及来源元数据可作为输入。旧A/D的view与新aux的native窗口都使用原像素160裁剪/补边，但输入来源及区域组织不完全相同，不能把它们说成已核实逐像素一致。原图不resize不等于特征采样不插值。VV/VH各自处理几何与有效性，不假定两极化的裁片框逐像元一致。C4为四次旋转及对应区域变换后的读出汇总，不是让标签由绝对船轴角决定。

没有加入大景邻船类别传播、港口功能区先验或未知类拒识；本轮新OBB没有加入真实雷达轴条件化。旧五点采样的方向参照入口另行保留，不据此宣称已证明真实雷达条件化的独立收益。当前输出仍是八类分数；实际预测可能只覆盖其中部分类别。检测误报并不会因八分类器存在而自动得到解决。

## 3. 核心一：类别响应分布读出

### 3.1 为什么做

全局均值相同，不代表响应在各位置上的起伏相同。现有模型已含复杂非线性特征，不能说它完全没有空间信息；更准确的问题是：**在现有分类分数与均值之外，显式保留响应分布是否仍有可用增量？**

### 3.2 已实现什么

对每个极化的局部特征 F(u)，使用源端类别读出方向 W：

`z_c(u) = W_c^T F(u)`，`mu_c = sum_u w(u) z_c(u)`。

之后去掉位置上的均值，并去掉位置处各类别的公共响应，得到相对响应 q。均值 mu 单独保留；q 不是雷达散射系数，也不是已分离的因果特征。

V1 用：

- `sigma_c = sqrt(E_w[q_c^2])`：响应相对均值的起伏。
- `kappa_c = E_w[q_c |q_c|] / max(sigma_c, epsilon)`：高、低侧平方响应的偏向。它不是常规定义的三阶偏度。

V2 的替代读出用（均值支路也与新注意力支路一起重新训练，不是复用V1均值头权重不动）：

- `alpha_plus/minus(u,c) ∝ w(u) exp(±q_c(u)/tau)`。
- 分别加权读取高、低侧响应，得到 q_plus、q_minus。
- `h=(q_plus-q_minus)/2`，`b=(q_plus+q_minus)/2`。

高、低侧指学习到的类别响应的相对位置，不自动等于“真类正证据/假类负证据”，也不是两个 Transformer 之间的交叉注意力。温度按源端规则确定；分类头同时读取所有类别，预测时不用真实类别选择通道。

共同接入方式是：`B=T(A+D)`，`s = B + Delta_mean + Delta_distribution`。V1 的分布输入是 sigma/kappa，注意力版是 h/b。保留 B 能测试额外读出的净增量，但不自动解决 B 原有的背景依赖。旧D随基线保留以维持匹配比较；本轮没有在最新完整组合中重新证明D不可替代，不能把继承D也算作一项新成立的核心贡献。

### 3.3 为什么保留

已有均值对照、sigma-only/kappa-only、注意力 high-only/low-only、匹配 donor 摘要替换和模型响应层干预。它们支持“本图的分布摘要有小幅、条件性的增量”，不是只因新增一个头就涨点。

注意力对 high-only 平均 OA/BA +0.183/+0.261 个百分点；对 low-only 平均 OA 相同、BA +0.398。它尚未稳定超过 V1，因此保留为替代实现，而不是依据名称更复杂就升级。

注意力原图解释中，5030 的主要救回来自均值，注意力只补强分差；7310 的均值先误伤，注意力略加重。不能把完整版本的一切翻转都归给注意力。layer3 的感受野可能覆盖整张 chip，响应格也不能直接叫“纯船体格”或“纯背景格”。

## 4. 核心二：目标几何引导的区域类别证据读出

### 4.1 为什么做

全图分布仍会丢掉响应的目标相对位置。新增问题是：**相似类别响应出现在框内、轴端或侧向时，保留这一区别能否改善已有分类器？** 旧A已经包含T/O/R和船轴分段，因此不是首次在本模型中使用区域。新增的是在layer1的源监督类别响应坐标中，按目标相对区域分别保存均值与高低侧分布，而不是只在stem通道特征上做旧摘要。

这不预设外围都是尾迹或环境，不预设外围都该删除，也不预设靠近的船类别相同。框外可能含目标延伸、海面、设施、其他船或伪影，具体案例必须回到原图解释。

### 4.2 已实现什么

- 在冻结 R50 的浅层 layer1 特征上读出；当前160画布对应40×40特征网格，步长4，理论感受野35。
- 依据检测 OBB 的中心、长宽与无向船轴建立框内、两端合并、两侧合并区域；没有可靠首尾标签，不将两端命名为船首/船尾。
- 轴端范围来自1.5L×W矩形减去框内；侧向来自L×2W矩形减去框内。这是当前实现选定的有限区域，不是已证明最优的物理边界。
- VV/VH 分开读，边界软化并处理缺失/小区域；公共输入包括区域有效性、质量等。
- 每个区域用源端浅层类别 reader 生成八类响应，再保留 mu/h/b。该 reader 不是把深层2048维权重直接施加到256维浅层特征。
- 共享的小型类别修正头输出 Delta_region，加到冻结的注意力版分数：`s_V2 = s_attention + Delta_region`。

当前新增区域头853参数；它不包含骨干及前置读出器的全部成本。虽然头小，也不能把缓存推理耗时当作端到端耗时。

**它是 OBB 引导的区域池化/证据读出，不是新卷积，也不是可学习采样位置。** OBB 的“动态”指区域跟随输入目标几何，不是网络学会自由移动采样点。当前没有使用真实雷达观测轴，不能写成已完成的船轴—雷达双轴模块。

### 4.3 已有证据

|匹配比较|OA差(pp)|BA差(pp)|支持的结论|
|---|---:|---:|---|
|动态OBB vs 冻结注意力版|-0.035|+0.483|在该任务中偏重类别均衡的净补充|
|动态OBB vs 固定尺寸模板|+0.246|+0.532|实际目标范围组织有价值|
|有区域身份 vs 训练/测试均置换区域槽位|-0.119|+0.498|稳定区域身份对BA有价值，OA有取舍|
|完整区域 vs 新增通道仅框内|-0.063|+0.289|外围有条件性补充，不是处处增益|
|完整区域 vs 框内+端部|+0.963|+0.455|不能凭某一外围单项代表完整作用|
|完整区域 vs 框内+侧向|+0.302|+0.374|同上|

置换对照保持相同名义输入维度和头参数，公共质量输入仍保留原序，因此不是彻底不可恢复的区域身份删除。仅框内对照的有效输入维数更少；不把零列造成的名义等容量称为完全等信息。多数聚类置信区间跨0，当前为有边界的正信号。

原图回看中，966的侧向摘要参与救回集装箱船，而2217的外围摘要参与误伤化学品船；1598的框内-only补充能救回，完整区域仍错。说明模块确实改变具体判别关系，同时存在使用边界。摘要干预不是像素级干预，更不能独自证明某种物理散射原因。

## 6. 各组件的创新性判断

这里衡量与最接近方法的新增差异，不给武断的“顶刊分数”，也不要求没有任何先例。

|部分|保留方式|创新性判断|
|---|---|---|
|旧A轴向/五点采样与D上下文|冻结基线组成，保留历史收益|有任务化设计，但本轮未重新隔离其最新组合增量，不重复计作新贡献|
|强分数校准|共同基线|通用方法，不列核心创新|
|VV/VH分开、C4、有效掩膜|支撑设计|有价值但已有充分先例，不单列创新|
|源类别方向投影、响应均值|分布读出的组成部分|单独较弱；类别响应注意力已有先例|
|均值保留+相对类别响应sigma/kappa|V1主候选|有实质任务化差异，可作为核心方法之一；不是首创二阶统计|
|双向类别响应注意力h/b|V1的可替代实现|有意义的读出改造，但与CSRA近；不作为与分布模块独立的第二大发明|
|OBB区域类别证据读出|V2有边界的核心候选|当前最值得发展的结构性贡献：目标相对区域身份与类别分布共同读出|
|小残差头、零初始化、源验证回退|训练与接入方式|通用实现保障，不当创新点|
|原图+响应干预+救回/误伤分析|贡献证据链|研究价值明确，但不自动称新解释算法或新评价指标|

### 与近邻工作的差异

- **CSRA（ICCV 2021）**已有分类权重投影、空间softmax和GAP残差结合。我们的可讲差异在于保留均值后的高/低侧相对类别响应及其条件增量，而不在“第一次按类别做注意力”。
- **GSoP（CVPR 2019）**已有全局二阶信息和通道/位置重加权。我们的读出在源监督类别坐标中进行，并把分布补充与均值、原分类分数的贡献分开验证，不是发明全局高阶统计。
- **CPINet（Remote Sensing 2024）**已有双极化、一二阶统计与局部交互。双极化本身不构成新的核心。
- **SCRC-Net（Pattern Recognition 2026）**已有预测长宽/方向的结构约束卷积采样，也讨论语义背景，不能说前人一概认为背景无用。我们改变的是冻结特征的读出组织，显式保留框内/轴端/侧向身份，再验证它对跨采集类别判别的贡献；不是再提出可旋转卷积。

可用的贡献表述：

> 我们研究跨采集SAR船型分类中的类别证据聚合问题。在保留已有分类路径的基础上，将局部响应映射到源监督的类别坐标，区分全局均值与响应分布的互补作用；进一步利用检测目标几何组织框内及方向性外围区域，使目标相对位置在聚合后仍可参与类别判别。通过合理读出替换、区域身份扰动及原图案例分析，识别有效增量与退化条件。

这是可保留、可发展的贡献定位，不是已经确认全球首创或达到顶刊录用要求。最近邻方法在同协议下的直接比较和独立采集验证仍决定论文论证强度；无需因此否认已有小幅有效模块。

## 7. 从主线移出什么

不纳入当前完整模型：5%专家交接；因果/稳定隐空间分离；未证实的雷达条件化新卷积；自由形变采样；动态频带切换；邻船类别传播；地理功能区先验；开放集拒识。旧五点采样仍保留方向参照，不与这些退出/未实现路线混淆。保留历史记录，不删除负结果。

不作为独立有效升级：单独端部、单独侧向；其平均目标收益并不支持这样定位。保留框内-only、普通浅层global作为合理简化对照，不能因其结构简单就排除。

当前不再为了模块数量增加结构。先使用 **“类别响应分布读出 + 目标相对区域读出”两项主要方法贡献** 组织论文，其他部分解释为这两项工作的必要支撑。若最终选V1，则OBB只能作为扩展候选报告；若选V2，则报告其真实OA/BA取舍，不能写成对V1全面替代。
