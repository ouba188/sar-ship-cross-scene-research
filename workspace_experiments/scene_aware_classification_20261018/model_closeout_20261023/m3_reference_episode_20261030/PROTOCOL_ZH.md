# M3源参考episode组织验证

预设目标保持两数据集额外分类净收益，非只改变中间量。M1/M2/骨干/分类头不变，不增参数，只训练原M3非reader参数131446个。源查询与每步顺序、CE+.1正确教师KL、AdamW1e-4、54/96步和每步16查询均沿用前轮CE。

实际数据依据：上轮原图31141、OSS2 003764显示同类参考形态覆盖差异；上轮新增变化仍以共同类别偏移为主。此前静态换库已经试过且未改善两边任务，因此不再重复静态换库当新方案。新假设是训练时更换参考可减少固定库适配，但未证明为根因。

原文基础：Matching Networks for One Shot Learning，arXiv1606.04080，PDF第4页§2.2已通过requests+PyMuPDF实际读取。作者按episode抽支持S与查询B，使训练匹配支持条件预测。我们仅借鉴参考变化训练，不迁移其新类别任务结论，不称episode训练原创。Web工具此次无可核验返回，原始URL记录为https://arxiv.org/pdf/1606.04080；不引用工具无返回时生成的引用占位。

参考池只用source_fit，自建1205、公开478。每类均匀抽船、船内均匀抽观测，同一库同类不重复船；预算保持原16/32。fit与adapt船和过境互斥；不利用开发查询类别或外观选库。

- 对照CE：前轮同一原库每步训练，复用已有端点。
- fixed_alt：偶数步原库，奇数步同一组新源库。
- episodic：偶数步原库，奇数步重新抽新源库。第一组与fixed_alt完全相同。

三者均在原参考库评价，原库教师预测不随episode更换，因此KL保护原部署预测；这个保持项可能限制变化，是共同固定设定，不按目标调参。新臂用到更多源参考观测，不能称等数据暴露；每步参考数量、梯度次数、查询相同。收益若出现，是训练组织与覆盖的共同收益，不能提前分解。

先两数据集seed17。仅若出现相对CE/原版值得验证的分类或风险信号，再固定配置扩17/29/43，不开额外倍率/学习率扫描。原版对4组源库的源端预测变化先保存，能验证参考输入是否实际影响输出；不把源变化视为泛化证明。

检查针对：参考来源/预算/独立船是否正确、旧基线是否逐值一致、未训练参数是否保持、保存重载/原chip前向是否一致；出现不符就修实现再比较。不用最终测试标签选参数。每轮回看四状态原VV/VH与实际原参考，保留负结果。
