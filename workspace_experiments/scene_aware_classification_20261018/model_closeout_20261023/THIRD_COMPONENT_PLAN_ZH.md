# 第三组件候选：跨采集区域效用学习与证据协调

日期：2026-10-23。状态：设计候选，未训练、未证明涨点，不改变当前V1/V2保留决定。本轮实际重看966/1598的VV/VH与区域面板，复用其他已完成案例、控制结果及有限历史设计审查。没有把两例当作总体收益估计。

实施续记（2026-10-23）：用户已授权源内pilot，实际协议见 `regional_utility_pilot/PROTOCOL_ZH.md`。以下保留原设计；其中单策略逐类概率误差效用在真实协调器训练前已修正为“固定等权背景下，替换一个类别分数后的完整八类Brier改善”，避免监督对象与实际融合操作错位。最终执行状态、结果与保留决定以pilot的FINDINGS为准，不能把本页初始“未训练”当作后续状态。

## 1. 推荐方向

前两项分别解决“类别响应读出什么”和“按目标的什么位置读”。第三项尝试解决：**面对当前类别竞争，采用哪一种已存在的区域组合，预计能改善判别，而不是仅提高置信度？**

工作名：跨采集区域效用学习与证据协调。它是学习机制和决策组件，不是新卷积。不为凑三个模块将普通门控重新命名；若只增加一个摘要MLP而没有独立增量，则不能立为第三创新。

## 2. 数据依据与剩余未知

- 966，Port Klang，集装箱船对化学品船：冻结注意力基底分差-0.0721，完整区域+0.1628，body-only -0.2453。完整区域救回，不能以“外围不赞同框内”为由压掉外围。
- 1598，Santos，散货船对集装箱船：基底-0.2780，完整区域-0.2812，body-only +0.6202。body-only救回，完整区域没救回；不是完整区域把原先正确的基底改错。
- 两例VV/VH均见长条亮主体、外围纹理和不同程度延伸，两极化和三区均有效。图像可见差异不能直接推导哪组证据可靠，仍需利用源端样本学习；不把亮延伸命名为尾迹/旁瓣。
- 配套训练中完整区域相对body平均BA+0.289pp但OA-0.063pp，说明存在取舍；不同头的独对集合只给出选择空间线索，尚未证明这份空间能够被输入信息预测。
- body_end/body_side的源验证收益部分在目标反转，提示普通训练内置信度不是足够的可靠性依据；这不是已证明的唯一根因。

## 3. 不重复三类旧路线

1. 旧内容/几何门控已经试过，正确几何没有独立稳健收益；留船OOF还出现内层D零、外层D非零的任务失配。不能简单再接gate(B,quality,区域)。
2. OSS2的28类对反对称头已经有paired与marginal三个seed top1一致的负结果；本候选不再以反对称类对边本身作为新意。
3. 不把与B一致、VV/VH一致或C4一致当作正确性。外围有价值时恰可能反驳B；C4不是独立观测，当前平均缓存也不能恢复各旋转方差。

## 4. 最小可实现结构

### 4.1 三个区域策略，复用同一套特征

先只保留三个候选输出，不追加两个已表现不稳的单外围头：

- s0：冻结的双向注意力基底，不增加OBB修正。
- sB：基底加body-only区域补充。
- sF：基底加完整body/end/side区域补充。

body-only仅指新增OBB通道；s0仍含旧A/D的上下文，不能称纯船体模型。三个输出共享可复用的骨干/区域缓存，不是训练三个独立骨干；现有实现尚需单独测量实际推理开销，不能直接称零成本。

### 4.2 真正改变的是监督

在合法源端留出观测i上，用同一固定概率转换规则得到各策略概率p_k。定义相对s0的逐类Brier改善：

`u_i,k,c = (p_i,0,c - 1[y_i=c])^2 - (p_i,k,c - 1[y_i=c])^2`。

正值意味着该策略改善了类别c的概率误差，负值意味着损害；u_0,c=0。这是当前模型/概率转换下的实测预测效用，不是物理因果真值，也不保证top-1改变。全类别平均效用用于辅助解释，最终仍评价OA/BA和完整系统。

选择这种软效用而非“谁判对就选谁”，是为了保留没跨决策边界的变化、以及候选同对/同错时的差异。它可能偏向概率校准，因此必须与相同结构、仅分类损失的版本比较，不能只报告效用拟合变好。

### 4.3 输入与输出

小学习器读取预测时确实可获得的内容：各候选八类分数、类别与竞争类别的分差、VV/VH的区域mu/h/b及有效性/质量。对所有八类使用共享规则，不用真实标签选择竞争者，不输入MMSI、采集ID、港口名或原始经纬度。

它对每个候选类别输出三种策略的权重w_k,c，softmax在策略维归一化。可以用以下固定融合接口：

`s_final,c = s0,c + sum_k w_k,c * (s_k,c - s0,c)`。

这里包括空修正策略k=0，因此允许退回s0；但不保证该回退一定正确。与一张图一个scalar不同，不同类别的竞争可以采用不同策略。这种逐类融合也可能把不同策略的错误拼起来，所以不能仅靠结构直觉认为它更可靠。

先用源留出u训练一个效用预测头，再以完整分类损失联合约束。候选区域分类头在该阶段冻结，避免一边改变教师效用、一边追逐移动目标。效用损失权重和温度只在源端预先限定少量选择；不在旧目标队列反复搜参。

## 5. 最关键的划分与训练要求

效用标签必须来自没有用该观测标签拟合的上游预测。当前辅助reader OOF不等于T、attention、OBB整栈OOF，不能直接将训练内预测当可靠效用监督。

首个小验证在源数据内做三个角色：策略拟合采集、效用学习采集、协调器验证采集；用过境组并按MMSI处理身份隔离。冻结ImageNet骨干与检测器，缓存特征可复用；所有使用标签拟合的reader/校准/小头必须遵守该轮排除关系，不能仅重训最上层门控。

先清点这些组的类别交集、独立船数、候选非零头与分歧数量，再确定可比较类范围。跨采集比较同时报告类别等权与原分布结果，避免把类组成变化误当条件迁移。少样本类可保留在总分类任务中，但不能以几例效用标签声称学出该类规律。

如果既有缓存不满足这些关系，需要重建相关小头预测，而不是重提全部骨干或修改检测器。源选择到0步的区域头本身没有区域增量，应记为无效用/平局，不给它编造区域贡献。

## 6. 最小对照与判断

1. 当前固定完整区域版与body-only版，保留为单策略参照。
2. 源端选定的固定融合，检查普通平均能否兑现互补。
3. 同结构、同输入、同训练预算的协调器，仅用分类损失。
4. 同一协调器增加跨采集留出效用监督，这是候选第三组件。

四组使用相同图像范围、类别、候选分数、预测转换与数据划分。比较源端未参与效用学习的采集上的效用排序/回归，以及实际OA、BA、Brier、救回/误伤和成本。不能只以“更像效用标签”替代系统增益。

已知标签下的最佳策略只能用于源端离线诊断，并明确为不可部署的选择上界；逐类概率上界不是OA上界。若候选几乎没有独对样本，则缺少选择空间；若空间存在但学习器不超过固定融合，则是空间尚不可利用，而不是默认需要更大网络。

按用户的任务化标准，部分采集/类别有可重复、值得成本的净收益即可保留；不要求处处获胜，也不要求解释成确定物理机制。若同结构仅分类损失已达到同样效果，则保留简单实现，不把效用监督硬立成创新。

冻结方案后才到目标队列确认，历史4744目标仍是开发验证而非独立盲测。不得用966/1598的测试真值训练权重。实验结束按既有规则回看新救回、误伤、持续正确/错误的VV/VH原图，并检查实际权重和分差，而不是仅展示注意力热图。

## 7. 文献基础、阅读范围与差异

本轮web搜索部分请求返回空；原文通过官方arXiv PDF内存解析阅读，没有保存或上传论文全文。以下只标注实际读到的范围。

- **Cruz et al., META-DES: A Dynamic Ensemble Selection Framework Using Meta-Learning, Pattern Recognition 48(5), 1925–1935, 2015, DOI 10.1016/j.patcog.2014.12.003。** 原文arXiv:1810.01270，第4–12页实际阅读，包括3.1/3.2/Algorithm1；未读完29页。它用独立meta训练集，根据分类器行为与邻域等信息学习competent/incompetent，再选分类器投票。不能说“学习谁可靠”首次提出。我们的候选不是通用bagging池或目标近邻标签选择，而是共享SAR区域读出上的body/full策略、逐类连续效用、跨采集监督。
- **Mozannar & Sontag, Consistent Estimators for Learning to Defer to an Expert, ICML 2020, PMLR119:7076–7087。** 原文arXiv:2006.01862第1/3/4页实际阅读，含问题公式和代价敏感归约；未读完一致性证明。借鉴优化实际决策代价，而不是将模型置信度当作唯一采用标准。我们的多个区域读出没有外部专家私有信息，也不恢复5%交接，不能继承论文一致性定理。
- **Li et al., Learning to Generalize: Meta-Learning for Domain Generalization, AAAI 2018, arXiv:1710.03463。** 原文第3–5页实际阅读，Algorithm1/式1–9及部分实验；源域拆meta-train/meta-test并优化跨域更新。这里只借鉴源内模拟未见域的训练原则，当前首轮不直接实现二阶MLDG；不能把普通分采集验证叫作已实现元学习算法。

可发展的novelty：**把目标相对区域的类别响应从“有内容就融合”，推进到“以跨采集留出上的实际判别改善监督其采用”，并区分不采用、框内补充和完整区域补充对不同类别竞争的价值。**

差异有意义，但仍是候选贡献：若结果只等价于普通动态集成，或效用监督没有独立增量，就应归入现有读出模块的训练改进，不为数量硬称第三大发明。
