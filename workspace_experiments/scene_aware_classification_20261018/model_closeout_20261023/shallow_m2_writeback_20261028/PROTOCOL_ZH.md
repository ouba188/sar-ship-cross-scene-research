# 浅层 M2 区域池化回写：配对可行性实验

2026-10-28，结果产生前确定。保持已交付默认模型和原结果不变。

## 问题与数据依据

现有 M2 在 layer3.5 回写，在 layer2 与 M3 后做区域读出。较浅区域特征虽然进入末端分类，但没有影响后续卷积如何形成特征。新实验检验：在细网格中先聚合框内/轴端/侧向证据并回写，是否改善后续特征和完整分类。细网格可保留更细位置差异，但区域掩膜仍只是位置占比，不是纯物理船体分割；不能预设更浅一定更好。

保持原生160裁剪/补零、VV/VH分开、原OBB区域、原Gabor尺度和同一参考集。layer1输出40×40、256通道，layer2输出20×20、512通道。本轮只在阶段输出、下一阶段卷积之前插入，不改变阶段内部卷积或下采样。

## 四组

- baseline：原完整M1/M2/M3，给予相同追加训练机会。
- layer1：原模型 + layer1末端M2池化回写。
- layer2：原模型 + layer2末端M2池化回写。
- both：原模型 + layer1和layer2末端M2池化回写。

新M2复用已实现RegionPoolWriteback，每极化独立参数，三区域各自变换后只回写相应区域。输出投影零初始化，不同时堆叠零增益。新增两层意味着更多参数与计算，不能把both比较解释成纯位置控制。

## 优化与隔离

统一起点为已交付 `weights/teacher.pt`，不是已适配模型继续训练。136条source_adapt、原101条useful选样、16条源参考、160条复用开发样本。原始教师分差下界与选样固定，不通过开发标签选样或调学习率。

三训练顺序种子17/29/43；每组6轮、有效batch16、54步，固定末轮。局部三个卷积lr3e-5，新增M2 lr3e-4，AdamW weight_decay=.01。原M1/M2/M3、分类头和BN冻结。全部源样本CE + .1教师判对KL + .3683066666选中样本原教师单侧分差下界。各组优化器统一重建；不是恢复历史优化器状态。

微批累积时按该有效batch全部样本权重和归一化，与直接batch损失一致。查询/参考都经过相同新增M2；参考活跃内容每次前向重新计算。冻结卷积仍保留输入梯度。只缓存新增模块之前的layer1以及原始冻结比较锚点。M3的layer2/深层比较描述保持原模型锚点，避免同时改变比较规则。

资源调整：微批4下baseline17完成54步但耗时303秒，其记录保留在micro4_resource_pilot；baseline29在18步后因合并微批而中断，不作为结果。独立资源探针显示both在完整batch16下前后向显存约2041MiB、热身后约1.96秒，因此主比较全部统一重跑batch16，无微批拆分。未据开发准确率更改设置，训练数学目标、样本顺序、54次更新和超参数不变。
