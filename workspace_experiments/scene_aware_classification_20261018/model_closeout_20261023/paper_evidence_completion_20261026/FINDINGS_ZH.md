# 论文证据补齐：阶段结果与下一步

2026-10-26。按“公平基线→模块替换→参考稳健性→机制连接→成本”推进，本轮均有实际结果；独立多折重训和完整链替换仍未完成，不能写成论文证据全部齐备。

## 先说结论

**已有组件确实有可保留的局部、类别和任务收益，但目前不宜把M1–M3整套模型直接写成优于强简单方法的最终方法。** 本轮补上强对照后发现：普通OBB区域特征加线性/MLP，在公开数据和双向迁移中经常更强；24港3075扩围中，完整模型与同总标签的区域MLP接近。这个问题比再加一种注意力更值得优先解决。

不是把历史收益推翻：原有相对旧基线的改进仍然成立。新的证据改变的是比较范围，以及能否将收益归于我们特定的类别响应压缩、区域组织和匹配设计。

## 1. 公平基线已补：强简单方法不能遗漏

冻结同一R50、原像素160裁补、C4、VV/VH、相同检测队列。区域基线用layer1原始256维特征，按框内/侧向/轴端质量加权均值，再接ridge或128隐层MLP；没有M1类别投影和M3案例匹配。它与完整模型共享OBB几何，因此结果不是“区域信息无用”，而是“直接读出区域特征已经很强”。

两种源训练口径同时报告：

- **pooled**：fit_train+utility_train训练，fit_validation+selection选点，覆盖整套模型可用的相同源标签总量，但改变了分阶段优化组织。
- **fit_only**：只用fit_train/fit_validation，与M1/M2训练角色一致。用于检验优势是否仅来自直接头看到了更多标签。

MLP固定200步、3种子17/29/43；ridge固定6个源端alpha候选。所有目标预测先保存再评价，不在目标上选最优结构、训练角色或种子。公开集均为四分类，不冒充八分类或全数据集无筛选评估。

另补全局layer3、多层layer1+layer3、局部原型、区域合并原型、DN4式image-to-class top-k余弦，以及与s12共用残差头的匹配对照。**DN4为冻结特征算子对照，不是原论文完整训练复现；DeepEMD没有在真实队列上运行，不计作已完成对比。** DN4残差的跨域OA/BA为50.44/46.59、61.13/51.81；没有解决强简单读出的差距。

数据：`stage1_analysis/main_table.csv`含所有方法均值/标准差；`all_metrics.csv`含原始逐种子值。24港见`regional_24port/*/metrics.csv`和`analysis/`。NLL/Brier也保留；普通头用原始softmax、局部独立匹配另做源端温度选择，不能把这些概率分数都当成统一校准后结果。

## 3. 参考抽样已补：存在实际敏感性

每源3次独立合法源船抽样，每类8张、共32张，搭配原3种子模型，保持源PCA、尺度和全部权重冻结。没有目标标签参与选参考。

| 队列 | 换参考后完整模型平均OA/BA变化，百分点 |
| --- | ---: |
| OSS1留出 | -3.17 / -0.63 |
| OSS1→OSS2 | -3.10 / -2.39 |
| OSS2留出 | -1.23 / -1.49 |
| OSS2→OSS1 | -0.18 / +0.61 |

**这是固定模型换库敏感性，不是换库后配套训练。** 不能把9个配置当9套独立训练或9个独立目标域。它说明原代表性参考库与学习到的读出有实际关系，尤其OSS1来源模型不能假定随意换库都保持收益。新采集折和换库后重训仍是未完成项。

## 4. 最终M3干预：区域证据有作用，频域调权额外作用小

在最终模型的局部匹配统计处，分别置零VV、VH、框内、侧向、轴端证据，重新计算对应读出与分数相关门控。另把频域门控输入标准化后置零，即源均值中和。没有修改图像，不是模拟真实散射条件，也不是配套重训消融。原模型回放误差受检查且预测一致。

| 干预 | OSS1→OSS2 OA/BA变化 | OSS2→OSS1 OA/BA变化 |
| --- | ---: | ---: |
| 去框内匹配证据 | -1.07 / +0.02 | +0.07 / +0.61 |
| 去侧向匹配证据 | -1.24 / -0.24 | -3.94 / -2.34 |
| 去轴端匹配证据 | -5.68 / -4.26 | +0.04 / +0.98 |
| 去VV匹配证据 | -1.54 / -1.07 | +0.14 / +1.50 |
| 去VH匹配证据 | -0.80 / -0.30 | -0.04 / -0.01 |
| 中和频域调权输入 | -0.02 / -0.03 | +0.07 / -0.11 |

可确认：固定模型在部分方向确实依赖特定区域的匹配证据，移除后会产生真实损失。也存在移除后改善的情况，表明依赖不等于净收益。频域门控输入的额外作用小且不一致；不能把“整个频域匹配都无用”作为结论，因为这里只中和了门控输入，没有移除M3匹配本身的频域成分。

这补上的是**模型内部证据→读出→预测变化**，不是物理因果定律。侧线干预推动分极化、分区域设计的价值可以写；“已发现普适因果因素并因此提升泛化”仍不成立。

## 5. 原图回看与运行成本

本轮回看包括公开强对照16张VV/VH+实际参考面板、24港4张、模块替换4张组合图，以及参考变动/最终读出干预的补充图库。各组均包含独对、误伤或双对/双错，不只挑成功例。完整路径/种子/预测/参考见各cases.json。

原图给出的共同事实：同类和混淆类都可能出现端部强亮、连续/分段细条；VV/VH的目标和周围响应不相同；部分查询有明显外围结构，但简单模型的独对并不限于复杂背景。**因此当前不能把所有失败归到朝向或背景，最需要定位的是直接区域特征进入类别响应压缩和参考校正后，哪些判别信息未被保住。** 这仍是待区分的解释，而非已确认根因。

成本测量为独立8类/64源参考工程：RTX5050 Laptop、batch1、8个实际chip×3次、预热后，每次重新读取图像和提特征；不使用查询缓存。排除检测和首次模型加载，包含图像I/O。

## 下一步只解决一个核心问题

**冻结上述强对照和任务，检验“直接区域特征中的分类信息，是否在类别响应压缩或匹配校正中被削弱”。** 最小设计是同一源训练角色、同一区域输入、相同选择协议，比较直接区域读出、类别响应读出、以及只接一个已保留模块的配套训练；先定位损失发生在哪一段，再决定补信息、改训练还是简化路径。不能先假定压缩就是根因。

明确保留：已观察到的条件性模块收益、分极化与区域可追溯设计、正负例和原始结果。明确不宣称：现模型整体领先强简单方法、频域门控必需、三个模块已分别证明原创并不可替代、已完成所有独立泛化确认。

仍待补的论文必要项：强基线上可重复净收益；完整链配套替换；独立采集折重训；最接近已发表方法的同协议复现/差异论证。先解决第一项比继续扩展低辨别力重复更重要。本轮没有自动重构主模型、覆盖原权重或启动无限调参。
