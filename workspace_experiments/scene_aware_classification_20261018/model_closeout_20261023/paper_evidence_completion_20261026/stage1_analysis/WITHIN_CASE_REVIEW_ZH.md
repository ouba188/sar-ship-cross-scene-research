# 第一阶段 within 原图回看

2026-10-26 已用 `view_image` 实际逐张查看本目录 8 张 `*within*.png`，并核对 `cases.json`、`analyze_stage1.py` 的抽样与 reference 含义。未查看/重复主代理负责的 8 张 cross 图，未进行新实验。

## 口径

本组比较是 `classical/regional_mlp`（原全源监督组织）与 `ours/frequency` 的完整 M1–M3 预测，不是 `classical_fit_only`，也不是本支线的 M1/M2 替换结果。所有案例固定 seed17；每个结果组按两模型真实类 margin 差的绝对值最大选取，是事后代表案例，不是随机样本，不能用于估计现象比例。

图中 QUERY 是 native160 裁补后的输入，VV/VH 分开，`input_scale=1.0`；黑色补边不是海面。表中目标像素数是检测 OBB 掩膜面积，不是人工船体像素面积。路径及 placement 的完整凭据在 `cases.json` 的 `provenance`，每例前两个条目为查询，随后为四张参考各两极化。

TRUE REF 与 RIVAL REF 是本次 **M3 实际检索的同类和竞争类参考**。JSON `refs` 是表行索引，图标题是观测 ID，下文使用图中观测 ID。RIVAL 是完整模型最强非真实类，不一定等于 MLP 的预测，例如 OSS1/595。MLP 没有读取这些参考图，不能用“更像某参考”解释其推理路径。

两模型分数尺度不同，以下 margin 只记录各自真实类对最强其他类的有符号分差；不能把跨模型数值差解读为校准置信度、模块贡献或证据增强量。M1–M3 判对也不自动证明是 M3 救回，尚无逐阶段干预支持这种归因。

### 595：有 VH 图像，但无有效 VH 目标框

已查看 `oss1_within_ours_only_595.png`。VV 为很小的近竖直亮目标，背景与船内结构可读信息少；VH 仍可见近竖直亮条及沿竖向延伸，但没有绿色目标框。JSON 确认 VH `target_present=false`、目标掩膜为零，不能描述成“双极化目标局部匹配共同救回”。

M3 同类参考为 474、759，竞争 container 参考为 748、174。同类参考一张很小、一张更长，竞争参考也包含短亮条与长亮目标，外观与尺寸存在交叠。可保留结论是：此小目标/单有效目标极化条件下，完整模型判对、MLP 判错，且完整模型 margin 只有 +0.1515。仅凭图不能确定增益来自均值、分布、参考关系还是上游分数。

查询源文件：`Visual_Tanker_x17091_y8445_{vv,vh}.tif`；完整目录见 JSON。

### 691：两极化均有有效目标，普通区域 MLP 判对

已查看 `oss1_within_simple_only_691.png`。QUERY 在两极化均为短横向、略倾斜的亮条，VH 背景纹理比 VV 更明显，内部亮暗块并不足以肉眼唯一判类。真实 container 参考 797、798 与 bulk 参考 508、880 都含相近尺度的亮条和局部亮点；没有“真实参考明显不相干”这种证据。

MLP 判 container，完整模型判 bulk。该反例说明真实类参考已被提供、两极化目标都可用仍不保证最终分类正确。它支持保留普通区域读出对照，但不能据此把错误直接归咎于某张 bulk 参考或 OT 匹配；需要具体分差/模块贡献才能定位。

查询：`Visual_Cargo_x22458_y10619_{vv,vh}.tif`。

### 585：小目标可被两条流程同时识别

已查看 `oss1_within_CC_585.png`。41×41 原图在 160 画布中占很小区域，VV/VH 都有清晰的短斜亮目标和有效框。chemical 参考 474、759 与 general 参考 1151、448 在图中仍存在短条状/亮点结构交叠；不能凭外观命名某种独占类别机制。

### 588：与 CC 共用同一组参考，仍同时误判

已查看 `oss1_within_WW_588.png`。查询为近竖向小亮条，VV 上端更集中，VH 的亮响应与周围纹理分布有所变化；两个有效框面积不同，但都保留全部目标掩膜。chemical 参考 759、474 和 general 参考 448、1151，与 585 使用的是相同集合、顺序不同。

### 1031：两极化的可用目标条件高度不对称

已查看 `oss2_within_ours_only_1031.png`。VV 可见多个强亮斑，未提供有效目标框；VH 框较宽且斜向覆盖到原小图右边缘附近，强响应集中于框的一端。JSON 确认 VV 无目标掩膜，VH 846 像素全部保留。不能把“图像有亮斑”当成 VV 局部目标模块可用，也不能把该宽框直接解释为人工准确船体边界。

实际 bulk 参考 2503、1960，竞争 container 参考 691、2017。参考 2503 的 VV 绿色框内偏暗、下方另有明显亮斑，VH 则框内有亮条；这是参考极化外观/定位值得保留的可见异常，不足以认定标签错误。其他参考多为细长亮目标，与查询的宽区域和边缘亮斑形态并不完全一致。

完整模型判 bulk 而 MLP 判 container，说明复杂输入仍有成功案例，但不证明 M3 正确忽略了某个亮斑或识别了某种物理散射。上游与局部路径如何分工仍未确定。

查询：`pub2_opensarship2_002831.png`，VV/VH 分别位于各自目录。

## 可保留结论与未解决点

八例确认：目标尺度、VV/VH 有效框与背景条件不同；完整模型有独有成功，也有普通区域 MLP 判对而其判错的实例；实际包含真实类参考不是正确分类的充分条件。同样的小目标条件可以成功或失败，不能用“原图太小”笼统解释所有负例。

本轮证据支持保留两套读出及既定 fit_only 对照，按已有源标签组织解释结果。尚未证明哪个模块利用了哪项物理信息，也未证明某张参考造成预测翻转。若后续需要机制连接，应使用既有逐阶段分差和针对性干预；本次不启动新实验，不凭这八张图挑方案。
