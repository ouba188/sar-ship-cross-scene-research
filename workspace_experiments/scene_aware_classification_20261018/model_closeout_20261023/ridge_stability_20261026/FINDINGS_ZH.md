# 反向ridge的优势是否稳定，以及下一步

2026-10-26。只复用已有预测，不重训、不调整参数或标签。OSS2→OSS1相同四分类921条观测、742艘船、21个过境组。ridge使用源验证选中的alpha1000，确定性lsqr；没有把一次ridge复制成三个随机种子。

## 结论

**不能因为ridge没有处处赢，就反推我们的模型更稳定。现有证据更具体：ridge相对新raw_summary的OA优势较弱，但BA有优势；相对接M3后的候选，ridge的OA优势更明确。** 尚未测源训练集变化或独立新划分的稳定性，不能宣布任何方法普遍稳定。

## 同查询配对结果

OA/BA为百分数；神经方法为三个训练种子的指标平均，不是预测集成。标准差为三种子样本标准差，只有三次，不能据此精确估计长期方差。

| 方法 | OA均值±标准差 | BA均值±标准差 |
|---|---:|---:|
| ridge | 63.74，确定性单拟合 | 54.97，确定性单拟合 |
| 普通区域MLP | 60.08±1.09 | 50.81±1.63 |
| 原M123 | 61.02±1.36 | 50.70±2.12 |
| raw_summary | 62.94±2.19 | 51.69±0.50 |
| raw_summary+M3 | 60.88±3.23 | 51.97±1.03 |

这支持一个局部判断：在当前三个种子中，接M3后新候选的OA和BA波动都增加，不能称M3使它更稳定。ridge的确定性不能被写成零泛化方差；它仍可能对训练数据或场景变化敏感。

下表全部为ridge减去对应模型，单位百分点，按过境簇4000次配对bootstrap，先平均同一查询的种子效果。

| 对照模型 | OA差及95%区间 | BA差及95%区间 |
|---|---:|---:|
| 普通区域MLP | +3.66 [1.16,6.63] | +4.16 [1.36,6.72] |
| 原M123 | +2.71 [-0.91,6.53] | +4.27 [2.09,6.48] |
| raw_summary | +0.80 [-1.66,3.20] | +3.28 [0.12,6.24] |
| raw_summary+M3 | +2.86 [0.82,5.19] | +3.01 [0.06,5.66] |

按MMSI独立重采样作为另一个敏感性口径，ridge对raw_summary的OA/BA区间为[-1.31,2.89]/[0.19,6.57]；对raw_summary+M3为[0.73,4.98]/[-0.12,6.16]。后者BA的区间跨0，说明其BA稳定性结论依赖聚类口径，不能把临界正区间写成强证据。两种单独聚类不是同时处理船只和采集依赖的双向bootstrap，更不是新训练折。

## 是否被单一采集撑起来

- ridge对raw_summary：21个过境组OA有14胜、7负；逐次删除一个过境组后，整体OA差范围[-0.04,1.36]，BA差[2.44,4.06]个百分点。OA优势并不牢靠，BA不是某一个过境单独撑起来的。
- ridge对raw_summary+M3：14胜、7负；删除任意一个过境组，整体OA差仍在[1.98,3.26]，BA差[2.27,3.78]个百分点。
- ridge对原M123：11胜、10负；留一过境OA差[1.33,3.29]，BA差[3.75,4.80]个百分点。这不等于每个场景都更好。
- 若每个过境组等权，ridge对raw_summary的OA差为-0.02个百分点，几乎持平；对其M3版本为+2.17。图像加权和采集等权回答不同问题，完整数据均保留，没有按有利采集筛选。

## 差距落在哪类

目标类别数量为散货675、普通货71、化学品72、集装箱103。对raw_summary：

| 类别 | ridge召回率 | raw_summary召回率 | ridge减候选 |
|---|---:|---:|---:|
| 散货 | 67.41 | 67.75 | -0.35 |
| 普通货 | 36.62 | 23.00 | **+13.62** |
| 化学品 | 43.06 | 43.52 | -0.46 |
| 集装箱 | 72.82 | 72.49 | +0.32 |

因此未接M3时，主要不是所有类别都变差，而是普通货这一类的读出存在明显缺口。接M3后散货召回也从67.75降到64.49，这与其占多数的类别构成共同造成OA损失。以上是可定位的类别效应，不证明其物理成因，也不能仅按样本数解释普通货和化学品的差异。

实际查看本目录4张native160 VV/VH面板，seed17、各正确/错误状态选最小obs_id，包含M3实际同类/混淆类参考。ridge不检索这些参考；图片只用于比较同一输入，不证明ridge在看哪一个亮点。

- 33集装箱：ridge判对、新完整候选判散货。查询是近水平小条，VV一端较突出、VH更连续；集装箱1409/2730与散货255/2521都有细长/端部响应，目视不能唯一判类。
- 4化学品：候选判对、ridge判集装箱。查询VV含数个水平亮点、VH较连续；化学品2625/1949和集装箱1531/249都能呈多段响应。这是候选具有ridge没有保住的正确样本的实例，不是已证明的物理互补。
- 0散货：两者均对。短斜条、多段亮响应，散货1926/1995和集装箱2730/1409均有细长结构；不同朝向不能直接作为类别解释。
- 3散货：两者都错，ridge判集装箱、候选判普通货。查询VV/VH近斜线上的分离亮点，散货1926/2517和普通货1919/565同样共享短条/端部结构；不能据此判标签错误。

这4例不估计总体比例，未覆盖普通货专项根因。后者是下一轮需补的针对性案例，而不是本轮已经解释清楚的原因。原路径、分数与参考ID在cases.json。

## 下一轮的最小设计（未执行）

1. **先完成同信息、不同读出的四格比较。** 原区域特征/原区域特征+摘要，各用ridge和MLP。已有三格可复用，新增只需训练“raw+summary ridge”。同源角色和源验证规则，不按目标选alpha。它能区分摘要是否有用与当前非线性读出是否容易损失普通货证据。
2. **以强原区域读出为参照，改接口而非重做骨干。** 保留区域身份、极化分离和类别响应，不强制叠加旧M1/M2分数。先比较现有联合读出与强基础加受约束增量，重点看普通货被救回与集装箱被误伤的来源；不把ridge本身包装成新模块。
3. **M3只改修正强度的最小对照。** 固定同一强基础、PairMetric和参考，在源端比较不修正、原VV/VH组合、允许整体缩小至零的组合，配套重训分数相关读出。先检验有效修正是否被过量/不合适组合抵消，再考虑动态网络。不在目标端直接选VV，也不预设VH无价值。
4. **再补真正的数据变化稳定性。** 两者使用相同的源采集分组与训练预算，至少三组配对训练/验证划分；受源划分影响的监督reader和后续头也必须重拟合，不能只重训一方。优先明确普通货源船数、观测条件与目标错误去向。与本轮固定预测重采样分开报告，不要求每组全胜。

当前最值得保留的主张不是“我们比ridge更稳定”，而是：**原始区域信息与类别证据已经存在互补收益，主要缺口集中于部分船型读出及后续极化融合。** 这是可以用局部修改继续解决的问题。
