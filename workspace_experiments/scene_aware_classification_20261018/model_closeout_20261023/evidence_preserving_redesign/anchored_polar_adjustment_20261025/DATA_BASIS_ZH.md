## 3. 固定半径能检验什么

由历史 `cases.json` 的冻结分数计算，不运行训练：对指定真实类与面板固定竞争类，

`m(alpha) = m_base + d_VH + alpha * (d_VV - d_VH)`。

下表给出越过该竞争类的必要条件，不将单一竞争类分差为正误作八类top-1必然正确。区间用闭包表示；tanh在有限logit下通常不精确达到半径端点。历史alpha与本轮全源选择一致。

| 案例/配置 | B的alpha；允许区间 | 固定竞争类边界 | 建议用途 |
| --- | --- | --- | --- |
| 30648/29 | .6；[.35,.85] | alpha>.638054；B分差-.012904，向上端可至+.071872 | 可达的救回候选；比较空间/频域是否真正需要查询变化。 |
| 9748/29 | .6；[.35,.85] | alpha<.627556才压住拖船；B分差+.013001 | 很小上调就能误伤，适合与30648配对。该历史面板本审阅未打开。 |
| 8492/29 | .6；[.35,.85] | alpha<.836138；B分差+.223891，上端-.013143 | 容易在上端误伤，检查源均值替换是否已足够。 |
| 24640/43 | .1；[0,.35] | alpha<.346785；B分差+.065373，上端-.000852 | 原centerVH救回的保留对象，防止微调抹去既有收益。该历史面板本审阅未打开。 |
| 22572/17 | 1；[.75,1] | 需要alpha<.086611；允许最优分差仍-.272693 | 范围外难例，只看方向与分差，不要求救回。 |
| 2080/43 | .1；[0,.35] | 需要alpha>.834862；允许最优仍-.127400 | 同上，不能将继续错误归咎于残差训练。 |
| 5585/29 | .6；实际固定.6 | 即使放开残差也需alpha>.892475，超过.85 | 当前明确不动；保持原B的缺失策略。 |
| 7944/43 | .1；[0,.35] | 最好alpha=0仍-.006430；整个[0,1]均不敌该竞争类 | 两个冻结端点都不能解决；不是再学比例即可救回。该面板本审阅未打开。 |
| 34327/17 | 1；[.75,1] | alpha>.543948即胜面板竞争类；允许最差仍+.190855 | 历史偏好例在B下已具优势，不能重复算作本轮新能力。该面板本审阅未打开。 |

这些是事后指定案例的解析边界，不估计全体样本可救比例，不据此扩半径或调开发集阈值。图像支持“相同粗形态可伴随不同分支效用”，尚未证明41/185维描述可以稳定预测有益调整方向。新增频域144维包含原PNG上的分带能量、协方差相似度和覆盖信息；频域块中和影响不等于某种物理频带机制得到验证。

## 4. 当前源码与已保存检查的窄审阅

以下行号对应本次读取的 `train.py` 与 `analyze.py`，未执行其中函数。

1. **逐折alpha符合协议。** `train.py:26` 的 `choose_alpha`仅接收传入ids的分数与标签；`:155`分别传入A、B和全源，`:169`各折训练使用 `anchors[name]`，而非全源alpha。选择沿用 `hybrid_polar_fusion_20261025/train.py:48` 的精确分数J、0:.1:1网格、平局近.5再较小alpha。全源alpha虽提前计算，但未用于折内训练或折外0步比较，因此计算顺序本身不构成泄漏。
2. **标准化与类别权重符合协议。** `train.py:66`只用tr拟合标准化，`:69`后的计数也只用tr；最终才在612上重拟合。冻结频域协方差标准化来自更早的644 utility_train（`query_polar_gate_20261025/extract.py:62`），不是本轮持出或开发标签拟合。
3. **零初始化与裁剪路径正确。** `train.py:43`只将最后层置零，`:48`直接在训练forward里执行 `clip(alpha0+.25*tanh(r),0,1)`，不是先训练无界alpha后仅推理裁剪。`prediction`只将两路残差加到一次base。`checks.json`初始重放最大误差2.384e-7、历史B重放最大误差1.907e-6，属于浮点等价，不宣称逐bit相等。
4. **端点初始化不是必然零梯度死锁。** 已存检查记录在alpha0=0/1下分别向内移动到.0062487/.9937513；内部点有限差分与自动梯度一致。该检查验证局部可训练性，不能证明所有查询在整个训练历程都未饱和。当前freeze重放12个模型误差全0（`analysis_receipt.json`），无需为同一问题重跑训练。
5. **缺失处理符合协议，且必须限定“固定总强度”的语义。** `train.py:49`先令非双极化有效样本alpha回到anchor，`:50`再乘availability；不重新归一化。双极化有效时两权重和为1，缺VH时有效权重和为alpha0，保持旧B的稀释程度。缺失样本对alpha网络的任务梯度为0是本轮设计结果，不是掉梯度bug。`analyze.py`已断言四arm在69条开发缺失样本上与B分数误差<3e-6，receipt记为missing_unchanged。
6. **0步、选择及最终重拟合正确。** STEPS继承 `(0,10,20,40,60,80,100)`；`:174`以折外0步J为初始最优，严格 `j>best` 更新，故平局保留早步。`:181`用固定选定步数在全源重拟合，未再根据重拟合曲线选步；最终评估循环位于所有状态写完之后。0步只是允许退回B，不保证所选非零步在开发集不退化。
7. **源均值替换是合法诊断，非独立选定的新方法。** `train.py:209`仅在源612中的双极化561条求alpha均值，随后只替换双极化查询；缺失查询仍用原anchor。没有用485开发均值。该诊断检验固定模型是否需要查询变化，但均值由已训练动态模型导出，不能直接把它包装成一个未经另行源选择就正式晋升的部署方案。

当前未发现需主代理修改的协议违例。上述历史选择复用、折组成不平衡和半径可达性是实际解释边界，不要求本轮补嵌套全流程训练、改划分、扩大搜索或重做模型。

## 5. 与本轮完成结果对齐
