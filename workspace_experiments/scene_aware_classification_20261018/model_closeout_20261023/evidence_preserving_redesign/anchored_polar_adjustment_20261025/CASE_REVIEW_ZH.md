# 原生chip回看：调权可以补证，也会重新引入有害证据

2026-10-25。主代理实际打开并查看本轮9张面板的VV/VH及同类、混淆类实际源参考。子代理另查看6张历史面板，见DATA_BASIS_ZH.md，二者不混计。

展示为native160裁剪/补零，未缩放船体；沿用既有拉伸PNG，不能将显示亮度当作定标RCS。框是区域覆盖示意，不是归因热图。底层图像路径、裁剪位置、参考ID与种子见analysis/cases.json。下面分差均固定真实类与该面板的竞争类，不将单一分差当整个概率分布。

## 1. 空间候选救回2418，配置17

图：analysis/rescue_2418_17.png。散货查询；同类2379/35396，竞争化学品9086/7564。

可见：查询VV是较宽近横向亮主体，VH内部亮响应更分散。同类参考一个近横向、一个斜竖，混淆参考也有紧凑亮主体。存在两极化局部结构差异，但不能从外观宣布哪一路必然正确，也不能归因为雷达方向。

模型证据：base分差-0.15622，VV补充+0.14125，VH补充+0.48763。B在此配置alpha=1，完全不采用VH补充，分差-0.01498；空间候选VV/VH=.80687/.19313，分差+.05192，救回。源均值固定替换也救回（+.04826），因此该例证明重新采用VH有用，不证明动态性不可替代。频域候选只给VH .03209，仍错（-.00386）。旧完整模型本来判对，不是旧系统从未具备的能力。

## 2. 空间候选误伤16596，配置17

图：analysis/harm_16596_17.png。渔船查询；同类20215/15934，竞争拖船26258/25298。

可见：查询是小而细长的近竖响应；同类和拖船参考均有小尺度紧凑亮结构。查询VH比VV更弱，参考类别间存在粗外观重叠。不能仅凭弱VH判定不可靠，具体有害性来自分数重放。

模型证据：base-.20274、VV+.26201、VH-1.06305。B只用VV，分差+.05928；空间候选加入.17932的VH，变成-.17834。源均值替换也误伤。与2418相比，加入近似数量VH产生相反后果，反映这个学习器尚未稳定区分“缺补证”与“会误导”。

## 3. 持续正确18767与持续错误21151，配置29

- analysis/CC_18767_29.png：渔船查询VV为短小偏弱主体，VH缺失；实际同类15663/15202，竞争海工22841/22924，部分参考VH也缺失。按协议不改变B，分差始终+5.07984。它不是双极化互补收益，展示确认缺失不会被伪装成动态选择。
- analysis/WW_21151_29.png：散货查询主体比同类35396/33678更短，VH可见向下细长延伸；竞争普通货26409也有向外延伸。没有凭据将延伸命名为尾迹/旁瓣。base强烈偏错（-4.50549），VV补充+2.29514强于VH+.23151；提高VV比例使分差-3.03580改善到-2.53571，但未跨边界。说明有益方向存在不代表本轮可达幅度能救回，也不是新增分类成功。

## 4. 频域候选相对B救回13372、误伤20820，配置17

- analysis/rescue_13372_17.png：普通货船查询近竖细亮；同类33307/26409和竞争化学品31086/24840也有细亮/紧凑主体，方向各异。base-.04293、VV-.01359、VH+.38253。给VH .19807后分差-.05652到+.02194。中和新增频域描述后变回-.03757，说明此冻结频域头的决策确实依赖新增输入；但空间候选和空间源均值也判对，所以不是频域不可替代证据。
- analysis/harm_20820_17.png：化学品查询为斜长连续亮体，VV侧上方有延伸，VH较紧凑；同类9086/24840较小，散货33678/23781也有长亮体。base+.03227、VV-.02046、VH-.60637。即使只加入.05415 VH也从B+.01181变成-.01992。该例原先距边界很近，两路补充都不利，单纯调比例不能保证不伤。空间、全局调整也误伤。

## 5. 新增频域输入的直接正反例26069/26043，配置17

- analysis/rescue_26069_17.png：化学品查询较小斜亮条；同类24840/31086与散货23049/33678都有相似细长亮结构，参考尺度跨度明显。VV补充分差+.19101，VH+1.20296。频域头给VH .22099，相对中和频域从-.09774到+.07640；但空间/空间源均值同样正确。不能将图像外观推成“这种细纹必然属于化学品”。
- analysis/harm_26043_17.png：同为化学品，查询为小近竖亮主体，显示窗口下方可见额外亮点；同类31086/24840和渔船15934/20215均有小亮主体。未做亮点遮挡实验，不能断言下方亮点造成误伤。VV+.05111，VH-.89336；频域头给VH .20028，中和频域时+.05859变为-.09505。频域输入确实造成决策变化，但方向有害。

两例同类却有相反VH效用，否定“按类别统一相信某极化”的简单解释。仅靠这些面板尚不能确认频域描述为何在两例给了相近VH权重；可以确认的失效点在权重对证据效用的映射，而非这两路完全没有互补信息。

## 6. 动态性反例26694，配置29

图：analysis/harm_26694_29.png。化学品查询；同类7564/7826，竞争原油30814/12549。

可见：查询呈近横亮体，周围显示纹理强；VH横向亮带与VV轮廓细节不同。原油参考亦有较长亮体，但几何和尺度各异，不能仅凭背景显示纹理认定船型。

模型证据：base+.35142，VV-.41581，VH-.02942。源均值alpha=.832479时分差+.000341；逐查询alpha=.838014时分差-.001798。这是极临界误伤。整个空间候选相对源均值无新增救回，仅这一例误伤；它说明当前top-1收益不需要逐查询波动，但不证明所有连续分数变化都无意义。

## 收口

已确认的链条是：同一冻结基础模型下，两路补充的类别竞争效用不同；重新分配比例可以救回或误伤具体案例；本轮有小幅平均净收益。尚未确认的是：现有频域输入能够跨场景可靠预测有益调整，以及逐查询变化本身有净分类贡献。后续不应只靠更复杂门控包装这些结果。
