# 旧VV与空证据归零VH的固定融合

## 问题与已有证据

上一轮center_vh相对prior_vh平均OA持平、BA增加0.5276个百分点；同时替换VV/VH的center_late未优于prior_late。22572案例显示VH救回可被VV压过，2080显示相反方向。两路不能被预设成处处互补，固定权重也不保证能辨别这些情况。

本轮只检验：保留旧VV、替换新VH是否兑现已有局部收益；源验证集选一个固定权重是否进一步有用。没有新训练、动态门控或新的频域处理。

## 冻结设计（开发集评价之前）

- 复用上一轮全部骨干、参考集合、匹配、读出头、分数及三个配置17/29/43。
- 源训练644、源选择612、开发查询485；参考集合64。485查询为445船、29过境、14港，已经反复用于研发，不是独立确认。
- hybrid_equal：0.5 prior_vv + 0.5 center_vh。
- hybrid_source：alpha prior_vv + (1-alpha) center_vh。
- ordinary_source：alpha prior_vv + (1-alpha) prior_vh，使用完全相同选权流程。
- alpha表示VV权重，候选0,0.1,...,1；每个配置仅使用612源选择样本，以J=(OA+BA)/2最大选取；精确同分先取最接近0.5者，再取较小alpha。
- 所有配置与两种组合的权重写入source_choices.json之后才计算开发集指标。源选择集也用于历史早停，因此不称为嵌套或独立交叉验证。
- 两个诊断交换：ordinary_at_hybrid_weight、hybrid_at_ordinary_weight。区分相同权重下的支路替换，与源端所选权重变化；不以开发结果挑选权重。
- 对照保留prior_late、center_late、old_full、base、strong及单独读出。单独读出仍接在已有双极化基础模型上，不等于仅用VV或VH图像。
- 分数是base+delta，所以融合后base仅计算一次。缺失VH不把VV权重重归一；alpha为0或1时属于退化到单个局部读出，不称双路收益。

## 验证与分析

先检查缓存行对应、端点重放、等权旧组合重放和base单计数，再评价OA/BA、同转换NLL/Brier、逐类/过境/缺失极化、配对救回误伤。三个配置不是三批独立船；过境bootstrap是开发诊断，不是确认性显著性证明。

回看实际查询与同类/混淆参考原图：至少救回、误伤、持续正确、持续错误，VV/VH分开，保留既有native160裁剪/补零、不改变船体缩放。案例解释包含分差和两路贡献，不把图像外观直接命名为因果散射机制。

收口标准：在明确数据范围内有可重复净收益即可保留候选，不要求处处胜；若源端选权不能迁移则如实保留负结果，不用开发集反选最优alpha。
