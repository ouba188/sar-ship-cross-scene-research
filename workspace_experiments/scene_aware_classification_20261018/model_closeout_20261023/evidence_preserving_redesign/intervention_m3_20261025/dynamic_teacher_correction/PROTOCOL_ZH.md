# 源端监督目标错位的单项纠正

原9次训练均完成并选择0步，原始结果全部保留。本轮源端操作表发现：seed29源选择obs1822的type0使真类相对旧固定竞争类优势增加0.084633，但另一错误类超越真类。该种子源选择68次有害操作中3次被固定竞争类标签记为正，其余种子没有此类误伤错标。不能把这个局部缺口当成全部失效根因。

在不改输入、模型、动作幅度、参考、种子、损失权重、优化步数和源J选择规则的情况下，仅将教师效用改成实际多分类分差的变化：

`u = [s_after[y] - max_{c!=y} s_after[c]] - [s_old[y] - max_{c!=y} s_old[c]]`。
