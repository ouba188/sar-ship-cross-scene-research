# 查询级双极化修正权重：分数、空间、空间频率

## 动机与冻结范围

22572需要VH而2080需要VV，5585的缺失VH使有效VV修正被固定半权稀释。此前固定权重有局部正信号、没有整体一致升级。本轮验证是否能从部署可得输入判断修正权重，特别是频域是否提供超出分数/空间关系的效用；不预设能涨点。

冻结M1/M2/M3匹配、旧VV头和centerVH头、64源参考、查询与实际每类两参考。输出 `base + gV*deltaVV + gH*deltaVH`，两个sigmoid权重独立，不要求和为1；VH缺失修正为0，不把VV自动重归一。初始gV=gH=0.5。训练和部署用同一软加权，不存在训练软选择/部署硬动作差异。

## 本轮真实的数据边界

- 旧组件在644上梯度训练、612上早停。不能用644的拟合预测教门控并称为留出。
- 改用历史selection612做门控训练/门控层分组交叉选择；历史早停污染不能撤销，不能称全链路严格OOF或独立验证。
- 用同采集或同MMSI的连通分量划分：最大分量A432条/385船/7过境，其余B180条/177船/21过境。两折船只与过境完全隔离，均有8类；A/B的化学品179/19，offshore35/2，有明显不均衡。
- A训练预测B、B训练预测A；标准化与类别权重仅拟合当前训练折。合并612条逐个训练步的折外预测，以J选步数；明确这是交叉选择分数，不是选步后的无偏性能估计。
- 再在全部612拟合选定步数。所有18个最终状态冻结后，才打开原485开发查询指标。485仍为445船/29过境/14港、历史反复使用的开发集，不改称独立确认。

## 输入与匹配对照

每个查询为8个候选类别的共享输入token，不输入真实类别、港口ID或船只ID。

1. score：11维，基础分数/两路残差/三种分差与概率/极化可用性。
2. spatial：加30维。VV/VH分别在框内、侧向、轴端，读取查询—真实参考内容余弦均值/标准差、两参考一致性、有效参考比例、查询有效性。来自历史内容均值，不把学习过的频域核偷偷作为新增空间特征。
3. frequency：再加144维。上述两极化三区域分别在4/8/16原生像素尺度，加入查询/参考Gabor对数能量、能量差、参考离散度、局部频率—内容协变量关系的均值/标准差、查询/参考完整滤波邻域覆盖。

频域从原生显示拉伸PNG提取，不是定标后RCS；方向取均值，不输入绝对朝向。能量不被手工规定为好坏，查询—参考频率接近也不被规定为同类。协变量通道沿用644源训练尺度，门控输入标准化仅在各门控训练折拟合。

网络采用类别共享MLP，类别维均值聚合为两路权重。score/spatial/frequency隐层宽12；另设score_wide宽161、spatial_wide宽51，参数量分别2256/2246，与frequency2258接近。constant仅学习两个全局参数，不读查询，检验收益是否只需改变全局修正强度。

6臂×3配置17/29/43，每臂两折+最终重拟合。AdamW lr0.003、wd0.01，100个全批次步，检查点0/10/20/40/60/80/100，合并折外J严格改善才更新、同分选早期；损失0.5微平均CE+0.5宏平均CE，按当前训练折类别计数。全部训练规则在开发评估前固定，不根据开发结果增步调参。

固定对照：旧完整both、原独立等权、混搭等权、此前源端固定alpha。另用训练折内选择固定alpha做源折外参考，不能拿全612选过的alpha假称折外。

## 何时认为频域有用

首先比较frequency与spatial及近参数spatial_wide；score_wide排除仅增加容量。报告OA/BA、NLL/Brier、救回误伤、逐类/过境/缺失组，不要求所有组胜。

固定已选frequency门控：将频域输入设为训练标准化均值，检验输入依赖；将每查询权重替换为源端平均权重，检验是否需要逐样本变化。前者只是输入诊断，不替代完整重训消融，不等于物理干预。

源端离散gV/gH网格只用于描述可救回/可误伤空间，不当部署方案或最优性能。开发标签不用于挑门控、权重、阈值或训练步。

结束必须回看原始VV/VH、实际同类和混淆参考，覆盖救回/误伤/持续正确/持续错误。没有翻转时仍分析权重与分差变化。保留负结果，同步GitHub，不上传模型/原始数据/大型缓存。
