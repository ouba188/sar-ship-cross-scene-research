# 查询门控原始chip回看

2026-10-25，13组均已查看。面板上排VV、下排VH，查询、两个实际同类源参考、两个实际混淆类源参考；原生160像素裁剪/补零，不把船缩放，使用已有显示拉伸。绿框内、橙轴端、蓝侧向是几何边界，不是归因热图。每例实际文件路径与obs_id、seed、参考、分数、权重保存在analysis/cases.json。

下述margin均为真实类减固定竞争类；正margin不必然代表八类top-1正确，是否正确同时以完整预测为准。对照不同必须分开解释。可见图像事实不直接命名为尾迹、旁瓣或某种船型的物理机制。

## 频域输入依赖的全部正确性翻转

固定同一frequency头，no_frequency仅将新增144维置为训练标准化均值。

### 5585 / seed29：加强已有VV修正，化学品船救回

文件analysis/rescue_5585_29.png。查询VV为紧凑亮长条，VH缺失；化学品与散货参考均有细长强响应，仅看截图不能给出可靠的物理分界。

base对化学品相对散货margin=-0.36121，VV修正=+0.40473。频域门控给VV 0.97596，最终margin=+0.03379；中和新增频域后margin=-0.07751。VH始终无局部贡献。保留覆盖但中和能量和协变量数值，VV权重降至0.87011，margin=-0.00905，发生误判；单独中和覆盖仍正确。

已证实是该冻结头对新增频谱数值存在决策依赖，不仅仅是缺失标记。未证实这些数值对应何种物理状态；spatial及score_wide也救回，不是频域独有能力。

### 26176 / seed29：跨界所需的幅度很小

文件analysis/rescue_26176_29.png。查询两极化均为小型细长亮响应；两个化学品参考更长，其中一例VV附近另有纵向亮结构，拖船参考也有相似亮短条。当前外观不能独立支持某个频段必然属于化学品船。

base=-0.08991，VV修正+0.17099、VH修正-0.01903。实际权重0.65619/0.65900，margin由no_frequency的-0.01035到+0.00975，由拖船改对化学品。两权重仍几乎一样，这是加强总体修正，不是精确抑制有害VH。spatial、spatial_wide、score_wide和源固定选权也正确，频域不具独占收益。

### 11655 / seed43：同时压低两路错误修正，拖船救回

文件analysis/rescue_11655_43.png。查询VV紧凑、VH较长竖向亮响应；实际拖船与化学品参考都包含细长亮主体，某拖船参考框外有亮点。不能仅凭该亮点断言模型使用了邻船。

base原本正确，真实拖船相对化学品margin=+1.47925；VV/VH修正分别-1.67703/-1.31371。门控权重0.45453/0.45932，margin=+0.11357，中和频域为-0.00010。有效作用是减少两路的错误修正，非增强某一路。spatial及旧完整both也正确；这能证明固定门控输入依赖，不能证明频域新发现了船型结构。

### 17182 / seed29：频域也会放大错误修正

文件analysis/harm_17182_29.png。查询VV主体很小且细长，VH中心较弱；渔船与拖船参考都出现小型亮响应。不能从外观把背景亮度等同于特定类别。

base对渔船margin=+1.2821；VV/VH修正为-1.60412/-0.13910。实际门控0.82581/0.81780，margin=-0.15636；中和频域后+0.29566恢复正确。单独中和能量字段也恢复，margin=+0.17828；只中和查询自身能量不恢复。说明不能把“频域反映图像质量”直接转成可靠加权规则，查询—参考联合字段的作用还未完全拆解。

## 可保留范围与未解缺口

本轮可以解释到“哪些已有类别修正被放大/缩小、由哪些输入块影响、哪些实际查询与参考参与”。可以保留缺失VH时不再稀释有效VV、两路错误修正共同减弱等局部收益。尚不能把频率数值解释成特定物理因果因素，也未证明频域能学到可靠的VV/VH相对偏好。代表案例不替代总体比例；全部翻转及分组统计见flips.csv、population_pairs.csv、preference_groups.csv。
