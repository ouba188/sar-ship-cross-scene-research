# 查询级极化加权：空间候选可留，频域尚未改善相对取舍

2026-10-25。本轮完成6臂×3配置的36次分组交叉拟合、18次最终重拟合、固定头输入诊断和13组原始尺度VV/VH查询及实际参考回看。没有替换旧主模型。

## 1. 结论先行

1. 按查询调整两路修正可以实现。紧凑空间门控相对本轮混搭等权为OA +0.4124、BA +0.2676个百分点，保留为低成本候选，不称为超过已有最强方案。
2. 加入频域后NLL/Brier改善，并有少数真实正确性翻转依赖新增频域输入；但OA/BA均未超过紧凑空间门控。不能把局部依赖写成频域可靠选择器已经成立。
3. 最具体的失效位置是：两个权重经常同步升降，主要调节总体修正强度，未有效解决“此查询更需要VV、另一查询更需要VH”的冲突。它不是实现上强制同权，但学习结果接近同权变化。
4. 缺失VH组贡献了多数净OA收益；双极化齐全组中频域相对混搭等权平均OA无净变化。当前收益不能全归功于频谱互补。

## 2. 实际流程与实验范围

冻结已有M1、M2、M3匹配及旧VV读出头、新空证据零修正VH头。基础路径本来已包含双极化；“VV支路”只指新增局部修正，不能叫纯VV完整分类器。

输出为 `s(x)=base(x)+gV(x)*deltaVV(x)+gH(x)*deltaVH(x)`。gV/gH为两个独立sigmoid，范围0到1，不要求和为1。缺失极化的修正权重为0，另一极化不自动归一。初始两权重均0.5，逐项重放与混搭等权完全一致。

每查询构造8个候选类别token。共享小MLP读取部署可得的分数、查询与实际源参考的关系，类别维聚合后产生两权重；不输入查询真实类别、港口ID或MMSI。训练和部署都是同一软加权。

| 方案 | 新增输入 | 参数数 |
| --- | --- | ---: |
| constant | 不看查询，学习两全局权重 | 2 |
| score | 11维分数、分差、概率及极化可用性 | 170 |
| score_wide | 同score，增加宽度 | 2256 |
| spatial | 加30维分极化、分区域内容关系 | 530 |
| spatial_wide | 同spatial，增加宽度 | 2246 |
| frequency | 再加144维区域频率关系及滤波覆盖 | 2258 |

空间关系在VV/VH各自的框内、侧向、轴端统计查询—参考内容余弦、参考一致性与有效覆盖。频域使用已有原生PNG提取的4/8/16像素尺度Gabor能量、查询—参考能量差、参考离散度、频率—内容协变量关系及完整滤波邻域覆盖。方向取均值，没有直接输入绝对船向。PNG是既有显示拉伸数据，不是定标RCS；滤波尺度不是米数。

这里“没有新增频域输入”的对照，其冻结分类分数仍继承旧M3中的频域处理。本轮只检验频域是否对新门控提供额外信息，不是整个系统去除所有频域的消融。

## 3. 数据与选择协议

旧组件梯度训练644条，历史早停使用612条。本轮不拿644条拟合预测冒充门控留出，而用612条做门控层分组交叉选择。按共享MMSI或过境组成连通分量，两折432/180条，船只与过境互不重叠。两折都有八类，但化学品船179/19、offshore35/2，覆盖明显不均衡。

标准化及训练类别权重仅拟合当前训练折，A训练预测B、B训练预测A，以合并612条的J=(OA+BA)/2选步数，再用全部612条重拟合。6臂×3配置的18个最终状态全部冻结后，才评估485条开发查询。612曾用于旧组件早停，故不能称全链路严格OOF；交叉选择分数也不是选择后的无偏性能估计。

开发集为485条、445艘船、29个过境、14港，已反复用于研发，不是独立确认。三配置17/29/43同时包含上游模型差异，不只是同一上游下的三个门控随机种子。64个参考均为源参考，不是本轮新增的64个目标标签。开发类别数为169/91/69/67/33/13/40/3；VH缺失69条，其中54条渔船，另416条双极化齐全。

## 5. 频域到底有没有参与

固定已训练频域门控，将新增144维输入置为源训练标准化均值，不重训、不变其他输入：

| 配置 | 保留频域输入的救回 | 误伤 |
| --- | ---: | ---: |
| 17 | 0 | 0 |
| 29 | 2 | 1 |
| 43 | 1 | 0 |

保留输入平均OA +0.1375、BA +0.1828个百分点。全部四个正确性变化已逐一回看原始chip和实际同类/混淆参考：5585、26176、11655救回，17182误伤。它们来自不同船与过境，但不是四次独立训练复现。紧凑spatial也能救回这些正例，不能据此声称频域不可替代。

进一步分开频谱数值和覆盖：固定头下只中和覆盖没有正确性变化；5585中和能量与协变量数值、保留覆盖后由对变错，说明该例不只是读到了有效裁片比例。反过来17182中和能量后恢复正确，说明频域也可能增强错误修正。固定头中和可能形成非自然输入，只支持函数输入依赖，不等于物理因果干预或重训消融。

把frequency每查询权重替换为源端平均权重：VV、VH分别在源端该极化有效的样本上取均值，部署时再屏蔽缺失极化，不是按双极化联合可用状态各拟合一组权重。实际动态版平均OA净变化0、BA -0.1788个百分点：既有个体救回，也有等量误伤。这是同一已训练头的诊断，不是证明所有动态门控无效。

## 6. 失效位置：学到总体力度多，学到极化偏好少

在416条双极化齐全查询中，frequency的gV与gH相关系数为0.9487/0.9987/0.9972，平均绝对差为0.0149/0.0038/0.0045。它们明显共同升降。网络并未绑定权重，不能说实现强制同权；也不能仅凭相关性断言训练目标或数据哪一项是唯一根因。

历史22572需要更强VH修正，2080需要更强VV修正，本轮仍错。24640两路修正都有益，却被共同缩小而未救回。原图与分数分解见CASE_REVIEW_ZH.md。

缺失VH组的VV平均权重达0.9639/0.9853/0.9932，不是规则强制为1。frequency相对混搭等权平均在该组多判对1.33条，OA +1.9324个百分点；双极化齐全组平均OA净变化0、组BA -0.3062。spatial在缺失组有相同净收益，在齐全组另平均多判对0.67条。因此本轮动态化的重要作用是避免将唯一可用修正继续减半，不宜包装成已解决双极化互补选择。

## 7. 保留项、下一步与复现

- 保留紧凑空间门控作为可选低成本候选；保留频域输入依赖正例、概率风险改善与误伤记录。旧both及原独立晚融合不覆盖。
- 目前没有证据把本轮MLP称为强算法原创模块，也没有新的物理因果发现。贡献是定位了选择器的实际功能和缺口。
- 更有针对性的下一步是区分“总体修正力度”与“两路相对偏好”的监督和评价，先核对源端冲突样本是否覆盖目标冲突；再决定是否做显式偏好学习。仅把两个权重改写成两个参数并不构成创新，本轮没有继续追加训练。
- 此轮完整收益仍限于该开发队列；没有全数据集、公开集扩围或新支持预算曲线。
- 初始等权重放误差0、缺失视图权重0、梯度有限差分及最终冻结检查点重放通过。模型与NPZ缓存留本地；上传代码、结果表、报告、派生审阅面板，不上传原始数据或权重。尚未测端到端时延，参数少不代表全链路无成本。

执行顺序：extract.py、train.py、analyze.py、diagnose_gate.py。依赖已有冻结缓存的实际本机路径见common.py及各脚本；Git归档不是脱离数据/权重即可独立运行的数据发布。病例路径、参考obs_id、权重及固定竞争类分差见analysis/cases.json。
