# 总体修正力度与相对极化偏好：预设实验

2026-10-25。接续query_polar_gate_20261025，不改M1/M2/M3、旧VV及centerVH读出、参考或图像预处理。先复核原生VV/VH的22572、2080：两类参考均有相似细长强响应，无法从亮度直接判定可信极化；分数分解却分别要求增强VH和增强VV。上一轮两个门控高度同步，故本轮检验显式偏好监督，不再仅堆输入。

## 范围与假设

学习器既要决定修正总量，又要决定相对VV/VH偏好。拟检验：在部署可得的查询—参考空间/频率关系中，是否有信息能预测两路的实际效用差，从而改善冲突样本并保住完整分类性能。两路输出均为共享双极化基础模型加单极化局部修正，不是纯VV/VH分类器。

采用等价覆盖原权重方形域的参数化：t=sigmoid(a)，d=tanh(r/2)，b=min(t,1-t)，gV=t+b*d，gH=t-b*d，随后屏蔽缺失极化。t控制共同修正，r控制相对偏好；初始t=.5/r=0，精确等于混搭等权。仅重参数化不是算法原创，本轮重点是监督与实际收益。

源标签可计算L_V=CE(base+deltaVV,y)、L_H=CE(base+deltaVH,y)。偏好软目标q=sigmoid(L_H-L_V)，差异可靠权重abs(2q-1)。正差表示VV的连续损失较小，不保证VV正确或最优融合为纯VV。仅两极化齐全样本参与偏好损失。源端监督从冻结分数产生，无查询标签进入推理。

总损失=原0.5微平均/0.5宏平均分类CE + 0.25*按上述效用差加权的偏好BCE(r,q)。辅助项在当前训练折的有效权重和上归一，不用目标标签或目标类别计数。该目标只是可检验假设；源端冲突与连续损失偏好覆盖分别统计，不将两者混为一谈。

## 评价和低成本归因

完整OA/BA/NLL/Brier之外，分别看源折外与目标上：只有VV正确、只有VH正确、两者均对、均错及缺失VH；报告偏好方向命中率、连续效用差相关、相对权重分离及救回误伤。结果不得仅靠偏好准确率定义成功。

固定头下将r=0但保留同一t，直接检验相对偏好是否有实际作用；t=.5保留r检验总力度；频域输入源均值中和只是函数依赖诊断，不是物理干预。发生退化时优先判别监督是否学到/是否跨采集迁移/是否兑现分类，而不是无限增加超参数。
