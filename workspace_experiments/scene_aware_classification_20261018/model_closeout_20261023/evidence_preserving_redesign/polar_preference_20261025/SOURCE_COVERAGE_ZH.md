# 源端 VV/VH 冲突覆盖：polar_preference_20261025

## 结论

历史 source selection612 的 A、B 两折，在三个种子下都存在“只有 VV 端点正确”和“只有 VH 端点正确”的相反材料；限制到双极化可用的查询后仍成立。因此不能将上一轮相对偏好不明显解释成源端完全没有双向材料。但冲突数量有限、B 折类别覆盖窄，而且 CE 偏好与 top-1 正确性不是同一个目标。当前证据支持开展有针对性的源端检验，不证明这些冲突能从部署输入学到，更不证明开发集收益。

本支线只完成缓存覆盖统计，不训练、不选模型、不计算 dev485 指标、不操作 Git。没有开展新一轮模型实验，也没有新增原图视觉机制结论；主线实验结束后的原始 VV/VH 与实际支持图回看仍需独立完成。

- 全源端 612 条、562 船、28 过境、16 港。A 为 432 条、385 船、7 过境、7 港；B 为 180 条、177 船、21 过境、13 港。A/B 船只和过境无交集，港口并非隔离单位。
- 端点为 `base + delta_vv`（旧 VV 修正头）和 `base + delta_vh`（中心化 VH 修正头）；base 本身已含双极化信息，不能把它们描述为两个纯单极化图像分类器。三种子与上轮 `prior_vv`、`center_vh` 源端分数完全一致，最大误差均为 0。
- 四种 top-1 结果互斥完备：两路皆对、仅 VV 对、仅 VH 对、两路皆错。“冲突”专指一正一错；两路皆错但预测不同不算此类冲突。
- CE 使用缓存端点分数转 float64 后的 `logsumexp(score) - score[y]`。`ce_gap_vh_minus_vv = CE_VH - CE_VV`，正号表示 VV 的 CE 较低，负号表示 VH 较低。用严格正负号，不根据结果挑阈值；CSV 单列统计绝对差不超过 1e-6 的数量，仅供数值背景参考。
- 每个种子单独统计；1836 条种子-观测记录只对应 612 个观测，不能当作 1836 个独立样本。源端历史上用于旧组件早停，因此这里不是全管线严格 OOF 或独立确认数据。

这里正 CE 差均指 VV 的损失更低，宏均值按所在折的类别均值计算；A/B 都有全部 8 类，对应上一轮训练损失的类别平衡口径。这是冻结端点损失差，不是拟合门控后的训练损失或潜在收益。

关键分解：种子29中，两路皆对的 296 条有 283 条 CE 偏 VH；两路皆错的 275 条有 212 条 CE 偏 VV，后一组平均 `CE_VH-CE_VV=+1.51744`。因此多数样本的 CE 偏好、损失平均幅度与 top-1 救回数会得出不同方向。数据已经说明总体 CE 优化可能主要改善仍然错误样本的概率，而非选择唯一正确的端点；它尚不能证明具体训练失败由此造成。

所有 11 个种子-观测的 CE/top-1 矛盾均来自双极化可用组，逐样本在 `coverage_samples.csv` 可复查。例如种子29的化学品船 `29647`，VV top-1 正确但 CE 为 1.51698，VH top-1 错误但 CE 为 0.98878。跨类别归一化概率和最大类别排名不同，所以这并非统计矛盾。反方向例子为种子43的集装箱船 `30522`：VH 正确，但 VV 的 CE 更低。

持续正确与持续错误组也普遍有连续 CE 偏好，不能因此将所有 612 条都计成“一路能救、另一路会错”的分类监督。`coverage_ce_top1.csv` 给出完整交叉表。

## 对主线的证据边界

1. 两折存在双向 top-1 材料，不能以“源端无冲突”为理由直接否定相对偏好学习。现有证据尚未判断部署可得的 score/spatial/frequency 是否能区分这些材料。
2. B 折冲突稀疏、类组成与 A 差异明显；逐折和逐类结果应连同总量解释，不能只用合并612后的总 OA/BA 讲学习稳定性。
3. CE 偏好、唯一正确端点、修正总强度是不同对象。若主线验证偏好机制，应分别报告对这些对象的行为，避免把仍然判错样本的 CE 下降称为学会了“正确极化”。
4. 缺失 VH 组的冲突是旧 VV 修正与 base 的差异，需独立报告；它不能证明双极化相对选择机制。
5. 覆盖观察不产生可部署 oracle，不证明泛化或因果机制，也没有用 dev 标签选择模型、阈值或训练方案。
