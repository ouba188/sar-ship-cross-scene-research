# 实际实现与接入范围

本轮是新M2第一次配套分类验证，不是三个新模块全部完成。旧M1（均值+双侧注意力）、旧M2、旧M3 both均在old_full中原样保留，新支路输出delta2。M3分类型匹配尚未训练，64个参考仅提前完成原生分解缓存。

## 可执行链

1. `prepare_native.py`重放原chip的二维PNG和权威placement。VV/VH分别在原图上做DoG，再裁/补到160。1805项，211个缺失VH，3399张有效图；不重标、不改几何、不把裁片缩放。
2. `train_native.py`从旧独立C4前向的layer1源PCA缓存取前7坐标，用真实center=0/stride=4映射到原网格，拼当前极化/尺度的DoG一通道。它不是从原像素训练一个新骨干；插值的粗语义不能被解释成原生细节。
3. 仅644个utility_train拟合6组像素标准化及8类ridge方向。源body均值、4视图均值用于监督投影；随后投影冻结，避免把本轮叫成端到端新表征训练。原生尺度通道的类别权重非零，不能预设未使用。
4. 逐类型处理8通道：恒等、普通3x3深度残差卷积、船轴对称关系卷积。所有极化数据/区域/统计分离，source条件gate可以共享；分支分离检查为双向。
5. 对应先槽均值或先逐位置双侧统计。moment在本轮只读区域合并的mu/h/b，数学等价于保存指数矩再合并；新槽级证据对应要等M3，不将此阶段冒充槽匹配验证。
6. 18类证据的每类mu/h/b及类中心化版本(108维)、18覆盖标记、旧分数与竞争分差(2维)进入共享128->12->1头。输出类中心化增量，零初始，和old_full相加。无有效区域时增量为零。
7. 源训练随机共同C4视图，源选择/开发预测平均四视图增量；每视图单独CNN缓存，不假设CNN等变。

## 实际纠错

- 默认F.interpolate中心错位：源端短跑中发现，改成显式grid_sample，已重拟合reader和全部方案。此前partial保留superseded_alignment。
- 可选卷积先构造会消耗随机数，使同seed头初值不同：调整构造顺序，头初值误差0；只重跑受影响卷积组。此前源记录保留superseded_head_initialization。两项修正均在读取主实验开发分类结果前完成，不使用负结果挑修法。
- score_only较快，先于主实验全部源拟合完成打印了其开发结果；它在打印前已按源端固定选好模型，后续主实验未依据该结果改变任何参数/选择规则。不是目标端选参。
- Godel独立只读复核实际接口、C4、极化、数据角色与配套比较，未发现其余阻断问题。实际首3步梯度记录在training_receipts.json：零初始头先学习末层，卷积末投影随后获得梯度，再传入内层；不是全部参数首步有梯度。

## 边界

源投影冻结、仅7个粗内容坐标、有限80步训练是本轮实现范围；失败时不能据此否定所有原生细节或全部可学习投影。只要产生净收益也不自动证明新卷积必要，需看配套moment/grid和固定头conv_zero。

输入干预/模块置零说明模型依赖，不能自动命名物理散射机制。训练耗时与缓存分支计时分别报告，分支计时不代表包含旧R50、旧M3和检测的整系统延迟。原始缓存/检查点不上传GitHub。
