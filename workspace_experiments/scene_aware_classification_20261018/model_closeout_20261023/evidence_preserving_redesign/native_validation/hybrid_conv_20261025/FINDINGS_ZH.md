# 两版卷积结合验证：有直接救回，额外几何/晚汇总优势尚未成立

2026-10-25。15次源训练、完整开发推理、固定分类头开关、24条源观测采样诊断与6个原始VV/VH案例均完成。旧主模型不变。本轮只改M2补充通道，不改M1、M3、支持案例、类别投影或标签。

## 结论先行

可以保留区域条件核作为有局部效用的候选，不能把本轮称为“两版优点已经互补成立”。结合版固定头seed43直接救回2例、误伤1例，是真实卷积作用；seed17误伤2例，seed29无翻转。固定图像轴与船轴版的全部top-1预测一致，先平均对照略优于分别处理后汇总。因此不把船轴采样和晚汇总列为已验证的增益模块，也不因其他单元退化删除2个救回案例。

五组：moment无卷积、grid_role固定轴区域条件核、axis_difference现有轴向均值差分、axis_early先平均后条件核、axis_role两端分别条件核再平均。后三个role结构同为1324卷积参数；axis_difference1244参数。所有组同一1561参数补充头，头初始化和源归一化相同但分别训练。grid_role是旧RoleConv思想的8维匹配移植，不是历史32维版本重放。

source644、selection612、development485；开发有445船、29过境、14港。类别数：[散货169，渔船91，普通货69，化学品/成品油67，集装箱33，原油13，拖轮40，海工补给3]。种子17/29/43，固定80步x32；选择点均为40/20/80，均由源selection确定。开发队列反复参与过研发，不是独立确认，也未扩展数据集/支持预算。

## 数据层面诊断

固定每类按obs_id取最早3条源观测，共24条；VV24、VH22可用，每个极化3频带4对方向。对源标准化输入统计：

R = ||(x+ + x-)/2 - x0||² / [ (||x+ - x0||² + ||x- - x0||²)/2 ]。

这是双端局部变化经过平均后的平方量比例，不是原图能量比例，更不是类别信息保留率。

- 7维语义坐标R中位数0.2847，均值0.3302；半径1、2、4时均值约0.174、0.285、0.532。
- 原生频带通道R中位数0.5151，均值0.5212；细频带约0.696、中频带约0.525、低通约0.342。
- 这说明平均抵消在真实输入中确实存在，尤其在插值语义坐标的小半径上；但它不证明被抵消部分是判别证据。分类对照未支持“保留更多两端关系就更好”。

## 原图证据与合理解释

已实际查看6组原始chip及固定M3使用的同类、混淆类参考，VV/VH分开，原像素裁补，不缩放船体。完整数值和路径见CASE_REVIEW_ZH.md及analysis/*.json。

- 25398：短亮主体，真类与化学品参考均有紧凑目标，外观不足以直接判类。卷积使海工对化学品分差-0.05432→+0.01013，VV框内和VH框内/轴端/侧向均有正作用；改成先平均仍正确。不能把它解释成晚汇总或船轴方向特有收益。
- 33528：VV有明显交叉亮纹，VH主体更集中。卷积使化学品对散货分差-0.01235→+0.01547；VV框内/侧向正、VH侧向负。不能从交叉纹直接命名物理机制，也不是VV/VH同样的增强。
- 20418：细长亮主体与两类参考都有相似处。分差+0.02510→-0.03191，主要是VH框内被改偏；不是只有外围背景才会产生误伤。
- 25781：小目标、与海工参考均较紧凑。先平均时分差+0.001128，分别处理后-0.000618，是真实但非常接近边界的翻转，不据此否定全部晚汇总路线。
- 18157持续正确、22406持续错误：增量很小，没有把持续正确记为救回，也没有将未翻转概括为没有任何响应变化。

## 成本与保留决定

每种子训练含源验证平均耗时：moment15.00s、axis_difference35.10s、grid_role47.04s、axis_early36.89s、axis_role48.87s；不含公共源统计和最终开发推理，不是部署延迟。结合版相对先平均耗时更高且当前收益更低。

保留：旧主模型；历史RoleConv14救回/7误伤记录；本轮区域条件核的直接救回与先平均候选。暂不提升：船轴取向独立优势、晚汇总独立优势、创新模块已完成。

下一步若继续，应先回到旧RoleConv有直接收益的32维表示/原接入上做同输入桥接，或用更简单的匹配值通道对照辨别本轮收益来自局部组合还是常规通道变换。它们是待选下一步，不是本轮已执行实验。不自动增加更多采样方向/自由偏移，不用新名称覆盖弱证据。
