# 两版卷积取长补短：匹配验证

2026-10-25。预先固定协议；本目录不覆盖历史结果。当前是开发集验证，不是独立最终确认。

## 数据依据与问题

旧RoleConv固定头seed43救回14例、误伤7例；25745的轴端/侧向增益与23397相同区域的损伤共同提示：区域内容的利用方式有价值，但不能把外围默认当好或坏。近期AxisPairConv在485查询、3种子的固定头开关中没有正确性翻转。

当前轴向卷积虽把两端绝对差输入门控，实际值通道只有(两端平均-中心)。中心8、两端10/6时该通道为零；这证明表达约束，不证明它就是总体失败的根因。新候选先按内容和区域关系分别处理两端，再对称汇总，同时保留邻居本身与邻居-中心两个值通道。

## 固定条件

- 复用source644、selection612、development485；不重新划分、不扩公开集。485查询对应445船、29过境、14港；逐类数量以实际表格重算。
- 每极化独立，三个原生频带独立：7个冻结PCA坐标加1个原生DoG/低通通道，8维；仅语义坐标由stride4特征插值，频带保持原像素尺度。裁大补小、不缩放船体。
- 同一源端6组类别投影W/bias、标准化、温度固定。不沿用上一轮可学习投影，避免混入它的分类变化。
- 全部使用相同的逐像素高低侧响应摘要，等价于矩统计合并；不把局部先压成均值。旧完整模型、M1和M3及实际支持/参考不变，输出为旧完整分数加新增M2残差。
- 17/29/43种子；80步、每步32、8个微批；完全相同抽样与C4旋转。AdamW lr .003、wd .01；半经验/半类均衡CE。源selection按J=(OA+BA)/2在0/20/40/80选，0步保留为回退。所有15次源训练选定后才读取开发集结果。
- 同种子头初始化与初始源标准化完全相同，残差输出零初始化。边界一致要求中心与两侧均有有效像素；不把补零当海面。

## 五组对照

|组|采样|值通道与组合|
|---|---|---|
|moment|无新增卷积|相同M2头/池化|
|grid_role|图像固定轴四对点|两端分别做区域条件核，再平均|
|axis_difference|现有AxisPairConv|两端平均减中心，现有门控|
|axis_early|船轴四对点|内容/区域先平均再做条件核|
|axis_role|船轴四对点|每端内容与对应区域先做条件核，再平均|

grid_role是旧RoleConv思想的匹配移植，不是旧32维/九宫格/旧接入方式的精确重放。为分清采样与关系处理，三个role组使用相同参数结构、半径1/2/4原像素和四对方向；固定轴的斜向点等半径，不叫整数九宫格。axis_early/axis_role仅改变汇总顺序；axis_difference是结构参考，不能把它与axis_role之差全归于某一项。

条件核由中心8维、邻居8维、4x4区域角色关系(含区域外)、极化频带类型4维、相对船轴三个无向二次坐标组成，经12隐藏单元到4个核基权重。核基有原邻居和邻居-中心两个值通道，极化频带分别持有基与输出矩阵。两端共享处理，180度轴符号反转只交换两端。无绝对朝向类别输入，不声称真实观测旋转完全不变，也不输入缺失的雷达轴。

## 检验和解释

实现检查检测：非零算子下180度符号不变、VV不受VH改动影响、缺失像素不注入增量、门控能获梯度、各组初始描述/分数/分类头一致。失败则先修实现，不启动主训练。

报告OA/BA/NLL/Brier、三种子配对救回/误伤、逐类与逐过境收益和计算成本。固定已选分类头关闭卷积，区分头改变和卷积直接作用；对新算子切成先平均仅作机制干预，不能替代独立训练对照。按过境聚类bootstrap给出开发证据范围，不要求每类都赢。
