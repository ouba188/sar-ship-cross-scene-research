# 原始chip回看：结合版卷积

2026-10-25，主代理实际查看6张面板。每张含查询和固定M3真实使用的两张同类/两张混淆类参考，分别VV/VH。图像展示原160像素画布裁补，不缩放目标；黑色补边不是海面。样本路径、框、极化有效性和预测值见analysis/cases.json、extra_cases.json。

所有区域量是固定头下，将一个极化/区域的卷积后描述替换为关卷积描述，观察真类相对固定竞争类的分差变化；三个频带一并替换。非线性头下这些量不能相加，也不是对原图某像素的物理归因。

## 25398 / seed43：直接救回海工补给

图：analysis/rescue_25398_43.png。原主模型也错，该例不是仅修复新增头制造的错误。

查询VV/VH为短的倾斜亮主体；真类30434较相似、13344更竖直；化学品31086/24840也包含紧凑亮目标。不得把同朝向或肉眼相似当作类别机制。固定卷积开关：化学品3→海工7，真类-对手分差-0.054317→+0.010133；旧主模型该分差-0.543678。先平均干预仍为+0.008832，因此晚汇总不是该次救回必要条件。

条件区域效应：VV框内+0.020561、轴端-0.001752、侧向+0.000357；VH框内+0.025620、轴端+0.009033、侧向+0.010936。该例同时利用框内及VH外围的补充，不是“只靠背景”。真正起作用的原图散射点和物理来源尚未定位。

## 33528 / seed43：直接救回化学品

图：analysis/rescue_33528_43.png。原主模型也错。

VV有长横亮主体与明显交叉亮纹，VH横向主体更集中、交叉纹弱；同类7564/28586呈不同朝向亮主体，散货26615/2379也呈横向长亮主体。不能用横竖朝向区分类别。固定卷积开关：散货0→化学品3，分差-0.012348→+0.015474；旧主模型该分差-0.460786。

VV框内+0.032667、侧向+0.016458，轴端-0.010298；VH轴端+0.017534，但框内-0.010092、侧向-0.017953。局部正负作用同时存在且极化不同；只说“增强邻域”不准确。未将交叉亮纹命名为旁瓣或尾迹，也未证明它是救回原因。

## 20418 / seed17：直接误伤散货

图：analysis/harm_20418_17.png。

查询细长、VV/VH主体清晰，与散货23049/26615及化学品31086/24840均有部分共同外观。旧主模型分差+1.214092；新增头即使关卷积已变成+0.025096，卷积进一步压到-0.031913，散货0→化学品3。

主要条件负效应是VH框内-0.041924和VV框内-0.014315。必须分别承认新增头造成的大部分分差损失与卷积导致的最终翻转，不能把全部+1.214到-0.032归于卷积，也不能只怪邻域背景。

## 25781 / seed43：晚汇总的直接误伤

图：analysis/harm_25781_43.png。

查询很小，VV/VH有紧凑倾斜主体，VV图上边还有独立亮点。海工和化学品参考也都较紧凑。远亮点不一定进入该卷积的局部采样范围，不能据此解释误伤。

旧主模型化学品对海工分差+0.498297；结合版关卷积+0.058966；结合版先平均+0.001128；分别处理后-0.000618。后两者在同一权重和头下唯一差别是汇总顺序，说明这个个案中晚汇总造成近边界误伤。只作个案解释，不把极小翻转升级成普遍方向否定。

此例保存的区域诊断仍相对关卷积：VV框内-0.032491，VH框内-0.018327等。它不等于“晚汇总相对早汇总”的区域归因。

## 18157 / seed29：持续正确渔船

图：analysis/CC_18157_29.png。查询较小，VV背景纹理较明显，VH更暗；同类与拖轮参考在长度、紧凑度和极化表现上并不一致。渔船对拖轮分差+2.851184→+2.850982；不同区域增量有正有负，抵消后变化很小。原有判别已充分，本次卷积不是正确分类的必要条件。

## 22406 / seed29：持续错误普通货船

图：analysis/WW_22406_29.png。查询VV/VH为细长亮条；真类26409/33307与散货23049/26615都有长条/紧凑主体及不同外围纹理。不能只按肉眼亮条长度判断错因。

普通货对散货分差-0.227298→-0.227139，仍错；六区域条件效应约1e-4量级。该算子没有提供足够增量跨越现有边界，但尚不能判断是原图类别证据不足、8维输入限制，还是训练没有学好这些关系。

## 可用边界

本轮可确认2个seed43直接救回，均伴有小幅跨界；也有真实误伤。收益既不局限于外围，也不在两极化上同向。先平均/固定图像轴能够获得相同或更多救回，故现阶段保留的是局部条件补充候选，不是已经成立的船轴几何创新。6张事后诊断面板不是全体比例，也不是6个独立实验。
