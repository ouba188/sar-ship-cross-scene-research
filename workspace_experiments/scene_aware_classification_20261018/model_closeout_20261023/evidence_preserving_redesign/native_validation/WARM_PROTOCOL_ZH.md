# 根因纠错：冻结已有读出，仅训练卷积

这是首轮开发结果之后提出的研发对照，不伪称预注册或独立确认。原四组结果保留。

依据：axis与moment三个种子预测完全相同；固定头关闭axis卷积仅0/0/1个预测变化，且全部正确性不变；梯度存在，但gate内层第三步约1e-7，主头约1e-1。梯度量级不能单独证明竞争原因，因而做配套纠错。

每个种子继承源选择的moment头及其标准化，冻结读出与源类别投影，只训练新卷积。普通grid与axis各3种子，均80步×32、同C4抽样/AdamW/源选择规则。零卷积精确重放父模型，保留step0候选。源选择集再次用于阶段选择，属于顺序开发；不根据开发查询结果挑步数或学习率。

若相对moment仍无独立增益，就不能把初始零头的梯度延迟当成主要解释；不再通过提高学习率、自由offset或增加层数继续搜索。本轮结束后再决定新M3如何使用已有槽证据。
