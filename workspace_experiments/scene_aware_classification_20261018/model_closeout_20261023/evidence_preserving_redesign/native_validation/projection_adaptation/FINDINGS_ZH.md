# 类别投影适配：有类别收益，但未激活船轴卷积增益

2026-10-24。两结构×3种子共6次源端拟合及完整推理、配对分析和4组原图回看完成。新增432个可训练投影参数，旧M1/M3、输入、池化、head结构和训练预算不变。不是新版M3，也不是OSS1第26轮诊断器的重训。

## 结果

评价仍为当前完整模型的485张开发查询、445艘船、29次过境、14港；源训练644、选择612。历史研发队列，不宣称独立盲测。各种子独立预测后平均指标，不是分数集成。

|方案|OA均值±种子标准差|BA均值±种子标准差|NLL|Brier|
|---|---:|---:|---:|---:|
|旧完整模型|59.66±1.75|40.89±2.17|1.20241|0.54915|
|冻结投影+分布池化|59.11±2.77|39.44±0.90|1.20639|0.55274|
|冻结投影+船轴卷积+分布池化|59.11±2.77|39.44±0.90|1.20657|0.55281|
|可训练投影+分布池化|57.80±0.31|41.04±0.91|1.24405|0.56802|
|可训练投影+船轴卷积+分布池化|57.80±0.31|41.04±0.91|1.24405|0.56803|

相对同结构冻结投影，适配平均OA -1.306pp、BA +1.600pp；相对旧完整模型OA -1.856pp、BA +0.146pp。不能把BA相对较弱新支路的提升说成完整模型提升1.60pp。概率评分也未改善。

船轴/无卷积在每个种子上的485张分类预测全部相同，含错误类别之间的比较；不是仅OA/BA碰巧相同。因而投影适配并未兑现船轴卷积的额外分类收益。

- 普通货船69张，三种子净救回+7/+1/+5，平均召回+6.28pp，是可保留的类别正信号。相对旧完整模型则+9/+3/0，平均召回+5.80pp，不声称三次都超过主模型。
- seed17主要代价为169张散货船净损失28张，而普通货、原油轮、拖船等获益，解释了OA下降而BA上升。seed43的海工类只有3张，其中救回1张就贡献该类33.33pp召回变化、整体BA4.17pp；不能把它当大规模海工证据。
- 化学品67张相对旧完整模型仍有+11/+3/+3净收益，但相对冻结moment为-2/0/-3；部分旧类别收益被读出重分配削弱。不能只选一套对照宣称全面改善。
- 不能通过预测时未知的真实类别手工开启本模块。当前结果是可进一步发展类别证据利用的边界，不是已可部署的类别开关。

按29个采集cluster配对bootstrap2000次、先平均种子：适配相对冻结moment的OA区间[-2.679,约0]pp、BA[-0.901,+3.614]pp；相对旧完整模型为OA[-3.539,+0.444]pp、BA[-1.972,+1.805]pp。BA仅使用包含八类的1736次抽样。区间跨零不等于证明退化都是随机，亦不否认普通货的描述性重复收益。

## 实现和解释闭环

1. 两结构初始描述子、零增量分数及head初值重放误差均0。W/bias被注册为参数，源分类训练第二步开始有非零梯度，不是只靠AdamW衰减产生漂移。首步输出头零初始化导致上游梯度为0属于预定结构。
2. 选中W相对源ridge的L2变化约0.39/0.32/0.96，说明投影确实可动；这不自动代表学到了更好的分类证据。两个新增组给予相同432参数和优化机会。
3. 六拟合累计约169秒（不含全队列推理/分析）。种子17/29源选择20步，后续选择J下降；43选择80步。未按开发结果改变轮数。这个固定预算比较不证明充分优化后的模型上限。
4. 图像中实际可见的共同点与差异见CASE_REVIEW_ZH.md。19531缺VH，缺失分支替代必须不适用；分析初稿对缺失描述子填平均信息会制造虚假VH变化，已纠正，所有训练与主指标未受影响。
5. 220的救回在固定新head、恢复原投影后仍存在；1128的误伤也未消失。因此这两个案例不能归为最终W独自起效，属于允许投影参与后的联合优化结果。固定head替换存在表征不匹配，只作敏感性诊断。

## 决定与下一步

保留旧完整模型，不把本轮候选替换为主方案；保留适配的普通货类别正信号、BA变化和完整负结果。不要求所有类别获胜，但当前整体OA/NLL/Brier代价不能被0.146pp的主模型BA增量掩盖。

本轮削弱“只因类别投影冻结，船轴卷积才无效”的解释；结合上一轮冻结头只训卷积也无净收益，不再继续对同一核盲目加步数或学习率。不能由此否定所有船轴设计。

下一处更具体的结构缺口仍是：本阶段只输出区域合并的mu/h/b，独立位置描述尚未用于新M3匹配。后续应在保留旧有效基础和极化身份的前提下，检验空间位置保留能否改善真实查询—参考竞争；不要以本轮船轴核为必要前置。尚未实现或启动该实验。
