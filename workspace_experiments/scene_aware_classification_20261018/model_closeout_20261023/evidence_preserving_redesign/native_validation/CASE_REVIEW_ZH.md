# 原生尺度M2原图回看

实际查看四种状态的原生160裁补VV/VH和同类/混淆类参考面板。绘图放大仅用于显示，模型输入不resize。两种新读出生成了8面板，但对应4个独立查询，不能当8份独立证据。完整路径、ID、源选择步数和替换数值见analysis/cases.json。

## 1377：成品/化学品船被救回

- seed17，旧预测集装箱4，新预测正确类3；分差-0.57698变+0.74687。
- VV目标斜向、两个较亮条状/斑块响应；VH较连续紧凑。真类9086/7826、混淆类21323/26479均能出现细长亮主体，不能从单一外形断言哪类。
- 用源均值替换新增VH证据后，固定竞争分差降至-0.29321，重新预测集装箱；替换VV后仍判对。说明该新头确实利用了VH证据，而非只用旧分数。
- 关闭卷积仍判对，固定分差变化仅0.000489；无卷积moment也救回。收益不能归功于新船轴卷积。
- 参考未变，不能声称本轮重新找到更好的同类匹配。也不能将VH的贡献直接称为某个物理散射机制。

## 6373：散货船被误伤成成品/化学品船

- seed17，旧预测0，新预测3；分差+0.11022变-1.46056。
- VV查询周围显示较亮的细碎纹理，主体短而紧凑；真类33678/23781同样有亮主体，其中23781明显更长。化学品7826/9086的主体形态与紧凑查询存在可见重叠，方向不能当船型证据。
- 替换VV或VH新增证据为源均值均减轻错误竞争分差，但单独替换尚未救回。两路新证据均可能误导，不能把一极化固定认定为可靠。
- 关闭卷积分差只改变约0.001086、仍错；moment亦同样误伤。问题主要已出现在新增类别读出，而不是轴采样引入一个大幅错误。

## 17004：持续正确的渔船

- seed17，渔船1持续正确；分差+5.30603变+7.71313。
- VV/VH目标都很小、较暗，真类16248/15663与海工22841/22924参考也都紧凑。一个错误类参考缺VH，面板明确缺失，未当成黑色海面证据。
- 将VV/VH新增证据分别替换为源均值，分差降低约1.075/1.468，但仍正确。这是置信分差变化，不是新增救回。
- 关闭卷积反而略提高分差约0.001566；仍无卷积必要性证据。

## 16727：持续错误的渔船

- seed17，持续误判散货0；真类分差-2.12055变-4.05443。
- 查询呈斜向连续亮主体，真类15934/20215更小；散货23049/26615也具有明亮细长主体。可见的尺寸/明亮结构重叠是分析线索，但不能仅凭图像认定标签错误或特定散射成因。
- 替换任一极化新增证据均能减轻错误分差，仍不足以救回；关闭卷积的作用仅约0.00465。
- 它与17004同为渔船，结果却相反，说明不能按船型统一启用这套新增读出。

## 有限结论

已证实：新证据进入了类别竞争，能补充，也能把紧凑亮主体误向另一类推；VV/VH不能提前视作同一种证据。当前救回/误伤主要由新读出产生，船轴卷积的独立贡献很小。

未证实：具体海况/散射机制、形态重叠是全部误伤根因、改变参考匹配即可救回。上述4例按预定状态和较大分差变化选择，不代表总体比例。整体和逐类数值必须回到FINDINGS与classes.csv。

## 冻结头纠错的原图补看

warm_axis seed17相对moment有6张预测变化，已生成6组面板；主代理实际补看3张误伤和1张错误类别变化，不把生成等同于查看。

- 7085散货：斜向连续亮主体，VV内部块状、VH较细长；真类33678/23781和化学品9086/24840都有亮主体。小正分差0.01573被卷积推成-0.04512。
- 20418散货：接近竖向细长响应、背景较暗；真类23049比查询短、26615方向不同，化学品31086也有细长响应。0.02749变-0.02270。不是和7085相同朝向造成的统一失败。
- 28319散货：斜向，VV背景较亮碎、VH主体明亮；0.01236变-0.04097。原参考未更换，和6373一样存在短亮形态跨类重叠，但不能据此认定这就是完整因果解释。
- 22406普通货：从错误散货变成错误拖轮；VV主体短、VH显示明显更长及纵向亮结构。仅记录极化显示/几何差异，不把它自动命名为散焦、临船或关联错误。相对新拖轮竞争类分差-0.68313变-0.67731，稍改善仍远未判对。
