# M2在layer2最后一个bottleneck内的位置比较

2026-10-28，结果产生前冻结。本轮只比较位置，不搜索次数、学习率、损失或最佳epoch。

## 数据与图像依据

沿用136条源适配、160条历史开发查询、16条源参考；原生160画布裁边/补零，不缩放船体。源、开发、参考的船只及过境不重叠；开发只有3港3过境7个实际出现类别，网络仍为8类输出。源适配128艘船20过境10港，开发158艘船；详见上一轮DATA_NOTES_ZH.md。

已重看10502的VV/VH及同类/混淆类实际参考：查询为短小亮主体，VV有细线，VH更紧凑；普通货与化学品参考均有短亮主体。此前layer1回写使此例由对变错，另有救回例，不能把区域级偏置视为普适有益。此前layer2的3075扩围BA增加而OA/NLL/Brier变差，说明要检验组织/利用方式，不预设浅层越多越好。

本轮假设：同一类区域摘要在残差分支中、局部卷积之前或之后加入，可能比阶段末尾直接回写更好地兼顾判别与信息保留。原图没有证明该假设；本轮配对训练用于检验。

## 固定比较

baseline：无新增浅层M2；stage：layer2输出后新增一次；pre3x3：layer2.3内部BN1/ReLU之后；post3x3：layer2.3内部BN2/ReLU之后。两种内部位置不改捷径、BN/ReLU顺序和下采样，均128通道20x20；stage为512通道20x20。内部前后等容量，内部对stage包含容量差异，不声称纯位置隔离。原深层M1/M2及M3保留。

VV/VH各一个专属适配器，参数在两内部位置同初始化；均隐藏维32、输出层零初始化。相同teacher、101/136干预选择掩膜、固定参考、相同源样本顺序17/29/43；6epochs/54steps/有效batch16。新增M2 lr3e-4，原layer3.5三卷积lr3e-5，weight_decay .01；其他参数和BN状态冻结，下游冻结运算仍可传梯度。M3比较锚点固定、内容路径实时更新，查询和参考使用相同当前模型。

baseline/stage直接复用上一轮完全相同协议的6个已训练模型及结果，先逐模型重放确认；只新训练pre/post共6次，不把复用包装为新训练。内部prefix只缓存到layer2.3之前，绝不缓存绕过新增模块的输出用于内容路径。原raw2仍只用于固定M3比较及指定诊断。新代码不覆盖已发布默认模型。

## 具体检查与判断

- 零初始化恒等、非零更新时原生block+hook对照、缓存/实时prefix重放：检出shortcut、ReLU、插入位置和缓存绕行错误，失败先修代码。
- 首步输出梯度及后续内部梯度、保存重放和冻结权重不变：检出死分支/丢失训练权重/非预期微调。
- 固定末轮OA/BA/NLL/Brier，逐类与救回/误伤；不按开发查询选最佳epoch，不自动扩大调参。
- 无重训关闭回写只能说明已训练模型的依赖，不替代有无模块的配对训练比较。
- 原图VV/VH与实际同类及混淆类参考必须回看，区别可见现象与已证实机制。
- 这是历史开发集上的设计实验，不是新盲测。若无净收益也保留负结果；下一步是否测试次数由本轮证据决定，不自动全排列。
