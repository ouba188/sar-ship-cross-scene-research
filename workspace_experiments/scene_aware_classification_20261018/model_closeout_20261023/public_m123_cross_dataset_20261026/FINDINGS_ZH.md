后续更新：已完成源恒零维度修复的完整重放，见normalization_repair_20261026/FINDINGS_ZH.md。本报告数值仍为原冻结结果，未覆盖；修复后正向B为50.4632/46.8130，频域50.5044/46.8156，反向不变。

2026-10-26，两个方向、每方向17/29/43三个种子全部完成。没有在目标数据集上训练、选择比例、重选checkpoint或拟合标准化。主要结论：**B相对旧both的平均收益具有方向性；新增空间-频域调权的准确率增量很小，尚未证明可稳定替代B。M1的累计分类收益在两个方向保留，M2的追加收益没有迁移过去。** 这不是否定此前同数据集、特定范围内的有效性。

## 4. 旧邻域D标准化失稳：已完成一个单因素诊断

路径：`normalization_diagnostic/`；脚本`diagnose_neighborhood.py`。没有使用目标类别、没有重训，没有改正式预测。

OSS1源fit中VV有10维、VH有8维邻域特征全为0，标准差均被下限置为1e-5。目标OSS2中部分维度不再为0，例如VV通道96最高2.2132704，除以1e-5后约221327。这不是频域物理强度，而是网络特征的数值归一化。

固定模型、图像及其他输入，仅把这18个由源数据定义的恒零维度置零：

|量|原冻结输入|单因素屏蔽|
|---|---:|---:|
|目标标准化输入最大绝对值|221327.05|1511.53|
|seed17 D残差最大绝对值|1383.35|5.69|
|D残差大于100的目标数|68|0|
|源fit D输出变化|0|0|

种子29/43该D支路源端选零步，输出均0；OSS2源训练的D三种子也均0，因此反向迁移没有同样D爆值。原始预测中axis/A仍在正常量级，U=A+D首先爆值，再传到M1/M2及M3，明确定位到上游D，不是数据表错位或目标读出器偷用。

已证实：源恒零特征在目标激活后被极小标准差放大，是这批D爆值的计算原因。未证明：它解释所有跨域误判、屏蔽后最终OA/BA一定更好，或对应某个物理散射因果因素。本轮没有据目标成绩选择屏蔽策略或重报修复后主表。下一步最小修复应在源端就排除不可学习的恒零输入，再固定重放全部后续步骤；低但非零方差维度仍可能失稳，不能把5.69当作完整修复已经完成。

## 6. 这轮允许得出的结论与后续

1. OSS2同数据集留采集复现已完成，B比旧both有平均净收益，见相邻OSS2报告。两个冻结跨数据集方向也已完成，不再只是少量样本或缓存重放。
2. 公共数据上M1有累计分类收益；M2需区分同数据集训练与跨数据集迁移，其后者不是稳定提升。保留已有范围内有效组件，不把反向负结果升级成一票否决。
3. B在OSS1→OSS2平均胜旧both，但反向BA退化；两个方向不是可互换的独立重复。空间-频域版暂保留有界候选，不能宣布稳定优于固定融合，也不能把新VH或频域单独写成已经验证的必要因素。
4. 下一轮优先修复有证据的上游恒零特征标准化失稳，并针对少数类损失与支持OBB疑点做有限对照，不继续无目标增加注意力层。修复后必须保留本冻结结果并分别报告。

本轮全部训练/推理/分析进程结束。代码、结果表、分组区间、原图派生面板及正负案例同步研究仓库；原始数据、权重和大型缓存不上传。
