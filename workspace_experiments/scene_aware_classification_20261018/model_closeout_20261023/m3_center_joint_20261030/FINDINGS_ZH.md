# M3中心化联合适配：开发重复与路径拆分

2026-10-30。阶段工作完成，目标仍未达成；正式模型未替换。本轮没有读取自建完整3075或OSS2完整378评价标签/预测。

## 本轮改变了什么

不再从训练完成的模型追加续训，而从各训练顺序的原source_fit端点进入原有六轮干预适配。两组同时更新原末block三卷积权重和M3值投影、输出、gain，使用相同数据、批次顺序、原干预教师、LR3e-5、加权CE/保持KL/分差约束。M1/M2、分类头、其他骨干及比较参数冻结。唯一组间差异是M3比较前按源fit中心化。

共12次短训练：自建6次×54步、公开6次×96步，总900优化步。另做24个不训练的组件移植诊断，分离M3变化与LIVE末段卷积变化。三顺序为17/29/43，共用原初始化与评价查询，不当作独立数据集重复。

源码experiment.py、transplant.py；约定见PROTOCOL_ZH.md。模型结构未扩张，源中心为固定统计缓冲区，无新目标标签。复用前轮正确保护锚点校准；reader的无梯度gain已从后续训练参数清单明确剔除，首组四个保存模型核对确认这些值实际未改变，不据此重跑或改变结果。

## 路径拆分回答了什么

将训练结果中的新M3或新LIVE分别放回保存的原完整模型，其他参数不动。以下为相对原完整模型的三顺序平均差，单位百分点。

| 来源/移植部分 | 自建OA / BA | OSS2 OA / BA |
|---|---:|---:|
| raw_joint，只M3 | -0.208333 / -0.216450 | -0.292398 / -0.187266 |
| raw_joint，只LIVE | -0.625000 / -0.811688 | 0 / 0 |
| center_joint，只M3 | -0.208333 / -0.514069 | -0.146199 / -0.095785 |
| center_joint，只LIVE | -0.416667 / -0.720418 | +0.146199 / +0.095785 |

这排除了本轮的一个简单解释：不能说“新M3本身已稳定有效，只被共同更新的末段卷积抵消”。自建只移植中心化M3有2救回、3误伤，正负均存在；公开只移植M3也不能保住联合版的新增分类收益。联合训练产生的参数依赖不能拆开后默认可相加。

这些移植说明具体权重组合的作用，不等于证明一般训练因果机制；不能将center训练所得LIVE-only的小增益包装成M3推理算子的独立贡献。完整/只M3/只LIVE的概率指标也各有权衡，见analysis/*/transplant_means.csv。

## 数据层面的新增发现

自建适配136张中：散货54、普通货26、化学品28、原油12、集装箱6、渔船4、拖船3、海工3。各类逆频权重总量均约17；单张拖船/海工权重5.6667，单张散货0.3148，相差18倍。按实际batch归一化后三张海工约承担9.9%至10.3%的CE系数暴露，而其样本占比约2.2%。

这不是实现错误，正是已有类平衡训练的定义。它说明少量船只可以对训练产生较大系数影响，为后续检查梯度与覆盖提供具体对象；但系数暴露不是实际梯度，不能据此直接认定它导致本轮误伤。自建新增独立误伤10407属于集装箱，也不能跳过证据把原因归给海工权重。

source表还列出每类MMSI/过境、教师判对数及useful标记。拖船和海工三顺序教师均没有正确预测，因而没有原正确预测KL保护；这说明训练保护是样本依赖的，不等于整个类没有训练监督。详见analysis/private/source_adapt.csv。

## 原图与有效范围

已逐张查看两数据集四态画廊的12个VV/VH面板及公开独立增量003648的2个面板。自建没有救回、公开没有误伤，因此不伪造缺失状态。公开003764没有有效VV，不能解释成真实黑图。图像使用实际原尺度crop/pad及真实合法源参考。

另已查看private组件拆分的30526救回、6194误伤各VV/VH，合计本轮18面板。30526仅M3移植有效而完整joint仍错；6194则仅M3移植误伤、完整joint正确。两个相反例与总体2救3伤共同限定了组件依赖的解释范围，不能只挑前者主张找到了修法。

自建10407是小型紧凑集装箱响应，和散货参考也有外观近似；原正确分差本已接近0，中心化后跨越错误边界。公开003555为沿轴排列的响应，中心化将集装箱相对散货分差从负变正；但普通货、散货参考也有相近亮点结构，不能凭图证明哪一处物理散射产生收益。详细数值与可见事实见CASE_NOTES_ZH.md。

## 决定

保留公开开发小信号、全部负结果及路径拆分，不将中心化joint升级正式M3，也不继续扩本候选的完整测试或倍率扫描。短期目标仍是两数据集上的额外净收益，没有降低为只公开有效。

目前更具体的下一处问题是：M3参数学习与分类目标、实际源适配案例覆盖之间是否一致。优先用源端梯度/案例检验少量高权重案例是否主导错误更新，再决定回放更广源案例或调整训练读出；不把数据数量、类平衡或固定分类头直接认定为已证根因，不因此重构M1/M2。
