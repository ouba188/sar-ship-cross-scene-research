# 后续根因对照：配套源端归一化

启动依据：首轮固定槽对源训练数据高低响应差的压缩比例中位数约7%—18%，但头仍沿用旧区域读出的标准化。这既可能改变可用统计，也可能改变优化条件，不能直接将整体退化认定为池化方向无效。

本小对照只比较 grid_refit 与 static_pool，不新增可学习卷积/池化，保留第一轮全部记录。各自的头输入均值/标准差仅从utility_train的644条样本计算。通过转换第一层权重和偏置，保证更新标准化后零步函数与原初始化一致；重放通过后才训练。

继续使用三个原seed、100步、每步64例、同样8例梯度累积、相同类别权重和源J选点/旧模型回退。不修改支持、查询、类别或标签，不用评价结果选择归一化。结果作为看到压缩诊断后增加的探索性对照，不能冒充预注册或独立确认。

如果改标准化即可恢复，说明首版优化条件是实质瓶颈，应再在一致口径下评价算子；如果未恢复，只能排除“简单换尺度就够了”，不能单凭这个对照证明被压缩统计必然是全部损失来源。
