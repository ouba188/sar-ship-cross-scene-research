# M2 卷积与池化首轮实现

## 接入位置

M1 均值加双向类别响应注意力、M3 both 的输入和输出贡献均固定。新算子只替换 M2：

`完整输出 = 旧完整输出 - 旧M2贡献 + 新M2贡献`

因此本轮不是从头训练三模块，也不是让 M3 使用更新后的局部 token。此前 M3 的空间—频率收益不能算作本轮卷积或池化收益。

## 卷积实际计算什么

读取冻结 R50 layer1 的局部特征。原类别响应用完整256维特征计算；新增路径使用既有源端 PCA32 坐标。每个中心位置取固定3×3邻点，按以下信息生成四个核基的混合系数：

- 中心和邻点的16维内容；
- 两点属于框内、轴端、侧向区域的软身份及9种发送—接收组合；
- 当前偏移沿船轴、垂直船轴的平方与乘积。

四个核基是带正负号的可学习通道滤波器，按偏移分别设置。组合邻点后由16维恢复32维，作为局部特征残差，再经源PCA基和既有类别reader形成类别响应改变量。输出投影零初始化，不改变旧特征；核本身不被限制为正权平均。

这里没有移动采样中心，也没有输入真实雷达LOS轴。先检验角色与无向船轴组织局部组合是否有用。船轴加180度时参数化不变，不代表真实观测角改变时分类绝对不变；C4沿用原骨干的四次真实图像前向。

新卷积2192参数，配套分类头853参数，共3045参数。首版不是设计文档中完全自由的256维残差，适用结论限于当前源PCA32路径。

## 池化实际计算什么

框内8槽、侧向8槽、轴端4槽。OBB坐标给出槽的软几何分配 A0；每个角色内部允许正的软连接，不跨三个角色交换质量。位置内容与槽的初始内容通过共享小网络计算交互分数；包含乘积项，避免只有行项加列项而被质量约束抵消。

`K = A0 * exp(0.5 * tanh(f(位置内容, 槽内容)))`

24次交替缩放后，使每位置总质量、每槽总质量保持 A0 的边际。再对槽内类别响应加权平均，读取槽之间的高低响应分布。新池化240参数，与头共1093参数；卷积与池化组合共3285参数。

这个池化改变“哪些位置被汇在一起”，并不直接删除噪声。固定边际使区域加权均值守恒，只有后续非线性分布摘要能利用分组变化。若卷积也启用，卷积可以先改变区域均值；池化的守恒只针对它接收到的那组响应。

## 数据和训练

原像素160裁补，不缩放目标；两极化分开处理、缺失极化屏蔽。源训练644条、源选择612条，开发评价485条。六臂与三个种子、训练预算及选择标准见 PROTOCOL_ZH.md。

运行环境为本机 ClearSAR Python / PyTorch。依次运行：

```powershell
python -X utf8 -B prepare.py
python -X utf8 -B train.py synthetic
python -X utf8 -B train.py run
python -X utf8 -B analyze.py
python -X utf8 -B diagnose.py
```

prepare.py 依赖本地原图、冻结权重和既有上游缓存；不能仅克隆代码仓库就重现。原数据路径与摘要回放记录在 extraction_receipt.json。训练选点只使用源端；评价结果不用于挑配置。若某臂选择回退，它的输出就是旧模型，不能当作新算子已验证有效。

## 为什么还要做关闭算子的对照

六臂回答匹配训练后的净效果。diagnose.py 则保持已训练分类头不变，分别将卷积残差归零、将池化恢复静态分配，检查已学算子实际改变了多少分数和判断。它是固定模型干预，不代替重新训练的消融。

原图案例另将旧到新分差分成“分类头变化”和“局部表示变化”。六区域Shapley分解只解释新头内部的数值贡献，不将某块亮响应直接命名为尾迹、旁瓣或物理因果机制。
