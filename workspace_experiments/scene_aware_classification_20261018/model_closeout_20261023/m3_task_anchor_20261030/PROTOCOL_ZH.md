# 任务特征作为M3比较参照

当前代码BottleneckEvidenceResNet50.stage3_paths同时返回经过LIVE/M1/M2的x/ref与保护原始raw3/rr3；M3使用前者生成值、后者生成深层比较描述。这是稳定性设计，不是已证错误。前轮图像显示同类形态差异与异类重叠，换参考训练未有独立收益。因此检验已学类别信息是否没有进入比较。

只将M3深层anchor改为当前pre-M3 x、reference.features，均detach；浅层均值和3频带、值映射、匹配算法、回写与原参考库不变。不更新M1/M2/骨干或改变它们的结构；不增加参数。先固定seed17权重，两数据集源适配查询检查实际逐槽reference_weights同类质量与熵，再记录开发预测；不把平均reference_logits当实际回写权重。

是否配套训练取决于明确的可利用变化：合法源同类关系或分类存在值得利用的改善，并且实现确实保持单一变化。无此信号就不做盲目全量重训。若训练，沿用前轮CE同样源样本、54/96步和参数范围，以旧CE端点为匹配对照。若训练后出现额外分类净收益，再固定配置做三训练顺序；不根据最终测试选参数。

本方案是比较特征与分类特征接口的最小实验，不宣称新注意力或因果特征。源域更判别的特征可能过拟合，未必跨场景更好；该边界由开发对照判断，不预设必然涨点。原图按本轮四状态回看，负结果完整保留。

源探针后决定：VV/VH两极化在两个数据集的实际同类权重均上升（自建约+.47pp，公开+.24/+1.00pp），开发无top1变化。进行仅seed17两数据集配套训练，不因无翻转否定学习空间。目标仍为实际分类净收益，若配套后没有相对原版/CE的信号，不扩三顺序。原模型教师、CE+.1原正确KL和AdamW1e-4/.01不变，131446个原M3参数；保存重载后必须重新attach新行为，不能仅加载state_dict。
