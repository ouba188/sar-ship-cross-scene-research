# M3参考覆盖与比较中心化：阶段结果

日期：2026-10-30。短期目标仍未达到，正式M3、M1/M2及骨干结构未替换。

## 结论

源参考覆盖确有不足，但直接扩大或重选参考库未转化为分类收益。源端中心化配合M3值路径训练，在OSS2上相对同预算原M3续训取得小幅正信号；在自建数据上没有独立净收益。两数据集相对保存的原完整模型均表现为BA上升、OA下降，不能宣称已完成双数据集增益目标。

不要求每类、每个顺序都赢。本轮不升级为正式模型，是因为自建集中心化相对同预算对照没有平均净增益，且追加训练损害原模型OA，不是因为存在个别负例。

## 任务与实现

- 自建：24港来源的既有八分类评价队列，3075张、1950艘、85个过境组、18港；2876双极化、199仅VV。本轮不是F_0921新增实验，也不是严格留一港独立确认。
- 公开：OSS2四分类378张、369艘、5个过境组；348双极化、12仅VV、18仅VH。不是八分类，也不是跨数据集迁移。
- 三训练顺序17/29/43，沿用各自已有完整模型端点；共享初始化及查询，不能当成三个独立数据实验。
- 先在自建开发160和OSS2源验证228筛选；唯一候选冻结后评价完整范围。不根据完整范围结果追加参数选择。
- 源fit统计中心，按重复MMSI倒数加权，各极化、区域槽、五描述流分开；比较前由L2(d)改为L2(d-mu)。原参考库不变，未使用查询标签计算中心。
- 仅训练M3值投影、输出和gain，共131074个可训练参数；M1/M2、骨干、分类头及比较器冻结。两臂同样6轮、batch24、LR1e-4、加权CE+0.1原正确预测KL，自建36步、公开66步。
- SimpleShot提供源均值中心化与L2的参考基础（arXiv:1911.04623，第2.1节）；本轮不把中心化本身包装为原创算法。

详见METHOD_ZH.md、PROTOCOL_ZH.md及源覆盖SOURCE_COVERAGE_ZH.md。

## 为什么BA升、OA降

自建相对原版，散货船947张的召回下降3.0623个百分点，化学品船803张下降1.2453；普通货船、集装箱、原油轮、拖船、海工分别有提升。损失集中在两个样本大类，所以按样本计算的OA下降，按类平均的BA略升。这是可核对的数据组成与预测变化，不等于已经证明具体优化因果。

公开相对原版，普通货船26张召回+5.1282、集装箱137张+0.7299；散货132张-1.5152、成品/化学品83张-1.6064。相对同预算续训，中心化净收益则来自散货+0.2525、集装箱+0.4866，普通货与成品/化学品top1不变。不能把普通货船相对原版的改善归给中心化。

自建相对同预算续训，普通货/原油轮有局部收益，但被集装箱、拖船、海工等损失抵消。现阶段可保留这种作用范围信息，不依据测试类别结果另行设置类别开关。

## 已查明与尚未查明

1. 已查明源覆盖不足：自建普通货VH仅1个有效原参考；部分同类参考来自同港；公开每类8参考实际过境覆盖3/7/3/7。候选源数据存在额外覆盖，但不保证可利用性。
2. 已验证直接换库不足：修正实现后，自建coverage同量/双量均OA45.000对原45.625；公开所有换库臂top1均不变。最终候选保留原库。
3. 查到本轮新统计代码的真实接口错误：深层统计曾误用live layer3，而原M3比较用受保护anchor_last。已改为同一路径，真实前向逐值对照最大差为0。旧结果保存在private/oss2，新结果在anchor_corrected；不是正式原模型存在同一错误。修复没有消除总体收益不足。
4. 开发集同类实际参考权重与概率指标有所改善，但直接替换不够，配套训练也未形成双数据集净收益。说明“比较关系改善”与“完整分类收益”仍未完全接通。
5. 原图和配对control确认部分救回/误伤由普通续训即可产生。中心化的独立贡献必须看新候选减control，而不能全部算到新模块名下。
