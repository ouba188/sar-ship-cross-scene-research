# 24港新版紧凑调参：可保留的净收益

## 结论

**合理调参确实改善了新版。本轮可以保留温度0.4、配套重训极化读出这一配置，不需要重构M1/M2/M3。** 在固定3075条跨采集扩围上，相对未调参新版，三种子平均OA+1.4092、BA+1.3555个百分点，三个种子OA/BA均为正。相对同一不接M3的基础模型，OA+1.1382、BA+0.7818。

它还没有超过旧完整模型的平均成绩。旧版继续保留，不以本轮局部改善宣布全任务替换；也不因尚未超过旧版而否定本轮实质收益。

## 做了什么

- 沿用八分类、3075条/1950艘/85过境/18港的固定扩围，以及485条开发评价。不是24个留一港折、不是新增盲测。
- 保持骨干、M1/M2、基础头、图像尺度、64条源参考、每候选类2条参考不变。
- 完成12组配置×3种子，其中default三组复用，另外33组完成对应训练。调整极化头学习率/正则/步数、匹配器学习率/步数、软对应温度；每组再检查7个统一修正系数。
- 只用644条源utility训练、612条源selection（28过境）选参。主候选和另一配置的复核候选按三种子平均源J=(OA+BA)/2选定，写入selected.json后才做扩围推理；没有计算所有候选的目标成绩再挑赢家。
- 源端主选为transport_eps04、lambda=1；复核候选head_steps400、lambda=1。仅调全局幅度也选择lambda=1，因此这个简单调整没有改变结果。
- 对冻结源预测逐次移除一个selection过境，28次中20次仍选同一主配置/倍率。它是选择敏感性诊断，没有重新训练，不是嵌套交叉验证。

## 实际参数变化

M3中的软对应由相似度除以温度后进入Sinkhorn。本轮温度从0.1改为0.4，随后重新训练读取这些关系的VV/VH头和门控，不是推理时直接改温度、沿用不匹配的分类头。

| 项目 | 保留配置 |
|---|---|
| 基础M1/M2及分类头 | 全部冻结为上一轮新版 |
| 初始条件度量PairMetric | 沿用，主候选不新增度量训练 |
| 软对应温度 | 0.1 → 0.4 |
| 极化头 | 源端配套重训，lr0.003、wd0.01、上限200步 |
| 整体修正lambda | 1，没有整体缩小/放大 |
| VV/VH固定比例 | seed17为0.7/0.3；29为0.7/0.3；43为0.4/0.6 |
| 频域门选步 | 5/0/0 |

因此，新增收益应归于**匹配温度与配套关系读出调整的系统效果**，不是“新匹配器训练成功”或“动态频域选择带来1.41点”。其他两组较小学习率的匹配训练在部分种子选到非零步，但未成为源端主选，不把它们换成目标端最佳配置。

## 匹配实际改变了什么

对本轮回看的8例，截取实际Sinkhorn对应（同类/混淆类、两参考、VV/VH分开），在相同初始度量下比较温度0.1和0.4：

| 对应诊断 | 0.1 | 0.4 |
|---|---:|---:|
| 真实单元间匹配质量均值 | 0.8471 | 0.6277 |
| 条件匹配熵 | 3.3188 | 3.6408 |
| 最大单元对占比 | 0.0976 | 0.0516 |

对应更分散，最大单元对占比降低；由于模型还有不匹配槽，分给真实单元匹配的总质量也减少。因此不只是“平均一下”，它改变了读出器接收到的匹配强度和对应组织。表格仅对应这8例，不当全队列比例。

这支持一个具体解释：原来较尖锐的局部匹配未必适合当前跨采集关系，较软的对应配合重训读出，可以减少部分错误修正并保留有用修正。但本轮同时重新训练了读出，**尚未单独分离温度、匹配质量变化和极化头再适配各自的全部贡献**；更不能把这称为物理噪声被分离。

频域门本轮只有seed17有变化：2876条有效双极化查询权重变化，9条分类变化，其中2救回、2误伤、5条错到错，OA净0、BA-0.0069；其余种子门为0步。主要收益不是动态频域门带来的，已有空间—频域描述仍在初始条件度量中使用。

## 保留方式

1. 将温度0.4及其配套读出保留为这批自建八分类的新版候选，原0.1配置和旧完整模型不覆盖。
2. 公开四分类模型暂不自动改温度；本轮只证明这个自建协议下有净收益。
3. lambda仍1，不新增无收益的全局缩放模块，不把调参本身包装成算法创新。
4. 这一轮按预定范围结束，不再据扩围成绩追加搜索。后续论文可报告该改进与边界，独立确认仍应冻结配置后开展。
