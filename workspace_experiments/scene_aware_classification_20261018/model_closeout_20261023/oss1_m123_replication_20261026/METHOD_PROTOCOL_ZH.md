# OSS1四类复现：方法与评价预设

2026-10-26。用户确认先做覆盖充分的散货、普通货、化学品、集装箱四类；不是八分类结果，也不是重新挑选类别取得好成绩。

## 任务与范围

沿用最早已有严格OSS1跨采集外折，不根据本轮模型成绩选折。目标查询、源训练与源选择按过境和MMSI隔离。具体角色数量与剔除原因由DATA_PROTOCOL_ZH.md和角色表记录。当前是一个固定公开集外折的三个训练种子复现，不称全OSS1或独立盲测。

保持原生160裁边/补零，不缩放船只；VV/VH分开，目标框无效的极化不制造目标证据。ImageNet R50冻结、C4原图旋转。几何/特征/参考/PCA不读取目标标签。

## 前端与四种后端

源端重建实际基础A/D/T、M1均值加双侧响应注意力、M2原OBB区域身份池化。四臂共享同一s12，不以简化GAP替换历史前端，不读24港监督权重。类别轴从8改4，不改各类别共享读出器的隐层结构。

源端PCA32及每类8艘不同源船参考，共32艘；source-only KMeans选实际代表，每候选类取最近2例，同船不作自己的参考。保留20槽、三区域、VV/VH与三尺度内容-频谱协方差。

1. 旧both结构复现：先源端训练15-12-1局部关系读出，再冻结读出学习640参数的成对比较度量，同时通过60步带空槽Sinkhorn影响匹配。
2. B固定比例：同一both匹配证据，独立VV读出与零证据中心化VH读出；源选择集在0至1、步长0.1的原网格选比例，J并列优先靠近0.5。
3. B+空间：围绕B比例作幅度最多0.25的有界调节，41维输入，12隐单元。
4. B+空间-频域：相同锚点与范围，185维输入，12隐单元。额外144维为查询-参考频域关系；不是在测试时替换正确率最好的极化。

所有头和度量在合法源端拟合与选择，步骤0也可选；不为了强迫模块生效而排除0步。损失沿用OA/BA对应的普通/类别平衡交叉熵混合，模型选择用源端J=(OA+BA)/2。旧both是四分类重新拟合的同算子结构，不是复用八类参数，也不保证复刻历史多轮研发中的全部优化顺序。四臂最终均在模型保存后才统计测试指标。

优先用独立于前端拟合的utility_train/selection训练M3；若数据容量不足，不自动把目标并入训练或重复参考，先明确实际可行划分。当前代码要求显式五角色，无静默回退。

## 评价与原图回看

报告每种子和均值的OA、BA、NLL、Brier、逐类召回、救回/误伤；不能把三个种子的重复预测当三倍独立样本。只有一个目标采集时，不估计跨采集总体可靠区间，查询/船bootstrap仅反映该采集内波动。

回看救回、误伤、持续正确、持续错误的原始VV/VH和实际同类/混淆类参考，并分解VV/VH对固定类对分差的改变。只能将图像事实和精确模型分数归因联系起来，不仅凭注意力/外观宣称真实物理因果。若步骤0或无翻转，也记录并解释证据变化。

任何收益均可按明确范围保留；不要求每类/每种子赢，但也不把小幅波动写成频域必要。数据、规模、类别、训练选模适配分别披露，不与24港八分类绝对数直接排名。
