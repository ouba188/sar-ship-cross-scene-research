# 新版自建24港完整实验

## 目的与冻结范围

将已保留的公开集新版 `raw_summary + adapted PairMetric + paired readout refit` 按同一训练逻辑扩展到自建24港八分类，不另搜索结构。输入为已有原尺度裁剪/补零的VV/VH；骨干、源类别响应读出器、PCA及64个源参考保持冻结，训练新版读出、极化修正、匹配度量及门控。不是从零重新预训练骨干，也不是重新运行24个留一港折。

## 固定数据

- 沿用既有源角色：1205条fit_train、296条fit_validation、644条utility_train、612条selection，485条evaluation单独报告。
- 扩围评价为既有3075条、1950船、85过境、18港，来自24港自建库；与原3387条源角色按观测、MMSI、过境隔离。
- 沿用内部MMSI排除145条，参考库64条全部属于fit_train；每类8条源参考，每次查询检索每候选类2条，不使用目标标签。
- 这两批评价都曾用于历史研发，称为固定历史跨采集验证，不称新增盲测。三个种子17/29/43是训练重复，不是三个数据划分。
- 训练文件中的485条和3075条评价标签均置为-1；标签真值单独用于所有预测冻结后的分析。

## 接入与对照

- 原始区域特征1538维，八类注意力摘要及质量/几何176维，合计1714维；类数变化逐项修改，不能直接套四类权重。
- 同一基础读出比较：原匹配冻结、新版任务对齐匹配、固定槽余弦比较。后两者都分别配套训练极化头和门控，避免只替换中间表示造成失配。
- 每条比较链输出bare、B固定比例、空间门控、空间频域门控。步数、学习率、验证准则沿用公开版，仅由源验证选择，不因3075条结果改选。
- 强简单对照采用同源数据、同冻结图像特征的区域MLP/ridge，并补合并全部合法训练角色的训练量匹配对照；旧完整8类模型原样保留。
- 缓存中非参考的base-only fit行没有高阶联合统计，这些行仅用真实原区域特征和注意力摘要训练基础头，不进入M3损失/选模/参考库；不报告它们的M3预测。

## 成功判据与解释

报告三种子均值/标准差、逐类/逐港/过境、VV/VH可用性、救回/误伤及按过境配对bootstrap。接受明确范围内可重复净收益，不要求各组全胜；若动态门控未被源选择，明确不能把完整模型收益归给动态频域。

完成后查看VV/VH原始chip与实际同类/混淆类参考，包含救回、误伤、持续正确与持续错误；保留负结果。代码、结果表及派生证据图同步GitHub，权重、原数据与大缓存不上传。
