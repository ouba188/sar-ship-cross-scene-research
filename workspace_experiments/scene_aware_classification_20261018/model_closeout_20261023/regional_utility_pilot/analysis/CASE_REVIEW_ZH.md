# 首轮协调器原图回看

2026-10-23。按预先约定的seed17、各结局最小obs_id取样，六个事件去重为五条观测。已实际查看五张面板的原生VV/VH及160裁补输入；不是仅用数表解释。原始路径、类别、预测和精确分差见cases.csv。以下解释限于本次固定模型，不命名散射物理机制，不把五例当作总体比例。

## 救回与误伤

- **1064，Fujairah散货船，原图两极化均72像素。** 主体是斜向长亮条，VV中可见横竖亮延伸，VH周边响应形态不同。不能据此认定尾迹或旁瓣。三个冻结策略原本都判对，普通CE协调器却判成原油轮；效用版恢复正确。因此这是“避免普通协调器误伤”，不是新增区域第一次看见类别。对固定原油轮竞争类，base分差+0.0270，body/full协调贡献分别+0.0123/+0.0782，最后+0.1175；普通CE为-0.4725。区域输入柱状图多处为负并不矛盾，因为它不是最终贡献。
- **220，Mombasa普通货船，两极化均64像素。** VV呈短宽亮块，VH主体上方可见一段窄亮延伸；小框及三区均位于原图内。base和普通CE正确，body/full均偏向散货，效用版仍采纳错误修正而误伤。真类对散货分差从base的+0.0730降到-0.2730，body/full贡献-0.2902/-0.0558。它直接展示当前协调器还不能可靠拒绝错误的区域增量；不能从这张图推断“短船就应关闭外围”。
- **1128，Tanger Med成品/化学品油轮，两极化均64像素。** 主体为较短横向亮块，VV更宽散，VH更紧凑。三个完整候选都判普通货船，逐类协调后普通CE与效用版都判对。这说明逐类组合可以得到任一完整候选都没有给出的答案，不能把“候选任一判对比例”叫该融合器的严格上界。效用权重对普通货船的body仅0.11，对真实类别的body约0.52；body对两个类给出的高分被区别使用。普通CE也能做到，故该例支持逐类协调，不独立证明效用监督必要。面板固定竞争类为最终最强对手散货，其分差分解不等同于相对旧普通货船的救回贡献。

## 持续正确与持续错误

- **150，宁波舟山散货船，VV96、VH112像素。** 两极化均见长而集中的亮主体，周围相对暗；裁补没有缩小主体。所有策略均正确。效用版对真类采用body权重约0.75，真类对普通货船分差由+0.5645增至+2.0797，body贡献+1.4704。这是已有正确判断被强化，不能算额外判对。
- **365，Port Klang海工支持船，VV72、VH80像素。** 主体同样呈较长亮条，VV/VH均有有效框和区域，并非图像缺失。所有策略仍判散货；效用版对散货的body权重约0.79，真类对散货分差-2.8056，比base的-1.0052更差。明亮、可见的主体不代表模型具有正确细分类证据。它与150的外观存在粗粒度相似，但仅凭这两图不能证明误判由哪种物理因素造成。

## 本轮能解释到哪里

可精确追溯“哪个候选、哪个类别坐标改变了最终分差”，五例分解误差均小于1.1e-7。不能由此证明输入中的某个局部亮点直接导致权重变化，更不能称物理因果解释。

源侧新链路本轮没有64支持集或查询-支持求解，故没有为案例虚构支持船。病例中的本体与外围是浅层RF35响应上的读出身份，仍不是互不混合的原始像素因果分区。

首轮同时存在异常的留出效用回归误差，单独根因诊断和后续修正不得覆盖本轮数值及原图记录。
