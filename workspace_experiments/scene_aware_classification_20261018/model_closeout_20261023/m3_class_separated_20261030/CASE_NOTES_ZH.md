# 原始 chip 回看：类别分离的 M3

主代理已查看开发图库12个查询、24张VV/VH面板，包含原始裁片、160像素裁剪/补零输入、OBB和实际同类/混淆类参考。没有把不同大小的船统一缩放。缺极化按不可用处理，不当作黑色图像。这里是代表案例，不是总体发生率；逐顺序分差和参考ID见对应cases.json。

## 新增救回与未解决问题

- 自建12741，原油轮，顺序43：原模型预测散货，真类对散货分差-0.12777，新通道后+0.18471。VV有明显向框外延伸的十字亮响应，VH外延响应相对弱；同类参考29922/2077没有同样明显外延，散货参考34478却有类似亮线。外观相似不能当作类别定论。这是新模型相对原版救回，但普通CE续训也救回，不能称为新通道独占能力。pooled同样救回，不能证明局部transport必要。源均值偏移没有复现该次救回。
- OSS2 003638，化学品/成品油轮，顺序17：VV/VH都是细长、近竖直局部亮结构；同类参考006746/005117较小且倾斜，异类散货参考006462/006477也细长。新模型救回不能解释成简单识别某个朝向。参考006462还出现框外更强结构，其关联没有另行确证，不能把所有框外亮响应命名为环境或同船散射。
- OSS2 000871，集装箱船：45像素裁片中仅紧凑亮响应；同类参考005219/001541可见尺度大得多，普通货船混淆参考004017/005079与查询可见尺度更接近。救回说明本次分类不只是追随视觉尺寸相近参考，不证明新模块学到了真实船长或某种物理结构。
- OSS2 003573，普通货船：VV不可用，VH显示短小亮结构，同类与混淆油轮参考均有相似短亮线。该例只有VH查询证据，不能用于论证双极化互补。
- 自建24399，散货：两极化均为短斜亮结构，散货参考31512与货船参考6913均有相近紧凑外观。顺序43从一个错误类别换成另一个错误类别，真类对原混淆类分差基本不变（约-3.55）。这不是有用救回，也说明类别比较无法凭空补足缺失判别能力。

## 误伤及持续状态

- OSS2 003630，集装箱船：近竖直、多个亮点的响应也与同类参考005219相似，但新通道误伤。与003638共同说明“细长/近竖直”不是本轮可泛化的使用条件，不据此添加方向规则。
- OSS2 003355持续正确：短小亮结构在不同类别参考中均可见。旧续训曾误伤该例，本轮保住原预测；这是保留旧能力，不是相对原模型新增救回。
- OSS2 003538持续错误：查询很小，同类集装箱参考较大，混淆油轮参考较小。可记录可见尺度差，但未通过控制实验证明尺度差导致该错误。
- 自建33658持续正确：VV中宽斜亮结构和极弱渔船参考有明显显示差异；查询VH不可用。不能把该例算作VV/VH联合证据。
- 自建5125持续正确、25311持续错误：两者都有向框外延伸亮线；25311还有另一个分离亮点。仅凭这些面板不能确认是邻船、同船外延或其他响应，也不能得出有亮线就利于散货分类。分类状态不同必须结合实际比较和分差，而不能仅靠亮度命名机制。
- 自建32253持续错误：普通货船与化学品船参考都呈短小亮结构，目前读出未消除这类混淆。

## 当前可解释到哪里

实现上，新分支先在各参考类内形成原型，再得到查询对各类别的相对距离，保留槽位写回现有网络。关掉新增通道会恢复原输出，这是干预新通道的直接功能对照。开发集源均值偏移不能复现自建唯一救回及公开多数救回，说明一个全体共享偏移不足以描述行为；但不意味着已证明某个局部位置或物理散射机制。

aligned与pooled开发OA/BA相同。现有证据允许保留“类别分离比较”候选，不允许宣称复杂局部对应是涨点原因。完整队列的净收益和成本由独立的evaluation表报告，不用少数展示图替代总体结果。

## 完整队列追加回看

主代理另外查看4查询8张面板，本轮合计16查询32张面板。图库机器生成的visual_status仍是not_reviewed，实际人工回看以本文件为准。

- 自建35673，顺序29，普通货船从渔船误判救回，真类/混淆类分差增0.39453。两极化均很小且较暗的短亮结构，渔船参考也小且暗，同类参考6913则明显更亮且背景纹理更强。新通道没有简单追随显示亮度相近的异类参考；普通CE本例仍错。不能由此断言已经剥离海况或亮度干扰。
- 自建11223，顺序29，散货误伤为化学品船，分差降0.09103。VV/VH都有较宽的近竖直白色区域，同类31512与异类24527都为较紧凑的竖直亮结构；查询的显示背景纹理比若干参考更强。pooled与aligned在本例预测不同，说明具体边界样本会受局部对应影响，但总体没有相应净收益，不能只挑这类差异证明复杂对齐有效。
- OSS2 002283，顺序43，普通货船从化学品/成品油轮救回，分差增0.05971，CE未救回。查询有近水平短亮结构，同类004017同样有近水平亮点排列；同类005079及异类参考也呈短小结构。可见排列是一个合理描述，不是已证唯一分类依据。
- OSS2 002401，顺序29，普通货船误伤为集装箱船，分差降0.04076，CE保持正确。查询也呈短横向双亮点，与被救回002283有表面相似；相同粗外观下仍发生相反效果，不能把短横向亮点当成有效开关。

完整统计解释了数量取舍：自建三顺序38次救回、56次误伤，散货净损35次；原油轮净增12次、海工净增5次。OSS2共5次救回、7次误伤，普通货船净增3次，26条普通货船中平均净增1条就对全局BA贡献+0.96154个百分点。以上是顺序事件而非独立船数。它解释指标差异，不证明图像亮度、纹理或某一物理条件造成了这些变化。
