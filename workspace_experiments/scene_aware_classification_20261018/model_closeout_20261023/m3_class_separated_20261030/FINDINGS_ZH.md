# M3类别分离比较：完成扩围，保留有限正信号

## 结论

本轮不是完全无效：固定参数后，自建3075张和OSS2四类378张的平均BA分别提高0.09475、0.56904个百分点。但OA分别下降0.19512、0.17637个百分点。可保留为类别均衡收益候选，不替换现有完整模型，不把小开发集的OA上涨外推为完整数据上涨。短期目标仍未充分兑现：尚未证明相对原完整模型及普通续训，在两个数据集同时具有值得新增计算的稳定净优势。

## 改了什么

原M3、M1/M2、骨干和分类头全部保留并冻结；只训练M3内部新增的类别比较回写通道。以现有空间—频域对应和参考权重为基础，先在各个参考类别内形成局部值原型，再计算查询到各类原型的距离，形成有类别与区域身份的差异场，零起点1x1映射回原网络。VV/VH分开处理，继续原layer4和分类头。没有重新加入M1/M2频域分支。

类别原型距离借鉴CrossTransformers的已有思路，不宣称该操作本身首创。新增通道检验旧M3跨类别汇总后可能丢失的竞争证据；当前实验不能反过来证明跨类汇总就是此前性能不足的唯一根因。

新增参数：自建八类16384、OSS2四类8192。普通原M3续训更新131446参数，属于同样样本/步数预算基线，不是等参数量基线。aligned与pooled新通道参数量、训练目标和预算相同；pooled保留区域和查询条件参考权重，只去掉参考值的局部槽位对齐。

## 开发与扩围的区别

开发自建160平均Delta OA/BA为+0.20833/+0.29762，公开228为+0.29240/+0.64537。这给出冻结方案扩围的依据，不是最终效果。扩大后OA方向转负，说明开发小样本的边界翻转并不能代表整个队列；不据此重选倍率或继续筛完整队列。

aligned与pooled公开完整OA/BA仍相同，自建平均OA相同、BA仅差0.01267个百分点。现有收益不要求复杂局部对齐；当前不能给aligned额外算法贡献背书。两者也不是“有/无参考”的对照，不能从中独立证明参考类别或频域的必要性。

## 计算和实现

12次短训练共900步全部结束；6组完整评价、每组4模型全部结束。3项CPU算子测试通过。每次训练验证零起点恢复原输出、冻结参数不变、新通道梯度非零、关闭恢复原输出、存取/原始chip前向一致。完整原版重放最大误差约1.2e-5，无证据表明结果由缓存或接入错位造成。

GPU batch4粗测包括查询编码，参考prefix缓存，不含磁盘读取。自建原版/新aligned平均174.05/203.43ms，公开191.87/195.25ms；自建顺序43存在较大时延波动。此为单次环境下顺序测量，不能据此下稳定耗时百分比结论，也未证明新增计算成本一定值得。

## 可保留和下一步

保留新增类别竞争证据的实现、两数据集小幅BA正信号及原图案例；原正式模型不覆盖。开发原图12查询24极化面板已由主代理查看，具体可见事实与分差见CASE_NOTES_ZH.md。源共同偏移无法重现全部救回，但这不是局部物理机制证明。

完整队列另看4查询8极化面板，总计16查询32面板。完整源共同偏移能复现自建23/38救回事件，却无法复现公开0/5救回事件，说明跨样本共同倾向和样本特异作用均需考虑，不能仅根据开发集认为全部收益均来自局部差异。详见新增案例11223/35673及OSS2 002283/002401。

下一步只围绕完整队列暴露的具体误伤定位：是哪类/哪种输入证据的竞争分数被过度推动，以及能否用源端相同现象约束新回写。不得用目标标签挑一个恰好涨点的强度；若源端没有可辨别规律，不能仅通过增加复杂对齐或重复调参宣称修好。
