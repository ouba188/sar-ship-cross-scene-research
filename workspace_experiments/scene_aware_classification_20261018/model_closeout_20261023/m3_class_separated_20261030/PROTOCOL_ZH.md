# 类别分离的局部比较小验证

既有证据：任务参照提高源同类权重但未增加分类收益；query/ref交互与跨参考训练没有双数据集净收益；原图显示同类外观差异与异类细长亮结构交叠。原M3在跨参考聚合时混合类别。新假设是先保留各类别的局部参考原型，再明确比较query与它们的差异，可能提供旧混合值通道未保留的类别竞争证据。不是已证根因。

借鉴CrossTransformers: spatially-aware few-shot transfer（Doersch等，NeurIPS2020，arXiv:2007.11498）。已读公开PDF第3-5页，重点§3.2、图2、式1-3：在每个类内对支持位置做对应，建立query-aligned prototype，共享value head后比较平方距离。不是声称“按类匹配”原创，也不直接复现其端到端训练/SimCLR。网页工具未返回可用正文引用，已从arXiv下载至内存并解析PDF核对。

本轮保持完整原模型不变，只给M3增加零初始化类别差异回写。沿用原空间频域匹配与16/32合法源参考；VV/VH分开，参考标签已知，查询标签不输入算子。同船/同ID及缺极化仍由合法掩膜排除。

每个区域：用同一LayerNorm加区域均值和L2归一化得到query/reference的1024维值。原transport先按query行归一化，将每个参考对齐到query槽；原reference_weights按类别重新归一化，得到每类原型；计算query到原型的平方距离，负距离按有效类别去均值，保留类别与空间槽身份。用C→1024的1x1零起点映射回写，继续原layer4和分类头。原project32未用于新距离，避免强制复用专门为旧混合回写训练的瓶颈。匹配器仍是原版，未宣布为新可训练度量。

两臂：aligned使用原局部transport；pooled每个参考在同一region内先按有效质量池化再广播，仍保留原参考权重、类别与query槽比较。故pooled是去空间对齐的对照，不是完全去注意力。参数量、初始化、数据、步数、损失相同。原模型和同预算原M3 CE续训为额外基线；后者参数数目不同，明确报告。

只训练新增回写；M1/M2/骨干/旧M3/分类头冻结。源适配136/241，沿用前轮逐样本顺序54/96步、batch16、AdamW1e-4/.01、CE+.1原正确KL。源端RMS归一化新增场强度，不用目标参数。先seed17两数据集两臂；出现值得保留的分类信号再扩29/43，无信号不自动扩大。旧检查点不替换，不读取最终测试、不重选目标倍率。

必须检查：零起点与关闭新增通道恢复原输出；无合法参考零更新；类内顺序等变；已知局部对应可以区分aligned/pooled；源标签只标识参考类别；其他权重不变；重载/原chip前向与缓存一致。训练后回看实际原图四状态和同类/混淆参考，不凭图像或注意力命名物理原因。

seed17后决定：两臂OSS2均OA持平、BA+0.58117pp；自建top1持平，但NLL/Brier较原版均改善，源分类也改善。因此固定结构和超参数扩29/43，不修改强度或学习率。已观察到pooled同样有公开BA收益，暂不能归因局部transport。扩围主要判断类分离回写是否有可重复净收益；训练顺序共享已有初始化，不称三次独立预训练。每臂两数据集最终共12次短训练900步，不读取最终测试。

三顺序结束：两臂均自建平均OA45.2083/BA36.0313（原版45.0000/35.7337），其中17/29持平、43提高；公开58.7719/50.2821（原版58.4795/49.6367），三组BA均提高。收益不大，但存在继续验证依据。固定两臂权重与全部参数，完整自建3075和OSS2四类378各三顺序一次性评价，同时重放原完整模型及精确同预算CE检查点。不得据完整结果调整该候选。aligned仍为预定研究候选，pooled为去局部对齐对照；两者开发准确率相同，不声称aligned独有贡献。数据为反复使用的历史队列，不宣称新盲测。
