# M2 等宽残差位置验证

日期：2026-10-28。用户确认补齐更多候选位置；本轮只变位置，不同时搜索次数或超参数。

## 问题与依据

上一轮相同128通道下 post3x3 优于 pre3x3，但阶段输出使用512通道，不能把它的优势全归于位置。原始chip回看中，35666的原油轮救回与20791的化学品船误伤涉及不同极化/区域回写；外观均存在同类与混淆类共有的亮条纹，简单广播区域信息并不必然有益。本轮检验：区域摘要来自残差变换还是完整合并特征、回写是否再经过ReLU，是否影响完整分类收益。

候选均在 layer2.3，即layer2最后一个stride1 bottleneck；一处M2，每极化一套参数：

| 名称 | 运算位置 | M2输入通道 |
|---|---|---:|
| baseline | 不新增浅层M2 | 无 |
| preadd (C) | conv3+BN3后，identity相加前 | 512 |
| postadd (D) | identity相加后，末次ReLU前 | 512 |
| stage (E) | 末次ReLU后，即原阶段输出 | 512 |

C只从残差分支池化；D从合并但未截断的特征池化；E从ReLU后的特征池化，回写后本block不再做ReLU。C/D的回写会受到最后ReLU影响。三者参数数量、初始化及区域定义相同，但输入统计不同，这是本轮要检验的处理差异，不将其当作纯几何干预。

## 固定协议

- 延用136条源适配、160条开发查询、16个源参考；8输出类，开发实际7类、3过境、3港口。不是完整24港或独立盲测。
- 船只/过境/观测隔离及实际队列沿用前轮，原生160裁剪/补零、VV/VH分别处理不变。不重新缩放，不换支持。
- 每组训练顺序种子17/29/43，6epochs共54步；不是3种独立预训练初始化。
- M2学习率3e-4；原layer3.5三个卷积继续3e-5局部微调；其余骨干、BN和原M1/M2/M3参数保持既有冻结策略。冻结运算仍保留通向新M2的梯度。
- 101/136的既有干预引导掩码、损失、类别权重、参考库和M3固定比较锚点不变；查询/参考值均使用当前参数。
- baseline/E六次既有训练经当前代码精确重放后复用；C/D共新增六次训练。固定末轮，不以开发集选择最佳epoch/倍率。
- OA/BA、NLL/Brier及逐类、救回/误伤都报告。没有预设所有指标都赢的要求；不以单次最高分下结论。

## 实现与解释检查

零初始化应复现原模型；非零回写分别与原生block的BN3后hook、第三次ReLU前hook比对，防止插错位置/重复相加。确认新模块梯度、参数量相等、冻结状态和保存重放。

训练后检查持续正确/错误、救回/误伤原始VV/VH与实际支持；固定训练权重关闭极化/区域回写属于模型路径干预，不是电磁物理因果证明。保留原正式模型，不自动替换。
