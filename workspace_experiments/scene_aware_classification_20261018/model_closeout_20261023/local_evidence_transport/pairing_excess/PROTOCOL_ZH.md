# 局部配对超额证据：训练前协议

2026-10-24。本轮不是在固定区域摘要后再加权，而是在汇总前构造查询局部船体与邻域的完整重配矩阵。尚无新分类结果，不预设创新成立。

## 数据起点

上一轮1128油轮被救回、5456普通货船被误伤，VV/VH和实际同类/混淆参考已重新查看：两类均存在短亮条及变化背景，不能凭外观命名物理机制。原有mixed只匹配b-n，即使W可学习，也可能利用端点各自内容而非真实配对。真实配对与shuffle101的平均OA相同，BA只差0.165个百分点。需要隔离配对证据，不再将这种总分直接解释为结构价值。

研究对象仍为当前source3387缓存中的跨采集分类，训练644、selection612、evaluation485，64个合法源参考，PCA32及骨干冻结。native160裁剪/补边，不缩放；VV/VH分别处理，四组side/end合法局部边不变。原V1/V2和上一轮候选均保留。

## 算法

一张查询和一张参考各有m、n条合法(b_i,n_i)局部边。令

    B_ij = b_i^T W s_bj / (2 tau)
    N_kj = n_k^T W s_nj / (2 tau)
    C_ik = log mean_j exp(B_ij + N_kj)

C的对角线使用原始船体-邻域配对；非对角线保留全部局部内容，只重新配对，不修改像素，也不将其称为物理反事实。

    joint = mean_i C_ii
    excess = mean_i C_ii - mean_ik C_ik

第二项等于所有查询邻域双射重配后的平均joint，不需枚举m!。对C任意叠加行偏置或列偏置，excess不变；如果参考仅一条边或任一端空间恒定，C可分离，excess为0。查询仅一条边也为0。此性质只针对该算子的配对信息，不等于消除所有成像条件、证明因果或普遍旋转不变。

普通二阶替代为covariance = mean_ij (H_m B H_n)_ij (H_m N H_n)_ij。它保留中心化的成对共变，是简单关系对照，不冒称复现完整DeepBDC。excess对小B/N的一阶项抵消，领先交互项与该协方差表达相联系；有限尺度的log聚合可产生更高阶区别，但不预设其有收益。

各参考独立计算后，在每类有效参考之间等权平均。所有臂统一要求查询和参考至少2条合法边，避免某臂依赖额外可用样本。类别中心化与源utility RMS固定，缺失组输出0。

W沿用I+(UV^T+VU^T)/2，U/V为32x4，全部类别、区域和极化共享；另有4个a，共260参数。接入冻结anchor只用sum a*(Z_W-Z_I)。U固定seed17小随机值，V=0、a=.25，初始输出严格0。无绝对朝向类别输入。

## 固定对照和训练

五臂：joint、excess、covariance、excess_shuffle101、excess_shuffle307。shuffle采用此前合法边内固定重配，训练和预测都错配，保持内容与有效性不变。每臂三套冻结基础配置17/29/43，共15 fits。比较同容量算子，不把之前不同聚合方式的body当严格匹配对照。

沿用200次全644梯度累积更新、Adam .01、.5普通CE+.5类均衡CE、.01||a||²+.01||W-I||²/32。内存批量可降低但每次全样本梯度权重不变。仅源selection J=(OA+BA)/2选0/20/50/100/200，严格改善、平局取早。evaluation不参与调参或改臂；15组完成后一次汇总。RMS只由utility初始特征拟合。

验证针对具体风险：枚举小m双射核对null均值；加性C行列偏置抵消；缺失组/单边不产生假证据；解析与有限差分梯度；标量实现与向量化结果；船轴符号整体翻转不改变关系。不是用这些算术检查代替分类收益。

## 证据与后续

同时报告OA/BA/J、概率损失、逐类与救回/误伤；不能把三套基础配置当三个独立数据集。完成后回看原始VV/VH和实际参考，显示C矩阵及逐边excess，比较真假类。若excess不优于joint/covariance或错配，则收缩机制主张，保留有效简单方案；不以本轮evaluation继续搜参数。独立扩围须以明确正信号和完成本轮解释为依据。

候选新增贡献是将同一图内保内容重配作为局部证据的内置参照，检验真实局部组合是否提供超额类别匹配；中心化、协方差、残差本身不作为首创。
