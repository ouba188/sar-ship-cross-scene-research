# 类条件配对风险算子：训练前协议

2026-10-24。前两个有效组件和上轮全部结果保留，不重训骨干。本轮读取上轮真实案例1376换参考失去救回、1338条件迁移误伤而独立重建仍对的证据，检验少量单船边求逆再平均是否限制关系的跨案例有效性。

## 算子

每个组（VV侧/端、VH侧/端）和类别，参考r的有效框内B_r与邻域N_r先各自图内中心化，m_r>=2。K为合法不同参考船数。G=mean_r B_r^T B_r/m_r；C=mean_r B_r^T N_r/m_r；lambda=mean_r ||B_r||F^2/m_r^2，floor1e-8。F=(G+lambda I)^-1 C，H=B_q F。每船等权，不让合法边多的船额外主导；lambda保留旧单参考归一化后的强度，不扫参数。独立核查补充：K=1仅在floor未激活时退化旧实现；旧floor施加在未归一化Gram，新floor施加在协方差，极小能量时不等价。当前源canonical数据未触发，非本轮收益或退化原因。

T=(2<N_q,H>-||H||F^2)/m_q。对各参考独立随机重排N_r，框内和G保持不变。令A_r=B_q(G+lambda I)^-1 B_r^T/(K m_r)，则V=sum_r ||N_r||F^2/(m_r-1)*(||A_r||F^2-||A_r 1||^2/m_r)/m_q。excess=T+V。实现可用协方差迹计算避免显式所有A/H；需用独立展开重放核查。

五臂：independent（类内池框内/邻域分别自重建）、covariance（2<C_q,C>，不求逆）、transfer（T）、excess（T+V）、excess_shuffle101（固定图内邻域错配，训练/推理一致）。均共享同规格M_b=I+UV^T/M_n、512变换参数和4系数。变换先于G/C计算，不额外归一化。prediction=full+sum a*(Ztheta-Zidentity)，每臂原64参考库utility身份RMS固定，初始增量严格0。图内中心化会删除均值信息，但旧full仍保留其证据。

## 训练评价

沿用reference_resampling/episodic相同200个逐step参考组织、同644训练查询、同全局混合CE/正则、Adam .01、200步、检查点0/20/50/100/200、相同六库selection612平均J。预定17/29/43三个已有基础配置，变换初始化均17；不是三次独立初始化。五臂共15fit。

主部署单一原64库，五新库仅作预定稳定性评价，不六库融合、不选最好库。原池KMeans代表点、新库模式分层随机且场景组成不同；海工参考共享，不能称独立参考重复。evaluation485是多轮开发集，选点后才评价。旧逐参考算子结果使用上一轮相同多参考组织训练结果，不重跑；本轮所有类别池内比较匹配参数和预处理。

## 验证与解释

训练前：单参考退化、两参考全排列精确随机期望、矩阵迹与显式H/A等价、部分有效边与缺VH、初始零及实际数据有限差分梯度。只检验具体可能出错的归一化、交叉参考项、索引或失活问题。
