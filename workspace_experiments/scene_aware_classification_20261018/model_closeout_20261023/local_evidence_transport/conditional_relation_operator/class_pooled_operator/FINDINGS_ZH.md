# 类池条件关系算子：完整结果与证据边界

日期：2026-10-24。15次匹配训练、独立算子核查、源端判别诊断及四组原始VV/VH案例回看均已完成。训练用时168.29秒，不含既有骨干特征提取和分析。强第三组件目标尚未达成，原有两个组件不替换。

## 结论先行

本轮确实改变了汇总前的关系估计方式，不是给最终分数换一个名字：从每个参考单独求局部映射，改为同类参考等船积累协方差后再求条件映射，并计算精确的独立参考配对置乱风险参照。

但是，扩大可表达的关系方向没有转化为完整分类净收益。新excess的OA/BA为58.3505/39.5925，原full为58.8316/40.1223；简单协方差59.0378/39.6966，OA略增、BA下降。当前不能把类池算子升格为有效创新模块。此前逐参考episodic excess的59.2440/39.6012及有限OA正信号完整保留，不能被本轮结果覆盖。

更具体的发现是：真实框内—邻域配对有可测类别信息，但学习后增强的往往是正确类相对一般错误类的差距，未必是相对最强混淆类的差距。下一步应定位这种竞争关系，而非继续把秩更高、拟合更好等同于识别更好。

## 数据和接入位置

冻结完整分类器full = 基础B(A+D+T_res) + 第一组件双向类别响应注意力(layer3) + 第二组件OBB区域类别证据读出(layer1)。注意力替代旧均值/分布读出，不重复堆叠。本轮第三候选并行重读局部token，发生在自身汇总之前，再以零初始残差接入full；不是处理第二组件已经汇总的向量，也没有混入额外普通匹配anchor。

复用1205条fit_train拟合的PCA32、冻结ImageNet R50、原生160裁剪/补边输入，不缩放船体。20个槽位包括8框内、8侧部、4轴端，VV/VH分开，C4特征沿用。4组关系为VV_side、VV_end、VH_side、VH_end。合法边要求两端均有效，每参考至少2条边。

源参考为fit_train中的不同MMSI：1205观测对应1004船。部署原库64船、每类8船，不是64个目标标注。utility644用于训练，selection612用于选择，evaluation485用于本轮开发评价，后者445船、29过境、14港，八类数量169/91/69/67/33/13/40/3。参考与三个查询角色无同船/同过境交集。该evaluation已反复用于开发，不称独立盲测。

三套基础配置17/29/43共享查询及新增变换初始化17，不是三个独立训练随机种子。每步参考重采样沿用10001..10200，五个压力参考库与原库同类预算/有效性匹配，但包含有限共享船只，并非独立重复。原库KMeans与新随机库的组织差异也不只是参考身份变化。

## 算子到底改了什么

每个参考独立中心化框内B_r和邻域N_r，合法边数m_r。对某类/组的K个参考等船汇总：

```text
G = mean_r(B_r^T B_r / m_r)
C = mean_r(B_r^T N_r / m_r)
lambda = max(mean_r(||B_r||^2 / m_r^2), 1e-8)
R = (G + lambda I)^-1; F = R C
H = B_q F
T = (2<N_q,H> - ||H||^2) / m_q
A_r = B_q R B_r^T / (K m_r)
V = sum_r ||N_r||^2/(m_r-1)
    * (||A_r||^2 - ||A_r 1||^2/m_r) / m_q
S_excess = T + V
```

含义：用某类参考的框内—邻域关系预测查询邻域，再评估真实关系比参考内部随机打乱配对好多少。先累加H再平方，保留跨参考交叉项。独立均匀置乱各参考N的合法行时，S等于置乱期望误差减真实误差；不是置乱后重训的期望，也不由此保证分类收益或跨域因果性。

匹配五臂：独立框内/邻域重建、无求逆的cross-covariance、条件迁移T、超额S、训练与评价均固定错配的S_shuffle101。每臂相同两个32维rank4残差变换及4组系数，共516参数。完整输出为full + sum_g a_g(Z_theta-Z_identity)，初始增量为零。每臂以原库utility恒等读出的RMS定尺度，之后冻结。

每臂三配置，各200步；Adam 0.01，损失为0.5普通CE+0.5类别平衡CE及固定正则。检查点0/20/50/100/200按selection六库平均J=(OA+BA)/2选择，平分选早。主部署仍是原库单库，不是六库测试集成。公式与代码详见PROTOCOL_ZH.md和run.py。

## 根因定位到哪里

独立检查表明，实际Reader五臂、恒等/非恒等变换和部分有效边对NumPy的最大误差1.11e-16，36个全排列风险恒等式误差1.11e-15。旧ridge正则后条件数不高，不能说旧算法数值病态。

原64库侧部单参考数值秩7、轴端3，类池侧部32、轴端15-24。方向覆盖增加属实，但可能含场景差异和噪声，不能直接视为有效判别信息。类内cross-covariance方向保留比例约0.39-0.57，说明不同参考并不完全同向；不能仅凭该比值认定有用关系被抵消，也可能是去噪。详细诊断见OPERATOR_REVIEW.md及rank_diagnostics.csv。

## 原始chip回看与实际参考

四幅面板均以原生160裁剪/补边、固定0..255展示VV/VH，主线程已实际查看，并同时读实际同类与混淆类参考。使用excess17非零检查点，不混用其它配置。

1. 220普通货船救回：相对散货船分差-0.1124变+0.3640，VH_side贡献+0.3995最大。查询是短亮响应，VV周围颗粒较亮、VH较暗；实际同类26409为紧凑亮响应，混淆33678为较长斜向亮结构。独立重建、协方差、迁移T也能救回，不能归为超额算子独有能力。
2. 1129成品/化学品油轮误伤：相对普通货船+1.0783变-0.1885，VV_side -0.3913、VH_side -0.6780。查询为短、近水平亮条；同类23631在VV呈较宽强亮团及侧延伸、VH更紧凑，混淆21927呈细亮条。简单独立重建与协方差仍正确，条件迁移T也误伤。因此应重点检查条件关系如何放大混淆，而不是仅以两幅图像不同解释退化。
3. 150散货船持续正确：优势+0.9668变+1.6026，VV_side贡献+0.4799。查询近竖向、同类26615近横向，均有拉长亮响应，混淆7884紧凑。该例说明朝向不同没有必然阻止匹配，不证明总体朝向不变性。
4. 365海工船持续错误：-1.8473变-2.0923，VV_side -0.2057。查询与混淆33678均为较长斜亮响应，同类905在VV/VH外观不同。所有臂均错误，不是新组件独有失败，不能凭外观强行命名物理机制。

## 实现修正及研究定位

独立核查发现CPU float64解释路径中rv/(整数K*m)先成为float32，使贡献重放差约6.5e-10。已在除法前转到sb.dtype，重新生成分析，GPU float32训练行为不变，未重训。单参考退化到旧公式仅在legacy floor不激活时成立；实际源池未触发，但不宣称极小能量输入也严格等价。负结果不归因这两处边界。

已有文献基础沿用上阶段LITERATURE_ZH.md的实际阅读记录。本轮没有新增成功获取的全文，不声称重新精读。ridge重建、协方差关系、残差更新本身不是原创；当前尝试的差异在于等船条件关系积累与精确配对随机参照的组合及其任务化使用。数学区别已实现，完整效用未成立，不能据公式复杂度宣称顶刊级创新。

下一步仅针对源端真实强混淆关系：在相同图像/参考预算下，区分哪些框内—邻域对应是真类与竞争类共享、哪些是有判别力的差异；先检验保留多个类内关系模式是否比同类平均更能利用这些差异，再决定是否开发非线性/竞争性局部算子。不用评价标签挑选类别或模式，不因本轮负结果抹去之前有限正信号。未开展全数据集/外部验证，本轮不修改原两个有效组件。
