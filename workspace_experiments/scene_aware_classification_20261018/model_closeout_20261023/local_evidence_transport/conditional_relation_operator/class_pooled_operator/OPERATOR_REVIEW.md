## 结论与边界

指定类内先积累后求逆公式和当前 `Reader.scores` 一致，有限参考置乱风险参照成立。更新后的实际 Reader 在五臂、恒等/非恒等映射、原样/部分有效边下与独立 NumPy 的最大差异为 **1.11e-16**。原 sourcebank64 的类池确实补充了单参考未覆盖的方向，但这不是判别信息增加或涨点的证据。

旧逐参考算子的有限秩来自有限的中心化边数；其 ridge 后条件数很低，**不能把有限可表达方向写成旧求解器数值病态**。主线程最新报告的完整结果为 excess OA/BA=58.3505/39.5925，full=58.8316/40.1223，covariance=59.0378/39.6966。这些数值由主线程提供，本侧支没有重算分类结果；它们不支持“类池化已经解决旧瓶颈”的结论。

## 公式与精确参照

所有均值仅含合法参考 `m_r >= 2`，`K` 为该组/类实际合法参考数。每个参考先独立中心化，不能将所有参考先拼接再全局中心化。

```text
G_r = B_r^T B_r / m_r
G = mean_r G_r
C = mean_r (B_r^T N_r / m_r)
lambda = max(mean_r(trace(G_r)/m_r), 1e-8)
R = (G + lambda I)^-1
F = R C; H = B_q F
T = (2 <N_q,H> - ||H||_F^2) / m_q
A_r = B_q R B_r^T / (K m_r)
gamma_r = ||N_r||_F^2 / (m_r - 1)
D = sum_r gamma_r/(K m_r)^2 *
    [B_r^T B_r - (B_r^T 1)(B_r^T 1)^T/m_r]
G_q = B_q^T B_q/m_q
V = tr(G_q R D R^T)
S = T + V
```

`Reader.weight = rv/(K*m)`、`lambda = sum(trace(B_r^T B_r)*weight/m)`、`D` 的 `weight.square()` 分别对应等参考权重、指定正则强度、独立参考方差。`lambda` 不额外除 K。H 必须先累加再平方；主实现 `F F^T` 保留了跨参考能量交叉项。

固定 B、查询、有效边和特征变换，对各参考独立均匀置乱 N 的合法行，有 `E[P_r N_r]=0`。不同参考的交叉预测期望为零；同一参考使用有限无放回排列协方差。因此 `E||N_q-H_perm||^2/m_q - ||N_q-H_real||^2/m_q = T+V`，且 `E[S_perm]=0`。这不是“置乱后重新训练”的期望，也不是把所有参考合并置乱或所有参考使用同一个排列的期望。训练后选择的变换、不同参考库之间的性能独立性均不由该等式保证。

所有 Gram 在 float64 中对合法行中心化后计算。数值秩为 `count(eigenvalue_i > 1e-6 * eigenvalue_max)`，**不是固定绝对1e-10**；CSV 同时记录每矩阵实际阈值和完整谱。该阈值施加在 G 的特征值，等价于 B 奇异值相对阈值1e-3。有效秩为谱熵 `exp(-sum p_i log p_i)`，`p_i=eigenvalue_i/trace(G)`；另附 participation rank。有效秩使用完整非负谱而非硬截断谱。正则条件数为 `(eigenvalue_max+lambda)/(eigenvalue_min+lambda)`，不是原始奇异 G 的条件数。

## 可以与不可以推断的事

原库所有32个 group/class 的 pooled rank 都高于该池任何单参考的 rank。对每个单参考的相对阈值子空间，计算 pooled G 在其正交补上的 trace 比例；即使取各类中覆盖最佳的参考，原库仍有约42%-70%的池化能量落在该单参考子空间外。这支持“不同参考提供不同输入方向”，不支持“这些方向属于新增类别信息”。不同方向可以来自场景、观测条件、船体差异或噪声，本检查没有区分这些原因。

G 是 PSD 平均，新增方向不会以正负号直接抵消；但关系 C_r=B_r^T N_r/m_r 可因异构映射而抵消。描述性方向保留率定义为 `||mean C_r||_F / mean ||C_r||_F`，原库组内各类范围为 VV_side 0.437-0.543、VV_end 0.396-0.452、VH_side 0.456-0.565、VH_end 0.390-0.520；canonical池分别为0.360-0.449、0.224-0.353、0.380-0.452、0.203-0.388。比值小于1证明 C_r 不是同向累加，但不能区分有益去噪与有害异构关系抵消，也不意味着已经找到实际退化原因。

保留的证据链仅到：单船边数限制 G_r 的方向数；实际多船池扩大方向覆盖；实现及精确随机参照正确。尚未证明新增方向在 held query 上可迁移、C 的合并保留了判别关系，或完整分类系统因而获益。主流程已报告的负结果必须保留；原图及配对预测分析由主线程继续，不据秩结果追加训练、筛选参考或改变协议。
