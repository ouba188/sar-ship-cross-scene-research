# 邻域输出RKHS条件关系：预先固定协议

2026-10-24。沿用前两个冻结组件及上轮输入RBF核，不重训骨干、不新增目标标签。本轮只把条件预测的输出表示由欧氏邻域向量改为邻域RKHS，保留每参考船的中心化和等船质量。

## 数据依据与假设

已有原图220/1338/150/365及其实际参考显示局部响应和邻域纹理不同，前轮源端分析中真类与混淆类都可获得较强线性输出关系。输入RBF没有带来完整净收益；这些事实不证明原因是分布信息缺失。本轮检验一个明确表达限制：相同框内条件下邻域的线性均值可能接近，而输出分布特征不同；RBF输出允许读取这种差异，但逐船中心化后它仍是关系表示，不是恢复完整真实条件分布或物理机制。

## 算子定义

输入A完全沿用kernel_condition_operator，核宽度继续读取该轮fit_train1004不同MMSI、seed613的固定带宽，不重新拟合。输出原始特征仍先按合法边作欧氏中心化，与前轮一致；再计算RBF核并在核空间按每参考船、每查询船独立中心化。

```text
Lss = Hs l(Ns,Ns) Hs
Lqs = Hq l(Nq,Ns) Hs
T = [2 sum(A * Lqs) - sum((A Lss) * A)] / m_q
gamma_r = trace(Lrr) / (m_r-1)
V = sum_r gamma_r * [||Ar||^2 - ||Ar 1||^2/m_r] / m_q
S = T + V
```

所有参考预测先累加再平方，通过Lss跨参考块保留交叉项。A只由B决定，输出置乱不改变A；独立船内置乱的精确期望风险差继续成立。独立支线以NumPy/有限Gram特征分解和全排列核查，不用主代码同构断言替代。

## 小验证与完整实验

先做固定恒等变换的源utility644/selection612诊断，对比线性输出、RBF输出、真实配对与固定错配。看真类对普通错类及强混淆类的差距、边际独立重建与关系读出的差异。若真实关系在至少一个组、两个源角色中均保持正的宏类别平均真类-平均错类差距，并优于该组错配，则有非退化可检验信号，可进入固定预算训练；不把它当作完整模型已涨点，也不要求它单独做好八分类。若不满足，先分析输入/尺度/关系而非直接训练。

完整实验仍五臂：输出RKHS独立重建、双核covariance无求逆、T、S、S_shuffle101。covariance同时省去求逆与能量惩罚，不把差异全归于求逆。每臂516参数、200步、源参考日程10001..10200、Adam.01、全局普通/均衡CE各半及相同正则。输出full + sum a*(Ztheta-Zidentity)，初始0。每臂utility恒等RMS冻结。检查点0/20/50/100/200，selection六库平均J严格增益才选，平分选早；主部署原64源参考，三基础配置共享新增初始化17。线性输出旧实验复用，不重复调参。
