# 输入核条件算子：完整实验与解释

2026-10-24。五臂三基础配置共15次训练完成，用时318.01秒（不含既有特征提取与后续分析）；源端诊断和四组原始VV/VH实际参考回看完成。代码、结果与负结果均保留。前两个有效组件不改，强第三组件目标未达成。

## 改了哪一步

完整full保持原样：基础B(A+D+T_res) + layer3双向类别响应注意力 + layer1 OBB区域类别证据读出。新通道在局部token汇总前并行取框内/邻域配对，最终以初始为零的增量接入；不替换前两模块，也不把额外普通匹配anchor混入full。

同类参考不先平均成一个原型。用框内特征的RBF核产生查询局部到参考局部的条件对应，再将对应迁移到邻域，比较预测与实际邻域。核空间按每参考船独立中心化，合法边等船加权；保留了上一轮精确的独立船内配对置乱风险参照。对应系数可以为负，不是概率注意力。

RBF宽度来自fit_train中1004不同MMSI的合法token距离，seed613、每组4096对，冻结后不使用目标查询确定宽度。相同516参数、200步、参考日程、损失、正则、6库源selection选择规则；200步后不继续按evaluation调参。源参考不是目标支持预算。三套基础配置共享新增初始化17，不是三次独立新增训练种子。查询、参考和图像预处理完全沿用上轮，仍是原生160裁剪/补边而非缩放。

线性核退化在真实缺失边及人工partial-mask下与前轮primal实现相差至多9.71e-17，排除了本轮线性基准接错。零初始增量、Vb/Vn有限差分梯度和36个独立船内全排列风险恒等式通过；最大风险差误差2.47e-15。全部训练正常结束，不把负结果归为已知实现错误。

## 哪些机制解释有证据

实际源码和文献共同明确了一个边界：本轮只有输入端RBF，预测对象仍为欧氏邻域向量。它允许框内内容不同处使用非线性对应，**不等于表达同一框内条件下邻域的多个分布模式**。不能把“核化了”直接写成“多模态问题解决了”。

源utility644及selection612诊断固定原参考库，比较线性/核算子在恒等变换和同一组核excess43所选变换下的分数，不新增拟合。下表为selection的VV_side宏类别平均，分数各按恒等utility RMS定尺度；不是完整系统OA/BA。

|线性/恒等|0.5948|-0.7245|0.2330|22.06%|0.1346|
|RBF/恒等|0.6334|-0.6849|0.2547|22.81%|0.1150|

skill=T_true/||Nq||^2，表示相对零均值邻域预测的平方误差改善。输入核有小幅判别关系优势，但不是重建风险普遍更低；学习后相对full原有竞争类的优势增加，最强关系错类仍可能更强。完整残差结果依然不增益。

一个辅助通道不必单独完成八分类，因此不能仅以这些top1低或最强关系分差负否决它。真正的否定证据是匹配条件下完整模型净收益未兑现；上述诊断只说明“关系拟合更好”“分开普通错类”“补充full识别”是不同问题，尚未唯一定位退化根因。selection用于检查点选择，不能再冒称独立机制验证。

## 原始chip与实际参考

分析使用配置17的所选S，按每个结果组最小obs_id确定案例，并非挑最好看的成功例。四幅原生160、固定0..255的VV/VH面板已实际查看，来源及放置见analysis/image_provenance.json。参考由实际贡献选出，以下外观只作可见事实，不命名物理机制。

- 220普通货船救回，23例救回中的一个：分差-0.1124变+0.3713，VV_side +0.2529、VH_side +0.2223。查询在较亮颗粒背景上呈短斜亮响应；同类33307呈近水平紧凑亮条，混淆23049更小、更接近竖向。独立重建与核协方差也救回，不能宣称为条件算子独占能力。此次实际主贡献参考不同于前轮，应使用本轮记录解释。
- 1338成品/化学品油轮误伤，29例误伤中的一个：相对散货船+0.3575变-0.2762；VV_end -0.6593、VV_side -0.3779抵消VH两组的正贡献。同类28586与查询均为近竖向亮条但倾角、周围纹理不同，混淆33678为斜向亮结构。独立重建仍正确，核协方差与错配S也误伤；不能把它归为某个正确物理对应的唯一后果。
- 150散货船持续正确：+0.9668变+1.5027，VV_side +0.4888最大。同类26615横向长亮条、查询近竖向长亮条，混淆7884紧凑，说明此例没有简单按朝向相近判类，但不证明整体旋转不变。
- 365海工船持续错误：-1.8473变-2.1674，VV_side -0.2347最大。查询和混淆33678较长斜亮，同类8183较紧凑且chip右上还有另一亮响应；8183的VH虽有图像但区域valid=0，**未参与VH关系计算**。不能将展示的VH图像误认为算法使用了它，也不能未经确认把额外亮点称为邻船。各主要对照也错误。

数值路径以每参考对称分配交叉能量，累计重放误差最大1.17e-6，算子内分配误差约5.6e-17。它解释谁贡献了哪些分数，不等于参考移除实验：删参考会改变整个核系统和正则。

## 文献差异与下一步

独立支线实际阅读FRN、Song等条件分布嵌入、Grunewalder等条件嵌入回归的指定章节/公式，详见LITERATURE_ZH.md。核回归、条件均值嵌入及核化重建均有现成基础，不能把换RBF当作强原创。FKFRN仅获得可靠摘要，方法全文未能访问，尚未完成与其逐式对照。

值得发展的差异仍是“框内限定对应，邻域检验对应，保留参考船边界，以配对随机化的精确风险参照形成类别关系证据”；本轮不能据此宣称有效模块完成。

一个具体且尚未实施的算法修正是将邻域输出也映射到RKHS，比较条件分布特征而非平均欧氏向量，并在同一Hilbert平方风险中保留精确船内置乱参照。文献支线已给出Gram形式推导及其中心化条件。下一步先检验该表达在真实源查询/参考上是否分开现有均值关系混淆，再决定完整训练；不能假定输出核化必有收益。输入核的负结果保留，不自动归因“还不够复杂”。

本轮没有外部数据扩围，也没有新增数据标签。主目标继续，未标记完成或暂停。
