# 非线性条件关系核：训练前固定协议

## 数据依据与可检验假设

已实际回看上一轮220救回与1129误伤的原生VV/VH及同类/混淆参考。1129的同类参考不是同一种局部亮条外观，类别相同不能直接假定关系相同；源端诊断也显示同类cross-covariance方向不同。类池扩大方向但未增加净收益，不能认定线性平均已保留有效模式。假设：允许框内局部内容通过非线性相似性决定向哪些参考局部传递，可能保留不同关系模式，比同类单个线性映射更有判别力。这是待检验解释，原图差异不证明原因。

## 算子

复用源PCA32、原生160裁剪/补边、20槽位、4组合法对应。每船中心化B/N，进一步在核空间按每船有效边独立中心化。参考核Kss、查询核Kqs同时保留单船中心化，不能把类内所有参考视为一船。W对每参考总质量1/K、每条合法边1/(K*m_r)。

```text
Kss = Hs k(Bs,Bs) Hs
Kqs = Hq k(Bq,Bs) Hs
lambda = sum_i W_ii * Kss_ii / m_ref(i)
A = Kqs sqrt(W) [sqrt(W) Kss sqrt(W) + lambda I]^-1 sqrt(W)
H = A Ns
T = (2<Nq,H> - ||H||^2)/m_q
V = sum_r ||Nr||^2/(m_r-1)
    * (||Ar||^2 - ||Ar 1||^2/m_r)/m_q
S = T + V
```

核用exp(-||b-b'||^2/d_g)。d_g是fit_train按MMSI取首条的合法源船token随机4096对平方距离中位数，seed613，B/N各自按4组估计后冻结，不读utility/selection/evaluation的特征来定宽度。不存在按evaluation调整核宽度。线性核应重现上一轮类池公式；该恒等性与实际缺失边是独立验证对象。

当A只由B决定、每参考N中心化时，独立参考内均匀置乱N的精确期望风险差仍为S。核与ridge本身是已知方法，是否具有论文方法差异由组合机制及实证决定，不因使用非线性自动称强创新。
