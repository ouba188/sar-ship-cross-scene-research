## 1. 结论与可发展的贡献

值得发展的具体问题是：在框内证据相近、邻域响应关系不同的参考船之间，单一线性类池映射是否掩盖了有判别力的局部条件结构。可检验的改动是用框内核相似性决定条件迁移，再在邻域空间评估真实配对相对船内随机配对的解释优势。这个变化发生在关系估计和风险读出内部，有实质算法内容；它的价值取决于是否改善最强混淆类竞争与冻结完整系统的分类结果。

文献支持这一方向的数学基础，但必须区分两件事：

- **仅输入核化**：预测 E[N|B=b]，允许不同框内区域采用不同非线性关系，但对同一个 b 下的多个邻域模式仍可能取均值。
- **输入与输出均核化**：预测 E[psi(N)|B=b]。若输出核具有分布可识别性且估计充分，条件嵌入可以表达不同条件分布；它是特征空间中的均值，不等于原始邻域特征的均值。有限参考、正则化及后续读出仍可能丢失有用区别，不能直接宣称“完整保留多模态”。

当前实现属于第一种：`run.py:77–79` 用框内核得到 A，然后执行 `H=A@sn` 和欧氏邻域平方风险；没有把 sn 映射到非线性输出 RKHS。independent 臂另用邻域核决定其自身重建系数，不会把主 excess 臂变成双核输出嵌入。因此，本轮只能检验“框内可辨的非线性局部条件关系”，不能写成已经保留同一框内条件下的全部邻域多模态。第二种仅用于说明文献边界，不是本轮实现或新增训练要求。

已知基础包括 ridge 重建、核条件嵌入、向量值回归风险、核化特征重建以及随机化参照。可能形成有意义差异的是：**框内决定对应，邻域检验该对应，保留参考船边界并用船内配对置乱的精确期望风险定义关系证据，再检验其在冻结前两组件后的增量效用**。目前这是待验证的组合与任务化设计，不是已证实的原创性或收益结论。

### [1] FRN：支持特征重建查询的直接基线

可靠来源：

- `https://openaccess.thecvf.com/content/CVPR2021/papers/Wertheimer_Few-Shot_Classification_With_Feature_Map_Reconstruction_Networks_CVPR_2021_paper.pdf`
- `https://arxiv.org/html/2012.01506`

原文核心式：设一类支持特征 S 为 kr×d，查询特征 Q 为 r×d，FRN 式 (1)–(3) 为

```text
W* = argmin_W ||Q - W S||_F^2 + lambda ||W||_F^2
   = Q S^T (S S^T + lambda I)^-1
Qhat = Q S^T (S S^T + lambda I)^-1 S.
```

式 (4) 使用每位置平均重建误差，式 (5) 对负误差做 softmax 分类。式 (6)–(8) 加入正的重建幅度 rho 与可学习正则：lambda = (kr/d) exp(alpha)，rho = exp(beta)。式 (10) 给出 d×d 的等价求解形式，式 (11) 对不同类支持特征的相关性施加辅助约束。

对本方案的启发：无需把一类压成一个原型；局部支持特征集合本身可用于分类。FRN 的对应权重由被重建的同一类内容决定。本项目则以框内 B 决定权重，再迁移配对邻域 N，核心区别是几何配对约束及配对风险参照。注意 FRN §3.7 式 (14) 已讨论 CrossTransformer 的 key/value 分离重建，所以“由一组特征确定权重、重建另一组特征”这一宽泛思想也不能称为首次。本文已读部分没有给出本文件第 4 节所述船内独立置乱风险构造。

### [2] Song 等：条件分布的核嵌入

可靠来源：`https://icml.cc/2009/papers/538.pdf`，实际逐式阅读依据为此 ICML 官方 PDF。

原文 §2 式 (1)–(4) 建立分布嵌入与中心化协方差；§3 Definition 3、Theorem 4/5 给出条件算子和经验估计。将 X 写成 B、Y 写成 N，保留 Theorem 5 原有的中心化与尺度：

```text
mu_(N|b) = E[psi(N) | B=b]
U_(N|B) = C_NB C_BB^-1
mu_hat_(N|b) = Psi_N (J K_B + lambda*m I)^-1 J k_B(b),
J = I - 11^T/m.
```

这里 Psi_N 的列是输出 RKHS 特征。原文还明确说明连续域中相关函数空间假设未必成立。不能把中心化估计、未中心化估计与总体逆无条件混为同一式；下篇提供更直接的回归解释。实现的逐船中心化和等船权重也不能由原文全局 J 不加说明地替代。

关键定位：条件分布被表示为输出特征的条件期望；Definition 1 的 characteristic 核提供分布嵌入的可识别性，线性输出核只表达一阶均值。Theorem 5 的权重是实数，不能自动解释成混合概率。本文的分布表达基础不能被重新命名为本项目原创，也不能向小样本、同船相关 token 估计直接搬用其恢复保证。

### [3] Grünewälder 等：把条件嵌入写成回归风险

可靠来源：

- `https://arxiv.org/abs/1205.4656`
- `https://arxiv.org/pdf/1205.4656`
- `https://icml.cc/2012/papers/898.pdf`（本次公式编号依据）

原文 §2.1 式 (1) 为条件嵌入估计；§3.1 式 (5)–(7) 导出代理风险，式 (8)–(10) 为经验正则风险及最小化。使用本文件记号写其式 (9)–(10)：

```text
min_mu sum_i ||psi(n_i) - mu(b_i)||_H_N^2 + lambda ||mu||_Gamma^2.
```

§3.1 式 (11)–(12) 及紧接的系数公式使用算子值核的 representer 展开。可分离核 Gamma(b,b') = k_B(b,b') I 时，系数矩阵为 (K_B + lambda I)^-1，恢复条件均值嵌入；原文明确注明与式 (1) 的 lambda 需重新缩放。§3.3 还区分条件期望误差与代理风险，不能把平方风险变好无条件解释为所有目标变好。

这篇给本方案最直接的支撑是：邻域 RKHS 重建风险可以是明确的学习/评分对象，而不必先把预测嵌入解码回一张邻域特征图。原文不提供“真实配对减船内置乱期望”的任务化风险分数；下文该部分是本支线基于现有项目公式作的推导，不冒充论文结论。

## 3. 本项目候选的数学位置

以下区分当前实现与解释性扩展。当前实现的 A、H、T、V 已与本目录代码和协议逐项只读对照；一般 RKHS 输出公式只是边界分析。

每个类别/关系组有 R 条参考船记录，第 r 条有 m_r 个合法配对 (b_ri,n_ri)。保持现有 VV/VH 和 side/end 分组及有效边定义。若一艘船有多条观测，须明确先在船内汇总再等船加权；当前原库为不同 MMSI，不能将 token 数量当独立船数。

设参考框内核矩阵为 K，查询对参考核矩阵为 K_qS，等船权重矩阵 D 的第 r 块为 I/(R m_r)。带权核回归的一个形式为：

```text
A = K_qS D^(1/2)
    [D^(1/2) K D^(1/2) + lambda I]^-1 D^(1/2)
H = A Z_S.
```

Z_S 是参考邻域的显式特征或 RKHS 特征，A 按参考船拆成 A_r。若输入/输出均使用与旧式相同的线性特征、同一逐船中心化、lambda 和等船权重，矩阵恒等式给出旧类池线性预测；仅把所有边拼接再均匀加权，在 m_r 不同时会改变原来的船权重。该退化关系可用于判断收益是否只来自权重/尺度改变，不需要另做大规模验证。

当前 Z_S=N_S，H 是欧氏邻域预测，输出核等价于线性核。只有另行令 Z_S=psi(N_S)，才会得到非线性输出 RKHS 风险；这不在本轮五臂中。核中心化及求逆后 A 可有正负系数，所以 RBF 的局部相似性也不保证最终 A 是局部概率分配，不宜称为已显式辨识多个专家或多个模式。

### 与已知 conditional mean embedding 是否等价

**在有限样本估计器的代数层面，是标准加权向量值 kernel ridge regression，也是线性输出核条件均值嵌入的实例。没有新的逆算子求解原理。** 更精确地，令 Phi 的列为框内 RBF 特征，tilde(Phi)=Phi Hs，每列是该 token 减去所在参考船的核特征均值；查询采用同样逐查询船的中心化。令 N 的列为中心化邻域输出。下列已知形式的目标：

```text
min_U sum_i w_i ||n_i - U tilde(phi_i)||_2^2 + lambda ||U||_HS^2

Uhat = N W tilde(Phi)^*
       [tilde(Phi) W tilde(Phi)^* + lambda I]^-1

(Uhat tilde(Phi_q))^T
  = Kqs sqrt(W) [sqrt(W) Kss sqrt(W) + lambda I]^-1 sqrt(W) N^T
  = A N^T.
```

这直接给出 `run.py:61–66` 的 A。正规方程的输入二阶算子与输入—输出互算子就是加权经验条件均值算子的常见组成；与 [3] 的差别是投影后的特征、非均匀 W 和本文规定的 lambda，而非新的核回归解。这里为了算子方向采用列特征记号，代码的 `sn` 等于上式 N^T。

不过，**不能把这个等价式写成恢复原始 P(N|B=b) 的保证**：逐船中心化让 tilde(phi_i) 依赖该船的其它合法 token，查询侧 Hq 也引入自身集合上下文；它估计的是这种中心化表示上的关系。W 保持等船质量，token 又非独立同分布，不能直接照搬原文 i.i.d. 收敛结论。主线程已验证线性核退化的 9.7e-17 数值一致性，证明实现衔接，不证明新的统计性质。

本轮实质可定位在三个层面：几何定义的框内—邻域跨内容配对；逐船投影、等船质量及船内独立置乱共同规定的统计比较单位；将精确置乱期望风险差作为类别关系证据。前两者是任务建模选择，第三者是相对普通 CME/FRN 读出的主要具体变化。三篇已读方法段落未提供这一整套构造，但本次检索不能证明该随机化风险差在其它领域从未出现。换用 RBF、源数据中位距离定宽度和 516 参数匹配本身都不足以支持强方法创新。

为隔离核化本身，中心化也应明确：对原始特征先减均值后应用非线性 psi，通常并不满足 sum_i psi(n_i)=0。若后续置乱公式要求输出零均值，需要在映射后做 Z_r=J_r Psi_r，J_r=I-11^T/m_r，对应输出 Gram 中心化。保留还是去除船均值是建模选择；与旧式比较时应匹配，不能把变化统称为“非线性收益”。

## 4. 船内独立配对置乱的精确风险：可扩展至 RKHS

这一节是本支线推导，承接本地已验证的线性公式。它限定于**平方 Hilbert 空间风险、给定参数与支持集、A 仅由框内证据决定**。每条参考船内独立、均匀地置乱合法输出行，不跨船混洗。

先给保留输出均值的通式。令 Q 为查询邻域特征矩阵，Z_r 为参考输出特征，bar(z_r) 为其行均值，Zc_r=J_r Z_r。置乱矩阵为 P_r：

```text
H       = sum_r A_r Z_r
H_pi    = sum_r A_r P_r Z_r
Hbar    = E_pi[H_pi] = sum_r A_r 1 bar(z_r)

V = sum_r [ ||Zc_r||_HS^2 / (m_r - 1) ]
          * [ ||A_r||_F^2 - ||A_r 1||_2^2 / m_r ]

S_excess = E_pi[ ||Q-H_pi||_HS^2/m_q ] - ||Q-H||_HS^2/m_q
         = [ 2<Q,H-Hbar>_HS - ||H||_HS^2 + ||Hbar||_HS^2 + V ] / m_q.
```

m_r>=2，与现有合法参考规则一致。推导理由：置乱后每行输出的期望为船内均值；零均值输出的置乱二阶矩满足

```text
E[P_r Zc_r Zc_r^* P_r^T]
    = ||Zc_r||_HS^2/(m_r-1) * (I - 11^T/m_r).
```

不同参考船独立置乱，因此中心化随机部分的跨船交叉期望为零；均值部分保留在 Hbar。该恒等式只使用内积，故欧氏输出与 RKHS 输出均成立。这里的“精确”指在指定随机化集合上的代数期望，不指估计了真实数据分布或获得精确泛化风险。

若每条参考在输出 RKHS 内已中心化，则 Hbar=0，形式恢复为旧式的 2<Q,H>-||H||²+V。记 L_SS=Z_S Z_S^*、L_Sq=Z_S Q^*、L_rr=Z_r Z_r^*，可直接计算：

```text
S_excess = { 2 tr(A L_Sq) - tr(A L_SS A^T)
             + sum_r [ tr(L_rr)/(m_r-1) ]
               * [ ||A_r||_F^2 - ||A_r 1||_2^2/m_r ] } / m_q.
```

必要的算法边界有实际后果：

- 精确条件是 A 在所定义的配对置乱下保持不变。仅由 B 决定是当前实现采用的充分条件；若联合 B/N 注意力或基于 N 的模式选择使 A 随配对置乱改变，上式不能继续作为该新算法的精确零参照。依赖置乱不变的边际统计本身不破坏这一条件。
- 期望是给定参数下置乱参考配对后重新读出的风险，不是每次置乱都重新训练模型的风险。固定错配训练臂检验的是另一件事，不能替代此期望。
- 应先累加参考预测 H，再计算平方范数；把各船风险分别相加会丢掉真实预测的跨船交叉项，改变当前类池算法。
- 该分数可为负，直接作为关系证据进入既有匹配的残差读出即可。截零、阈值接受或依据最终类别分数选择是否启用，会另加门控机制，不能与风险差本身混写。
- 船内位置未必在真实采集机制下可交换。它仍是合法的有限随机化参照，但不能仅据此称为显著性检验、条件独立性证明或物理因果识别。

| 当前 kernel transfer T → kernel excess S | 船内随机配对风险参照是否提供净增益 | 无优势则保留非线性关系的可能效用，缩小对精确零参照必要性的主张；不能把原始 T 加最终阈值当作等价实现 |
| 同样核/容量的框内与邻域独立重建 | 改善来自跨区域条件关系，还是一般核重建能力 | 独立重建复现收益时，跨区域配对的独特价值未成立；它是 FRN 风格匹配基线，不冒称 FKFRN 完整复现 |
| 当前 excess → 固定错配 shuffle101 | 完整训练流程是否利用真实对应而非仅边际内容 | 错配复现收益则削弱配对机制解释；此干预与给定参数下的精确置乱期望不相同 |
| 当前 kernel covariance → T/excess | 简单交叉关系能否达到相同效用 | covariance 已是值得保留的简化基线；代码同时去掉求逆与预测能量项，不能把全部差异归因于求逆 |

`run.py:91–92` 的 covariance 使用 `2<Nq,A Ns>/m_q`，而 T 还含 `-||A Ns||^2/m_q`。这是本轮定义，不是实现错误。只有以后要单独声称“求逆是收益来源”时，才需固定风险形式只替换 A；否则无需扩充实验。各臂单独冻结恒等 utility RMS，复用旧结果时仍应把尺度与选择协议作为已知比较条件说明。

输入 RBF/输出 RBF 仅是将来若坚持“同条件多模态”主张时才有意义的扩展对照，不要求本轮做。当前非线性输出缺席本身不否定输入非线性对分类的潜在价值。

“简单局部匹配”是出现解释歧义时才考虑的替换对照：先对未在 RKHS 中中心化的非负 B 核相似性乘等船权重并行归一化得到 P，再按比较协议使用 Hq P Hs，沿用相同输出特征与精确置乱风险。不能直接归一化已经中心化的 Kqs，其行和可能为零且含负值。该对照区分局部邻近选择与正则逆算子的必要性，不要求本轮新增训练。

本轮已含船内固定错配训练/评价臂，直接利用其结果作上述干预证据即可，不另行要求相同作用的新臂或枚举所有排列训练。

已有最强混淆类诊断应直接复用：分别看真类减平均错类、真类减最强错类及冻结 full 的救回/误伤。若训练内条件风险下降但最强竞争差距更差，可能是学习了共享可预测结构，不能以拟合更好证明模式保留成功。evaluation485 已反复参与开发，不称独立盲测。

主线程继续从实际 chip、实际同类/混淆参考及配对贡献检查收益条件：区分输入可分的局部模式与输入相似但输出不同的情形；图像外观和局部权重只是证据线索，不能自动命名物理机制。原有 1129 条件迁移误伤而简单对照正确等案例可优先复用，但代表案例不能代替总体比例。此支线没有查看新原图，也没有为机制附会新的图像结论。

## 6. 可用的暂定定位表述

> 我们研究冻结分类器中局部关系证据的读出：用逐船中心化、等船加权的核条件均值回归，以框内证据确定参考迁移系数，再检验其对配对邻域的解释能力。类别关系分数定义为真实配对相对参考船内部独立重排配对的精确期望平方风险优势。我们检验输入非线性是否改善线性类池关系对可区分局部响应的混合，以及该风险读出能否改善最强混淆类别竞争和完整分类结果。求解器沿用已知核回归形式；本轮输出为线性邻域特征，不主张恢复完整条件分布。

完成相应匹配对照前，使用“研究/检验/候选”措辞。不能写成“首次核化重建”“已恢复完整多模态分布”“证明船体与邻域物理耦合”或“已获得完整模型增益”。已读文献提供了具体数学基础，也留下有意义的任务差异；FKFRN 方法全文仍是最明确的近邻核查缺口。该缺口限制排他性 novelty 表述，不阻止已获授权的针对性实验。
