# 多参考组织训练：修正参考库依赖

2026-10-24，训练前冻结。

## 依据

父目录固定查询更换参考库的诊断已完成。43配置excess的200步终点在原库utility为OA85.25/BA88.11%，换五库后OA35.87-42.08/BA31.38-35.35%；即使只训练20步，utility BA也由48.17降到约41.72，低于原完整模型42.20。改变参考而非查询即可破坏训练收益，支持存在参考依赖，但仍不能将全部跨采集退化归于此。

## 唯一训练改变

保持上一轮低秩变换、条件重建/随机配对参照算子、512+4参数、完整前两模块、每步644查询、全局混合CE、正则、Adam .01和200步。每个优化步从fit_train1205中的合法独立MMSI池重新抽64个参考，每类8个，匹配原库四组可用性模式；同一步所有臂和配置使用相同参考库。预定随机种子10000+step，不根据标签效果选参考。

对同一抽取参考库计算Ztheta-Zidentity，使用原训练臂的utility身份RMS固定尺度。仅共享变换和四个系数学习，不学习参考ID专属参数、不加门控。

四臂independent/transfer/excess/excess_shuffle101，三个既有基础配置17/29/43，共12拟合。变换初始化仍共享17，不能说三次独立初始化。错配臂对每图有效邻域槽位固定置乱，训练和推理一致；不改其边集合或可用性。

## 对照与选择

为了排除更改选择口径的影响，将上一轮固定库训练保存的0/20/50/100/200检查点，按本轮相同选择口径重新选择。不得重新训练或按evaluation选倍率。

选择口径：selection612上，原库加父目录预定五库的J=(OA+BA)/2等权平均，严格提高才更新，平局保留早检查点。五新库之间和训练参考之间会重叠，尤其稀有类；这是参考组成扰动，不是独立数据集。选择标签不进入算子训练。

主系统评价仍部署一个原有64参考库，另外五库逐个报告稳定性。不要把平均六库的预测融合偷偷作为主模型；六库只用于选择和诊断。evaluation485仍为开发集，所有选择完成后才读出评价结果。全部结果公开，不挑最好新库。

## 成立范围

若多参考训练改善完整分类净收益，并超过相同组织训练的独立重建/错配算子，才支持局部条件关系的额外价值。若只改善稳定性而未提高分类，也如实保留。参考重采样本身属于训练组织修正，不宣称是底层算子创新。

每轮仍完成原始VV/VH、实际同类及混淆参考的救回/误伤/持续正确/持续错误回看。同步代码、正负表和解释，不上传数据缓存或权重。
