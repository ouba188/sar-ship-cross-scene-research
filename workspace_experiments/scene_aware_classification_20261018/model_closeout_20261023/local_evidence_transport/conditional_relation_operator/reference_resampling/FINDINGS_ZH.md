# 参考依赖诊断与针对性训练修正

2026-10-24。结论：发现了可操作的参考组织依赖，并用12次多参考训练得到有限OA正信号；还没有形成兼顾类别平衡与换参考稳健性的强第三模块。此前两个有效组件和其他保留候选均不替换。

## 1. 这一轮到底改变了什么

原路径为冻结基础分类器 + 双向类别响应注意力 + OBB区域类别证据读出，记为full。第三候选在汇总前读取同一冻结layer1的框内B和对应邻域N，框内建立ridge对应，再解释邻域响应。excess以真实配对重建误差相对于随机重排参考邻域的解析期望误差作为分数；共享低秩M_b/M_n学习关系变换，四个系数将相对identity变化加到full。

本轮不是另造门控或增加注意力层。先固定所有参数只换参考，随后只将固定参考训练改成逐优化步重抽参考，算子、512+4参数、200步、学习率、损失与正则不变。independent使用框内/邻域各自独立重建，transfer没有随机配对参照，excess保留配对参照，shuffle101错配真实边；四者训练组织与预算相同。

参考数量仍为每类8、总64个源案例，不是64个目标标签；本轮没有目标支持适配、外部数据集扩围或测试时六库预测融合。

## 2. 先确认真实可用数据

fit_train1205观测、1004艘不同MMSI；排除原64艘之后有940艘新参考候选。每MMSI沿用第一条合法观测，与旧库口径一致。旧库由每类KMeans代表点选出，五新库为预定101/307/509/711/907模式分层随机替代，各64艘、每类8艘，VV/VH四组有效模式与原库逐槽一致。fit_train与utility644、selection612、evaluation485无MMSI/pass交叉。

海工类只有17艘canonical参考，其中VH可用10艘，原库已有6艘，所以新库各保留2艘旧船、共享4艘新VH可用船。五库总320槽仅239艘不同船，不是五份独立证据。各库class-pass覆盖也改变；因此本实验识别的是对参考构成和代表性的依赖，不能单独证明只是在记忆某些船只身份。完整审计、所有原图路径见POOL_AUDIT.md和pool_inventory.csv。

## 3. 固定查询换库，收益怎样变化

先对原库重放，分数最大误差为0；之后用同一尺度、同一参数、同一查询换库，identity项也使用同一新库，未重新拟合倍率。

43配置、excess20步（上一轮源选择结果）：

|查询集合|full BA|原库BA|五新库平均BA|
|---|---:|---:|---:|
|utility644|42.20|48.17|41.72|
|selection612|40.25|43.15|39.27|

更晚的200步终点在原库utility为OA85.25/BA88.11%，换库后OA35.87-42.08/BA31.38-35.35%。终点只诊断utility/selection，没有使用它评估evaluation。固定查询就能破坏已学训练收益，支持参考依赖；不把它说成全部跨采集损失的唯一原因。

43配置evaluation的旧/新库分数增量平均相关仅0.4385；约79.9%的新增量平方能量不能由旧增量的一个缩放解释。说明不只是“新库修正得少”，关系方向也变化。连续风险/类别结果/全部库分别见metrics.csv、changes.csv、paired.csv。

## 4. 针对性修正：训练轮换参考，不换查询

每步从同一fit_train候选池按原模式抽取64参考，预定种子10001至10200，所有臂/配置共享抽样序列。训练644查询、selection612仍固定。每组关系先计算同库identity，再算学习增量，初始严格零。重绑定参考张量与新建reader的输出误差为0，没有只改bank索引却沿用旧缓存。

选点使用六个固定库上的selection J等权平均，不挑最好库；旧固定库训练的保存检查点也按同一口径重新选择，全部退回0步。新训练仅excess、independent、transfer的17/43配置启用，29配置退回0；shuffle三个配置均0。六库参与源选点并可能被重抽训练接触，不称未见参考。

### 换参考并未解决

excess在五新库的平均OA为56.29-58.08%、BA38.45-40.56%，尚未保住完整识别收益。43配置、同为20步时，旧/新库增量平均相关由0.4385升到0.6040，换库差异RMS由0.8606降至0.4194，但原库增量RMS也从0.8732降至0.4497。故既有幅度收缩，也有方向一致性改善；不能把变小全解释为学到了稳定机制。新库仍有约63.4%的增量能量不能用原库的一个缩放解释。详见episodic/stability_comparison.csv。

## 5. 原图和实际参考回看

主代理实际查看两轮各四幅原始VV/VH面板，共8面板，以及源覆盖2面板。所有推理面板使用native160裁/补零、不缩放、固定0..255显示，标明region及有效性；特征RF35，框内/外不是像素级完全隔离。展示参考为该次分差变化最强组中绝对贡献最大的实际同类/混淆类参考，不是注意力图或人工挑选最像图。

- 1376化学品船换库后失去上一轮救回：相对散货从+1.470变-1.141，VV侧向贡献+.681变-.305，VH侧向+.808变-.110。查询细长亮响应与新散货26962均有延展响应，新同类30725较紧凑且边缘另有亮点；这些是图像事实，不能仅据外观断言某一结构造成翻转。计算上改变的是实际类内/类间参考的关系分数。

## 6. 创新判断与下一步

本轮可以保留：原完整模型不动的OA小幅增益、正确配对算子与错配/独立重建的差异，以及“固定查询下参考构成即可破坏关系学习收益”的具体发现。不能保留的宣传是：已经得到强第三创新模块、所有参考下稳定有效、几何/物理机制已证实。

多参考训练本身是修正学习组织，不作为底层算子创新。算子候选仍是“框内建立对应、迁移邻域、用有限配对随机参照评价超额关系”。其最关键剩余缺口不是训练有没有动，而是个体参考的少量局部边能否支持可靠的类条件关系。

下一步优先检验汇总层次：当前先为每艘参考的4或8条边单独求逆再平均，端部中心化后最多3个独立方向；可比较先在类内按船等权积累框内协方差与框内—邻域交叉矩，再求一个共享条件算子。它改变的是逆算子估计位置，不是再加分类后权重。需要保留图内中心化、配对随机参照，并与普通交叉协方差和独立重建匹配比较；只有源端类别关系与完整增益同时支持再扩围。这里是有数据依据的下一步，尚未实施，不能作为已完成创新。

## 7. 运行与解释边界

固定库诊断约10.5秒；12训练约182.2秒（冻结缓存上的局部模块，不含图像骨干提取）。本轮没有重训前两个模块。固定原库分数重放误差0，动态参考重绑定检查误差0，原图贡献与完整分差差值小于3e-5。首次诊断将非连续角色位置误当有序位置，被断言截获，改为显式反索引后完整重跑；错误运行未生成性能表。稳定性分析首次目录父级写错，修正后运行，无性能选择变化。
