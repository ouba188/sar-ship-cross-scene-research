# 下一算法方向：竞争发生在局部证据汇总之前

2026-10-24。依据本轮冻结扩围、源端实际响应及原图；这是下一阶段设计约束，不是已实现/有效的第三模块。

## 已定位的现象

输出核 independent 的源selection17中，757/2346个查询×组记录同时出现真类skill提高、真类减最强错类差距恶化。相对平均错类更好也未保证排除强错类。17/43共享新初始化，不算独立重复；selection已用于原选点，诊断是探索性的。

21952主要排除了集装箱竞争，却仍偏向渔船局部证据；31546的VH主体8/8 token对渔船/拖轮都为负，邻域有部分正贡献。图中两查询都是紧凑小目标，不支持按清楚部件顺序建模。当前普通局部匹配在3075查询上仍更好，不能替换为更复杂但总体更弱的核重建。

## 真正要改变的位置

现有新核通道：局部重建贡献 -> 对token均匀求和 -> 8类4组摘要 -> 固定组系数 -> 加到full。Mb/Mn虽受完整CE训练，但共享线性变换不根据当前查询及其竞争类改变局部读出。

下一候选应保留局部证据矩阵 E[token,class,group]，在丢失token之前计算候选与其他类的关系，再决定同一位置如何支持或反对候选。完整M1/M2和已有来源信息冻结，训练仅用合法源查询/参考。不能输入真测试类、人工指定“当前错误类”或根据目标成绩挑阈值。

## 必须避免的伪创新

若仅把每个token的类别分数改成log-softmax，再对token平均：

```text
sum_i log softmax_c(E_ic)
= sum_i E_ic - sum_i log sum_k exp(E_ik)
```

第二项与候选c无关，类间分差不变。这不会产生新的判别能力，只是重写原平均分数。普通类别中心化后再等权平均也有同样问题。任何拟议公式先排除此类等价变换，再谈算子创新。

## 可检验设计空间

候选级竞争必须实际改变局部选择/表示，而不是只改总分标度。可探索查询内容与“候选-竞争类证据剖面”的低秩交互，输出位置相关的有符号或归一化权重；它必须区别于已有M1的单个图像类别响应双向注意力：本通道的输入是查询与实际参考在局部形成的多候选关系，交互发生在参考比较之后、空间汇总之前。

这仍可能落入已有判别注意力/度量学习范围，不能直接声称首创。需继续核对最近的局部few-shot判别学习方法，明确与单纯softmax竞争、普通内容注意力、M1复用的实质差别。本轮在线检索未取得可核对的新全文，未编造文献或以标题断言novelty。

## 下一轮最小有辨别力比较

1. 冻结原两个模块与同一参考和token，保留原普通匹配基线。
2. 候选竞争交互与同容量“只看本类局部值”、内容独立加权、等权汇总比较；三者使用同损失、参考日程、训练预算与源选点。不能把已有CE当新增机制。
3. 明确初始通道基线：要比较新表示本身，不能只评价相对自身恒等输出的增量；但初始无扰动也要保留为接入对照，防止悄悄更换完整模型。
4. 单独检查排除最强错类、真类已占优部分误伤、逐类与参考抽样范围；若有局部独特收益就记录，不要求所有港口获胜。
5. 回看真实token及原图，尤其31546这类主体全部偏错的反例。如果新权重仅重新放大错误局部，先判断是否需改变局部表示，不反复增加注意力层。

当前没有开始这轮训练。它只有合理待验证路径，尚未满足强算法创新和净收益目标；不把上述设计文档当成已完成模块。
