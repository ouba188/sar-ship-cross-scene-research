# 查询与参考一致的尺度差分读出

2026-10-24，训练前固定。基于image_frequency_probe的像素干预和原图回看开展，不新增采集或重新选择数据。

## 依据与假设

既有原图细尺度衰减既可救回23733，也会误伤36491；邻域粗尺度响应主要受框内输入经滤波扩展驱动。因此不直接去掉某带、不称邻域为纯环境。本轮检验：同一query和reference都经过一致的尺度处理，网络对逐渐移除细节的响应差，能否补充原有匹配。

固定原M1/M2输出，在补充局部匹配支路比较四种组织方式。普通独立局部匹配仍作为强基线，不要求处处胜出，但需分清是否只是多尺度/参数增多带来收益。

## 读出定义

在未补零原PNG上形成I、G1(I)、G4(I)、G12(I)，reflect边界；再按原placement原生crop/pad160，不缩放、不重新拉伸、不改变OBB和20槽位。每幅图使用同一冻结R50 layer1、C4、source-fit PCA32得到未unit坐标Y0/Y1/Y4/Y12。非法极化/槽位保持无效。

这是网络对不同输入尺度的响应。差分为F(I)-F(G1(I))，不等于F(I-G1(I))，也不是纯傅里叶频带或已识别物理因素。四个差分加起来恢复Y0，不增加观测信息；价值只能来自对匹配/学习更适合的组织。

| 臂 | 四个通道 |
|---|---|
| repeat | Y0,Y0,Y0,Y0，同容量无新增尺度信息 |
| multiscale | Y0,Y1,Y4,Y12，普通多尺度 |
| difference | Y0-Y1,Y1-Y4,Y4-Y12,Y12，逐尺度差分加低通余项 |
| mix | 固定seed1024正交4x4混合四尺度，检验是否一般换基也有效 |

每臂同样逐通道unit、同样各极化/区域独立局部匹配、同样source参考每类2张。参考身份在原始主体相似度下固定，不随臂变化，不用query真类选参考。四路各12局部响应，加3个旧full类别分数/竞争上下文，共51维；同一51->12->1共享类残差头，637参数。旧205参数单尺度独立匹配、原M1/M2完整链同时报告。

## 检验与解释

未处理原图特征、参考选择与旧局部读出必须能重放；尺度差分重构、orthogonal mixing逆变换只检验实现，不视为创新证据。记录差分范数，防止把小范数归一化后的匹配误当强内容。

报告OA/BA/J、真实/错误类分差、类别/过境分层及三配置结果。真实原VV/VH和实际同类/混淆参考回看持续对错、救回、误伤。解释尺度通道贡献可通过冻结头的替换/积分诊断，不将响应差直接命名物理机制。

保留标准：明确范围内可重复、有净收益和可解释作用即可。若仅普通多尺度有效，就保留多尺度，不为凑第三模块宣称差分创新成立；若都未受益，先定位表示/归一化/接入问题再决定是否修正，不无界调参。
