# 成对空间—频率条件比较：本轮完成

2026-10-24。九组训练、配对评价、源端关系诊断、八组原生VV/VH及实际参考案例回看完成。**保留为小幅OA/概率风险收益候选，不覆盖旧强模型；它没有同时保住上一版的原油轮收益。**

## 1. 这轮实际改了什么

此前把联合描述符统一变换成每张船的新向量。新版本不统一改写船，而是针对每个查询槽位和参考槽位，选择哪些旧内容通道更值得比较。原图、OBB20槽位、骨干、PCA32、参考库和分类头都不变。

每个槽位已有三尺度频率能量与内容的同位置协变量 `C=E[eF]-E[e]E[F]`，共96维。先投影 `h=A*C` 到4维，再由查询/参考的均值及绝对差生成32个正权重：

```
phi = [(hq+hs)/2, abs(hq-hs)/2]
w = 1 + 0.25*tanh(B*GELU(phi))
K = sum(w*xq*xs) / sqrt(sum(w*xq^2)*sum(w*xs^2))
```

A为96×4、B为8×32，无偏置，共640可训练参数。B零初始化，权重限制在0.75至1.25。K对交换查询/参考对称、范围[-1,1]，统一放大所有权重不会改变K，因此不是单纯调高相似度或OT温度。不宣称K是全局正定核或满足三角不等式的距离。

新K进入原区域OT，再得到各类的VV/VH框内、侧向、轴端匹配摘要。最终 `score=strong+head(newlocal)-head(oldlocal)`，初始化重放原强模型。C不直接产生独立类别分数。没有给条件网络输入真类、港口名称或绝对角度，但这不等于证明隐表示完全不含方向/场景关联。

三臂同640参数：pair_joint是上述方案；separable_joint分别生成查询和参考权重后取均值，没有成对交互；pair_marginal将C换成独立均值外积 `M=E[e]E[F]`。两个新对照均使用同一归一化K、图像范围、训练量和选点协议。旧joint与frequency仅作上下文基线，不当作只改变一个变量的消融。

## 5. 已回看的图像与计算证据

八组主线面板均实际查看；原PNG160 crop/pad不缩放、统一显示0至255、VV/VH分开，包含实际两个真类参考和两个旧最强错误类参考。黑色边缘是补零，不是海面。源端另有两组由子代理实际查看。观测事实、冻结网络内部替换和物理机制分开表述。

**28839散货，seed29，救回。** 旧集装箱→新散货；其余本轮对照、旧joint及frequency均仍错。查询为短斜亮主体；错误参考8286也有相近短斜轮廓；真类23272更长偏竖、23781偏横，不能靠“方向相同就是同类”解释。查询VH轴端可见延伸响应，VV/VH强弱不一致，未命名为尾迹。实际参考23272/23781对8286/21323。真类优势-.11016→+.19909。固定头六区域精确Shapley中，VV/VH轴端合计+.20772，框内合计+.12270，侧向合计-.02117。它说明这些读出改变有计算贡献，不证明外围是纯环境或某条纹导致分类。

把比较分数K和对应分配T交叉替换：旧T旧K分差-.11016，仅新K为+.05287，仅新T为+.02710，两者同时+.19909，均可救回。因此不是只在最后输出上加一个偏置，局部比较及分配两部分均参与。T包含拒配/真实匹配质量，不只是空间位置重排；这些是冻结模型内部干预，不是配套训练的替代架构成绩。

**7875散货，seed29，误伤。** 旧散货→新成品/化学油轮；各自条件化仍对，marginal、旧joint、frequency也错。查询短斜亮主体与两种类别参考均有共同外观；真类33678/35396整体比查询更长，错误类31086/24840更紧凑。不能仅凭此宣布模型按长度分类。分差+.06912→-.11059；VV框内-.08370、VV轴端-.06727是主要负贡献。仅新K已-.07244而判错，仅新T仍+.03103正确，说明该例的错误比较本身足以制造错误。

**4598持续正确，seed17。** 成品/化学油轮，分差+.47404→+.51350。查询近横向、真类7564/28586更竖向，错误散货26615/2379也近横向；背景颗粒强弱不等。六区域小幅正贡献，不形成新top1收益，也不是朝向匹配规则。

**367持续错误，seed17。** 海工补给仍被判散货，分差-2.77865→-2.82512。长亮查询与紧凑同类30434/3187有明显外观差别，错误散货23781/33678也呈细长亮主体。当前轻量比较修正不能弥合该强错误；不能凭外观改标签。

**上一轮30232与4531，seed29。** 30232 VV强交叉延伸、VH较弱，本轮仅把分差-.51598改至-.50327，仍错；上一轮joint能救回的结果没有保住。4531本轮保持正确，+.16964→+.09876，避免了上一轮joint误伤，但优势仍下降。两者共用错误散货26615/2379。因此不能说本轮同时解决了原先两例的问题。

**2080原油轮，seed43，BA边界。** 查询竖斜且VV有交叉延伸，真类12549/1156偏横斜，错误35396竖斜；VH延伸较弱。同类参考也有延伸，故不构成散射类型规则。分差+.13836→-.17557，VV/VH框内贡献合计-.24772，占主要负变化。仅新K就判错(-.04502)，仅新T尚正确(+.02695)。真类VV框内局部匹配下降.02779，错误类仅下降.00849；VH真类下降.02071而错误类上升.00843。这是具体错误关系，不是泛称少数类难。

**29687原油轮，seed43，BA边界。** 查询和真类1156/12549均横斜、尺寸及背景有差异，仍被改成散货，说明不能以“真类方向不一致”统一解释2080与29687。分差+.13014→-.00322；框内贡献合计-.09937。仅新K(+.06776)或仅新T(+.04987)各自仍对，联合才越界。它与2080的失效路径不同。

## 6. 根因定位到了哪一层

已排查插入/梯度：零初始化整分数重放最大3.58e-7、局部3.87e-7，有限差分与实际梯度吻合；交换对称及统一权重缩放不变检查通过。八案例新旧T/K端点均重放缓存，区域贡献加和重放完整固定类对分差。没有发现“模块没接上或没训练”的证据。

源端独立诊断不支持手写“联合描述符越近越同类”：utility真类较旧rival近为50.78%，selection为54.90%；强救回36384真类反而更远，强误伤35739真类仍略近。该标量明显依赖类别/参考，不能把频谱接近直接当奖励，亦不能据此否定96维组合的价值。详见source_diagnostic。

当前模型层面的已证事实是：可改变比较通道及匹配分配，部分关系变好、部分框内真类关系被过度削弱。表中OA/BA分歧已定位到实际观测，**但尚未证明为何所学通道偏好会在这些原油轮失效**；可能涉及源类条件覆盖、参考代表性、共同参数或冻结读出适配范围，不能直接选一个当根因。source selection J/NLL可改善，不能仅凭开发BA下降一概称为过拟合。

## 7. 创新定位与下一步

可保留：区域同位置空间—频率联合证据驱动、查询—参考边特定的归一化通道比较；它接在已有区域组织与分类读出之间，不是独立重做分类器。成对注意力、联合矩和加权余弦各自已有先例，不以改名宣称首创。当前证据足以保留有边界的算法候选，不足以宣布强第三核心模块已经完成。

下一步不加更深网络、不按这两张目标样本调类别阈值。优先在源端找同样的真类框内被削弱现象，再做一个有针对性的匹配对照：**让联合信息只改变局部证据如何对应，而保持旧内容相似度用于计分**，与当前同时改K和T配套训练比较。它可能保护7875/2080，但不能保证所有样本收益，也可能失去28839的一部分效果；29687表明联合累积效应同样要保留检查。该下一版尚未训练，本轮不把它写成已解决。
