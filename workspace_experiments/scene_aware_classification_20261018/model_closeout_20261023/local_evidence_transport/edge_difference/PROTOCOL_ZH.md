# 四点交叉差分：先检验结构证据，再开发可学习算子

2026-10-24，运行前方案。目标是算法层面可解释的改动，不是多加一个attention gate。本轮为有界可利用性验证，不预先宣布新卷积成立。

## 数据起点

reference_dependence冻结外推未保住BA。实际渔船-普通货船竞争子集中，76条外部查询有74/75条VV船体/侧邻域首选同一普通货船参考3536。原始chip显示316普通货船、13734渔船、189普通货船均有弱小条状目标，3536也具有较暗、较弱显示响应。固定类别偏置参与错误，但去掉偏置也没有改善整体。因此不能把下一步简化为删除3536或减一个bias。

待验证假设：分别相似的局部未必具有相似的船体-邻域变化模式；四点交叉比较能提供当前局部均值与参考依赖统计遗漏的关系证据。它不声称暗背景是噪声，也不要求某类具有固定方向。

## 算子

一条query边连接船体槽位b与实际相邻槽位n；support同理。令S_ij=q_i^T s_j，则

```
M(q_b,q_n;s_b,s_n)
 = (S_bb + S_nn - S_bn - S_nb)/2
 = (q_b-q_n)^T(s_b-s_n)/2.
```

这是对2x2匹配块施加固定核[[1,-1],[-1,1]]/2。若相似度污染是a_i+b_j，它被精确消去；**不等价于消除了所有亮度、观测条件或物理散射影响**。强非加性干扰仍可保留。原单点证据在冻结anchor中保留，不把差分当作替代船体表示。

实际船体边与邻域边按原OBB槽位连接：侧向8条(b=i,n=8+i)，轴端4条(b=0,1,6,7;n=16,17,18,19)。不确定船首尾，不用AIS朝向，不输入绝对角度。每组边作为集合匹配，OBB轴180度翻转只排列集合。对整图任意旋转不宣称严格不变；底层仍是已有四视图平均特征。

使用已有源PCA32单位token，不将差分向量再次单位化，以免弱差分变成强证据。不改变输入尺度、图像范围、检测框、源参考库。VV/VH分开，各自侧向/轴端共四组。

## 配对对照

1. body：仅q_b^T s_b。保留四组入口和相同合法边集合，检验差分是否只损失船体证据。
2. additive：.5*(q_b^T s_b+q_n^T s_n)，同一对顶点普通联合相似。
3. mixed：上述四点差分。
4. mixed_shuffle101/211/307：仅在每张图、极化、边组内把有效邻域端点按固定随机排列重新连接，保留所有船体/邻域token和各自质量。训练和评价均错配。不要对无效节点作伪填充。

所有算子用同样query边质量、support边质量和聚合：只用两端mass是否为正确定合法边，合法边组内等权；对每条query边在类内有效reference、有效support边上做相同tau=1/sqrt(32)的log-mean-exp，再对合法query边平均log证据。每个有效reference等权。**不用两端面积乘积重算权重，否则置换端点也会改变质量，混淆配对作用。** 类间中心化四组分数，再按utility源RMS缩放；缺组按实际mask贡献0。

这四组只拟合4个类别共享系数，叠加冻结anchor。它是对新结构证据的低成本检验，不以4参数线性头本身作强原创。各arm均有相同训练/选择资源，规模差异不得当作结构收益。

## 训练与评价

沿用644utility训练、612selection选0/20/50/100/200步、485evaluation汇报，三个基础配置17/29/43。Adam.01，0.5CE+0.5balancedCE+.01平方和；严格源端J提升才选新checkpoint，默认step0。六臂18fit，不用评价标签挑边、温度、缩放或对照。

本轮先做源端；未经结果解释不自动扩外部。若有结构增量，下一步才学习通道/边兼容性，并加入有数据依据的参考覆盖训练。不因四点恒等式正确就保证会涨点。

## 验证与解释

必要实现检查：四项展开与差分内积一致；加任意行/列偏置后M不变；轴反向后真实边集合与评分仅重排；有缺极化/无效端点时只保留有效边；保存预测与四组贡献重放。检查对应具体失败，不扩大为全库审计。

每轮回看实际query与同类/竞争类参考原图。记录每条边的四点分数和最终贡献，不把采样位置热图当物理机制证明。若仅普通additive有效，保留它的收益但不把mixed包装为创新；若错误参考仍占据多数，说明加性混淆解释不足，需要回到表征/学习关系。

四点差分本身是经典双线性交叉差，不是新代数。值得争取的进一步算法贡献是：**在目标相对区域图上构造具有明确零一阶响应性质的关系算子，使混淆参考的共同匹配不再自动等同类别支持，并通过跨采集的真实净收益与对应边贡献验证。** 当前只是有数据依据的候选；可学习设计和强创新验证尚未完成。
