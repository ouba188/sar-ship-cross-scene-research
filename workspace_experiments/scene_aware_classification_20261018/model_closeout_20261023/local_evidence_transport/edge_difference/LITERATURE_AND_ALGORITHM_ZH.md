## 不是另一个最终分数门控

当前错误发生在局部相似被聚合时：两处都偏向同一混淆参考，未必构成两个独立的正确证据。普通最终门控可以调小增量，却无法改变这个相似度定义。

四点原型先改变匹配单元：

```
body(query) <-> body(reference)
near(query) <-> near(reference)
减去两条交叉对应：
body(query) <-> near(reference)
near(query) <-> body(reference)
```

它问的是“对应角色是否比交叉角色更相配”，而不是简单问“两个区域是否都亮、都与某参考相似”。这是模型关系解释，不是把背景减掉得到真实船体，也不是物理去噪。

若S_ij = a_i + b_j，四点输出为0。若S还有不能拆成单端偏好的交互项，四点才可能非零。该性质对正负加性偏好均成立，但不保证所有非零项都与类别有关。

## 值得深化的可学习版本

只有真实原型显示结构证据可利用时，再把固定点积换为共享可学习通道算子：

```
M_W = (q_b-q_n)^T W (s_b-s_n) / 2.
```

同一个W同时用于四项，不能四项各用互不约束的权重，否则零一阶响应性质消失。W可低秩参数化控制成本。进一步的位置处理必须使用目标相对边角色和轴反向一致的几何量；不能输入绝对朝向去预测船型。

这与只学7个统计系数不同：W直接学习哪些通道间的局部变化能构成对应关系，作用发生在匹配聚合之前。需要与同容量无交叉项的bilinear匹配、一般关系网络或RENet-inspired相关滤波公平比较。低秩、双线性和差分各自都不是新数学；潜在贡献是**受零一阶响应约束的目标-邻域关系计算及其跨采集增量效用**，并须由数据建立，不用命名替代验证。

## 不能忽略的失败路径

1. 若船体和邻域token因感受野重叠几乎一致，差分可能只剩少量不可靠量；不再次单位化去放大它。
2. 若混淆来自真实的共同形态而不是加性偏好，四点不一定解决，需要负结果界定范围。
3. 一个目标只有某一局部有效时，过强的关系要求可能删去真实证据；因此保留原路径，不强迫关系分支单独识别所有船。
4. 若additive已经同样好，说明新增交叉抵消未建立独立价值，不能将普通边聚合当强原创。

阶段成功不是“有复杂公式”，而是：明确改变了错误证据形成方式；保持图像范围/容量等条件后有可重复净收益；真实边优于错配边或说明有效边界；实际query与reference能追踪贡献。当前还在争取这些结果。
