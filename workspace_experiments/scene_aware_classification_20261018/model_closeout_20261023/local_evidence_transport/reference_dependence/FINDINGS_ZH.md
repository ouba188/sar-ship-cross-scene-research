# 参考内联合证据：先保留边际，再检验关系

2026-10-24。源端18个头、冻结边际15个头及3075条冻结外推均已完成。尚未建立强原创核心；源端有限收益保留，外推负结果保留。

## 检验的问题

分别看船体、侧邻域、轴端或VV/VH，会得到各自对64个源参考案例的匹配。原来的聚合丢失了“两个区域是否同时匹配同一实际参考”的关系。本轮固定每个区域的响应集合，只改变参考之间的对应，不把普通注意力权重改名当原创。

令h_g(r)为query区域g对候选类参考r的正核响应，本轮统计：

```
D_gh = log mean_r(h_g(r)*h_h(r))
     - log mean_r(h_g(r)) - log mean_r(h_h(r)).
```

它是归一化协方差的log形式；亦等于log(R*dot(softmax(u_g),softmax(u_h)))，R为共同有效参考数。它不是新数学，也不等价于因果信息或完整统计独立性。七组关系为VV、VH各自的船体-侧向、船体-轴端，以及跨极化的船体、侧向、轴端。

三组错配在共同有效参考内置换第二个区域，逐query/class保持所有单区域响应及边际不变。另设同容量的单区域乘积nonlinear。缺VH不填伪观测。源码prepare逐样本验证了边际和多重集不变。

## 原图与实际作用位置

主代理逐一查看analysis四组VV/VH query与实际同类/竞争类参考，共40个面板。native160裁剪/补零，不缩放；layer1感受野35，不把区域token说成像素纯船体或纯海面。

- 1064散货船相对nonlinear被救回，但full原本已正确：bulk-crude分差+.2786，经新边际变成负值，joint最终仅+.0019。联合项+.2947在修复新边际项造成的-.5714。不能把它包装成救回旧模型错误。
- 2418散货船：nonlinear正确，joint错误。去除联合项后分差从-.0586变成+.0758。这是联合项真实误伤，而非模块没接入。
- 150持续判对，联合项对bulk-crude分差+.0442；220持续判错，联合项+.1317仍不足以抵消其他项。

## 针对性修正

依据上述损坏旧读出的案例，冻结已有full+uniform局部读出，仅训练7个补充关系系数，详见frozen_marginal。源端OA/BA得到改进，但外推3075条没有保住BA，故“重学边际”只能解释局部失效，不是已证实的唯一根因。

该阶段不支持直接开发更复杂的自由耦合网络。先识别联合项究竟提供query特异的判别关系，还是主要隐含了参考库的类别偏好；同时保持已有主模型和正负结果不变。

## 创新定位

有价值的是具体研究问题及可辨别对照：在单区域证据不变时，实际参考内联合关系是否有额外作用。统计公式和7参数线性补充本身不是用户要求的强算法创新。下一步若深入，应改变关系形成或学习机制，并优于边际乘积、真实/错配关系等合理替代；不能只增加参数或更换模块名称。
