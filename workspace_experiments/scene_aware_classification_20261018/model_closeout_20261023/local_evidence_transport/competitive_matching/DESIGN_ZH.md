# 共享查询证据的竞争匹配：算法候选

2026-10-24。设计与算子小验证阶段，不是已成立的第三创新组件。原有效V1/V2不改；泛用MLP条件增量降为备选对照。

## 问题和实际证据

源端88的实际query、散货船参考与集装箱船参考均有强亮条状响应，239则是不同类别共享短小亮块。PCA32下239的最高真类参考相似度仍低于错误类最高值。图像与分数见 `../semantic_projection/DIAGNOSIS_ZH.md` 及 `analysis/case_88.png`、`case_239.png`。这些现象支持“高相似不等于有区分力”，尚未证明它是全体失效的主要原因。

原body锚定匹配并未胜过独立区域匹配，区域二阶核也未证明正确依附必要。因此不继续把几何结构固定得更强；本候选改的是比较目标：同一候选类别与竞争类别必须使用同一组query证据，并允许竞争类别在这些证据上取得自己的最优匹配。

## 与直接相关方法的边界

- DMN4：已读原文arXiv:2103.08160v2第3.3–3.5节，公式1、6、12–13及算法1。跨所有支持类建立MNN，使用最近本类与最近异类的余弦差，避免累计低判别局部描述子。故“减去异类相似度”“区分相似与判别”“任务相关patch筛选”都不是我们的新概念。
- SOT-GLP：已读arXiv:2603.08347v1第3.1–3.4节，公式7–10。按候选类的prompt集合选同一top-K patch集合，再在该类多个prompt之间做平衡OT。不能把摘要的shared support误读成所有候选类别联合分配。它证明了这类组织方式有前人基础，不等于我们的跨采集SAR结果。
- DeepEMD、FRN、CrossTransformers的既有原文笔记见 `../LITERATURE_ZH.md`。局部对应、重建和query条件匹配均非空白。
- 新检索到SL-JFDA，IEEE JSTARS，DOI 10.1109/JSTARS.2026.3728527，IEEE页面记载2026-08-31发表。当前仅读官方摘要：局部交互、散射先验、query到类支持分布的Sinkhorn匹配。未取得方法全文，不据此声称其没有竞争优化。

## 算法目标

输入为已冻结的区域局部描述子，保留原像素尺度、VV/VH区分、源端PCA和同一支持库。先不增加可学习key或修改检索，以免混入表示及参考变化。

令a为query有效区域的初始质量，w为优化后的质量，b_c为类别c支持质量，S_c为相似度矩阵。所有质量由可用性和预定归一规则生成，不读query标签。将真实query与支持总质量各设为1，各再加质量1的dustbin，令增强边际为(w,1)、(b_c,1)。这样真实query拒配量可变化，不能仅固定一个null列后误称可自由拒配。

令a0=(a,1)，b0_c=(b_c,1)，R_c=a0 b0_c^T / 2。对每个候选类求

F_c(w) = max_T { <T,S_c> - eps * KL(T || R_c) },

约束T的行、列和为(w,1)、(b_c,1)，null边相似度为0。KL为广义KL，所有类使用相同eps、拒配规则和类内质量预算。重复支持若拆分原质量，不应凭数量获得分数优势。

候选c的竞争证据分数为

G_c = max_w { F_c(w) - max_{d != c} F_d(w) - lambda * KL(w || a) }。

原型先约束sum(w)=1、0<=w_i<=2a_i、a_i=0则w_i=0。上界用于限制只挑一个幸运亮点；这是预设工程约束，不是SAR物理定律。所有类别都需在每个新w上重新取得最优匹配，不能把负类T当作可任意压低的参数。不同候选c仍有不同w_c，这一选择偏差必须报告，不声称整幅图得到唯一解释。

本候选的意义不在OT或min-max名称，而在：证据选择会改变支持侧容量竞争；竞争类的最佳对应又反过来约束证据选择。最终输出G作为原冻结模型的补充，源端选择接入强度；不得用目标标签选算子或倍率。

## 求解和能证明到哪里

内层为标准熵正则运输。外层一般非凹，不承诺全局最优。原型从w=a开始，以内层行对偶敏感度更新w，使用带上限的镜像上升、回溯和原目标重算，保留最佳访问点。只有内层边际误差合格时才接受外层改善。

需核实的性质：

1. 相同类支持分布应给相同分数，不能无信息也偏向某类。
2. 复制支持且拆分原质量，匹配值不应变化；这检查熵或库大小伪增益。
3. 对所有类和null同时加入同一query行常数，竞争分差不变；不能将这类常数“去偏”称新算法。
4. 每次报告真实优化目标而不是只报告相似度项，避免丢掉熵项后对偶梯度失配。

去掉支持容量约束后，单一竞争类及无上限时会退化为局部gap的log-sum-exp软选择。这是必须面对的普通方法，不是新颖性证据。本轮若未证明容量耦合和竞争响应有额外价值，就不把候选立为第三核心。

## 有界实验

首先在已有源端缓存上做：固定质量OT gap；无支持容量耦合的gap软选择；完整共享质量竞争匹配。相同参考、相同区域输入、相同源端接入规则。先不叠新MLP，不动骨干，不在目标集调参。

源端utility用于设计诊断，selection用于冻结参数，evaluation用于本阶段确认；这些是重复使用的开发划分，不称全新盲测。原始top2在所有方法中固定；如后续研究全8参考，必须所有方法一起更换。

看完整OA/BA、NLL/Brier及增量计算成本，同时观察w集中度、竞争类变化、实际运输变化。回看救回/误伤/持续对错的原VV/VH和实际参考。只在合理任务范围内要求可重复净收益，不要求每港每类全胜。

若只有固定质量gap已带来收益，保留简单有效组件并据此归因；若外层优化只给所有类都增加可挑选分数而不改善判别，先定位优化偏差，不继续堆网络。算法层面值得主张的候选差异是“同证据、最强替代匹配的耦合选择”，目前尚未证明首创或有效。

## 当前实现状态

`solver.py`已实现固定KL参照的内层求解、对偶梯度、上限质量投影与回溯外层。`solver_checks.json`仅为合成检查：边际误差1.11e-16，对偶梯度与有限差分误差4.49e-12，复制支持并拆分质量误差1.11e-16，完全相同类别分差0。两区域示例中，优化将权重移向有类别分差的区域；这只能说明目标按定义工作，不说明算法新颖或真实SAR有效。尚未开展新分类训练/真实数据评估。

本原型调用方必须先去掉无效token并保证质量严格为正；不能把缺失slot随意填成可匹配零向量。真实缓存接入时需要处理各类不同有效支持数、缺失极化和区域身份，不能直接将所有token混成没有身份的袋。

独立只读审查核对了固定R的对偶梯度符号、两dustbin可变拒配、cap KL投影和完整目标接受规则，未发现这四处实现错误。竞争类切换处使用单一活跃rival的梯度可能提前停止；停止不证明驻点，更不证明全局最优。这是后续成本/求解误差评价的边界。
