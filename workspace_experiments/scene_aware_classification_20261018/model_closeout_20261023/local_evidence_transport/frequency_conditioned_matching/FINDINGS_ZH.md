# 空间与频率共同决定局部匹配：首轮结果

2026-10-24。六组训练及原图分析完成。结论：**频率条件化有可保留的局部收益，相对匹配容量的内容条件化更好；但相对旧强普通局部模型，OA略降、BA略升，整体基本持平。保留候选，不替换旧主线，也不宣布第三个强原创模块已经成立。**

## 1. 实际做了什么

沿用既有M1/M2、R50 layer1/C4/PCA32、OBB组织的20个局部槽位、64张源参考库及每类固定两张参考。没有恢复5%交接，没有重新训练骨干，也没有改变参考身份。

新增的不是整图FFT分类头，而是局部内容比较算子：

1. VV/VH原生PNG分别做4/8/16像素波长、四方向的零直流Gabor滤波；先在真实PNG上滤波，再读区域。图像不重新缩放或拉伸，不在补零画布上滤波。
2. 每个槽位形成24维频率描述：12个对数能量及12个相对响应份额。框内方向相对船轴；外围每尺度四方向响应排序，保留方向强弱差别，不用绝对朝向编号。
3. 对查询局部块与参考局部块，将两侧描述的和及绝对差输入共享小网络G，输出32维有界调制。
4. 用它调整原内容token的逐维乘积，再进行原区域内OT匹配：

   `K(q,s) = dot(fq,fs) + 0.25 * sum(tanh(G(eq+es,abs(eq-es))) * fq * fs)`

5. 冻结旧局部分类头h：`s_new = s_strong + h(L_new,z) - h(L_old,z)`。初始化完全回到旧强模型，仅训练680参数G。

空间域规定“哪些局部位置可以互相比较”；频率描述影响“这些位置的内容，应怎样比较”。两者在匹配前交互，并非各自分类后拼分数。调制不是类别标签，也不强制同频率等于同类。

同预算content臂用既有PCA单位token前24维作条件，其余容量、优化、支持和查询一致。它是一个明确的内容条件化对照，不代表所有可能的强内容度量方法。

## 2. 数据与选择

- 1805条并集：源参考64、utility训练644、selection选点612、历史evaluation485。
- 评价485条涉及445艘船、29个过境组、8类。这是反复开发的队列，不是新增独立确认集；本轮未扩到公开集或外部3075队列。
- 三个既有配置17/29/43；content/frequency配对初始化，共六个模型。100次全源更新，固定checkpoint集合，仅源selection的J=(OA+BA)/2选点。
- frequency选择100/40/60步；content选择60/80/100步。所有模型和选点落盘后才汇总评价结果，没有按评价分数追加训练。
- source utility有效极化1205个，OBB长中位24.00px、宽9.40px，波长由这批几何范围确定，不按评价调参。

这直接解释本轮OA/BA方向不同：大类损失在OA里权重更高，多个较小类别改善对BA更有影响。它不是“所有样本关系都更好”。少样本类只报告现有计数，不据此宣布稳定类别边界。

源utility每条有效极化平均船长的25分位15.94px作为小目标阈值。按目标长、16px滤波真实支撑覆盖率分组已写groups.csv；不同配置方向不统一，尚不能制定“某尺寸就开启”的使用规则。

## 5. 原图与实际参考：已逐张回看VV/VH

面板保持native160裁剪/补零，无缩放；8px热图是固定滤波响应，不是学到的注意力。图中相似颜色不能证明频率匹配决定了类别。以下精确六组Shapley替换在冻结头内计算，分解VV/VH的body/side/end新旧摘要对固定类对分差的影响，不是物理因果归因。

### 救回220，普通货船，seed17

查询船体较短，VV周边可见颗粒状响应，VH中心响应更突出；两张同类参考6970/21927的背景亮度不同，散货参考33678/35396呈较细长响应。不是“背景一样所以同类”。

- strong误判散货，frequency判对普通货，content仍错。
- 真类对最高错误类分差 -0.2092 → +0.0216。
- 真类body匹配分数增加VV +0.0692、VH +0.0503；散货body改变VV -0.0030、VH -0.0353。
- body对最终固定类对分差的贡献合计+0.1953，总变化+0.2308；主要来自船体匹配，不是外围占主导。
- 真类body运输矩阵L1变化VV0.2547、VH0.2260。匹配值与对应都改变，但未单独证明运输重排的额外效用。

### 误伤12716，散货船，seed17

查询是紧凑横向亮目标，两张散货参考35396/2379更长；普通货参考12625也呈横向亮块，26409更小。可见外观有重叠，不能靠这一图断定船型或物理机制。

- strong/content判对散货，frequency改错普通货。
- 分差 +0.1397 → -0.1066。
- 真类body匹配下降VV -0.0211、VH -0.0321；普通货body上升+0.0706/+0.0490。
- body贡献-0.1864，总误伤变化-0.2463。

两个案例共同说明：新比较方式确实能重新区分普通货与散货，但也可能把“紧凑响应与参考组合”错误地当成普通货证据。**这是数据外观与计算路径一致的待验证解释，不是已证实的通用失效规则。**

### 持续判对25486，成品/化学品船

查询和两张同类参考均较紧凑，散货参考一短一长。分差+0.0993 → +0.4945；body合计+0.2993。原先已经判对，所以证据增强不产生OA增加。

### 持续判错25876，成品/化学品船

与上一例共享同类参考31086/24840，查询也呈紧凑亮目标，但散货参考组合不同。新算子增强真类body匹配，却从散货误判变成集装箱误判。

真类对当前最高错误类分差-0.4780 → -0.0471；固定旧散货竞争类的改善约+0.5037，其中body+0.4238。两种分差不可混同。改善一个类对仍不足以战胜第三类别，不能把局部关系改善直接当作八分类成功。

## 6. 实现、数据边界与根因判断

- 初始strong输出重放误差3.58e-7、原local3.87e-7、旧头4.77e-7；梯度有限差分一致，G不是未激活或完全没学到。
- 常量/零直流/单位核范数、90度联合坐标、半周船轴能量、mask映射和保存回读检查通过。它们验证实现性质，不证明完整模型对任意朝向不变。
- 16px波长对应49px核，不是16px窗口。源utility轴端完全真实支撑覆盖平均VV0.222/VH0.227；本轮反射边界可能影响粗尺度描述，432/485评价条目的平均覆盖<0.9。未按此剔除样本；尚未隔离其对性能的因果影响。
- 核可以跨OBB，所谓body只是读出中心区域，不能声称该频率描述纯粹来自船体。外围四方向排序也不是雷达观测轴建模。
- seed29训练损失持续下降，而selection J从40步0.4949降到100步0.4788；selection NLL却由1.4669略降至1.4621。这更具体地表明top-1目标与连续损失的兑现不一致，不宜笼统称所有表征过拟合；已按源选点40步保留。
- 旧头冻结便于保持基线，但也限制读出适应；尚未证明这是主要瓶颈。content仅取前24维，尚未排除换一个更强内容条件描述即可达到相同收益。

因此，当前已确认的是实现可学习、局部比较及类别排序确实改变、部分船型收益存在；未确认的是净收益稳定优于strong、运输重排不可替代、边界或某种物理机制是主要原因。

## 7. 保留与下一步

保留frequency作为“频率条件局部比较”的候选及完整正负记录；旧M1/M2+strongordinarylocal仍为主线。不因为不能处处获胜删除候选，但也不把content较弱包装成新算子全面胜出。

下一步最有辨别力的方向是：**固定本轮候选，分离频率调制匹配值与改变局部对应的作用**，再用合法源端训练的区域限定版本验证body主贡献是否可复现。先从源selection及已有原图证据入手，不按这485条挑倍率/区域；本轮未执行该追加训练，也未扩展公开集。

提取1805条耗时73.0秒，六组训练加缓存评价总132.1秒，仅新增680可训练参数。这些是离线批处理计时，不能替代端到端推理成本对比。原图频率提取与匹配均有额外成本。
