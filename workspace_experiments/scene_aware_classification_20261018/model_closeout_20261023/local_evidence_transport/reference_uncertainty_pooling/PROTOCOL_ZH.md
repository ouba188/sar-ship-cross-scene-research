# 参考扰动下的局部证据组织

2026-10-24，先写方案再运行。复用原始chip回看：412中的选择能避免误伤，968中的VH端部选择反而阻碍救回。可见亮响应不提供可靠性标签，不能先假定它们来自某种物理机制。前轮位置权重确实变化，但普通/共享位置权重更好，说明“能够变权”不等于“知道何时该变”。

本轮首先源端检验：删去一个参考船后，同一查询不同位置的类证据是否共同变化；这种敏感性是否预测替换参考库的分差波动，以及在匹配局部间隔后是否关联判错。完整源参考每类8船，VV/VH和区域分开。删除是对匹配算子的干预，不是对真实SAR生成过程的干预。

保留每个参考的log-mean-exp局部响应。对每类删除第r个有效参考后重新算类混合，得到leave-one-reference剖面。剖面中心化外积给出T×T扰动协方差，按(n-1)/n缩放（描述参考敏感性，不宣称总体方差无偏、独立采集或置信区间）。候选对使用两类独立扰动协方差之和，不假设真实场景变化在两类间独立。少于2有效参考则没有可估协方差，不能把它称为高可靠。

复用已有utility644/selection612，源fit_train参考及六个合法库；先不读取485/3075结果用于决定信号。查询/参考按既有船/采集隔离。源阶段可以使用真类诊断，但拟议算子不得使用查询真类。保留稳定但错误的反例，不将低扰动直接等同判别信息。

若实际参考替换有可预测扰动且实现可行，尝试以明确的优化目标组织局部证据：保持类对交换对称，对位置权重施加共同参考扰动风险约束，同时允许类间差异提供判别目标。比较不考虑风险、仅对角风险、完整协方差风险，固定输入、容量、源选点和完整模型。协方差和凸优化本身均非首创，是否形成方法贡献取决于其位置、实际信息和净收益。若源证据不支持，不为新名称硬训。
