# 为什么可学习线性W仍不是最终算法

2026-10-24。下面是算子信息限制的推导，不是SAR数据已满足该反例的证据，也不是新的分类结果。

## 差分之前丢失的信息，差分之后的线性学习无法恢复

定义一条目标-邻域边为(b,n)，d=b-n，m=(b+n)/2。现有mixed只使用d：

M_W(e,e') = d^T W d'/2。

即使学习任意完整W，两条具有相同d但不同m的边也始终不可区分。单位化并不排除这种情况。例如在三维特征空间取d=(1,0,0)，m1=(0,sqrt(3)/2,0)，m2=(0,0,sqrt(3)/2)，各自b=m+d/2、n=m-d/2；四个端点均为单位向量，两条边差分完全相同，端点内容却不同。这里特征坐标不是地理角度，不能把例子解释为船舶朝向。

因此，当前学习W的实验只能判断已有差分通道的可利用性，不能解决所有目标-邻域关系别名问题。body/additive对照与mixed同容量，有助于区分一般通道适配与关系增量。

## 对下一步算法的具体约束

若真实SAR案例证实这种限制与错误有关，则需要在丢失端点内容之前构建关系，而不是对差分后的向量继续加权。例如比较phi(b)-phi(n)与phi(b-n)是两个不同的问题；非线性phi可能保留端点依赖性，但也可能过拟合。非线性核、核均值嵌入及双线性度量都是通用工具，单独使用不自动构成新算法。

强组件应进一步回答：在不改变原有效路径、不依赖绝对朝向的前提下，什么端点内容使某条关系具有区分类别的价值；如何通过受约束的对应计算保留这种依赖；同容量普通局部算子是否已经足够。不能以数学反例替代真实chip和完整分类证据，也不据此立刻追加多种网络搜结果。
