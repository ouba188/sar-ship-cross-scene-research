# 当前算法推进位置与最近邻工作

2026-10-24。用户要求算法层面的足够强创新；以下区分已做事实、普通对照和待发展的核心，不用模块数量代替贡献。

## 已有事实支持改动位置，但尚未支持强方法结论

在固定区域汇总之后调整系数，无法改变正确类和混淆类都能得到强匹配的现象。当前固定四点虽然有明确代数性质，却没有产生完整分类净收益。下一轮把学习移入通道相似度，目的是回答“固定匹配是否限制了可用性”，而不是宣布普通矩阵学习就是核心创新。

源端正信号与外推失败必须共同保留：reference_dependence冻结旧边际后有源端收益，但外部渔船反复确认了同一个普通货船参考。不能据此推断所有重复确认都应删除，也不能自动把邻域当作噪声。

已读作者renet.py、cca.py和scr.py；本轮未获取可完整阅读的PDF。它用局部自相关增强表征、query/support四维相关上的可分解卷积修正，以及双向归一化注意力。CCA对交换query/support后的结果转回相加。因此“相关张量上做卷积”“双向注意力”已有明确先例。

### IFR，IJCV 2026

Cross-domain Few-shot Classification via Invariant-content Feature Reconstruction，期刊页面记载2026-01-11发表，不能从DOI中的2025推断年份。已读HTML全文§4.1-4.4及§5实验设置；算法1为图片，本轮未读取图片细节，不声称核对过该图。

其前提是内容与风格独立；对支持图做保内容增强，以原图/查询为Q、增强支持为K/V做注意力重构，再与原表示相加、线性变换、原型分类。适配时学习Q/K/V及变换，不是额外的背景分割损失。用到裁剪缩放、翻转、灰度和色彩扰动，不能直接照搬为SAR物理观测变化。注意力重构与原表示融合已有先例，不能换名宣称原创。

对本项目的启发（推论）：需要区分合成增强下的稳定性与真实跨采集有效性；邻域未必都属无用风格。当前协议继续使用原始尺度和真实参考，不为模仿论文加入缩放或删背景。

## 本轮普通对照能决定什么

1. learned body与mixed同样增益：主要支持通用通道适配，不支持船体-邻域关系的独立价值。
2. mixed优于同容量additive且真实配对优于错配：才支持进一步发展角色关系约束，仍需案例和冻结迁移检验。
3. 连续损失改善、分类不改善：保留中间进展，不以此宣称最终任务已受益，也不直接判为过拟合。
4. 全部无增益：不得无休止增加参数；应回到具体分差与实际支持，判断固定区域/表征是否已经限制信息，而非继续末端加权。

## 强算法组件的实际设计目标

不是额外套一层attention，而是使匹配计算同时区分：局部响应本身的相似、这些响应在目标-邻域角色中的对应、该对应对真类与混淆类的区分能力。若采用新约束，需说明它改变了哪一项计算，普通同容量算子是否已能替代，以及哪个实际错误因此被修正。

船轴仅用于目标相对组织，轴反向不应改变类别；不引入绝对朝向类别捷径。保留原有效路径，避免为获得纯关系表示强迫删除原有类别信息。当前W原型是可利用性探针，不把它作为已达成的第三核心，也不宣称顶刊创新目标已完成。
