# 汇总前通道关系学习：匹配容量的可利用性验证

2026-10-24，开始训练前固定。本轮是对算法设计依据的验证，不预先称第三强创新组件。上一轮固定四点的真实类/竞争类均有强响应，仅四个汇总系数无法改变其通道相似度。原图4717/1064/150/220及edge_difference诊断为依据；不预设可学习版本一定有效。

## 明确改变什么

旧固定匹配为q^T s。引入共享对称矩阵

W = I + (UV^T + VU^T)/2，U,V为32x4。

所有区域/极化/类别共用W，U以固定随机种子生成的小随机数初始化、V为0，初始W=I。无绝对船轴角、AIS首尾、目标标签输入。W可非正定，因此称有符号相似度而非严格距离。256个通道参数加4个原区域系数，各臂相同容量。原anchor、骨干、PCA、参考库均冻结。

五臂：body、additive、mixed、mixed_shuffle101、mixed_shuffle307。前者仅b_q^T W b_s；additive为(b_q^T W b_s+n_q^T W n_s)/2；mixed为(b_q-n_q)^T W(b_s-n_s)/2；置乱沿用edge_difference合法邻域端点置换，不改变边的有效性/等权质量。

四点使用同一W，不能四项各用独立矩阵。它仍保留单端加性匹配偏好抵消的代数结构，但不将这种结构直接等同于因果去噪、正确类别信息或强原创。可学习度量、低秩、对称化均为通用做法。

## 回答的问题与读法

1. 相比固定版本，学习相似度能否增加有效类别分差？保存初始/所选W、四组分数和系数、逐类及救回/误伤。
2. 若body或additive同样更好，说明主要是通用通道适配，不把它归为关系结构创新。
3. 若真实mixed比错配好，进一步检查具体真类与混淆类参考；不能只据均值认定区域关系已证明。
4. 训练更新、源selection连续损失及J分别报告。未选择非零模型则如实保留阴性，不用evaluation挑步数。
5. 原始VV/VH及实际参考回看由主代理执行；无翻转也看持续对/错和分差。先只源端完成，再决定下一步，不能自动扩围。

本轮若有可重复净收益，只说明存在可学习的汇总前关系或通道证据。强算法创新仍需在此之上明确独有的结构约束及其独立价值，不能降低目标为“训练了一个矩阵”。
