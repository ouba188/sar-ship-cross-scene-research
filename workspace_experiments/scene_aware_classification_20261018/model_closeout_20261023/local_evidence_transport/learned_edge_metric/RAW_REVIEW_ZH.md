# 原始图像与学到的匹配：四例回看

2026-10-24。主代理已查看analysis四幅完整面板，每幅含查询、两个实际真类参考及两个竞争类参考，VV/VH各自展示。维持原始160裁剪/补边，不缩放船只；显示范围内的轮廓是读出区域，不是像素纯前景/纯背景分割。案例固定seed17，按mixed相对anchor的四种结果选最小obs_id，不按视觉好看挑案例。

## 1128：成品/化学品油轮被救回，但不是关系特有的救回

查询来自Tanger Med，VV/VH均为短亮条；实际真类7826、24840是不同背景上的亮条，混淆普通货船33307、6970也呈类似粗略形状。不能凭肉眼认定某个区域只属于油轮。

真类减普通货船分差：anchor -0.192230，mixed +0.129851；body +0.875977、additive +0.195604也救回。因此该案例证明局部通道适配能补充该查询，不独立证明四点配对必要。

固定所选系数a，W从I换为学习值后四组分差贡献依次由+0.033807/+0.021610/+0.248535/-0.135379变成+0.220194/+0.128597/+0.212708/-0.239417。主要新增正贡献来自VV侧部和端部；VH端部反而更偏向错误类。面板所列参考按最大绝对贡献组VH_end检索，不能误称这些参考就是正向救回的全部来源。

## 1064：局部匹配确实改善，但仍误伤

散货船查询有VV横向亮延伸、VH较低位置亮块；实际真类33678/35396较暗背景上是亮条，错误原油轮34742/12549也有亮条且背景较亮。图像支持粗略响应存在混淆，不支持命名确定的物理根因。

四组raw真类-竞争类分差从W=I时全负，改善为-0.112971/+0.060222/-0.096816/+0.054608。学习后局部增量合计仍为-0.163839，超过anchor原有+0.152668优势，最终变为-0.011171。也就是说，学到的W比同一系数下的I有帮助，但整个补充路径仍把原本正确的样本推错。

这不是“W完全没学到有效信息”，也不是“raw分差改善就等于完整模型受益”。additive在该例保持正确（+0.308474），不支持只能用mixed解决此例。

## 150与220：持续对错亦有信息

- 150散货船为长亮条，真实与原油轮参考粗略形状相近。VV_side的raw分差由-0.414561变为+0.116852；mixed最终分差1.078888至1.160246，持续正确。说明某些通道关系可学，但它不是新增正确数。
- 220普通货船VV背景较亮，VH较暗且条状。四组raw分差均比I改善，其中VV_end转正；其余组仍偏向散货船，合计增量-0.366604，最终分差-0.481512，比anchor更差。类别分差改善相对于哪个参照，必须说清楚。

## 本轮能保留的认识

1. 存在具体查询的关系分差改善，不能把训练整体概括为“没学到东西”。
2. 这些改善尚未形成评价485上的净收益，而且普通body/additive也能救回代表案例；未建立mixed结构的独立优势。
3. 区分三件事：学习W相对I的作用、整个补充路径相对anchor的作用、真实边相对错配的作用。不能用其中一项代替另两项。
4. 本轮不能证明背景无用、不能证明所有关系学习无效，也不能把差分的数学别名反例当作这些图像误伤的已证实原因。
