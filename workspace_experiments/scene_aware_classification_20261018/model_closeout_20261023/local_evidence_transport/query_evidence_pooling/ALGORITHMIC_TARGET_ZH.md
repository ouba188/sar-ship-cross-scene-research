# 从算法角度定义下一步，而不是给权重改名

2026-10-24；设计说明，尚未完成强创新验证。

## 真实起点

支持权重学习能改善局部判别，但整体只带来有限增益；逐query平均log也没有建立完整系统优势。贡献统计不支持普遍单强峰垄断。因此不能预设“选错几个亮点”就是全部问题，继续加门控也不会自动构成创新。

新的问题是：在保持每个区域各自的类别匹配证据不变后，它们之间的关系是否还有额外判别信息？reference_dependence先检验这个前提，使用真实参考内共同出现与保持边际的参考置换对照；这不是已经证明关系有效。

## 不能冒充原创的数学

令h_g(r)>0是query区域g对同类参考r的核响应。比较E[h_g h_t]与E[h_g]E[h_t]，得到

```
D_gt = log E[h_g h_t] - log E[h_g] - log E[h_t]
     = log(1 + Cov(h_g,h_t)/(E[h_g] E[h_t])).
```

这个统计就是归一化协方差的log形式，不是新概率定律。D=0只说明这两个核响应的协方差为0，不能证明随机变量完全独立。加一个线性头也不能单独构成用户要求的强算法创新。本轮用它回答“值不值得开发联合算子”。

## 若联合证据确有增量，算法深化的对象

由原来的单区域注意力权重，转向**保持单区域证据质量的关系耦合算子**。用pi表示同类合法参考质量，关系矩阵C必须满足

```
C >= 0, C 1 = pi, C^T 1 = pi.
```

在该约束下，联合响应为h_g^T C h_t，两个边际不变。独立关系C0=pi pi^T；真实参考内关系Cdiag=diag(pi)。可学习版本必须从合法源数据学习有用关系，不能针对每个候选类无约束地寻找使自己最高分的排列。缺失极化须在共同有效参考集合内建模，不用伪观测补足。

这是算法问题的入口，不是本轮已经实现的模块：**如何在不偷偷改变单区域相似度、类别先验和可用参考数量的情况下，学习有用的联合关系，并以分类的增量效用训练它。** 边际约束、退化到独立模型的条件、与普通attention/独立局部匹配的严格差异，都应在同一算子中说明。

至少需要通过三件事才值得作为强核心推进：真实/学习关系优于保持边际的无关系或错配关系；收益能由实际query和支持的联合响应解释；相对简单替代有值得成本的完整分类净收益。允许任务范围明确、不要求处处获胜，但不以复杂公式替代新增贡献。

若本轮reference_dependence不支持联合关系，不启动上述可学习耦合。届时保留普通局部补充的有限收益，重新定位表征或训练目标，而不是给无效关系再套优化器。

## 补充原始文献：联合统计本身不是新发现

主代理直接阅读 [DeepBDC作者预印本](https://arxiv.org/pdf/2204.04567) pp.3–5、§3.1–3.3。其BDC由联合特征函数与边际乘积差异出发，落成图像特征的双中心化距离矩阵，再以矩阵内积/类原型分类。它已经把依赖统计转成可训练网络层。我们的候选统计是在固定查询下，比较多个区域对实际参考集合的响应依赖，统计对象不同；但“考虑联合分布”这句宽泛主张不能再当原创。

另直接阅读作者 [Few-Shot Learning in Long-Tailed Settings](https://daviswer.github.io/files/tpami2021paper.pdf) pp.4–5、§4.2–4.4。其方法结合leave-one-out训练、前景/背景定位及双线性池化。启发是明确具体任务困难，并验证已有思想经过有意义改造后解决了什么；不是必须发明全新数学，也不是三个通用组件拼起来就自然成为强方法。网页检索标题与PDF标题不同，此处按实际PDF标题记录。

上述两篇新增阅读不替代LITERATURE_ZH.md中的四篇，亦不等同全领域首创调查。我们要争取的是具体算子、学习目标及边际约束共同构成的方法差异，而非宣称前人没考虑关系。
