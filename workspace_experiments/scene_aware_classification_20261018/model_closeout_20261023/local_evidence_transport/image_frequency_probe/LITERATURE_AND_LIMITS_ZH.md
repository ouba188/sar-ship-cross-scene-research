# 原PNG频带干预：近邻工作与设计边界

日期：2026-10-24。独立只读侧线；本次仅形成此文档，未训练、未运行干预实验、未修改主线代码。以下是实施建议，不是已经获得的实验结果。遵循 `codex-brain/INDEX.md`、`01-project-rules.md`、`04-workflows.md` 及 `08-sar-research.md` 的证据边界。主代理负责实现、原图回看与阶段同步。

## 1. 判断与本次问题

**该计划可以执行，适合回答“冻结的局部匹配器对输入中哪些空间尺度、位置和极化的变化敏感”。** 原参考冻结是合理的诊断设定。主要修正应放在滤波与定位的操作顺序、最终扰动剂量和分差定义，不需要新增网络、大审计或训练。

必须保留三个限定：PNG空间频带不是雷达射频/多普勒频段；单边干预可改变查询与原参考的匹配兼容性；局部频带衰减与相位随机化都不能自动保持船型语义或只移除某种物理机制。因此可作模型依赖诊断，不能仅凭频谱相关或分差变化命名尾迹、散斑、失焦、海况等物理因果。

## 3. 三项最接近的原始依据

### [1] Yin et al., NeurIPS 2019

**A Fourier Perspective on Model Robustness in Computer Vision**。作者：Dong Yin、Raphael Gontijo Lopes、Jon Shlens、Ekin D. Cubuk、Justin Gilmer。

来源：[会议原始论文PDF](https://proceedings.neurips.cc/paper/2019/file/b05b57f6add810d3b7490866d74c0053-Paper.pdf)。本次已读取正文，重点第2节、PDF第2–3页的 Fourier heat map 定义。

论文用单位L2的实值傅里叶基扰动，在给定强度下考察模型错误率随频率位置的变化。对本项目直接有用的是**控制扰动范数后测频率依赖**的思路。本文的Gaussian尺度差分、空间softmask与参考匹配是本项目扩展，并非该论文原方法；其自然图像结果不证明SAR高频等于噪声，也不提供本项目的物理解释。

### [2] Wang et al., CVPR 2020

**High-Frequency Component Helps Explain the Generalization of Convolutional Neural Networks**。作者：Haohan Wang、Xindi Wu、Zeyi Huang、Eric P. Xing。

来源：[CVF论文记录](https://openaccess.thecvf.com/content_CVPR_2020/html/Wang_High-Frequency_Component_Helps_Explain_the_Generalization_of_Convolutional_Neural_Networks_CVPR_2020_paper.html)，[作者CMU站点PDF](https://www.cs.cmu.edu/~epxing/papers/2020/Wang-CVPR20.pdf)。CVF直开返回403；书目信息经会议检索核对，实际读取的是作者站点标注 arXiv v3、2020-03-24 的全文，不声称逐字核验会议最终版。

第3.1节对输入FFT做径向高低频切分、逆变换，再比较CNN预测；文中明确区分“利用高频”与“过拟合”。它支持在输入端直接测模型依赖，也提醒不能预设高频全部有害。本文建议使用平滑滤波以降低硬截谱振铃，但这不意味着获得互不重叠、纯语义的频带。

### [3] Copernicus 官方 Sentinel-1 产品说明

来源：[Copernicus Data Space Sentinel-1，GRD/SLC小节](https://documentation.dataspace.copernicus.eu/Data/SentinelMissions/Sentinel1.html)，同一产品解释的官方交叉依据：[SentiWiki S1 Processing](https://sentiwiki.copernicus.eu/web/s1-processing)。本次核验了官方返回的产品说明段落。

SLC像素含I/Q复数信息，保留幅度与相位；GRD经过检测、多视与地距投影，雷达复相位不保留。由此对本项目的推论是：实值PNG的FFT仍有数学相位，但它表示该**显示图像的空间组织**，不是已丢失的SLC复相位。即使PNG来源标为SLC，只读取幅度/显示灰度也不能恢复I/Q。单独扰动VV/VH灰度不能解释为操纵极化相位差或真实散射机制。

术语建议统一为“PNG空间尺度成分”“图像傅里叶相位随机化”“冻结模型输入依赖”，避免“雷达相位干预”“去散斑因果验证”等超出观测内容的命名。

## 4. 针对当前管线的具体修正

以下为基于本地实现和线性滤波关系的设计推导，不是上述论文已经验证的SAR结论。

### 4.1 真实像素域先滤波，160画布只承担既定输入布局

本地 [native_input.py](E:/临时会话/same_vessel_gallery_20261019/local_condition_module/native_input.py) 的 `crop_pad` 先建立全零画布，再复制真实像素；[common.py](E:/临时会话/scene_aware_classification_20261018/eight_class_evidence_20261023/obb_dynamic_readout/common.py) 的 `native` 返回画布、有效footprint和几何。因此“先pad到160，再Gaussian/FFT”会把真实图像与补零的跃迁算入频带。这是当前支持输入下可达的问题。

建议顺序：读取单极化原PNG浮点灰度 -> 在真实图像矩形域计算Gaussian响应 -> 使用与基线完全相同的crop/placement截取频带 -> 在有效像素内乘干预mask -> 加回原160画布。原图较大时可只读/使用覆盖crop及滤波半径的现有原图上下文；原图外使用明确记录的reflect边界条件，不能把反射像素称为观测。

基线输入中的零padding保持原样，干预在padding内严格为零。不能为了滤波方便把网络输入也改成反射padding，否则同时改变基线。真实图像边缘仍存在有限视野假设；干预mask在靠近真实边缘处向内平滑降为零，宽度参考最大滤波核半径。目标太靠边而没有足够内部区域时，将该案例标成边缘受限，而非假装完整主体被干预。不要静默删掉小chip后把结果推广至全体。

### 4.2 把“三个尺度”和“三个band”写成唯一公式

若有三个正尺度 `s1 < s2 < s3`，建议明确：

```text
B1 = x - G(s1)*x
B2 = G(s1)*x - G(s2)*x
B3 = G(s2)*x - G(s3)*x
L  = G(s3)*x
x  = B1 + B2 + B3 + L
```

这是三个差分带加一个保留的低通底图，不能把B3称为包含DC的全部低频。如果计划是“三带完整分解”，则采用两个正尺度，第三带直接为低通底图，并单独说明其衰减也改变亮度。不要在两种定义之间混写结果。

各 `G(s)` 均直接作用于同一原图；若级联Gaussian，需要按方差相加换算有效尺度。Gaussian频率响应重叠，分量相加可重建不等于能量可相加，也不等于独立因子。先固定像素单位尺度；没有每幅图可信仿射/像元间距时，不换算成米或称跨产品相同物理尺度。保持160 crop-pad不缩放是合理的，但不会消除不同产品分辨率差异。

### 4.3 先求band再乘mask；现有1像素soft边界不足以保证无伪高频

`common.py::soft_regions` 明确使用1像素宽线性过渡；其设计适合区域读出，不自动适合频谱干预。现有 `extract_tokens.py::slots` 还用硬分槽划分20个token，**不要把这些分槽边界直接作为像素干预边界**。

定义干预为 `d = -a * M * Bk`、`x' = x + d`。不要先把主体外清零再对 `M*x` 分带，否则频谱首先包含遮罩轮廓。`M` 使用独立于结果的平滑余弦/平滑阶跃过渡，并与真实边界内缩taper相乘；可从固定数像素过渡开始，依据实际窄船宽度避免主体被全部吞掉。读出mask仍沿用原模型，干预mask另行说明。

乘mask本身仍会使频谱卷积扩展，任何softmask都不能实现严格局部且严格带限。故名称应为“局部作用的尺度成分衰减”，不是“只改某个频带、其余频率绝对不变”。同一mask必须用于真实干预与sham；若效应仅集中在mask过渡圈，优先归为定位边界敏感，不能直接归为主体内容依赖。

主体/side/end在当前定义中是OBB代理区域，不是纯船体/纯海面。layer1已有约35像素感受野，局部像素变化影响邻域token是预期现象，不是泄漏或错误；据此不能把某token分差变化唯一定位到其池化区域内的物理对象。

### 4.4 把相位sham定义为“扰动场”还是“图像替换”，两者不要混用

与衰减最直接配对的建议是**带限候选扰动场的随机相位对照**：对真实域 `Bk` 的FFT幅度保留，随机化共轭频率对的相位，逆变换得到实值 `Bk_rand`，再用同一个 `M` 定位。这样得到的 `d_rand = c*M*Bk_rand` 是向原图添加的随机扰动；它不是保持整张图像幅度谱的纯相位变换。

若采用“原带相位替换”，应写 `d_phase = M*(Bk_rand-Bk)`；它与上式不同，既删除原带结构又添加替代结构。两者都可研究，但不要在报告中都简称等价的随机phase对照。首轮保留一种即可。

共轭对相位取相反值，自共轭频点保持实值，明确DC是否保留；不能独立随机所有FFT格点再简单丢弃虚部，否则幅度/能量也被非预期改变。随机化也应发生在真实域，使用一致的边界延拓与回裁，不能在带零边框的160画布上生成“原图频谱”sham。

L2必须在**最终有效像素、乘mask并完成所有像素处理之后**匹配：`||d_rand||2 = ||d||2`。相同能量不代表相同局部均值、对比度、结构破坏程度；mask后也不再严格保持先前幅度谱。至少随结果记录实际L2、区域均值变化和越界/裁剪比例，不能只记录名义系数a。

若主张“不是亮度变化而是空间组织”，再做一个有辨别力的均值匹配版本即可：对两类候选场都减去其M加权均值后再乘M，然后重新匹配L2。此时检验对象变为“均值保留的尺度成分扰动”，应与原始衰减分开命名。低通DC带不能通过保留DC的phase sham假装获得同等亮度对照。

### 4.5 保留浮点输入；不要让重拉伸或裁剪主导结果

当前模型将灰度除255、复制为3通道，再执行固定ImageNet标准化。建议扰动在原显示灰度对应的浮点域进行，保持既有归一化，不重新按图min-max、直方图匹配，也不先写uint8 PNG再读取。后者会量化微小干预并可能发生截断。

PNG高亮饱和与暗背景是实际可达输入，衰减/随机场都可能越过合法范围。预先规定处理：可选用固定的小幅度并记录实际越界；若要求输入始终在范围内，则在一次配对中统一减小剂量至可行范围，或在最终裁剪后匹配L2并明确这是含裁剪的干预。大量裁剪时先修剂量，不把裁剪制造的谱变化归于原band。不要按分差结果挑剂量。

固定a与固定L2回答不同问题：前者是去掉该样本现有带成分的一定比例，后者是单位输入变化下的敏感性。首轮可维持固定a、每样本配对等L2 sham；跨带比较必须同时读实际剂量，不能把高能量带更大的分差下降直接判为更重要。

### 4.6 冻结整个测量坐标系，但正常计算每次query的特征

R50须保持eval，包括BatchNorm统计；PCA32的均值/投影、拟合尺度、参考特征、参考ID、有效性、类别聚合规则和温度保持原样。每次干预后重算query特征及既定的逐向量归一化；“冻结归一化规则”不等于强行沿用旧query范数。

原图上只生成一次干预，然后连同mask/几何进入相同C4路径。四个旋转是同一干预的视图，不是四个独立随机sham；若每个旋转重新采phase，会混入随机平均效应。先复制为RGB再三通道各加不同噪声也会改变灰度输入语义，应在单通道生成后复制。

若原匹配按query选择nearest参考：冻结参考库并不等于冻结实际选择的参考ID。主诊断建议固定原始所选ID，测同一query-reference关系；需要保留原算法重新选择时，可将它作为单独的“匹配器总响应”，注明分差包含参考切换。不能把两种读数混合。

单极化干预时另一极化保持原图、原特征及原有效性；分别报告该极化匹配读数与组合读数。合成双极化补偿、阈值与读出可能影响最终响应，不能从单极化敏感性大小推导VV/VH的普遍物理重要性。

### 4.7 分差同时固定竞争对象并允许真实竞争变化

令 `s_c(x; R)` 是冻结参考R下的类别分数，`c0` 是原始query的最高错误类：

```text
m_fixed(x') = s_y(x';R) - s_c0(x';R)
m_best(x')  = s_y(x';R) - max_{c != y} s_c(x';R)
effect      = m(x') - m(x)
```

两者都保留：固定竞争者用于说明哪段原关系变化，动态最高错误类用于判断是否真的更接近正确决策。同时保留真实类与竞争类各自分数变化，避免“两者都下降、错误类下降更多”被写成真实类证据增强。标签用于离线诊断，不据此为每个query挑干预或参考。

原参考冻结的结论范围是“相对于原始参考库的查询敏感性”。明显退化既可能是破坏有用结构，也可能是制造查询—参考失配；等L2 sham能削弱一般扰动强度解释，不能自动区分二者。无需首轮增加双边实验；若后续结论必须声称“该频带天然无用/应从模型删去”，才在一个已有代表案例上补同规则双边变换等有辨别力的对照。当前不得从单边结果推导删除该频带后重训一定获益。

PCA32后的负结果仅表示当前保留子空间及读出未显著响应，不能证明输入没有这类信息。无需因此自动回到全部通道或换骨干；先在当前结论中保留这个边界。

## 5. 小范围实施与收尾建议

首轮维持原计划的源端样本、冻结原参考和三个预定尺度，使用同一批query逐样本配对真实干预与固定少量phase种子。随机种子只是干预重复，不算新增船只证据。强度和mask宽度事前固定，不按好看的分差挑结果。

仅嵌入能改变下一步决策的几项检查，无需另建审计框架：

- `a=0`须复现原分差；失败就先修预处理、C4/PCA或参考选择路径，停止解释干预结果。
- 在一张原本需要padding的真实chip上看扰动图：padding必须不变；边框/遮罩过渡若主导扰动，就先调整真实域滤波和taper，不做模型结构解释。
- 对实际送网像素核对配对L2及裁剪/均值变化；失配就修sham剂量，不能继续叫“等L2对照”。若重建公式对应三差分带，保留低通余项并确认其定义，没有必要跑完整历史重建审计。

结果只需按既有源划分、类别、极化及必要的边缘受限状态配对汇总；重复船/过境与参考draw不是独立样本。不要把原先已有的分组信息再全量重建。无论涨、平、跌，由主代理回看持续对/错、救回/误伤代表原chip以及实际同类、混淆类参考；VV/VH分开，原图与干预图采用同一显示范围，附实际扰动剂量。没有翻转时看分差与证据变化，不编造物理原因。

可接受的收尾表述是：“在固定源端样本与原参考下，某区域/极化的某尺度成分衰减使某类竞争关系发生变化，超过/未超过同区等L2随机扰动的响应；存在某些失效或边缘受限案例。”这既保留有价值的模型依赖证据，也不把尚未验证的SAR机制写成定论。
