# 原图局部频带干预：源端小验证

2026-10-24，运行前固定。使用karpathy-guidelines及现有原生像素/OBB/冻结局部匹配实现，不新增训练。

依据：既有135号同类参考含框外亮响应，161号查询和参考的细长主体及局部纹理不完全相同；nearest2误伤说明参考相似不等于判别帮助。但外观和参考删除不能区分响应尺度。假设为：某个区域、尺度的图像响应可能推动错误或正确的局部对应。不是预设高频为噪声，也不是解释原始雷达多普勒。

1. 从source selection内有效VV/VH样本，每类固定seed1024抽12艘不同MMSI，每船一条，共至多96条；既有135/161/258/445/921额外作为诊断，不混入抽样平均。排除已知错误obs31237。该源selection曾用于模型选择，故本轮是开发诊断而非独立泛化确认。不使用evaluation或外部目标标签。
2. 按原生PNG像素，先在未crop/pad的原图做反射边界Gaussian尺度差：fine=I-G1、middle=G1-G4、coarse=G4-G12；保留G12低通。它们是重叠平滑频带，不是三个独立物理信号。分别对OBB主体与原有端/侧邻域干预，VV/VH分别试。加窗限制会混频，不称严格仅删除某频率。
3. 25%残差衰减；先在对应softmask内去掉残差均值，尽量不改局部平均亮度。记录截断比例与实际亮度改变。相同原图频带幅度、随机phase(101/307)产生两个对照，经过同mask、去均值、clipping后数值匹配实际L2能量；随机相位只针对灰度图频谱，不是SAR复数回波相位。能量相同不等于全部感知属性匹配。
4. 冻结原R50 layer1、C4、PCA32、区域和参考。原图同尺度crop/pad160，无拉伸重算或缩放。参考身份固定在原始query选定的每类2个，不随干预重检索。首先重放未干预token、匹配分数及完整读出；误差异常则先修实现。
5. 主统计：局部同类/最强混淆分差、原强独立局部匹配接入既有M1/M2后的输出变化。旧主路分数不变，干预仅进入补充支路，故这是支路机制实验，不是全系统改预处理或新方法准确率。3个既有配置分别报告，不作独立新训练种子。以抽样船/采集为重复单位，不把干预次数算样本数。
6. 实际同类和混淆参考保持可追溯。查看救回、误伤、持续判对和持续判错原图及频带差分。出现条件信号才能设计后续配套训练，不从本轮多个干预中挑最高OA直接宣称方法有效。不保证涨点，不因此无限扩展band/强度。

成功标准：定位可重复、区别于等能量扰动的区域×尺度依赖，并给出模型分差和原图证据；若只有一般扰动敏感或不一致，明确保留负结果。物理成因和收益兑现属于后续问题。
