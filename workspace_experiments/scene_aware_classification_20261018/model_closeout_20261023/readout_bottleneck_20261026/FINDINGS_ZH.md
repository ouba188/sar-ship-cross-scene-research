# 本轮结论：信息压缩缺口与后续利用问题已经分开

2026-10-26。完成同输入40次拟合、16次紧凑坐标核查，以及两源、三种子、两种base的12组配套读出重训。所有本轮训练已结束，旧模型和负结果保留，未替换正式主模型。

## 一句话回答

**这次有证据指向模型的信息组织问题，不是只能笼统地说数据太难：源类别读出器没有保住全部区域判别信息；后续修正又没有充分、稳定地利用更强基础提供的证据。** 数据中的类别构成影响收益怎样汇总，但本轮没有发现新的原图或标签错误，也没有排除所有数据因素。

## 1. 相同图像、相同源训练角色，信息在哪里丢了

冻结原生160像素裁补、骨干、极化、区域、源fit_train/fit_validation、目标队列和训练预算。VV/VH分别处理，取框内、侧向、轴端的256维区域特征。比较完整输入、现有类别reader保留的方向、被它消去的正交补，另设同秩PCA和紧凑坐标控制。

下表为三种子MLP均值，OA / BA，单位%。公开四分类为散货、普通货、化学品、集装箱；正向1619张查询，反向921张查询。

| 输入 | OSS1→OSS2 | OSS2→OSS1 |
|---|---:|---:|
| 原始区域特征 | **53.78 / 51.08** | **60.08 / 50.81** |
| 类别reader保留的信息，紧凑坐标 | 45.23 / 41.59 | 47.27 / 40.80 |
| 类别reader消去的部分 | **53.70 / 52.06** | **60.55 / 51.47** |
| 同秩源PCA坐标 | 48.03 / 46.90 | 49.37 / 47.42 |
| 实际M2摘要加质量/几何，普通MLP | 46.16 / 43.72 | 53.67 / 48.88 |

这说明：**原始区域特征里存在当前类别投影没有保留、但仍能支持跨数据集分类的信息。** 不是只有“换个分类头没涨”这一间接现象。

- 当前四分类reader每极化实际秩为3。维数小本身不是程序错误；本轮实验证明它对这里的区域分类任务不够充分。
- 主对照相同输入宽度、头结构和初始化。追加独立坐标对照后仍有明显差距，排除了“仅仅是冗余展开难训练”这一完整解释；参数化仍解释了一部分差距。
- 原始特征减紧凑reader的OA差为8.54、12.81个百分点；按过境配对bootstrap的95%区间分别为[5.47,11.87]、[7.20,17.90]。这是固定历史队列上的区间，不是独立新折训练。
- 正交补与完整输入差异的区间跨0，不宣布正交补更优。正向正交补ridge弱于其MLP，说明信息存在不代表任意读出都能利用。
- 行空间对照不是M2全部非线性空间摘要的等价替代；实际M2摘要另作补充比较。也不能将layer1 reader结果外推为M1/M3的所有信息都只剩3维。

详见COMPRESSION_FINDINGS_ZH.md和compression_analysis/中的完整表。

## 2. 实现中找到的具体设计差异

现有reader在整张chip有效区域的全局平均特征上学习类别方向，随后把同一权重用于局部响应和区域摘要。代码位置为oss1_m123_replication_20261026/train_frontend.py中的fit_reader及fit_base调用；extract_frontend.py构造global1/global3。

**“适合全图平均分类的方向”没有被验证为“足以保留局部区域信息的方向”。** 这是已核实的设计事实，不是代码执行错了。本轮信息投影实验支持其不足；但尚未单独对比全局训练reader与区域配套训练reader，不能宣称这是唯一根因。

## 3. 保住信息后，后续模块能否配套利用

强base严格采用上一轮fit_only区域MLP，不使用pooled训练优势。M2输入和头不变，重新训练；M3重新构造base相关输入及标准化，并配套训练读出、极化组合和门控。所有选择只用源端。

**M3的PairMetric、32张源参考和匹配缓存冻结，因此这是配套读出重训，不是整套M3重新学习。强base也替换了原M1分数，不能把本轮称为已完成的新M1–M3主模型。**

| 路径 | OSS1→OSS2 OA / BA | OSS2→OSS1 OA / BA |
|---|---:|---:|
| 裸强base | 53.78 / 51.08 | 60.08 / 50.81 |
| 加配套M2 | 53.68 / 51.50 | 60.08 / 50.81 |
| 再加配套M3（B+空间—频域gate） | **54.09 / 51.39** | **59.21 / 51.71** |

正向相对裸基础约+0.31 OA / +0.31 BA个百分点，三种子并非全赢；反向OA -0.87、BA +0.89个百分点。因此可保留局部净收益和类别取舍，但不能把配套重训说成已经全面解决问题。

更具体地：

- 正向最终修正主要提高散货召回，约+4.32个百分点，其余三类平均轻微退化。
- 反向普通货召回+5.16个百分点、散货-1.73个百分点，解释了OA下降而BA上升的汇总差异，不等于证明物理原因。
- 反向单独VV修正为61.45 / 52.22，源端选出的B融合为59.46 / 51.80，频域gate为59.21 / 51.71。存在有用修正，但当前极化组合没有完整保住它。这个目标域观察用于定位，不能事后改选VV并宣称源端选择成功。
- 频域动态选择本轮没有形成新增正收益：正向源选零步，反向比B固定更低。保留旧的局部有效结果，不扩大频域选择的主张。
- 反向M2三种子均在源端选零步。不是人为强迫模块生效；也不能直接把零步归因于训练饱和，本轮没有独立操纵这一因素。

旧M1→M2共12项源/目标重放误差为0；M3共24组输入核查确认base相关字段重算、固定图像描述不变、零步输出恒等。旧路径M3读出重拟合与历史M3优化顺序不同，未冒充全链精确重放。详见strong_base_refit/FINDINGS_ZH.md。

## 4. 原始chip是否支持这些解释

已实际查看4张压缩诊断组合图（16个案例位置、13个不同查询）及8张配套读出面板；VV/VH分开，保持原生尺度，参考式模型同时展示真实检索参考。

- OSS2查询2359：类别坐标误判为散货，完整区域及正交补都判对化学品。可见VV较弱、端部突出，VH更连续，但本轮不能把这些外观直接等同于某一隐向量。
- OSS2查询2597：类别坐标原本判对，正交补反而误判，说明不能简单删除类别响应通道。
- OSS2查询2296：主要由M2救回；M3反而略减正确优势。不能把最终正确都归给M3。
- OSS1查询0：M2未动，M3主要降低错误集装箱分数而救回散货，说明修正不只是增强真类分数。
- OSS1查询976：M3把真类普通货压得更多而误伤。救回与误伤发生位置可以确认，具体物理响应的因果身份尚不能确认。

图像显示不同类别共享短亮条、端部亮点等外观；这里只用原图约束解释，不凭肉眼命名船首尾、旁瓣或散射机制。详细案例在两个CASE_REVIEW_ZH.md中。案例不是总体比例。

## 5. 收口判断与下一步

**已有模块不整体推翻，旧收益保留；但不应继续让低维类别响应成为局部信息的唯一接口，也不应先加一个更复杂的最终门控。**

下一步最小且针对性的改动是：在区域身份保持的读出中保留原始区域特征通道，类别响应保留作辅助证据；用源端配套训练比较“完整信息+类别辅助”与“仅完整信息”。若新增部分没有净收益，就保留强简单读出，不为凑模块强留。

先解决区域信息接口，再判断M3比较度量是否需要配套重训。当前固定matcher在旧基础上学得，不能把读出重训不充分推广为整个匹配思路无效。不要根据目标域表格挑极化权重作为正式方案。

本轮没有新增24港/F_0921实验或独立采集折，没有发现纯因果因素，也没有证明新的正式模型超过所有强基线。完成的是一个可行动的诊断：**信息确实仍在，当前类别投影漏掉了一部分；保留信息后，还要针对性解决后续利用，而不是继续怀疑数据是否完全无解。**
