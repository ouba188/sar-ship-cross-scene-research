# 近分数匹配诊断（无训练）

2026-10-23。只读新旧划分已有 jointCE+J signed-only 与 score-only 的 source validation/test 预测；不拟合、不改选点、不改变任何父文件。主问题不是谁总分最高，而是 signed 独有判对是否在近似相同基础/校准分数下存在，以及这些描述性条件是否重复。

匹配向量为三维类中心化 A 加三维类中心化 score-only 输出；每划分/seed 用 source validation 的逐轴标准差统一尺度（不使用标签），测试沿用。只在相同 fold、真类、A top1、score-only top1 内，将“score-only 错且 signed 对”与“两者都错”一对一贪心最近匹配，不重复使用对照。标准化六维 RMS 距离固定 <=0.25；匹配不够不放宽。类别标签只用于事后分层，不进入模型。

source validation 为设计依据；test 只描述，不用它挑组。报告匹配覆盖率、距离、候选独对和校准独对、匹配正负两侧类别/港口/pass 组成。源重复条件预定义为同一 class/port 在每个划分至少 3 个独立 ID 获两个以上 seed 的独有判对，且至少两个 pass；同时报告两划分均满足与不能满足者。源匹配正侧需至少有样本在两划分出现，才标为分数匹配支持的重复条件；不以测试结果改变规则。

竞争类定义为排除真类后的最大分数类，分别计算 A->score-only、A->signed 的变更率，并同时报告 top1 变更；不把固定旧竞争类 margin 增加当最终正确。

重复划分/seed 不是独立数据复制；相同 class/port 也不是同物理条件。这是带标签的条件诊断，不是无混杂匹配、增量互信息估计或可部署 oracle。只生成小表和简短报告，复用已看原图说明必要例子，不追加图像提取/训练/超参数搜索。
