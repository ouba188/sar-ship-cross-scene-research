# 冻结校准 B 之外的常量矩对照

2026-10-23，完成。**new 的 OA 增量不要求逐图矩才能达到，但真实矩三个 seed 的 BA 都略高；old 的真实矩 OA/BA 均优于常量矩。** 保留这个条件边界，不宣称逐图矩一般必要，也不据此否定所有局部信息。36 条既定轨迹已全部完成，无追加搜索、无父文件修改、无 Git 操作。

## 协议与实际输入

- 同一三类队列：5695 targets、4312 MMSI、163 pass、15 port；bulk/fishing/general 分别3170/1147/1378。不是八类，也不是独立新数据；new/old 是同一开发队列的两个既有划分。
- 严格复用父 `run_increment.load_fold/ref` 和已有 source OOF/native moments。每折常量为 `oof[train].mean(axis=0)`，形状3x2，按**所有源训练样本平均、保留类别读出方向**，不按真实标签分组。每 seed 的冻结 C 沿用父对应 checkpoint，`B=C(A)` 原样保留。
- 训练、validation、test 的 sigma/kappa 描述量、其类中心化版本以及最终乘法载体 kappa 全部替换。唯一剩余的逐图输入是 B；不是“固定所有样本输出”，而是固定类别参照下的 B 条件函数。
- 架构仍为113参数 signed-only，零末层；共享标准化仅用该折源训练输入重算。名义容量相同，但信息量、输入分布和有效优化条件改变，不称严格同有效容量或纯因果消融。
- 两划分各6fold、seed17/29/43、200步、AdamW .003/.01，jointCE和父一致；每5步源val J=.5OA+.5BA，含epoch0，平局最早，无NLL打破平局。36选点全部保存后才统一评价test，未按test调参。
- 基础读出为源内OOF，**C本身不是OOF**；源残差监督不是整流水线样本外误差监督。源val先选C再选增量，有选模复用；本轮不能作为独立确认。

## 原窗与可解释范围

已实际查看new/old各8张VV/VH双栏面板，固定seed17，覆盖每臂救回/误伤/CC/WW；见 `RAW_REVIEW_ZH.md` 与 `new/old/review_cases.csv`。标题和正文均为 `B (frozen calibration)`，传入了明确subtitle，无A误标或文本遮挡。

new 0052448常量救回而真实仍错，0052252常量误伤而真实保住；old 0066654常量救回而真实仍错，0031578真实独有救回而常量/extra-score仍错。old 0056010真实误伤、常量保住。CC的0030906及WW的0031200/0031231也已回看。可见连续亮区、框外亮延伸、纹理和VV/VH差异，但这些外观不是模块用到该位置的证据，不命名物理机制。

本轮可保留的结论是：**固定类别矩+B门控足以在new产生相当OA增量；真实逐图矩在general类和old上保留条件性优势，但一般必要性尚未建立。** 不是“所有空间信息都无用”，也不是“图像细节机制已证实”。VV/VH提前合并是否丢失可用信息仍属主流程后续待诊断问题，本轮没有开展该诊断或新增head。
