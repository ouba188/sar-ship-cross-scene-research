# 背景参照读出：运行前协议

2026-10-22。承接 context_expansion_20261022，冻结5695个目标、六个采集包划分、MMSI隔离、原生双极化图像和A分类器选择。不是旧八类A+D主表。

## 数据依据和问题

扩大数据后，split_unit平均BA提高0.734个百分点，OA基本持平；固定/重训常量上下文不能复现。角色投影显著改善原特征重构，却没有改善分类。因此“真实邻域有信息”可保留，“保留更多区域方差就能涨点”不成立。已查看原图：0031576的目标与邻居具有较亮的共同背景，0052382等也显示邻域可能误导。图像现象不证明背景具有某种物理成因。

假设：邻域除了作为类别证据，也可能提供当前图像响应的参考水平；在保持旧读出器的情况下，有限度地调整目标特征的中心和尺度，可以改善跨采集判别。不是先把预测变化认定为噪声，也不宣称恢复物理散射量。

## 数据与算子

moments/从原始窗口的冻结R50 stem提取特征图一阶、二阶矩。排除所有同产品置信度>=0.25、像素有效的VV检测OBB及3像素膨胀区。VV/VH独立；C4平均仍是同一图像重复读出。原图不缩放、不遮挡；背景不是纯海面。

每个极化64通道。源训练目标背景建立参照mu0、var0。当前背景一阶、二阶矩为mu、second，var=max(second-mu^2,0)。逐通道正增益为sqrt(var0/max(var,0.01*var0))，限制到[0.25,4]；源方差<=1e-8的通道保持不变。候选读出 h_ref=mu0+gain*(h-mu)，同一变换用于mean和max池化特征。最终 h_new=h+alpha_group*(h_ref-h)。

每极化8组，每组8通道，共16个alpha，均位于[0,1]，mean/max共享。alpha从0开始，冻结原A；无邻域者精确退回A。背景只改变目标表示，不单独产生类别分数。线性A允许缓存16组对应的分数增量，但数学上仍是对目标特征的仿射调整；需与直接调用A(h_new)核对。

## 匹配四组

1. own_matched：自身窗口背景。
2. external：该目标合法邻居窗口背景的等权图像矩。重叠窗口不是独立像元样本，不声称为整片海面的无偏方差。
3. same_scene_replacement：同产品另一目标的外部背景参照；按ID循环选择第一个合法候选，任何供体窗口若与受体目标OBB包围框相交则拒绝。没有合法供体时保持原参照并明确记录。供体可重复，不称为随机置乱或双射。
4. constant_external：源训练目标外部背景矩的均值，检验全局特征调整能否解释效果。

四组统一只在双极化外部背景有效的1165个目标上激活；own_matched也不额外覆盖无邻域目标。分母、旧A、划分和训练机会一致。替代供体有部分邻居相同的情况要记录，不能把所有供体替换都说成信息完全不同。

## 训练与评价

沿用已冻结源验证选定的ridge alpha。训练用四个源分组包的基础OOF预测，并对每一包使用其余合法源船重拟合A、mu0/var0和constant_external；不能用外层已见该船标签的A构造训练增量。源验证与测试均使用外层训练A及参照。

16参数全批次Adam、学习率0.01、200步，每步投影到[0,1]，无权重衰减。类别/MMSI权重沿用旧协议；每5步以源验证类别平均NLL选择，包括0步。此过程确定性，不复制三个相同随机种子充当独立证据。

报告OA/BA/每类召回、救回误伤、逐采集收益、按过境与MMSI分别的块bootstrap，原图回看CC/WW/救回/误伤和真实邻居。模型选择只用源验证；本队列已经用于开发，结果定位为开发扩围而非未触碰确认。原A是浅层诊断基线，模块有效后仍需强主模型接入和新的采集验证，不能由此宣称顶刊成果已经完成。
