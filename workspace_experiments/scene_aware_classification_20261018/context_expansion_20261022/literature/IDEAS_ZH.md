## 1. 建议与证据起点

优先候选是**框外统计条件化的目标特征校正**：让外部环境规定目标证据的参考尺度，而不是直接提供邻船类别。第8节讨论不允许环境独立生成类别增量的受限候选，这是设计约束与研究比较，不是人类对全部方案的禁止。第3节含均值平移的仿射原型仍可作为允许加性中心的对照。备选是**ego 分离的邻居成对关系读出**：显式保留邻居之间的差异及其空间对应，检验现有逐边汇总丢失的关系。二者分别检验“环境如何改变读法”和“对象集合的组织是否提供新信息”，首轮不要合并。

这两个候选借用已有方法原则，尚无收益或首创性结论。不把不传播邻居标签等同于消除了场景类别偏差，也不把结构分支命名为已识别的物理因素。

已读本地依据：

## 2. 五篇 primary papers：实际读到的方法

以下是本次定向搜索中的最近方法组，不声称完成全领域优先权排查。文献卡是方法转述，非长篇原文复制；原始地址列在文末。

### P1. Hu et al., Relation Networks for Object Detection, CVPR 2018

读取 arXiv 作者PDF的解析文本，重点为§3的关系算子。关系权重是外观点积的指数乘非负几何权重后归一化；几何含相对中心偏移和宽高比的对数，经正余弦嵌入及ReLU投影。关系输出为变换后其他对象特征的加权和，多关系拼接后加回目标。未用PDF截图独立核对公式版面。

借鉴：对象外观与相对几何必须有匹配基线。区别：这是检测RoI关系，不是背景统计校正；单层仍是目标对其他对象的聚合。我们的普通attention只是相近基线，未精确复现其几何函数；不可称已经击败Hu原法。多层Hu网络可能间接表达高阶关系，候选2也不拥有一般性的表达能力独占权。

### P2. Zhu et al., Beyond Homophily in Graph Neural Networks: Current Limitations and Effective Designs, NeurIPS 2020

读取会议原PDF解析文本的问题设定与模型段落。H2GCN分开ego与邻居，分别度归一化聚合一跳和准确两跳邻域，再拼接不同跳数；最终拼接初始ego及各轮中间表征。聚合阶段去掉通常每层的非线性变换。其准确两跳按最短距离定义，不等于直接把含回返路径的A²当新邻居。未用PDF截图独立核对公式版面。

借鉴：保留自身与不同关系范围，不预设相邻同类。区别：本队列邻船类别未知，无法据此断言异配；现有独立A加残差已部分满足ego保留。候选2新增的是邻居对内容—几何关系，不是假称复现H2GCN，也不是它的准确两跳节点集合。

### P3. Ortiz et al., Local Context Normalization: Revisiting Local Normalization, CVPR 2020

读取作者PDF解析文本的方法段落。LCN逐样本在局部空间窗口与通道组内求均值/方差，再作中心化、尺度归一与可学习仿射。用输入及平方输入的积分图、膨胀卷积计算局部矩，计算量对窗口尺寸不敏感；统计不依赖batch。未用PDF截图独立核对公式版面。

借鉴：context可以是归一化的参照，而非分类票。区别：原法并不专门排除船体，也不是外部对象图；候选1改为检测掩码约束的框外参照，并保持冻结SAR读出。本文涉及遥感动机，但不是SAR船型跨采集结论；不能直接移植其成绩。

### P4. Chen et al., Few Shot Object Detection for SAR Images via Feature Enhancement and Dynamic Relationship Modeling, Remote Sensing 2022, 14(15), 3669

出版方网页直开返回429；通过出版方搜索索引读取§3方法正文，核到§3.4式(10)、图节点初始化及式(14)，§3.5推理段。RelationGCN用support与query RoI外观的余弦相似度构邻接；节点初值含query类别概率和support标签，图损失训练类别关系。另有support动态卷积及类间正交约束。正文明确推理用原分类概率，不参与GCN和类间约束。

区别：它不是推理时真实地理邻船的无标签图。可借鉴训练中关系约束，但本任务不能把未标注邻船换成有标签support。未读代码；§3.5文字称微调不用meta loss，式(17)仍含该项，保留为原文实现歧义，不自行替作者修正。该歧义不影响上述节点含义判断。

### P5. Wang et al., Feature Disentanglement Based on Dual-Mask-Guided Slot Attention for SAR ATR Across Backgrounds, Remote Sensing 2026, 18(1), 3

发表日2025-12-19、卷期2026。通过出版方及DOI索引实际读§2.1/2.3/2.5与§3.1方法段：先用直方图匹配、分割掩码引导slot自编码重建，再固定编码器训练分类；CAM选择目标slot，使用中心约9%区域先验。测试无需分割重建。实验含MSTAR、OpenSARShip及式(15)高斯背景替换。

借鉴：背景与目标可有不同计算职责。区别：候选1保留背景作为观测参照，不抛弃所有背景slot；不新增slot网络/掩码重建任务。中心先验、合成背景变化不能直接代表偏心、多亮响应、靠岸的实际chip。论文使用的因果措辞不作为本研究的因果证据。未审计其代码、全部划分与附录。

## 3. 候选1：框外统计条件化的目标特征校正（优先）

### 问题链与图像收益路径

0069192的01443邻居面板有大面积强亮结构；whole_raw受误导，whole_unit在seed29恢复，但其他种子并未全部解决。0044888/0046003显示区域读出可能有用，却不是正确几何/query独有收益。由此提出可检验假设：外部窗口的一部分作用是表征观测背景的中心与尺度；直接把它变成类别增量，可能误用为类别组成证据。范数约束只有整体幅值约束，没有逐通道中心/尺度参照。

这不是已证实的噪声机制。01443的框外可能属于不同环境，反而不适合作为目标参照；0047041的海面邻居也能误伤，故本候选不以“岸边全删”作解释。

### 输入、算子与完整接入

复用冻结骨干同层的原尺度特征，VV/VH分别统计，之后沿用现有融合顺序。对每个外部窗口，仅用OBB guard之外的有效空间位置计算通道一阶、二阶矩；若同窗另有已知检测框，也从统计区排除。它仍是框外特征，因感受野混合不能叫纯环境。窗口重叠像元按同产品坐标去重，不能让重叠次数决定参照强度。

记目标池化前特征为F_i，外部统计为mu_i、v_i；源训练对应框外统计的固定参照为mu_0、sigma_0。构造：

```text
T_i(F_i) = mu_0 + sigma_0 * (F_i - mu_i) / sqrt(v_i + epsilon)
h_ctx_i = original_pool_and_polarization_merge(T_i(F_i))
h_new_i = h_i + a * (h_ctx_i - h_i)
s_new_i = R(h_new_i)
```

`R`为该折冻结的完整A读出，包含原投影与分类器；a可先固定为一个共享强度，正式轻量版本用少量通道组强度（例如8组，范围[0,1]，零初始化）。这是特征坐标逐组变换，改变不同类别的竞争，不是对旧D logits再乘单一门控。背景不另接类别头；但中心化仍可能间接注入背景类别偏差，不宣称结构上排除了shortcut。

缺外部背景或区域无效时直接用h_i，不用中心化后的“零向量”冒充有效参照。均值/尺度参照、投影和训练监督严格源端；拟合a时使用源内留采集A及该内折参照，最终测试冻结外折A与外折源参照。不能以全源in-sample A替换旧合法OOF训练路线。梯度只进a，不进检测器/骨干/A。

旧regions.npz中的bg池化均值不足以恢复区域方差，**需要以后从冻结特征图补一、二阶矩**；不把对节点均值求方差混称为像元背景方差。这属于未来候选实现工作，本支线未执行。若新归一化使固定A不适配，先记为冻结读出条件下失败；区域专用PCA或重拟合A须另立匹配比较，不能同轮悄悄替换。

## 4. 候选2：ego分离的邻居成对关系读出（备选）

### 问题链与图像收益路径

0047041展示多个不同外观邻居，全部旧臂误伤；0082497也有不同方向的邻居，条件化和错配均能救回。面板只支持“集合内部有差异”，不证明这种差异是船型组织，更不证明误伤由均值化造成。可检验假设是：对象相互之间的形态差异怎样对应其排列，比单个邻居证据的汇总更有用。0069233只有一个邻居而whole_unit三种子救回，应保留其原有路径，不能为高阶故事牺牲它。

借P1的外观—相对几何表达，借P2的ego/不同关系范围分离。这里不做类别概率传播、不强迫相邻嵌入相似；H2GCN本身没有下面的三元关系算子，下面是本研究的待验证组合。

### 明确新增的计算

保留匹配的whole_unit作为基础s_whole，邻居节点z_j先用同一合法源投影。对目标i的无序邻居对j<k构造：

```text
d_jk = [abs(z_j - z_k), z_j * z_k]
t_ijk = [distance(j,k), abs(distance(i,j)-distance(i,k)),
         cos(angle(j-i,k-i)), cos(2*(axis_j-axis_k))]
p_i = mean_(j<k) psi(d_jk, t_ijk)
s_i = s_whole_i + 1[n_i>=2] * W_pair * p_i
```

距离用源端固定尺度，方位使用无向/交换不变表达；邻居对顺序交换不应改变结果。psi用小型共享非线性（例如内部16维），末层零初始化。目标自身证据经s_whole独立保留；没有邻居对时严格回到s_whole。用现有全局几何/原始中心坐标构造相对量，不能从已经丢失符号的摘要凭空重建角度，不输入绝对经纬度/港口ID。至多16邻居对应120对，计算O(n²)，报告实际参数及延迟。

这一结构把邻居对差异绑定到pair几何，产生共同邻居集合的交互，区别于现有conditional的逐边均值。仅加方差或`z_i-mean(z_j)`容易退化为统计扩展/线性重写，不作为此候选贡献；任意高容量DeepSets或多层关系网络可能逼近类似函数，不能宣称一般表达能力首创。

训练只用目标标签、合法源OOF基础分数；若冻结s_whole再拟合pair残差，必须为源训练生成whole_unit自己的OOF分数，不能只有A做OOF。现有输出不自动等于这种OOF缓存，所需小头重拟合应计入未来实现成本。本支线不生成它。

### 可证伪的最小实验

| 臂 | 所检验的差异 | 失败后的决定 |
|---|---|---|
| whole_unit + 成对内容—几何 | 集合交互能否补现有一阶读出 | 无可重复净收益则停止增加高阶模块 |
| whole_unit + 容量匹配的逐边psi、相同原始节点及几何 | 是否只是多了参数/非线性 | 相同则不主张邻居对必要 |
| 同一pair结构，保持节点与目标—邻居几何，错配pair内容与pair几何 | 是否真用成对对应关系 | 不降则改为集合差异建模，不能讲空间组织机制 |

为避免无效反证，n=2只有一个无序pair，pair内置换必然不改变结果；pair错配只在n>=3有多个非等价pair时有辨别力，其余单列“不可检验”，不得算作通过。若扩展后这样的目标仍太少，就只检验成对内容表示，不作几何贡献结论。无需预先恢复所有邻居身份或构建整景两跳图。

旧队列中仅21个多邻居目标、15个单邻居目标；21不是独立场景数，成对数量也不是新增样本量。这是旧实验的证据范围，不能据此判断扩展后监督仍不足。两候选均保留；新队列的有效背景、多邻居及n>=3覆盖待主代理实际提取结果决定，不重复开展扩展。

## 5. 与已有三种结构的实质差异

| 方法 | 环境/邻居进入哪里 | 保留的信息 | 当前可主张什么 |
|---|---|---|---|
| whole_unit | 归一化节点均值进入残差头 | 一阶袋表征 | 现有低成本BA候选 |
| split | fg/bg分别归一后均值进入残差头 | 分区差异 | 局部正例、整体未优于whole |
| conditional | 每条边表征乘query投影后均值 | 目标条件化的一阶交互 | 使用query，尚无明确样本净收益 |
| 候选1 | 框外矩进入目标特征中心/尺度变换，再用A读出 | 原目标证据的环境参照 | 待验证的观测条件化路径 |
| 候选2 | 邻居对内容差异与pair几何进入新增残差 | 对象集合内部的成对对应 | 待验证的集合交互路径 |

可发展的定位：在检测后SAR船型分类中，把场景信息的两种职责分开检验：作为目标读出的环境参照，或作为对象集合的关系证据；与普通邻居袋/条件化读出作信息及容量匹配比较，并用真实对应替换确定收益边界。贡献是否成立取决于完整分类收益和上述区分性实验，不能只靠模块命名、attention图或组间相关。

## 8. 主流程更新、受限候选与补充原文

### 8.1 新数据范围

主流程已像素核对恢复6134个双极化目标、4574个MMSI、163次过境、15港，仍为三类；后续最终进入训练5695条观测、4312个MMSI、1165个上下文目标，见扩围FINDINGS_ZH.md。旧198/36只承担历史机制与图像案例证据，不能继续作为新方案的样本规模结论。6134个目标不等于6134艘独立船，163次过境也不能直接当作互相独立的训练/验证/测试组。

### 8.2 候选1修订：只调制目标证据

受限候选采用“邻居不能独立生成类别增量”的设计约束，用来与允许加性中心的仿射背景参照作研究比较；这不是用户禁止其他方案。第3节T_i中的环境均值平移会产生加性项，不满足零目标增量条件，但仍是合法对照。以下受限版本保留“背景统计作为观测参照”的思想，删除环境到目标的加性平移及环境类别头。主流程的仿射背景参照试验允许加性中心，并未声称满足零目标条件；其结果须单独核验。

设h_0为源训练目标特征参照，q_i=h_i-h_0；环境一二阶矩只生成少量通道组的正尺度D(e_i)，类别读出R完全复用冻结A：

```text
h_mod_i = h_0 + D(e_i) * q_i
delta_i = R(h_mod_i) - R(h_i)
s_new_i = s_A_i + valid_i * delta_i
D(e_i) = 1 + bounded_group_scale(e_i)
```

D从恒等开始，幅度界与组数在源端固定。没有环境到类别的投影W_e，没有环境加性bias，不另训练类别方向。这里q=0时，不论环境怎样变化，delta严格为0；环境缺失时严格回A。实现可以让e包含框外均值、方差，但这些量只能产生尺度，不能把mu_i直接减进目标向量。VV/VH先按各自来源统计，源参照及a的OOF要求沿用第3节。

此约束只保证“无目标偏离证据就无环境增量”，不是物理无目标证明，也不排除环境通过目标中稳定存在的通道间接编码类别。要报告背景置换与上述q=0恒等验证。单一正标量若只是缩放所有类别同样的证据，可能不改变argmax；因此至少使用少量特征组，判断不同目标证据的可靠性，而不是只调全局温度。

与旧q*phi residual的差异应准确表述：旧代码query有bias且经过tanh，q为零并不保证query为零；末端W、bias可学习新的类别方向。新方案明确锚定源中心、强制零目标增量、正的低自由度特征尺度、冻结原A的判别方向。这是计算路径与可学习自由度的实质限制。**若R是线性的，展开后仍属于双线性交互的受约束子类，不宣称数学上与所有q*phi完全不同。** 可以用允许环境加性项的容量匹配版本作一个针对性对照；只有受限版本更有效或更少误伤，才支持“限制环境职责”这条机制。

### 8.3 候选2保留，但正式输出也只能调制目标

两个候选均保留。第4节的pair描述及几何错配反证保留；若测试“禁止邻居独立类别增量”的受限版本，则把原W_pair*p_i改成D_pair(p_i)的通道尺度，使用与8.2相同的冻结目标读出：

```text
delta_pair_i = R(h_0 + D_pair(p_i) * q_i) - R(h_i)
s_new_i = s_A_i + 1[n_i>=2] * delta_pair_i
```

这里单邻居回A。whole_unit独立作为匹配性能对照，**不能把它放进正式受限模型当基础**，否则旧whole_unit已经允许邻域独立类别增量，整体约束仍被绕过。若希望单邻居也利用环境，可单独比较候选1；首轮不自动合并两个候选。第4节的s_whole+W_pair*p_i只保留为不受限关系基线，不是正式候选实现。候选2因此检验“成对组织能否更好估计目标证据可靠性”，不是利用邻船类别投票。
