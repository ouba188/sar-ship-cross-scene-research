# 原生尺度区域特征读出

2026-10-22。已实际运行并查看原图面板。本目录仅负责冻结特征提取，没有训练、重跑基线或 Git 操作；所有新文件均在本 `readout/` 目录。

## 输入和顺序

读取 `../../context_relation_pilot_20261022/prepare_ports24.py` 及其 `ports24/targets.csv`、`neighbors.csv`、`features.npz` 的当前最终版，未使用任何 `pre_fix` 文件。固定 198 个目标、85 条边、36 个有上下文目标，162 个无上下文目标。85 条边对应 77 个不同读取窗口，重复窗口仅缓存计算，不合并边或删除样本。

每条边严格使用旧 `read_window=[left,top,width,height]`，从对应目标记录的 `raster_vv/raster_vh` 经 GDAL 读取相同窗口；没有重新根据中心或 side_m 取整。`targets.csv` 行顺序决定第一维，`neighbors.csv` 原始边顺序对应旧 mask 的有效槽位。运行中断言两种顺序和逐目标邻居数一致。

## 描述子和掩膜

复用旧 `Reader` 的 ImageNet R50 conv1/bn/relu、归一化、权重及 eval 模式，并关闭参数梯度。输入是既有整景 8-bit TIFF，VV/VH 分开进入网络，不是未经显示处理的物理后向散射。无图像缩放，无 CNN 前掩膜，也没有掩膜边缘输入网络造成的额外响应。

- `fg`：将 `source_points` 减去实际窗口左上角，复用旧 PIL 多边形栅格化方法得到 OBB 内像素。
- `bg`：OBB 栅格掩膜以 7×7 方形核向外扩张 3 个原生像素后取补集，即 Chebyshev 半径 3，不是欧氏圆盘。保护带不属于两种区域。
- 每次 0/90/180/270 度精确旋转同时旋转输入和掩膜。仅将掩膜用 `area` 重采样到 conv1 特征网格，得到权重 w。
- masked mean 为 `sum(z*w)/sum(w)`；masked max 为在 `w>0` 位置取最大响应，不乘 w。空分支直接输出 128 维零向量，无 NaN。
- 各旋转先完成均值/最大池化，再对四次结果平均。每个极化 128 维；最终固定顺序是 VV mean[64]、VV max[64]、VH mean[64]、VH max[64]，与旧 whole 相同。

**conv1 的 7×7 像素感受野会混合边界内容；区域池化不等于纯物理分离。** 尤其 area 权重的位置支持和最大池化的 `w>0` 规则不能保证每个被选特征的感受野都完全处于对应原始区域。前景不是已确认真船，背景也不保证只有水面或只有岸边。

## 文件接口

`regions.npz`：

| key | shape / 类型 | 含义 |
|---|---|---|
| fg, bg, whole | (198,16,256), float32 | 三种描述子；无节点槽位为零 |
| mask | (198,16), bool | 原 features.npz 的节点 mask，完全保留 |
| instance_ids | (198,), Unicode | targets.csv 原顺序，无需 pickle |
| fg_valid, bg_valid | (198,16), bool | 该节点该区域是否存在；无节点为 false |
| fg_empty, bg_empty | (198,16), bool | 有节点但区域为空；无节点为 false |
| edge_index | (198,16), int32 | neighbors.csv 的零基行号；无节点为 -1 |

区域有效标志与节点 mask 分开。使用方不能因区域为空偷偷删除旧节点。当前 85 条边前景/背景各 85 个有效，空分支各 0。`region_stats.csv` 逐边保留原行号、槽位、检测 ID、原文件路径、窗口、多边形、有效标志、像素面积、描述子范数/余弦相似度和重放误差，便于追溯。

## 检查结果

实际运行的 whole 对旧 `features.npz['neighbor']` 全数组最大绝对误差 **0.0**，逐元素完全相同。三种数组全部有限，所有无节点槽位严格为零。保存后重新打开缓存，核对数组、mask 与 instance_ids 完全相同。空权重池化返回零，以及全一权重池化等于常规 mean/max 的定向检查通过。这些检查针对空值传播、接口错位及 whole 算法漂移，不包含训练或预测结果验证。

脚本内部计时约 2.88 秒，整个 Python 命令约 9.21 秒，前者不含模块导入；不是端到端整景检测耗时。运行环境为既有 ClearSAR，没有新增依赖。完整机器可读结果在 `readout_checks.json`。
