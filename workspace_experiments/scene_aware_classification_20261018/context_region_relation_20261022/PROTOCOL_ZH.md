# 区域读出与目标条件化关系：冻结的小验证

2026-10-22，训练前记录。本轮复用198船/6采集/三分类开发队列、85条合法外部边、36个有上下文目标及旧源训练/验证划分。主A不变，不新增目标标签；不声称独立确认或原八类完整模型结果。

## 数据依据与可检验假设

上一轮实际原图显示0069192的邻居01443裁片含大面积岸边结构；删边可减弱错误渔船倾向，但不能完全恢复正确类别。普通海面邻域也误伤0047041，0069233与0044888仍有救回信号。问题不只是有没有上下文，而是候选对象及其周边信息混在一起、异常幅值可支配增量，且同样邻域对不同目标的作用未被建模。

H1：将候选OBB内部与周边分开读出，比同容量整窗读出更能利用外部证据。
H2：如果只是压住异常幅值，同结构整窗幅值约束即可获得相似收益；不能据此宣称分区创新。
H3：在相同分区及归一化下，目标条件化交互能优于邻居袋；目标换成源训练均值后若不变，则没有证明样本级目标条件化必要。
H4：若正确几何对应有价值，训练开始即错配几何的同结构模型应丢失部分收益。单邻居样本的错配无效，必须报告实际可置换边/目标数，不夸大辨识力。

## 输入与读出

使用旧冻结R50 stem、原像元尺度、同一VV/VH窗口、同一C4。从同一次特征图前向分别池化整窗、OBB内、OBB外膨胀3像素以外区域。区域掩码用于特征读出，不在输入制造黑边；代价是7像素卷积感受野仍混合边界，不能称纯船体/纯环境或物理因素分离。无有效区域保留状态，不随结果删除目标。检查整窗重放旧缓存。

源A训练的32维投影同时用于目标和各邻居区域。幅值对照将每个32维邻居向量按L2归一到范数sqrt(32)，不是按测试分布定阈值。整窗复制为两块、分区以框内/框外两块组成，均除sqrt(2)，最终均64维；三种袋对照参数完全相同。整窗复制不增加独立信息，不能当双骨干。

几何使用既有7项无向相对几何/置信度。所有方法共享15维几何均值、方差和数量摘要；标准化仅来自源训练。关系模块还读取逐边几何，统计仅来自源训练合法边。没有绝对港口、经纬度、邻船类别或船首真值输入。

## 固定实验臂

| 名称 | 内容 | 回答 |
|---|---|---|
| whole_raw | 同容量整窗邻居袋，无逐节点幅值约束 | 共同结构基线，旧C成绩另外保留 |
| whole_unit | 整窗袋+逐节点L2范数约束 | 单纯幅值处理能否解决异常主导 |
| split_unit | 框内/框外分区袋+相同约束 | 在幅值处理之外，分区是否额外有效 |
| attention | 同一分区，目标query/邻居key-value及几何logit的普通关系注意力 | 合理的关系方法对照，不声称完整复现Hu2018 |
| conditional | 目标投影与逐边内容-几何phi做低秩逐元素交互，再均值聚合 | 目标依赖的有符号类别增量 |
| conditional_constant | 同结构，但目标query换成源训练query均值 | 检查目标个体条件是否必要，不称完全相同有效自由度 |
| conditional_sham | 同conditional，逐目标将真实邻居与几何循环错配 | 检查正确内容-几何对应作用 |

attention与conditional的隐维32；末层零初始化，所有方法无邻居严格输出0。C/关系末端都保留几何摘要；不将邻居类别投票当分类依据。增量未强行限制为正，也不强迫目标特征接近邻居。

## 训练与评价

复用旧ridge alpha/源划分，先核对A预测重放；残差仍使用源训练内部按采集留出的A预测。每臂200步、相同优化器/源类船权重、每5步源验证NLL选步，含epoch0。3种子17/29/43，7臂x6折x3种子=126次头部训练；不根据目标成绩追加超参数或改半径。比较OA/BA/F1、源选步、逐采集净救回、上下文子集与极端误伤。

分别报告训练变化、完整读出收益、原图案例；使用同一批查询的三个种子不是三份独立数据。实际源验证有上下文样本少的限制继续保留；不把本轮阴性当所有关系不可行。若仅whole_unit有效，就保留幅值处理候选，不包装分区/注意力的贡献。

原图回看必须包括救回/误伤/持续正确/持续错误，以及上一轮01443岸边结构案例。逐边删除重算聚合；分区分支置零仅是依赖诊断，不能当物理因果干预。现有A+D不变，完成后归档正负结果并同步GitHub。
