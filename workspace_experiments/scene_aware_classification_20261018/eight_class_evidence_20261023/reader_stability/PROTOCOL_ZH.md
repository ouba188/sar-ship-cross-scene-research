# 源内判别证据稳定性诊断

只读取既有三外层/四内层模型和源held样本，不训练、不读取目标标签决定设计。
当前门控只看条件图像，不读取q本身。先检验其调节的同一原通道组，在合法源子读出和完整源读出之间的类别作用是否稳定。

对同一源held输入，精确分解
`q_inner-q_outer=(h-h_outer)*(W_inner-W_outer)+(h_outer-h_inner)*W_inner`。
分别记录分类方向变化和参考中心变化的RMS；两者可能相互抵消，不把RMS比值当加和解释比例。
用共同外层源标准差缩放权重后，比较每个组/类对的方向cosine；另记录真类对固定竞争类的组证据符号分歧，以共同幅度加权，避免微小值翻号主导。

完整源模型看过这些source-held标签，因此两者准确率差不能作为泛化收益。诊断只回答读出与参考变化是否足以让“只看图像条件的门控”存在信息缺口，不自动证明应该换结构或一定能涨点。若方向稳定则不增加判别证据输入；若变化明显，结合纠正PCA坐标后的实际结果再决定下一步。
