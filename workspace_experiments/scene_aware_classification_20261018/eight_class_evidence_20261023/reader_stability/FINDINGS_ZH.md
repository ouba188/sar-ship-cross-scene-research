# 源内判别证据变化：有变化，但不是单纯中心漂移

无新训练，完成12个源内/外层读出比较，13229个source held事件、7934个唯一观测。outer模型已经训练过这些标签，故准确率差不作为泛化收益，也没有用测试标签挑模块。

同一输入上的组证据差可以精确分成分类方向变化项与参考中心变化项，重构误差最大2.95e-15。各inner组证据差RMS .03187-.04441，方向项 .03171-.04419，中心项 .00184-.00401；两项RMS不可直接加成解释比例。主要可见变化来自W方向而非h0。共同源标准差单位下，各原通道组/类对方向cosine均值.7649、中位.7763、P05 .6056。并非完全相反，也不是完全固定。

相同真类/固定竞争类下，组证据符号分歧的幅度加权比例平均8.21%。它不是错误率，也不证明门控必然需要更多输入；当前门控看到相同条件时不能显式区分不同W的证据状态，但已有类方向语义也提供一定稳定性。暂不仅凭这些数字开发新网络，结合PCA坐标修正后的八类结果判断。

## 四个源图对照已查看

按ID固定选source held与outer in-sample的两次都对、两次都错以及两种翻转；不是独立测试的救回/误伤。VV/VH按实际160裁补显示，不插值，缺失有效性保留。

- pair_0001226渔船：仅VV参与模型，主体是小亮点；两读出都正确，幅度加权符号分歧3.84%。不能从显示VH也有亮点推翻已有无效标记。
- pair_0000019散货：两极化有细长亮主体，VV可见横向延伸亮纹；两者均错，但held判拖轮、outer判集装箱，符号分歧40.77%。相同图像可以对应不同错误竞争类，不能简单说背景变化导致本例变化。
- pair_0000079散货：VV背景明显亮于VH，主体均短而紧凑；held判原油轮、outer判散货，分歧29.76%。outer看过该标签，因此不计为方法救回。
- pair_0000002散货：双极化均有细长斜向亮主体；held正确、outer误为原油轮，分歧15.13%。更多训练数据也不保证每个源样本决策改善，案例不是总体比例。

这些图像和严格同输入对照把变化定位在读出及训练组成，而不是图像被替换。但没有证明哪种图像物理结构决定方向不稳定。后续可检验的假设是条件门控是否应读取当前类别证据关系；本轮只建立数据依据，不宣称该设计已经有效或原创。
