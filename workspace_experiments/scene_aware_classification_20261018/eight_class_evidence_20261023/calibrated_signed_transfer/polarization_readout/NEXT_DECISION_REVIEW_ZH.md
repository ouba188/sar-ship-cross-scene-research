# 下一步决策：先区分本图证据与校准

2026-10-23。只读建议，不启动实验。结论：**校准是已得到直接支持的重要收益来源；逐图分路矩仍有可保留的类别竞争证据，但其校准之外的样本特异效用尚未被充分分离。下一轮最值得做一次固定头、分数条件匹配的整组矩置换，不再更换小头。** 这不是认定全部增量仅是校准，也不是因区间跨0否定方向。

## 哪些证据仍成立

| 假设 | 当前判断与直接证据 |
|---|---|
| 普通分数校准能贡献大量收益 | **保留，优先级最高。** 旧A+D接入score_only净+332/+340/+304，free_real为+62/+79/+54；OA优势不是局部矩独有。但score_only的BA下降更多，不能称其全面优于矩读出。 |
| 分路矩可以改变具体类别竞争 | **保留为已观察事实。** 226参数real支原油轮净+7/+6/+8；救回2959同时增强真类、相对压低chemical竞争；误伤5990则把bulk提高得更多。不是统一降低响应，也不是只看真类增量就能解释。 |
| 本图矩在相近基础分数下仍提供有用区别 | **保留为最值得验证的假设，不写成已证明。** free真实路相对constant三seed BA都略高，但OA为−4/+1/+10净差，constant复制了大部分平均OA。现有训练替换同时改变输入变化范围、优化及选点，尚未单独识别“本图对应”的效用。 |
| 分路普遍优于提前聚合、特殊κ载体必需 | **降级。** 普通free已能获得收益；其真实路对aggregate在校准B上净+20/+1/+12，但BA两seed较低；旧A+D上变为+22/+29/−23，BA差+.0218/−.1882/−.4659pp。不是处处必须赢，而是目前无法给出稳定的适用条件。 |
| 同类亮条/背景差异已经揭示物理机制 | **不成立为现阶段论证。** 已查看crude_rescued/harmed/CC/WW四图；连续长条出现在正负结局，强条状延伸也只有单例。深层RF混合、原窗/显示差异与类别竞争同时存在，不能据此命名散射机制或制定去背景规则。 |

原油轮是事后因正收益而选出的类：26个不同救回对象中23个只在一个seed救回，3个在两个seed救回，没有三seed都救回的对象；源val该类净+1/+1/0。这支持“类别层面有正路径”，不支持“已找到能复现的逐船条件”，也不能把226头病例当作209 free机制的直接证明。

读取的是full_model_integration最新pooled及paired_metrics，不是把新支B结果搬到旧系统。各seed同4744对象：

score_only有280参数、跨8维分数读出，free为209参数逐类共享映射；这不是同容量信息对照，更不能证明矩已被校准完全吸收。反过来，free比score_only少损失约.715/.831/1.289pp BA，也不是额外样本信息的充分证据，可能含函数限制造成的取舍。下一次若做训练型系统增量，必须明确以已校准旧A+D为固定起点，而不是继续对未校准旧分数报增益；本轮建议不立即再训一组头。

范围仍是协议中的冻结旧A+D，不含全部历史目标支持适配；旧支3包OOF与新矩4包OOF各自身份隔离，组合不是全链过境OOF。不能称历史最终系统或独立新数据确认。

## 唯一建议实验：分数条件匹配的矩置换

**问题：基础分数和可用观测相近时，冻结读出用“本图矩”是否优于用“另一对象的整组矩”？** 主检验锁定现有已校准B上的free_shared九个头，全部复用，不按test选择头、类或seed。它比再做常量训练多隔离一件事：保持头/scaler/边际矩分布，仅破坏逐图对应。

1. 先在各fold source validation内，按相同valid模式，以源train尺度标准化的完整中心化B向量作距离，不用真类、正确性或救回标签。求无自身/无同MMSI的最小代价一一置换；整块搬运[pol,class,moment]，不拆σ/κ、不交换类轴、不打散VV/VH。该集合内均为同一outer reader，避免inner/outer方向及尺度混用。
2. 固定B、flags、head、scaler，仅重算替换矩生成的完整descriptor。一一置换保持该集合联合矩经验分布；与常量化不同，不把局部输入压成低变化量。预先锁定一种匹配规则，不调距离/分组直到出现正结果；报告匹配距离与可匹配覆盖，不足就明确这一检验未识别，而非放宽后挑结果。
3. 主要看source上本图−置换的J、OA/BA、NLL和类别竞争margin，并单列冻结B的原正确/原错误组，记录救回与新增误伤。不能只看输出改变了多少。锁定后test用同fold、同role内无标签置换作描述性复核，禁止跨train/val/test混配；test协变量仅用于诊断，不构造部署方法。两种块区间都保留，sourceval已参与选头的乐观性也需注明。
4. 回看少量本图与实际donor原窗，而不是再画孤立热图。若本图稳定更有利且不是少数港/重复MMSI驱动，可支持“固定读出确实利用了分数条件下的逐图关联”；若输出变化大而效用不升，则是使用了信息但未证明有用；若相近，只能说当前矩/当前读出未给出这项证据，不能推出原始双极化图像无增量。

这是条件匹配干预而非严格因果/条件独立性证明：近似匹配仍可能留下分数差异，置换也可能破坏未控制的观测条件。它不证明几何排列创新，更不解决旧A+D校准后的最终增量问题。选择它的理由是当前最小缺口为“逐图关联是否有用”，而不是缺一种更复杂的非线性。

## 创新边界与停止线

沿用literature_comparison已读方法记录：CPINet已有跨极化引导、二阶/双线性与带符号局部读出；轻量双极化融合研究已有普通拼接/求和比较。本次没有重新检索或声称重读原论文。**不能把双极化、σ/κ、乘法门控或分路融合单独包装成新机制。** 可发展的是冻结类别坐标下，遗漏证据的可利用条件及相对强校准的实证解释。

目前不足以据此设计新空间模块或继续改小头。最小需要补的是上述“相近分数、不同本图矩”的效用证据；若现有样本缺乏匹配覆盖，最小新信息应是补足相同预测竞争关系下、跨独立采集的不同船观测，而不是事后增加原油轮标签规则。若覆盖充分仍无效，应保留校准与类别tradeoff成果，停止在这组压缩矩上继续调头；不能无证据跳到“更强注意力会有效”。本建议不要求处处赢或以显著性作单一门槛，也不启动任何训练。
