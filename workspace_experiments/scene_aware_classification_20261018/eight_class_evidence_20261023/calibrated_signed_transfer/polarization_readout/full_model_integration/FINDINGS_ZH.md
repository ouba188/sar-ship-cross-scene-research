# 旧 A+D 上直接接入极化读出：结果与边界

2026-10-23。27条轨迹、全部统计及12张原图实际回看已完成。未另训C、未重新提图、未修改父checkpoint、未Git、未追加实验臂。

## 结论先行

**free_real在固定旧A+D、既有4744条测试观测上的OA收益成立：三seed净增62/79/54，OA分别+1.307/+1.665/+1.138个百分点。** 不因BA小降把它写成无效；也不能写成全面胜出。其BA分别-0.428/-0.194/-0.376个百分点，收益与损失落在不同类别。

相对同参数、同初始化aggregate，real净差+22/+29/-23；尚未显示跨seed稳定的分路优势。score-only直接分数残差的OA收益更大（+332/+340/+304），但BA下降也更大。本轮支持保留real的明确范围OA收益和相对较小的BA代价，不支持“必须保留极化才能获得增益”，也不支持其胜过所有普通校准读出。

源验证为915次折暴露、816个唯一instance；模型选择始终在各自折上完成。以下是事后汇总，不用于重新选择：

可证实的是：real的OA增加由散货、油化和普通货船贡献，集装箱及若干小类的召回损失解释了BA小降；score的大幅OA提升主要来自油化和散货，同时更明显伤害集装箱、原油轮、拖船、海工。这是实际类别构成和判决变化，不是只用总OA/BA猜原因。

源码/训练组织上，旧上游使用类/身份加权拟合与原残差目标；本轮按约定用jointCE和J，不是BA不下降约束。J允许OA与BA取舍，源val上score也已显示这个方向，因此不能说是test才出现的隐藏错误。旧源OOF与最终全源模型仍有训练样本量、选零步D等差异；本轮未将其与跨日期/采集变化因果分离，不把剩余差异全归为OOF问题或物理极化机制。

测试有效VH=4436、缺VH=308。real在有效VH组净+66/+77/+55，在缺VH组-4/+2/-1；aggregate对应+42/+49/+78和-2/+1/-1。不能从不同样本组的相关结果直接推断“VH带来这些净收益”。源val缺VH82次暴露，分层全表见 `vh_metrics.csv`。

18个实际测试港的结果全部保留。real净增主要集中在Richards Bay(+27/+22/+19)、Jebel Ali(+14/+23/+12)、Santos(+6/+12/+13)；Mombasa为-2/-1/-2，Fujairah为+3/-1/-3。港口不是本轮输入，不能将分层关联解释为港口模块效应。各fold/港/过境完整结果见 `fold_metrics.csv`、`port_metrics.csv`、`stratified_metrics.csv`。
