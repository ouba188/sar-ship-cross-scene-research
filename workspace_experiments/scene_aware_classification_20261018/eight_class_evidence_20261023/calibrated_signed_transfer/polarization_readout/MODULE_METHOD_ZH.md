# 可保留候选：校准分离的类别局部分布读出

2026-10-23。工作名，不宣称首创或已经达到顶刊标准。对应 `strong_calibration_increment` 的local实现，不是另设计但未运行的网络。

## 为什么这样组织

现有证据揭示两个不同问题：旧类别分数有可通过普通校准改善的竞争关系；原图局部响应在基线分数相近时仍可能提供额外信息。让一个小头同时承担两者，会把普通校准收益误算为局部机制收益。

因此把它们分开：先冻结已有整图和邻域分类 `S=A+D`，用普通源监督分数校准得到 `B=T(S)`；再从图像中读出局部分布，学习对B的补充。T是标准组件，新增价值应落在最后一步相对强B的效用上。

## 已实现的详细流程

1. **原始输入。** VV/VH分开，按既有记录160 crop/pad，不把大船缩小或小船放大；无效极化不参与该路统计。footprint区分真实图像与补零，但不把深层感受野截断成纯船体/背景。模型保留原native来源；当前原PNG已经包含其历史显示处理，不冒称物理标定后RCS。
2. **局部特征。** 冻结R50到layer3，分别计算四个90度旋转视图。每个视图得到每位置向量 `F_p(u)`。这里是原图坐标的内容特征，不额外输入船轴、港口名称或雷达方向。
3. **投到辅助类别方向。** 用仅源数据拟合的辅助读出器 `W_{p,c}`，得到 `a_{p,c}(u)=W_{p,c}^T F_p(u)`。W的8类方向与任务一致，但不是旧非线性A+D的精确分解。源训练使用各自inner-held读出器，目标使用outer读出器。
4. **去掉平均与所有类共享变化。** 归一化footprint权重为 `w(u)`；先计算 `v_c(u)=a_c(u)-sum_u w(u)a_c(u)`，再计算 `r_c(u)=v_c(u)-mean_c v_c(u)`，最后再按w去一次空间均值。这保留的是某类别相对于其他类别的局部波动，不是直接把整张chip的亮度当类别证据。
5. **读出分布形状。** 对每路每类计算 `sigma_c=sqrt(sum_u w(u)r_c(u)^2)` 与 `kappa_c=sum_u w(u)r_c(u)|r_c(u)| / max(sigma_c,1e-12)`。sigma描述相对响应起伏程度；kappa描述较强正/负偏离的倾向，**不是标准三阶偏度，也不是“正确性”**。较大或正的kappa不一定有利，需结合当前类别竞争。四视图各自统计后平均，不先平均特征图。
6. **与强分类分数共同读出。** 每类输入11维：中心化B分数1维；VV/VH各有sigma、其类中心化值、kappa、其类中心化值，共8维；加2个有效标记。所有类别共享 `11 -> 16 GELU -> 1` 的209参数小网络，产生逐类增量；最后去掉增量的类公共项。没有再乘kappa载体，也没有把这个MLP叫成已证实的空间注意力。
7. **最终分类。** `s_final = B + delta(B, sigma_VV, kappa_VV, sigma_VH, kappa_VH, valid)`，取八类最大分数。没有测试标签路由、没有按目标真类选方向，没有额外5%交接。本轮是源分类器开发，不含全部历史64支持适配。

## 实际结果与例子

在相同4744测试观测上，local相对冻结强B的三seed净数为+26/+41/+11；OA增加+.548/+.864/+.232pp，BA增加+.627/+1.232/+.546pp。再加一个仅看分数的小头为+11/-8/+29，局部臂相对它的BA三seed都更高，OA两高一低。源验证local相对B的OA/BA也均正。完整置信区间与类别边界见该实验最终报告，不将重复seed视为独立数据。

- 普通货船5030：VV是较宽斜向亮主体并有纵向亮延伸，VH主要表现为分开的两个亮区。强B判为散货，新增读出主要抬高普通货船分数，使真类margin从-.15439到+.06857。图像证明两路响应形态不同，实际分数证明救回；尚不能由此断言“两个亮区就是普通货船的物理标志”。
- 散货returned_20260915_0001367：VV长亮块、VH沿长轴亮暗不均；增量也提高真类，但原油轮提高更多，margin从+.05253变-.33509，造成误伤。不能把“更重视局部”默认当正确行为。
- 3494保持正确，margin2.35965到2.52181；3504仍错但margin从-.64017改善到-.55098。后者体现连续证据改善未跨越决策边界，不写成救回。

以上四例VV/VH原图与模型实际输入均已由主代理实际查看。它们不是全体类别比例，也不支持把旁瓣、尾迹、船首或船尾作为已识别机制。

## 这个候选的创新应放在哪里

不是首次双极化、二阶统计、残差连接或MLP；CPINet等已存在相关方法。可发展的新增点是：在明确隔离普通分数校准之后，以辅助类别坐标组织局部分布，将其转为有可核对类别竞争作用的增量，并验证它在跨采集任务上的范围效用。

同辅助W的普通GAP均值对照现已完成。mean-only相对B净+77/+50/+84，OA+1.623/+1.054/+1.771pp，BA-.199/-.318/+.403pp；local相对mean的BA+.825/+1.550/+.143pp，但OA-1.075/-.190/-1.539pp。两者都有价值，不能再主张局部分布全面优于均值，也不因均值OA更高而撤销local的类别均衡收益。mean的chemical获益与offshore代价在源验证已出现；local相对较能保留offshore和crude。详见mean_only_control/FINDINGS_ZH.md。

源验证已有两种读出各自独对的对象，但错误互补不等于已经学会无标签选择。下一步先查看源端分歧原图及实际均值/局部读出，再检验共同利用是否可学习，保留合理联合读出作为对照。当前统计没有保留完整位置排列，不能称为新几何卷积或因果池化。5030同时被mean和local救回，故撤去把此例作为局部分布独有信息证据的任何暗示；它仍是有效的实际判决例子。

训练/选择边界：源损失为普通CE与类均衡CE各半，源验证J为OA与BA各半；T不是全栈OOF，源验证和开发队列多次使用。后续需要固定候选后的更广采集覆盖；不要求每港每类全胜，也不把已有收益撤销。
