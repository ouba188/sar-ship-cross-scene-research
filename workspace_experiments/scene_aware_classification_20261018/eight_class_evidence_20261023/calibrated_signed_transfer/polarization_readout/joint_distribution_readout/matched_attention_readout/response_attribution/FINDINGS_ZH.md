# 真实双向 attention 的固定响应归因

## 结论

真实 attention checkpoint 的 seed17 四个预定 test 案例已完成原窗重提、h/b与完整分数重放、响应层IG闭合、小干预和原图视查，无新拟合、无案例或模型重选。**这些例子显示本图响应确实参与分差，但5030的救回主要由mean分支完成；7310的响应加重误判而非唯一根因。** 不以四个案例证明总体收益来源。

64点中点积分全部通过事先设定的容差 `1e-5+1e-4*abs(M1-M0)`，最大闭合误差2.40e-6；无需128点。缓存h/b最大重放误差7.86e-6，完整分数最大误差2.26e-6，缓存输入descriptor误差0。四例均有效双极化、均非epoch0。实际用了fold0/epoch75与fold1/epoch55的attention头，不是旧分布头。

## 固定路径与分差

每极化、每C4独立计算 `a±=softmax(log(w)±r/tau)`，`q±=sum(a±*r)`，`h=(q+-q-)/2`，`b=(q++q-)/2`，随后C4平均。沿 `r(t)=t*r` 固定B、mu、valid、outer W、checkpoint内tau和源scaler。这里h/b随t的变化是非线性的，实际重算softmax，并非把缓存h/b简单乘t。

分差M为真类减真实attention最终最高非真类，整个积分和干预均固定该竞争类。M0是同head的r=0输出，**不是B，也不是attention分支整体删除**。h/b=0经scaler后不保证零输入，已训练头也不保证零残差。

- **7310：** 零响应时已错，真实响应再减0.038069；VV负贡献大于VH正贡献，属于加重而非唯一误判原因。

- **3504：** 本图响应相对零响应增加0.016143，仍然判错，完整分差也仍差于B。局部正贡献不等于实际救回或相对B获益。

## 固定响应层干预

对每极化单独操作，另极化保持原样；各C4按 `abs(sum_class IG)` 排序，选择 `ceil(0.2*n_valid)` 个高格，低组在不重叠条件下优先匹配pool权重层并取最低绝对IG。选中格所有8类响应先置0，再在整个有效支持内减去加权空间均值。**重中心化改变未选格，选中格最终也不一定为0**；这是响应空间的置零后投影，不是像素遮挡，更不是严格局部删除。

5030的VH高组干预影响明显大于低组，但5030的VV并不遵从“高组必有更大效果”。IG是径向积分贡献，不能推出另一条有限干预路径的效果一定同号或大小排序相同。其余分差变化保留，不据此挑选极化、格数或新模型。

配对边界必须保留：

- 64x64的三个案例每view有16有效格，取4格，实际为25%；7310每view有36有效格，取8格，实际为22.22%，不是精确20%面积。
- 32个case/pol/view配对中29个pool权重多重集一致；7310的VV旋转2、VH旋转0和2不一致，最大质量差0.037037，即3.70个百分点。详细选中索引、质量与差值在 `intervention_support.csv`。因此 `matched_weight_multisets=false`，不能声称全部严格面积匹配。
- 即便权重质量匹配，响应变化范数也不匹配；`interventions.csv`记录实际weighted response L2。不得声称严格匹配区域、干预强度或独立局部因果效应。此小检查只支持固定响应层可达作用，不承担总体机制检验。
