# 条件信息贡献诊断的文献边界

1. Strobl 等，Conditional variable importance for random forests (2008)，DOI: 10.1186/1471-2105-9-307。正文2.4区分打断X与Y及其他Z的关联和仅条件于Z考察X与Y的关系；2.5用每棵树已有切分点构建条件网格，在网格内置换并评价OOB准确率差。模拟结果显示条件方案减少相关变量的重要性高估，但并未完全消除。本轮分数相近匹配借鉴其问题定义，不等同于树网格算法。
2. Debeer 与 Strobl，Conditional permutation importance revisited (2020)，DOI: 10.1186/s12859-020-03622-2。拟核查边际与条件贡献的定义和对已拟合预测器的解释边界。作者、卷页及正文细节在本轮尚未完成核查，不复制到正式参考文献。

对我们的启发：旧分类分数已经包含大量类别信息，因此要问的是“在旧分数相近时，本图新增矩是否仍有作用”。保持同一模型、同一查询分数，换入另一个不同船但分数接近的整组局部矩，比简单全局打乱更贴近这个问题。

边界：当前一对一最近距离配对并非上述论文算法，也不是从真实条件分布抽样；相同预测类别并不代表类别、几何和图像条件被完全控制。不能套用文献的统计性质或因果解释。正结果最多支持当前模型依赖本图对应而获得条件性预测效用；负结果也不证明原始SAR局部信息不存在。检验本身是借鉴既有解释方法，不应再包装为一个创新网络模块。
