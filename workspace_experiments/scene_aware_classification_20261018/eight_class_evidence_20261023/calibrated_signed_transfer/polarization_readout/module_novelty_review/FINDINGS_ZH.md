# 当前真实模块的Novelty梳理

2026-10-23。仅方法与证据梳理，不新增网络、训练或Git。**可以保留的贡献候选是：将普通分数校准与辅助类别读出分开，识别SAR均值证据和局部分布证据对类别竞争的不同作用，并以同输入对照限定实际增量。不能再主张局部分布全面优于普通均值，更不必因基础算子已有先例而否定这条研究路线。**

本轮已实际读CSRA方法第3.1–3.4节、GSoP第3.1–3.4节及相关训练设置；CSRA核实为ICCV 2021，不是CVPR，也不是仅arXiv预印本。CPINet/2026双极化论文复用既有核心方法笔记，未假称重新精读。来源、页码和访问限制见`READING_RECORD_ZH.md`，以下[R1]–[R4]对应其中记录。

## 1. 先确定比较的是哪个方法

当前系统以S=oldA+D为冻结起点，先训练普通源监督分数校准T，冻结B=T(S)。辅助源监督ridge在冻结R50 layer3上给出八类方向W；每极化、每C4分别计算局部a_c(u)=W_c^T F(u)。它不是旧非线性A+D的精确分解，不是按目标真类挑选W。

local在有效footprint上去空间均值、去类公共项，得到r_c；保存sigma=sqrt(E_w[r_c²])及kappa=E_w[r_c|r_c|]/max(sigma,eps)，再平均C4统计。两路各sigma/类中心化sigma/kappa/类中心化kappa，加中心化B和valid，构成11维类共享输入；209参数11→16 GELU→1输出直接残差，最后去类公共项。**它不乘kappa、没有tanh cap，也不生成逐位置attention权重。** 不能把历史226头的乘法贡献图直接当成当前非线性209头的精确空间分解。

新mean-only以同W、同OOF、同极化/footprint/C4的响应均值，重复填入两组统计槽，其余结构和初始化相同。均值是加权GAP的类别投影，不含reader截距；它不是完整oldAD，也不等同强B。重复槽不新增信息，名义209参数相同而有效输入维数/优化条件不同。

最新joint_distribution_readout已完成18头：joint将均值与分布合为15维、15→16→1，共273参数；additive将相同信息分别送入mean7→12→1与local11→12→1后相加，共266参数。两路各含B和valid，输出仍去类公共项再加同一强B。两臂同信息、近容量而非同参数化；联合MLP、GELU、分路相加都不是本轮原创。下文209头用于说明单独信息对照，当前收口候选以最新additive结果为准。

## 2. 最接近方法的真实差异

### CSRA：已经把类别方向、局部响应与GAP残差连起来

[R1]单头直接使用分类权重m_c，对每位置t_c(u)=m_c^T x_u计算softmax(T*t_c(u))，得到类别专属加权聚合，再与GAP相加。其分数为`mean_u(t_c)+lambda*sum_u softmax(T*t_c)*t_c`。T乘在响应上，T趋于无穷为max分支；原文既有无需再训练的插件，也有端到端BCE训练及不同分类W的多head版本。

所以“类别方向组织空间响应”“在GAP之外增加局部证据”“保持原路径的残差”都不能单独作为本项目原创。我们的具体变化是：辅助W与主B解耦；不按响应值给位置softmax，而是先去均值、统计带符号/无符号波动，再由同一共享函数结合当前类别分数决定增减。CSRA的注意力聚合与我们的分布摘要不是同一个算子；但这只是可解释的方法差异，是否更有效仍由对照决定，不能把CSRA写成已被我们击败的baseline。

CSRA仍是当前重要的思想近邻，而不是因为其主要做多标签就与本项目无关；论文也展示了单标签ImageNet的测试时用法。我们的核心任务则是单标签、类别不均衡、身份隔离的SAR跨采集开发。

### GSoP：二阶统计并非空白，但统计坐标和作用位置不同

[R2]对特征通道或位置计算全图协方差，以逐行归一化/卷积等映射生成缩放权重，作用于中间特征；网络端可接GAP或矩阵归一化协方差。它不是以任务类别作为固定统计轴，也没有把一个既有校准分类器单独冻结成参照。该差异不意味着它不能解决本任务，只说明本文不能以“首次利用二阶信息/通道关系”立论。

更准确地看我们的sigma：每极化/每C4令u_c=W_c-mean_class(W)，C_w为F的加权协方差，则在精确算术下`r_c(u)=u_c^T(F(u)-E_w F)`，`sigma_c²=u_c^T C_w u_c`。**这是监督类别方向上的协方差二次型，不是新的二阶统计原理**；与完整协方差相比，只保留少量任务相关方向，未保留所有交叉协方差。C4最后平均的是各视图sigma/kappa，不能改写成先平均图再算同一协方差。

kappa是归一化带符号二次矩，不是三阶偏度：反转r时sigma不变、kappa变号，且|kappa|≤sigma。它补充正负波动的不对称，但没有原文检索依据支持“首次提出此统计量”；当前也没有在强B及同均值条件下证明它单独必要。把这两项视为可压缩的类别证据描述符，比宣称新统计学量更准确。

### 两篇SAR近邻：必须正面承认简单融合和高阶交互

[R3]CPINet已用GAP与分组双线性统计做跨极化通道调制，并用对应位置的低秩双线性交互、带符号非线性与池化。我们不能占据“双极化+一二阶+符号”的宽泛概念。当前方法不要求VV/VH逐像元对应后相乘，而是在各自footprint内得到同一类别轴的摘要后融合；这适合现有两路窗口/有效性不完全相同的输入，但不恢复相干散射矩阵，也未证明任何跨极化空间配准机制。[R3的细节来自既有阅读记录]

[R4]2026双极化方法用两个MobileViTv2分支的GAP向量拼接分类，并比较简单融合方式。mean-only新结果说明这类第一阶读出思想在本任务也确实有竞争力；不能把它贬为“只有均值、天然不够”。我们的差异不在多了一次concat，而在源监督辅助类别坐标、独立强校准参照、有效极化/源OOF组织，以及对均值与分布各自类别作用的拆分。[R4的细节来自既有阅读记录]

## 4. 可保留的新增贡献与必须降级的说法

**可形成有意义的推进：**不是发明一个新的attention，而是把“同一图像中均值类证据与响应分布证据，在已有强分类与校准之后如何影响类别竞争”变成明确、可检查的问题。具体实现将W作为所有极化共享语义的辅助坐标，分别读出响应分布而非对不完全对应的像素强行交互；强B、mean-only和固定头交换使普通校准、额外均值读出、样本对应三种解释开始可分。当前结果已形成实际增量与类别条件边界，研究价值不只是一张热图。

**应承认继承的部分：**类别响应图与残差继承CSRA等思想；二阶统计、GAP/高阶混合和双极化融合已有充分先例；C4平均、mask加权池化、零初始化残差、类共享MLP、GELU联合映射、两个残差分支相加与源验证选点也不是本轮首创。联合CE/J解决的是本任务目标一致性，不是新损失理论。源OOF是监督组织，不能包装为新网络。

**必须降级：**“首次类别局部分布”“首次符号极化”“局部分布全面优于GAP”“特殊kappa carrier必需”“纯粹消除校准后的信息增益”“新空间排列/几何建模”均没有当前证据。分布统计对加性空间常量不敏感，但209头仍读取B，故sigma/kappa为0也不保证整个残差为0；“校准分离”是实验参照与建模组织，不是强制正交分解。类别公共响应去除在某些onehot+intercept ridge条件下还可能冗余，不能单列为关键创新。

**边界不抹掉成果：**strongB后的local已三seed OA/BA同正，mean提供了更强OA路径，二者不是二选一否定。与此同时，centered交换发生于oldAD上的冻结free_real，不是strongB上给定均值后的条件检验；不能把21/23/43例直接挪作“分布独立于均值”的证据。源验证重复用于开发、T不是全栈OOF、同队列反复研究，后续固定方案仍需更广独立采集确认；目前不是顶刊成果已完成。

## 5. 唯一下一方向

**按主流程安排冻结additive，转向更广的独立采集覆盖验证，不再在同cohort搜索小头。** 此方向已考虑joint18的实际结果，替代本报告早期未执行的凸融合建议；不追加融合臂或超参数。本次只更新判断，不实施新训练或采集。

所需新证据是：固定当前方法与预先声明的评价口径后，均值/分布共同读出的类别取舍和相对强B效用能否在未参与本轮开发的覆盖上保留。优先保留同一强B、mean-only作为解释参照，而不是仅与较弱旧分数比较。是否每类全胜不是门槛；真实净收益、受损类别与可用极化/采集条件都应记录。扩大覆盖不能自动等同独立证据，仍需说明新增对象和采集与已有开发数据的关系。该方向不预设结果，也不把本轮模型选择包装成已完成外部确认。

## 6. 可直接使用的Novelty论证段

本研究关注跨采集SAR船舶分类中一个容易被混淆的问题：新图像读出的收益究竟来自已有分数的重新校准、额外的类别均值证据，还是均值之外的响应分布。区别于CSRA将类别响应用于空间注意力聚合，以及GSoP/CPINet在特征层利用高阶依赖或跨极化交互，我们在冻结识别器和普通强校准之上，以源监督辅助类别方向统一组织各有效极化的均值与局部分布，再分别读出、相加为实际类别竞争的补充。当前同源协议实验显示，均值读出提供更强的总体准确率及概率风险改善，分布读出保留部分不同类别的正确判断；源验证已有对应的互补迹象，近容量对照又表明简单分路相加足以保留相对强B的三seed OA/BA正增量，无需把联合隐藏层交互作为必要机制。其有意义的推进在于任务类别坐标下均值与分布的分离、强校准参照下可复核的效用证据，以及由此得到的简洁读出组织，而非宣称双极化、二阶统计、联合MLP或相加首次出现。现阶段支持固定开发范围内的效用及明确类别取舍，尚不主张普遍优于均值、已证明物理机制或已完成独立采集确认。
