# 八类冻结空间离散度外推结果

日期：2026-10-23。状态：固定方案已完成；没有新增训练、读出重拟合或额外实验臂。

## 结论

三类的正向结果没有直接外推到本次八类：4744 个互不重复的测试目标中，contrast_std 救回 121、误伤 215，净 -94。OA 从 39.523609% 降至 37.542159%（-1.981450 pp），BA 从 40.349061% 降至 40.048918%（-0.300143 pp）。三折均由源验证 balanced NLL 选择 lambda=0.5，没有使用测试标签选参。

负结果不是所有风险指标一起恶化：测试 balanced NLL 从 1.683299 改善到 1.668419，balanced Brier 从 0.742998 改善到 0.735094；但普通 NLL/Brier、OA 和 BA 下降。应保留这个目标与类别组成的取舍，不将其写成实现错误、空间信息全无用或八类完整 A+D 已完成。

## 固定输入与算子

- 全部输入 15251 目标、6688 MMSI、316 pass、330 products、8 类；测试 4744 目标、2973 MMSI、85 pass、18 港。测试三折互斥，沿用父流程的源训练/验证/测试与 MMSI 排除，不重新分配。
- 实际读取父 `prepare_features.py` / `native_input.py` 的原尺度 160 crop/pad；没有把原始 64/72 等窗口 resize 为 160。目标保留与裁剪坐标逐例对齐父 coverage。原窗有效 footprint 经 area 下采样至 layer3 的 10x10 网格，与父 weighted pooling 完全一致。
- VV 有效 15251，VH 有效 13783；1468 个无效 VH 的 mean/delta 均严格为零。测试中无效 VH 为 308 个。零 footprint 的 padding cell 不进入统计，但卷积感受野仍可能混合边界/padding，不能声称消除了 padding 对网络的全部影响。
- 冻结同一 ImageNet R50、fp32/eval、四次整 90 度旋转。每个极化每个 C4 map 单独求加权均值和 population std，再极化求和、C4 平均；不先逆旋转平均 map。
- 对三折已保存 W 同时计算 `v_c(p)=W_c(F(p)-F_weighted_mean)`、`r_c(p)=v_c(p)-mean_class(v(p))`，`delta_c=sqrt(sum_p normalized_weight(p)*r_c(p)^2)`（实现显式减去数值残留加权均值）。不引入 source h0 常数摊分，不把标签送入 delta。
- 原始 A 分数独立保留，`score=A+lambda*delta`。lambda 仅在源验证按 balanced NLL 从 `[0,.1,.25,.5,1]` 选择，包含 0，平局优先较小值。三折原 ridge alpha 均为 1，不重新拟合 PCA/scaler/ridge，没有新 NN 或 OOF 训练。

这是冻结读出的范围外推，不是官方 CSRA 复现，也不是独立新数据确认或整流水线 OOF 的声明。八类基线与三类基线的任务、类别组成和输入组织不同，不能直接以 OA 差解释某个模块优劣。

## 保留与停止边界

目前能确认：实现与固定 A/有效 footprint 对齐；空间离散增量有类别依赖取舍；三类收益不能作为八类收益保证。不能确认：退化由某一背景/散射机制或 std 丢失符号单独造成。

数学上 std(v)=std(-v)，因此它确实丢失正负非对称信息；这是后续有符号证据实验的合理问题，但不是本次八类退化根因已被证明。主流程正在独立目录处理 signed 比较，本分支不添加新臂、不扩大 lambda 网格、不更换选参目标。保留本轮完整负结果，等待不同证据算子的独立结果后再判断下一步。
