# 区域身份与外围增量：配套训练对照

日期：2026-10-23。方案在本轮训练和目标评价之前固定。

## 依据与问题

上轮动态OBB相对同容量固定模板有BA/OA平均收益，但分开/合并区域头853/565参数，尚不能单独解释区域身份。obs966侧向摘要参与救回，2217端部/侧向参与误伤；固定头置零不能替代配套训练。当前用已有原图、摘要和这些已记录事实启动有针对性的验证，不重提骨干特征。

## 固定内容

继承父目录的全部样本、源训练/验证、三fold、三seed17/29/43、冻结旧双向注意力分数、layer1类别reader、温度、native crop/pad、OBB区域和有效性规则。旧full(dynamic)九个选定头与结果直接复用，不重新挑checkpoint。目标仍为4744观测的历史开发队列，不是新的独立盲测。

四个新增臂，每臂9头，共36头：

|臂|新增区域输入|所检验的问题|
|---|---|---|
|shuffled|每观测独立固定置换三个区域槽位|稳定区域身份是否比无稳定身份更有用|
|body|仅框内摘要，端/侧原始摘要置零|只增加框内读出能做到多少|
|body_end|框内与端部摘要，侧向置零|端部的配套训练增量|
|body_side|框内与侧向摘要，端部置零|侧向的配套训练增量|

所有头输入69维、853名义参数，使用相同初始化和32维真实共同质量输入。部分区域置零减少实际活跃输入，不宣称有效容量完全相同。保存训练输入非恒定列数。框内/外围指新增通道；冻结旧模型仍能看到整张chip，layer1感受野也跨区域，不把它称为全系统纯框内或纯背景分类。

shuffled使用default_rng([4711,int(obs_id)]).permutation(3)，每观测固定，跨fold/训练seed复用；VV/VH使用同一置换，区域内的全部8类与mu/h/b一起移动。训练、源验证和目标评价都用相同规则，不只在test时扰动；不使用类别或预测结果决定置换。部分排列为恒等是随机对照的一部分。公共几何/质量仍保留真实顺序，不置换；因此测试稳定摘要槽位的效用，不声称彻底移除所有可推断的区域身份。

新增臂仅改变原始区域摘要，随后正常生成类中心化槽并用本fold源训练拟合scaler。训练、优化器、步数、损失、source J选择含0步、最早平局策略与父实验完全一致。不添加超参数搜索。

## 评价与病例

主要比较full-shuffled、full-body、body_end-body、body_side-body、full-body_end、full-body_side；同时所有臂对旧模型报告。OA、BA、预定J=(OA+BA)/2、NLL/Brier、救回误伤，3seed逐项及均值标准差，按类/港报告。主对照按MMSI与过境组分别做2000次配对bootstrap；不将重复seed扩充成独立船。

区分非零头比较与0步回退；保存完整源学习轨迹，失败先看训练是否能拟合、验证是否退化、实际病例与区域覆盖，不预设方向无效或代码错误。
