# OBB 动态区域读出：首轮配对验证

日期：2026-10-23。用户已授权设计实验并验证。此文件在本轮训练和测试结果产生前写入。

## 要回答什么

现有双向类别响应注意力保留整体响应分布，但未明确区分响应相对目标位于框内、长轴外围还是侧向外围。新假设是：在原尺度图像上按检测 OBB 组织较浅层响应，可以提供旧完整模型尚未充分利用的分类证据。

本轮检验区域读出，不声称新卷积、纯前景分离或物理因果。已有深层注意力的收益不是新区域设计已经有效的证据。

## 固定任务与数据

- 继承 eight_class_evidence_20261023 的原身份/日期外划分、三个 outer folds、每 fold 四个 inner readers，八类闭集。
- 源提取队列预计8750条，历史目标开发队列4744条；实际数量和各角色有效性由运行表确认。不混淆每fold训练集与源队列并集。
- 固定旧 matched_attention_readout 已选定的三个fold、三个种子17/29/43模型作为 s_keep；按 fold、seed、role、instance_id 读取同一基线。所有新臂使用相同预测。
- 旧浅层以外的 A/D/T、原双向注意力、检测器与R50骨干不重训。旧T及注意力补充头的源训练分数不是全栈OOF；新类别reader仍按原inner排除held身份/采集。不得声称整个残差训练输入完全OOF。
- 本轮不使用目标支持标签、64案例适配、5%专家交接、邻船真实类别或港口ID。
- 不新增公开集，不改标签，不因本轮结果修改评价成员。该历史队列是反复研发过的开发评价，不是独立盲测或严格留港确认。

## 图像与区域

沿用native160 crop/pad，不resize船体。VV/VH各自使用可追溯的OBB与裁补偏移；C4同步变换像素、真实footprint和区域。浅层候选固定layer1；记录实际stride、网格原点和理论感受野，不将网格位置当成独立像素支持。

首轮候选rhoL=0.25、rhoW=0.5，固定1原像素软边；源图覆盖检查确认可读后冻结。不用测试准确率挑窗口。三个区域为框内、沿长轴扩展后减框内、沿短轴扩展后减框内。长轴两端合并、两侧合并；theta与theta+pi相同，不声称真实首尾。

固定模板L/W分别由合法源训练样本检测长宽的中位数确定，并保留每个目标的实际中心和船轴。源inner摘要的模板来源也必须与对应reader拟合范围一致。动态模板直接使用该目标检测L/W。

区域与真实footprint相交；有效性、面积、覆盖率与n_eff均记录。最低区域可读条件在源覆盖检查后、训练前补记。无OBB或无有效区域时明确置零及标志，旧路径继续工作；不可悄悄更换全队列或放大图像。

## 比较臂

| 臂 | 新增读出 | 主要问题 |
|---|---|---|
| R0 | 无，固定s_keep | 是否有完整系统增量 |
| R1 global | 同layer1整图类别响应均值与双向摘要 | 浅层内容加共同几何辅助能否奏效 |
| R2 fixed | 固定源模板长宽、逐目标实际船轴、三个区域 | 固定模板是否已经足够 |
| R3 dynamic | 实际OBB长宽、相同船轴、三个区域 | 动态大小是否优于固定模板 |
| R4 merged | R3相同三个区域摘要，按有效区域合并后输入 | 区域摘要压缩是否损失有效信息 |

R2/R3是主配对，共用reader、方向、槽位、头结构、尺度标准化规则、种子与步数。各臂获得相同真实尺寸和共同质量输入，不能R3单独知道L/W。质量量可共同使用动态区域质量或固定与动态两组质量，但需一次确定并记入实现配置。

R1/R4维度与R3不同，报告实际有效参数，不靠填零或复制摘要假装容量严格匹配。R4可支持保留区域摘要的实用价值，不单凭它宣称纯区域身份机制。

## 读出与训练

新layer1类别方向使用合法源训练数据拟合，共用同一reader读取各区域。区域内保留mu及原双向响应摘要h/b，VV/VH分开，每C4视图完成非线性读出后平均。每极化共享温度，使用合法源OOF整图响应尺度确定，各臂共用；不做温度搜索。

新类别共享小头输出delta，最终s=s_keep+center_class(delta)。末层零初始化必须精确回到旧模型。拟合输入标准化仅用对应源训练样本；新头用CE与类别均衡CE各半，AdamW lr0.003、weight_decay0.01，200步，每5步按源验证J=(OA+BA)/2选择，包含第0步，同分保留更早步。三fold三seed四臂至多36新头，不做测试驱动追加倍率或窗口搜索。

所有源配置与检查点选定后，评价一次固定历史目标队列。源端结果不佳仍完整保留，不能以测试回选改写训练选择。雷达双参照暂不实施。

## 必要验证与其用途

- theta+pi不变、C4同步和裁补坐标：发现错位则先修实现，不将错位结果解释成区域假设失败。
- 原图区域覆盖：发现外围普遍缺失或目标错配则明确数据范围并修接口，不扩大图像冒充同输入对照。
- 固定/动态区域确有差异且R2/R3公共输入相同：排除没有真正检验动态大小或混入附加信息的情况。
- 零步s_keep一致、训练/验证/目标ID对应：发现基线不一致立即修接入后再比较。
- 源reader身份/采集划分继承、源配置冻结：防止用目标标签选择reader、窗口或模型。

不做与上述具体失败无关的全量审计。

## 结果与原图解释

报告逐seed及均值OA/BA/NLL/Brier，净救回/误伤，R3-R2主配对，R3-R1/R4辅助比较；逐类与实际采集分组。以MMSI和过境组分别做配对bootstrap区间，避免把三seed重复观测当独立船只。解释性分层使用源端长宽/覆盖分位数，不从测试挑获胜阈值。

每轮回看原尺度VV/VH：救回、误伤、持续正确、持续错误各有代表；优先展示R3与R2真正发生分歧的样本，也标明相对s_keep的结局。显示真实区域、真类/实际竞争类分差、固定头区域摘要置零或替换后的变化。干预是响应/摘要层证据，不是删除原始像素或证明物理原因。

报告新reader拟合、图像提取、mask/readout和头的实测成本；仅缓存推理时间不得冒充端到端成本。

## 源覆盖后冻结记录（训练前）

主代理已查看coverage_panels的small、large、slender、square、clipped五组原尺度VV/VH。有效源极化输入16524个（VV8750、VH7774），均可恢复目标OBB。框内、端部、侧部的最小视图n_eff中位数分别17.91、10.96、21.68；仅2个端部读出低于4，框内和侧部没有。各区域覆盖率1%分位数均约1，但极端紧裁片存在明显截断。

据此冻结rhoL=0.25、rhoW=0.5、1像素软边、区域可用条件area>0且四个C4视图最小n_eff>=4。覆盖不足不额外筛除样本，质量输入明确记录；不改变原图范围。

图像可见事实：small固定模板覆盖比实际目标更宽；large固定模板只读强响应中心而动态框扩至更大响应范围；slender固定模板未覆盖整条纵向强响应；clipped两种策略都无法读到图外信息。观察只证明区域改变了可见输入组织，不证明分类收益或物理船体边界准确。square的VH原本无效，继续维持无效，不因新模块重新启用。

网络layer1实际步长4、中心原点0、理论感受野35；区域mask使用以实际采样中心构造的Voronoi面积权重，画布边缘截到[-0.5,159.5]。坐标与面积守恒检查已通过。此时尚未得到本轮分类训练结果。

## 实际拟合接口

新reader采用源fit StandardScaler、PCA128（randomized，seed17，iterated_power4）、post StandardScaler及身份/类别均衡Ridge。outer在预设alpha=1/10/100中按源validation balanced NLL选择，inner继承对应outer alpha；输出尺度固定3。这是15个保存reader（含outer候选拟合），与36个新增小头的训练次数分别记录，未使用目标标签选择。

各臂共同32维质量量：每极化log1p长宽、检测置信度和有效标志，以及实际动态三区域各自的log1p面积、覆盖率、log1p最小n_eff与有效标志。类别输入包含s_keep中心化分数，以及各摘要原值/类别中心化值。global和merged输入45维、565参数；fixed和dynamic输入69维、853参数。两主配对的初始化、共同质量输入及其源标准化完全相同。模型是class-shared Linear-GELU-Linear，隐藏12；不是额外大骨干或自动移动采样点。
