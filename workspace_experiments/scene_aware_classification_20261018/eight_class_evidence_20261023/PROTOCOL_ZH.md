# 八分类共享读出准备

2026-10-23，阶段为特征准备，不是分类增益报告。

目的：三类整景恢复队列只能检验其自身范围；自身chip条件模块不依赖外部邻船，所以可回到既有八分类队列检验。先准备同输入、同骨干的强读出和区域读出，不覆盖旧A+D，也不把三类OA与八类OA直接比较。

## 固定数据

沿用 `same_vessel_gallery_20261019/conditional_evidence_pilot/cohort.csv` 的15252条观测/6688船/330产品。排除已明确身份错误的31237，其他标签不改。沿用 `local_condition_module/view_snapshot.json` 中检测框及已有跨极化关联失效标记；无效VH保持零特征并显式记录，不凭外观重新关联。

使用既有 `crop_pad(...,160)`：大的裁边、小的补零、保证目标掩膜全部像素保留，无插值。VV/VH分别输入。当前以原PNG为输入，其历史拉伸保持不变；不把8位显示强度当校准RCS。所有原始路径、原尺寸、裁补位置和有效区域另存表。

## 同一冻结前向

冻结ImageNet R50，一次前向共享stem和layer3，C4旋转图像及掩膜后平均。layer3按有效图像足迹作均值池化；stem按同样区域作mean/max。读取whole、目标OBB框内、框外三个条件描述，框外排除目标和已检测其他船的3像素膨胀区，补零区域不纳入池化。

这不是卷积前背景隔离：卷积感受野会跨区域/补零边界，尤其深层感受野很大，不能称纯船体表征。层深与池化改变相对旧模型不是单因素消融，后续只在同一新基线内部比较模块增量。

## 本阶段的验收问题

确认没有把目标裁掉、是否存在极化/区域缺失、保存顺序是否和队列一致；核对单样本与批量前向、C4图像和掩膜共同旋转读出是否一致。检查这些是为了发现接入错误，不再全量审计标签。

查看每类预先按ID选取的一例原图及区域覆盖，统计真实可用量。本阶段不训练分类器，不宣称新模块有效。后续沿用既有身份/时间源划分，或明确另设过境划分；不能混用未说明的两种协议。源端拟合预处理、分类器和任何注意力，目标标签仅评价。完整训练设计待当前三类的常量、区域和共同倍率诊断后冻结，不根据八类测试结果挑结构。
