# 固定layer3、新采集划分：自身chip调节复验

2026-10-23。完成一轮约定预算：6个固定layer3 A、54个调节头、30次外层/内层读出拟合，无追加训练、无选best划分，无Git。全部写入本目录。

## 结论先行

**没有复现旧划分自身centered调节稳定的OA净收益。** 新划分A已经达到OA **81.650571**、BA **80.265736**；centered三种子净救回 **+2/-3/+2**，平均OA仅 **+0.005853pp**，近乎持平。BA三种子均正，平均 **+0.270755pp**，但按过境和MMSI分别做的块bootstrap区间均跨零。保留“小幅改变类别权衡、相对raw/bias较稳”的观察，不升级为确定总体收益。

raw三种子OA净变化 **-1/-8/+3**，BA均下降；centered_plus_bias为 **-14/-22/-13**，OA/BA均下降。本轮不证明中心化原创、独立偏置必然有害，或所有SE式门控无效。输入坐标、原截距抵消和优化尺度都影响这项同预算比较。

这仍是同一开发队列的另一随机采集划分，不是独立新数据确认；与旧父实验比较同时改变读出选择规则和采集划分，不能单独归因其中一个因素。另一支线whole/fg/bg同容量对照不在本轮，未使用其未完成结果解释区域分解价值。

## 分解、尺度与实现检查

30次fit的最大centered重构误差 **5.77e-15**、raw重构误差 **6.22e-15**、raw-centered-origin恒等式误差 **1.50e-15**。float64线性图对直接A分数最大差 **2.74e-6**，top1变化0；训练/预测各arm使用的是同一个直接A分数，而不是这个重算值。

54个PT保存后GPU回放误差0；随后独立从NPZ/PT重载，在CPU对持久化预测CSV回放，最大差 **9.54e-7**，全部top1一致。未发现需要重训修正的分解、样本对齐、激活范围或基线接入bug。读出fit索引/W/h0/origin在`origins/`，大缓存和权重仅本地。

centered数学上等价于对源均值标准化后的原特征组做门控，不声称中心化本身原创。固定同一门控a时，raw比centered多`Σa_g W_g h0_g`，会改变原常数项与特征项的抵消；实际两臂还分别训练，a也改变。因此本实验是具体实现的同预算比较，不是对所有SE模块的公平否定，更不能仅凭退化断言独立偏置机制已被证明。

已读本轮外层source缓存的96个有效组，最大origin/centered RMS比为 **5.853**：fold1/group25的centered RMS **0.0930**、origin RMS **0.5444**、raw RMS **0.5523**。这说明本轮仍有偏移与优化尺度差异，但不是原划分含stem某组0.0735对213.9的巨大抵消。后者是主流程提供的另一支线结果，不冒充本轮重新测量。尺度表见`scale_diagnostics.csv`；这些量并未单独证明BA退化的根因。

已用图像查看工具实际打开以下四张面板。按运行前规则选seed29的centered救回/误伤/CC/WW各首ID，优先无外部邻域；这四例恰均为散货船，不代表三类总体。图像为既有native target PNG原像素直接粘贴，不插值、不增强、不重新检测。VV/VH分开，路径、原窗口、过境、MMSI及四臂分数见`review_cases.csv`。没有外部邻居输入，不添加邻居图来解释本轮模块。

1. **救回 pair_0031218，Mombasa，fold5**：VV64×64、VH72×72均见紧凑块状高亮结构，VV亮区边缘较散，VH周围较暗。A把散货判普通货船，真类分差 **-0.10759 → +0.10729**；raw +0.87644、bias +0.47406也救回。centered对原竞争类的分组增量合计+0.21488。可见图像证据与计算链都支持“同chip已有证据可被重新读出”；不能由亮块外观确定具体物理机制。
2. **误伤 pair_0033132，Ningbo-Zhoushan，fold0**：两极化都为较细的斜向亮结构，VV周围纹理更强。A正确但分差仅 **+0.10335**，centered后 **-0.06457**，raw -0.44485、bias -0.12565也误伤。centered所有16有效组的乘子约 **1.4544–1.4999**，接近共同放大上限；实际真类对普通货船的增量为-0.16793。正向放大并不保证正确类分差增加，且中心常数仍不随之变化；这说明计算上的误伤路径，不证明海况或某散射成分导致它。
3. **持续正确 pair_0030906，Melbourne，fold0**：VV72×72、VH80×80呈近纵向细长亮结构，VV背景较斑驳。A分差 **+1.77256**，centered **+2.14514**；raw +1.53913、bias +1.59266也保持正确。此例本来已有较大证据余量，调节不是新增信息来源。
