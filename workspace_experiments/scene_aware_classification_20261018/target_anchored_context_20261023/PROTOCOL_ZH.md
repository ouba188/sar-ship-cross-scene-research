# 目标证据锚定的上下文调制

2026-10-23，训练前固定。

## 数据依据

扩围5695条三类观测中，原stem分区邻居模型BA+0.734pp、OA持平，正确图像与布局联合好于各自常量。更深单骨干源验证选layer3或stem+layer3后，单船A达到OA81.370/BA79.851；原split增量三种子OA均下降，BA仍略增。已有0052382等普通海面案例显示：添加上下文会把本来正确的散货证据推向普通货船。上述证据尚不证明这一定由独立类别偏置造成。

背景仿射参照试验也没有得到净OA收益。不能继续默认把环境差异减去即可分类更好。下一候选不改变原图、骨干或判别方向，而是检验“限制上下文的职责”是否减少误伤。

## 模块

原A是冻结R50的源选择读出。将其线性类别分数精确拆成 b + sum_g q_g(x)，q_g(x)=W_g*(h_g(x)-h0_g)，h0为源训练目标特征均值。原神经通道固定，分组不使用标签：stem每极化8组且mean/max同通道共享组；深层每极化8组，共32个位置，无stem读出时对应16组为零。这里不是任意PCA坐标分组，而是原骨干通道分组；组本身不宣称对应物理机制。

邻居分区内容均值与布局摘要共79维输入一个79->32->32 MLP，输出a_g=0.5*tanh(...), 最后一层零初始化。新分数：

`s_new = s_A + valid_context * sum_g a_g(context) * q_g(target)`。

对应原特征变换是h0+(1+a_g)*(h-h0)，1+a范围[0.5,1.5]，原A方向和偏置不变。当目标恰等于源参照、q全零时，任何环境都不能独立产生类别增量；无邻居严格回A。这个限制比允许环境加性中心更强，但不证明无场景捷径、因果分离或纯物理目标信息。仍是受约束条件交互，不声称首次发明条件调制。

## 对照与训练

- anchored：实际上下文调节目标证据。
- constant_env：同结构从训练开始用源上下文均值，检验固定证据重加权能否解释收益。
- scene_replacement：同结构训练开始用同产品另一个合法目标的上下文；复用已核对不重读受体OBB的供体映射，无可用供体则原样并报告覆盖。它同时替换供体布局，不是独立几何置乱。
- 原strong split_unit：已有真实上下文直接加性残差，完整保留。它2659参数，新受限MLP3616参数，不冒称完全同容量；恒定和替换两组与新模块严格同容量。

固定六个采集包及MMSI隔离，不换标签或查询。每个内层held包重新拟合选定A的PCA/标准化/ridge及h0，并由该A生成OOF的q组和分数；同一组始终是原骨干通道，避免跨折PCA坐标漂移。环境表示复用外层源训练的无监督投影，因此仍不称全流水线OOF。验证/测试用外层A与h0。

三种子17/29/43，200步AdamW(lr=.003,decay=.01)，类别/MMSI平衡CE，源验证类别平均NLL每5步选择，含零步。固定范围不因目标成绩扩大。指标OA/BA/宏F1、类别和过境净救回、原图与组贡献。开发队列仍为反复使用库存，不是独立确认或旧八类A+D。

## 首轮后针对性比较

首轮anchored三种子OA/BA均正，但固定已训练头换同景供体后大部分收益仍在，因此不宣称精确邻接必要。controls.py新增三臂，其他训练不变：own_regions_matched使用目标自己的fg/bg表示、源均值布局，仍只启用1165个匹配上下文目标；own_regions_full使用同一自身输入，所有5695目标均可启用，单独报告覆盖差异；anchored_plus_bias共享原隐藏层，再允许一个32->3零初始化加性类别头，增加99参数，用以检验无独立类别增量限制。前两者3616参数，后者3715参数。自身区域不是纯船体/环境分离，整张原chip仍可被A看到。

这是结果引出的追加探索，不伪称最初预注册。own_regions_matched与full区别必须同时包含训练/验证/测试的激活范围，不把训练时关掉、测试时打开当公平部署。
