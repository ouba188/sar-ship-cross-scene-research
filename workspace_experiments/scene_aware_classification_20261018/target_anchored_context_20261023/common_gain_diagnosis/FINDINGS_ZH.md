# 共同倍率、组间差异与中性中心：固定模型诊断

2026-10-23。只写本目录；加载36个已有头、12个已有outer W/center，**零训练、零重新拟合**，用时48.33秒。未修改父目录、复验或centering_probe文件，未Git。

## 核心结论

1. **定位到了触发案例的计算原因，而不是证明物理根因。** 新复验pair_0033132各有效组接近共同放大；共同项相对非均等的参考分数b移动类别边界，单独即造成误伤。去掉共同项后该例恢复正确。为何网络从该chip学出这种响应，尚不能由本诊断或外观解释。
2. **整体收益不是由共同项独自承担。** 旧own_regions_full的original净+14/+8/+16，common-only为-5/-11/-4，contrast-only为+17/+12/+15；新centered_own_full相应为+2/-3/+2、-6/+1/-9、+10/+6/+14。共同项的分数增量范数虽更大，不等于其分类贡献更好。
3. **共同项也有真实局部收益。** 新pair_0031218几乎完全由共同项救回；不能用总体负net否定其样本自适应价值。另支线从训练开始恒定输入的18头对照也已完成，不能把样本依赖的共同倍率误称为全局固定缩放。
4. **weighted-neutral中心的恒等式得到数值验证。** 使用与ridge完全相同的源训练weights，A(h0w)各类距1最大2.11e-5；固定原m，在34170个样本-seed对上，中性中心共同倍率的argmax变化为0。中心是设计选择，当前unweighted中心并非实现bug。
5. **下一步证据最直接指向训练匹配的contrast-gate验证；neutral anchor应作为另一个可区分解释的对照。** 常量重训练已有结果，不应重复。所有建议尚未在本支线执行，不能将事后删除共同项当作已训练新模块的收益。

## 数学与数值验证

令有效组集合G，a_g(x)=0.5tanh(controller_g(env(x)))，m(x)=mean_G(a)，c_g(x)=a_g(x)-m(x)。对固定原模型：

`delta(x) = m(x) * sum_G q_g(x) + sum_G c_g(x)*q_g(x)`。

原A满足`s(x)=b+sum_G q_g(x)`、`b=A(h0)`，所以common-only严格等价于：

`s_common(x) = (1+m(x))*s(x) - m(x)*b`。

两类j/k的分差变成`(1+m)*(s_j-s_k)-m*(b_j-b_k)`。只要b不是各类相同，就不是一般意义上的纯temperature；它含样本依赖的类别偏移，可改变类别倾向。这里的“先验作用”指这种分数偏移，不声称b就等于校准后的真实类别先验概率。

源训练加权ridge使用未惩罚的截距，因此精确算术下，截距的一阶最优条件给出加权残差均值0。由于整个固定读出链为仿射：

`A(h0w) = weighted_mean(A(h_train)) = 3 * weighted_mean(onehot(y_train))`，

其中`h0w = sum_i weights_i*h_i / sum_i weights_i`。此weights对三类等总权重，并在类内平衡MMSI，三类均有源样本，所以右侧是`[1,1,1]`。

实际用保存W直接计算，不重拟合，12个outer的最大中性误差 **2.1083e-5**，与原训练数值精度相容；源样本原A分数的加权均值也给出相同数量级结果。原unweighted h0对应b则明显不等，例如新fold0为 **[1.418553, 0.630438, 0.950985]**。完整每fold数据见`anchor_verification.csv`。

定义`qw_g = q_g - W_g*(h0w_g-h0_g)`并保持同一个A和原m，则neutral-common满足：

`s_neutral_common = (1+m)*s - m*[1,1,1]`。

因为1+m>0，精确数学下argmax不变，但概率、NLL仍可变。实测使用数值bw而不是强行替换成精确ones，**34170/34170样本-seed对无argmax变化**。共同公式/中性公式相对缓存分数最大误差约1.001e-6；共同与contrast的delta重组误差 **6.66e-16**。36头original对持久化预测回放最大差 **4.00e-7**，top1全部一致。

注意：将整个模型改用weighted-neutral q，不等同于这里只去掉common。重新锚定也改变每组q，因此contrast部分也会改变；本轮只验证neutral下common的性质，没有训练或评测一个neutral完整新模型。

## 与已完成常量控制的关系

已实际阅读`../controller_readout_probe/CONSTANT_FINDINGS_ZH.md`，没有在此重复其训练或回放。该报告的constant_own_full从训练开始到验证/测试都用源全体ownenv均值，全量激活，18头净 **-31/-33/-31**；相对父adaptive own，平均OA **-0.77846pp**、BA **-0.50500pp**，pass/MMSI两种区间均不跨零。

这排除了“当前指定静态分组再校准足以复现父总体收益”的简单解释，支持继续保留样本自适应。但constant是**整组gate向量不随样本变化**，并非对本诊断的单一m(x)训练了一个匹配静态标量对照；不能仅凭该结果把优势全部归于sample-specific common gain。我们的0031218则直接显示sample-specific common存在局部有效路径，二者并不矛盾。

whole/fg/bg输入控制仍由另一代理推进，本报告不引用未完成结果，也不宣称两区域组织已有独立价值。共同/contrast拆分只涉及输出门控职责，不证明所有区域信息无用。

## 下一步判断

**优先：训练匹配的contrast gates。** 理由是两个现有划分、全部六个seed组合的固定模型contrast-only相对A净正，且触发误伤确被共同项移除消解；这比只依据“neutral共同项不翻类”的代数性质更直接连接当前实际错误。仍需先明确contrast幅度界和保持预算，训练后重新用源验证选步；本次事后结果只提供候选依据，不能作为已完成的性能结论。

**其次：neutral anchor作为独立对照。** 它能清晰区分“相对非均等参照的类别偏移”与其他组间作用，理论/数值路径已成立。但neutral完整调节也改变contrast的q，且会移除0031218这类共同项的翻类能力；尚无证据保证净收益，不应与contrast改动捆绑后把收益归给任一项。

**不重跑retrained constant。** 配套公平常量控制已经完成，可直接引用；若要单独量化sample-specific common的总体价值，另需明确针对共同标量的对照问题，而不是把现有全gate常量结果外推。当前没有新增该实验。

中心选择是模型设计选择，不自动是bug；中心化等价标准化坐标门控，不宣称原创算子。上述建议都尚未执行。保持开发数据反复使用、非独立确认、原A强基线以及OA/BA类别权衡边界。
