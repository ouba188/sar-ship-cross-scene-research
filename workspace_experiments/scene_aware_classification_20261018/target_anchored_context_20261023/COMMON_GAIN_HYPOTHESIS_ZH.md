# 从通道选择中分离整体倍率与类别参照

2026-10-23，诊断假设，不是已测结论。触发证据：新划分案例0033132的16个有效组倍率几乎全在1.4544–1.4999，说明至少这一例并非明显的分组差异选择。

## 已知代数关系

固定读出`A=b+sum(q_g)`，注意力增量`sum(a_g*q_g)`。在结构上有效的G个组中，定义共同分量`a_bar=mean(a_g)`、差异分量`d_g=a_g-a_bar`。则：

`A_new = A + a_bar*(A-b) + sum(d_g*q_g)`。

它把当前模型实际使用的两种操作精确分开：对全部特征证据共同增减；对不同组作相对选择。两个分量的分类效果不是线性相加，因为argmax边界可能变化。

只保留共同倍率时，`A_common=(1+a_bar)*A-a_bar*b`。由于原a范围[-0.5,0.5]，共同倍率始终为正；若b各类别相同，argmax与A完全一致。若b各类别不同，共同倍率可以改类别判断，这不只是softmax温度改变。

## 为什么当前b未必均等

当前h0是源样本无权均值，但ridge按类别和身份加权拟合。带截距的加权ridge在其加权特征均值上的输出等于加权标签均值；训练权重每类总量相同，三类一热标签均值为1/3，经当前分数尺度乘3后应为各类约1。

因此，改为训练权重对应的h0w，保持原A和所有分类方向不变，可以得到类别中性的参照b_w。当前无权h0没有这个性质。两者都是可定义的参照，当前实现不自动算bug；但共同放大对类别组成的作用必须解释。

## 现在开展什么，不开展什么

先固定已完成的两个划分模型，仅重放共同项、差异项及完整输出，并验证源加权参照的实际数值。这不新增训练，不利用测试标签选择门控或中心。逐类、逐采集记录救回/误伤，并回看原图。

若收益主要来自共同项，保留其低成本类别校准价值，但不能描述成已学会复杂区域选择。若差异项有额外判别收益，再针对如何保护它做配套训练。源均值控制从训练开始恒定的对照也在另一支线进行，避免仅凭固定头输入置均值判断自适应必要性。

即使共同项贡献显著，也不证明背景/区域无用；控制输入仍可能决定何时应调整。反过来，分组权重不同也不自动证明物理语义。下一轮结构选择取决于本轮分解和配套控制，而不是预先认定必须加零和门控或新损失。
