# 让共同倍率只负责置信度，让组间取舍负责类别判断

2026-10-23。针对已观察失效的下一项算子改动；启动前定义，不预报收益。

## 实际依据

固定头去掉共同项，在两个划分保住正净变化；但从头训练contrast-only后，新划分净+13/+10/+11，旧划分-13/-13/-10。由此不能把事后干预直接当部署方法，也不能断言真实组间证据没有用。

已验证的原算式：`s_old=A+sum(d_g*q_g)+m*(A-b)`，其中`a=.5*tanh(net)`、`m=mean(a)`、`d=a-m`。在原h0对应的b各类不等时，m既可改善置信度，又改变类别竞争。具体误伤0033132已能定位到共同项。直接删掉m也改变学习过程，可能丢失其用于概率拟合的作用，但这仍是待检验解释，不是已证根因。

## 针对性改动

只改变共同倍率的作用位置：

`s_new=(1+m)*(A+sum(d_g*q_g))`。

固定d时，`1+m`在(0.5,1.5)，因此不改变类别排序；它仍进入训练CE和源验证NLL，可用于概率拟合。组间差异决定分类结果，共同倍率只负责条件置信度。没有新增网络头、没有新增温度超参数、没有目标标签选倍率，也不在训练后丢掉某条预测路径。

这不是“温度缩放首次出现”，也不是物理因素分离。可检验的新增点是将冻结SAR读出中混在一起的类别竞争和共同尺度分开，并检验是否比直接删除共同项更好。整体有效性不能由正倍率不改排序这一恒等式代替。

## 固定比较

沿用old/new两个开发划分、各自冻结A与合法OOF、同env、3616参数、200步、3seed和源验证选步含0。共36个新头。比较已完成的original、contrast-only重训与range-matched重训，不扩大参数搜索。

检查OOF/outer的A传入是否正确、零初始化是否回到A、有效组d和为0、实际score与括号内score的argmax是否逐样本相同。报告OA/BA，也报告NLL/Brier以区分置信度与分类作用；保留逐类损失、两个划分差异和实际原图救回/误伤/CC/WW。

若仅改善NLL、不改善分类，就按概率校准结果记载；若只一划分有效，保留其范围而不宣布通用解决。之后再决定是否进入已准备好的八类主任务，不能先在八类测试上找一种有利变体。
