# 共同倍率作用位置解耦：36头结果

2026-10-23。已完成本轮36头、独立磁盘回放及8张原始VV/VH面板回看。只写本目录，不修改父级、不Git、不追加训练臂。

**结论：新划分三seed净+15/+11/+16；旧划分-7/-2/+16，尚未恢复原模型稳定的OA收益。** 相比同容量的contrast重训，两划分正确数均增加，但不能据此宣布普遍分类优势。共同倍率现在对固定差异分量只改变概率、不改变类别；这一性质已数值验证。微平均NLL/Brier改善，类别平均NLL并非所有参照中最佳。局部正饱和确实压缩差异幅度，但没有全体门控共同饱和的证据。

## 1. 冻结范围与算子

仍为5695观测、4312 MMSI、163pass、15port，三类：散货3170、渔船1147、普通货船1378。不是八类实验。old使用原源验证选择读出，fold0/1/3为layer3，fold2/4/5为stem_layer3；new固定layer3，沿用种子20261023的新采集六包与MMSI隔离。两队列内部A原样不变，但old/new各自拟合的A不同，不能把队列差异单独归因于划分或读出。

读取既有q/oq/env/base/oof及索引，不重新拟合读出、不重新提取图像。q仍按原神经通道分组，不是PCA轴；layer3只激活后16组，前16零槽不参与均值。own env仍为源拟合的fg/bg各32维stem投影及常数layout15，全目标激活。保留这一输入以隔离算子，不主张双区域优于whole/fg输入。

同一79->32->32网络、3616参数、末层零初始化：

```text
a = 0.5*tanh(net(env))
m = mean(a over structurally active groups)
d = (a-m) on active groups; inactive slots = 0
core = A + sum_g d_g*q_g
score = (1+m)*core
```

原full算子为`A+sum(d*q)+m*(A-b)`，其中不等的b会介入类别竞争。新算子移除这种直接的`-m*b`路径，而保留共同分量参与训练CE及概率输出。因为`1+m`为正，固定模型的score与core argmax相同；**这不意味着m对训练出的d没有影响**，二者共享有界a及优化梯度。

训练显式传入`oq[train], oof[train]`；源验证/测试传入outer `q, base`，不混用。200step、seed17/29/43、原类别/MMSI权重CE、AdamW(.003,.01)，每5步按实际完整新score的源验证balanced NLL选步，含0步。未缩放core不参与选步，不选测试温度、无额外校准头。源内OOF读出来自既有重拟合缓存；env仍是outer source拟合，因此范围是基础读出OOF，**不是整流水线OOF**。

没有全局`m≈.5`坍缩。正负a同时饱和仍可保留较大的d，故48%-52%的绝对饱和率不能解释为共同放大挤掉了全部差异。局部挤压确实存在：m>.49的old目标为15/17/45例，new为99/76/55例，这些尾部d SD均值约.009-.013；m在(0,.25]时old约.387-.395、new约.326-.335。m与d SD相关系数old约-.56至-.64、new约-.63至-.69。

这是共享有界a下局部自由度收缩的观察，与代数限制一致，**尚不是old退化的已证实根因**；相关性部分由参数化本身决定。`curves.csv`记录每5步训练统计，`gate_stats.csv`记录选中模型train/val/test，`sample_gates.csv`及`saturation_strata.csv`保留逐例与固定分层。下一轮若研究优化耦合，可把“在线性logits先分共同/差异再分别有界化”列为待检验假设；本轮不执行、不预设有效。

## 6. 验证、产物与范围

36头训练运行27.743秒，没有重拟合强读出。初次启动有一个空列表解包数目错误，在任何训练前已修正；未因此重复训练预算。0步与对应A逐值一致；d有效组和最大绝对误差1.3113e-6，非有效槽精确为零。全部36×5695次outer样本/模型检查中，score与core argmax差异为0；这不是205020个独立目标。A/q同时为零时输出为零；仅q为零时为A的正倍率，不存在独立env类别头。

36头GPU磁盘重放最大误差0；独立CPU重放最大分数误差4.7626e-7，top1一致。基线分数原样保留。代码为`run_score.py`和`analyze_score.py`；`models/`保存36头PT，`predictions.csv`保存34170条测试预测，`paired_predictions.csv`保存逐例参照关系，另有逐折、pooled、类别、来源、耗时及验证表。PT及缓存只留本地。

可保留的结论是：共同倍率作用位置可在不改变固定d分类的前提下保留实际概率路径；这次同预算重训减轻了旧contrast的退化，并在新划分有正向正确数变化。仍未解决old散货/特定采集包损失，未确立相对contrast的显著分类优势，也未证明局部饱和是这些损失的原因。

这是同一开发数据上的两套划分复验，不是独立新数据确认；多轮方法选择的适应性未被上述条件区间覆盖。主流程的标准CE线性对照不构成所有强头的穷尽比较。通道竞争、相对归一化、tanh、恒等初始化与温度调节已有方法，本轮不声称概念首创；研究候选是针对冻结SAR读出共同倍率与类别参照纠缠的限制及配套证据。到此停止本轮预算，保留正负结果，不追加arms或择优改报告。
