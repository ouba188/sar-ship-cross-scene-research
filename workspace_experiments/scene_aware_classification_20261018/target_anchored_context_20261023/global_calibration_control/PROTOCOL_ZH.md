# 固定类别偏置能否解释类别交换

目前三类候选常表现为散货损失、普通货船收益；八类首轮也存在类别交换。需要区分条件化判别与固定类别偏置调整，而不只对比更复杂的上下文加性网络。

固定所有base/合法source OOF及训练/验证/测试，仅拟合两个低成本确定性对照：
1. 全局零均值类别偏置b，score=A+b。
2. 同一偏置加全局正尺度s=1+0.5tanh(t)，score=s*A+b。

无图像/港口/角度条件，无目标标签，无多种子伪重复。old/new三类各6折、八类3折，共30个小拟合。沿用类/身份加权CE、AdamW(.003,.01)、200步、每5步源验证balanced NLL选步，含0步；零初始化回到A。八类PCA条件错位不会影响本轮，因为它完全不读取该条件。

若可复制门控的分类收益，优先保留低成本全局对照，不把类别比例调整包装成局部证据创新；若不能复制，才保留条件化确有额外作用的解释。报告OA/BA/NLL/Brier与逐类交换，并回看固定预测的原图；不因结果不好扩大搜索。
