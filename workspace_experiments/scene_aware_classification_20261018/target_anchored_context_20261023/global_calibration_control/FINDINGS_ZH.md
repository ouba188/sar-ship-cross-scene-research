# 固定类别偏置不是当前条件化收益的充分解释

完成30个确定性小拟合，不新增图像特征、不重新拟合A。两种对照都仅用合法source OOF训练、源验证balanced NLL选步含0。参数只有3/8个类别偏置，或再加一个全局正尺度；没有样本条件和空间选择。原值及成本见表和summary.json。

固定偏置在old有小幅BA收益，但OA下降；不能复制三类候选兼有的平均OA/BA变化。在八类，固定尺度+偏置OA与修正后的decoupled很接近，后者BA略好：这进一步限制了当前八类模块价值，不能仅凭“远好于高自由度加性网络”立创新。

这不是所有校准方法的穷尽比较；本轮源限定、与候选相同优化预算的简单替代，没有测试标签选偏置。源验证NLL最优不等于测试OA最优，未根据结果延长训练或扩参数。

## 十二张原图已实际回看

固定选scale_bias，每个队列按ID各取救回、误伤、持续正确/错误一例，VV/VH分别打开；三类保留原生64/72/80/88等窗口，八类按既有160裁补，无插值。原图路径、类别、折号在review_cases.csv。

- 八类救回0007313散货：横向细长亮结构，VV有垂直亮纹延伸，VH更紧凑；原油轮改散货。误伤0003626散货：中心不规则亮结构，两极化相似，从散货改成品/化学品油轮。CC0003494、WW0003504都呈短横亮主体，后者仍误为成品/化学品油轮。
- new救回0032624普通货船：小亮主体、可辨结构少；渔船改普通货船。它也是之前门控的救回例，因此单个成功案例不足以证明用了特有局部信息。误伤0031199散货：纵向亮主体，改为普通货船。CC0030906长亮主体仍正确，WW0030918带明显VV横纹的目标仍错。
- old救回0054011普通货船：暗背景中短斜亮主体，散货改普通货船；误伤0030918散货与new WW是同原图，不重复算独立证据。CC0030906仍对，WW0031200仍错。

本轮没有读取新局部结构，所有翻转只能来自同一折的固定类别偏置/尺度改变。这是可验证的决策原因；不能凭图像外观把成功强行解释成某种物理散射线索。已保存的条件模块与其局部成功重叠，不等于总体机制相同，须结合全表对照。

## 验证与决定

30个保存参数重放类别全同。new队列原base为float32，CSV重读提升为float64后算术差最大4.26e-7；按原dtype及Python scalar顺序重放至1e-10内。不是模型更新或测试预测修补。训练起点严格A，权重与原三类实现逐值一致，八类沿用相同类/身份规则。

保留标准对照，不替代主模型。它排除了一个具体简单替代解释，但并不使通道门控自动成为顶刊模块。下一步已根据真实空间积分定位转向GAP前的局部证据分布，不继续扫类别偏置参数。
