# 标准交叉熵线性头对照

2026-10-23。48次确定性拟合、12个源验证选择的模型全部完成。没有重新训练骨干、没有目标标签选参，也不是三个独立训练种子。

## 结果和范围

同5695条观测、三类、old/new两套过境与身份隔离划分；每套使用原有冻结特征、预处理、源端选择的特征类型和样本权重。只把ridge换为multinomial logistic regression；C仅在源验证集从0.01/0.1/1/10选择。后者自然logits，ridge沿用原固定3倍分数，未另做温度选择。

| 划分 | 原ridge OA/BA | CE线性头 OA/BA | 正确数净变化 |
|---|---:|---:|---:|
| old | 81.3696 / 79.8514 | 80.2985 / 79.0977 | -61 |
| new | 81.6506 / 80.2657 | 81.3345 / 79.9320 | -18 |

old散货/渔船/普通货船净变化-56/-9/+4；new为-11/-10/+3。不是所有类别或采集都退化，但该常规替换没有解释掉候选模块的准确率收益。它也不能证明ridge优于所有强线性头、更大骨干或端到端训练。

连续风险应单独报告：old balanced NLL .55131→.54090，但Brier .28725→.29270；new balanced NLL .54893→.52858、Brier .28533→.28276。CE优化概率和top-1准确率并不等价。不能只用OA/BA说其完全没学到东西，也不能用NLL改善声称分类准确率提升。

## 原图回看

每套按首ID选救回、误伤、持续正确、持续错误，八张VV/VH面板已实际打开；保持本批原生窗口尺寸，不插值、不改像素。面板记录两种头的真类分差，但logit尺度不同，不直接比较分差绝对增量代表的信息量。

- old救回0031587普通货船：短横亮主体，VV背景较斑驳、VH较暗；ridge预测散货，CE转为正确。已有attention候选也救回它，因此该案例不是候选机制专属证据。
- old误伤0030918散货：VV主体附近可见重复亮线，VH主体更集中；CE将原正确散货改为普通货船。new中同一张原图却被CE从错救回。图像固定而源训练组成/读出改变，直接说明不能仅凭这类亮线外观断言必然失效。
- new误伤0031199散货：两极化都有纵向亮主体，VV周围纹理较强；从散货改为普通货船。没有证据归因于确定海况或入射角。
- 两套持续正确0030906：纵向细长亮主体，各头均判散货。持续错误0031200：VV较长亮主体及上方亮点、VH较窄，各头均误为普通货船；单纯换线性损失未解决。

这些是实际判别边界差异，不是物理原因的确认。没有外部邻船输入和支持检索，故不虚构邻船/支持解释；完整来源在原targets表中，原图ID与划分在review_cases.csv。
