# 场景上下文首轮：已接通，不能直接把邻居均值接入主模型

2026-10-22。本轮已完成F_0921对象对应候选恢复，以及24港备用材料上的A/B/C小实验、原尺度VV/VH回看、源端选择和预测重放。没有更新既有A+D，没有运行D普通关系注意力/E目标条件化关系模块，也没有开展邻船类别传播或地理设施先验训练。

## 结论先说

1. 场景上下文能够恢复和实际进入分类器，不再只是方案。F_0921得到71个唯一几何对应候选，27个在原chip外1km内有保留对象；候选尚未新增逐例原图确认，不当成新增训练真值。
2. 24港备用小实验有6次采集、5个港口、198张不同船的目标；固定三类为散货船85、渔船29、普通货船84。不是原八分类主表。37个目标有外部候选，161个没有，后者严格返回基线。
3. 修正真实的像素边界取整错误后，A/B/C均值如下。当前简单邻居均值方案没有净收益，不接入主模型；不能用这组结果否定尚未实现的目标条件化关系模块。

## 本轮具体模型与训练

- 冻结ImageNet R50的conv1/bn/relu，在原尺度VV/VH上分别做精确90度旋转C4和均值/最大池化，共256维。没有SAR自监督重训，也没有恢复原完整八类双路主模型。
- A：源训练拟合StandardScaler、32维PCA及缩放，类/船加权ridge三分类。alpha在1/10/100内仅按源验证的类平衡NLL选择；ridge分数统一乘3。
- B：7项边几何/置信度的均值、方差以及数量，共15维；32隐藏单元ReLU、零初始化三类输出，共611个参数，向固定A加分数增量。
- C：在B的15维上增加经同一源PCA投影的32维邻居视觉均值；同样32隐藏单元，共1635个参数。**它是邻域袋基线，没有目标视觉与邻居之间的条件交互**，不是拟议的E创新模块。
- 没有邻居时增量严格为0；对上下文分数仍允许正负，未使用邻居真实或预测类别。
- 外层按完整orbit/datatake采集组留一。剩余源采集按固定循环留一验证；训练、验证、测试MMSI隔离。当前198船恰好无重复MMSI，但代码仍做排除。
- 残差训练用源训练内部按采集留出的A预测，内部再排除同MMSI；不是让残差利用A在训练集的完美拟合分数。该内部A训练量较小，与最终源A有分布差异，是已知限制，不宣称消除所有训练/部署差异。
- B/C各6折×3种子=18个训练，合计36个头，每个200步。源验证每5步选择一次，并保留epoch0；不按测试OA/BA决定是否启用。

多数折的源验证只有1–5个有上下文目标；只有宁波测试对应的源验证有23个。Port Klang虽有23个测试上下文目标，源验证只有2个，三个种子的C均选epoch0。**材料数量和场景分布目前不足以稳定选择上下文模型；这不是“那23个目标没有潜力”的证据。**

预备提取约9.27秒；A/B/C训练与评估runner约9.54秒。均为该小缓存/本机运行时间，含各自实际阶段，不是完整整景检测成本，也不是正式部署延迟对比。

## 原图与模型证据：哪里有用，哪里误用

主代理实际查看 `ports24/outcome_review_1.png`、`outcome_review_2.png` 和两页 `neighbor_detail_*.png`，每页包含分开的原尺度VV/VH。旧PNG与本轮输入并排保留，未将显示差异当物理变化。

### 两个可重复救回案例

seed29下，上海 `pair_0069233`（散货）与 `pair_0083595`（普通货船）各有一个外部候选。两例目标均呈狭长强响应，周边候选也有独立紧凑/狭长亮响应；不能据此外观确认邻居船型。C在三个种子下均把这两个目标从错误类别救回。

- 0069233：散货相对普通货船的分差由-0.119变为+6.811；删除唯一邻边后回到-0.119，恢复原误判。
- 0083595：普通货船相对散货的分差由-1.180变为+5.548；删边后回到-1.180。

这证明本次预测改变依赖新增邻域输入，不证明邻船同类、某种物理机制或跨采集总体有效。分数增量很大，既能救回也可能制造过度自信，需与以下误伤一起解释。

### 一个明确的岸边结构主导案例

上海 `pair_0069192` 的6个邻域候选中，`det_01443` 的原裁片包含大面积岸边亮结构及线状响应；不同于另外几个相对紧凑的海上候选。不能仅凭此图给它确定船型或断定整个OBB是假目标。

seed29下，基线“散货－渔船”分差+1.251，C后为-21.468。删除01443、重新计算邻居均值和数量后，该分差变为+3.438，说明这条候选对错误的渔船方向有很强影响；**但最终预测转为普通货船，仍未恢复真实散货类别**，所以不能称“删除它解决了整例错误”。

该目标的标准化上下文输入范数55.71，而该折有上下文源训练目标的最大值34.92，源验证最大17.75。结合原图和删边证据，可以确认：当前邻域袋读出允许一个包含大量岸边结构的候选主导类别增量，且该测试上下文超出了当前源样本的幅值范围。不能据此认定这是全部退化的唯一根因。

### 不是所有误伤都由岸边候选解释

宁波 `pair_0047041` 的4个邻域候选图像主要是水面亮目标及其局部响应。基线正确但分差接近边界，C在seed29/43将其误伤。逐个删边没有可靠恢复正确类别；这提示普通海上上下文也会产生错误类别先验，不能只靠陆地筛选解决问题。

### 持续判对和持续判错

Port Klang的0054051/0054075持续判对，0052425/0053974持续判错。原图都能看到chip之外其他亮目标，但该折三个种子C均由源验证选为epoch0，实际没有使用上下文。逐边删除仅有约1e-7量级重算浮点差异，不能说模型成功理解了这些船群，也不能用其未改善否定上下文的潜力。

## 实现修正与证据边界

独立复核发现原版本坐标往返后直接floor使75/198个目标窗口上移1像素。现改为距整数1e-6像素内先吸附再取整；真正非整数邻居窗口保留原取整规则。旧结果、代码和图表保留在 `ports24/pre_fix_native_rounding/`，没有删除。

初版C曾显示平均OA+0.505、BA+1.400个百分点；修正后变为OA-0.842、BA-1.158。旧版不能当正结果引用。两版标签、划分、超参数搜索范围不变，但所有受输入影响的源训练与选择重新执行；不能把结论翻转归因到某一个物理因素，也不能把正确坐标退回去追涨点。现有浅层读出/少样本选择对输入变化的敏感性是实际边界。

当前C checkpoint重放最大分数差1.91e-6、预测一致；逐边删除重新计算数量/均值，不把删边差误作可线性相加的贡献。没有无标签/目标标签泄漏的已知实现问题。几何轴和绝对船首不同，未输入绝对朝向、港口ID或经纬度到分类头。

## 下一步的针对性设计，不再凭总分换模块

当前保留的是数据接口、两个稳定救回案例和已定位的错误利用现象，不是宣称C有效。

1. 先把检测候选的OBB内响应与其周边区域分开读出，让“其他对象”与“岸边/水域结构”有不同入口；保持冻结目标A，不能因同一裁片亮就把两者混成一个邻居类别向量。靠岸真船仍保留，不根据测试错误手工删候选。
2. 按既有计划实现D普通关系/E目标条件化关系时，加入相同的节点读出、源端训练和幅值处理。E才利用目标自身视觉决定如何使用邻域。由共同的简单读出对照区分“去掉异常幅值”与“学会关系”，不能把两者收益混称新注意力。
3. 先恢复F的原图对应与备用队列缺失身份，补充多个采集下真实有上下文的源训练/验证材料。不是扩大所有数据集盲跑，也不是要求每港全胜；是让学习器实际见过要处理的输入。
4. 若继续在本198条上开发，明确它是开发队列；更广采集确认前不升级为主表和创新模块定论。本轮不再按测试结果扫半径、删岸边对象、调融合倍率。
