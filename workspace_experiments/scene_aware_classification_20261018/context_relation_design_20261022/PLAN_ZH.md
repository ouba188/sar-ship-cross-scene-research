# 从可恢复场景到目标条件化关系：下一轮设计

2026-10-22。状态：数据与原图推理、文献方法阅读、方案制定；尚未实现或训练该模块，无新增OA/BA。已有A+D及其负结果继续冻结保留。采用brainstorming-research-ideas的problem-first/矛盾分析和experiment-design技能，不把skill当作涨点保证。

## 1. 真实问题与已有证据

当前单目标分类已利用chip内部邻域，但同景其他目标的完整形态、距离、排列以及设施位置并未进入近期模型。上一轮仅用A和D分数学习单一倍率没有净收益，提示不要只继续放大/缩小相同的邻域描述。它不证明更大范围的新证据有效，也不证明所有门控无效。

本轮实际重看 `f0921_priority/object_bridge_31cc_2ec7/review/cases_3.png`：31CC的两个来源LPG案例（636022583、538006974）显示狭长水域附近多个独立亮响应及候选框，64像素局部裁片不能呈现完整周边布局。两例邻域明显重叠，不是两个独立场景；标注为来源标签、关联仍有歧义，不能据此证明框中船型、邻船类别或分类收益。右侧旧model128展示经过缩放，仅用于回顾，下一轮不用该数组冒充原尺度。

还重看 `land_mask/review_2.png` 的五组VV/VH及地图：部分候选紧邻水陆边界，部分落在连续陆地结构中。支持区分船群候选和设施/岸线环境，不支持把所有框外亮响应当船或海面。地图有时间和定位差异，不能只靠中心落陆排除靠岸船。

库存依据见上一轮 `context_recoverability_20261022/FINDINGS_ZH.md`。F_0921五景1008局部对象候选/990保留/3604邻接边不是整景；B529另有全幅VV4275/VH1422候选。不能把局部窗口密度和全幅密度混用。24港可补充有全景检测、可定位分类样本和部分设施几何的任务。公开集当前适合作为部分同景关系的后续材料。

## 2. 创新候选与假设

研究问题：目标视觉证据模糊时，真实空间邻域是否提供额外的、能跨采集使用的类别判别信息；怎样利用这种信息而不是把目标预测简单拉向邻船？

H1（新信息）：在同一批目标、同一预处理和同一训练划分上，加入chip之外真实邻船的几何/视觉信息能带来可重复的净收益。未证实。

H2（利用方式）：同一个邻域对不同目标的类别竞争应具有不同作用，目标条件化的关系描述优于邻居袋均值和普通几何注意力。未证实；不预设近邻一定同类。

H3（边界）：效果依赖可见邻居、采集与环境组织；跨采集评估和保持邻居内容、打乱关系对应的对照可区分真实局部对应作用与场景类别组成关联。该对照不是物理因果干预，同景也涨不构成否决。

可贡献的暂定表述：针对检测后中低分辨率SAR船型识别，把chip外对象组织成可追溯的关系证据，分离目标自身与邻域读出，学习目标条件化、可正可负的类别增量，并以保持邻域内容的关系替换对照及跨采集验证确定使用边界。普通图网络、关系注意力、残差和有符号增量本身不是首创；独特增量是否成立需要对比和更完整近邻文献核查。

## 3. 最小可执行模块

不一次混入设施、风浪流、邻船类别、因果约束。首轮只建目标-邻船关系，已有设施先作描述/分层，第二轮再独立检验。

输入：目标的冻结视觉描述h_i；同一产品中的邻居冻结描述h_j；相对几何r_ij；检测置信度、双极化/定位可用性和有效覆盖。邻船不需要真实类别，不输入AIS身份、目标类别、港口名称或原始经纬度作类别特征。

邻居来自固定检测版本、跨窗去重和合理跨极化关联的对象目录。目标本身及重复检测不作邻居。首轮主对照只使用其中心位于目标原chip窗口之外的候选，单独记录重叠框，避免把内部补充重复算作新信息。跨产品/跨时相检测不能混为当前邻居；目标场景无标签节点可以参与推理，这是scene-available设定，不声称严格chip-only。

几何：米制距离、长宽比例、相对目标无向船轴的轴向/横向位置、相对轴角的双角编码。不得把有向船首当已知；绝对北向角和港口编号不进入类别头。检测置信度不是校准后的真实船概率。雷达方向作为后续单独变量，不在首轮强加物理命名。

候选关系形式：e_ij = phi(h_j,r_ij,q_ij)；t_ij = (U h_i) elementwise_product e_ij；delta_i = W mean_j(t_ij)；最终分数为固定基线s_i + delta_i。小型非线性phi，U/W为共享投影；W零初始化。无有效邻居时明确delta=0。相同邻居因目标h_i不同可产生不同类别增量，增量可正可负；不执行邻船类别投票，也不强迫分类嵌入趋同。

这是待验证的低秩交互式关系读出，不宣称它优于注意力。先固定一个源端可承受容量（建议内部32维）；通过容量匹配对照判断设计必要性。平均聚合不依赖节点排列，但可能丢失密度，故邻居数量/覆盖另列共同输入及消融；不把截断后的数量伪装为真实海面船密度。

图构建初值建议物理半径1km、最多16邻居。这是操作起点，不是物理定律；源端覆盖分布若使几乎全无邻居或大面积截断，可在看到目标分类结果前修订一次并记录理由。若需比较半径，仅在源验证比较0.5/1/2km，各方法共用选定值，不按目标BA挑选。局部窗口不足以覆盖所需范围时只用已观测覆盖，或补统一检测；缺失不能当作零邻居。

## 4. 接入与任务不混用

近期24港A+D是八类源监督原尺度模型；F_0921历史桥接是七细类、双骨干目标支持适配。不得把其预测/标签空间直接拼接，也不得拿两套任务的旧分数差作为本模块增益。

首轮为源监督固定编码器的同协议重拟合：每个数据集冻结自己的标签词表、划分和输入版本；对基线及全部关系臂用同一合法源样本训练。邻居描述与目标描述共用冻结编码器。继续采用已有可复现的分类读出与分数目标，不在同轮另换骨干、损失或加入目标支持。各数据集使用合法的源侧统计/拟合，不能让目标船身份通过标准化或预训练偷偷进入。

旧A+D权重保持不变作既有参照，但若新目标集/输入/源训练划分改变，必须训练自己的匹配基线，不声称历史41.512%直接可比较。目标实例标签必须有实际可用对应；没有确认对应的候选只参与无标签上下文/可视化，不自动升为训练标签。旧预训练来源不能验证时披露暴露范围，不能宣称从未见目标域。

输入从可追溯原景/原分块按目标位置读取，保持像元尺度，不用已经缩放的128数组。画布需要完整容纳目标；超过画布不能切掉船体来凑固定尺寸。VV/VH使用对应地理窗口并分开读出，缺失保留状态，处理版本在所有方法中固定。

## 5. 核心比较与每项回答的问题

| 臂 | 内容 | 回答 |
|---|---|---|
| A | 同协议chip基线 | 不用场景信息的水平 |
| B | A + 邻居数量/距离/大小/无向排列统计 | 几何和布局本身是否够用 |
| C | A + 邻居视觉均值袋 + B | 新视觉信息是否有效，无需复杂关系 |
| D | A + 普通外观-几何关系注意力 | 已有关系方法是否足够 |
| E | A + 上述目标条件化低秩关系读出 | 所提利用方式是否增加价值 |

第一批A/B/C先跑，随后在同一任务上跑D/E，不以A/B/C必须先涨点作为开工门槛。公平限制训练样本、视觉来源、源验证选择机会和可训练参数数量级，报告精确参数/耗时。每臂3种子，先覆盖可用且身份/采集可隔离的任务，不无条件重训所有公开集。

主机制替换：固定每个目标的邻居集合及其图像，在训练开始即随机错配邻居描述与相对几何，测试按同规则处理，形成与D/E容量相同的训练对照。若E优于无图像袋但不优于错配，支持邻域内容有用，不支持正确空间对应必要。另作已训练E的逐边删除诊断；二者不同，不把删边分差当物理原因。

仅在出现“场景组成解释”疑点时增加同景远端、数量匹配的邻居替换，不自动无限追加。邻船概率传播暂不进入首轮；若下一轮加入，源训练时预测必须由合法独立预测生成，不能训练用真邻类、测试用预测类。

## 6. 划分、评价与结束条件

主评价按完整采集组留出；相邻切片同轨道/datatake合并，不把不同产品文件自动当不同观测。训练源验证与测试按已知MMSI隔离；源监督及统计不接触目标标签。目标场景中的无标签邻居全部来自该目标采集，记录这是可访问场景上下文，不是目标标签适配。

同景诊断若开展，应按空间块及船身份隔离，并考虑邻域半径的缓冲；不能随机分chip让同一物理对象或重叠局部几乎重复进入两侧。主结论仍由跨采集配对比较支撑。类别覆盖不足时明确该任务的固定闭集词表和目标实际出现类别，不用标签平衡采样来暗中改任务。

F_0921优先做可追溯五景子集，B529可先检查全幅上下文接口；它单景不承担跨场景泛化证明。对象对应完成后再冻结正式评估清单，不用保守唯一规则的一小撮冒充代表性全样本。若F源/目标可评价数量不足，24港中已有完整原景/检测/分类对应的采集承担补充机制验证，不混池或改标签凑类。公开集暂不自动全量下载。

OA、BA、macro-F1、逐类召回、逐采集配对增益、救回/误伤、3seed均值与标准差以及延迟/内存一并报告。按MMSI及采集的相关结构解释区间；只有少数独立采集时不拿大量chip伪装高确定性。低置信目标、近岸/开阔、稀疏/密集、覆盖完整/截断等分层在看目标正确标签前定义。几何有效范围取源端分布，不按测试收益选边界。

每轮回看持续正确/持续错误/救回/误伤的原尺度VV/VH、原景邻域、实际采用邻居及每条边的类别分差贡献。上述线性末层加均值结构可计算固定图上的逐边增量；删除边后若重新归一化，必须重算，不能直接当原增量相减。只能说明当前模型依赖哪里，不把邻近、注意力或预测相关性等同因果。

保留标准：在明确范围内可重复且值得新增计算的净收益即可，不要求全港/全类/每seed获胜。若只C有效，就保留简洁邻居补充，不硬造E创新；若E比匹配对照更好且正确空间关系替换能解释增量，才将其提升为论文核心候选；若所有臂都无收益，先定位对应、覆盖、重复检测、输入与训练/推理一致性及标签组成，再决定调整方向。禁止无限按目标结果调图/半径/标签。

## 7. 最小文献基础与阅读边界

Hu等，Relation Networks for Object Detection，CVPR2018，arXiv:1711.11575：已读原PDF方法。以外观和相对框几何构成关系权重，将其他对象的变换特征加回目标；几何使用相对位置及尺度比并嵌入，另有重复检测处理。任务是自然图像检测，不是我们当前的SAR跨采集分类。可借鉴关系基线，不能把外观+几何注意力本身宣称原创。

Zhu等，Beyond Homophily in Graph Neural Networks: Current Limitations and Effective Designs，NeurIPS2020：已读原PDF摘要、模型设计和实验相关段落。强调ego/neighbor分离、高阶邻域和中间表征组合等设计在异配图上的作用。任务是图节点分类，不是船群；它支持“不预设邻居同类”的设计方向，但不能证明真实SAR邻船确为异配或本模块必有效。

## 8. 四个真正改变设计的审稿问题

1. 是否只是看到更多图像？C提供同一邻居内容但不建关系，D提供合理已有方法；若C足够就不强称新关系算子必要。
2. 是否只记住港口或类别组成？不用港口ID，完整采集与身份隔离；必要时做同景远端、数量匹配上下文替换。即使只部分范围有效，也如实限定，不要求所有港口赢。
3. 是否只是邻船复制目标、标签泄漏或有标注密度？排除自目标/重复候选，只用检测目录，不按AIS/目标标签挑邻居；记录覆盖和源/目标输入协议。无标签邻船不需要被删。
4. 是否又只有总OA、没有为什么？同时保留类别分差、逐边增量、训练错配替换及原图正反例；相关贡献不等于真实物理因果。结果足够解释到哪一层，就写到哪一层。
