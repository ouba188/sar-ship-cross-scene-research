# Patch_Cal强响应尺度的source-only九头草案

2026-10-23。**仅设计文档，未实现/训练/新增提取；按主流程补充证据修订，训练暂不启动。** 建议检验两个Patch_Cal强响应尺度候选是否在冻结B及PNG可得信息之外有样本特异效用；不将它们称为精确丢失的归一化因子或精确反归一化，也不把普通校准包装为模块创新。沿用source fold0 train1542/validation279，不使用test。

## 依据与待证假设

已读inspect_sources.py、source summary及对应表定义。1821对象的Patch_Cal全部存在，3642极化band有限且非负；正确极化Spearman中位约.989-.994，交叉极化约.266-.270。固定255*sqrt(float/max)重构PNG的MAE中位.253-.256灰度，而强度maxnorm为8-12灰度。多数图近似这一关系，但中位数不能证明所有图采用同一显示算法。

主流程随后补充核验：约10%的样本MAE超过0.8-1灰度，最差7.585；幅度minmax更差。rawPatch为float32存储的整数幅度，与sqrt(Patch_Cal)在本图内近常数比例，PNG与rawmaxnorm的误差也相同。这支持两种数值表示的本图比例关系，却不能确定PNG都由最大值归一化生成；部分PNG可能提前饱和。上述补充为主流程报告，本支线未重复扫描。撤回此前将max解释成精确丢失因子的表述。

主流程拟做无标签像素拟合`p≈clip(a*sqrt(f),0,255)`，在未饱和像元上用through-origin最小二乘估计a，并报告完整残差与饱和行为；该工作尚不被本草案写成已完成，也不等于找到了官方pipeline。本轮不将拟合a自动加入候选特征或增加实验臂。

TIFF unit/description为空，产品abs_calibration_flag=0不是Patch_Cal单位声明。因此下文只称Patch_Cal数值或sqrt(Patch_Cal)尺度，不称Sigma0、RCS、绝对物理散射强度或已校准跨产品辐射量。

设f_p(x)是对应极化Patch_Cal，M_p=max_x f_p(x)>0，t_p=sqrt(M_p)，新增仍仅两个简单强响应尺度：

`s_p = log(t_p) = 0.5*log(M_p), p in {VV,VH}`，使用自然对数。t不是上述待拟合的显示斜率a，也不预设t=255/a。

只有对近似maxnorm、未发生额外提前饱和的图，PNG/255约等于sqrt(f_p)/t_p，PNG RMS乘t_p才近似sqrt(mean f_p)。这只是受限的数值解释，不是全队列恒等式。一般情形下s表示原Patch_Cal最大响应的对数尺度，不保证恢复PNG丢失的全部数值信息；饱和还可能丢掉局部高值差异。保留s是因为它简单、单chip可得且有明确来源，而非已证明它是正确逆变换。不另把float_mean、分位数、拟合斜率或极化比塞入模型。最大值可能受孤立强响应、噪声、处理约定影响，新数值信息不等于必然有分类价值。

可证伪假设：在相同采集与原尺寸、相近PNG/B观测条件下，本图两尺度比借来的两尺度更有助于源验证分类或概率预测。只能得到这批source条件下的证据，不能仅以own超过B认定样本特异有效。

## 固定共同信息与同容量头

冻结原A/T/W和每seed自己的B（17/29/43），不更换PNG、不重提R50、不加入局部矩或拓扑。两个PNG摘要都从原native像素计算，排除224 padding：

- `u_p=log(sqrt(mean((PNG_p/255)^2)))`，即同一个RMS摘要族的两极化值。
- `g_p=log(H_p*W_p)`，PNG可直接取得的像素数；它是共同尺寸控制，不宣称物理船长/面积。

共同12维为`[B-mean_class(B):8, u_VV,u_VH:2, g_VV,g_VH:2]`。最后加两个尺度槽，共14维。三臂名义同容量`14→16 GELU→8`，376参数，末层零初始化；输出减八类均值后加原B。无tanh cap、乘法carrier、额外温度或参数网格。各seed三臂初始化完全相同；禁用槽在scaler前置0。名义容量相同但summary臂有效输入维数较少，明确报告。

|臂|共同前12槽|最后两槽|回答的问题|
|---|---|---|---|
|png_summary|本图B/PNG RMS/像素数|0,0|便宜图像摘要与普通分类校准能否解释收益|
|own_scale|完全同上|本图s_VV,s_VH|正确附加尺度是否有增量|
|matched_scale|完全同上|配对donor的整组s_VV,s_VH|收益是否需要当前对象与尺度的对应|

不输入产品ID、pass ID、MMSI、AIS尺寸、真类、heading或支持对象。两个g可能相同（当前VV/VH同尺寸），保留固定接口并承认有效维数冗余，不为此另开架构。共同尺寸输入也不能从逻辑上保证消除所有尺寸关联，需配套替换对照。

## 固定错配规则

只提出一个规则，无随机seed扫描、无匹配阈值搜索。匹配先冻结，再训练九头。

1. train和validation分别处理，绝不跨角色借用。train同时遵守已有inner reader归属；同pass的held图原本由同一inner读出生成，仍显式记录。源OOF监督特征不换成outer训练内分数。
2. 硬条件：同pass_group、同两极化精确原H/W、不同MMSI。保持同采集及同原生像素数，不把浮点值、标签或结果用于候选筛选。
3. 硬条件内，以**预先固定seed17**的centered B八维及两PNG log-RMS组成10维匹配坐标。每维尺度仅用source train估计；validation复用。所有候选对按标准化欧氏距离、两个排序ID依次排序，贪心选择尚未匹配的最短边，确定性互换。这份匹配在三个训练seed间共用，不随其结果改变。
4. 交换整组VV/VH尺度，不独立打乱极化，保留donor自身的双极化关联。双方互换保证每个pass/精确几何块及整个角色中的尺度经验分布完全不变，因而不能靠改变整体尺度分布制造对照差异。
5. 不可匹配者保持自己的尺度并明确标记；不丢样本，不改规则凑覆盖率。九头训练/验证仍使用全部1542/279。报告全部及预先匹配子集上的own-vs-matched差异；若覆盖很少，结论就是此控制信息不足，不自动改成跨pass或跨尺寸置乱。

“近B/PNG”只由距离排序实现，没有宣称完全条件采样。错误标签不用于匹配；真实同类率、原B预测同类率、类别/尺寸/采集覆盖、距离、未配对原因均只事后报告。不同MMSI不等于独立采集证据。匹配使用本split源验证协变量作为诊断性干预，matched臂不是可部署推理方案。

这种构造保持块级尺度类别先验的潜在来源而破坏本对象对应：若own仍优于matched，证据比own优于零槽强；但不能严格排除块内类别组成、未匹配观测条件或未记录处理因素。因此禁止写“已排除所有采集/尺寸/class prior”，只写控制了上述明确条件。

## 拟执行预算与数据流

3臂×seed17/29/43=9轨迹，源标签/划分和既有预算不变：200步jointCE=.5普通CE+.5八类均衡CE，AdamW lr.003/wd.01；每5步源val J=(OA+BA)/2含0，严格更优才更新，平局最早。只用源train拟合各臂scaler；own/matched由于互换保持每角色尺度分布，其source scaler应数值一致，可直接核对。未用test选择，不额外比较其他损失、压缩、max替代统计或后验温度。

用source_correspondence既有`float_q1`（脚本中q=1，即原band最大值）提取s；不用float_mean/其他分位数。新增u只读对应PNG计算，不借浮点均值反推，否则图像控制已经使用额外Patch_Cal信息。同一对象/pol对应按产品元数据确认，不按波段亮度猜顺序。几何/尺寸来自PNG本身，不用AIS或标签派生物。

开始前只需完成主流程正在做的显示转换核实、匹配覆盖表、有限正最大值检查、sample ID与原source映射；发现真实不兼容则报告，不默默换数据。当前summary的四组最小M均>0；尚不把这当作未来输入保证。缓存可以含全cohort数组，但本实验只切source索引，不读test标签或输出测试预测。

## 什么结果支持什么结论

主比较固定为own_scale相对png_summary和matched_scale；同一批验证分别报告OA/BA、J、NLL、balancedNLL、Brier、救回/误伤和逐类变化。保留epoch0选择及完整train loss/sourceval曲线，不以挑出最好的seed或指标代替结果。

- own只优于B、却不优于png_summary：普通图像摘要/再校准足以解释，尚无附加强响应尺度的必要性证据。
- own优于summary、与matched相近：新增数值/其块级关联或优化影响可能有用，但本图对应的必要性未建立；不能称物理幅度机制。
- own相对summary与matched都有可重复方向，且不只来自未匹配部分/单一pass/少数类一两例：保留“与当前观测条件相匹配的Patch_Cal尺度有补充用途”的有限证据，仍不是独立目标确认。
- 持平、选0或退化：报告原样停止，不把“显示数值与Patch_Cal存在差异”偷换成“log-max应有收益”，不自动扩大统计库/换头；也不由这个简单尺度的失败否定全部原数值信息。

两个paired比较采用同样pass块与MMSI块区间，不择优；源val块数少时明确其不稳定性，3seed也不是3份独立数据。固定尺寸/采集分层与匹配子集用于判断收益集中在哪些样本，不据结果挑阈值或重新训练。报告GT同类率只能描述匹配难度，不能回头按GT换donor。

若后续授权执行，至少保存：九头checkpoints/scalers、预测/分数、selected/完整曲线、尺度与PNG摘要、train/val donor表（含未匹配）、配对metrics/类别/采集表。沿用主流程4张共享尺度原图；另对固定seed17结果四结局取首ID，并显示误配时真实donor的VV/VH及正确/错误尺度。缺失结局如实记，不能把donor外观或尺度差命名为真实散射原因。

## 单chip自足与未来回退

own_scale部署只需要当前chip的两路PNG与来源兼容、顺序明确、配准尺寸一致的两路Patch_Cal，使用固定source scaler和已冻结B/头；不用同批其他船、目标域均值、场景统计或标签。不要求部署做匹配，匹配仅用于研究对照。训练source统计拟合scaler与推理单chip自足不矛盾。

若任一极化float缺失、顺序/来源无法确认、配准不符、非有限/负值或max<=0，整条尺度增量回退原B，不填log(0)、不伪造均值尺度、不把另一极化复制过来。缺失分支没有训练支持，不宣称单极化可用；不另加missingness头。PNG摘要不存在的退化chip也回退B（前提是原B仍能合法产生）。新数据的数值单位/处理来源与当前Patch_Cal不兼容时同样不能无条件套用本头；本轮元数据不足，绝不声称跨产品绝对物理标定已解决。
