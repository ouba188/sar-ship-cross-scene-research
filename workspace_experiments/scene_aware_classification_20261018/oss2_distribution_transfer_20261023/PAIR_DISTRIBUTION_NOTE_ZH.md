# 类对局部分布：有界方法反思

2026-10-23。只读既有实现、报告及原图后的结论：**在已核对的当前读出实验链中，没有发现八类“先求类对空间响应差、再统计其局部分布”的等价实验。这个信息缺口在数学上成立；原图和错误提供了可检验动机，但尚未证明它具有额外分类效用。** 不实现模块、不提新特征、不训练。源端实际pair covariance及原图诊断由主代理另行负责。

## 1. 不等价具体缺什么

固定一个pol和C4视图，令footprint权重a和为1，mu_c=E_a[W_c F]，v_c=W_c F-mu_c，r_c=v_c-mean_class(v)。现有缓存只保留各类sigma_c=sqrt(E_a[r_c²])、kappa_c=E_a[r_c|r_c|]/sigma_c，以及mu_c；然后跨C4平均。

先类对差再做局部矩则是：

`t_cd = r_c-r_d = (W_c-W_d)(F-E_a F)`

`sigma_cd² = sigma_c² + sigma_d² - 2 E_a[r_c r_d]`

因此缺失的二阶量是**同一空间格、同一视图、同一极化上的交叉协方差**。它不是sigma_c-sigma_d、kappa_c-kappa_d，也不是全局分数B_c-B_d。类对kappa_cd=E_a[t_cd|t_cd|]/sigma_cd进一步依赖差分的非对称分布，仅有交叉协方差也不能完全确定它。

一个八类可容纳的反例：取两等权位置u=(1,-1)。情况A的前四类响应为(u,u,-u,-u)，情况B为(u,-u,u,-u)，其余四类为0。两情况每个位置类和均为0；所有类的均值、sigma、kappa逐类完全相同。但是第一/第二类的差在A恒为0，在B为2u，类对标准差分别0和2。故即使给一个更强的MLP全部现有边缘矩，它也不能普遍恢复被丢掉的同位置关联。

差分均值mu_c-mu_d本身不算新信息，已有mu就能得到。可能新增的是差分的中心分布，而不是把已有均值重命名成类对证据。

## 2. “消除共享响应”的准确边界

现有r已经消除了所有类共同的任意空间场：给每类都加g(p)，类中心化后不变。因此**不能把去全部类公共响应作为新类对方法的新增作用**。

类对差还有更局部的消除作用：若只有c、d共享h(p)，其他类别不共享，原类中心化后c、d仍各保留(1-2/K)h(p)，而r_c-r_d会将该项精确消除。等价地，同位置正相关会降低差分方差，反相关会提高差分方差；独立的两个边缘sigma无法判断是哪一种。

这只是代数消除，不证明被消除的就是噪声或无关背景。相关响应可能来自真实共享船体特征；正协方差也包括两类同时低于其空间均值，不等于“两个正峰共同出现”。类对sigma大也不表示真类获支持，交换c/d后sigma不变；有符号类对矩交换顺序则反号。当前没有论据把它命名为物理噪声剔除。

## 3. 已有实验覆盖到了哪里

核对了contrastive_spatial_pool/run_pool.py、signed_evidence_pool/extract_signed.py、八类extract_moments.py、local/mean/additive descriptor和四例spatial_cases分解：

- class_residual/contrast_residual/contrast_std在每类响应或类中心响应上分别做softmax/标准差，不是对每个c-d先求空间差再做统计。
- local/signed/polarization/mean/additive及本轮asinh都在边缘统计已聚合后处理。减类均值、对两个类的最终增量求差、把同一图的mean与local相加，都不会恢复上述交叉项。
- 既有精确贡献图是对各类非线性局部贡献分别求出后做margin差，例如g_c L(r_c)-g_d L(r_d)。这不等于先算t_cd，再做L(t_cd)。图可定位现有模型的粗格加减，但不是pair分布模块的既有有效性试验。
- 普通score校准即使包含全局28类对，也只重组已池化分数；不能从中反演逐空间格的类对关联。这个判断取决于输入层次，不取决于头是否叫pair或参数量多少。
- 原邻域/方向采样等历史模块不等价于此处固定源W下的八类空间响应协方差；不能用“曾建过关系”证明已检验同一信息。

**三类的一个重要例外：** 单视图内若r_1+r_2+r_3=0，则cov(r_c,r_d)=(sigma_e²-sigma_c²-sigma_d²)/2，故sigma_cd²=2sigma_c²+2sigma_d²-sigma_e²。在这个特殊维度中，三个边缘方差已约束全部二阶交叉量；不要笼统声称过去三类方差完全没有类对信息。但旧缓存先分别跨C4平均sigma，不能直接用该公式恢复“各视图类对sigma再平均”；有符号差分分布也不由三个方差决定。八类一般没有这种可恢复性，因此三类std结果不能替代八类pair检验。

## 4. 原图与错误：支持问题存在，不证明答案

本次重新实际查看OSS2原VV/VH四张PNG：000011为49×49，中心细短亮结构呈分段/双亮团，两极化上部伸展不同；000707为117×117，中央近横向多亮点，周围均见纹理。原图没有类别响应标签，不能直接判定哪一亮点对哪一类别共同支持或相互排斥。

既有冻结结果提供了具体竞争问题：000011的local把general误伤为offshore，真类虽增分，offshore增得更多，最高竞争者还从fishing变为offshore；000707的additive将crude救回container，两类都上调但container更多。这些是类别取舍事实，足以支持检查“同一亮响应是否同时驱动多个类方向”，却同样可能由B校准或边缘统计就能解释。

24港四例精确图中的0007746对旧rival6略改善、却因新rival3而误伤；0003504的负margin贡献落在中央目标相邻粗格。它们说明只盯真类增量或固定旧rival可能遗漏实际竞争，但已有图没有单独报告交叉协方差，不能直接作为“共享响应消除有效”的证据。原图相似而细类错误也不保证存在可被当前冻结W利用的类对信号。

因此已有材料支持的是：**应该从实际竞争类、同一格响应关联检查一个尚未检验的缺口**，不是证明特定pairreadout必然涨点。OSS2的OOF重尾、类均衡目标及旧/新基线信息差异仍同时存在，类对差不能自动解决它们。

## 5. GSoP/CSRA已有性与可能贡献边界

沿用此前实际核心方法全文阅读记录，不追加新文献搜索：module_novelty_review/READING_RECORD_ZH.md已记录GSoP CVPR2019第3.1–3.4节与CSRA ICCV2021核心方法。

GSoP已经通过通道/位置协方差建模二阶关系。固定W时，类别响应协方差就是W Cov(F) W^T；类对方差又是其中的特定二次型。因此“首次交叉协方差”“首次利用共同出现”或“首次二阶池化”均不成立。将全特征协方差限制到源监督的类别差方向，是任务坐标和读出范围的选择，不是新统计学原理。

CSRA用类别方向生成空间权重并作类别特定残差聚合，已有“分类坐标上的空间证据读出”基础；它并不因此等价于本候选的类对中心分布，但也不能把类别方向/残差读出本身称作首创。

有意义的贡献候选只能是：在冻结校准B及合法源辅助W的设定下，针对已证实的边缘矩信息损失，保留竞争方向的局部联合统计，并证明它比同信息预算的普通校准/边缘读出提供额外效用。该贡献还需主代理的源端数据诊断和后续受控结果支持，目前只是具体、可证伪的候选，不是已完成方法贡献。

## 结论

该缺口不是已有八类边缘矩换个小头即可补回，也未被robust36等价否定；数学上的新增信息明确。与此同时，**类对统计对位置的共同置换仍不变，它保留同格配对关系，不保留几何排列或邻接结构**，不能重新包装成空间布局建模创新。当前就停在这一步，等待主代理实际源pair covariance与原图诊断；不再启动模块、训练或新一轮搜索。
