# 几何数据来源恢复结果

日期：2026-10-16。已完成本轮可从历史原始记录恢复的部分；没有新训练、调阈值或覆盖旧结果。

## 一、结论

**缺失不能全部靠补文件解决，但这次确实补回了可用信息。**
当前固定局部读出队列为 8,622 个样本，不是整个 24 港数据集的全部样本。
输出文件保持全表 38,091 行，仅在此队列内补缺；队列外原字段保持不变。

| 字段 | 本轮前可用 | 本轮后可用 | 新增 | 本轮后覆盖率 |
|---|---:|---:|---:|---:|
| 船体轴方向代理 | 1,145 | 1,145 | 0 | 13.28% |
| 雷达地距方向代理 | 3,477 | 5,975 | 2,498 | 69.30% |
| 入射角 | 6,448 | 6,448 | 0 | 74.79% |
| 三项同时可用 | 961 | 1,145 | 184 | 13.28% |

这里仍是无向轴代理，不是真实船首航向或完整雷达波束几何。
数据恢复不等于分类收益；本轮没有生成新的 OA/BA。

## 二、补回了什么

### 1. 旧裁片与源影像的精确关联

4,289 个旧样本的 VV/VH 源 TIFF 路径此前未写入当前清单，现从原始裁片清单恢复。
关联同时检查实例 ID、极化、完整产品名、裁片文件名和原始目标像素坐标，不按港口近似匹配。

其中 1,711 个样本找回 VV 地理参考：1,675 个直接来自精确源路径头信息，36 个由同产品原整景头信息及原有 4×4 重叠切块规则恢复。
这 1,711 个坐标全部与另存的历史精确裁片坐标吻合，最大差异约 1.1e-9 米，属于浮点误差。
这是历史资料间的一致性验证，不是独立实地测量证据。

### 2. 产品注释和方向网格

原来缺雷达方向的 5,145 个样本涉及 87 个产品，现已备齐 87/87 个完整注释及五字段网格。
先恢复 4 产品覆盖 787 行，再扩展 83 产品覆盖其余 4,358 行。
实际使用历史保存的完整 SAFE 注释，不需要下载整景影像；网格保留 line、pixel、latitude、longitude、incidenceAngle。

新增可用雷达方向 = 原有地理参考但缺网格的 787 行 + 新恢复 VV 地理参考的 1,711 行 = 2,498 行。
仍须通过原来的网格范围与距离检查，不把“产品文件已找到”直接计为“样本字段有效”。

### 3. 一个缺裁切中心的样本

`returned_local_knowledge_0002695` 的 VV/VH 裁切中心从原始 server2 清单找回，且与实际 PNG 尺寸核对。
按原船轴估计器重算后，VV 仍为 weak_or_cluttered，故没有增加有效船轴。
此前 3,075 个弱响应/缺有效视图和 43 个极化不一致的拒绝判定保持原样，没有降阈值补值。

## 三、对现有任务有什么实际影响

本轮新增雷达方向中，184 个样本原本已有船体方向与入射角，因此完整几何覆盖确实增加。
以下按固定 S32 任务、原支持/查询及原启用规则计算，不改变抽样。
“青岛/上海”在此为留港任务名称，对应的 fit/selection 材料来自该任务合法源端，并非取其目标标签训练。

| 任务池与阶段 | 完整几何可启用任务数：前→后 | 可启用独立查询样本：前→后 |
|---|---:|---:|
| 青岛任务的源端 selection / cross | 0→10 | 0→176 |
| 上海任务的源端 fit / cross | 0→8 | 0→16 |
| 新加坡 target / cross | 0→15 | 0→43 |
| 新加坡 target / same | 5→15 | 13→43 |

查询样本会跨支持抽样重复，不能把事件数当成独立样本数。
只要求船体方向可用、其他角度允许缺失的版本，任务覆盖不变。
但其中原来缺雷达方向的样本现在有了真实可用的方向输入，是否有帮助尚未训练验证。
早先“新增方向均落在船轴无效样本上”的判断只适用于上一轮恢复，不能沿用到本轮。

## 四、还缺什么，能否继续补

| 剩余缺口 | 数量 | 下一步所需条件 |
|---|---:|---|
| 雷达方向缺精确 VV 源地理参考 | 2,647 样本 | 原源 TIFF/可靠头信息或原投影与切块记录；仅产品注释不足以恢复自定义裁片坐标 |
| 缺双极化完整地理参考 | 4,358 样本 | 其中 1,711 已有 VV 但仍缺 VH；其余 2,647 两者均缺，不能借用 VV 冒充 VH |
| 入射角缺可靠当前裁片坐标 | 2,174 样本 | 恢复精确当前裁片定位后才可继续插值 |
| 已评估但船轴弱/不一致 | 3,119 样本 | 不是补产品文件能解决；需更合适的估计方法或额外可靠观测，不能保证都能恢复 |

以上缺口相互重叠，不能相加为样本总数。
历史表中 1,534 条 inherited_verified_sample_center 候选只验证过同 MMSI/产品关联，尚未证明对应当前裁片目标，不作为精确定位写入。

原 F 盘目前未挂载，历史远程源机器名也未解析到当前可达地址。要继续补余下源头信息，优先恢复原盘或提供当前可访问位置；不需要先全量重下 Sentinel-1。
本轮没有获取新的训练标签，也没有通过测试标签选择恢复结果。
