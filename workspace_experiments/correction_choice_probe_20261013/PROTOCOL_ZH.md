# 原版与关系校正版选择：小规模可利用性验证

2026-10-13，用户批准。只训练低维线性选择器，不训练骨干、不改原分类器、不覆盖旧输出。

## 问题与证据链

已有关系校正既救回也误伤，概率风险门控不稳定转化为BA收益。本轮检验：预测分歧与支持集折外净效用能否预测**修正相对原版的优势**，而不是只检测原模型是否错误。存在oracle空间不算可利用性通过。

## 冻结设计

- 只做B16、关系校正dose=1。动作是raw完整融合或initial完整融合，不是基础分支与专家交接，不宣称节约骨干计算。
- 训练：复用21源港FIT中的3船只折x3支持抽样x3几何版本=27个episode，取已缓存fusion[0]与fusion[8]。几何版本复用船只，不能称为27个独立任务。
- 两种固定L2逻辑回归C=0.1，最大1000次迭代：8维预测分数特征；加8维支持净效用/覆盖特征的16维完整版本。每种分别训练pooled以及三个context版本，共8次小模型拟合。三港各用本港context的9个FIT episode；external用pooled27个。无参数搜索，阈值固定0.5，无目标港标签选择。
- 监督：initial对/raw错为1，raw对/initial错为0；两者同对或同错不提供相对偏好。先按整个episode的真实类别频数计算BA权重，再过滤事件；不重新平衡正负事件。27个episode等权，重复几何与抽样只作为开发暴露。
- 支持可靠性来自3次4折按船分组OOF，两种读出都重算；initial仅变换训练折。先平均同一支持行的3次概率再判断对错，不把重复预测当作48个标注。每类救回/误伤/中性采用固定Dirichlet(1,1,2)平滑，输出净效用均值及标准差。预算仍为16。
- 选择器输入不含真实查询类别、港口名、船身份、绝对类别ID。支持效用通过raw预测类/initial预测类这两个角色读取；类别覆盖比例和整体均值作为上下文。
- 对照：raw、initial、两者最大概率更高者、源FIT类均衡净效用决定的常数动作；已有light/combined/initial_guard在可用的外部缓存上保留为参照。

## 评价范围

1. source HELD：3版本x3抽样=9个episode，读出层与选择器未见船，按真实港口另行汇总；不是三个新港口。仅评价，不调参。
2. 历史留出港：Los Angeles、Port Klang、Santos，各5个历史支持组合，共15单元。各港selector只用对应context，不能合并其他context，因为其上游源头/几何可能包含本港。沿用逐港模型和行级查询协议，不宣称全部预训练未见评价船或目标支持/query跨船。
3. F_0921/OSS2：复用joint_support_correction已冻结的legacy/new各5组，每数据集10单元。new指前轮新增支持组合，本轮不冒称新采集或新抽样。这里也是开发数据复用，非独立确认。

外部source FIT存在已知MMSI重合。除完整历史查询结果，预先固定附加评价：排除全部1296 FIT行对应已知船身份的query，保留相同模型/支持/决策。未知身份单列计数，不冒称严格未见船确认。pooled多context上游与external源过滤不完全一致，因此外部是已训练模型的开发性迁移，不是整个上游监督链严格identity-held。

主要结果：各任务/抽样完整OA/BA，对raw与initial的配对增量、救回保留/误伤避免、成本。辅助：救回vs误伤的加权AUC、改用initial比例、类别贡献；oracle仅诊断。三港先抽样均值再等港均值，source三几何分别保留且不当独立港。

目标预测全部写入后才读目标查询标签评价。已知已有目标性能用于提出假设，但不能用于选择本轮参数。支持OOF只给训练信息，不是选择器独立验证。

## 最少验证与决策

- 检查事件符号与全类分母，防止误伤被当正收益或稀有类权重错误。
- 检查重复OOF不放大标注量，以及输入对类别一致重排不变，防止身份捷径。
- source raw/initial及目标支持读出与已有缓存重放，检查上下文、行号、融合和校正接入。
- 冻结后比较收益：若有范围内可重复净收益则保留；若只在FIT有用，区分过拟合/关系迁移失败与目标信息不足，不继续目标调参或扩建复杂模块。
