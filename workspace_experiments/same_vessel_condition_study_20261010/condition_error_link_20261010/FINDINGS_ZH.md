# 条件向量是否知道同船分类判断如何变化

## 结论

这轮出现一个有限但可保留的正信号：关系监督得到的32维条件向量，能帮助预测同船两次观测之间分类间隔的变化幅度；但它没有可靠预测变好或变坏，整体也没有优于普通上下文。当前更接近“波动提示”，还不是可直接使用的“纠错指令”。本轮没有测得完整模型OA/BA提升，也没有识别出纯噪声或物理因果因素。

## 实验如何进行

- 固定R18分类器：只用源fold1的834张图、292艘船拟合，八类均在。
- 误差变化预测器：只用源fold2的910张图、313艘船训练。其中203艘有可用同船异景时序对，共3019对。
- 最终检验：源fold0的823张图、302艘船。其中200艘有可用时序对，共1492对。
- 三组船舶身份互不重合；训练和检验使用同一个固定分类器，不把不同分类器的变化当作观测变化。
- 条件向量与普通上下文编码器沿用已有权重，原训练使用源fold1+2。fold2并非编码器未见身份；fold0才是本轮表示学习的留出身份。
- 按真实观测时间由早到晚配对，排除同一大景和同时刻，不按分类结果挑选方向。每艘船总权重相同，避免多时相船舶主导。
- 目标为真实类分数减最大其他类分数的变化。真实类别只用于训练目标和评价，不作为预测器输入；没有对特定船型定制抑制规则。
- 同时预测有符号变化和绝对变化；分别对应变好/变坏和变化幅度。有符号变化并不总会导致分类翻转。
- 读出采用固定正则强度10的岭回归。线性版输入坐标差，交互版另加入“坐标中点×坐标差”，无测试集调参或选择训练轮次。
- 比较普通上下文32维、条件32维、稳定128维、原始512维、原始PCA32维以及固定分类器最大分数/前两类间隔这两个置信度量。

这是已有两次观测的回顾性解释，不是提前预测尚未获取的观测。固定分类器及骨干的历史数据暴露沿用此前设定，不是独立外部确认。

## 留出结果

下表是交互版。误差降低比例均相对于对应常数基线：方向任务以“不变”为基线，幅度任务以训练船的平均幅度为基线。正值更好，负值更差；不是分类准确率涨点。

| 输入 | 有符号变化MSE | 有符号预测误差降低 | 幅度MSE | 幅度预测误差降低 |
|---|---:|---:|---:|---:|
| 常数基线 | 0.632060 | 0% | 0.313162 | 0% |
| 普通上下文32维 | 0.619712 | 1.95% | 0.259799 | 17.04% |
| 条件向量32维 | 0.704273 | -11.43% | 0.280470 | 10.44% |
| 稳定向量128维 | 0.625515 | 1.04% | 0.249598 | 20.30% |
| 原始PCA32维 | 0.704003 | -11.38% | 0.190153 | 39.28% |
| 原始512维 | 0.639155 | -1.12% | 0.184316 | 41.14% |
| 分类器置信度2维 | 0.566383 | 10.39% | 0.142174 | 54.60% |

原始特征和置信度来自生成分类分数的同一模型，天然更接近被预测量。这些是任务信息对照，不能作为找到了物理原因的证据。

条件线性版的有符号误差降低为-2.83%，幅度误差降低为4.12%。因此失败不只发生在增加交互项后；交互增强了训练拟合，但有符号泛化反而更差。

按200艘检验船进行2000次聚类bootstrap，固定模型不重新训练：

- 条件交互版幅度MSE减常数基线：-0.032692，95%区间[-0.064844, -0.005339]。这是本轮可保留的正信号。
- 条件交互版幅度MSE减普通上下文：+0.020671，区间[-0.010993, +0.056594]，没有优于普通上下文的证据。
- 条件交互版有符号MSE减普通上下文：+0.084561，区间[+0.002773, +0.175240]，本次切分下反而较差。

区间仅反映本次固定训练和留出船舶抽样，不包含多次训练、跨场景簇相关或多重比较的不确定性，不作为最终方法确认。

## 真正分类翻转的样本

1492对中393对发生对错翻转，其中197对正确变错误、196对错误变正确。条件交互版在这些配对上判断方向的准确率55.68%、AUC0.586；普通上下文54.15%、AUC0.581。这个差异很小且没有单独确认，不能说条件向量已经会纠错。

仅在首次分类正确的配对中，条件交互版对随后变错的排序AUC为0.620。这是事后按真值分组的诊断，不是部署时可直接知道哪些首次预测正确。不能把这一结果写成可上线的错误检测能力。

## 为什么没达到预期

### 已有证据

1. 不是完全没有学习：条件交互版在训练船上的有符号MSE相对零变化降低37.65%，到留出船变成-11.43%；普通上下文分别为30.97%和1.95%。当前主要现象是训练关系未充分迁移，而不是参数没有更新。训练身份曾参与编码器学习，也可能扩大这段落差。
2. 不是所有任务信息都无法预测：两维置信度对照能降低有符号误差10.39%，降低幅度误差54.60%。不过它直接读分类器输出，不能证明条件分支也应当达到同样水平。
3. 条件监督没有表现出独特任务收益：普通上下文的幅度结果更好。已有“更能区分场景关系”的结果，不足以推出“更知道哪些变化会伤害分类”。
4. 不是只在跨港配对上出问题：同港配对137艘、1013对，跨港配对116艘、479对，两组有重叠船。条件交互版有符号MSE分别0.684457和0.672486，均高于各自零变化基线0.614026和0.639834。
5. 跨港幅度存在小线索：条件交互版MSE0.270750，普通上下文0.276462；同港分别0.272579和0.250844。跨港的小优势是事后分组描述，没有单独确认，不能据此选用条件版。

### 仍待检验的解释

条件变化方向与“分类受益还是受损”的映射可能依赖当前判别状态，单独用条件坐标不够；也可能条件分离监督保留了场景差异，却未保留可迁移的任务敏感信息。本轮不能在两者之间定论，也不能将所有变化归因为物理噪声。

758/823张留出图所在大景在编码器训练身份中出现过，所以本轮主要说明新船身份上的表现，不是严格未见大景或新港泛化。即使在这一较宽松条件下，也尚未看到条件版独特的纠正方向优势。

## 建议的下一步

不要继续把这32维直接转成抑制或放大指令。若继续开发，最小有价值的下一步是检验：给定已有分类状态以后，条件向量能否额外预测可靠性下降。必须与置信度单独输入及置信度加普通上下文同容量比较，使用身份隔离的训练外残差目标；只有取得增量收益，才考虑将其用于有限修正或专家交接。这一项尚未实施。

如果条件向量没有额外信息，就保留本轮幅度预测观察，不再凭“它区分场景更好”推动模块接入，转而改造因子学习目标。
