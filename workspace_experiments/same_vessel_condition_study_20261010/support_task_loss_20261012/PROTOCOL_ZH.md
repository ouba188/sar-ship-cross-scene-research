# 同一支持修正器的重建监督与完整任务监督

日期2026-10-12。本轮接受准则：在明确论文任务范围内，存在可重复、值得成本的净收益即可认可；不要求每港、每类、每个预算和每次抽样均获胜。局部负结果用于界定范围和指导改进，随机波动可接受，但不能未经证据就将退化解释为随机性。

## 范围与对照

沿用8类跨港SAR识别、B16/64/128、3个冻结几何版本、现成合法排除源先验和基础分支。当前先做源留出可行性，不新增骨干、数据集或物理因果声称。

两种训练目标共享同一个576输入/输出仿射残差修正器，332352个可训练参数；以原同类其他船均值监督模型初始化。骨干、基础分支、源先验、查询表示、支持质心/能量匹配、等权概率融合全部冻结。

1. 重建监督：预测同类其他船的特征残差，按源类别/船权重计算MSE；除以固定源目标能量以改善数值尺度，此正比例缩放不改变重建目标的最优解。
2. 完整任务监督：支持端修正后重新计算K_SS/K_QS，按原类别权重、signed one-hot目标与lambda(B)=8B/64求解，再与冻结基础分支等权概率融合，以查询类别均衡交叉熵训练。梯度须经过真实求解和融合，不把概率直接当logits送入交叉熵。

保留不训练的原修正器、无修正模型和最新源选简单衰减作为对照。修正剂量固定沿用之前源端专家选择的1/0.5/0.25，不在本轮重选。简单对照沿用源端完整模型选择a=0.25/1/1，不从本轮目标结果调参。

## 数据、训练与冻结

- 1296条源拟合观测均可供两种目标使用；原初始化器曾只用其中1040条多时相观测。如今同类他船目标可覆盖单观测船，两种训练目标共同扩展到1296条，明确披露，不把数据变化仅归于损失。保留旧初始化结果以区分继续训练与新增数据的作用。
- 同类均值目标仅用源拟合观测，排除焦点整船。不使用源留出或目标查询标签生成目标。
- 按原3个船级fold构造训练episode，OOF基础/专家先验排除当前fold和全部留出船。每个episode先取32条不同船查询，再取128条不同船支持；每船随机一条观测，支持前缀嵌套到16/64/128。同一预算块的查询保持不变。
- 两个随机种子31415/27182控制训练episode抽样与顺序。每个几何版本、每种目标、每个种子都训练90步AdamW，学习率1e-4、weight_decay=1e-4。两目标使用完全同一episode序列；没有损失系数组合或学习率网格。
- 固定第90步模型，不用留出标签早停或挑checkpoint。第0/30/60/90步的拟合probe只在源拟合数据上做学习诊断，不是独立验证。
- 先冻结全部12个修正器，再生成源留出预测，最后评价。源留出使用原3组支持、固定418条查询/156条船；源几何版本共享船，不能当作独立港。

## 评价与成本

主报告完整系统的配对OA/BA，并区分相对原修正器、继续重建训练、简单衰减的收益。报告两训练种子、各支持抽样、预算、几何版本/实际港类的差异，保留概率风险和特征拟合改善，不能用任意一种替代其他结论。

少量重叠支持抽样不是独立样本；只描述配对均值、范围和胜平负，不自动声明显著性或纯随机退化。新任务训练与重建训练推理结构/参数量完全相同；记录实际训练耗时，不把理论相同结构当成完整端到端计时证据。

如果源留出存在与论文目标一致的可重复净收益，则在模型、预算与规则冻结后继续3个历史目标港；无需全部预算/类别同时胜出。若只有训练误差下降、没有任务相关留出收益，先进行有限根因诊断，而不直接扩大网络或盲目调参。历史骨干/几何源暴露和既有目标行级排除限制保留。
