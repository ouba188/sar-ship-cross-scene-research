# 补入判断状态，能否释放条件向量的增量价值

## 结论

本轮没有发现现有条件向量在分类判断状态之外提供可迁移的增量价值。“此前只是缺少判断状态”不足以解释失败，但尚不能据此认定因子学习目标就是唯一根因。

补入状态后，条件版的有符号变化MSE从上一轮交互版的0.704273降至0.556078；然而只用状态就达到0.474049。前后轮读出结构不同，这个前后降幅不能直接归因于条件信息被激活。真正的同轮比较表明，加入条件向量未改善状态基线。

预先设定的8维低容量版也没有恢复增量收益。当前证据是“训练拟合改善、身份留出恶化”，与不可迁移的关联或过拟合相符；不足以证明所有条件信息无用，更不是纯物理噪声识别。

## 对照设计

沿用上轮固定划分和配对：源fold1的834张/292艘用于拟合固定分类器；源fold2训练变化预测器，其中203艘形成3019对；源fold0最终检验，200艘形成1492对。三组船舶身份互斥。

判断状态包括八类原始分类分数、最大分数、前两类分数间隔。没有给预测器真实类别，也没有逐船型定制规则。

| 对照 | 输入 | 有符号任务参数量 |
|---|---|---:|
| 简单状态基线 | 判断状态的一、二阶项 | 65 |
| 等容量状态32 | 状态 + 从状态二阶项提取的32维PCA坐标及交互 | 449 |
| 状态+普通上下文32 | 状态 + 普通32维上下文及交互 | 449 |
| 状态+条件32 | 状态 + 关系监督条件32维及交互 | 449 |
| 等容量状态8 | 同上，仅使用8维状态派生坐标 | 161 |
| 状态+普通上下文8 | 上下文源训练PCA压到8维 | 161 |
| 状态+条件8 | 条件源训练PCA压到8维 | 161 |

等容量状态组没有新信息，额外坐标完全由状态派生；用于区分“模型参数变多”和“新条件信息”。参数量相同不意味着相同有效秩或完全相同函数空间，因此同时保留简单状态基线，不仅与可能更易过拟合的大模型比较。

每张观测先构造状态二阶项，以及上下文、上下文平方、状态与上下文的两两乘积。两次观测的有符号差用于预测变化方向和数值，绝对差用于预测幅度。交互项允许相同条件变化在不同判断状态下有不同效果，而不是只拼接线性输入。

所有模型固定岭正则10，一次解析拟合，无测试集调参。各特征块按自身维数归一化，添加上下文时不改变状态块本身的归一化。幅度模型多一个不受惩罚的截距。32维为主比较，8维是结果出来前规定的低容量诊断，不根据留出效果选择部署模型。

编码器冻结，普通和条件编码器均来自此前源fold1+2训练。所有归一化和PCA仅拟合fold2，不使用fold0或目标港标签。

## 主要结果

MSE越低越好，预测目标仍是“真实类分数减最大其他类分数”的两次观测变化，不是完整模型OA/BA。

| 输入 | 有符号变化MSE | 变化幅度MSE |
|---|---:|---:|
| 简单状态基线 | **0.474049** | **0.080945** |
| 等容量状态32 | 0.541421 | 0.132988 |
| 状态+普通上下文32 | 0.523691 | 0.085269 |
| 状态+条件32 | 0.556078 | 0.088196 |
| 等容量状态8 | 0.465625 | 0.091478 |
| 状态+普通上下文8 | 0.503890 | 0.086751 |
| 状态+条件8 | 0.549743 | 0.090340 |

条件32相对简单状态基线，有符号MSE增加17.30%，幅度MSE增加8.96%。相对普通上下文32，两项分别增加6.18%和3.43%。幅度上的小差异没有明确统计支持，不能写成已确认退化。

条件32的幅度结果虽然好于等容量状态32，但不如更简单的状态基线，也不如同容量普通上下文；不能只挑前一项比较声称条件模块有效。

## 不确定性

按200艘留出船进行2000次bootstrap，以下为条件版减对照的MSE差，负值有利：

| 任务/条件维数 | 对照 | MSE差 | 95%区间 |
|---|---|---:|---|
| 有符号/32 | 简单状态 | +0.082029 | [+0.047633, +0.122846] |
| 有符号/32 | 等容量状态32 | +0.014656 | [-0.069053, +0.111783] |
| 有符号/32 | 普通上下文32 | +0.032387 | [-0.004565, +0.069840] |
| 有符号/8 | 简单状态 | +0.075694 | [+0.044647, +0.109737] |
| 有符号/8 | 普通上下文8 | +0.045853 | [+0.006842, +0.092408] |
| 幅度/32 | 简单状态 | +0.007250 | [-0.002643, +0.021624] |
| 幅度/32 | 普通上下文32 | +0.002927 | [-0.004296, +0.011905] |

这些是固定训练、固定数据切分的船舶抽样区间，不包含多次训练、共享大景相关和多重比较的不确定性。本轮沿用了已用于研究诊断的留出船，属于开发诊断，不是新独立确认。

## 原因排查

### 1. 判断状态确实接入了，不是只增加一个名字

实际包含状态与上下文乘积；单元测试确认改变状态能改变交互响应。有符号配对反转时预测严格反号，幅度配对反转时输入不变。源训练拟合明显改善，也不支持“优化完全没生效”。

原固定分类器在全部3019训练对和1492检验对上重算目标，与上一轮配对文件最大差4.44e-16；观测ID和fold逐一对应。没有通过更换分类器、配对或真值制造差异。

### 2. 条件版仍然主要改善训练拟合

| 输入 | 训练有符号MSE | 留出有符号MSE |
|---|---:|---:|
| 简单状态 | 0.279169 | 0.474049 |
| 状态+普通上下文32 | 0.164668 | 0.523691 |
| 状态+条件32 | 0.187493 | 0.556078 |
| 状态+条件8 | 0.209019 | 0.549743 |

这支持“目前学到的额外关联没有迁移”，而不是“只缺少当前判断状态”这一充分解释。压低维数没有解决问题，但这不是完整学习曲线，也不能排除更多源船舶或其他正则方式会有效。

### 3. 问题不只出现在某一港口配对类型

同港1013对/137艘：状态基线、普通32、条件32的有符号MSE分别0.443408、0.510180、0.527806。

跨港479对/116艘：分别0.402919、0.449110、0.481345。两个子集有重叠船，不能将其船数相加。这只是分组诊断，不是统一所有观测条件后估计的港口因果效应。

### 4. 能分清到哪里

可以收窄：在本轮交互方式、已有样本和固定读出下，补判断状态没有让现有条件向量产生独特增量；“缺少状态”不是充分解释。

还不能定论：因子监督目标不合适、训练身份依赖、样本支撑不足、可用信息已包含在状态中，这几种解释仍可能并存。负结果不证明信息论意义上绝无额外信息，也不证明分离出的坐标是真实物理噪声。

## 下一步边界

本轮仅完成批准的第一步，没有重训因子编码器或改主模型。若继续，应固定此处的状态基线和评价，把实验变量移到因子学习目标：让条件分支学习对未参与分类器拟合的源船舶，哪些观测变化会伤害判断；对照旧场景关系目标，保留普通上下文和低容量比较。

必须先按船产生训练外监督，不能用训练船的低拟合误差当可靠性标签。只有新目标相对旧目标和状态基线同时有增量，才支持目标错配解释。否则应停止将此条件分支作为纠错模块推进，而不是继续叠加状态输入。

## 适用范围与文件

这是源域留出船的双观测回顾性诊断，不是单张测试图的部署评估。判断状态直接来自生成被预测间隔的同一分类器，较强结果不代表它揭示了SAR物理成像原因。

758/823张留出图所在大景在编码器训练身份中出现过，骨干历史暴露沿用旧设定；没有新的严格留场景、留港或外部数据确认。

全部代码和结果位于侧会话目录，CPU单线程，未修改主线程模型或作业。

- `metrics.csv`、`predictions.csv`：完整训练/留出两类目标结果和逐配对预测。
- `ship_bootstrap.csv`、`port_groups.csv`：不确定性和分港关系描述。
- `replay.csv`、`protocol.json`：目标重算与协议。
- `coefficients.npz`：所有固定读出系数。
- `../condition_state_link.py`、`../test_condition_state_link.py`：实现与三项通过的针对性测试。
