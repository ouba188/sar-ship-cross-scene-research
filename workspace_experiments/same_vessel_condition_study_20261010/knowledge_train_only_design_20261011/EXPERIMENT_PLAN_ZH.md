# 下一轮实验设计：训练期知识锚定，预测期只使用 SAR

日期：2026-10-11。状态：**设计与数据可行性核查，不是已完成的训练结果。** 本轮没有启动神经训练，没有修改论文主模型。

后续执行记录：用户已批准继续。尺寸掩码及源船三折可读性探针已完成，结果另存 `../knowledge_train_only_20261011/PROBE_FINDINGS_ZH.md`。原方案保留为开训前记录，不将以下计划文字冒充执行结果。执行中的条件读出使用真实船型只作诊断，不能用于部署；是否继续只看源三折，不看源留出或目标港。

## 1. 要回答的一个问题

在相同 SAR 输入、船型标签、模型容量和支持预算下，**训练时增加有来源的 AIS 船体属性监督，能否帮助单图模型学到跨船、跨观测条件仍有用的判别证据？**

保留用户提出的工作假设：存在微弱但可利用的因果相关成分。实验不要求每个隐向量有唯一物理含义、不要求绝对不变，也不以大幅涨点为成功门槛。但不能预先假定现有数据一定能恢复这些成分。

本轮与之前的实质区别：给表示增加外部实体属性的参照，不再把“可预测的图像变化”直接定义为应当删除的干扰。

若真实知识没有产生独特收益，应同时保留“当前学习方式未能利用”和“该知识不足/不能从当前 SAR 中读取”两种解释，不自动增加下一模块。

## 2. 严格的部署边界

训练时可以使用源训练船的真实尺寸、MMSI 同船关系、其他采集图像及成像元数据；这些内容不作为学生网络的输入。

```text
训练：
单张 SAR -> 冻结已有图像编码器 -> 可学习32维证据 -> 船型分数
                                      |
                                      +-> 训练期属性头 -> 船长/船宽监督
同船其他采集 -> 冻结教师 -> 多观测教学目标 ---------^

评估分析：入射角、相对方向、身份等只用于分组计算指标

预测：
单张 SAR -> 同一图像编码器 -> 32维证据 -> 船型分数
                                      + 既有支持集残差校正
```

预测图中没有属性表、MMSI 查询、真实船型、角度、方向、港口编号、历史同船图或教师调用。训练期属性头从部署包删除。不能把文件名、路径中的类别或身份解析为预测特征。

这里 SAR-only 指**不使用额外知识或元数据作为预测输入**；沿用已接受的 64 个标注支持样本预算，支持集建立后单个查询只输入 SAR。不是把任务偷偷改成零目标标签识别。支持图像也只经过 SAR 路径，不读取其外部属性。

## 3. 知识选什么

### 3.1 第一优先：真实船体属性

本文件的“真实知识/真实属性组”指使用船舶实际 AIS 报告，而非类别均值或 SAR 检测框造出的标签；不表示报告值已经独立核验为物理真值。正式结果统一称“AIS 报告属性监督”。

- 第一候选为有来源的 AIS/船舶记录船长 L、船宽 W；有效值必须为正、单位明确、可以通过身份可靠对应。
- 两个训练目标为源训练统计标准化的 log(L)、log(W)；长宽比作为派生诊断，不另加重复监督项。
- SAR 检测框长宽、裁片像素长宽、从同一 SAR 预测的尺寸，不冒充外部真实尺寸。
- 不能按船型均值填补缺失并称为真实知识。类别均值只用于明确标记的对照组。
- 同船重复记录按身份汇总，检查明显冲突；未解决的冲突不参与属性损失。所有图像仍参与相同的船型监督，不因知识缺失更换分类训练队列。
- 不查询目标船型，不把 MMSI 当网络特征。若登记来源本身由评估标签派生，不能用作独立属性证据。

### 3.2 本轮几何知识的角色

当前 observations.csv 与既有 cohort 的只读核对：源训练 1296 张/525 艘中，855 张有入射角、103 张有相对方向；源留出 823 张/302 艘中分别为 523、73 张。这是当前字段非空覆盖，不等于所有记录都完成额外精度验证。

首轮**不新增角度门控、方向网络或变化抑制项**。角度用于训练源内可读性诊断和最终条件分层评估；MMSI/采集编号用于训练多观测教学及身份隔离。相对方向样本少，先作探索性诊断，不作全样本必需条件。

角差沿用已有 <2 度、2–5 度、>=5 度诊断区间，保留未知组，不看到结果后改区间。成像条件分组只衡量效果在哪里成立，不把组间差异直接当因果效应。

这一取舍是为了先区分外部实体属性是否有信息增量。几何条件指导教师筛选仍是后续备选，**不在首轮同时上线**。

## 4. 开训前的最小可行性检查

### A. 真实属性是否存在、能否对齐

核查原始字段、单位、join key、source-fit/validation/held 的观测与船身份覆盖、按类别覆盖和同船冲突。结果见同目录 KNOWLEDGE_INVENTORY_ZH.md。仅找到总表字段不等于完成同船对齐。

本轮已核实 AIS 导出字段来源并完成 fit/held 联结。源训练 1296 次观测中，1140 次可找到同产品唯一正数长宽对；再要求已读同船记录只有一个尺寸对，剩 1104 次/496 艘。留出相同口径为 699 次/285 艘。这是候选覆盖，不是完成异常审查后的合格覆盖；新船验证集的属性覆盖尚未单列核查，其分类验证不依赖属性。

首轮候选监督采用上述交集，以同产品原始联合长宽对为值，不拼接两个字段各自的众数。已读记录冲突以及 L<=W、L>=500 米、L/W>30 的待核实记录暂不进入属性损失；这些阈值仅用于标记本批明显异常，不能写成普遍船型定律。开训前固定并导出最终掩码、按类别覆盖及剔除原因，C/D 共用。所有观测仍保留分类监督，留出属性只供事后诊断。

对象 JSON 必须按 UID 联结，不能依赖旧对象数组下标；审查已发现79个视图下标不一致。AIS 报告值未独立经船籍核验，也未核实是否参与历史标签细分，因此它提供的是新增监督参照，不是已知独立的因果真值。

没有可核验尺寸时，不以检测框或类别均值代替后开训；先处理数据来源缺口。此时不能把“尚未找到字段”说成数据中不存在相关信息。

### B. 当前 SAR 表示能否读到这些属性

计划使用既有三折源训练船划分，固定小型岭回归探针，从现有冻结 SAR 表征预测 log(L)、log(W)，不扫描正则强度。

比较：源训练全局均值、源训练类别均值、SAR 探针。类别均值使用真实类别仅供离线诊断，绝不能部署为 SAR-only 预测器。均值及归一化只能由各折训练船计算；同船重复观测等权，探针标签只来自对应训练折。

看两件事：总体属性误差，以及**同一船型内部**能否区分不同船的属性。若只达到类别均值水平，现阶段只能说属性与类别有关，不能宣称找到了额外个体结构信息。

此检查只决定当前属性辅助任务是否值得投入；负结果不证明原 SAR 图像完全不含信息，因为冻结表示或裁片尺度处理也可能限制可读性。不可据此自动改骨干继续搜索。

阶段 B 是拟议实验，**本设计轮未运行**。只在 A 有合格数据后运行；不评价目标标签或拟合目标属性。

## 5. 首轮四组对照

四组共享分类架构、训练图像、源标签、支持/查询抽样、随机种子和训练步数。训练期属性头结构均保留，仅开关对应损失；部署结构完全相同。

| 组别 | 本轮分数分支训练 | 回答的问题 |
|---|---|---|
| A：SAR 任务对照 | 船型监督 + 原64支持任务损失 | 本轮公平的普通训练基线 |
| B：多观测教学 | A + 同船其他采集的共享证据教学 | 多观测信息本身是否有用 |
| C：真实知识锚定 | B + 真实船长/船宽辅助监督 | 外部实体属性是否有新增收益 |
| D：类别均值对照 | B + 对应源训练船型的平均长宽监督 | 收益是否主要来自重复提示类别 |

**核心对比是 C-B 与 C-D。** C-A 只是总效果，不能全部归因于知识。

D 用与 C 完全相同的有效属性观测掩码、属性标准化、辅助头、损失系数与抽样；类别均值按源训练船等权计算，不按重复图像数量加权。C/D 不能因为缺失处理不同获得不同训练样本或计算预算。

不做全局置乱搜索。类均值对照已经直接针对“只是重复类别提示”的解释；如后续仍有具体未区分问题，再决定是否需要额外对照。

## 6. 可复用的具体模型与训练

### 表示与读出

复用已有冻结 R18 图像特征以及 CandidateProjector 的 512->32 投影、源协方差尺度规范化和8类线性头。新增 32->2 线性属性头，仅用于训练。不是重新做双骨干，不定义“其余维度都是噪声”。

案例匹配核固定为同种子的既有 source-case 输出；只训练分数/证据路径，避免本轮同时改变支持匹配几何。固定核有历史多观测训练，因此 A 只表示本轮分数分支不增加多观测教学，不声称整个系统从未使用过同船关系。

四组分数投影从相同源 PCA 与源分类头初始化，不用不同历史模型的最终数值直接相减。记录旧模型作为参考，但以本轮 A/B/D 为归因对照。

### 多观测教师

使用 source-fold 缓存中对该船完全折外的分类分数。每个锚点只聚合源训练同船的其他 product，排除锚点整个采集；同采集先平均，再按不同采集等权。source validation、held、目标港观测都不能进入训练教师。

首轮保留完整中心化分数教学，不新增整向量收缩，不把变化向量减掉，也不把教师置信度当成事实。教师可能出错，因此同时保留真实船型监督，并报告知识是否减轻或加剧教学冲突。

### 损失与预算

```text
L_A = L_class + 0.5 * L_support_episode
L_B = L_A + 0.5 * L_other_acquisition_teacher
L_C = L_B + alpha * L_real_attributes
L_D = L_B + alpha * L_class_mean_attributes
```

分类及支持损失沿用现有正负目标与平衡 MSE；属性损失用标准化 log 尺寸的平方误差，按船型/船身份平衡，有效掩码仅作用于辅助项。源均值/方差及属性头初始化仅用 source-fit。

alpha 预定上限0.1；在初始化的固定8个源训练批次上测投影参数梯度，若属性梯度超过主任务梯度的10%，只向下缩小到该比例。由真实属性组确定一次，C/D 共用，不按验证或目标收益扫描。梯度检查是防止辅助任务淹没分类，不是因果验证。

首轮种子 31415、27182，4组共8次微型拟合，每次400步、Adam 0.001，监督批次128、每步64支持/96查询，支持/查询按船隔离。沿用数据抽样模式，不把400个重复任务称为独立实验。

每20步评价一次，包括step0。全部新组只用既有新船验证集选择：先平均 BA，BA数值相同时选平衡 CE 更低者，再同分选更早轮次。此规则在新实验运行前固定，不追溯修改旧实验，也不让源新时相身份重叠验证影响本轮主选择。

若要进一步确认微弱正信号，可预先指定第三种子 16180，只复核已经固定的 C、B、D；不能趁机改损失/数据/读出。该学生种子固定复用31415的上游教师与案例核缓存，只衡量下游训练随机性，不称第三套独立上游模型。这是有条件的后续预算，不包含在首轮8次拟合中。

## 7. 数据与评价顺序

1. **源训练**：固定1296图/525船，属性可缺失；不因有无知识替换船型训练集。
2. **源新船验证**：固定已有299图/80船及3组支持任务，只选checkpoint。此前已用于研发，不是独立新确认集。
3. **源留出诊断**：823图/302船；先冻结模型，再报告原始单图和64支持适配后的 OA/BA、每类召回、救回/误伤。
4. **目标港评价**：模型与方案冻结后，按既有 Los Angeles/Port Klang/Santos 的3组64支持任务评价。没有目标尺寸/角度输入，没有目标身份查询。一次完整报告所有组，不按目标港选不同模型。

这些数据历史上反复用于研发，且冻结骨干存在历史预训练接触边界。不能称新独立数据集验证。本轮不启动 F_0921、OpenSARShip 或其他跨数据集实验。

## 8. 怎样判断因果相关候选，而不自我证明

主效用：C相对B和D的 OA/BA、类别召回与救回/误伤。按神经种子分别报告，支持抽样不能代替独立训练种子。

机制诊断限定为四项：

- **属性可读性**：在未见船上是否能读出真实尺寸，特别是类内差异，而非只预测该类平均船。
- **跨条件保持**：同船不同采集/角差条件下的属性预测是否一致，并且比“所有船都预测成均值”更准确；稳定与误差必须一起报告。
- **判别信息是否保住**：同船距离相对同类异船距离、独立分类探针与实际识别共同看。漂移须按各模型自身方差规范化，避免把整体缩小当成不变性增强。
- **知识关联方向在哪里起作用**：仅在源训练拟合属性读出方向，在留出诊断中屏蔽相应方向，并与相同维数/能量的普通方向比较。只定位功能依赖，不把屏蔽降分直接解释为因果贡献；分类器可能依赖相关代理。

最后一项只在 C 有分类或属性泛化正信号时做，避免对无效模型追加大量可解释性图。若属性监督没有传到分类证据，优先检查梯度接入与训练/预测一致性，而不是立即下结论信息不存在。

## 9. 什么结果对应什么决定

| 结果 | 允许说什么 | 下一步 |
|---|---|---|
| C在未见船和目标港总体优于B/D，且属性类内可读性改善 | 有外部知识支持的可迁移判别候选 | 保留小收益，再固定第三种子复核；不要求绝对纯净 |
| 属性预测更好，但识别不改善 | 学到了部分结构信息，尚无分类效用 | 分析是否与易混类别相关；不自动改下一模块 |
| C约等于D，二者都优于B | 辅助类别结构/多任务正则可能有用 | 可保留工程收益，但不归因于个体结构分离 |
| 只训练好、未见船退化 | 当前学习/信息条件不足以支撑泛化 | 检查实现与一项最相关对照，保留负结果后收口 |
| 只有个别船/种子贡献正均值 | 局部线索，尚未稳定 | 报告贡献集中情况，不用平均涨点包装成功 |
| 属性不可核验，或当前SAR属性探针没有类内信息 | 外部知识来源或当前表征可用性不足 | 停在该环节，不用伪尺寸替代，不启动完整组合 |

这里不要求每港、每类、每次抽样全部上涨，也不设置“至少涨若干百分点”的人为门槛；但把局部发现、可用模块和因果解释分开分级。

即使本轮全部正向，也首先称“知识锚定的可迁移证据”，不是已证明完全分离的纯因果因素。本轮不识别潜变量唯一性，不估计真实物理干预的因果效应。

## 10. 验证只围绕真实失败风险

- 部署调用只接受 SAR 特征/图像及已建立的支持参数；去掉属性头、删除或更改外部表后，同一图像预测必须不变。检测隐性依赖，而非泛泛安全检查。
- source teacher排除整船上游拟合和锚点采集；属性统计按训练船拟合。发现身份串入就修复拆分，不增加无关数据审计。
- 单次反传检查属性梯度确实到达32维证据分支，且没有读取query标签。缺知识样本仍有分类梯度。
- 原残差目标完整保留 `R=(2*onehot-1-prior_support)*present`；测试支持集缺类时仍正确。复用已修复实现，不能重新引入漏项。
- 导出模型、归一化、obs_id顺序和预测数组，按原环境重放。只在新修改或失败时重跑相关检查。

## 11. 与已有工作的关系

[1] Lopez-Paz, Bottou, Schoelkopf, Vapnik, *Unifying distillation and privileged information*, ICLR 2016, arXiv:1511.03643。原文第4节区分训练时额外信息与测试输入，第5节同时展示有效与无效的蒸馏例子。它支持本轮训练/部署信息不对称的设定，不保证教师信息能被学生利用。原文：`https://arxiv.org/pdf/1511.03643`。

[2] Lang, Wu, Xu, *Ship Classification in SAR Images Improved by AIS Knowledge Transfer*, IEEE GRSL 15(3):439–443, 2018, DOI:10.1109/LGRS.2018.2792683。已阅读作者公开全文的方法段：AIS侧使用真实长宽及派生几何量，SAR侧用最小外接矩形形成几何量，再用多类自适应SVM迁移。它不是本轮的属性辅助头或多观测蒸馏，但说明AIS几何知识迁移不是新的大方向；尤其两域几何量不能未经处理就等同。作者全文：`https://www.researchgate.net/publication/322617915_Ship_Classification_in_SAR_Images_Improved_by_AIS_Knowledge_Transfer`。

当前要验证的差异是：将**源训练真实船体属性、同船跨观测教学、未见船/跨港诊断及SAR-only部署**放在同一协议下，检查属性是否提供超出类别均值的效用。这里只是实验问题与方法来源，不是完成了系统novelty检索或已经建立顶刊创新。
