# 航速选老师的收益前置检查

2026-10-11。用户要求：开发前先明确收益依据。本轮只使用现有源域预测缓存，**新神经训练0次、目标港评估0次**，不启动上一轮提出的教师选择训练方案。

## 结论与决策

**目前不推荐把“航速相近/差异指导教师选择”作为下一轮主攻，先不开发学生模块。** 真实历史观测之间存在可利用的类别证据差异，但当前航速规则没有可靠地选出更好的教师。这一检查不证明航速知识永远无用，也不能保证另一种选教师方式成功。

## 检查对象

源拟合使用按船交叉拟合的原OOF教师分数；源留出使用对应全源教师的分数，拟合船与留出船不重叠。留出队列过去已用于开发，是历史复用诊断，不称全新独立确认。不同角色的教师拟合规模不同，各角色内部比较匹配。

所有策略从同船其他采集选择教师，当前整个采集排除。候选SOG至少两个已知且不同，当前SOG已知；未知及不参与候选部分保持等权质量。零速保留，没有最近时间替代，没有重新提取或训练骨干。

| 覆盖 | 源拟合 | 源留出 |
|---|---:|---:|
| 全部观测 | 1296 | 823 |
| 可构造其他采集老师 | 1040 | 721 |
| 航速已知 | 540 | 327 |
| 可按航速选老师的观测/船 | 231 / 48 | 136 / 31 |
| 进一步限制同港、入射角差≤2度后 | 167 / 36 | 78 / 19 |

可选子集有7类，缺少渔船；全体多观测评估保留原类覆盖。子集BA和全体BA的类别/样本权重不同，不能互相替代。

## 算法与对照

固定 `d=min(abs(log1p(v_i)-log1p(v_j))/log(6),1)`。near按`2-d`，far按`1+d`重加权，已知候选总质量不变。该尺度是固定诊断选择，不是物理阈值，没有扫描参数。

另算同船已知航速置乱的对应规则、只看教师自身top1-top2分数差的置信度权重，以及仅选最近/最远航速教师的硬选择诊断。它们不训练选择器，不用真实类别作为可用策略输入。

**标签事后理想选择**在等权方案和“将候选质量分配给某一个教师”之间，用真实类对最强竞争类的优势选最好者。真实标签仅用于这一诊断。它是当前有限候选集合中的乐观参照，不是可部署模型，也不是学生模型可能涨点的数学上界。

## 结果：教师类别质量，不是最终模型准确率

以下为源留出721条有历史观测样本、两个种子平均的教师分数BA。未额外用64支持案例适配，也未训练学生。

| 策略 | 教师BA | 相对等权，百分点 |
|---|---:|---:|
| 等权历史教师 | 42.1063 | 0 |
| 相近航速优先 | 41.9170 | -0.1894 |
| 不同航速优先 | 42.0122 | -0.0941 |
| 相近航速规则，航速置乱 | 41.9676 | -0.1388 |
| 不同航速规则，航速置乱 | 41.3429 | -0.7635 |
| 仅图像教师置信度 | 42.2957 | +0.1894 |
| 硬选最近航速 | 41.3806 | -0.7257 |
| 硬选最远航速 | 42.1582 | +0.0518 |
| 标签事后理想选择，仅诊断 | 46.8626 | +4.7562 |

near两种子的BA增量为-0.3788/0，far为-0.2894/+0.1012；不是两种子一致分类正信号。置信度版只比等权多救回一个种子中的一条观测，不能据此宣布另一个强模块已经成立。

near全体教师CE从1.813578降到1.813225，中心化类别目标MSE从0.363422降到0.363198；存在很小的分数误差改善，但BA反而下降。不能把所有指标说成均负，也不能把这点误差收益等同最终识别收益。

### 正子集也保留

在136条可选子集上，far教师BA从29.8279升到31.3125，硬选最远到34.0896。说明并非完全没有局部可能性；但全体BA分别是-0.0941和+0.0518，OA/按船均衡准确率也不完全同向。不能只摘选子集+1.4846或+4.2617来宣布路线可行。

进一步限定同港且入射角差≤2度，全体721条的far教师BA降至41.5382，相对等权-0.5682；near仍为41.9170；置信度版持平。可选78条的far BA从36.1495降至34.8890，near降至35.7293。此时候选池和可选样本也改变了，**不能把前后差值直接解释为消除港口混杂的因果效应**；只能说没有出现跨这些条件稳定的优势。

源拟合全体1040条上的near/far教师BA也未提高：等权46.1443，near45.9559，far46.1363。不是单纯到了留出才掉点。

## 能明确什么，不能明确什么

- **有收益空间：** 标签事后挑选能救回每种子15/16条原等权错误，且不误伤。相同历史数据里确实存在更好的类别证据。
- **尚未找到可用选择依据：** 相近航速没有选出更好的类别教师；差异航速只有条件依赖的局部正值，未形成总体稳定优势。
- **教师收益不等于学生收益：** 本检查只评估被蒸馏的类别分数。即使教师更好，学生是否能用单张SAR学到仍需后续验证；反过来，教师小幅BA下降也不是所有正则化收益不可能的证明。
- **当前投入判断：** 没有足够依据把上一轮提出的航速教师路线列为优先开发。暂停不是要求绝对保证或大幅涨点，而是连第一段“知识能改善教学证据”的链条都没有可靠建立。

原先的“航速相关状态信息可读性提高”结果不撤回；它证明的不是教师选择能力。下一方案提出前，应分别交代可利用错误、实际可观测选择依据和低成本可验证证据，不能用一个任务的正值替另一个任务背书。
