# 分层评价结果：学习、任务效用与系统收益

日期：2026-10-12。状态：已完成。本轮读取已有特征、数值缓冲区和预测缓存，补齐评价，未训练新模型、重选温度或模块强度，未替换主模型和论文结论。

## 结论先行

**支持集评价增补已完成：** 见`support_sensitivity/FINDINGS_ZH.md`。在固定共同查询上补充64支持组成、OA/BA均值/波动、配对胜负及预测敏感性。目标支持修正降低了三个港的BA波动，但平均性能有正有负；源端弱收益也对查询人群敏感。下文原口径结果完整保留，不被新诊断覆盖。

**三层区分有必要，而且已经改变了对部分旧结果的解释。** 有的方法改善概率预测但没有改善top-1；也有的方法提高BA却恶化概率风险。不能用任意一个指标代替全部研究目标。

1. **关系蒸馏学到了教师关系，连续风险略有改善，但跨港同类检索没有同步改善。** 不能概括为什么都没学到，也不能说已学得更好的跨港类别空间。
2. **面向实际支持读出的蒸馏修复有小幅、较一致的检索收益。** 六个几何版本×训练种子单元的MAP@R都提高；平均风险和源端BA亦有很小改善。尚未证明完整目标系统受益。
3. **同船历史支持修正有检索正信号。** 源端更明显，目标检索很小且港间方向不一；源端类别等权风险仍变差，不能称全面改善。
4. **同类异船共同信息修正在源端有分类效用，但不是通用近邻结构改善。** 源端BA提高3.67个百分点、风险下降，MAP@R反而下降；目标端检索和整体风险退化，不能仅归咎于最终融合掩盖收益。

这些是已有研发数据上的探索性证据，不是纯因果因素识别，也不是独立确认实验。

## 1. 范围与口径

- 源端检索：823个留出观测、302艘船、20个实际源港；每个查询排除同港及同MMSI图库观测。源端LA/Klang/Santos名称仅为几何版本，不是三个独立目标测试集。
- 实际目标检索：Los Angeles、Port Klang、Santos共5666个观测；12个身份缺失观测退出跨船检索，保留5654个。图库固定为上述823个源端观测，在对应模型坐标下比较。
- 主MAP@R：完整专家表示去常数项、固定余弦距离、固定候选及并列排序。先平均实际港口×类别，再平均类别和港口。以下以百分比报告。
- 支持修正检索保持查询原样，只修正合法候选图库，并匹配该候选集原中心和能量。这是非对称案例库诊断，不是统一对称嵌入。
- ridge分数用T=1的softmax；缓存融合概率直接使用。NLL用自然对数；Brier对八类平方误差求和后平均，越低越好。不宣称概率已校准。
- 源端分类风险覆盖814个不同查询观测，取决于原支持排除；检索覆盖823个。每项指标内新旧严格配对，不假定不同指标使用完全相同查询。
- BA保留历史逐实验单元等权口径；风险主表使用查询行曝光均值。另存池化后类别/港口汇总，不静默替换旧结果。

详细定义见同目录`PROTOCOL_ZH.md`。本轮未计算LogME，未追加指标筛选。

## 2. 用户指出的反例

| 指标 | 任务训练学生 | 关系蒸馏学生 | 含义 |
| --- | ---: | ---: | --- |
| 留出关系MSE | 0.103770 | 0.061187 | 更像教师关系 |
| 跨港跨船MAP@R | 13.8070% | 13.1523% | 同类排序下降 |
| NLL，支持抽样等权均值 | 1.668709 | 1.667377 | 风险小幅改善 |
| Brier，同上 | 0.736652 | 0.736297 | 风险小幅改善 |

**准确结论是：关系拟合成功，概率风险微弱改善，但跨港类别检索与top-1未受益。** 不是整个实验毫无作用，也不是只差一个融合步骤就能兑现教师收益。

## 4. 分类风险与BA

以下NLL/Brier为查询行曝光均值；BA变化保持历史等权实验单元口径，单位为百分点。正BA变化更好，风险越低越好。

| 方法与范围 | NLL：旧→新 | Brier：旧→新 | 历史BA变化 |
| --- | --- | --- | ---: |
| 源端关系蒸馏 vs 任务训练 | 1.665993 → 1.664610 | 0.735391 → 0.734929 | -0.0122 |
| 源端读出修复 vs 任务训练 | 1.665993 → 1.665856 | 0.735391 → 0.735232 | +0.0322 |
| 源端图像预测同船历史修正 | 1.668469 → 1.664958 | 0.736416 → 0.734023 | +0.2274 |
| 源端类别条件同船历史修正 | 1.668469 → 1.625365 | 0.736416 → 0.717530 | -1.2019 |
| 源端同类异船共同信息修正 | 1.668469 → 1.643040 | 0.736416 → 0.725983 | +3.6672 |
| 目标专家：同类异船支持修正 | 1.688220 → 1.709902 | 0.744790 → 0.753872 | +0.2395 |
| 目标完整融合：同上 | 1.724014 → 1.737005 | 0.760275 → 0.765454 | -0.0227 |
| 目标融合：仅换方向、保留原分数幅度 | 1.724014 → 1.727713 | 0.760275 → 0.762163 | +0.3124 |

最后一行是既有结果后诊断，不是源端预选出的正式方法。它提高BA但恶化风险，仍有取舍。

类别条件同船历史是反驳“BA降就是毫无价值”的直接证据：Brier有明确数值改善，BA却降低。但这也不能反向成为替换分类器的理由。

同船历史图像修正存在权重差异：源端行均值Brier改善0.002392，类别等权Brier反而恶化0.002403。不能只保留前一个数字。目标同船历史本轮仅评检索，不能借用同类异船方案的目标分类结果。

## 5. 改善与损害发生在哪里

关系蒸馏的行均值Brier在15/20个实际源港改善，但幅度小、检索仅8/20港改善。读出修复虽然检索较一致，Brier只在10/20港改善，尚不能称各层面都跨港稳健。

目标同类异船修正使专家和融合的行均值NLL/Brier在三个港均恶化。固定原预测正确/错误集合后：

| 对照 | 原预测集合 | 正确类概率变化 | Brier收益，正值更好 |
| --- | --- | ---: | ---: |
| 目标专家 | 原错误 | +0.006499 | +0.015605 |
| 目标专家 | 原正确 | -0.020858 | -0.035525 |
| 目标完整融合 | 原错误 | +0.002138 | +0.005171 |
| 目标完整融合 | 原正确 | -0.009002 | -0.015818 |

**修正不是完全没帮助，而是原正确样本损失超过原错误样本收益。** 这是固定集合风险分解，不是物理因果识别，也不能用真实错误标签作部署门控。

按池化曝光后逐港BA，目标融合最差港仍为Port Klang，41.1708%降至40.5199%。原逐港/逐抽样BA也保留；先池化分子分母再算BA与先算各draw的BA再平均不同，不互相覆盖。

`probability/draw_spread.csv`记录支持抽样标准差，ddof=0，仅作描述，不是独立重复的置信区间。修正融合LA/Klang/Santos逐抽样BA标准差约0.1512/0.9387/1.4508个百分点，不能凭均值宣称稳定获益。

## 6. 机制结论与后续边界

**已证实：** 教师关系拟合、同类邻域检索、支持核读出、完整融合是不同效用，存在真实取舍。较低MSE不保证较高MAP@R，较高MAP@R也不保证较低风险或较高BA。

**合理但未证实的解释：** 同类异船修正可能改善带符号残差求解器中案例的整体作用，而不改善余弦近邻排序。检索按候选集匹配中心/能量，与64支持的核读出也非完全相同操作；不能只凭二者相反就锁定唯一根因。

更有价值的问题是：哪些SAR可观测的关系变化能在未见船上提供有用证据，同时避免对原正确样本造成更大损害？读出修复和同船历史的微弱正信号保留，不自动升级为新模块或启动扫描。

本轮完成评价层分离。下一次事先固定此指标组合，再判断新设计改善哪一层；不能在本轮结果上挑指标后，把同一批数据改称独立确认。暂不声称已分离纯因果因素。
