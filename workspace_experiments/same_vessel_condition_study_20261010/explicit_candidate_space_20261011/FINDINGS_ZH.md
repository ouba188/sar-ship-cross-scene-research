# 显式候选隐空间：提取结果、有效性与边界

日期：2026-10-11。状态：八次训练及冻结诊断完成，主模型未修改，所有本轮进程已结束。

## 结论先行

**已经实际提取并导出了一个更稳定、仍有船型判别能力的 32 维候选空间。** 不应再把它说成“没有隐空间”或“必须绝对纯净才有价值”。

但是，该版本还没有获得优于普通任务学习/PCA 的总体目标 BA。可靠关系加权能减轻普通同船稳定约束造成的退化，不能据此宣称已经找到唯一因果因素或形成主模型净收益。

本轮采用务实标准：相对减少同船条件变化、保留类别信息、在未见船只上检查；不要求零漂移、逐维物理名称、所有港口都上涨。稳定性、判别性和识别收益分开报告。

## 1. 与前几轮的区别

前两轮是 512→64→8 分类分数残差，原特征核不变。本轮直接训练 512→32 的显式投影，分类头与 64 标签支持集残差校正都必须经过 32 维向量，没有原始 512 维捷径。

历史上已经做过同船平均重建、稳定/条件双头与交换损失。本轮不是重复这些，也不是声称首次存在隐空间；新增的是共同支持的类别关系监督、显式可还原线性子空间，以及适配后任务目标的联合训练。

```text
冻结 R18 的512维特征
      |
源训练归一化 -> 可学习正交基Q -> 源方差归一化 -> 显式32维向量z
                                                    |          |
                                              8类线性头   支持案例相似度
                                                    |          |
                                                    +----64标签残差适配
                                                              |
                                                           八类预测

训练信号：原监督 + 完整教师蒸馏 + 支持/查询适配后损失
          可选：可靠类别关系区间
          可选：同船多观测的向量稳定约束
```

投影基 Q 的列正交；每个输出坐标按源训练协方差计算的标准差归一化，再除 sqrt(32)。源训练总方差为 1，不能只通过把所有向量缩小来降低漂移。仍额外检查有效秩，防止不同坐标变成冗余复制。

每个模型可训练参数 16648：512×32 投影参数，加 32×8+8 分类头。源均值与协方差是固定缓冲，不算可训练参数。

## 2. 四个逐步对照

| 方案 | 任务与适配训练 | 可靠关系区间 | 同船向量稳定约束 |
|---|---|---|---|
| task | 有 | 无 | 无 |
| relation | 有 | 有 | 无 |
| uniform | 有 | 有 | 合格队列等权约束 |
| reliable | 有 | 有 | 按共同支持的类别关系占比加权 |

另保留未训练的源 PCA32 初始化对照。

所有模型保留原监督 MSE、0.5 完整同船教师蒸馏、0.5 支持适配后类别平衡 MSE。关系项权重 0.25，按源初始分数梯度 RMS 定标；向量稳定项权重 0.1，除以各自源初始化的期望漂移。相同容量、初始化、批次、训练回合和优化步数，没有目标选权重。

稳定约束连接同船不同采集场景的图像/场景平均特征。同类其他船只用于判断类别关系是否共同成立，不直接强迫不同船向量相等。612 个元数据合格锚点、135 艘源船沿用上轮队列；reliable 权重来自七个竞争类中共同正关系的比例，而不是人工指定物理因素。

重要限制：这个权重是锚点级标量，会作用于整个 32 维向量，不是已经定位了每一条关系对应的独立稳定方向。

## 3. 数据、训练与选择

- 训练：1296 张、525 艘源船，两个种子 31415、27182，每个分支 400 步 Adam 0.001。
- 初始化：源训练 PCA32 和类别/船加权 ridge1 分类头，四个分支相同。随机种子影响训练采样、适配回合及原教师，不改变 PCA 初始化。
- 每步：128 张监督样本；64 艘独立支持船及其余身份中的 96 个查询样本；64 个同船稳定关系采样。
- 训练适配回合来自源港合并池。多数源港不足 64 艘独立船，所以不能称为严格逐港或留港元训练。
- 验证：原新船与新时相验证集，各三个固定 64 标签支持回合，查询与该回合支持身份隔离；按适配后平均 BA 每 20 步选最早最佳检查点，包括 0 步。新时相集按原设计可以与训练共享身份，不混称全是新船。
- 源未见船诊断：823 张、302 艘，未用于检查点选择。
- 目标评估：Los Angeles、Port Klang、Santos，各三组原有 64 标签支持集，两个训练种子。支持/查询船身份隔离，目标船不进入源训练；预测全部冻结后读取目标结果。

目标数据已反复用于研发，并非独立确认集。本轮是 R18 侧线，不是完整双骨干主模型。新投影改变特征核、分类头与训练目标，不能把它和旧 512 维残差方案的分数差直接归因于一个模块。

## 4. 空间确实变稳定了，但保留判别性有代价

源未见船上的结果，两个种子平均：

| 方案 | 归一化同船漂移，低较好 | 同船方向距离，低较好 | 有效秩 | 独立固定线性探针 BA (%) |
|---|---:|---:|---:|---:|
| PCA32 | 1.7372 | 0.8287 | 29.06 | 37.84 |
| task | 1.7097 | 0.8311 | 27.39 | **39.86** |
| relation | 1.7097 | 0.8301 | 27.34 | 39.78 |
| uniform | **1.5439** | **0.7197** | 21.84 | 39.24 |
| reliable | 1.5964 | 0.7296 | 22.91 | 38.17 |

reliable 相对 task，归一化同船漂移下降 6.63%，方向距离下降 12.21%；有效秩约 23，未坍缩成常量。独立分类探针仍显著高于八分类随机水平，但低于 task 1.68 个百分点；相对 PCA32 仅略高 0.34 个百分点。

因此，可以叫“保留一定判别性的相对稳定候选空间”，但不能说“稳定化无损”或“可靠关系加权已经比普通稳定化更好”。

另外，reliable 的同船漂移/同类不同船距离比值为 0.9031，task 为 0.8956，并没有改善。部分绝对距离减少也伴随同类不同船距离收缩，不能把所有变化都归结为只去除了观测噪声。

源观测入射角线性可读性 skill 从 task 的 35.09% 到 reliable 的 34.49%，仅小幅下降，仍保留观测条件信息。这个观测性探针既不覆盖全部条件，也不是非因果因素比例。

### 单独检查真正的跨港观测

只取源未见船中不同采集产品的成对观测。跨港部分为 116 艘船、479 对；港内部分为 137 艘船、1013 对。这两组船不完全相同，不能把组间均值差当成港口因果效应。

| 方案 | 跨港归一化漂移 | 跨港方向距离 | 港内归一化漂移 |
|---|---:|---:|---:|
| task | 2.0543 | 0.9193 | 1.5591 |
| relation | 2.0556 | 0.9188 | 1.5559 |
| uniform | 1.9325 | 0.8171 | 1.3756 |
| reliable | 2.0251 | 0.8304 | 1.3722 |

reliable 的跨港方向距离下降约 9.7%，但归一化距离只下降约 1.4%。不能只挑前一个指标，声称跨港漂移全面大幅消失。其港内改善比跨港距离改善更明显。

## 6. 失效原因定位

### 已定位：向量约束不是没有生效

训练集与未见船几何均改变，且 task/reliable 的子空间平均平方余弦重叠约 0.65，而 task/relation 约 0.99。整向量稳定约束真正改变了所选空间，并非只重命名了原 PCA 坐标。这个重叠量也不能直接解释成“更换了 35% 因果因素”。

### 已定位：分类分数与案例相似度受影响不同

冻结所有模型，分别替换 task 的分类分数与支持集特征核；保持同一 64 标签支持集：

| 替换为候选 | 只换分类分数 BA | 只换特征核 BA | 两者都换 BA |
|---|---:|---:|---:|
| relation | 37.288 | 37.424 | 37.377 |
| uniform | 37.025 | 36.763 | 36.935 |
| reliable | 36.960 | 37.290 | 37.116 |

共同参考 task 为 37.345%。

普通同船约束明显损害了支持案例相似度；可靠加权让这部分损失从约 0.582 缩小到 0.055 个百分点。但可靠版本的分类分数仍有损失。说明可靠加权有具体作用，主要是保护支持匹配，不是已经使基础船型判断更准确。

固定源分类探针在 reliable 上也弱于 task，因此问题不只是最后一个训练分类头没有拟合好；但这不等于所有类别信息已消失。

### 检查点因素不能忽略

选定检查点的源未见船原始 BA：task 40.187%、reliable 38.704%。统一查看第 400 步，二者分别为 40.437%、40.136%，差距缩小到 0.301 个百分点。

因此，不同的源验证选点可能放大了某些未见船原始分类差距，不能将其全部归因于表征损坏。这里只作源域末步诊断，没有改选检查点或重新用目标结果挑选末步。

### 下一步假设，不冒充已证实根因

当前可靠性是“若干类别关系可信”，但稳定项作用于整个 32 维向量。这把局部判别关系的可信度扩展成了整向量应该不变的要求，有可能同时压掉有用差异。

更针对性的下一设计是：稳定约束只作用于可靠关系支持的判别方向，对其他坐标保留自由度；继续由适配后任务损失决定哪些信息需要保留。现有证据支持优先检查这个作用范围，不支持继续盲目增加稳定损失或把剩余部分一概称为噪声。该方向本轮尚未训练。

## 7. 如何使用本轮结果

1. 保留显式向量和投影，作为后续研究对象；承认它已经具有一定相对稳定性，而不是因不够纯就否定。
2. 将“相对稳定候选空间”和“已证明提高识别的主模块”分开。当前满足前者的部分条件，后者尚未成立。
3. 不要求每维物理名称，不要求全港全类都涨点；但不能省略强对照、类别可读性和净收益。

向量目录共 37893 条观测，每条 32 维；不是 37893 张训练样本。使用与还原公式见同目录 `VECTORS_ZH.md`。剩余输入分量不自动等于纯非因果信息。
