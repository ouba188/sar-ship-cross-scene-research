# 平移方向指导教师选择：收益空间与可利用性

日期：2026-10-12。状态：完成；无运行中的实验进程。新增神经模块训练 0；目标港评估 0。

## 决策先说

**有候选收益空间，也出现了方向信息参与救回样本的局部正信号；但还没有证明这条线能稳定利用收益空间。本轮不启动学生模块训练。**

不能只报平均 BA +0.91 个百分点。这个数值是历史源域留出船上的教师质量，不是完整模型、目标港或跨数据集性能；两套教师种子的净收益方向不一致。方向相对速度的额外收益高度依赖一艘集装箱船。

完整有效结果位于 `corrected/`。顶层首次运行的部分文件保留：该次在同港/近入射角筛选时触发 Pandas 只读数组错误，没有完成留出评估。修正为复制局部布尔掩码，并增加对应匹配池测试后重跑；没有改划分、特征、正则或决策规则。首次已拟合32个小型读出，修正后完整拟合32个；新增神经训练始终为0。

## 做了什么

这不是上一轮“长宽 × 船首向 × 航速”的再包装。本轮只研究对地平移的可用代理，去掉长宽和船首向缺失造成的不必要门槛。

输入为 AIS SOG、COG 和缓存的原生 GRD 地距轴方位。令 u=SOG/(1+SOG)，theta=COG-地距轴方位。方向特征采用 u²cos(2theta)、u²sin(2theta)，全部有界，避免上轮乘积外推放大。它表示无向平移方向，不区分反向航行，不是船体姿态转动或实测雷达径向速度。

有效零速直接设运动向量为零，即使 COG/grid 缺失也无需编造朝向；正速需要有效 COG 和本产品有效网格。AIS 与产品中点存在时间差，并非孔径内精确运动测量。没有新下载。

四种固定岭回归读出，ridge=0.1，不标准化、不带截距、不扫参：

| 读出 | 输入维数 | 输入 |
| --- | ---: | --- |
| confidence | 1 | 预测分数间隔的有界值 |
| speed | 3 | confidence + u + u² |
| direction | 5 | speed + 两个方向项 |
| capacity | 5 | speed + u³ + u⁴，同参数量对照 |

训练目标是同船、不同产品的正确类分数间隔之差。真实类别只用于构造训练目标和评估，不进入读出输入。每类、每船、每对依次平衡，配对权重总和为1；没有把长历史船的大量配对当成大量独立船只。

使用既有源船三折的原生 OOF 教师分数；在缓存上再做船只三折读出预测。完整源读出冻结后，才读取留出教师结果。上游没有嵌套重训，因此不能称端到端独立验证；这些历史数据也已经反复用于研发。

选择教师时，整个 focal 产品排除。所有方法用同一个可改权 donor 集合；未知 donor 的原始等权质量不变，已知 donor 总质量不变。软权重在候选内部按预测质量归一到1到2；另报硬选择诊断。这个规则会改变相对权重，不会直接修改图像特征或减去“干扰”。

## 收益空间存在吗

同一个候选池里，使用真实类别选择最佳候选的诊断 BA 为47.7923%，等权为42.1063%，差5.6859个百分点。两种子平均能救回23条且不伤害原正确样本。

这是**有限候选池中存在更好选择**的证据。它不是可部署算法，不是当前读出或学生必能达到的上限，更不能把它作为已实现收益。

## 为什么局部能涨

保持所有非方向系数不变，只在已训练读出中移除两个方向项，结果的 BA 与速度读出一致。恢复方向项的留出增量分别为+0.8319、+0.2894个百分点，说明这里不是仅靠联合拟合改变速度系数获得的差异。

可直接追踪的案例：集装箱船 MMSI 563050500，focal观测29438。候选教师中，29439误判为 crude_oil_tanker；29437判对为 container_ship；29440也判对但没有运动知识，保留原质量。

| donor观测 | 移除方向项后的权重 | 加入方向项的权重 | 两种子判断 |
| --- | ---: | ---: | --- |
| 29439 | 44.44% | 22.22% | 错误 |
| 29437 | 22.22% | 44.44% | 正确 |
| 29440 | 33.33% | 33.33% | 正确，运动未知 |

这就是本轮已经解释到的计算机制：**方向项改变了候选顺序，降低了错误教师的影响，提高了正确教师的影响，使合成分数跨过分类边界。**

不能据此声称已经证明物理散射机制：这些观测还跨New York与Tanger Med，入射角和背景等也不同，没有把成像变化独立归因于运动方向。元数据方向是候选关联线索，不是已识别的因果因素。

## 为什么还不能开发模块

方向项相对移除方向项，种子31415救回3条/2艘、伤害0条；种子27182救回1条/1艘、伤害2条/1艘。两个种子的集装箱救回都来自563050500；种子27182损失的2条来自同一艘散货船622121414。

BA的增量不等于更多样本都受益：该队列集装箱只有32条，散货247条。第二个种子救回1条集装箱的BA贡献大于损失2条散货，故方向相对速度的BA上升而OA下降。

作为依赖性诊断，移除563050500的4条观测后，方向相对速度的BA变化分别仅+0.0506、-0.1012个百分点，平均**-0.0253**。方向额外优势因此消失。这个排除仅用于解释依赖，不作为新实验主结果，不用于选择模型。

同港且入射角差不超过2度的候选池中，方向、航速、同容量三种软加权的平均BA均为42.2957%，没有方向额外优势。它的可改权覆盖只有73条/18艘，队列改变，因此不能宣称已经排除了港口/角度混杂的因果效应。

## 当前判断与下一步边界

1. 收益空间：有。候选教师有正确/错误互补，理想选择能改善。
2. 可利用性：局部存在，可追踪到实际教师权重和分类翻转；尚未跨种子、船只和源交叉验证稳定成立。
3. 模块开发：暂不启动。保留正信号，不把单船方向偏好升级为普适物理规律，也不自动追加种子、扫参或加注意力。

后续如继续，应先解释为什么方向能区分该案例的好坏教师、这种关系是否能在其他船中用现有证据识别；仅在有新的、可区分解释的证据入口时做小检验。不能因为本轮平均正值就宣称满足了“有办法稳定利用”的条件。知识仍限定训练时使用，最终预测只用SAR。
