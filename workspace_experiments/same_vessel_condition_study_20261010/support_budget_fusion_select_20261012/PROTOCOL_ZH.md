# 第一步：只改变选择目标，保持训练损失不变

日期2026-10-12。目标是在训练新模块之前检验：现有候选是否因按专家而非完整系统表现选配置，导致完整系统收益未兑现。

## 固定条件

- 沿用B16、64、128，以及上一轮完全相同的源选择、源留出、目标港支持/查询ID。
- 保留源端3船级折，每折3抽样，3个冻结几何版本。这些几何版本不是3个独立验证港；源选择仍是同一episode内类别均衡BA、再episode等权，暂不同时改变港口加权规则。
- 保留学习修正器、专家先验、骨干和分频网络，不修改训练损失、不新训练神经网络。补拟合基础分支分类头，所有头排除整组留出船；源选择的头额外排除验证折船。历史编码器、分频网络和几何的源端暴露保留为限制。
- 原始方法、简单衰减a=0.75/0.5/0.25/0，以及学习修正dose=0.25/0.5/0.75/1，总计9个不同候选。全部采用lambda(B)=8B/64，基础分支也使用相同B适配。

## 选择与比较

在完全相同候选输出上对比两种选择目标：源端专家BA、源端完整等权概率融合BA。每个B独立选择；准确并列时最小干预优先，再按原始、简单、学习修正的顺序处理同强度并列。

主要比较两种目标从9候选并集中选出的模型；次要分别在原始+简单、原始+学习修正子集内比较，避免把新增方法搜索与目标变化混为一谈。OA、NLL、Brier、逐类和支持抽样变动继续报告，但不参与本轮事后择优。

所有配置在源端冻结，不根据源留出或目标结果重新选择。源留出用于检验可利用性；目标只运行已经源选的候选，不在目标搜索完整网格。报告中不把源选择分数当作泛化证据。

## 验证与继续条件

需要重放旧专家选择分数及旧专家选定模型的预测，检查更换选择环节时没有意外更换其他计算。新建基础分支需与现有部署特征/核的对应参考对齐，并披露拟合排除范围。检查支持/查询索引与嵌套预算，避免源验证标签进入先验拟合。

第一步完成后再判断是否存在值得训练利用的收益。若只有选择数据改善、留出或目标不兑现，先定位候选收益、选择可靠性或迁移边界，不直接启动大规模新损失训练。第二步的完整任务损失训练尚未开始，本协议不能被表述为已经完成任务驱动训练。

范围：3个历史目标港，非新增独立数据，非全23港，也不是F_0921或OpenSARShip补实验。源留出按整船排除；目标保持历史行级排除及同船重叠限制。
