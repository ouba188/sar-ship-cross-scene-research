# 支持案例修正接入完整模型：三目标港紧凑试验

日期：2026-10-12。状态：完成。无新训练，复用冻结残差预测器；三个实际目标港、各五组原64标签支持划分。主模型和论文未覆盖。

## 1. 结论

**源端+3.67 BA的收益没有直接转化为完整模型的跨港收益。** 冻结支持端修正使专家的港口等权平均BA提高0.2395个百分点，但等权概率融合BA下降0.0227个百分点，基本持平。Santos有效，Los Angeles和Port Klang融合退化，不能整体替换原方案。

本轮进一步定位了两个不同层面的问题：

1. **收益在专家阶段已经明显减弱。** Port Klang专家本身BA下降0.7918，不能全部归咎于基础模型或融合。
2. **专家排序与分数强弱的配合影响最终结果。** 固定诊断中，保留新排序、恢复旧中心化分数范数，融合BA相对原模型提高0.3124。但这是看到主结果后的诊断，不是源端选定或独立确认的新成绩；且Port Klang仍退化。

保留上述局部正信号，不把它包装为全港有效或因果因素分离。

## 2. 冻结接入方案

训练沿用上一轮 `case_completion_class_control_20261012` 的三个模型：1040源观测、同类异船目标、排除焦点整船、固定岭回归；剂量1由上一轮源船三折选择。本轮不重拟合、不使用目标港标签选剂量或融合权重。

```text
原基础模型 -------------------------------------> 原基础类别分数

目标港64个有标签支持案例
    -> 原专家特征
    -> 已冻结的图像残差预测器
    -> 只改R18相关576坐标，恢复原支持中心/能量
    -> 重算支持核KSS与原64标签残差系数

待测SAR -> 原专家特征、原先验，不改写
    -> 与修正后支持案例计算KQS
    -> 新专家类别分数

原基础分数与新专家分数 -> 原0.5/0.5 softmax概率融合
```

保持基础模型、两个骨干、专家先验、查询表示、其他专家坐标、ridge=8、支持标签和评测掩码不变。576为相关坐标数量，并非576个独立自由维度。预测不新增AIS、身份或历史图像；既有SAR采集字段仍保留。

这是原全量等权融合的接入测试，没有调整5%预算、交接策略、温度或融合比例。也没有叠加上一轮骨干续训/同船教学，不能把不同试验的收益相加。

## 3. 主结果

OA/BA单位为%，差值为百分点。按原协议，对三个港口各五个支持划分的指标等权平均。

| 读出 | 原OA | 新OA | ΔOA | 原BA | 新BA | ΔBA |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 专家 | 47.568173 | 47.980918 | +0.412745 | 42.784184 | 43.023699 | +0.239515 |
| 最终融合 | 48.354620 | 48.426005 | +0.071384 | 43.343317 | 43.320577 | -0.022740 |

未变化的基础模型OA44.911230、BA40.140038。相对基础模型的优势不全是新模块贡献，必须和对应原融合比较。

| 目标港 | 专家ΔBA | 原融合BA | 新融合BA | 融合ΔBA |
| --- | ---: | ---: | ---: | ---: |
| Los Angeles | +0.479527 | 43.260956 | 42.870459 | -0.390497 |
| Port Klang | -0.791788 | 41.234744 | 40.558349 | -0.676395 |
| Santos | +1.030805 | 45.534251 | 46.532924 | +0.998674 |

15个非独立港口/抽样单元中，专家ΔBA为8正7负，融合为9正6负。多数单元正不代表平均幅度为正。

**汇总口径不能混淆：** Port Klang样本更多。按查询行数池化的OA，专家48.282791→47.961271，融合49.309463→49.002558。港口等权OA微正、池化OA为负并不矛盾，也说明不能只展示一个有利汇总数字。

## 4. 增益是否被基础模型覆盖

以下计数是重复支持抽样下的预测事件，不是独立船数。专家共救回2163个事件，同时误伤2251个。

| 专家救回后，最终融合发生什么 | 事件数 |
| --- | ---: |
| 融合也从错变对 | 880 |
| 融合原来已正确，仍正确 | 657 |
| 融合仍错误 | 618 |
| 融合反而从对变错 | 8 |

因此“基础模型已经会了”只解释一部分。基础模型错误时，专家救回也未必能越过融合决策边界；只比较两路argmax不足以解释概率融合。

880个融合救回中，536个基础模型原本错误，344个基础模型原本正确；后者说明原专家曾拖累融合，修正后解除拖累。657个融合本来正确的事件中，599个基础模型正确、58个基础模型错误。

最终融合总计救回1421个事件、误伤1505个；不完全对应专家argmax翻转，因为类别分数变化也会影响融合。救回涉及1104个独特观测、914个已知MMSI；误伤涉及1152个观测、855个已知MMSI。身份缺失分别为3个救回观测和1个误伤观测，单独统计，不虚构为一艘船。两组船/观测可在不同抽样中重叠。

去掉最大正贡献的已知港口/船组合（Los Angeles，477713800），固定其他预测、重算类别分母，融合ΔBA为-0.1060。本轮原接入不是被单个偶然正例掩盖的强收益。

## 5. 固定分数尺度诊断

将每个查询的八维专家分数减去本行均值，拆成方向和L2范数。交换原/新方向与范数，不拟合参数、不使用查询标签构造变换：

- “只改方向”：新中心化分数×原范数/新范数，严格保留新专家argmax。
- “只改幅度”：原中心化分数×新范数/原范数，严格保留原专家argmax。
- 全部使用同一个未改变的基础模型与等权概率融合。

| 固定诊断 | 融合OA | 融合BA | 相对原融合ΔBA |
| --- | ---: | ---: | ---: |
| 原模型 | 48.354620 | 43.343317 | 0 |
| 完整支持修正 | 48.426005 | 43.320577 | -0.022740 |
| 只改方向，保留原幅度 | 48.573849 | 43.655717 | +0.312400 |
| 只改幅度，保留原方向 | 48.442797 | 43.474081 | +0.130764 |

只改方向时，Los Angeles/Klang/Santos融合ΔBA分别为+0.3944/-0.6545/+1.1972；15个单元10正5负。新分数/原分数范数比的港内中位数均值分别为0.9317、0.9500、0.9245。

**能下的结论：** 分数强弱确实参与了融合退化；Los Angeles恢复原幅度后由负转正。完整修正与两个分量的作用存在交互，不能把它们简单相加。

**不能下的结论：** 不能说“幅度收缩总是有害”，因为单独换幅度也有小正收益；不能说分数已经校准成真实置信度，也不能认定这是唯一根因。Port Klang的类别排序本身已退化，范数修正并未解决。

该诊断是在主结果之后提出的固定干预。+0.3124应作为下一步源端融合验证的依据，不应当作本轮预先选定的新主模型成绩。实际部署该变换还需同时计算原/新专家分数，不能声称没有额外求解开销。

## 7. 协议与实现核对

- 本轮是三个真实目标港，而上一轮三个名称仅表示几何版本。目标行数分别583、3425、1658；每组查询519、3361、1594，均含八类。
- 64是标签观测数，不保证64艘不同船。保持原始逐行支持排除，部分查询与支持共享MMSI，不能改称“未见船评测”。详见`scope.csv`。已知身份中，查询与1040行补全训练集没有船只交集；缺失身份不据此断言没有交集。
- 目标数据历史上已反复开发，不是新增独立确认集。未运行其他24港划分、F_0921、OpenSARShip或跨数据集试验。
- 初始检查发现`target.npz`的`expected_base`为较早版本，Los Angeles有88/2915处与当前基础缓存不同。改用`frozen_comparison_20261010`的`ours_base`和`softmax_average_all`作为正确历史参照，而非放宽阈值。当前基础与融合argmax均与正式冻结结果一致。
- 原专家/融合分数重放、支持修正与独立调用路径均在1e-10绝对容差内一致；非R18支持坐标、查询特征、先验和基础输出不变。诊断变换保留指定专家argmax，原/新融合重放匹配。
- 归因初版按MMSI分组时漏掉缺失身份贡献；已改为保留未知身份项并单列计数。修正后船/未知身份贡献总和与融合ΔBA一致（-0.0227395650）。分类指标没有因此变化。
- 本轮新增拟合次数0，所有运行结束。原模型、旧结果、论文均未覆盖。

## 8. 下一步范围

不直接升为主模块，也不因为均值接近零就丢掉Santos与方向保留诊断的正信号。

下一步优先在源端的**实际完整融合**上验证是否应保留旧分数幅度，再固定规则做目标验证，不能根据当前三个港口逐港开关。随后针对Port Klang所暴露的油轮等类别排序损害，先检验支持关系在哪些类别边界上把有用证据压掉；只有找到可用信息能区分这些损害时，才设计有边界保护的支持修正。不追加无收益依据的网络、损失或权重扫描。
