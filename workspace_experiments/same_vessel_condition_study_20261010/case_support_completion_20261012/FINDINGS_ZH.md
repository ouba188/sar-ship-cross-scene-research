# 从模仿同船历史转向改善支持案例：收益空间与实际试验

日期：2026-10-12。

## 1. 本轮结论

不是简单地继续加大学生的蒸馏强度。本轮先定位教师增益来自哪一端，再试一个轻量可部署接入，最后用匹配对照检查收益来源。

**找到一条更值得保留的路线：学习源数据中同类不同船的共同表示，只改写64个支持案例的R18相关表示，查询船保持原始表示。源端留船评测OA由46.0894%升到50.4771%，BA由45.0995%升到48.7667%。**

这条路线不需要在预测时拿到待测船的类别、身份、历史图像或AIS。它不是纯因果因素分离，也不是已经验证的最终融合/跨数据集成绩。它原本是解释收益来源的对照，却比本轮同船历史补全方法更有效，应如实保留。

## 2. 先证明哪里有空间

固定原有专家读出、源端先验、64个支持标签与ridge=8，仅交换支持端/查询端的R18相关表示。教师使用同船其他完整产品的表示均值，属于特权诊断。

| 使用历史信息的位置 | OA (%) | BA (%) | 相对原始BA变化（百分点） |
| --- | ---: | ---: | ---: |
| 都不使用 | 46.0894 | 45.0995 | 0 |
| 只改善支持案例 | 47.5683 | 46.7198 | +1.6203 |
| 只改善查询船 | 48.0424 | 46.9312 | +1.8318 |
| 两边都改善 | 49.3295 | 48.1964 | +3.0969 |

以上恢复原支持集合的中心和中心化能量。未做尺度匹配时，仅支持端改善仍有+1.1900 BA，因而并非只靠整体尺度变化产生收益。

因此，教师增益不全来自查询船多看几次。支持端自身有改善空间，值得先尝试修正支持案例。两端收益存在交互，不能简单相加；这些教师成绩也不是单张SAR学生的数学上界。

## 3. 做了哪些真实试验

所有候选使用相同初始全专家表示、先验和支持读出，查询端不变。只在源端拟合轻量线性残差预测器，没有重训骨干。

| 方案 | OA (%) | BA (%) | ΔBA |
| --- | ---: | ---: | ---: |
| 原始专家 | 46.0894 | 45.0995 | 0 |
| 利用支持标签向源类别中心收缩，无同船教学 | 47.2747 | 45.0737 | -0.0258 |
| 类别平均历史残差 | 46.0894 | 45.0995 | 0，源端选择关闭 |
| SAR预测同船历史残差 | 48.3586 | 45.3269 | +0.2274 |
| 已知支持类别条件化的同船历史残差 | 46.4239 | 43.8976 | -1.2019 |
| **SAR预测同类其他船的共同表示** | **50.4771** | **48.7667** | **+3.6672** |

最后一行与“SAR预测同船历史残差”使用同样的输入输出维数、拟合行、类别/船只权重、残差岭回归、剂量候选和源端选择协议，仅改变训练目标。其预测器不输入支持类别，类别标签仍仅按原流程用于64样本专家适配。

源端三折留船、每折三次支持抽样、三个几何版本共同选择剂量0/0.25/0.5/1，不用823个留船评测样本选剂量。最终共同表示方案选1，其源端交叉验证BA为52.0000%，原始为47.2624%。历史预测选1、标签条件历史选1、直接类别中心收缩选0.5。没有在查看留船成绩后改这些剂量。

## 4. 新候选具体怎么做

### 训练时

1. 使用原1296个源端拟合观测，其中1040个有同船其他产品的观测作为匹配训练集合。共同表示对照也只用这1040行，不靠扩大训练集占优势。
2. 取原专家中受R18影响的64个保留坐标和512个补充坐标。共576个坐标，不是576个独立自由维度；其他分支不动。
3. 对每个源训练样本，构造“同一船型、其他船”的加权平均表示作为目标。排除该样本的整艘船，按船只均衡加权。源端交叉验证时，训练船和验证船整体分开，目标均值仅由拟合船生成。
4. 从单次SAR表示x学习残差 d(x)=b+(x-mu)W，使x+d(x)接近这个类别共同表示。加权残差岭回归的正则固定为0.1×设计Gram矩阵迹/维度，不做强度网格搜索。
5. 仅用源端交叉验证的真实64支持分类BA选择改写剂量，不按重建MSE选择。

### 预测时

```text
64个有标签支持案例的单张SAR
    -> 原有特征与专家坐标
    -> 已冻结的共同表示残差预测器
    -> 仅修正R18相关坐标
    -> 恢复原支持集合的中心和中心化能量
    -> 与原64个标签、固定源先验一起求解专家残差系数

待测船的单张SAR
    -> 原有特征与固定源先验，不做上述改写
    -> 与修正后的支持案例计算关系
    -> 得到专家分类分数
```

没有查询真标签、MMSI、船舶历史或AIS进入预测器。保留既有SAR采集入射角路径，不能称为严格只读像素的新系统。外部知识在本候选中不是必要条件，实际新增的是源船型监督下的支持表示修正。

## 5. 为什么这次比继续模仿历史更值得做

**已证实的计算层面事实：**

- 只改善真实历史支持案例可以涨点，支持端是有效作用位置。
- 在匹配的线性预测器中，更换训练目标为同类其他船共同表示，明显优于预测同船另一时相的完整表示。当前瓶颈不只是模型容量或训练步数，教学目标本身值得改变。
- 历史预测能解释约37.62%的留船历史残差能量，但BA仅+0.2274；普通类别中心对历史残差的解释比例甚至约39.60%，BA却不提高。重建更准不是分类更好的充分条件。
- 标签条件历史预测的类间/类内散布比也改善，却出现BA退化。不能靠“类更紧凑”这一张几何图证明接入有效。
- 最好的共同表示方案反而不更接近历史教师最终分数：中心化分数MSE约0.04103，原始约0.02125。教师的完整输出不是本任务唯一应当模仿的答案。

**目前合理但未完全证明的解释：**

同船历史表示还包含个体结构和观测条件差异；复原这些差异未必帮助区分船型。其他同类船形成的目标更直接地强调类别共同证据。只改支持端，会改变支持案例对查询分类的作用，同时保留查询端原有细节。这比把所有观测都压向一个“稳定表示”更符合本轮读出任务。

此解释不等于已分离物理干扰，也不能把被压缩的方向全部叫作噪声。真正可确认的是训练目标与接入位置的作用，不是因果识别定律。

### 固定接入位置对照

使用同一个已训练的共同表示预测器和已固定剂量1，不重新选参，只改变作用端：

| 作用位置 | OA (%) | BA (%) |
| --- | ---: | ---: |
| 原始 | 46.0894 | 45.0995 |
| 只改支持端，主候选 | 50.4771 | 48.7667 |
| 只改查询端 | 49.7674 | 46.5887 |
| 两边都改 | 50.5278 | 46.7568 |

只改支持端的BA高于全量改写约2.01个百分点。两边改写的OA略高，但不能因此忽略类别均衡识别的损失。这是后续坚持“案例库修正”而不是全局表征替换的直接依据。该表属于固定干预诊断，不是新的验证集择优结果。

## 6. 收益覆盖与失败边界

### 三个几何版本

这些名称表示冻结几何的版本，不是本轮评测了三个目标港。

| 几何版本 | 原BA | 新BA | ΔBA |
| --- | ---: | ---: | ---: |
| Los Angeles | 44.3433 | 48.8890 | +4.5457 |
| Port Klang | 45.7056 | 48.6969 | +2.9913 |
| Santos | 45.2495 | 48.7142 | +3.4647 |

三次独特支持抽样×三个版本，9个非独立读出全部ΔBA为正，范围+1.1755至+7.6868；OA八个正、一个持平。不是9个独立训练种子。

### 各类召回变化

| 船型 | 共同表示方案Δ召回（百分点） |
| --- | ---: |
| 散货船 | -1.1690 |
| 渔船 | +7.7625 |
| 普通货船 | +9.7462 |
| 成品/化学品油轮 | -5.4071 |
| 集装箱船 | +6.8801 |
| 原油轮 | +0.7957 |
| 拖轮 | +7.0309 |
| 海工供应船 | +3.6987 |

六类受益，两类退化，尤其不能忽视成品/化学品油轮。后续若处理该问题，应先在源端验证能否保护油轮边界，不能用当前评测标签做类别开关。

跨9个独特读出，共245个独特观测/146艘船至少一次被救回，163个观测/113艘船至少一次被误伤；两组可能重叠。最大正贡献船366876000贡献约0.5927 BA个百分点；移除这艘船并重新计算类别分母后，平均增益仍为+3.2238 BA。

相反，同船历史预测的+0.2274 BA移除其最大正贡献船后变为-0.0692，说明该微弱正信号仍脆弱，应保留但不作为主模块依据。

## 7. 范围、检查与不应作出的结论

- 本轮评测为旧的823个留船源观测、302艘船、20个源港；支持64个不同船，查询排除支持船。不是新的跨港目标评测、F_0921或OSS2结果。
- 历史两组seed标签实际复用同三组支持划分；本轮已显式去重做船只归因。均值不受重复标签影响，但不能把6个标签当作6次独立抽样。上一轮实际神经网络训练的两个随机种子仍是不同训练，并非因此无效。
- 源先验与源端OOF头排除所有302艘留船评测船；补全器的拟合船与评测船分离。但历史骨干/PCA/几何接触过源数据，留船队列也已反复开发，不是端到端独立确认。
- 共同表示对照是在看到本轮第一阶段结果后提出；剂量仍只用源端选择，但整轮研究有顺序探索性质，应如实报告。
- 本轮沿用初始专家表示，没有叠加上一轮task-only骨干续训，也没有测试基础模型与专家最终融合。+3.6672不能直接加到现有论文主表。
- 使用实际完整专家的支持残差求解器，两块kernel由同一角色特征计算。原始读出与旧缓存、固定支持端干预与已保存候选输出均在1e-10绝对容差内一致；教师2×2共72个重放匹配。零剂量严格回到原模型。
- 运行36次线性残差拟合：首轮24次，匹配共同表示对照12次；神经网络训练0次。保留所有负结果，不改主模型或论文。所有本轮实验进程已结束。

## 8. 下一步应如何接，而不是继续空想

保留“源类别共同表示驱动的支持端修正”为下一步候选，暂不增加蒸馏损失或更大网络。它已经同时具有本轮真实收益空间和一个可实现的利用方式，但跨域有效性尚待确认。

下一项有价值的紧凑实验是：冻结本轮训练目标、正则和源端选择规则，在原完整模型里只更换支持案例表示，比较原专家/新专家及各自相同的最终融合。不动查询表示、源先验、支持预算和基础模型；先用原有目标港的小规模匹配设置判断收益能否传到最终输出。若融合吞掉增益，先拆清专家救回是否已被基础模型覆盖；若油轮继续受损，先定位类别边界，而不是追加全局抑制模块。

不将本轮结果包装为纯因果因素或全新理论。方法上更接近监督度量/原型校准与少样本支持表示改善；我们的潜在增量应落在已有跨港专家管线里的接入位置、源端目标构造和实际有效性上。
