# 从近邻文献看：应该稳定什么，而不是一概抹平什么

日期：2026-10-11。以下基于原论文方法、公式和假设阅读，不是只读摘要。范围是本轮最接近的四项方法，不是穷尽截至今日的所有相关工作；不据此声称唯一原创。

## 1. CoRe：稳定同一对象的预测，不必稳定整段特征

Christina Heinze-Deml, Nicolai Meinshausen. *Conditional Variance Penalties and Domain Shift Robustness*. arXiv:1710.11469，2017 首稿，所读 v5 为 2019。

原文：`https://arxiv.org/pdf/1710.11469`。重点：第 2 节结构模型、第 3.2 节式 (9)-(11)、第 3.3 节组内估计。

CoRe 按类别与对象 ID 分组，在预测风险上加组内预测或损失方差。分类实验用 logits 方差；核心与风格变量的理论保证依赖其结构模型、干预范围和相应渐近条件。

**借鉴**：MMSI 能提供对象配对；可只稳定决策，不强迫整个表示相等。

**本轮差异**：我们用可靠关系掩码选择单位类别差方向，并联合 64 标签适配目标；logit 对照只借用分数一致性思想，配对权重、中心化和训练协议均不同，不叫官方复现。本轮 logit BA 37.274%，未超过 task；不能借原论文成功保证我们的任务必涨。

## 2. MatchDG：对象级匹配，与类内差异共存

Divyat Mahajan, Shruti Tople, Amit Sharma. *Domain Generalization using Causal Matching*. ICML 2021, PMLR 139:7313-7324。

原文：`https://proceedings.mlr.press/v139/mahajan21b/mahajan21b.pdf`。重点：第 4.2-4.4 节、式 (3)-(4)、算法 1。

已知对象时，分类损失加跨域同对象表示距离；未知对象时，先对比学习并迭代更新跨域同类近邻匹配，再用所得匹配正则化分类。其理论讨论区分对象条件不变与类条件不变，并明确潜在因果特征未必可唯一识别；对象不变的论证也有结构和分布条件。

**借鉴**：同类不代表所有向量应一样，应保留类内对象差异。

**本轮差异**：我们已有 MMSI，不靠近邻猜同一船；同类其他船仅验证类别关系，稳定项只约束被选方向。原文主要是无目标标签 DG；我们有 64 目标支持标签，不能混报协议。本轮尚未复现 MatchDG。

## 3. ISR：把不变性写成可提取的子空间

Haoxiang Wang, Haozhe Si, Bo Li, Han Zhao. *Provable Domain Generalization via Invariant-Feature Subspace Recovery*. ICML 2022, PMLR 162:23018-23033。

原文：`https://proceedings.mlr.press/v162/wang22x/wang22x.pdf`。重点：第 3 节假设、第 4 节算法 1-2，以及有限样本稳健版本。

ISR-Mean 对各环境的类条件均值做中心化谱分解，ISR-Cov 对环境间类条件协方差之差做谱分解，取低变化方向再训练分类器。恢复保证在特定线性混合、高斯生成及环境差异假设下建立；有限样本会模糊特征值分离，原文用多环境对的子空间汇总改善稳健性。

**借鉴**：显式坐标可导出、独立读出可检验，而不是仅以准确率命名“因果空间”。

**本轮差异**：我们用真实同船变化和类别关系约束学习 32 维投影，未使用 ISR 的估计器，也不直接继承其恢复保证。小港稀有类的矩估计是否可靠，需要另行检验；本轮未跑 ISR 对照。

## 4. VICReg：避免坍缩，不等于保住所有类别信息

Adrien Bardes, Jean Ponce, Yann LeCun. *VICReg: Variance-Invariance-Covariance Regularization for Self-Supervised Learning*. ICLR 2022。

原文：`https://arxiv.org/pdf/2105.04906`。重点：第 4 节式 (1)-(6)、编码器与 expander 的分工。

VICReg 在增广对的嵌入上同时最小化差异、维持逐维标准差、抑制非对角协方差；训练后丢弃 expander，用编码器表示完成下游任务。

**借鉴**：稳定性约束与下游表示不必完全共用同一个空间；同时须检查常量坍缩和信息冗余。

**本轮差异**：源方差归一化和有效秩诊断不是 VICReg 复现；我们没有其协方差损失或训练后丢弃的 expander。本轮空间未坍缩但分类探针下降，说明不坍缩也不能保证类别信息无损。将“稳定化空间”和“支持匹配空间”分工，是可借鉴的后续设计假设。

## 5. 我们真正可发展的新增贡献

不把“同对象不变”本身当原创。可发展的差异是：针对 SAR 重复观测中不同类别关系可靠性不一致的问题，以同船多观测和条件匹配的同类其他船共同支持的关系，确定哪些判别方向值得稳定；只在这些方向施加归一化一致性约束，并以少量目标支持适配后的识别为实际目标，分别检验分类证据与案例相似度的作用。

本轮提供的初步证据是：判别方向跨港漂移下降，小幅 BA 收益落在分类分数路径；完整空间和 OA 并未同步改善。因而可推进的故事是“选择性稳定决策证据、保留适配所需差异”，不是“唯一提取纯因果因素”。这段是研究差异定位，不是已完成的理论保证或顶刊贡献认证。
