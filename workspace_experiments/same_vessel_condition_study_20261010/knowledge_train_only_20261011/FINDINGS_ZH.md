# 训练期知识锚定：执行结果与根因分析

日期：2026-10-11。状态：**首轮8次拟合、一次限定修正4次拟合以及诊断全部完成，无运行中任务。未修改论文主模型。**

## 结论先行

1. **现有 SAR 表征确实含有超出类别平均值的尺寸相关信息。** 源训练船三折条件诊断中，船长/船宽误差相对类别均值降低41.72%/35.51%，三个折均为正；但条件诊断用了真实船型，不能作为部署性能。
2. **基线32维表示已经隐式包含不少这些信息。** 未见船上，B组32维的类内尺寸读出比类别均值好35.31%/34.63%。没有证据支持“32维压缩把尺寸信息全部丢了”。
3. **显式尺寸监督仍未形成总体跨港分类优势。** 首轮C组目标港BA比B低0.188个百分点；修正辅助头初始化后差距缩小至-0.088，但仍低于B和相应类别均值对照D。
4. **找到并修正了一个真实的训练问题，但不是全部根因。** 随机初始化的辅助头在有限训练步数内没有充分读出已有尺寸信息；源训练闭式初始化显著改善属性拟合，仍不能消除未见船属性误差和分类收益缺口。
5. **发现现有细类标签与AIS记录的实质分歧。** 当前有效属性中的30艘`tug_towing`，AIS汇总描述为Cargo18、Tanker6、Tug4、保留码2。两个分歧实例已确认UID/MMSI/尺寸联结正确，原JSON本身就是`mapping_only`细类标签。不能把该类强尺寸信号直接解释成真实拖轮物理机制，也不能仅凭AIS粗类自动改八类标签。

本轮没有提取出已验证的“纯因果因素”，也没有证明微弱因果相关因素不存在。更具体的结论是：**有可读属性信息，但目前的属性辅助任务没有比基线已经利用的信息带来独特的跨港分类收益。**

## 3. 信息究竟在哪里

先用同一个固定岭回归器读取各模型表示，均只在源训练合格属性上拟合，再在未见船上评价。这样不把A/B未训练的随机辅助头当成其信息不足。

下表是离线真实类别条件下，尺寸误差相对源类别均值的降低比例，不是分类提升。

| 表示 | 船长 | 船宽 |
|---|---:|---:|
| 原始512维 | 29.61% | 23.72% |
| 初始32维 | 33.01% | 31.10% |
| B训练后32维 | 35.31% | 34.63% |
| 原C训练后32维 | 33.16% | 32.24% |
| 修正C训练后32维 | 34.27% | 33.98% |
| 修正D训练后32维 | 35.31% | 34.66% |

至少在此读出协议下，32维并未表现出严重的尺寸信息缺失；B已有可读信息，原C反而稍弱，修正C恢复了一部分但没有超过B。不能因为32维探针优于512维，就推断32维含有更多信息；也可能是固定岭回归在低维下更容易泛化。

直接SAR尺寸读出（没有真实船型输入）在源三折上船宽好于类别均值11.11%，船长差3.98%；但在源留出上，B的船长/宽分别比这个带真实类别的对照差1.55%/3.03%。条件可读性与不依赖真实类别的准确预测仍有距离，真实类别均值只是离线强参照，不是可部署基线。

## 4. 已检验的失败原因

### 4.1 不是辅助损失没接上，也不是预测依赖AIS

针对性测试确认：属性损失有梯度传到投影；缺属性样本仍有分类梯度；所有组统计只从源训练合格尺寸计算；C/D共享属性掩码。12个导出模型移除属性头后，用原始SAR特征重放全部37893行的分类分数与固定案例核，最大差均为0。

### 4.2 随机辅助头确有优化不足，已做一次限定修正

原C选中模型的属性头在训练集上标准化MSE为船长0.4652、宽0.4942；同一冻结表示换成源拟合的线性读出可到0.1681、0.1756。已有信息没有被有限步数内的随机辅助头充分读取，不能直接把原C负结果归为尺寸信息不存在。

限定修正：从相同分类投影起点，用源训练尺寸为C初始化线性属性头，用源类别均值为D初始化；D初始化不使用个体尺寸目标。四次拟合的其余分类设置不变，保留全部原始负结果。

梯度限幅采用原有规则重新计算，因此系数也随初始梯度变化：原两种子0.01683/0.01572，修正后0.02747/0.02720。没有按留出/目标收益调系数；但不能将修正前后差异说成固定数值权重下唯一头参数的效应。

修正C的训练属性MSE降为0.1598/0.1634，问题确实改善。但未见船属性头MSE仍为0.2925/0.3203，比真实类别均值参照差4.99%/6.48%，分类BA仍不如B。**辅助头优化不足不是全部失效原因，修正后仍有泛化与任务效用缺口。**

### 4.3 更稳定不等于识别更好

原C相对B的自身方差归一化同船漂移从1.7155降至1.6057，同船/同类异船距离比从0.8919降至0.8775；同时有效秩从27.37降至25.44。它确实改变了表示几何，却没有换来跨港BA。

修正C的归一化漂移1.7107接近B，属性读出反而改善、BA退化也缩小。结果不支持把“漂移更小”作为独立成功指标，更不支持把原C的几何收缩解释成因果因素分离。

### 4.4 OA与BA的差异来自不同类别的得失

原C-B目标平均类别召回：散货船+1.477个百分点，原油船+0.441，但集装箱船-1.760、渔船-0.610、海工补给船-0.610、杂货船-0.337。完整逐港逐类值保留在training/target_classes.csv。

三港两种子三个支持抽样合计，C-B救回277次查询、误伤229次；这是重复支持抽样下的查询次数，不是独立船数。更多救回不保证各类等权BA上涨。案例身份记录在mechanism/changed_cases.csv，不把净救回数量冒充跨域稳定性证明。

### 4.5 标签/知识参照尚非干净语义

尺寸表与图像的联结已核实，并不意味着八分类标签已被独立船籍核实。详见PROBE_FINDINGS_ZH.md、source_semantic_examples.json。已确认的是原细分类映射与AIS记录存在分歧，不是本轮JOIN错误；尚未确认原映射、AIS记录、身份历史中哪一项是每条分歧的最终责任来源。

这可能限制“尺寸监督帮助某一真实船型”的解释，但目前不能拿它解释所有港口或所有旧负结果。没有因看到结果就自动重标、删类、改队列或重画物理故事。

## 5. 收口与下一步

保留：源三折与未见船上的属性可读性、基线已含相应信息的证据、巴生港局部正值、源原始分类小收益、辅助头不足及修正结果。

不并入主模型：当前AIS尺寸辅助模块。没有证明其独特效用超过多观测教学和类别均值对照；不把更稳定的几何或小幅OA正值替代完整分类结论。

下一步优先解决一个具体问题：**把出现分歧的源船细类映射追到原始依据，确认类别与尺寸知识是否在谈同一对象、同一语义。** 这不是新增模块，也不是认定全部标签错；先核对已经识别的分歧实例，不泛化成全量清洗工程。未经该核对，不继续把这些标签下的稳定子空间称作真实船型因果因素。

同时保留方法与信息不足两种解释：即便标签参照改善，尺寸也可能不足以区分易混船型；现有辅助目标也可能没有把可读属性转成有用决策。当前证据不能保证下一步必涨。
