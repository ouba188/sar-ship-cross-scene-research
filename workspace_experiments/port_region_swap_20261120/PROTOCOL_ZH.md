# 冻结分类器的换参考 × 换细分位置诊断

目的：在实有局部匹配路径上区分参考主效应、粒度位置主效应，以及参考改变粒度位置偏好的交互。不训练选择器、不读取正式测试、不作为未见港结果。

- 使用前轮 baseline_s17 的源验证选中权重（保留全部通道）。原参考库正常软选择的输出与已有缓存逐查询重放；另外重复同条件前向记录数值差。
- 候选是历史源内剩余757中的油化、集装箱查询。固定顺序种子20261120，每艘船只取一张；排除与任一参考同船、同过境的查询。根据几何选出两极化都有效、双方父区域都可细分、各极化有效子槽数相等的查询；不按预测挑样本。
- 原16参考中将首个油化参考分别替换成来自源训练池、尺寸有效、最接近Houston中位数183米的两艘不同Houston船。两艘不同过境，同距离按原索引。每库只换一艘，其他15艘及参考软选择规则保持不变。这是两次具体换船，不是对所有原型抽样策略的统计推断；长度、外观和港口未单独解耦。
- 位置交换一：框内沿无向船轴的两个半区（父槽0、1）。交换二：侧向和轴端各一块（父槽2、6）。两极化都将一块设为细、另一块设为粗，其余六块保持同一样本原软选择；两臂实际正质量槽数逐样本、逐极化相同。这不等同于测得推理加速。
- 分差为真类logit减重新寻找的最强竞争类logit。Δ为同库A减B；交互为新库Δ减原库Δ。报告原始强度、预测翻转和两次替换均反转的计数，同时列出0、0.01、0.05 logit描述阈值，不据此调参。真值只用于读出指标。
- 对照原库/新库正常软选择，以及原库A/B的救回、误伤、持续判对、持续判错。各状态取固定顺序第一例；重复案例不当作独立证据。VV/VH原图及实际参考留在本地。

复用工作区入口，按 `probe.py`、`summarize.py`、`trace_cases.py` 顺序运行。依赖原研究工作区的权重、清单与原图。公开归档不含这些私有输入及逐船记录。
