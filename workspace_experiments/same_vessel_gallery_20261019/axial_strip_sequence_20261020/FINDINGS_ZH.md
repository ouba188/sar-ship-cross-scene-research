# 沿轴条带顺序卷积：小幅OA正信号，排列独立价值尚未成立

2026-10-20，27次拟合、配对统计、源均值替换诊断与8组VV/VH原图回看完成。

## 结论

**沿轴走已经真正实现，不是只改变遍历顺序。但在上一轮有效五点模块之上，本轮未建立值得升级主组件的连续排列收益。** 原主候选五点模块保持冻结并保留。

新顺序卷积平均OA增加0.112个百分点，BA变化-0.005个百分点；三个种子净救回为+3/-6/+19。它比逐点变换后平均的BA稍好，但同容量打乱序列的OA更高、BA稍低，未显示全面或稳定的顺序优势。无需要求每港每类获胜，但当前可重复净收益还不足以支持“沿轴连续排列解决了主要瓶颈”的主张。

源训练集平均残差替换诊断表明，一部分变化可由整体类别分数偏移复现。不能把新模块说成完全无图像依赖：真实输出与源均值替换仍每种子有34/53/64个不同top1；固定卷积模型打乱输入顺序也有预测变化。**“使用顺序”与“顺序带来额外分类收益”仍是两件事。**

## 做了什么

保留原PNG原尺度160画布，不放大/缩小船体；冻结R50浅层、旧轴向Ridge、上一轮MSE keep_refs五点补充模型。新分支是：

原图 -> 冻结stem -> 按船轴/雷达参考组织中心及两侧线 -> 固定4原像素间距的可变有效长度序列 -> 共享64到8投影 -> 两层长度3对称卷积 -> 有效区域池化 -> 新分数残差 -> 冻结五点分数。

两侧线在当前参考方向的OBB投影边缘外4px，沿向覆盖投影两端各外延8px。49仅为补齐长度，不将目标伸缩为49点。按目标/非目标分读，非目标含其他候选，不能称纯环境。无目标框/停用极化的新分支为0，不废弃旧模型输入。角度不直接送入类别头，卷积左右权重共享，侧线对称汇总；不假定首尾、不宣称彻底消除朝向关联。LOS垂线不是精确SAR方位轴。

strip_mean读同样内容，用两层逐点变换后平均；strip_conv采用上述对称邻接卷积；strip_shuffle用相同卷积和容量，但训练/预测都打乱有效沿向次序，内容与掩膜同步置换。mean参数1688，conv/shuffle1816；严格同容量的顺序对照是conv与shuffle，不是mean。

## 根因定位到了哪一步

### 1. 不是只改了访问顺序，也没有漏训

实际条带内容、坐标、掩膜均进入学习器；9个卷积模型中4个源验证选择非零步，5个选择0步。非零模型固定权重后打乱次序，分别产生13/132/42/66个预测翻转。因此模块会使用邻接关系，但对应正确率并未一致改善。

源末步等折/种子平均：训练BA从冻结基座66.126%升至66.727%，验证BA从46.643%降至45.893%。有拟合训练而未稳定迁移到源验证的迹象，故保留0步回退有实际依据。不能将所有退化简单归因为过拟合；当前容量、图像内容、读出和目标匹配仍共同影响结果。

### 2. 判别变化中包含整体类别分数偏移

没有新拟合，只将每个已选卷积模型在源训练集的平均残差向量固定后加到测试基座，得到平均OA41.013%、BA42.515%；真实卷积为41.076%/42.560%。两者差仅0.063/0.045pp。源均值不使用测试标签。

这支持整体分数偏移足以复现一部分变化，而不是证明全部收益均为校准。非零模型的逐样本残差相对源常量仍有明显差异，个别预测不同不能忽略。

fold1/seed0中普通货船残差源均值+0.0527、测试均值+0.0596；散货船测试均值-0.0009。它能同时解释“普通货船被救回”和“散货船被推向普通货船”的方向。具体样本是否跨过边界还取决于原分差与图像相关部分，不以均值替代逐例证据。

### 3. 数据能够提供的是短程线索，不是充分展开的长结构

实际测试船轴中心线目标有效点中位数7、雷达参考中心线5；船轴有效三连点中位数5。原图有峰谷，但stem单位置9x9感受野、4像素步长使相邻特征重叠。3x3局部掩膜占比也不是目标本体分割。

8899原VH可见暗间隔，但64通道均值曲线以较平滑主峰为主。这提示取样层级和平均展示可能掩盖细节；不能由通道均值图认定所有64通道已丢失该信息，更不能据此直接增加分辨率并预言涨点。

1719中心PNG截顶，船轴中心特征均值反而在中间较低、两端较高，提醒我们stem响应不是原图亮度本身。侧线有响应差异，但该例源验证选择的分支为0，未兑现分类变化。

各类召回增益pp：普通货船+0.380、化学/成品+0.293、散货+0.129、原油+0.082、渔船约0、集装箱-0.128、拖船-0.165、海工-0.631。它们界定变化，不作为一票否决。

## 处理决定

保留上一轮五点候选作为当前有效组件。沿轴条带代码、有限OA正信号、正负案例和所有对照完整归档；暂不升为主模块，不继续盲目增加层数/采样点/搜索倍率。

下一次值得回答的是：原图的峰谷/侧向变化在什么层级仍可辨，并且哪部分样本相关变化能超出源均值修正。应先复用本轮token与案例做针对性读出设计，再决定是否调整采样层级；目前没有证明需要抛弃船轴先验，也没有证明更复杂卷积一定有用。
