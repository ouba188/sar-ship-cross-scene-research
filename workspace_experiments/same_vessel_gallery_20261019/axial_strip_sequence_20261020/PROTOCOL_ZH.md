# 沿轴连续序列：冻结旧组件后的增量验证

2026-10-20，结果生成前固定。

## 依据与问题

8899等原图可见沿长轴亮响应及间断，9180的短横向亮团也可作为短序列边界。它们只是图像事实，不是特定船型或物理首尾的证明。旧五点读出把局部均值/差分在空间上汇总，没有显式学习沿整段目标连续位置之间的关系。

要检验的是：相同内容按船轴/雷达参考方向组织后，连续邻接关系能否在已有效五点模块之外补充分类证据。不是改变遍历顺序即可改善，也不是把雷达LOS垂线命名为精确SAR方位轴。

## 数据与输入

复用15,252条开发队列及既有三身份折/日期划分，排除31237，停用既有疑似冲突VH；旧划分不改，非严格留港、非独立新采集确认。使用原PNG原像素160画布裁边/补零，不按目标长度缩放，不统一物理米制尺度。旧R50浅层冻结，四次整数90度旋转读出平均。原图像/身份/采集的既有局限保留。

每个有效目标框：以检测中心为原点，两组参考分别为船轴和雷达LOS（无雷达参考用图像水平轴）。每组取中心条带、两条外侧条带；侧带位于该方向的目标OBB投影边缘外4像素。沿向间隔固定4原像素，范围覆盖目标投影两端各外延8像素，最大49位置，仅用于补齐，不将不同长度拉伸成49点。按目标/非目标有效区域分开读出；非目标包括其他候选与其余区域，不冒充纯环境。无可靠目标框或停用极化的新通道置零，旧模型照常使用。

中心条带是一维采样线，局部宽度来自冻结骨干感受野，不宣称完整覆盖船体宽度。区域权重来自原分辨率3x3局部掩膜占比，在实际采样坐标上读取；浅层感受野已混合的信息不能靠掩膜撤销。

## 四组

1. frozen_fivepoint：上一轮MSE keep_refs各折各种子的已选模型完全冻结。
2. strip_mean：相同条带内容逐点变换后按有效区域平均，不学习相邻位置关系。
3. strip_conv：共享64->8内容投影，两层长度3的对称序列卷积，再区域平均。
4. strip_shuffle：与strip_conv相同容量/训练过程，但训练和预测都按观测级固定随机排列打乱沿向顺序，内容和区域权重同步移动；两侧端点置换成对，保持反向等价。

三条带共享处理，两个侧带对称平均；卷积左右核权重共享，不输入绝对角度，不指定首尾。不同方向独立读出后融合。没有证明任意角度/完整检测链旋转不变或完全消除朝向捷径。mean与conv有少量参数差异，shuffle与conv严格同容量；不能仅凭conv胜mean就归因于空间排列。

## 训练与评价

新分支残差加到冻结五点旧分数。源训练标准化，MSE正类+1/其他-1，原有按类别/身份加权；AdamW .001/.001、150步、128批次、3种子；源验证0/50/100/150步按BA、再Brier选步。0步严格返回冻结五点输出。所有组共享批次顺序、支持范围（本轮无支持适配）、测试样本和选步机会，不依测试标签挑超参数。

报告OA/BA/Brier、净救回/误伤、各类/长度/雷达可用性边界；固定卷积模型的顺序替换仅作依赖诊断，不能替代重训shuffle对照。训练/验证失效时先看中间状态，不自动扩展调参。结束回看VV/VH救回、误伤、持续对/错原图及实际采样位置；当前任务无支持案例，不虚构支持关系。代码、表格、报告和少量案例同步GitHub，不上传大缓存/权重/原始数据集。
