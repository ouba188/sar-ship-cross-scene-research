# 创新模块构思：从独立响应累加到保留对应关系的局部读出

日期：2026-10-20。状态：研究构思与代码/原图复盘完成；没有新增训练，没有新的准确率结果。

## 1. 决策

使用 brainstorming-research-ideas 与 creative-thinking-for-research：从实际问题出发、检查隐藏假设、寻找不变性与判别性的冲突，再压缩为可检验的最小机制。另由独立审阅者只读核对计算图。

建议发展“观测参照下的局部关系读出”：船轴/雷达参考负责组织位置，内容之间的联合项负责表达关系；只对整套坐标的等价翻转保持不变，不主动抹掉目标与邻域的相对对应。第一步做联合卷积/池化的一个核心原型，不同时开发新卷积、新池化、新注意力并将它们算作三项独立贡献。

值得研究的不是“沿轴走一定更好”，而是：在原尺度有限局部证据下，哪一种对应关系比独立读出更能补充跨采集识别。现有正信号保留；本方案的收益与几何特有作用仍待实验。

## 3. 计算图的明确限制

../axial_strip_sequence_20261020/run.py:148-176：逐线、逐角色卷积；分别沿长度池化；两侧平均；线性类别输出。对固定几何、掩膜和输入token，新分支可写为 z(C,S)=f(C)+g(S)。因此侧线改变的logit增量不依赖中心线内容，没有显式跨线联合项。

更重要的是：左右共享的卷积加全局平均，使某一条线内容与掩膜单独反序也不改变该分支输出。中心不动而侧线倒序，目标与邻域的空间对应变了，模型仍看成一样。

我们需要的是无可靠首尾时“整体坐标翻转不改变判断”，不是“每条线可以各自翻转”。这是一个可证明的表达约束区别，不是已经证实的分类失败根因。

边界：旧骨干感受野已混合局部像素，采样几何也依赖目标框，旧五点含端点绝对差。不能据此声称整个系统没有关系信息，也不能说平均池化抹掉一切。新联合模块是否有必要，必须优于合理的普通非线性融合对照。

## 5. 一个核心模块的具体设计

### 5.1 输入与先验的职责

沿用合法原尺度crop/pad、冻结有效旧读出器。第一轮复用现有token，不同时改变区域、分辨率和训练损失。船轴来自检测、雷达参考来自可追溯观测元数据；缺失回退保持显式标识与分组，不伪造雷达轴。VV/VH先分别处理，不默认两张动态chip天然逐像素对齐。

绝对朝向不输入类别头，也不按“角度相近”提高查询支持相似性。船轴/雷达轴只规定局部关系的取样坐标。原像素间距不等于跨产品固定米数；未来跨分辨率扩展需使用真实像元间距，不靠每船缩放消除尺寸。

### 5.2 关系卷积：内容决定另一处响应的作用

记 c_t 为目标中心线局部特征，s_(l,t) 为侧线l同位置特征。最小联合项：

    r_(l,t) = (U c_t) * (V s_(l,t))
    q_(l,t) = m_center,target,t * m_side,non-target,l,t

星号为逐通道乘积，U/V将现有特征投影到低维。q是两端同时有效的配对权重，不是从标签估计的重要性。无有效配对时新项为零；旧主干仍输出。

这使相同邻域响应可以随对应目标内容产生不同作用。它不是将海面减掉，也不预设侧线亮点是尾迹或特定船型。

若最小配对证明可用，再将关系扩为短程delta=-1,0,+1，并在关系维上共享卷积：

    h_t = phi(W0 c_t + sum_(l,delta) W_(l,delta) [(U c_t) * (V s_(l,t+delta))])

delta保持原像素步长，不拉伸到统一船长。与仅转动普通核不同，此处增加了显式内容-内容二阶项。它属于已有关系/双线性运算的任务化发展，不能仅凭公式命名为全新算子。

### 5.3 配对池化：先组合，再汇总

第一版采用 q 加权的 E[(Uc_t)*(Vs_t)]，保留原有一阶读出作为残差基座。船轴参考、雷达参考先分别形成关系向量，避免提前合并两种坐标语义。

给出最小示意而非真实案例：中心响应[1,0]，侧响应[1,0]与[0,1]各自均值都为0.5，但同位置乘积均值分别为0.5与0。配对项能区分“对应出现”和“错开出现”；哪一种有利于哪个类别，要由跨采集训练与测试决定，不能手工命名。

不能把一条线独自反转视为等价变化。对同一参考的整套坐标符号翻转，所有对应线、掩膜、左右角色与偏移同时变换，然后共享模型预测再平均。先形成联合关系再做这种整体对称化，保留相对配置。第一轮delta=0的逐点联合项已自然满足共同反序不变；无需同时更换旧逐线卷积。更丰富的非对称局部核与整体群平均留作后续单独验证。

这只是坐标选择不变性，不是任意真实观测角变化不变性，更不是完全杜绝数据中的朝向捷径。

### 5.4 后续注意力不是必选模块

先用关系向量接原有低成本读出，明确新增信息是否有用。有效后再把查询与支持的关系描述用于支持核或局部匹配，注意力回答“哪些关系有可参考案例”，而不是“哪些亮点看起来重要”。先与等权关系核/FRN式简单读出比较；只有额外净收益成立才加入新注意力。

若保留原支持岭回归，先使用样本独立描述构建正半定Gram核。查询-支持成对注意力可能破坏此性质，不能直接塞进原求解器当同一种核；需改为明确的成对得分模块或另验求解条件。

训练仅用合法源采集/源身份；最终按现有固定先验、相同支持预算与抽样、相同求解器接入。支持缺类保留源先验，不以没有支持为理由删除该类别。3身份折探针结果与完整系统结果分开报告。

## 6. 下一轮最小、可区分原因的实验

第一阶段固定当前输入、旧五点模型、三身份折和三种子，只比较：

| 组 | 运算 | 回答什么 |
|---|---|---|
| A | 冻结旧五点基座 | 保住已有收益 |
| B | 两端分别加权平均后作低维乘积 | 整体非线性交互是否已足够 |
| C | 同位置乘积后加权平均 | 对应位置是否有额外价值 |
| D | 容量匹配的池化后拼接MLP | 是否普通融合即可达到 |

B/C严格共享配对权重q、编码结构、参数量、初始化、训练批次、选步机会。固定编码时C-B等于相应加权协方差；分别训练后不能把预测差直接称为协方差的纯效应。C若胜B，再用单侧倒序或保持有效集合的错配，做固定模型依赖诊断，必要时做从训练开始错配；不把破坏邻接的旧同步shuffle冒充配对专用对照。

优先同位置，不一次扩多种距离或任意可变形偏移。源端预先选定训练日程与尺度；延续既有分数目标以隔离结构，不在本轮同时换损失。

如C确有增量，再比较实际参考与图像参考的匹配结构，检验几何组织的独立价值。邻域没有新增价值而目标内部关系有效时，将贡献收窄为目标结构读出，不硬保留“环境补证”。如果几何无增量，则保留内容关系，不强行命名为物理感知核心。

## 7. 怎样闭环与收口

- 结构闭环：共同坐标反转结果一致；单侧倒序在构造的非对称配对上可以改变表示，表明不再错误地强制独立翻转不变。不要求真实每例都变化。
- 信息闭环：B/C/D与源均值残差替换，区分位置配对、全局交互和总体类别偏移。可重复局部条件净收益即可，不要求处处胜。
- 应用闭环：候选冻结后，进入合法跨采集支持/查询任务，源端决定参数；报告OA/BA、类检索和连续风险、救回/误伤及成本。历史开发数据不充独立确认。
- 图像闭环：持续对/错、救回/误伤分别看VV/VH和实际支持；画出发生贡献的两端位置、内容、角色和实际分差变化。注意力图不能单独证明物理机制。
- 数据边界：侧线无有效目标关联、近方形轴不稳、临船、截顶、极化缺失分别记录，不靠事后删难例制造收益。同景也涨不否定跨场景价值。

## 8. 拟议贡献表述

针对中低分辨率SAR中局部区域独立聚合难以保留对应结构的问题，拟在船轴与观测参考下构造低维目标-邻域联合读出，将坐标整体翻转的不变性与局部相对配置的可辨识性分开处理；通过位置配对、边际交互和普通融合的匹配对照，检验哪些关系能够补充跨采集判别。

真正值得争取的新意是“保留什么关系、消除什么坐标歧义，以及它在本任务中为何有效”的统一设计，不是把双线性乘法、注意力或旋转采样分别宣布首创。目前这是有实现依据的候选核心，尚未验证收益，也未完成首创性排查。
