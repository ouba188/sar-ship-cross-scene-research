# 分类收益与损失的条件分析

2026-10-21，运行分析前固定。复用旧模型和原图，不训练新分类器，不改标签。

## 研究问题

1. 同船不同观测的判别分差变化，与已知几何、目标像素尺度、PNG显示响应、周边候选等因素如何关联？
2. 简单局部补充、联合关系、条件联合三个冻结候选的净收益集中在哪里？
3. 当前数据不能回答哪些训练覆盖/支持组织问题？不以背景作为唯一解释。

## 固定材料和单位

- 使用 paired_relation_probe_20261020 的完整4744测试观测及已有预测。
- 机制描述主队列是此前不按正确性选择的910个MMSI，每船一对最大日期间隔观测；1820原图观测、VV/VH分别分析。它来自24港实验语料，不是F_0921整景队列。
- 三个种子先在同一观测/船对上平均，不计为三倍独立样本。分差统一采用真实类减最高错误类；原predictions.csv的固定竞争类分差不冒充这个指标。
- 源分类器不改；本轮使用历史测试标签开展探索诊断。诊断模型按既有身份折留出船只，不能将此再称独立确认测试。

## 固定因素和对照

- 元数据：VV/VH检测长宽像素、船轴相对雷达无向角的cos2/sin2、入射角、其他候选数；同/跨港、平台变化、时间间隔用于分层。像素长宽非物理船长。
- 原图：各极化框内均值/标准差、255截顶比例、排除检测候选后的其余像素均值/标准差、框内-其余均值差。均为已有Uint8显示图统计，不命名为RCS、海况、尾迹。
- 船对差分为后观测减前观测。报告Spearman相关、逐身份折、同港子集、逐类方向；300次按船对重抽样区间仅描述固定开发队列，不覆盖采集层/重训不确定性。
- 探索性线性Ridge(alpha=10)诊断：metadata/image/both三套固定输入，三折船只留出，训练折内标准化/缺失填补，预测旧模型的同船分差差值。比较训练折均值常数预测，报告每折误差和全体误差，不按结果搜索参数。不作为部署分类器或因果识别。
- 几何差分分组预定为相对角差0-15/15-45/45-90度、入射角差0-2/2-5/>5度；看同船正确性变化和原模型难度，不由结果选阈值。
- 原图回看：包含稳定对、稳定错、对变错、错变对，VV/VH、框内及周边候选分开展示；代表案例不估计全体原因占比。

## 边界与下一步

本轮是观测性关联与读出收益分析，不是角度/水域干预实验。单船配对控制身份但不能控制同时改变的所有因素；同港不等同同水域。未改变训练来源、样本量或支持组成，不能据此归因训练覆盖不足或支持不匹配。先依据可重复关系决定下一轮最小对照，不自动扩展新模块或大规模训练。
