# 结果驱动的限定追查

主分析后发现：100对原油轮的VV/VH对比度差分与原分类分差差分负相关，三身份折方向一致，同港71对仍保留，逐一排除单个产品后方向保留。该候选为24因素/7类别探索中发现，不是预注册结论，相关区间不做显著性胜负宣称。

追加一个固定诊断，不开发新模块：仅用VV/VH两个对比度差分，Ridge alpha=10、原三身份折，分别在其余原油轮上拟合，预测留出原油轮分差变化。已知真实船型仅用于机制研究，不能直接部署为未知船型分类器；对比同训练折均值预测，不搜索特征/参数。

同时分解真实类分数与最大错误类分数变化，并展示对比度方向与分差方向组合的原图。统计数量仍是100艘船，不因种子或多个极化扩大。若有可预测性，只支持这个开发队列的类别条件关系，不证明调整亮度可以涨点，也不命名散射物理原因。

独立审阅后补齐原计划的时间间隔描述，固定0-14/14-30/>30天三档，不按收益选择边界；另生成原图旁的实际区域归属图，核对目标/其他框/其余像素与统计计数一致。原始raw案例图仍保留。
