# 分类收益与损失：先找到类别条件关系，而不是统一归因背景或角度

2026-10-21。本轮完成缓存再分析、3640幅原始VV/VH图的统计、同船配对诊断、图像回看及结果核对。没有训练新分类器，也没有替换主模型。

## 一、结论

1. **目前最清晰的是类别条件差异，不是统一的“大角度更难”“背景更亮更难”。** 同船配对中，普通货船/拖船更多是持续判错；原油轮更常出现一次对一次错。总体数据关系很弱，不能据此否定具体类别的有效关系。
2. **原油轮出现可保留的关联：同船框内相对周围的显示对比度增加，旧模型的原油轮判别分差反而倾向下降。** 100艘船，VV/VH相关系数-0.375/-0.389，三个身份折均负，同港71对仍负，逐一排除单个产品后方向保留。仅用两个对比度差分的小线性诊断在留出船上降低分差预测MSE约23.81%，三折均改善。这是事后发现的类别条件关联，尚非物理因果或分类涨点。
3. **场景分组差异会被类别组成改变。** 未校正时跨港“两次都错”38.80%低于同港43.92%；按7类等权后跨港50.94%高于同港46.06%。不能直接把粗分组差异叫作港口影响。
4. **已有组件有不同类别的收益边界。** 简单补充对原油轮召回+1.399个百分点，三种子均正；对海工-1.515、集装箱-0.321，三种子均负。联合关系对集装箱+2.312，但对散货-2.196。不是所有模块都应按同一种全局规则加强。
5. **尚未完成同景/跨景训练矩阵、严格框内/整图重训对照或支持替换。** 当前配对两端使用相同fold/seed的同一个源分类头，无目标支持适配。不能把损失归因支持失配，也没有证实训练覆盖不足。

## 二、实际材料与口径

- 数据来自24港历史实验语料，而不是F_0921新整景。完整测试4744观测、2973个MMSI、18港、8类；使用此前冻结五点读出及marginal/joint/joint_condition分支的三种子预测。
- 同船机制主队列每船一对，910个MMSI、1820观测、7类、13港、65产品。渔船缺席；721对同港、189对跨港。按最大日期跨度选对，与预测正确性无关；已做元数据/跨极化对应筛选，但不等于910对全部人工确认。
- 三种子对同一船对先平均，不当作2730艘船。VV/VH分别统计。原图不重新拉伸、不缩放目标；显示图中的均值、标准差、255比例不是定标RCS或实测海况。
- 目标区域来自现有OBB；其余区域排除目标和其他可用检测框。OBB不等于完整真实船体，未检测响应也不一定是纯海面。
- 统一判别分差为真实类分数减最高错误类分数。此前predictions.csv的固定竞争类分差不直接替代此定义；本轮从冻结scores重新计算并核对。
- 本轮使用历史测试标签进行探索诊断，沿用三身份折作诊断留船验证；不是新的独立确认集，也不是留采集验证。不同船仍可能共享产品。

## 四、几何、地点与总体图像统计

相对船轴-雷达轴差0-15/15-45/45-90度分别189/337/384船对；两次都对17.81/21.86/20.23%，一次对一次错36.33/35.11/38.54%。没有“大角差越大正确率越低”的单调规律。按类别等权后CC17.62/18.30/18.75%，仍不能以粗角差直接定难度。

入射角差0-2/2-5/>5度分别503/231/176船对；原始CC21.40/21.07/16.29%。但类别等权后CC19.55/17.73/17.31%，一次对一次错35.44/31.51/33.66%并不单调。可以保留大入射角差关联难度的候选，不把它当已隔离的独立原因。

时间间隔0-14/14-30/>30天分别263/206/441对，原始CC20.91/17.80/21.16%，WW42.08/46.60/41.57%，没有单调的“隔得越久越差”关系；当前最长跨度选对与时间/港口/类别组成同时变化，不作时间因果解释。

整体24个因素差分与分差变化的Spearman相关绝对值均小于0.086。统一小线性诊断的船只留出MSE：

| 输入 | MSE | 常数预测MSE | 相对误差变化 |
|---|---:|---:|---:|
| 几何/检测像素尺度/邻框数 | 0.299455 | 0.296454 | +1.01% |
| 图像区域统计 | 0.296527 | 0.296454 | +0.02% |
| 两者合并 | 0.299335 | 0.296454 | +0.97% |

这只说明当前低维、类别共享的线性解释不足，不等于所有关系不存在。相关置信区间仅按船对重抽样，未覆盖共享采集或开发筛选的不确定性；未将24因素的单个区间作为显著性发现。

## 五、值得继续的原油轮条件关系

显示对比度定义 C = mean(PNG/255 in OBB) - mean(PNG/255 outside all candidate boxes)，每个极化单独计算。分析后观测减前观测的delta C，不是直接以亮度阈值分类。

| 检查 | VV rho | VH rho |
|---|---:|---:|
| 全100对 | -0.375 | -0.389 |
| 同港71对 | -0.439 | -0.452 |
| 身份折0，40对 | -0.279 | -0.512 |
| 身份折1，34对 | -0.514 | -0.429 |
| 身份折2，26对 | -0.349 | -0.136 |
| 逐一删除单个产品后的范围 | [-0.429,-0.271] | [-0.481,-0.315] |

结果驱动的追加诊断已单独记录在POSTHOC_FOLLOWUP_ZH.md：固定两个输入、Ridge alpha=10，分别用其余身份折原油轮拟合。留出40/34/26对MSE为0.3814/0.3883/0.4883，训练折均值对照0.5309/0.5363/0.5595；合并0.4115对0.5401，降低23.81%，OOF Spearman0.413。三折两个系数都为负。它使用真实类别限制研究对象，不能直接当未知船型的部署模块。

模型分数链：VV/VH对比度增量分别与真实原油轮分数变化rho=-0.370/-0.372，与最高错误类分数变化rho=+0.325/+0.317。因此关联不只是竞争类在更换，真实类和竞争类的分数均参与。仍属于冻结模型证据记账，不是原像素干预或物理成因识别。

不是确定规则：平均VV/VH对比度增/减与分差增/减四组合共18/31/31/20船对，反向关系62对、同向38对。不能要求每艘船符合，也不能忽略反例。

尤其不能据此直接设计“压低船体亮度/抬高背景亮度”的模块。对比度由目标和周围两端共同决定，可能代理当前显示拉伸、散射结构、检测尺度和观测条件。下一步要分开这些可能性。

## 八、下一步：先区分“信息变化”与“利用错误”

优先围绕100对原油轮的可重复关联，而不是再给全体船加入角度网络。限定三步：

1. **核查显示处理依赖。** 找可追溯的同观测拉伸前数据/拉伸参数，分开目标增亮、周围增亮和局部结构变化；若恢复不到就保持PNG层面的结论，不当RCS规律。
2. **固定查询的读出对照。** 在相同源训练/验证协议和同一批查询上，比较真正卷积前框外屏蔽、整图、框内/框外分开读出；保持目标原生像素大小与可用尺寸字段一致。检验对比度相关的错误是否来自周围输入，还是框内判别也有同样问题。测试时单独遮挡仅作敏感性诊断，不能替代配套训练。
3. **单独检查训练覆盖。** 从现有训练索引恢复实际原油轮和主要混淆类的条件覆盖，先统计不重训。若发现可比较的覆盖缺口，再固定查询、训练量与类别配额做同/跨采集来源替换。完整支持流程需另轮固定支持再接入；当前没有支持集，不凭空解释成支持问题。

此处尚未验证上述新对照，不承诺其一定涨点。本轮保留一个有实证基础的类别条件候选及各模块有效范围；不因全体线性诊断未改善而否定它，也不据此包装成因果因素已分离。
