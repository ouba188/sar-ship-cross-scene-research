# 局部条件模块：结果、数据错误隔离与使用边界

日期：2026-10-19。状态：36次训练完成，固定模型干预、五组原图回看完成。原始数据及旧轮结果保留；未接入完整查询-支持适配系统。

## 首先纠正31237

用户确认31237的VV/VH不是同一物理对象，属于数据集错误。该例不能证明船型救回、极化差异或条件化物理机制。已建立EXCLUSIONS.csv，从本轮训练/验证/测试中隔离，而非仅停用VH。保留原始图像、历史数值和发现过程，不修改标签或人工交换框。

发现时第一折首个plain拟合完成；已中止该轮，移存interrupted_before_quarantine，重新完整执行36次。沿用原划分再排除31237，其他身份、采集及源训练统计不重新抽取。最终查询4744条、2973艘船、18港、8类。31237不在源训练或验证时间带，故旧分类器及PCA拟合样本不变。上轮去掉该例后OA增益仍为1.9604pp，但不能据此挽回该例的解释。

固定队列15252条的地理对应检查：10330映射到VH目标框，48映射到其他候选框，266映射出图，4608未知。其余47条疑似冲突没有自动判为数据错误，四组统一停用这些观测的新VH局部分支，旧模型不变。坐标未知不等于错误；落入目标框也不是独立身份真值。scale未给CRS，使用同产品同scale来源共享坐标系假设，不能称为独立测绘验证。详见ALIGNMENT.json与crossview_alignment.csv。

## 做了什么

依据上轮全局乘积交互正信号以及原图中多目标/框外响应混杂，冻结既有interaction Ridge，只训练局部补充通道。

1. VV/VH原PNG分别等比例置入96方形画布，不旋转、不重新逐图拉伸。冻结ImageNet R50 conv1/bn/relu，面积汇聚到24x24，保留64通道。
2. 原生OBB划分T目标、O其他检测候选、R剩余chip。其他框与T互斥，padding不属于任何区域。空区域严格保持空。三类区域是检测代理，不是干净物理成分；R不是纯海面。
3. 1x1投影至12通道，每区域独立进行三组可学习3x3逐通道卷积，输入先按区域屏蔽并以有效邻域质量归一化。
4. 区域内容摘要与相对朝向/入射角及有效性标志产生滤波混合权重。pre先混合局部响应，再非线性和内容加权池化；post先对各滤波器非线性及池化，再按条件混合。
5. 保留2极化x3区域描述，线性头输出8类残差，加到冻结旧分数。头初始严格为0；源验证可选择0步而不改变旧输出。

四组均3057参数，plain同结构但条件输入置0，wrong从训练开始错配条件；所有组固定150步、batch48、AdamW lr0.001、weight_decay0.001、三个训练种子、三个身份折。源验证每50步选择BA优先/Brier打破并列端点，测试不选参。类别/船次平衡采样，使用与旧Ridge一致的正负一编码平方损失。预先协议见PROTOCOL_ZH.md。

没有实现旋转采样网格，不声称已验证可转向卷积；池化仍是普通内容加权池化，未实现有限偏移跨区域共现。不能把本轮命名为三个原创算子。掩膜在冻结stem之后，不能消除stem感受野中已有的信息混合。

## 结果：保留小收益，不扩大主张

下表先合并每个种子的三折预测，再对三个训练种子求均值及样本标准差；每种子均4744条同一查询，不把三个种子当作三倍船只。

| 方案 | OA%均值±SD | BA%均值±SD |
|---|---:|---:|
| 冻结旧全局条件交互模型 | 36.320 | 39.512 |
| plain：无条件局部补充 | 35.483±0.330 | 40.075±0.319 |
| post：汇聚后条件混合 | 35.926±0.219 | 40.503±0.243 |
| pre：局部响应先条件混合 | **36.453±0.317** | **40.388±0.633** |
| wrong：训练起错配条件 | 35.666±1.041 | 40.301±0.331 |

pre相对旧模型OA+0.1335pp，BA+0.8759pp；三个种子OA增益+0.4637/-0.1686/+0.1054pp，BA+1.4410/+0.9946/+0.1921pp，救回/误伤分别222/200、123/131、151/146。Brier约0.81709降至0.81170，固定温度1转换，不能解释为已校准概率。

船级分层bootstrap500次，先对同观测的三个训练种子配对差求均值：OA增益95%条件区间[-0.528,+0.705]pp，BA[+0.163,+1.530]pp。没有包含重新训练、场景相关性或预训练暴露的不确定性。可保留BA层面的有限收益，不要求每港每类获胜。

pre相对plain平均OA+0.970pp、BA+0.313pp；相对post OA+0.527pp但BA-0.115pp；相对wrong OA+0.787pp、BA仅+0.087pp。不能说聚合前条件交互在所有指标上更优。

固定150步不做源选端点时，pre OA35.947%、BA40.644%，与源选端点形成OA/BA权衡；不是测试选优。pre九个折种子中有两个选0步。源验证波动及损失/BA选择与目标OA不完全一致，是实际范围；不能仅据此判定代码错或所有局部信息无用，也不追加无界训练扫参。

## 条件到底有没有起作用

固定训练好的pre，仅替换预测时的条件：OA36.467%、BA40.294%，相对正确条件OA+0.014pp、BA-0.094pp。三个种子分别改变329/67/136条预测，错配后的救回/误伤81/84、19/16、36/34。

这说明条件并非完全未进入模型，但正确对应产生的净收益很弱，纠错和误伤大体抵消。当前结果不能把局部模块收益主要归给正确物理几何。旧基线本来就使用全局正确条件，本轮检验的是其上的额外局部作用，不是条件总体有没有价值。

## 哪些信息在贡献，哪些在误导

固定pre读出，去除指定区域的最终描述贡献，不重新训练、不作为本轮选择规则：

| 输入干预 | OA% | BA% |
|---|---:|---:|
| 完整pre | 36.453 | 40.388 |
| 去T目标描述 | 35.807 | 39.441 |
| 去O其他候选描述 | 36.509 | 40.439 |
| 去R剩余描述 | 36.172 | 39.460 |

T与R均有净作用；O整体未带来净收益，去除后仅微小改善。不能直接把R叫环境、O叫邻船真值，不能把测试后去O结果冒充已选部署方案。

分类召回变化：渔船+4.83pp、集装箱船+4.05pp、原油轮+2.88pp、拖船+1.65pp、成品/化学品+0.68pp、海工+0.25pp；散货-1.78pp、普通货船-5.54pp。整体BA改善伴随类别取舍，不能概括为全体更稳。

数据对应分层：映射落目标框3913条，OA-1.25pp、BA+0.56pp；未知723条，OA+7.75pp、BA+2.42pp；出图91条OA-1.47pp；疑似冲突17条OA+3.92pp（已停用新VH）。总体OA的正信号主要依赖未知对应子集。未知常由地理元数据缺失造成，不等于标签错误，但目前不足以支持跨极化物理解释。不能因该组涨点便跳过这一边界。

## 原图及作用位置回看

五组案例均为种子20261019，原始VV/VH分开、固定0-255、原生像素展示，绿框T、橙框O。贡献为对指定竞争类的线性残差分差，不是注意力物理真值。具体路径及贡献见case_review.csv。

- 17957，渔船，宁波，救回：图内紧凑低亮主体，周围少量弱响应；旧海工margin-0.414变渔船+0.299。VH的T(+0.335)与R(+0.263)主要贡献。两路对应状态未知，因此只作模型读出案例，不作已证实同船极化物理案例。
- 31244，成品/化学品船，新加坡，映射落目标框的救回：旧海工-0.175变正确+0.157。原图有中心强响应及上/下分离亮响应；最大帮助来自VH其他候选区域(+0.246)，不是目标自身证据主导。这个救回支持“模型用了周边对象”，不能证明“船体散射被解释”。中心落框一致仍不是邻物体类别真值。
- 7052，普通货船，鹿特丹，误伤：低亮细长主体，VV可见分离亮斑，VH较连贯；旧正确margin+0.048变渔船-0.283。VV目标描述贡献-0.245，是主要误导项，并不是所有误伤都来自邻船。
- 14679，渔船，宁波，持续正确：暗背景下窄弱竖向主体，margin+1.544到+2.238；VH的T/R共同增强。仍为对应未知，不强行命名散射物理。
- 26119，成品/化学品船，Port Klang，持续错误：强亮中心船形响应与右边缘独立候选，旧海工-0.261变-0.669。O区域在VV/VH分别贡献-0.177/-0.213，说明候选邻域确有误导实例；只证明该模型利用方式，不证明边缘物体实际船型。

31237从本节证据中移除，其数据错误说明单独保留。

## 收口与下一步

本轮保留：冻结旧模型、局部区域分开读出的低成本补充候选，尤其BA层面三种子均改善；代码与负结果保留。尚不晋升完整模型或宣称新几何卷积机制成立。

下一步优先围绕证据归属：在可核实对应的样本上，保留T/R，单独约束O不能作为目标身份的直接替代；用真实查询-支持关系验证局部读出能否改善同类与混淆类匹配。需要先沿已有场景/检测关联修复已确认错误，不能用“可能是数据问题”解释所有退化。也不因为未知子集有收益便要求全部数据重做。正确条件的独立增益较弱，此时继续叠新注意力的依据不足。
