# 局部条件卷积与分区域池化：运行前协议

2026-10-19。本轮从已有全局交互正信号出发，冻结该分类器，只训练局部补充通道；不是完整支持适配主表，也不同时宣称三个原创算子。

依据：31237被救回但图内存在多个额外亮响应；5155误伤且VV/VH背景差异明显。全局乘性交互无法定位证据。局部模块必须分开目标框、其他检测候选框、剩余chip，并分别处理VV/VH。检测框只是候选归属，不等于真实目标/海面标注；冻结骨干的感受野仍可能混入框外信息。

队列及训练/验证/测试隔离完全沿用conditional_evidence_pilot/cohort.csv和indices函数。已有缓存预训练暴露限制不变。只在本地生成新局部缓存，不重建活动图库。原图等比例适配96方形画布，空白补零并屏蔽，冻结ImageNet R50的conv1/bn/relu，面积汇聚成24x24；保持原生坐标角度，不做旋转增强或各极化拼像素。当前卷积作用于该特征尺度，不解释为固定米数。

模块：64通道投影到12；三组可学习3x3逐通道卷积。每个区域在新卷积前屏蔽，按有效邻域质量归一化，空区域严格输出0。区域内容摘要与本极化可用的相对角、入射角共同产生每通道三个滤波器的混合权重；正确条件对局部响应加权后经GELU，再用内容加权池化保留六个极化-区域描述。最终线性头输出8维残差，初始为0，叠加冻结旧分类分数。不是用角度计算样本相似度。本轮只检验条件混合滤波，尚未旋转采样网格，也不是已经验证的船轴/雷达轴可转向卷积；池化保留区域但未实现有限偏移跨区域共现，注意力为普通内容池化，不宣称三种新算子已经成立。

四组相同参数量：plain将几何输入置0但仍用内容产生权重；post先分别非线性及池化三个滤波器再按条件混合；pre先按条件混合局部卷积响应再非线性及池化；wrong与pre同结构但训练开始条件按划分内港口/平台/季度整体错配。post/pre区别包括非线性、池化与条件混合的顺序，不把任何差异单独归为池化创新。条件实际为每极化3个标准化数值及3个可用性指示；缺失数值置源均值，不能假装缺失角等于实际零角。plain将这六个输入都置0。

训练前的数据修正：原始案例31237发现VV目标映射入VH其他候选。对固定队列按同产品/相同scale来源的原生仿射进行点落框检查，48条存在此类冲突，所有组只停用这些观测的新VH通道；不交换框、不改标签、不删观测、不改旧分数。266条映射到图外及4608条未知不算已确认对齐，保留标志及分组分析。scale未提供CRS，使用同产品同来源同CRS假设，不声称独立测绘验证。

基础分数重放上轮源端所选interaction Ridge。补充通道使用与旧Ridge一致的正负一编码平方损失，按类别和船重复次数平衡采样，AdamW lr0.001、weight_decay0.001，batch48，固定150步，源验证每50步一次；允许0步保留旧模型，按验证BA优先/Brier打破并列选端点。不按测试改步数或学习率。三个身份折、三个训练种子20261019/20/21、四组，共36次训练。

评估：原4745测试观测除去用户确认错误31237后为4744；逐折/种子OA/BA/Brier、逐港逐类、救回误伤。主要比较pre对旧模型、plain、post、wrong。报告固定训练终点和源选端点，区分学不会/过拟合/选择不迁移。固定模型分别去掉目标、其他候选、剩余区域的残差贡献，及错配条件，检查收益来源；这是模型读出干预，不能证明原始物理因果。

用户确认后的隔离修订：31237不是同一物理对象的VV/VH配对，属于数据集错误，不再作为任何有效救回/物理解释案例。EXCLUSIONS.csv记录依据，所有训练、验证、测试集合都在原有划分后排除该ID，不重抽其他身份/采集，不删除原图。发现时仅第一折第一个plain训练完成，已中止，输出移至interrupted_before_quarantine，正式36次从头执行。该观测不在源训练/验证时间带，因此源PCA及旧分类器训练样本不变，旧预测只在相同4744查询上重新汇总。其余坐标疑似冲突没有自动升格为确认错误，单独标记。

实现测试只针对实际风险：区域像素归属与补零质量、空区域输出、屏蔽后其他区域改变不影响本区域模块输出、初始残差精确为0、条件对pre反向梯度可达、三极化区域位置索引正确。完成后必须看救回/误伤/持续正确/持续错误的VV/VH原图与区域覆盖。正负结果都保留并同步GitHub。
