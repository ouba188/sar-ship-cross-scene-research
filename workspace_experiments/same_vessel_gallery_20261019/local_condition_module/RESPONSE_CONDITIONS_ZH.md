# 哪些条件下值得参考局部响应

2026-10-19。仅复用本轮冻结模型、预测及区域描述移除缓存，没有新训练或策略选择。31237继续排除。4744条观测、三个既有训练种子；分组结果是探索性边界，不是已经验证的在线开关规则。

## 量的含义

区域净作用 = 完整pre的OA - 固定同一模型但移除该区域描述的OA。它不是完整pre对原基础模型的提升，不能把不同区域净作用相加。所谓目标/其他/剩余仍是OBB代理，并非纯物理成分。训练种子均值不表示三倍独立船数。

输入分组均不使用测试标签：旧模型最高与次高类别分数之差（不是需要真标签的margin列）、VV目标框面积占有效chip面积比例、有效其他候选是否存在。前两者分界取各折源验证集25/50/75分位点，第三者扣除已停用的新VH。测试标签只用于最后统计纠错/误伤，没有据此选择开关。分组选择本身是在已开发数据上的探索，仍需源端学习并在后续采集验证。

“旧模型越不确定，越该看邻域”没有形成可靠的OA规则。最低分差四分位1319条中，R均值仅+0.202pp，范围-0.986至+2.274，1/3种子正；其BA+2.785pp与OA不一致，反映类别权衡。第三分差四分位1211条中T净作用+1.596pp、3/3正，说明有价值的补充并非只发生于最不确定样本。分差不是已校准置信概率。

其他候选O在259条上的负作用，均值每种子救回3.33、误伤6条，是有限样本下的小数量证据；不证明任何邻船信息都没用，也不证明检测候选均为真船。它支持当前不宜把O直接当作目标身份特征使用。

## 对应可靠性仍是解释边界

映射落目标框3913条中，T的OA净作用+0.128pp，R为-0.204pp，但R的BA为+0.671pp；未知对应723条中，T/R的OA净作用为+3.596/+2.997pp，均3/3正。未知不等于错误，但总体OA正信号依赖该组的事实仍在，不能把全队列统计直接讲成跨极化物理规律。

## 与原图证据怎样对应

本分析没有新增预测翻转，复用本轮已回看的原始VV/VH案例与区域分差：

- 7052目标框内描述误伤，说明目标来源正确不保证局部形态不会混淆；低旧分差也不能成为自动加强补充的充分条件。
- 31244的O帮助救回，但26119的O加重错误。259条子集统计说明这两种情况共存且当前净负，不能把单个好例子推广为邻域准则。
- 17957和14679中T/R共同支持渔船，但两路对应仍未知；它们可以解释模型在哪里加分，不能充当已验证物理机制。
- 31237为用户确认数据错误，始终不参与。

## 设计含义，而非已部署结论

1. 将目标相对尺度、有效像素覆盖、原模型前两名差距作为源端学习的条件输入，而不是仅用角度；不把测试分组的最佳阈值直接做成门控。
2. T与R保留独立通道，让模型可以调整互补程度；目标小并不意味着应一律放大邻域。
3. O优先作为独立对象/上下文信息，不能无条件并入目标类别描述。是否作为遮挡/拥挤条件，或通过可信支持关系使用，仍需独立对照。
4. 用同类不同船、不同采集的真实支持案例检验这些条件能否预测净收益；当前局部实验没有支持集，因此尚未证明支持可靠性规则。

建议可概括为：目标自身证据保底；剩余区域有条件补充；其他候选不能直接替代目标。这里只得到可检验线索，尚没有能事先可靠判断每张图该参考哪里的规则，也没有得出某个朝向/入射角区间必然有益。
