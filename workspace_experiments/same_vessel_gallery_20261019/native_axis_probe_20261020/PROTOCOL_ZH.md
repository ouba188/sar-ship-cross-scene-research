# 原生尺度、前后交换不变的结构小验证

2026-10-20，结果产生前固定。目的：检验按船体长轴组织局部内容是否比整块或无关分区有用，不验证没有标注的真正首尾语义。

- 输入为本地固定快照的VV/VH原PNG，160裁边补零，不缩放、不做任意角插值旋转。排除31237；已知疑似冲突VH停用。船体像素长度、宽度保留，米制尺度未统一。
- 冻结R50浅层conv1/bn/relu，固定2x2响应池化。分别输入0/90/180/270度无插值旋转，区域同步旋转，对区域描述平均，避免这些绝对方向直接决定分类。不是任意角度旋转不变证明。
- 全部分类头不输入船轴角、雷达角、入射角、港口名、坐标或日期。轴仅用于分区，所有组共同输入无向长度/宽度及区域像素数，以免新组仅靠额外尺度字段获益。
- 整块基线读取T/O/R；新组额外读取目标内三段：两端均值、中间、两端差的绝对值。交换端点后描述完全一致，不按亮端猜尾部。
- 同维对照：横向三段；随机打乱轴向区域位置但保留每段像素数。图像范围、骨干、掩膜归属、极化和分类器相同。随机分区仅为位置诊断，不是可部署先验。
- 沿用既有按船只身份和日期/产品隔离的三折，保持排除前分配；alpha仅源验证BA选优，Brier打破并列，候选0.1/1/10。测试不选阈值。三折不是三个随机训练种子。
- 与历史OA36.32等不能直接比较：本轮使用原生输入浅层表征，没有历史缩放双骨干或条件基线。只做本轮配对对照。
- 检查原像素及目标覆盖、描述90度旋转一致性与端点交换一致性。结果报告OA/BA、逐折、逐类和救回/误伤；回看原始VV/VH案例。没有支持集，不编造支持匹配解释。
- 仍可能存在非90度的朝向信息和场景关联；不直接输入角度不等于证明完全没有方向捷径。历史ImageNet预训练未重新做源域限定。
