# 源训练覆盖分析

日期：2026-10-21。状态：完成。仅在本目录新增脚本、元数据统计及报告；没有训练分类器、读取特征大数组、读取原图或开展论文检索。图像对照、论文、原图回看及合并后的 GitHub 同步由主代理负责。

## 结论

合法 source 内原油轮的独立船和观测明显少于散货船，但不是“原油轮类别总损失权重较低”：每折的八类总样本权重严格相等。100 同船对的 200 个端点，大部分处于原油轮训练几何范围及邻近条件内。按训练数据自身的邻近距离 95% 参照，VV 有 6/200、VH 有 12/200 个端点超出；两极化合计 14 个独立端点。当前结果不支持将主要错误普遍归因为这些几何维度上的源覆盖缺口。

覆盖仍有可定位的局部不足：固定邻域内 VV 11/200、VH 12/200 无原油轮源邻居；两极化合计 15 个独立端点。3 个端点在对应训练折中没有同港原油轮，31 个没有同港且同平台的原油轮。散货船邻居更密集，但类别权重、船数、可用几何和产品组成共同作用，不能从邻居数直接推出模型偏向散货船的原因。

上述各类每折都有两个平台，具体平台、港口、产品的观测数与独立船数见 `category_coverage.csv`。八类完整 train/val/test 统计见 `class_coverage.csv`。

实际 source loss 权重为：

`w_i = N_train / (8 × n_obs_of_ship_i × n_ships_of_class_i)`。

因此每类总权重为 `N_train/8`，分别为 549、552.375、552.25；同一类内每艘船总权重相等，同一艘船的观测均分该船权重。重复观测增加观测量，不增加该船的总损失权重。每类每折的实际权重总量已检验，逐条权重可在 `split_membership.csv` 复核。

这里说明的是 paired_relation 训练残差头调用的 `prior.weights(f,tr)`。其 source PCA 协方差采用 token mass 加权，标准化采用相应有效训练观测的均值/标准差；不能把 loss 的类别等权扩写成“所有处理阶段都按类别、船舶等权”。本报告也不审计骨干网络原始预训练集的覆盖。

以全部 405 个原油轮测试观测、三个 baseline seed 的 1215 次预测计，719 次正确；误分为散货船 240 次、集装箱船 156 次、成品油/化学品船 58 次。因此重点展示这三类，覆盖脚本仍为所有八类计算相同统计。seed 事件不是独立观测，不能将三个 seed 当作三倍证据。

## 几何口径

读取 `view_snapshot.json` 的 ship_axis、radar_axis/radar_kind、radar_incidence、OBB 原生像素长宽及可用性字段。VV/VH 分开计算；不读取 PNG 或特征数组，不使用原始经纬度、投影坐标或仿射变换判断水域。港口仅采用 cohort 中已有港口标签。

相对轴角是无向船轴相对 orbit LOS 的角度，保留带符号的 180 度周期。邻近距离使用圆周差，避免 -89 度与 +89 度被误认为相差 178 度。单变量范围额外报告绝对锐角 `[0,90]`；这个范围不是完整的有向相对角覆盖证明。OBB 长宽均为快照的原生像素尺寸，不是实际船长宽，也不据此命名物理机制。

`geometry_ranges.csv` 给出每折、划分、类别、极化的 min/max、5/50/95 分位数、source 权重分位数和字段可用量。单字段统计使用该字段可用观测，联合邻域要求轴、orbit LOS、入射角均有效。原油轮训练 VV 有效几何为 239/284/253，VH 为 235/280/251；200 个待比较端点两极化均有完整几何。VH 缺失不以 VV 或零值填补。

## 邻近条件

计算前固定描述性尺度：相对轴角差 15 度、入射角差 3 度、OBB 长宽各不超过 1.25 倍。定义距离：

`d = max(axis_gap/15, incidence_gap/3, abs(log(Lq/Ls))/log(1.25), abs(log(Wq/Ws))/log(1.25))`。

`d <= 1` 表示同时满足四个邻近条件。它是便于解释的描述性邻域，不是经过测试准确率优化的阈值，也不是物理等价或分类可迁移的判定标准。导出连续距离、最近邻 ID/船/产品及各维差值，避免结论只依赖二值阈值。

另以每折、每类、每极化的 source 内部最近邻距离生成参照：对每条训练观测，排除同 MMSI 和同产品候选，取剩余最近邻；用原始 source 权重计算经验 95% 分位数。缺少几何的训练观测不参与，保留其余观测原训练权重再归一化，不重新赋予“几何有效子集内每船等权”。这样不把同船重复暴露或同产品多个 chip 当成独立校准邻居。参照分位数从未使用验证或测试正确性。

原油轮 VV 的 source NN95 为 1.097/0.978/1.073，VH 为 1.066/0.960/1.002。不同类别阈值不同，稀疏类别自己的阈值会更宽；跨类别比较应看统一固定邻域及连续距离，不能用各类“超过自己95%”比例直接排列绝对覆盖优劣。这些分位数也不是显著性检验或具有校准保证的异常概率。

该结果说明若干主要类别共享这些几何条件，几何邻近本身不等于类别可分。散货船源船数更多，邻居数会随供给量上升；其 VH 完整几何只有 540/535/508 个观测，也不能将 VV/VH 邻居数差异全解释为场景差异。`endpoint_source_coverage.csv` 同时给出邻近观测/独立船/产品/港口数量和邻域占原始 source 类别总权重的比例，避免仅比较样本数。

原油轮所有端点都有同平台 source；3 个没有同港原油轮 source 的端点是 fold 1 的 22553、5197、22554，港口标签均为 Richards Bay。另有 31 个没有同港同平台组合的原油轮 source。测试产品与 source 产品整体不交叉是设计使然，不把“没有同产品”记为数据缺陷。港口缺口不能推断近岸/外海、海况或背景机制。

## 覆盖与预测的事后关联

覆盖定义、source 参照和端点覆盖计算完成后，才读取既有 baseline scores。下面正确率为每端点三个 seed 正确率的均值，不产生新的分类器、门控或阈值选择。

|---|---:|---:|
| 超过 source NN95 | 6 / 61.11% | 12 / 55.56% |
| 未超过 source NN95 | 194 / 54.81% | 188 / 54.96% |
| 固定邻域无同类源邻居 | 11 / 54.55% | 12 / 66.67% |
| 固定邻域有同类源邻居 | 189 / 55.03% | 188 / 54.26% |

小样本缺口组没有更低正确率，并不能反推缺口有益或无害。每艘船有两个相关端点，组内港口、船型外观、产品、模型证据仍有混杂；本轮不报告独立样本假设的 p 值或因果效应。`coverage_outcome_strata.csv` 保留 fold、港口、平台分层结果，但稀疏分层不构成混杂已消除的证明。

100 同船对的 `B-A` 最近同类源距离变化与 `B-A` 真类对最强错误类分差变化的 Spearman 相关：VV -0.079、VH -0.056。逐折 VV -0.203/+0.125/-0.030；VH -0.117/+0.040/-0.113，不呈一致强关系。它与此前图像对比度关联使用的是不同的解释变量，不能相互替代，也不能由这里的弱相关否定所有训练覆盖机制。

已证实：合法训练集合、各类独立船和观测供给、训练权重、具体几何邻域的稀疏端点、部分港口/平台组合缺口。尚未证实：这些缺口导致哪些分类错误、增加相应 source 船舶或条件是否能修复错误、图像中哪些证据被现有模型误用。本轮没有干预训练组成或模型，因此不能作因果结论。

适合主代理优先对照的 ID 已在 `crude_gap_cases.csv` 中附上 pair_id、两极化覆盖、对应合法 source 最近邻、分差和正确率。例如 22553 同时存在同港 source 缺口，6272/10036 两极化均超过 source NN95；这些只是元数据定位线索，不代替原图观察，也不是代表全体比例的精选案例。本轮保留“大多数端点有几何邻近覆盖但仍有错误”的事实，下一步应由主代理结合原图及其输入对照检查实际证据可利用性，不能仅据本报告扩大训练或修改标签。
