# 参考论文与本轮评价

已阅读本机15页全文：Awais、Reggiannini、Moroni、Del Corso，*Cross-Dataset Transfer and Unknown-Class Detection in Imbalanced SAR Ship Classification*，arXiv:2609.31658v1。文件：`E:/Docms/无监督域适应/translated/0917/related_papers/Awais_2026_Cross_Dataset_Transfer_Unknown_Class_SAR_Ship.pdf`。

## 真正可借鉴的标准

这篇文章提出的是 SSOB 评价框架，不是一个统一的“涨多少就算有效”阈值，也不要求每个类别都赢。

- 闭集、不平衡分类：主要报告 BA、macro-F1，并展示逐类召回；OA 保留但不单独决定结论。依据第6页 Section 3、第10页 Table 5。
- 跨数据集：两个方向分别报告，避免一方向表现掩盖另一方向失效。本文不是在做新的跨数据集实验，不能拿不同任务的绝对准确率直接比高低。
- 未知类：逐个留出类别训练，测试已知/未知检测 AUROC；补充材料有 AUPR。当前八分类所有类均在源端出现，本轮不据此声称开放集能力。
- 错误检测与未知检测不同：前者正类是预测错误，后者正类是训练未见类别。原文 Section 2.5 描述未知检测，Section 3 开头又谈错误检测；我们必须显式保存二者不同标签，不能混用 AUROC。

原文采用冻结骨干和分类头训练。我们的输入对照也冻结骨干，但采用现有 Ridge 读出、三折船舶身份/时间划分，不冒称复现其五划分五随机种子的设置。

## 对原油轮研究的启发

研究重点是解释“同一艘船在不同观测中为何变错”，而非追求一个总分。增加 macro-F1 后仍需报告：原油轮召回、具体混淆类别、100对中双对/一对/双错、哪些原图被救回或误伤。原油轮有收益而其他类有退化时，明确净收益和边界，不自动否决，也不隐藏损失。

本文的原型距离可作为未来误判筛查参考，但不能用一个离源均值较远的数值就认定“缺少训练条件”，更不能替代本轮实际源观测覆盖恢复。我们没有在这轮额外开发未知检测模块。

本轮遵循配对、相同输入尺度和源端选择。置信区间按测试船舶重采样，描述固定模型下的样本不确定性，不代表独立采集重训的方差。
