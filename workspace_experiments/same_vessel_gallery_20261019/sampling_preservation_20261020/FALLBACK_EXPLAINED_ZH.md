# 图像方向回退的真实作用范围

2026-10-20。仅复用既有案例、实际掩膜与采样函数绘图，没有重训或新增分类结果。

回退替换的是某一极化整张特征图使用的第二套参考方向，并非只替换框内方向。所有40x40位置都建立五点采样，再按目标T、其他候选O、其余有效区域R的掩膜计算统计。不是直接将整个chip无区别池化，也不旋转或缩放原chip来完成回退。

案例9180的VH原PNG为64x64，原像素不缩放，四边各补48像素到160x160；目标框172像素，剩余区域3924像素，无其他候选框。船轴角约2.973度，有效；雷达参考缺失，因此第二参考为图像水平0度及其垂线。两套参考很接近，是本例可见事实，不代表真实雷达方向已知。

采样发生于浅层40x40特征图。五点为中心、沿参考方向正负两点、垂直参考方向正负两点。本例两种半径为0.75和0.5个特征格，对应画布上的约3和2像素位移；非整数位置双线性采样。图中坐标是特征网格单元中心投影，并非逐个读取原图灰度；浅层卷积感受野有重叠。

- A为框内特征中心(19,19)。回退五点区域占比分别为0.75/0.75/0.75/0.875/0.375，沿向和横向成对权重为0.5625和0.28125。
- B为其余区域特征中心(16,16)，五点区域占比均为1，两种成对权重均为1。
- 成对权重为中心区域占比乘两端区域占比的较小值。取值先按区域掩膜采样和归一化，补零不作为有效区域；不能把这一点解释为消除了骨干卷积中已经混入的框外信息。

每个区域汇总中心响应、沿向两端均值、横向两端均值、沿向绝对差、横向绝对差。图展示未旋转的一次；实际四次整数90度旋转读出平均。完整流程中有读出器学习，但这里的采样和掩膜权重不是学习到的注意力。

此前全区域保留版本seed0将本例由拖船救回散货船，散货相对旧拖船分差从-0.336变为+0.680。这是整个补充通道的结果，不是单独A/B点或图像轴回退的因果效应，也不是最佳keep_refs版本的单例证明。
