# 训练前修正：无向参考的任意端点配对

独立审阅发现初版early_both/keep_roles直接将两参考的正端相加，再取绝对端差。虽然同时翻转两个参考不变，但只翻转其中一个参考会改变结果，违反无向轴设定。原来的联合端点翻转与C4测试不足以发现这个问题。

例：两参考端差分别为+2和-2，直接配对后绝对均值差为0；翻转一个参考则为2。固定采样没有变化，仅轴的记号改变，属于实现问题，不是物理效应。

修正：同时计算两个可能的相对端点配对，分别合并、归一化、计算局部非线性统计，再平均。上述例子固定为1。各参考均值、区域缺失质量及池化也经过同一对称化，保持独立端点翻转不变。

新增针对性测试逐个参考翻转，在四种合并配置下检查输出一致。保留原五点、原半径和原学习头。初版受影响缓存保存在本机invalid_signed_pairing目录，不上传；未进行任何模型训练、选步或测试性能读取。其余四组提取缓存复用，只有early_both/keep_roles重新提取。

此修正先于实验结果，不是根据负结果换方案。它也说明为什么不能只以单个旋转测试代替无向轴对称性要求。
