# 同船多时相覆盖与重复性分析

本轮修正上一轮每船仅取最大时间间隔一对的限制，不改已有模型或主实验。

1. 对整个图库按 MMSI 统计观测；独立过境键为 Sentinel-1 平台、绝对轨道号、datatake。相邻产品切片不增加过境数，VV/VH不分算。图库本身是既有重复观测子集，不代表原始数据全集。
2. 定量主队列沿用上轮已核查目标关联的 observation_eligibility.csv。保留两极化原生坐标及轨道几何可用、类别一致的船；同船同过境按时间、obs_id选择第一条，不依据预测或亮度。至少4次过境后纳入多时相分析。另报告全图库的潜在扩展规模，不冒充全部已测量。
3. 复用此前原生PNG测量：OBB投影米制长宽、固定物理半径高响应范围、框内和框外统计。重用缓存，无缓存才读取原图。PNG不是定标后向散射；表观长宽不等于真实船体尺寸。
4. 逐船列出过境数、港口数、时间跨度、VV/VH入射角范围和轴向相对角最大差。全部观测保留在输出表，不增加随机种子伪装独立样本。
5. 探索性重复性对照：同船、同平台、同升降轨、同港，入射角差<=2度时，将相对角差<=10度记为近条件，>=30度记为远条件。仅同一艘船同时具有两组配对时比较；先每船每组取平均绝对对数尺寸差，再等权跨船汇总。配对不独立，bootstrap仅按船；观察数据不证明因果。这个阈值方案在读取该对照结果前固定，不按结果调阈值。
6. 按已有frozen_fivepoint seed0局部分类器的持续正确、持续错误、混合且末次正确、混合且末次错误分组，各选观测最多的一艘（MMSI打破并列）展示全部VV/VH原图。案例是覆盖展示，不估计全体比例。不训练新分类器，图库旧R50/R18预测不混入。
7. 本轮先回答材料是否足够、条件是否重复覆盖。未见船/未见采集的预测检验仍是后续任务，不将本轮描述为已证明条件化分类收益。
