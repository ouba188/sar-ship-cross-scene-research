# 源端留船门控：本轮结果与原因

2026-10-22，已完成。结论：**把门控训练材料换成整条分类链未见过的源船预测，尚未带来比训练内对照更好的分类收益。已发现明确的有效监督不匹配，不应继续盲目叠加几何或直接归咎于损失函数。** 原有邻域读出候选保留，本轮门控不升级为主模型组件。

## 1. 做了什么

保持原有强基线 A 和邻域补充 D 在最终测试时完全不变，只训练力度 w：`A + wD`，`w ∈ [0,2]`，初始 w=1。

以前门控看到的是 A、D 在自己训练船上的表现。本轮在源训练集内按 MMSI 分三折，重新拟合每折的标准化、ridge、keep_refs 和邻域残差，生成真正未见该船的预测；不是只把最后一层留船。

重训模型的隐向量坐标不一致，因此门控输入改成有统一类别含义的 A 八类分数与 D 八类分数。两个训练方式都使用这个 16 维输入，比较的是训练内预测与 OOF 预测，而不是拿新输入直接与上一轮隐向量门控比较。

- 同一 24 港来源队列中的 4,744 个测试观测、2,973 个 MMSI、18 个实际覆盖港口、8 类、3 个配对种子。
- 3 个既有身份/日期外划分；不是严格留港，也不是新增独立确认集。
- 内层拟合每折使用 2,865–2,989 个观测、1,763–1,802 艘船，外源训练为 4,392–4,419 个观测、2,649–2,700 艘船。
- 27 次 ridge 候选拟合、54 次内层神经头拟合、36 次门控拟合。每个神经头最多 150 步，源验证选 0/50/100/150；不使用测试标签选步。
- 原尺度 160 裁剪/补零，未重新缩放或提图像特征；排除 31237。
- 训练记录耗时 50.5 秒，为缓存上的小头实验，不是端到端部署时间。

本轮 A 仍是看整张 chip 的原模型，D 是独立邻域补充。因此这是系统增量/训练信号实验，**不是“船体与背景已完全隔离”的新证明**。前一轮的配套训练 body-only 诊断单独保留。本轮也没有重新接入目标支持适配或使用邻船类别传播。

逐类 OOF 相对 A+D 的召回变化：散货 +0.155、渔船 +0.230、普通货船 -0.076、油化船 -0.135、集装箱 +0.064、原油轮 +0.082、拖船/海工 0 个百分点。全部类别与港口表保留，未事后挑选收益子集为主结果。

## 3. 查到了什么原因

### 3.1 训练内乐观程度确实不同，但不只改变了这一项

按实际训练行加权汇总，原全源模型在训练内 A 的 OA 为 62.23%，留船预测为 51.18%。原 A+D 在训练内为 63.12%；OOF 为 51.18%。OOF 邻域补充累计救回 536 次、误伤 536 次，原训练内则为 890/535。

这些是多个外折和种子的重复训练行暴露次数，不能当成独立船只数。OOF 模型还少了约三分之一源船，不能把差异全部解释成训练内过拟合的因果效应。

### 3.2 有些门控根本没有收到可调节的残差信号

27 个内层邻域头中，**12 个被源验证选为零步**。由于输出层零初始化，D 恒为零，`A+wD` 对门控的数据梯度也为零。

最明确的一组是外折 0 / seed 0：4,392 条门控训练材料的 OOF D 全为零，但最终接入的全源 D 非零。这里不是“门控认真学了却泛化失败”，而是没有学到如何调节这条实际会启用的通道。

相反，外折 2 / seed 2 的 OOF 有 2,879 条非零 D，最终全源 D 却全零。这组门控即使学到东西，也无法改变最终分类。原模型的两组全零 D 均保留在主表，没有事后删除。

其余组也存在部分零输出。**名义上的相同行数、步数，并不等于相同有效监督量。** 这是实现符合协议后暴露的实际训练组织问题，不是代码泄漏，也不能直接断定是训练数据量不足造成的。

### 3.3 学到的主要是轻微整体减弱，不是逐例识别何时该用

9 组 OOF 门控仅 4 组选择非零训练步，测试平均力度约 0.935–0.971，组内标准差仅约 0.005–0.009，其余组回退 w=1。以该折源端平均力度替换动态力度后，结果仍很接近。

这说明“需要少信一些邻域”的群体倾向较容易进入结果，而“这一艘应该减弱，那一艘应该保留/增强”尚未学好。不能把这种变化包装为已证实的精细条件化注意力。

### 3.4 不能简单说 MSE 本身没有收益空间

训练完成后增加一次解析诊断，不再训练、不选新模型：事后给定真实类别，计算每个样本在 w∈[0,2] 内最小化八类 MSE 的力度。公式为 `clip(<D,t-A>/<D,D>,0,2)`，D=0 时仍取 1。

这只是假想上限，**真实标签不能在预测时使用**。它的平均 OA 为 44.231%，而分类边界可达上限为 44.730%。三次 MSE 假想调节分别救回 152/183/80，误伤 11/12/5。

因此，MSE 与 top-1 确有局部冲突，但不能据当前小增益说它完全无法引导有效力度。更直接的缺口仍是：合法可用的信息和训练组织，能否学到这种逐样本区别。假想上限没有证明这个区别可学习。

这些解释确定的是模型分差和调节作用。亮纹是否旁瓣、尾迹或其他物理散射机制仍未独立验证，不据外观强行命名。

## 5. 保留与下一步

1. 保留已有 A+D 的邻域补充收益及所有正负结果；本轮 OOF 门控记录为小幅、未胜过配对对照的候选，不作为新核心模块。
2. 本轮不再加角度、扩大门控或搜索更多步数。已有证据首先指向训练材料与最终残差不同，以及门控学成整体微调。
3. 若继续这条力度路线，下一轮应采用**同一冻结 A、D + 独立源端校准船**：校准船从所有上游拟合、标准化和选步中排除，门控学习和最终测试都使用这一份 A、D，不在校准后回灌重训上游。先配对其自身无门控基线，明确减少上游训练量的代价；不能直接冒充原全源模型升级。
4. 将“该减弱的错误”与“倍率无解的错误”分开。后者需要回到图像读出和混淆类证据，不要求门控解决不存在于其函数范围内的问题。

该下一轮尚未启动。仍不能宣称同船不变表征、纯因果因素或新卷积已成立。
