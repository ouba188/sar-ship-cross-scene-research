# 条件变化是否提供可利用类别证据：固定特征小验证

2026-10-19，运行前固定。不是新卷积/池化训练，不替代完整模型主表。

## 问题与判断

物理条件影响图像，不自动意味着条件化能提高分类。比较：image、condition_only、concat、interaction、同维content_interaction、mismatched_interaction。前两者区分图像信息与条件类别关联；interaction对concat区分有限乘积交互，正确条件对错配条件检验配对用途，同维图像非线性防止把增加表达能力当几何贡献。

主比较interaction-image，机制比较interaction-concat/content_interaction/mismatched_interaction。保留全部结果，不要求每港每类获胜；如果仅concat有收益，就定位为辅助条件，而非局部几何卷积已有效。全局冻结特征上的阴性结果不否定尚未检验的局部读出，但不因此自动继续加模块。

## 数据与隔离

- 从当前图库读取一次并导出cohort.csv：有目标VV检测轴、orbit_los与原产品annotation入射角；不用旧range_proxy混填，不用AIS方向。历史图库更新前案例报告不改写。
- C三维：检测无向船轴相对轨道LOS轴的cos(2delta)、sin(2delta)、annotation入射角。折叠180度，不宣称知道船首。近方形/歧义轴先不硬删，记录长宽比/关联状态以分层解释。
- 使用已有38091行R50(2048d)和R18(512d)冻结缓存；instance_id/manifest_row/class/MMSI对齐。历史骨干预训练暴露未排除，只声称条件于现有冻结表示的探针，非端到端源限定自监督结果。
- 沿用按类别分层的三折MMSI身份编号，轮流作为测试船。非测试船中每类固定20%身份为验证；其余为训练。训练日期<2025-09-01，验证2025-09，测试>=2025-10-01。三组身份及产品必须不相交；时间带隔离相邻产品切片。所有比较同一划分。
- PCA32/16、标准化、内容投影、岭回归只用训练。这里训练使用合法源标签，不是16/32/64目标支持适配。三折是不同身份划分，不伪称三个神经训练种子。
- 同船多次测试观测保留；不把每对或每次观测当独立船。图库已用于开发，因此本轮是扩展开发验证，不是全新独立数据确认。

## 模型与选择

X为source-only PCA的R50/R18拼接48维；H(X)为固定种子的三维随机投影经tanh并按训练统计标准化。concat=[X,C]，interaction=[X,C,vec(X*C)]，content_interaction=[X,H,vec(X*H)]；后两者同195维。mismatched_interaction只换C，结构相同。

错配在train/val/test各自内部按港口、平台、季度置换，绝不读取测试类别；保留条件分布，破坏图像对应；报告实际改变比例。它不是纯物理干预，仍可能改变条件与类别关联。只用一个预定置换，结果不代表置换分布。

每臂同一正则候选alpha={0.1,1,10}，以源验证BA优先、Brier打破并列选定，然后一次测试。训练按类别及船只重复次数加权。概率用固定温度1 softmax，仅作为未校准分数转换，Brier不是校准性证明。

## 输出与后续决策

输出逐折OA/BA/Brier、逐港逐类效果、逐观测分差和配对增益。合并逐船重采样bootstrap(500次)给当前已拟合模型下的条件区间，不包含骨干/划分/训练随机性。配对抽样只反映当前队列。

每轮查看实际持续正确、持续错误、救回、误伤的VV/VH原PNG；这里不是支持分类器，没有“实际目标支持”可展示，不虚构支持原因。案例用于追查是内容响应、几何代理可靠性，还是类别/采集组成问题。

若正确条件交互有可重复净收益且优于内容替代，继续将这一关系落实到局部C/P；若只有条件拼接有效，保留辅助信息并缩小机制主张；若没有收益，先看源训练/验证/测试和轴可靠性分组，决定接入/容量/可观测性哪个解释值得一个针对性修正，不无限扫参。
