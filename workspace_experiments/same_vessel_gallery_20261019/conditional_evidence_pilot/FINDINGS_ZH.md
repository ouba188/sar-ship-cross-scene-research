# 观测条件能否提供类别线索：冻结表征小验证

日期：2026-10-19。状态：六组读出实验、固定模型条件干预及原图回看完成。尚未开发新卷积/池化，也未接入完整支持适配系统。

## 结论

有可保留的任务收益证据：图像内容与正确观测条件的乘性交互，使本队列 OA 从34.35%提高至36.33%，三折均提高。不能据此声称朝向本身决定类别、已经发现物理因果因素，或当前完整系统提高1.98个百分点。

更准确的假设是：相似的图像响应在不同观测条件下，其类别判别价值可能不同。当前交互读出比直接拼接更能利用这种关联；仍需将它落实到局部证据，并区分船体与场景关联。

## 数据与协议

- 从同船图库固定快照得到15,252条观测、6,688艘船、330个产品、21港、8类。只保留VV具有可用目标OBB、原产品轨道LOS及annotation入射角者。不是全库评价。
- 条件为OBB船轴相对于LOS轴的cos(2差角)、sin(2差角)，以及入射角。船轴无首尾方向；LOS来自精确产品轨道与原生图像仿射映射，不是图片竖轴或升降轨标签。船轴是图像测量，不是完全独立的外部条件。
- 三个身份划分轮转：训练早于2025-09-01，验证2025年9月，测试不早于2025-10-01；每折训练/验证/测试MMSI、产品均隔离。各集合均有8类。测试合计4,745条观测、2,974艘船、18港。
- 沿用既有冻结R50/R18缓存；仅用源训练样本拟合标准化、PCA32+16维及分类头。历史预训练接触范围没有被重新排除，不能宣称端到端完全未见或重新源域限定自监督。
- 训练按类别、船只重复次数平衡。Ridge的alpha只在源验证集从0.1/1/10选择；测试不选参。三折不是三个神经网络训练种子。
- 该实验是冻结表征监督读出，不包含目标支持集、查询支持关系或完整融合。已有开发数据再使用，不是全新独立确认集。

## 设计

X为48维图像表征，C为3维条件。交互读出为[X,C,vec(X乘C)]，共195维。它允许同一个图像特征在不同条件下具有不同的分类权重，尚不是局部卷积或注意力。

所有组扩展后均按源训练统计标准化并除以维度平方根。等宽内容交互对照用固定随机投影+tanh得到H(X)，替换C；不是对所有内容非线性模型的穷尽比较。错配条件在每个划分内部按港口、平台、季度整体交换C，不使用标签，保持条件边际分布；只有一次预定错配，不是置换显著性检验。

| 方法 | OA% | BA% |
|---|---:|---:|
| 图像X | 34.35 | 39.03 |
| 只用条件C | 9.27 | 19.89 |
| 图像与条件拼接 | 34.25 | 38.73 |
| 图像与正确条件交互 | **36.33** | **39.52** |
| 同宽内容交互 | 34.60 | 38.15 |
| 从训练开始即错配条件的交互 | 33.32 | 37.59 |

交互比图像：救回441，误伤347，净增94；OA+1.981pp，BA+0.489pp。三折OA增益分别+2.050/+1.900/+1.997pp，BA分别+0.641/-0.426/+1.350pp。固定模型、按类别分层的船级配对bootstrap500次：OA增益95%区间[+0.854,+3.116]pp，BA[-0.787,+1.779]pp。区间未覆盖重新训练或场景共同变化的不确定性。

Softmax温度固定为1，未校准的Brier从0.816712变为0.817015，略退化。不能说所有指标都改善。

## 固定模型干预

重新构造相同源端PCA及已选参数，逐条验证预测与margin重放一致，再固定全部权重，只改变测试条件。不是再训练另一个模型。

| 固定同一个交互模型的输入 | OA% | BA% |
|---|---:|---:|
| 正确条件 | 36.33 | 39.52 |
| 所有条件置源训练均值 | 34.29 | 38.22 |
| 仅相对朝向编码置均值 | 35.72 | 39.25 |
| 仅入射角置均值 | 33.80 | 38.14 |
| 同港/平台/季度错配条件 | 31.68 | 34.13 |

因此，实际预测依赖条件对应关系，收益不只是训练时扩展参数。入射角置均值损失OA2.53pp，相对朝向置均值损失0.61pp；不能把收益主要归给船轴。两者交互，影响不可简单相加。均值角编码不是一个真实物理朝向，错配也不模拟同船真实再观测；这些是模型输入干预，不是物理因果实验。

## 原始chip回看

VV/VH分开读取原生尺寸PNG，固定0-255显示，不重新逐图拉伸。PNG不能用于证明校准RCS。此读出没有支持集，因此没有实际支持chip可对应；完整适配实验必须再查看实际支持案例。

1. **31237，MMSI565996000，Singapore，2025-11-24，成品/化学品船**：图像模型判海工供应船，margin -0.997；交互后正确，margin +0.222。VV/VH中心响应均较紧凑，框外有多处亮响应，尚不能确认其为邻船、旁瓣或其他物体。固定模型将相对角编码置均值后又判海工船，margin -0.549；仅入射角置均值仍正确(+0.152)。该例确实依赖相对角相关项，但不证明模型使用的是目标船本体。
2. 对31237的真实类对最强竞争类分差可精确分解：截距+0.055739、图像主项-0.637248、条件主项-0.078223、图像条件交互+0.881715，合计+0.221983。**救回不是条件单独给某类加分，而是交互项改变了图像证据的权重。** 这是分类器代数作用位置，尚非物理解释。
3. **9666，MMSI352004652，Richards Bay，2025-12-13，散货船**：由集装箱船救回，margin -1.242到+0.341。原图有细长斜向主体及横向弱条纹，不能仅凭条纹命名多普勒/旁瓣原因。
4. **5155，MMSI259106000，Los Angeles，2025-11-22，原油轮**：由正确改错为普通货船，margin +1.272到-0.222；VH背景纹理较亮，VV/VH主体形态不同。同船5153在11月11日本来即错，本轮仍错。条件不保证救回。
5. **21571/21572，MMSI422031500，Port Klang，集装箱船**：10月1日持续正确；11月18日由散货船错判救回，margin -0.105到+0.027，仅小幅越界。原图主体、条纹与VV/VH对比不同，但多种条件共同变化，不能只归因船轴。
6. **9953，MMSI352005525，Ningbo，普通货船**：持续判海工船，margin -0.247到-1.206；VV仅少量亮响应，VH主体很弱。未见证据说明条件能恢复缺失的船型细节。

## 下一步设计取舍

保留条件内容交互这个方向，不晋升完整模型。当前证据足以支持一轮正式局部模块实验，不必继续寻找保证成功的理由。

- **卷积**：将船轴、真实雷达轴作为局部采样坐标依据；条件与实际局部响应共同决定有限邻域滤波，不能直接用相同朝向提高案例相似度。保持目标框、邻船候选、剩余邻域的独立读出。入射角必须保留，不把相对方向当唯一主因。目标框与雷达响应范围分别按船尺寸/原生像元组织，避免拉伸后固定像素虚构物理尺度。
- **池化**：冻结已有有效读出，补充有限的框内—邻域关系；先保留各区域内容再汇聚关系，不能先全局均值再声称恢复局部交互。目标自身证据不应被邻域强响应直接替代。
- **实验**：相同输入、参数规模、支持查询及源端选参，比较普通局部内容、聚合后拼条件、聚合前条件内容交互；保留正确/错配条件对照。接入完整支持适配后报告实际净救回与成本，而不是将本probe涨点当完整系统结果。
- **针对性边界**：优先追成品/化学品船与海工/货船混淆；同时保留受损类和港口。按同船多次观测回看条件、局部证据及实际同类/混淆支持，验证收益是否在未见采集、不同船案例关系中兑现。不要把同船正配对本身充当跨船类别证据。

尚未证实：具体散射物理机制、类别无关的方向消除、新卷积/池化优于合理同容量方法、完整系统净收益。本轮不声称原创机制已经成立。

run_pilot.py为原实验；cohort.csv为固定输入快照。intervene_pilot.py仅从快照重放既选模型并做条件干预，逐条校验预测与分差；score_decomposition.csv记录可加分解。analyze_pilot.py与review_gain_class.py生成分组表和原图面板。不要在活动图库变化后用run_pilot.py覆盖本轮快照；另开目录进行新实验。独立只读审查未发现使OA增益无效的索引、划分或选参问题。GitHub归档将三个较大CSV压缩为.csv.gz；运行分析前解压到同名CSV，原图与特征仍需本机既有文件，不随仓库上传。
