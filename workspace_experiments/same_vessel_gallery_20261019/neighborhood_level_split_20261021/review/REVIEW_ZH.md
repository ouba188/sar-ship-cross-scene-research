## 解释边界，非实现缺陷

- 冻结 baseline 仍读取原来的图像特征。C 只使新增 R 分支去掉加性均值；不能称整个预测器删除了亮度信息或具备全模型亮度不变性。协议已明确这一点。
- `run.py:223` 把 D 的标准化均值槽置零，表示替换为源训练可用视图的平均 R 亮度，而非原像素零亮度。它保留 D 的已训练参数，并不等于重新训练的 C；只能测 D 对显式均值槽的依赖。
- D 把均值加在冻结非线性描述子之后，不能保证恢复 B 的特征，因为“加回像素均值再卷积”与“描述子后拼接均值”不同。D 与 B 是读出方式对照；即便 D 获益，也不能仅凭这一比较断言某种物理成因。
- R 掩膜边界和局部幅度仍可见，R 不保证纯水；中心化只删除加性均值，不清除所有与均值相关的信息。协议已有对应限制。
- 该队列及两例已参与开发。源端选择正确并不把本轮变成全新独立确认数据；协议已如实声明。

### 聚合与区间

`analyze.py:19` 将三个互不重复的测试折按行拼接后计算每种子整体指标，再在 `42` 行对三个种子取均值；不是简单平均各折 BA，也不是先平均三个种子的分数再做 ensemble。实际每种子恰有 4744 个唯一测试行。

`analyze.py:50` 先对同一观测三个种子的正确性取平均，之后按真实类分层、MMSI 成组配对 bootstrap。OA 按观测数加权，BA 为八类召回差的平均，符合当前指标定义。区间只表达固定模型、当前船舶样本下的不确定性，不含重训和独立采集不确定性；代码输出 unit 已说明。

| 比较 | OA 差，百分点 [95% CI] | BA 差，百分点 [95% CI] |
|---|---|---|
| D - baseline | +0.5481 [+0.2251, +0.8651] | +0.1426 [-0.2404, +0.5188] |
| D - C | +0.2038 [-0.0071, +0.3993] | +0.1021 [-0.1492, +0.3347] |
| D - B | +0.1616 [-0.1550, +0.4669] | +0.1074 [-0.2373, +0.4630] |

D 的三种子 pooled OA 均值为 41.5121%，baseline 为 40.9640%；BA 为 42.7074% 对 42.5648%。可以保留此开发集范围的整体 OA 收益。D 相对 C/B 的差异小且上述区间均跨零，不能把“D 点估计最高”作为分离机制已获证的结论，也不能反过来宣称 D/C/B 已被证明等价。
