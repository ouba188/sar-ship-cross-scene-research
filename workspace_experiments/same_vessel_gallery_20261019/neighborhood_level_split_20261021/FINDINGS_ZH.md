# 邻域纹理与整体亮度分离：冻结较强读出器的配对实验

2026-10-21，已完成。**新增邻域通道有小幅可保留的净收益；尚不能把收益归功于“显式亮度分离”这一机制。** 不替换原模型，不删除负结果，不继续针对本轮测试集调参。

## 1. 实际完成了什么

这是24港语料的原生尺度实验队列，不是F_0921，也不是公开集新结果。沿用3个身份/日期隔离折，共4744条测试观测、2973艘船、18港、8类。各折训练/验证/测试数为4392/310/1561、4419/286/1632、4418/319/1551。不是严格留港，也不是独立新采集确认；这些数据已参与方法开发。

冻结当前较强的 `sampling_preservation_20261020/mse_aligned/keep_refs` 分类器及其3个种子权重。它仍保留原有完整输入。只训练一个附加通道，未接入完整双骨干、目标支持适配或专家交接流程。前轮35.139% OA的整图诊断头不是本轮基线，不能把两轮数值直接当作进步。

这里先拼接3个互斥测试折，再计算每个种子的指标；表中为3种子均值±样本标准差，不是9份独立测试，也不是3模型集成。

D相对A：OA **+0.548个百分点**，BA **+0.143个百分点**，macro-F1 **+0.467个百分点**。三个种子的净救回分别26、31、21条，OA均为正；BA分别约-0.118、+0.581、-0.036个百分点，未同向改善。平均救回98.33、误伤72.33、净增加26条正确观测。

固定已训练模型，按类别分层、MMSI成组，对种子平均正确性做1500次配对bootstrap：D-A的OA差95%区间为[+0.225,+0.865]个百分点，BA为[-0.240,+0.519]。D-C的OA差+0.204，区间[-0.007,+0.399]；D-B为+0.162，区间[-0.155,+0.467]。区间不包含重训或独立采集不确定性。**D点估计最高值得保留，但尚无充分证据说分离方式优于普通邻域补充。**

## 2. 通道具体如何工作

1. 原PNG仅原生裁边/补零到160，不缩放船体。VV、VH分开处理。
2. R区域是有效chip范围减去目标OBB和其他合格检测框，排除padding。它仍可能包含散射延伸、未检出的其他物体或岸边结构，不能命名为纯海面。
3. 在R内计算PNG均值mu。B用原值x；C/D用x-mu，保留正负变化，不除以单图方差。
4. B和C使用相同固定编码：R外0.5，R内分别0.5+x/2、0.5+(x-mu)/2，无截断。均值差是操纵变量，斜率和填充相同。
5. 冻结R50浅层读取R，区域均值/最大值池化，四个直角旋转平均。每极化128维，合计256维；D再提供两个均值，三臂均有两个可用性标志。
6. 三臂统一260→32→8、GELU、8616个参数的残差头，最后层从零初始化，输出加到旧类别分数。相同批次、学习率、权重、150步训练，源验证在0/50/100/150步选取。共27次训练。

缺失目标框或冲突VH不进入新增通道，但不删除对应旧模型预测。源训练统计用于全部特征标准化。没有类别、港口、经纬度、角度、测试标签输入；掩膜几何仍可被读出。

这不是新卷积，也不是已经学会空间对应关系。当前补充分支保留局部响应的通道统计，最终仍做均值/最大值池化；本轮没有证明哪种空间排列是关键。C只消除新增通道的加性整体水平，不使完整模型对亮度不变，更没有恢复物理后向散射。

## 4. 收益原因查到哪一步

**显式亮度被使用，但净收益很弱。** 固定D参数，把两个均值槽替换为源训练平均值，三个种子分别改变18/32/17条预测，正确数相对D净变化0/0/-2。不能说均值没被使用，也不能说它解释了+0.548个百分点。D与重新训练的C还有优化轨迹、所选步数差异，不能把二者差直接当作亮度的因果效应。

**新增通道并非只有全体统一偏置，但部分收益确实能由统一修正获得。** 把每张图的残差换成源训练样本的平均残差，D的OA均值从41.512降到41.217，相对A仍高0.253个百分点。个体残差比此固定偏置高约0.295个百分点。它证明当前模型中的个体输入有额外作用，不等于证明纯邻域纹理是唯一来源；掩膜、幅度和数据组成仍混在读出中。

**训练有效不等于验证收益稳定。** 150步末D的训练BA平均66.99%，旧模型66.13%；源验证末步46.24%，旧模型46.64%。源验证选择后为47.22%，其中2/9选择零残差回退。当前有限监督与补充头可能出现泛化退化，不能归结为根本没训练或一律方向错误；本轮不通过加步数/换损失追逐测试结果。

## 6. 验证、成本与收口

- 旧9个模型测试分数重放完全一致；27个新头CPU重放最大误差7.15e-7。
- 原生目标像素保留、输入scale=1、身份/产品隔离通过；独立审阅重算源统计和27次选步，无实质实现错误。
- 去均值编码对邻域统一加值误差2.98e-8，描述子4.77e-7；R外像素隔离为0，C4误差1.91e-6。这是首批样例数值验证，不是所有真实条件的不变性证明。
- 本机提取约84秒，27头训练与旧分数重放约50.6秒。新增8616可训练参数，但还需额外的邻域掩蔽后冻结stem推理，不能只按参数少宣称部署免费。尚未测完整系统端到端延迟。

**收口：冻结A/B/C/D及本轮记录，D作为小幅有效候选保留，不替换原主模型，不把“亮度分离”立为已证实的核心创新。** 已证实的是当前开发范围内新增通道的净OA收益及具体正负作用；仍缺的是分离方式相对普通补充的明确优势、几何/纹理与类别偏置各自贡献、独立采集确认和完整支持系统收益。

下一步若继续，应先围绕已发生的个体误伤，比较掩膜/幅度与局部内容的匹配读出；不因为本轮点估计最高，就直接叠加新注意力或物理命名。原有有效组件和全部阴性对照继续保留。
