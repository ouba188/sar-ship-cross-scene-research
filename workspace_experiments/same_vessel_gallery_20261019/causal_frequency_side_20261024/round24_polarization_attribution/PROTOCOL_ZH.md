# 第24轮：VV/VH反向效应的区域、幅度与读出分解

目标：回答第23轮10号散货船为何VV/VH框内fine削弱作用相反，不新增分类模块、不训练、不搜索参数。主要案例10，另核对既有0/4/6/18/81号，共六个已查看案例，不能当随机总体样本。

## 对照顺序

1. 保留第23轮每极化自己区域、自己等L2的原结果。
2. 两极化仍用各自区域，但同一观测的两极化、所有区域/尺度使用共同L2。
3. 各区域改用VV/VH同名区域的像素交集，保持步骤2的共同L2。共同幅度在2/3两组全部未缩放提案的最小范数上取0.5，避免裁剪与过强削弱。两个剂量保持0.5/1。

两极化来自同一产品、同一center_x/y的配对Patch_Uint8，要求原图尺寸相同，不额外插值配准。本轮六张原图均小于160，读出时补零位置相同；共有区域只是相同像素集合，不等同经物理验证的亚像素共址。三个区域仍为检测框内、轴端和侧向，并非人工语义分割。

只操作一个极化，另一极化和四维OBB尺寸固定。保留同区域同均值对照；不把它称为等能量对照。检查每次操作范围、L2、均值、取值范围和基线重放。失败时修对应实现，不更换研究终点。

## 特征与读出权重的分解

共享stem使两极化的128维描述处在同一通道坐标系。对正确类y和原最强错误类r，使用包含源标准差的有效权重：w_p=(coef_y,p-coef_r,p)/(std_p*sqrt(260))。图像改动的精确分差变化是w_p乘特征变化df_p。

保存2x2读出矩阵：VV变化/VH变化分别交给VV权重和VH权重。对角线为真实对应操作，非对角线只是线性读出反事实，不是训练或部署了交换极化的模型。

VV效应减VH效应精确分解为：

- 特征变化项 = 0.5*(w_VV+w_VH) dot (df_VV-df_VH)
- 权重差异项 = 0.5*(w_VV-w_VH) dot (df_VV+df_VH)

这是固定坐标系中对两个比较顺序取平均的代数分配，有交互和抵消，不是物理因果比例。特征项还混合原始输入差异、拉伸、共享编码器非线性等；权重项含源训练与归一化偏好。先验证两项之和等于实际分差差，再讨论哪个环节更值得研究。

本轮成功标准是解释差异发生的位置及边界，不要求涨点。结果逐案例、逐极化报告，并回看共同区域、实际改动图和贡献通道。原始数据/已有模型/主线程不改。CPU两线程，结果与文档归档GitHub。
