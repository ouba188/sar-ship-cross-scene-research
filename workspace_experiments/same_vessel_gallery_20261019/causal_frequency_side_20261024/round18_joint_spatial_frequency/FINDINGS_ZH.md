# 第18轮：空间—频率联合研究结果

## 结果先行

联合分析有用：它区分了“局部响应朝向在变”与“细粗结构比例在变”，这两件事不能统称频域变化。当前最强信号是方向频谱随图像方向变化；空间形状指标已经解释其中较多变化。尚不能把它命名为雷达观测造成的物理散射变化，也没有新的分类收益。

## 数据与实际执行

沿用同一组26个候选同MMSI配对，只有一个12天重访采集对。26525所在整对因已知VV/VH定位不一致从本轮主分析隔离；两次都有本极化检测轴后，VV19对、VH20对。未新增船只、采集或训练分类器。执行代码为上一级joint_spatial_frequency.py。仅CPU小型描述提取和留一船岭回归，不影响主线训练。

采用第16轮定标去噪幅度，同一原生10m网格；主窗为原锚点半径60m余弦窗，另报告OBB中心。空间测量为幅度均值、变异系数、幅度加权RMS半径；频率测量为20–40m/40–120m波长功率比及固定图像轴的方向矩。幅度加权空间二阶方向矩是首轮结果后的根因对照，已在协议注明。所有预测为留一MMSI，标准化在训练部分拟合，alpha=10固定，无超参搜索。不是跨采集外推。

FFT统一64×64积分格，仅窗口外补零；并不提高频率分辨率。初版依赖原chip大小的结果保存在diagnostic_variable_fft_grid.csv，修正前后主要判断不变。Parseval能量与幅度比例不变性检查通过，分别用于发现FFT归一化和指标实现错误。

## 1. 空间方向与频谱方向确实一起变化

主锚点窗口的留一船预测MSE（越小越好），预测目标为两次观测的频谱方向矩之差：

| 输入 | VH，20对 | VV，19对 |
|---|---:|---:|
| 训练船均值基线 | 0.110797 | 0.065619 |
| 空间均值/CV/RMS半径+入射角差 | 0.139559 | 0.087449 |
| 上述+相对角差 | 0.064214 | 0.057566 |
| 上述空间基础+空间方向矩 | 0.039844 | 0.067315 |
| 空间方向矩+相对角差 | 0.034318 | 0.059739 |
| 空间基础+图像中的船轴方向（不使用雷达相对角） | 0.054567 | 0.066264 |

VH在加入空间方向矩后，相对角仍使误差降低约13.9%；OBB中心约20.1%。这是当前固定小样本、固定回归下的增量预测信号，未做独立采集确认或宣称统计显著。它不是总体分类准确率提高。

关键限制：本批实际雷达轴仅168.0714–168.1444度，几乎不变。相对角变化主要随图像检测轴变化；图像轴对照已有接近的预测能力。不能把相对角的回归收益解释成雷达条件的独立物理作用。单个方向矩也不是完整方向频谱。

空间方向矩与频谱不是独立证据来源；空间图形的方向本来就会影响其谱。当前结果支持联合表征的描述能力，但不支持把同一个转向现象计作两条因果证据。

## 2. 细粗频带比例没有复现同样的强关系

VH主锚点：相对角差与直接FFT频带比变化的Spearman相关仅0.0226；加入相对角后留一船MSE从0.725690变为0.766242，退化5.6%，且两者均差于均值基线0.692050。OBB中心同样没有增量预测改善。

既有高斯导数尺度比与相对角的相关仍为0.3489，但加入空间方向矩后的描述性偏秩相关为0.0793；直接FFT比与高斯导数比之间相关为-0.0571。不能据此说旧结果错误或物理关系不存在：两种算子权重、边界、频带不同，并非同一个量。

具体区别：高斯导数在完整图像滤波后对圆盘内求局部能量，涉及圆盘外邻近像素；FFT先去均值、乘紧支撑窗，再计算带内功率，含窗口卷积影响。因此本轮不是“同一个测量用FFT独立复核”，而是不同空间—频率描述的对比。

空间方向矩可能是观测影响的中间结果，而非前置混杂因素。控制它后相关减弱，只说明共享结构较多，不能当作排除物理总效应的因果检验。本轮回归的箭头用于预测组织，不代表已经识别的因果箭头。

## 3. 原图回看得到什么

详见CASE_REVIEW_ZH.md与四张面板。25750→25752的VH响应由较分散变得更集中，RMS半径28.47→23.81m，方向谱随之改变；但FFT细粗比下降，而高斯导数比上升。这个例子直观说明“更集中”“更高频”“更容易分类”并不等价。8368→8369存档预测由错到对，VH细粗FFT比却近乎不变；7324→7326方向谱明显变化但仍持续判错。不能把可见变化直接解释为判对错原因。

本轮没有支持式分类重放，故没有新查询—支持配对归因；四种状态只引用旧dual存档，未混用为新模型效果。

## 收口与下一步

可保留发现：在当前同船重访样本中，方向频谱是与局部空间形状和朝向密切相关、可预测的描述；仅用亮度/集中程度不够描述它。不能保留“雷达角度导致细频能量增加”的普遍结论。

下一轮应增加独立重访和雷达几何覆盖，冻结本轮读出。若要验证物理因果链，优先区分图像平面转向与实际响应重排，并使用不依赖同一局部纹理的角度参照。不要把本轮方向结果直接升级为模块收益或因果因素分离。
