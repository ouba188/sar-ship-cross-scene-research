# 第22轮：空间—频率分类效应的候选全集验证

## 完成范围与主要结论

第一步完成：没有改模块或启动完整模型实验，冻结第21轮的分类诊断器、区域、频率分解、剂量及对照，扩到全部既有候选。结果支持部分可重复的局部分类效应，特别是VH框内结构和侧向中尺度结构的不同作用；不支持统一的“某频带总有用/总有害”规则，也不把输入干预直接解释成自然观测的物理因果。

最有用的进展不是只出现几个翻转，而是明确了适用边界：成品/化学品船对VH框内结构的依赖更突出，VH侧向中尺度削弱在这一类及集装箱船上平均有利，在散货船和海工供应船上平均有害。

## 1. 最清晰的扩围效应

以下均只看新增104船，高预定剂量，先逐船平均。数字是线性分类分差，不是概率或准确率百分点。正数表示削弱该结构后正确类相对原最强错误类更有利。

| 操作 | 船平均分差变化 | 船级探索性95%区间 | 与同均值对照的差 |
|---|---:|---:|---:|
| VH框内细尺度 | -0.003910 | [-0.005232,-0.002528] | -0.002997 |
| VH框内中尺度 | -0.003981 | [-0.005423,-0.002568] | -0.001433 |
| VH侧向细尺度 | +0.000082 | [-0.000475,+0.000637] | -0.000068 |
| VH侧向中尺度 | +0.002023 | [+0.000882,+0.003169] | +0.001417 |
| VV侧向中尺度 | -0.001454 | [-0.002477,-0.000476] | -0.001147 |

VH框内细/中尺度削弱在31次采集中的23次平均不利；VH侧向中尺度削弱在24/31次平均有利。这是多个采集上出现同向现象，不表示每次采集的类别组成已经匹配或独立物理机制得到确认。

频率的直接作用在VH侧向区域比较清楚：fine减middle的效应差为-0.001941，船级区间[-0.002736,-0.001092]；相对亮度对照后仍为-0.001485，区间[-0.002155,-0.000781]。同一位置中，两种尺度处理不能等同。

但原始body-vs-side的区域×尺度交互+0.002012，在亮度对照差中变为-0.000078、区间跨零。不能忽略这个变化，也不能把原始交互全部归为纯频率机制。亮度对照只匹配均值、不匹配L2，其相减本身也不是纯结构因果分离。

## 3. 同船换次观测是否还能重复

新增船中，两次干预对各自原最强错误类的分差作用同号，按船等权：

| 操作 | 同船同号比例 |
|---|---:|
| VH框内细尺度 | 76.9% |
| VH框内中尺度 | 74.0% |
| VH侧向中尺度 | 76.0% |
| VV框内细尺度 | 57.2% |
| VV侧向细尺度 | 45.7% |

41对原竞争类相同的子集中，VH框内中尺度同号39/41，侧向中尺度35/41；它们是子集描述，不是所有船的准确率。效应同号可能同时反映类别和分类器的共同偏好，不能仅凭同号认定同一物理因素。原竞争类不同的情况和共同竞争类下的自然分差变化均完整保留。

跨两日期的实际改动幅度并不强制相等；等L2只针对同一视图六种操作，不能把效应大小差异全部归因于观测条件。弱效应阈值1e-5及同竞争类敏感性表见same_ship_repetition.csv。

## 4. 有分类翻转，但不是一个新部署方案

全候选中4个不同观测至少一次被救回，4个至少一次被误伤；去掉旧探索船后为4个救回、3个误伤。各操作之间有重合，不可相加或取每图最优操作计算模型准确率。

一个有解释价值的救回例子是成品/化学品船7797。削弱VV框内中尺度后，正确类分数下降0.004668，但错误的海工供应船分数下降0.020867，因而分差增加0.016199，从-0.016102越过零。亮度对照只增加0.006679，不足以击败原竞争类。同船7796同操作分差+0.016928但原劣势更大，仍未救回。说明该局部结构可能支撑混淆类别，而不只是损失真实类别信息；这个作用在同船两时相同向，但仅一张越过决策边界。

反例26082削弱VV框内细尺度后，正确化学品船分数下降0.005609、普通货船增加0.000133，造成误判。同船26083自然错误为海工供应船，依旧不能把人工错误与自然失效直接连成同一个原因。其原图显示主体在两时相大小与内部显示结构不同，不能只归为方向变化。

## 5. 原图与结论边界

六组原图已逐一查看：四种自然状态各一组，另一个救回、一个误伤案例；每组包含同船两日期、VV/VH、频率分量、实际改动和亮度对照。详见CASE_REVIEW_ZH.md。没有支持集，不能捏造支持案例解释。

全部操作的对应局部分量能量均下降；98.71%低高剂量作用同号，97.14%绝对作用随剂量增加。它们说明操作可控，并不自动证明真实成像条件的因果。

收口结论：空间—频率结构影响分类的证据已从少数案例扩大到有类别和极化边界的重复现象；当前最值得保留的是特定区域的频率成分如何改变类别竞争，而非全局高低频规则。原均值交互与亮度对照之间仍有差别，自然条件→结构变化→分类错误的链条还没有完全闭合。
