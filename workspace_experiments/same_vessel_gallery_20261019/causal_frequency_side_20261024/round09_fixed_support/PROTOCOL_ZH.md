# 第09轮事前协议：固定读出位置的输入贡献

2026-10-24。沿用第08轮VV/VH各114对，不按本轮结果选样。

问题：第08轮雷达参照优势消失是否依赖移除近船输出位置？此次不移动输出位置，只分解导数算子的输入来源。固定10m尺度，框内、轴端和侧向分别记录。

对线性导数D与OBB掩膜M，零基准分解为D(MI)+D((1-M)I)。它会引入相互抵消的掩膜边界项。因此主分析采用输出像素灰度为参照的对比贡献：g_B(p)=D(MI)(p)-I(p)D(M)(p)，g_O=g-g_B。两者之和等于原导数；各自对共同亮度平移不变。该分解仍是算法归因约定，不是物理散射源分离。

记录T_total=T_B+T_O+T_cross，cross为两个导数向量外积的对称交叉项，允许负值。不将归一化贡献称为因果百分比。保留零基准敏感性，检验结论是否仅依赖归因参照。
