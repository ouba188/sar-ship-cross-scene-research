## 研究目标

最新纠偏（第21轮）：用户要求空间—频率共同解释分类，不以空间预测频谱为主要终点。已完成12船/24观测的冻结诊断器区域×尺度干预、亮度对照和原图复核，见 `round21_classification_joint/FINDINGS_ZH.md`。这是局部分类敏感性证据，不是当前完整模型收益或自然物理因果证明。

用户要求不必先分离“纯因果隐向量”，但希望辨别：船体结构、船只姿态/运动与雷达观测条件如何共同改变图像响应，以及这些变化是否与船型判别有关。图像检测轴是轴向代理，不是可靠船首方向，也不代表完整三维姿态；当前数据没有直接观测横摇、纵摇及合成孔径期间运动。

## 以后每轮的记录约定

本侧线后续每轮在独立子目录记录：问题与事前比较、实际样本覆盖、代码与结果表、正负发现、原始 VV/VH 案例、适用范围和下一步判断。完成前不把计划写成结果；历史聊天中未落盘的统计注明回溯性质，有可用脚本的在此重新执行并落盘。不自动重训或修改主线。

三层证据必须分开：图像/模型中的可重复关系；是否有类别判别价值；完整系统是否受益。预测关系、输入替换和可视化不单独构成物理因果识别。图像空间频谱不等于原始复数 SAR 多普勒谱。
