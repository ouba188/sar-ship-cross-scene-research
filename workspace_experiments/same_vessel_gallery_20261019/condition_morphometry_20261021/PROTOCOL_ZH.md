# 同船条件与表观形态配对实验

2026-10-21。先固定协议再计算；不训练或修改分类模型。

## 样本

复用 paired_relation_probe_20261020/data_review/main_pairs.csv 的910艘船，每船一对，按最大时间间隔选取，不按分类结果或本轮变化量选取。7类（没有渔船），189对跨港，其余同港。不同日期/产品、同MMSI/类别，已有双极化唯一目标关联与双向映射检查。继承身份、坐标系及反复开发数据的限制，不声称独立人工身份验证或因果实验。

## 测量

- 原生PNG像素，不缩放、不旋正、不改变灰度；VV/VH分别计算。
- OBB长宽、面积、长宽比用每幅裁片仿射映射到投影地面米制；这是检测响应范围，不是真实船体尺寸。
- 框内统计及距离OBB边界20–80米的近邻统计，排除其他有效检测框。区域可能含旁瓣、尾迹、岸边等，不称纯海面。
- 独立于OBB边界的固定范围：以原产品目标参考位置为中心，半径180米内测高响应，220–300米环带估计背景。排除其他检测候选；保留可用面积比例。用背景median+3和5倍1.4826MAD作为两组固定阈值，MAD最低1灰度级。阈值均报告，不择优。
- 高响应权重=max(I-threshold,0)。计算沿检测船轴、船轴垂直方向、雷达水平视线及飞行方向的5–95%加权投影跨度、面积和中心偏移。跨度不是船体边界长度，船轴方向仍来自检测；不以OBB边界截断高响应。
- 响应统计主分析要求固定圆/背景环带各自覆盖率>=0.90、OBB至少95%落入180米范围、有>=5个高响应像素。覆盖不足不填零，不将删失范围当作完整范围。OBB统计保留所有有效对。
- PNG均值、饱和率、局部对比度仅代表显示域统计，不报告sigma0、RCS、真实极化比或dB散射变化。本轮不读取定标测量像元。

## 分析

每船、每极化计算第二次减第一次的尺寸对数差、对比度差和条件差。报告几何变化与表观变化的Spearman相关，同港/跨港及按类别分层；不把每个像素或两极化当独立船。

用固定的5折MMSI隔离、岭系数10的线性统计模型，比较类别均值参照与类别+几何变化预测器的留出误差。几何包含入射角变化、无向相对角的sin(2phi)/cos(2phi)变化与均值及相互项、平台/升降轨变化、时间间隔；不输入港名/MMSI/分类标签预测值。固定测量规则，不以回归结果挑阈值。能预测变化不等于干扰应被消除，也不是分类收益。

首次结果后的归因补充：在完全相同折与岭系数下，新增“类别+平台/升降轨变化+时间间隔”参照，分别加入入射角、相对方向或二者交互，区分条件包收益是否需要角度。这是有针对性的补充对照，不以结果选最优测量阈值。真实船型仅作为已知类别的统计控制，测试船标签不用于拟合但用于条件描述；该模型不能冒充不知道船型时可直接部署的分类器。OBB轴来自图像，角度与形态共享测量过程，关系不是外生因果作用。bootstrap仅固定交叉拟合预测、按船重采样，不包含重拟合或采集聚类不确定性。

按既有种子0局部基线的CC/CW/WC/WW各取一个案例，选VV OBB宽度绝对对数变化在该组内接近中位的实例，避免只选极端图。展示原生VV/VH、OBB、固定窗口及测量值，回看后区分观测事实与原因假设。该基线不是完整支持模型，本轮没有支持案例。
