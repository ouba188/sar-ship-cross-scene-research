# 强响应端先验小验证（没有真实首尾标签）

2026-10-20，拟合前固定。用户确认暂时没有独立首尾标注。只检验图像强端定向的效用，不验证十字旁瓣位于真实船尾，也不推断船首定位准确率。

固定上轮native_axis_probe_20261020全部样本、原生160裁边补零、C4读出、源端选参和划分。保留现有796维前后交换不变的描述。在此基础上追加128维两端有向差异，四种同维对照：

1. hard_strong：按每端原PNG像素最强20%的均值确定强端，特征为强端减弱端。若该统计相同，用端内全像素均值打破并列；仍相同则有向项置零。该规则不读船型标签。
2. soft_strong：有向差异乘端强度相对差的绝对值，差异接近0时追加的原始描述趋零。不使用测试标签选置信阈值。整头重新拟合且特征标准化，因此不保证恢复旧axis预测。
3. random_flip：从训练开始随机翻转hard_strong的符号，既定种子20261020、每观测/极化一次。控制增加相同维度但破坏一致的强弱端语义。
4. symmetric_content：追加原端间差的平方；提供同维非线性内容扩展，不引入有向端点关系。
5. soft_random_flip：soft_strong按与random_flip相同的随机符号翻转，匹配软强度加权后再破坏一致强弱端。
6. soft_absdiff：追加soft_strong的绝对值，保留强度加权的差异大小但不保留强弱端有向关系。

第5/6组在分类头拟合前由独立审阅指出的混淆补入：仅soft提高时，必须区分强度加权和有向排列。未查看本轮测试结果后追加。

基础axis组796维，其他924维；只与axis对比不能排除增容。所有组均不直接输入角度、位置、港口、AIS航向、雷达条件或人工首尾标记。不缩放/旋正船体；输入1个像素仍为原PNG1个像素。

岭回归alpha0.1/1/10，仅源验证BA优先/Brier打破并列；三身份折不是三训练种子。额外检查固定soft/hard头反转有向项或置零的影响，属于模型诊断，不按测试结果选模型。

报告整体/逐折OA、BA及救回误伤，检查VV/VH端点强弱一致性（只在对应可比时解释），查看代表性原图中的端点强度、饱和顶端、强交叉延伸及判对/错。不能凭图命名旁瓣/上层建筑的物理成因。无新增标注，无全量重新审计。
