# 强响应端先验验证：没有新增净分类收益，真实首尾仍未验证

2026-10-20。用户确认暂时没有独立首尾标注。本轮只检验图像强弱端排序是否提供额外效用；没有生成船尾真值，没有验证十字旁瓣位于船尾的比例。

## 结果与范围

完整保留上一轮有效的无向轴向结构，在同一批4744条观测、2973船身份、18港、8类上追加强端有向差。21个确定性岭回归头（7组x3身份折）完成，非3个神经训练种子。原生裁边补零，不缩放船体，分类头不直接输入角度。source-only标准化/选参，旧axis逐条预测复现，新提取的对称描述与旧缓存最大差0。

hard对axis OA-0.548pp、BA-0.675pp，救回207/误伤233、净-26；soft OA-0.337pp、BA-0.946pp，救回171/误伤187、净-16。hard逐折OA -0.320/-1.716/+0.451pp，soft +0.256/-0.613/-0.645pp；并非每折都负。Brier有很小改善，不概括为所有预测质量均退化。

固定模型、船级聚类500次bootstrap，hard OA区间[-1.379,+0.305]pp、BA[-1.538,+0.274]pp；soft OA[-1.292,+0.458]pp、BA[-2.029,+0.114]pp。区间跨零，不宣称显著有害；但当前没有新增可重复净分类收益，暂不升级为正式组件。区间不覆盖重训、场景相关性或反复开发的不确定性。

一致强端排列优于本轮随机翻转与部分同维内容扩展，说明它不只是无效随机项，但这不足以替代与原axis基线的比较。随机翻转只有一次既定抽样，不是置换检验。

## 实际检验了什么

每端先取原PNG最亮20%像素的均值；两端并列时，以整端均值打破并列；仍相同或端点缺失则有向项置零。符号只用于把已读出的端差变为“强端减弱端”，不把大地朝向输入分类头。

hard追加128维，soft将其乘强度相对差绝对值。保留原796维描述，新组均924维。非定向平方差与软绝对值是内容对照；两个软对照在拟合前按审阅建议补入，未看测试结果后新增。

soft追加的原始特征在两端相似时趋零，但标准化及整头重新拟合意味着不能保证恢复旧axis预测。低置信回退并未在系统输出层实现。

## 根源分析：已证实与未证实分开

### 实现与使用

强端符号、端点交换、强度并列处理的测试通过，输入延续原像素；C4仅保证既定画布和掩膜的直角旋转读出，非任意角度不变。没有发现缓存/符号/接入错误。

固定hard头，把有向项反转，OA39.165降至25.190；置零降至33.769。soft反转降至34.781，置零37.542。说明模型确实依赖新项，不是未学到或未接入。固定头破坏输入后变差不证明新模型优于旧模型，不能称为物理因果实验。

### 图像与强度依据

- VV测试4744张，3292张（69.393%）两端最亮20%均值并列，强端规则实际常由整端均值决定；至少含一个255像素的比例为端0 93.170%、端2 93.845%。这指PNG编码顶端，不是传感器饱和或校准RCS。
- VH4727张（17条停用不纳入）峰值并列61.815%，其中包含端点缺失；不能与VV直接解释为极化物理差异。没有独立首尾真值，未计算“真实首尾正确率”或语义一致率。
- hard在VV峰值不并列的1452条中救回64/误伤64，净0；并列的3292条救回143/误伤169，净-26。退化集中于并列组，但仅为诊断相关，不证明处理数值顶端即可解决。
- 按各折源验证的强度差中位数分组，hard高对比组净-7/低对比组净-19；soft高对比净-19/低对比净+3。当前没有形成“强弱越明显就越值得用”的可靠规则，不按这些测试结果选门控。

### 学习与泛化

逐折均值（不是合并测试指标）：axis训练OA57.73/BA62.52，hard58.91/64.94，soft59.01/64.38；验证axis44.22/45.70，hard43.51/45.07，soft44.07/44.73。新增关系更拟合源训练，却未兑现验证/测试收益，呈现过拟合或关系迁移不足的模式。现有对照不能进一步唯一归因于错误首尾估计、信息冗余或目标读出方式。

因此当前可以确认的是：有向内容被利用、强度端点代理常缺乏明显强度差、训练收益未迁移。不能确认的是：真实首尾没有用，或十字旁瓣先验错误。
