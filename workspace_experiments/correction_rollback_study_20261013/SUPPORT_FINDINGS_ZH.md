# 支持交互与已救回样本回退诊断

2026-10-13。已完成，只读取冻结缓存，无重提取、训练、调参或看图。对象为上一轮 `expanded__contextual` BA 选择器，不是 joint/micro 新选择器。脚本：`support_interaction.py`；所有数据输出为本目录 `support_*.csv`。

**关键结论：计数惩罚有 BA 目标下的平均风险依据，不能把 count 当成纯噪声，也不能概括为源到目标关系反转。支持证据的不足在于难以辨认个体修正效用：平均风险关系可延续，同时仍会回退大量已正确救回的多数类样本。零 OOF 事件也不是跨港统一的错误回退解释。**

## 1. 频率角色：目标取舍已经存在于源端

角色始终按查询的 raw/initial **预测类别**索引支持标签计数，预测时不使用查询真类。分组为 `initial_support_count > raw_support_count`（下称 >）及其补集（<=）。救回/误伤由查询真类事后定义。每个 episode 先在**全部 query**上计算 micro 权重 `1/N` 和 BA 权重 `1/(C*N_y)`，再筛分组及事件；各 episode 的质量等权平均后，计算 `救回质量/(救回质量+误伤质量)`。源 episode 大小不同，故 micro 比例也不是直接汇总事件数之比。未在筛出事件后重算 BA。

| 范围/context | >组救回/误伤暴露 | micro 救回占比 > / <= | BA 救回占比 > / <= |
|---|---:|---:|---:|
| source FIT / LA | 134/60 | 68.54% / 51.84% | 44.44% / 67.58% |
| source FIT / Klang | 119/58 | 66.47% / 53.20% | 39.51% / 66.10% |
| source FIT / Santos | 122/62 | 65.90% / 52.04% | 45.26% / 70.18% |
| target Los Angeles | 59/24 | 71.08% / 53.54% | 49.91% / 67.71% |
| target Port Klang | 382/355 | 51.83% / 56.40% | 42.08% / 66.22% |
| target Santos | 346/103 | 77.06% / 38.46% | 40.51% / 67.25% |

Santos 目标 >组占全 query 的 micro 质量 10.435%、BA 质量 8.461%。**原 initial 相对 raw** 在该组的全任务贡献为 OA `+5.0995救回 -1.5181误伤 = +3.5814` 点，BA `+1.5090 -2.2158 = -0.7068` 点。对应源 Santos context 也是 micro 净正、BA 净负。BA 强调少数类后，误伤质量超过救回质量；因此压低该组的平均偏好并非毫无依据，但不能据此正确拒绝组内每个具体救回。此表是分组关联和目标质量核算，不是 count 的独立因果效应，也未证明当前惩罚幅度最优。

完整 source-held、三港、F/OSS legacy/new 的质量、分母、组内救回率/误伤率及事件救回占比见 `support_frequency_role_units.csv`、`support_frequency_role_summary.csv`。主代理的 logit 中和结果另行汇总；本分支没有运行中和或提出关闭 count 的新政策。

## 口径、验证与边界

152个输入单元逐一以其 `label_path` 的 `iloc(support_ids)` 重建counts/rescue/harm并与缓存完全核对；15个三港单元逐观测重放上一轮10025行；44个评估单元的选择器OA差与发布值相符，共211项记录于 `support_verification.csv`。追加频率质量独立核算的44个OA及44个BA总和均重放原initial相对raw，最大误差分别2.67e-15、4.89e-15。`support_units.csv`给出每个UID的原输入和标签路径；`support_members.csv`给出原16个支持的位置、ID、船号、类别和OOF gain；分母见 `support_denominators.csv`。

这些是共享支持组合、重复使用的开发数据上的描述性诊断，不是29次独立支持实验。配对固定了观测和救回状态，没有固定其余支持诱发变量；OOF事件稀疏解释可用证据有限，不证明它是唯一根因。真实标签仅用于事后评价、BA权重和分层，不进入预测角色选择。报告不新增阈值、策略、训练或下一轮实验；主脚本、记忆和旧文件未改动。

主代理整合后续记：上文“旧文件未改动”指子代理交付范围。主代理随后已在旧 `condition_audit.py` 修复 `groupby(..., dropna=False)`，增加全部观测覆盖检查并重算诊断表，旧两份报告记录232→233更正；45项旧指标重放最大误差仍6.66e-16。没有修改冻结预测或旧OA/BA。
