# 多场景案例记忆小验证：原方案未奏效，定位退化后出现弱正信号

2026-10-13启动，2026-10-14收尾。实验、一次定向修正和验证均已完成。没有训练新骨干，没有接入外部数据集，没有替换论文主模型。

## 结论先说

**原来的“RBF参照响应直接拼成关系核”没有达到预期；定位到共同响应占主导后，改成相对关系表示，在小范围分类上出现可保留的正信号。**

跨采集支持B64，修正后的场景记忆相对原模型OA/BA为 **+0.084/+0.203个百分点**，五组支持平均BA有4组正、六次采集有4次正。普通同容量多原型为OA/BA **-0.330/-0.129**。这是探索信号，不是成熟模块：收益小、概率风险没有同步改善，且总体合并样本的正确数略减。

本轮证据支持继续研究“相对参照关系如何用于适配”，尚未证明单靠场景记忆能普遍解决跨场景损失，也未证明可解释为纯因果机制。

## 1. 做了什么

- 数据：24港语料中的巴生港、杰贝阿里、新加坡，六次实际采集；300个查询观测、288艘已知船。
- 港口按满足B64任务的采集数选前三；各港取最早和最晚可用采集，不按预测成绩挑选。
- 两预算B16/B64；每预算五组支持；同采集/同港其他采集支持逐类数量匹配，查询固定。两个预算的支持不是嵌套抽样。
- 每港先按船只留出约30%作为查询身份池，其余船只用作支持；查询身份不会在其他采集支持中重复出现。
- 将三港全部观测及其在其他港的同船身份、采集从源拟合池排除。实际源拟合10633行、八类齐全；源记忆统计6047艘船。
- 新拟合一套共同PCA/统计量与三个源线性头；四方案共用。编码器冻结，历史训练/研发暴露仍在。
- 模型是共同紧凑双路读出，不是旧完整版；没有把本轮绝对成绩替换论文主表。

查询类别：散货33、渔船1、杂货20、成品/化学品油轮124、集装箱32、原油轮33、拖船30、海工27。前五采集各7类，最后新加坡采集3类。虽然合并有八类，但每次采集BA按其实际出现的类别计算。对渔船几乎没有独立评价能力。

汇总顺序为支持抽样、采集、港口；本轮每港恰有两采集，因此相当于六采集等权。五组支持不是五次独立训练。

## 2. 四个原始对照

1. 原始专家核，不加入参照记忆。
2. 每类一个源均值，共8个参照。
3. 每类8个普通KMeans原型，共64个。
4. 先按类别-采集计算同船去重均值，再对这些场景均值聚成每类8个模式，共64个。

后两组记忆容量、输入特征、RBF带宽、核混合比例相同。混合比例固定0.25；带宽和核能量匹配只取源数据。支持-支持和查询-支持同时换核，系数分别重求解，正则8、基础分支和0.5概率融合不变。

注意：场景组既改变聚合单元，也改变重复船只/场景的权重；本轮没有把这两个作用进一步分离，不能把差值全部命名为“识别出了场景因子”。

原方案场景记忆相对原核：

| 支持条件 | B | OA变化 | BA变化 |
|---|---:|---:|---:|
| 跨采集 | 16 | -0.094 | -0.182 |
| 跨采集 | 64 | -0.333 | -0.600 |
| 同采集 | 16 | -0.422 | -0.129 |
| 同采集 | 64 | -0.519 | -0.057 |

三种原始参照方案在跨采集两预算的OA/BA完全相同，仅概率有小差异。固定跨采集图库的类-采集宏平均MAP@R从原核 **6.948%** 降至场景记忆 **5.420%**，不是只有最后融合掩盖了关系改善。

## 3. 根因定位，而不是直接否定方向

源记忆的RBF响应矩阵，第一奇异方向占未中心化总能量 **99.895%**，有效秩 **1.012**。这不是“99.895%的分类信息”，也不是把未中心化能量等同于方差。

关键是进一步做了真实分类对照：

- 只保留这个源端拟合的共同方向、重新求解支持系数，就能复现原场景记忆在本轮全部6000个查询-支持条件暴露中的紧凑分类决策。
- 这个共同响应的幅度与原特征范数相关系数 **-0.985**，支持其主要携带整体远近/幅度关系，而不是丰富的参照偏好。
- 只保留其正交差异部分，不重新放大，结果多数接近“原核直接乘0.75”的对照。B64跨采集BA为+0.034，而单纯收缩为-0.204；局部差异仍存在，不能说剩余信息绝对无用。

**已定位的实现层面机制是：公式按设计正确执行了，但所选关系表示在当前数据上退化为近似共同响应。** 不属于漏接梯度或系数复用错误；也没有因此证明记忆中不存在可用判别信息。

## 4. 一次针对性修正

对三个参照方案统一采用：

```text
RBF参照响应
  → 每个样本的响应向量L2归一化，去整体幅度
  → 减去源端独立船只的平均关系模式
  → 用源端平均能量定标
  → 按原0.25比例并入原核
  → 重新求解支持系数
```

所有均值、尺度只来自源数据。没有搜索混合比例，没有扩大训练；此次修正由本轮诊断触发，属于同一批数据上的探索修正，不是新独立确认。代价是新记忆不再保留绝对“离参考库多远”的幅度，原特征核仍保留。

修正后场景关系的第一方向能量降至17.585%，有效秩升至31.167。这只说明关系不再近似单一响应，不能独立证明它对任务有用。

### 跨采集分类结果

以下均相对原核，单位为百分点：

| 修正后的参照方式 | B16 OA / BA | B64 OA / BA |
|---|---:|---:|
| 每类一个均值 | -0.012 / +0.111 | -0.799 / -2.929 |
| 同容量普通多原型 | -0.046 / -0.095 | -0.330 / -0.129 |
| 场景多模式记忆 | **+0.065 / +0.058** | **+0.084 / +0.203** |

场景记忆同采集B16为+0.071/+0.138；B64为+0.168/+0.362。

B64跨采集，场景记忆的原模型OA/BA为43.519/39.892，修正后43.603/40.095。BA支持抽样标准差0.595个百分点，4/5组正；OA3/5组正。B16跨采集BA仅2/5组正，平均增益不足以解释为稳定收益。

### 收益发生在哪里

| 港口 | B64跨采集 OA变化 | BA变化 |
|---|---:|---:|
| 巴生港 | +0.270 | +0.714 |
| 杰贝阿里 | -0.221 | -0.265 |
| 新加坡 | +0.202 | +0.160 |

六次采集中的BA变化：+1.224、+0.204、-0.768、+0.238、-0.124、+0.444个百分点。并非每港都赢，但也不是仅一次抽样正。

B64跨采集BA贡献：杂货+0.238、海工+0.135、散货+0.074，成品/化学品油轮-0.054、拖船-0.190，其他类净0。净收益主要来自少数边界判决，不能说所有船型都学到了新证据。

**务必保留汇总口径差异：**五组支持、六次采集累计救回7个、误伤9个重复暴露事件，合并全部300查询×5抽样的OA变化为-0.133个百分点；而每采集等权OA为+0.084。小采集/不同类别的权重不同，导致二者方向不同。因此应称“等权场景/类别目标上的小收益”，不能称“总体多认对了船”。

## 5. 检索、概率风险与分类不能混成一个结论

固定图库、排除查询身份、图库均来自其他采集，类-采集宏平均MAP@R：

| 关系 | MAP@R |
|---|---:|
| 原核 | 6.948% |
| 原场景记忆 | 5.420% |
| 修正后场景记忆 | 7.181% |
| 修正后普通多原型 | 7.334% |
| 修正后每类均值 | 11.764% |

每类均值检索最好，却在B64跨采集适配BA明显退化；普通多原型检索略优于场景组，分类却较差。检索排序不是有符号残差求解和完整分类的充分替代指标。

修正后场景记忆B64跨采集宏Brier变化 **+0.000145**、宏NLL **+0.000255**，均略差；同采集B64宏Brier **-0.000311**、宏NLL **-0.000637**，改善。统一使用T=1，不把未校准softmax称为已校准概率。

因此，本轮不是“关系、连续风险、最终分类全部闭环提升”。已闭环的是：原表示退化被实验定位，修正改变了表示与部分分类；新增场景组织相对普通记忆的效用仍需要固定候选后的扩大验证。

## 6. 成本与验证

- 初次特征编码、共同源拟合、记忆构造和预测约28.3秒；不含元数据准备、后续诊断、报告，也不是图像端到端时间。
- 在相同缓存特征和查询上，重复10次计时再按上下文取中位：B16专家关系计算+适配+预测约7.23→11.07ms；B64约8.81→16.25ms。修正版包含关系映射，但不含编码器、源记忆构建、公共基础分支、文件读取。绝对开销小，但这部分计算并非免费。
- 原始480次专家求解，诊断360次，修正360次；新神经训练为0。
- 原始960条、修正720条OA/BA由sklearn独立重算；120个独立KernelRidge求解检查通过；类别贡献求和、显式联合特征核、零混合系数回退、手算MAP@R均通过。
- 保留原始失败、诊断与修正独立目录，没有覆盖失败结果。

## 7. 如何推进

可以保留“去共同响应后的相对参照关系”作为候选，尤其关注B64、等权场景/类别目标。当前不启动大规模训练、不宣称新模块已成立。

更有价值的下一步是冻结这次修正及全部参数，在未参与本次设计的其他源采集上检查同一增益是否重现，同时继续保留普通多原型和每类均值对照。若收益延续，再考虑轻量学习；若只限于当前少数决策，就按局部有效记录，不靠继续调参扩大叙事。
