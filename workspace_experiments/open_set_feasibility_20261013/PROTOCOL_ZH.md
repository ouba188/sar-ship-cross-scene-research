# 开放集与目标缺类：收益空间诊断

2026-10-13。在任何本轮新预测之前固定。独立侧线，不修改已收口主模型、稿件、其他目录，不训练神经网络或新门控模块。

## 先回答什么

1. 目标缺少一个已知类时，原8类读出是否仍误判成该类？知道真实类别集合的上界有多大？简单屏蔽支持中未出现的类是否会伤害其实存在但未抽到支持的类？
2. 将一个类别从本轮源读出、PCA和支持中排除后，已有表征能否区分它与跨域困难已知类？
3. 在相同已知类支持与分类器下，目标支持关系能否比分类置信度提供可重复、值得付出成本的净收益？

## 边界与冻结范围

- 目标固定为Los Angeles、Port Klang、Santos、F_0921、OpenSARShip 2.0。三个港是既有常用八类覆盖任务，不根据本輪输出选择。
- 用固定R50原图/C4与pre-task e206 R18缓存，无新增编码器训练。历史冻结骨干暴露未重置，因此是冻结表征的留类可分性/拒识可用性诊断，不是端到端从未见过未知类的正式开放集成绩。
- 本轮新拟合的PCA、标准化和源分类头严格只使用该轮已知类；不是从旧8类输出中简单删除一列。使用紧凑C4基础头与192维双路专家，各自源岭先验+目标支持残差、等权概率融合。不含完整版的分频、漂移/稳定坐标、入射角和高维补充核，因此不是原完整模型新主表。
- 源集取三港、F、OSS2原允许源索引的交集，再排除目标五任务全部已知船舶身份；排除源内标签冲突身份。每源类最多随机512个不同船舶，各一观测，seed20261013。在这些固定源案例上分别拟合8类参照和八套7类诊断；PCA128/64、源类平衡ridge1，目标类平衡ridge8，参数固定。
- 每目标任务只使用可核验9位身份且同任务内类别一致的船。按身份固定约30%为候选支持池，其余为查询池；每类最多128艘查询船，每船随机一观测。身份选样与预测无关。查询与支持整船隔离，查询/支持身份与本轮源拟合隔离。保留每类覆盖和无法入组的任务。
- 每轮未知类0..7；目标支持池排除该类后随机选64个不同身份，5次抽样。未知类不进入支持，属于已知标签库适配诊断；不模拟从混合未知池花64次标注就一定取得64个已知标签。若容量不足或该未知类无查询，记录不可评估，不换有利任务。

## 四个固定拒识分数

- MSP：1减融合最大概率。
- source_knn：已知源案例中最近5例的平均余弦距离。各已知源类最多128例，固定随机抽样。
- support_knn：当前64个目标支持中最近3例的平均余弦距离。
- msp_support：MSP和support_knn分别按支持留一分数的均值/标准差标准化后，固定等权相加。不训练选择器，不搜索权重；这是信息组合探针，不宣布为新模块。

全部分数共用同一分类预测。基于目标已知支持逐例留一重算残差系数得到校准分数；相似度排除自身。阈值为校准已知分数的90%和95%分位，测试标签不进入阈值、权重或模型选择。64个支持之外不追加验证标注。使用经验分位不宣称有限样本拒识率保证。

## 评价与开发决定

报告未知检出率、已知类误拒率、拒识前后已知BA、H-score、类平衡AUROC、OSCR、逐未知类和五支持波动。所有已知类宏平均，不由多数类主导。

条件性净收益U(pi)=pi*未知检出率-(1-pi)*被拒掉的原本正确已知类比例，后项按已知类宏平均。固定pi=5%、20%、50%，只表示设定混合比例下相对于同分类器不拒识的收益，不是新指标原创声明。主工作点95%支持校准分位与pi20；其他为预设敏感性，不按测试最优挑工作点。

另报告使用查询标签才能得到的5%已知误拒下未知检出上界，用于区分“分数可分但阈值失配”与“当前分数本身分不开”；明确标记oracle diagnostic，绝不当部署性能。

缺类实验使用8类参照和同一64支持，仅评价非缺席类查询。比较原预测、真实缺席类屏蔽（不可部署上界）、支持零计数类屏蔽（简单可用规则）。此处8类参照和未知7类实验不混用源头。

有针对性检查：源/支持不含本轮未知类，已知支持与查询身份不交叉；类别编码回映正确；留一校准与独立岭求解抽查一致；保存预测后独立计算指标。正信号按任务范围保留，若只改善排序但系统未受益，分别解释；不据此直接否定因果因素或所有开放集路线。
