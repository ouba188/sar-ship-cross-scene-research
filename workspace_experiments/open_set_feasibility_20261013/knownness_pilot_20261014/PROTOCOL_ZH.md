# 已知缺支持与真正未知：轻量拒识试验

日期：2026-10-14。独立侧线，不更改主模型或论文。

## 目的与预先约定

检验源域类别证据能否减少目标支持不足引起的已知误拒，同时保住未知检出。
先检验冻结表征上的收益空间，不训练新骨干、不宣称复现 OVANet/PEELER。
借鉴 OVA 类别边界、模拟未知任务和近邻拒识；新增部分只是四变量逻辑回归探针。

## 数据与隔离

- 外部评价：OSS2、F_0921、Port Klang；沿用原查询、64支持、5抽样。
- 八次外层留类 u：最终源读出/PCA、目标支持均排除 u。冻结骨干历史接触不重置。
- 源任务训练查询港：Jebel Ali + Qingdao；源校准查询港：Singapore + Ningbo-Zhoushan。
- 这两组是混港模拟任务，非纯单港复刻；记录组成，不将其迁移结果视为必然。
- 每个外层 u，再逐个选 v != u 为模拟未知。该任务源 PCA、分类头、OVA 和近邻库均排除 u、v 及整组查询港。
- 查询不含外层 u；模拟未知 v 不进入支持。源每船一例，支持/查询身份隔离。
- 每组预先固定35%船为支持池，查询每类最多40船；3抽样，随机与刻意缺一已知类两种支持任务。
- 刻意缺支持类别只按标签容量和固定轮换指定，不根据模型表现挑选。
- 最终随机/cover1目标支持直接复用已有计划，cover1是有标签候选库存上的覆盖干预，不等于仅64次标注请求。

## 方法

分类预测全方法相同，使用原紧凑双头适配；不是冻结论文完整模型。
拒识分数：MSP、源5近邻、支持3近邻、独立平衡二分类 OVA 的 1-max(knownness)、
源/支持距离标准化后的 min（任一路支持即可保留）、四变量逻辑回归 joint。
四变量：OVA未知分数、源距离、支持距离、log(1+预测类别支持数)。
不输入查询真实类别或标签。目标支持校准使用 LOO，支持计数也扣除被留出的那一例。
OVA和joint均为确定性凸优化，没有神经训练随机种子；3次源支持、5次目标支持不冒充训练种子。
joint训练按任务及已知/未知平衡，已知内部按类平衡。

## 校准、选择与评价

主阈值：源校准任务已知分数的加权95%分位；阈值在目标评价前冻结。
辅助阈值：目标已知支持LOO分数95%分位。用于分辨排序与阈值迁移问题。
六种方法均报告；额外 source_selected 只按源校准 U(20%) 选择上述方法或不拒识，目标不挑优。
目标标签仅用于评价：AUROC、OSCR、诊断TPR@5%已知误拒、实际已知误拒、未知检出、拒识前后OA/BA、U(5%)/U(20%)。
U(pi)=pi*未知检出-(1-pi)*原正确已知被拒比例，后者采用已知类别宏平均；不是自然分布OA。
分支持覆盖/缺失已知组、各未知类、每次抽样报告；五次相同查询的抽样不当独立数据集。
原判别器不变，逐船核对救回已知/新误拒及新增未知检出/错误放行，解释净收益。
目标上同误拒率曲线是诊断，不拿其最优阈值部署。

## 决策

不要求每港每类获胜。明确范围内重复且值得成本的净收益可以保留。
先检查训练内有效性、源校准迁移、目标排序、目标阈值、类别与支持组成，再判断方向。
失败保留原结果，不以目标标签无限调参。简单方法已足够时不推广复杂模块。
本轮不自动扩展23港或改写主方案。
