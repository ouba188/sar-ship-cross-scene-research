# 已知缺支持与真正未知：本轮结果

日期：2026-10-14。已完成，独立侧线；没有修改主模型、论文、共享记忆或并行任务。

## 结论先说

**有可利用的局部收益空间，但尚未得到一个统一有效的覆盖感知未知检测模块。**

新正信号不是八类闭集BA上涨，而是真正留类后的未知拒识收益：

- F_0921：渔船从拟合类别中排除时，轻量类别边界头明显优于原支持距离；5次支持抽样均改善。
- Port Klang：同样留出渔船，联合分数提高检出，4/5抽样优于原支持距离。
- OSS2：简单固定规则有正收益，学习的联合判别器没有超过它。

不能把按数据集分别看到的最好办法拼成一个已会自动选择的算法。源验证选择器本轮并未找出这些目标域最优方案。
局部渔船范围此前已发现，具体“F用OVA/Klang用joint”的归纳来自本轮结果，仍是探索性范围结论。

## 做了什么

复用原查询、64艘支持、5抽样，在OSS2、F_0921、Port Klang逐个留出8类。每类目标比较random/cover1两臂，共240个目标评价上下文。
采用原紧凑冻结双头读出，不是论文冻结完整模型；所有拒识方法在同一臂内共享相同分类输出。

源任务为Jebel Ali+Qingdao训练、Singapore+Ningbo-Zhoushan校准，支持随机/刻意缺一已知类两种任务，各3抽样。
外层未知u、内层模拟未知v均从对应源PCA、分类头、OVA和近邻库拟合中排除；源拟合还排除该任务的整组查询港。
内层训练6个已知类，最终外层测试7个已知类；这个任务差异保留，不宣称完美同分布。
训练与校准查询船不重叠；各内层源拟合分别留组，不是把所有校准港永久从整套源研发数据中删除。

总计672源任务、56次源几何拟合、112个源ridge头、64组OVA（共392个二分类头）、8个四输入逻辑回归。
无新骨干/神经训练；确定性凸优化不把支持抽样称为训练随机种子。预测流水线含加载约236.6秒，CPU单线程；不含历史图像特征提取。

六种分数：MSP、源近邻、支持近邻、OVA、固定规则fixed_union、joint。另报不拒识和仅按源验证选出的source_selected。
OVA是独立平衡线性二分类，不是完整OVANet；模拟未知任务借鉴开放集元学习，但不冒充PEELER复现。
固定规则对源/支持距离分别用支持LOO统计标准化，再取min；joint使用OVA分数、源距离、支持距离、预测类别支持数量。

U(20%)=0.2*未知检出率-0.8*原本正确已知被拒的类别宏平均比例；不是八类OA或BA增量。

| 方法 | F_0921 | OSS2 | Port Klang |

| MSP | +0.035 | +0.183 | +0.233 |
| 源近邻 | +0.546 | -1.169 | -0.965 |

OSS2固定规则五抽样均为正（均值+0.709，SD0.313），joint为4/5正（均值+0.453，SD0.333）。
F的源近邻五抽样均为正（均值+0.546，SD0.151），joint五次均负。Klang的joint五次均负。
这些是相同查询上的支持抽样变化，不是五个独立数据集。

主协议的“源校准阈值直接迁移”下，joint的U20分别为F -0.006、OSS2 -0.055、Klang -1.306。
F和OSS2不是几乎完美地保留已知，而是几乎不拒任何东西：未知检出仅0.020%、0.195%。

## 二、具体有价值的范围：渔船作为未知类

这里三个数据集的已知类均为另外7类，渔船不进该轮源读出/PCA/OVA拟合及目标支持。
冻结骨干历史类别接触没有重置，不能称端到端从未接触渔船。
使用支持LOO阈值；同一查询/支持抽样与原支持近邻配对。

| 数据集与候选 | 未知渔船查询数 | 未知检出：旧→新 | 已知误拒：旧→新 | U20：旧→新 | U20改善抽样 |
| --- | ---: | ---: | ---: | ---: | ---: |
| F_0921，OVA | 128 | 0.63%→20.00% | 6.77%→7.39% | -1.472→+2.735 | 5/5 |
| OSS2，固定规则 | 128 | 25.00%→28.28% | 7.59%→7.88% | +3.201→+4.177 | 3/5 |
| Port Klang，joint | 38 | 25.26%→41.05% | 6.28%→7.90% | +2.898→+5.549 | 4/5 |

这些正收益允许付出一定误拒代价，不是同时改善每个指标。
相对旧支持近邻的U20差值，在固定模型/支持下按查询船类别分层配对bootstrap1000次：

- F：+4.207，95%区间[+2.832,+5.710]。
- OSS2：+0.976，区间[-0.928,+2.852]，额外优势尚不确定。
- Klang：+2.651，区间[+1.055,+4.083]；仍只有38艘未知渔船。

未知占比改为5%，上述候选自身相对不拒识的U05分别为-0.502、-0.342、-1.108。
**因此收益适用范围必须同时说明未知比例和误拒代价，不能称为罕见未知出现时也已划算。**
不同数据集分别选择候选是本轮结果解读，不是无标签可部署选择器。source_selected在全部类别上也未选择joint。

## 三、为什么会这样：哪些已有证据

### 1. 源域阈值不适合直接搬过来

源随机任务已知样本平均支持距离约0.723，OSS2为0.413，F为0.496，Klang为0.721。
平均支持近邻源阈值0.862；目标LOO阈值OSS2 0.627、F 0.728、Klang 0.848。
joint源阈值平均0.599，目标LOO分别0.411、0.470、0.590。
这直接解释了外部两个数据集使用源阈值时几乎不拒识的计算现象。

已证实的是分数分布和阈值迁移不匹配。混港任务、源/目标表征分布、拟合样本与6→7类差异各贡献多少没有被独立干预，不能单独认定混港是唯一根因。

### 2. 校准不是唯一问题，平均区分能力仍然弱

joint全部留类平均AUROC：F50.63%、OSS2 55.85%、Klang51.66%。
支持近邻分别51.02%、55.24%、51.86%。学到的组合基本没有产生新的普遍区分能力。
源训练joint AUROC58.08%，源校准54.96%；源校准U20仍-0.918。
因此不是只在最终融合时丢失收益；源任务阶段也没有形成强且普遍有用的类别边界。

### 3. 相同线索，在不同目标域对渔船的意义会反过来

- F渔船未知：支持距离AUROC31.08%，OVA64.62%。新边界提供了原局部距离没有体现的区分，五抽样多检出且净受益。
- Klang渔船未知：支持距离76.08%，源距离23.52%。源空间里“靠近已知”并不能直接当作“肯定已知”；固定取min规则AUROC降到32.76%。
- OSS2渔船未知：支持距离72.56%、源距离69.56%，固定结合后75.50%；此处两种证据方向更一致。

这说明“只要源域支持就保留”的规则不能通用，更不是已经证明了源类别证据能普遍救回缺支持类。
上面是类别、数据集和计算证据的解释，不是唯一散射物理原因。

### 4. joint的局部增益主要不是覆盖计数

对已经冻结的joint做计算归因：将一个标准化输入置为源训练均值，其他参数不变，仅按支持LOO重新校准。
这是结果后诊断，不重新训练，也不把查询标签用于阈值；不是物理因果干预。

Klang渔船范围的U20：

| 保留/去除输入 | U20 |
| --- | ---: |
| 原joint | +5.549 |
| 去除支持距离变化 | -0.366 |
| 去除源距离变化 | +4.273 |
| 去除OVA变化 | +3.956 |
| 去除支持数量变化 | +6.085 |

这支持“目标局部距离是主线索，源距离/边界分数在此范围补充修正”，不支持“覆盖数量是有效新核心”。
F中反而去除joint的支持距离变化后，渔船U20从-1.321变成+1.299，符合局部距离在该数据集误导这一观察。
所有置均值结果仅解释现有计算依赖，不能直接升级成在测试集上挑出的新模型。

### 5. 覆盖干预与拒识模块必须继续分开

cover1相对random，joint的V20（含分类变化）为F+0.403、OSS2+0.111、Klang+0.181。
但原缺支持已知组在random下，joint误拒分别15.01%、7.98%、26.28%；没有普遍解决缺支持误拒。
覆盖收益不能拿来证明joint有效。跨支持臂比较用V，固定分类器拒识价值用U，避免混淆。

## 四、下一步判断

1. 保留F渔船OVA、Klang渔船joint的局部正信号；不因总体平均弱而抹掉它们。
2. 暂不把四输入joint推广成完整模型的新核心，也不继续增加复杂度。
3. 如果继续，优先冻结一个明确已知类别范围，验证“域内可比的源/支持证据关系”，并用已知支持选择规则而非按未知测试类别选最优。
4. 先证明这个关系/选择能复现局部收益，再接入完整模型、扩展港口与预算；本轮没有自动启动下一轮。
