# 固定64支持预算的类别覆盖干预

2026-10-13，预测前固定。只在本目录写入，不修改上一轮预测或主模型。

问题链：目标支持距离混淆新类别与未覆盖已知类 -> 在相同预算下补齐已知类 -> 检查受补齐类别的误拒是否下降 -> 检查未知检出、原本正确已知预测的损失及完整决策净效用。

## 固定项

复用上一轮全部5目标、8留类、5支持抽样，200个组合。查询船、历史冻结骨干、每轮7类PCA/标准化/源分类头、残差岭配方、融合权重、四种拒识分数保持不变。只因支持样本变化按原配方重新求解残差及支持留一阈值，没有新模型/参数搜索。不是冻结原支持残差系数后改变其训练数据。

从原身份隔离的30%候选支持池抽样，不将查询船搬入支持。不重划数据。各臂恰好64艘，未知类始终不进入支持。

## 抽样臂

1. random：完整保留上一轮64案例。
2. cover1：每个已知类至少一艘，仅对缺类做最少替换。从当前最多案例的可让出类别中随机移出一艘，换入缺类的一艘未选船；保留其余原案例。
3. sham1：与cover1相同的替换位置和替换数量，换入被移出类别的另一艘船，原类别计数不变。检验是否只是换了案例而非覆盖修复。
4. cover3：预设敏感性，每个已知类尽量至少三艘，与固定3近邻的证据需求相对应。算法同cover1，不改变近邻数。候选池不足3则取可用容量；池内没有该类则记录不可实现，不能宣称全覆盖。

所有抽样仅依赖候选支持标签和身份，不用查询预测/正确性。优先看原随机支持确有缺类的组合，同时报告全部组合，禁止只挑修复后获益组合。渔船未知的OSS2及Port Klang作为上一轮明确提出的候选范围；其余留类全部保留。

## 评价和归因

主工作点仍为已知支持LOO的95%经验分位，不用查询标签选阈值。报告AUROC、未知检出、已知误拒、拒识前/后已知BA、U(5/20/50%)。U仍相对各臂自身不拒识参照，不能单独当跨臂完整系统差值；另计算V(pi)=(1-pi)*拒识后已知BA+pi*未知检出，跨臂差才是统一参照下的总效用变化。

按原random的零支持类别/有支持类别分层，在相同查询上配对。报告被补齐类别、让出支持类别及未变化类别，避免类别组成变动伪造误拒下降。对support_knn补充固定原阈值和固定原分类预测的交叉评价，区分邻域变化、校准阈值变化和分类读出变化。source_knn查询分数应不随支持变化，是分数路径控制。

五次抽样报告配对均值、标准差和方向；重复使用相同查询不是独立船舶重复。保留全部失败结果；不搜索更多floor、门控、阈值或分数权重。

## 标注预算含义

本实验比较已标注候选库中各选64个支持的价值，类别定额使用候选库标签。这是支持构成的控制实验，不保证从完全无标签池只付64次标注就能实现类别覆盖。部署若需额外搜索标签，必须另计成本。本轮不利用未知类标签训练未知分类器。

## 有针对性的检查

重建输入与旧source/query/support索引一致；回放每个任务/留类的一个原始预测和阈值；确认64唯一身份、类别隔离、cover/sham替换数及计数；独立按类核算误拒/检出及救回-伤害；检查未改变支持的臂输出一致。任何不一致先修实现，不解读收益。
