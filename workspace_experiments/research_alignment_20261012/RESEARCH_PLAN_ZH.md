## 1. 先说结论

目前最值得解决的不是再造一个“更稳定的隐空间”，而是两件已经有具体证据的问题：

1. **跨数据集后，哪些外观线索与船型的对应关系发生变化，模型是否真的依赖它们？** 类别与显示对比度的关联反转已经观察到，模型依赖和可修复性还要等输入对照。
2. **目标支持案例提供了有用证据，为什么改好一个分支却没有改好整个系统？** 已经定位到先验更新、支持残差和概率融合的相互作用；但“完全保留更新”也会误伤，因此不能把抵消全部视为坏事。

研究主线建议收敛为：**中低分辨率SAR跨港细粒度识别中，利用任务有用的互补表示与少量目标支持案例，在不同标注预算下获得可解释的净收益。**

这里的预算首先是目标标注数量B，不是必须保留5%专家交接。当前完整参照仍为双路等权概率融合。部署不新增AIS、MMSI或同船历史依赖；已有SAR采集元数据与严格仅像素设定需要分开说明。

因果因素探索保留为研究线索，但现阶段不能把“稳定候选空间”“映射残差”或“计算路径归因”直接命名为已分离的纯因果因素。

### 3.1 近期主线训练的准确判断

拆分预算后的三港完整模型OA/BA分别为：B16=48.1511/38.8990，B64=48.2429/43.2380，B128=49.3232/46.4750。

它在B64/128相对共享训练有两个训练种子同向的小收益，值得记录。但B16已有简单方案BA40.5348，B64旧修正器43.3327，B128无修正46.6056，均仍是相关的更强参照。不能事后拼出一个按目标成绩挑选的最优组合称为新方法。

“不同预算梯度普遍冲突”缺少支持：所测同查询平均梯度余弦为正，真实AdamW跨预算单步平均也改善其他预算损失。原始梯度大不等于实际更新支配其他预算。暂不开发PCGrad式处理。

### 3.2 侧线最有价值的完整模型证据

OSS2较强历史基线为OA/BA=42.5971/34.6744。相同64标签更新专家先验：

| 阶段 | 相对该阶段自己的参照，OA/BA变化（百分点） |
| --- | ---: |
| 专家先验 | +3.0698 / +1.4318 |
| 专家先验再加重新求解的支持残差 | +0.2391 / +0.1502 |
| 最终等权概率融合 | -0.0489 / -0.0868 |
| 后续支持内部CV选择的最终模型 | +0.2934 / +0.2253 |

这些不是可逐项相加的贡献。最后一行是后续独立接法选择结果，不是前几行的下一个必然步骤。

先验与残差的分数变化余弦约-0.9828，变化范数平均保留18.69%。**这是分数抵消，不是81%的准确率被抵消。** 对固定核、支持权重和岭强度，记支持拟合算子为A，则：

```text
f(Q) = P(Q) + A_QS [Y_S - P(S)]
改变先验P -> P + D后：
Delta f(Q) = D(Q) - A_QS D(S)
```

该恒等式解释了为什么先验更新会被后续残差部分减去；它不证明这是实现错误，也不证明应当取消支持校正。保留全更新时，散货召回约-12.13、集装箱约+12.05个百分点，说明二者有真实的边界交换。

CV减少了部分误伤：散货损失缩到-2.6540，集装箱增量缩到+3.3578，最终净收益更好。五组仍只有2正、1负、2平，去掉收益最大一组后OA/BA仅+0.0611/+0.0030。它是有限但可解释的正信号，而非应抹掉的失败或已稳胜的主模块。

还有一个重要投入边界：这四个固定候选事后用查询标签逐组挑最高OA，增量约+0.3912；目前CV为+0.2934，只差约0.0978个百分点。这个数只约束当前候选、五组支持和OA，不是所有方法/BA的理论上限。**因此不值得围绕同四臂先开发复杂选择网络。**

### 3.3 双路和输入问题如何接起来

同折冻结模型下，R50到R18的MLP重建R²在港口/OSS1/OSS2为0.4446/0.0440/0.0160；在可重建部分上再加剩余部分，专家类宏Brier分别下降0.001306/0.008568/0.005258。类别匹配后差异仍在。

可支持的解释：当前源端映射难以恢复、但对分类有用的成分，在公开目标上更重要。不能支持的解释：这些成分在任何单路中都不存在，或已经对应某种独有物理因素。

显示对比度的类别排序也反转：“集装箱高于渔船”的概率在自建/OSS1/OSS2约0.9855/0.0159/0.0292。这是数据关联变化，不是模型已依赖它、更不是纯噪声已经被定位。

正在运行的输入对照将回答后一个问题。裁切同时改变视野、尺度和插值；显示拉伸不是物理辐射校准，不能将其正结果自动讲成成像原因已唯一确认。此处也不借历史F_0921输入问题解释科研现象。

如果重复仍有成本合理的净收益，作为适用OSS2条件下的轻量接法纳入候选；若均值不确定但概率风险重复改善，准确描述该层收益；若接近零，则按辅助诊断收口，不继续扩复杂门控。随后才决定是否值得把该接法扩到B16/128。

### P2：需要更大提升时，优先试已有强表征，而非继续细调当前选择器

已有源端领域SSL的R50（D50）紧凑同口径试验，在F/OSS2相对通用R50的BA约+1.06/+3.40个百分点；这不是完整模型提升，但比近期修正器差异有更明确的表征收益空间。原G50+D18混合双路并未自动成为最优。

建议将“D50强单路是否能兑现到实际读出”列为下一次训练/模型接入的优先备选。先复用已训练权重与可用缓存，不立即再做SSL大训练。沿统一读出比较G50、D50、D50+现有第二路，并保留当前完整模型为外部参照。

不能直接把D50特征送入旧G50的PCA、分频嵌入或源分类头。成对重拟合必要的源端变换；如完整算子需要再训练，先做同算子的配对桥接，明确哪些步骤改变。第一阶段只用已有源留港任务选择，固定后才读目标结果。

**两个有用的出口**：若D50单路在任务和成本上已接近/超过双路，就允许简化；若第二路仍有净收益，再用已有核/先验分解解释它补了什么，而不是为保住双路反向设计理由。F当前仅保留这一已有权重的验证备选，不重新讨论历史输入问题；本轮主资源仍优先给OSS2和港口诊断。

### P3：只在上述证据支持后开发核心模块

优先候选不是“纯因果净化”，而是**任务约束的互补证据保留与一次性支持适配**。它还只是设计方向，不是已经验证的模块名称。

要解决的是：有用的全局类别证据与局部案例证据不能在独立适配中重复计算、又彼此取消；同时不能以强制一致性抹掉第二路的有效差异。

最小可行验证先用固定特征和低容量读出，在源留港episode上比较既有残差流程与联合求解，评价最终融合。先检查联合线性版本是否仅等价于已有拼接核/岭回归；若等价，就作为基线，不包装成新机制。只有出现任务收益且简单接法不能解释时，才加入有限容量的条件关系学习。

这与刚做过的“训练一个支持特征修正器”不同：要改变的首先是全局与局部适配的协同求解，而不是再给相同修正器换一个损失。但它的额外收益尚未证明，因此排在已有可运行证据之后，不马上启动。

## 7. 评价与解释保持闭环

保持三个层级：学到了什么、这些信息是否任务有用、完整系统是否受益。相应保留跨实际港口/跨已知船的检索，固定概率转换下NLL/Brier，固定先验重求支持核的风险差，以及最终OA/BA。

B是可变标注数量。报告U(B)和固定先验的核效用U_K(B)，同时报告支持组成与配对波动；64只是目前工作点。不要把五个draw当五次神经训练，也不把未知身份都当同一艘船。

核心解释图建议固定四类：

1. 输入变化到分支/先验/核/融合的收益传递图。
2. 每类救回与误伤，尤其主要混淆类别之间的交换。
3. 固定查询下的支持预算曲线和支持抽样散布。
4. 真实样本、支持案例及有符号贡献的对应图，包含负例。

不是要求所有港、类和抽样都赢。认可声明范围内可重复、成本合理的净收益；随机波动可以接受，但要由配对重复支持，不能事后把所有负值称为随机。

## 8. 论文贡献怎样组织

目前可形成三条相互衔接的贡献线，而不是先定四个模块再填内容：

- **问题与证据**：中低分辨率SAR跨港细分类中，表示可重建性、案例关系效用和最终识别收益并不等价；不同目标域改变互补证据的使用价值。
- **方法候选**：以任务有用的互补表示及少标签支持适配为核心，解决证据在先验、局部校正和融合间的利用问题。最终选择哪个新增方法，必须等P0-P2结果，当前不能宣布顶刊级机制已完成。
- **评价与解释**：把标注预算、支持组成、核的条件效用和最终净收益联合报告，用逐阶段、逐类别和逐案例归因说明收益及边界。协议设计可成为贡献的一部分，但均值差或Brier本身不是新指标发明。

候选novelty表述：不同于只追求跨域不变性或教师关系逼近，本研究围绕有限标注下的实际适配效用，分析并保留双路中的任务相关互补证据，定位它们在类别先验、支持核与融合决策中的作用，再据此设计适配机制。已有工作提供求解器、适配器和共享/独有信息思想；我们的新增应落在SAR任务证据、支持预算条件和经过完整系统验证的机制上，而非给通用组件换名。

暂缓：纯因果因素命名、没有新收益空间的蒸馏变体、动态频带/样本门控、PCGrad、固定5%预算主张，以及FUSAR和通用跨域大矩阵。不是否定这些方向存在价值，而是当前已有证据不足以让它们优先于上述工作。
