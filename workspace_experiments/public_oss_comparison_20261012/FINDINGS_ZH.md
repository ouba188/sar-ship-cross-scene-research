# 公开集比较：OpenSARShip 1.0 与 2.0

## 结论先行

**OSS1 已完成新实验。它与 OSS2 都显示：第二路中，当前两个 R50 重建器未覆盖的残差具有任务价值。**两者不是完全不同的作用机制；差异更多体现为收益强弱、受益类别、源先验与支持核的相互配合。

本轮还把“同一个模型”拆清楚了：历史结果是同架构／配方、不同任务适配权重；新增严格控制则让两个公开目标共用相同冻结骨干、36,610 行共同源训练集、同一 PCA／尺度、分类头和两个重建器。严格控制下残差作用仍然存在，因而不能只用任务模型不同来解释它。

完成两种模型条件、三个评测队列、每队列五组 64 标签、两种重建器、七臂、两种读出和两种 query 口径，共 1,680 行指标。第三队列是 OSS2 的 GRDH 子集，不是第三个独立数据集；两种模型条件复用相同的 15 组目标支持集。

## 两层模型控制

**task_trained：原任务实例。**复用各自排除目标身份后的既有 jointR18、PCA 和补空间统计；重拟合同配方源先验。OSS2 复用已有 linear/MLP 重建器，OSS1 新拟合相同固定配方。OSS2 的五个旧 expert 分解臂逐样本分类精确回放，连续概率与旧缓存一致到容差。

**shared_frozen：严格共享实例。**共同保留源行是两个排除集后的交集，36,610 行。两边共用 ImageNet R50 与原始 e206 R18，再共用一套源几何、源分类头和 linear/MLP 重建器。这里没有使用任务专属的 layer4 适配，不等同于最新完整双路模型；它的用途是检验换数据集时是否仍有差异。

这里“共享”指冻结骨干、源先验与表示变换完全相同；各目标仍用自己的64标签重解支持适应系数。因此不是声称适应后所有分类器参数也相同。

不能直接把现成 OSS2 joint checkpoint 搬到 OSS1：独立审查确认，其训练源中有 386 行属于 OSS1 应排除集合，且全部参与过训练，其中 365 行进入 query 损失；对应 OSS1 最终目标的 153 行／131 个身份。反向也有 733 行源排除差异。事后只重拟合分类头不能消除这种编码器暴露。本轮没有这样迁移。

## 分解与指标

R 是 R50 核；P 是由原始＋C4 R50 重建的 R18 部署成分；E=T-P 是部署坐标中的残差；PE 将两者作为独立坐标使用；T 为真实双路核。R/P/E/PE/T 固定同一 R50 先验。另有支持 trace 配平的 PE_scaled，以及同时使用双路先验与真实核的 DD。

每臂独立重解同一 64 支持、类平衡 ridge8。固定温度1的 softmax；Brier 为八类平方误差之和。以下风险收益等于对照减候选，正值表示降低风险。

### 严格共享模型：主机制证据

固定先验 expert，原五组 query 口径；表中为类别宏平均 Brier 风险收益。两个重建器完整报告，不择优。

| 队列 | 重建器 | P-R：重建成分 | E-R：残差单独 | PE-P：在重建上追加残差 | T-R：真实核 |
|---|---|---:|---:|---:|---:|
| OSS1 | linear | +0.002854 | +0.010244 | +0.008890 | +0.012314 |
| OSS1 | MLP | +0.003047 | +0.010221 | +0.008414 | +0.012314 |
| OSS2 完整 | linear | +0.002365 | +0.005779 | +0.004979 | +0.007029 |
| OSS2 完整 | MLP | +0.002616 | +0.006363 | +0.005354 | +0.007029 |
| OSS2 GRDH | linear | +0.003759 | +0.008332 | +0.006996 | +0.010005 |
| OSS2 GRDH | MLP | +0.004071 | +0.008234 | +0.006640 | +0.010005 |

以上所有 P-R、E-R、PE-P、T-R 的宏风险收益，在对应五次抽样中均为正。OSS1 与 OSS2 都更支持“当前重建器之外仍有有效关系”，而不是“第二路仅重新利用已重建成分”。这不等于信息论上的新增信息，收益也不能换算成信息百分比。

## 为什么同样结构的模型收益不同

**1. 确认存在类别与支持覆盖差异，且贡献落在不同类别。**OSS1 散货船占60.49%，五组支持每组都缺类；OSS2 类别更分散，支持覆盖更完整。严格共享模型 T-R 的逐类召回变化如下，单位为百分点：

| 类别 | OSS1 | OSS2 完整 | OSS2 GRDH |
|---|---:|---:|---:|
| 散货船 | +12.09891 | +0.52747 | +5.31281 |
| 渔船 | +3.03355 | +5.15745 | +4.47141 |
| 普通货船 | -3.03758 | -2.05878 | -1.80199 |
| 成品油／化学品船 | +1.80858 | +4.82663 | +4.38884 |
| 集装箱船 | +15.52841 | +12.23451 | +19.91687 |
| 原油船 | -1.81818 | -2.15719 | -10.59880 |
| 拖船 | -1.17647 | -1.06667 | +0.00041 |
| 海工补给船 | +2.50000 | +2.30018 | +1.66154 |

这给出实际的收益组成，而不是想象两支分别负责轮廓或散射。BA 消除了类别频率的直接加权，但没有消除支持缺类、同类图像分布和少量稀有类样本的影响。不能把总体正收益说成每一类都受益。

**2. 产品类型会改变比较条件，但不足以解释掉残差价值。**在同为 GRDH 的比较中，OSS2 的 E-R 与 PE-P 仍为正，且与 OSS1 的风险收益更接近。这里同时改变了 OSS2 的 query 队列和支持抽样，不能将全队列到 GRDH 子集的性能变化全部归为 SLC 的纯因果效应。

**3. 历史模型也并非相同参数。**任务专属 R18、源几何和源排除集合不同，原来仅称“同一个模型”不够准确。严格共享控制排除了这部分差异作为唯一解释，但仍保留不同目标数据及支持集。

**4. 可重建性和任务效用不是同一个量。**严格共享模型的 R50 输入源标准化均方量，OSS1为2.449，OSS2为5.617，OSS2 GRDH为5.103；对应源标准化理想参考约为1。这是分布偏移诊断，不是物理距离。两个重建器在完整OSS1/OSS2的目标R2都只有约0.03～0.07，但残差仍有任务价值。偏移大小与残差收益不呈简单单调关系，不能单靠它认定根因。

**因此，目前支持“目标分布、支持组成和训练实例共同影响同一表示的任务效用”，还未唯一识别造成差异的物理因素。**这轮没有继续盲目训练或目标择优组合。

## 系统读出与支持敏感性

为公开集匹配，系统读出统一为 C4-PCA128 源先验＋目标残差的 base，与专家概率各半融合。**它不含历史完整 base 的学习频率、stable 或 incidence 模块，不可直接与前一轮完整系统 BA 排名。**

| 模型条件 | 队列 | R 融合 BA | 固定先验 T 融合 BA | 双路先验 DD 融合 BA |
|---|---|---:|---:|---:|
| task_trained | OSS1 | 31.41267 | 33.23980 | 33.00432 |
| task_trained | OSS2 完整 | 29.55299 | 33.03453 | 34.10959 |
| task_trained | OSS2 GRDH | 35.44783 | 38.84528 | 39.85964 |
| shared_frozen | OSS1 | 31.04861 | 32.87907 | 32.83701 |
| shared_frozen | OSS2 完整 | 29.60005 | 30.93354 | 31.72464 |
| shared_frozen | OSS2 GRDH | 35.23414 | 37.33652 | 37.50495 |

源先验也会改变结论：共享模型下，OSS1 的 T expert BA32.76383，但 DD 为29.90479；OSS2则由30.95806升为31.31549。不能仅凭“真实双路特征有用”保证换上双路先验后也更好。

额外保留跨五抽样共同 query，防止把 query 组成变化误当支持敏感性。共享模型 MLP 的 PE-P 宏风险收益依次为 OSS1 **+0.008964**、OSS2 **+0.005383**、OSS2 GRDH **+0.006361**，均5/5为正。原口径与共同 query 均保留，未挑选更漂亮的一个。

支持 trace 配平也完整保留，不择优。例：共享模型 MLP，T 相对 PE 的宏风险收益在OSS1为+0.000853，OSS2为-0.000941；配平后分别为+0.001360、+0.000168。交互差异不是一个不受尺度影响的固定“信息份额”。

## 身份与证据边界

- 原支持与 query 仅行互斥，OSS1每次仍有21～35条 query 与支持共享已知身份；OSS2为50～64条。不能称为未知船舶／未知场景测试。
- OSS1 与 OSS2 最终队列共有419个身份，涉及532／647行；还存在同次采集的 GRDH／SLC 产品。两个公开集不是完全独立的确认集。
- 共同源行排除了两套既有源排除集合，但不追溯消除 e206 无标签预训练与历史开发暴露。本轮是机制对照，不是首次盲测或完全未见域结论。
- 只检验64标签预算；五个支持抽样不是五次独立神经训练。新 MLP 仅一个固定训练种子，未做超参数扫描。
- 新拟合的是两个源域 MLP和两个线性重建器，以及匹配的源几何／分类头；没有重新训练骨干。OSS1 joint源特征由现成layer3与其自身layer4冻结前向得到。

## 验证与文件

- OSS2旧五臂 expert分类逐样本精确回放，风险指标也与前轮匹配。
