# 局部 Q 与整图残差类别抑制：资格边界和最小修订

日期：2026-11-22。范围为设计与代码只读审查；没有训练、没有修改任何资格字段。依据当前第一阶段设计第 6.2–6.4 节、`two_stage/training.py`、`stage1.py`、`stage1_losses.py` 及本地已提取的 CausalDRL / GDOS 原文。

## 结论

**扩大 Q 数量、平衡 donor 类别、固定输入与填充模式，可以核实局部干预的实施条件，但不足以证明当前 D 所见的整张 Fs 背景已与类别解关联。** 当前 `leakage_controlled=false` 应保留；不能在完成这几项操作后自动置 true。

这不是数据量不足一个问题。当前资格描述强于当前干预生成器能实现的内容：生成器仅替换局部 Q，D 却读取整张有效 Fs。若坚持“背景已解关联”作为启动条件，单靠现有 OBB、更多局部 Q 和更长审计，不能把这一缺口补成已证事实。应把可验证的数据与采样条件，同研究中的解耦假设分开。

## 当前代码究竟控制了什么

把输入写为 `X=(T, B_Q, B_rest)`。`intervene_background` 更换 `B_Q`，原目标及 `B_rest` 保持不变。即使严格设计 `B'_Q ⟂ Y`，也不能推出 `(B'_Q,B_rest) ⟂ Y`。一个直接反例是：原图框外某个未替换区域的亮度与类别相关；替换其他角落之后，这个相关线索仍在。

`ResidualClassDiscriminator` 对六份 Fs 做全有效区域的 4×4 池化，并拼入有效性标记。它可读取：

- Q 外未改动的场景、邻船、岸边或纹理响应；
- 目标保护带及 OBB 中混合的自然背景；
- 与类别相关的 Q 位置、面积、边界、原生尺寸与填充模式；
- 编码器大感受野带入的远处信息。

原有三个 Q 约占各自原生 chip 的 **13.44%、8.18%、10.08%**。这些比例证明干预是局部的，不代表剩余区域都是背景，也不代表这些具体图像必然存在类别混杂。它们只是不能支持“整图背景已解关联”的充分证据。

供体采样也有一个实际陷阱：每类只有一艘时，排除自身会同时排除该类别供体；即使采样代码不读取类别，供体分布仍可能依赖接收类别。“不读标签”与“统计独立”不是同一件事。

## 不依赖训练、现在就能核实的最低操作条件

以下条件适合独立命名并逐项保存证据，不能合并成一个过强的因果有效标记：

| 操作条件 | 核验方式 | 能支持的结论 |
|---|---|---|
| 共同像素坐标 | 联合 TIFF、量化映射和 PNG 逐像素回放 | 两极化本地空间索引一致 |
| 局部可信 Q | 双极化逐图复核、目标/邻船保护、原始像素对应、水域上下文 | 选定局部像素可作为已审背景 |
| 保护与配对 | Q 外及目标保护区逐像素不变；VV/VH 共用 donor 索引 | 配对改变局限于指定背景区域 |
| 训练侧来源隔离 | donor、标准化与原型均来自 train；船/场景边界检查 | 不把验证/测试信息用于拟合 |
| 供体分配平衡 | 分开 recipient 池与 donor 池；每个 recipient 覆盖同一 donor 列表与同一次数 | 在指定采样台账内 donor 来源独立于 recipient 类别 |
| 已知输入模式控制 | 分层或匹配 canvas、极化可用性、填充与固定 Q 模式；完整交叉表 | 审计过的这些变量不因配对方案产生额外类别差异 |
| 四类监督实际覆盖 | 训练时记录真实 scene / paired / controlled 类别数及各参数梯度 | 损失确实接入并更新对应参数 |

最后一项是在合法协议批准后进行的训练验证，不需要预先承诺它一定有效。原生 footprint 与供应方传感器有效 mask 也应分开：可以明确选择“发布 chip 的有限观测支持”作为开发输入约定，但不能称其为恢复了物理有效性标注；这是输入协议的明确假设，不是背景独立证据。

## 三种处理方式及其代价

### A. 保持当前强资格定义

维持 `leakage_controlled=false`，继续做 Q、共同坐标及采样审计。完整四项训练仍不启动。要获得更强数据支持，需要可靠的目标/背景分离、覆盖完整非目标区域的背景替换，或同目标在多背景/观测条件下的受控数据。

即使有精分割，目标内部的观测条件与成像效应也未必独立；因此最终仍需明确“控制的是哪些因素”，不能把一个布尔量写成全部场景因素独立的证明。当前只有 OBB 时，直接整幅合成还可能把框内背景和合成边界作为新的类别线索。

### B. 保持四项损失，把 L_leak 定义为经验类别抑制正则（最小可执行候选）

保留当前 D、交替更新、`KL(π || D(Fs))` 以及其他三项损失，不新增网络模块和损失。明确训练目标是：**抑制当前判别器能从 Fs 读取的类别信息，同时让 Fs 保留可核验的背景统计任务**。不要求在训练前先证明整个背景独立，也不将训练后 D 接近先验当成已识别出纯因果因素。

接口上另用语义明确的 `leakage_regularization_eligible` 或同等实验协议字段，条件限于真实 Q/配对、训练来源、已审采样设计及类别覆盖；原 `leakage_controlled` 不改真。固定 π 来自明确的采样分布，不能由 D 自己拟合。

完整实验仍使用四项损失，但必须称为“经验解耦方案”，并在报告中明确它相对于当前强受控方案的修订。场景统计与类别相关时，`L_scene` 与 `L_leak` 可能存在真实目标冲突；通过验证集的背景回归相对常数基线、独立类别 probe、Fc 分类信息与局部稳定性，以及匹配预算的消融来判断，而不是在开跑前把冲突解释为已消除。

这项修订保留模型与最小损失数量，代价是收缩原来的因果资格主张。**用户刚选择“先补齐监督资格再跑完整三组”，因此不能未经说明把 B 当作已经满足 A 的结果。需明确得到其对方法语义修订的确认。**

### C. 改为条件类别抑制

针对事先声明的 nuisance 条件 Z，用 `D(Fs,Z)` 与固定 `π(Y|Z)`，让 Fs 不额外携带超出 Z 的类别信息。条件可以涉及已知采集/输入因素，但不能任意把本来要保留的船型结构都作为 nuisance 条件。该方案改变判别器输入、先验估计与目标含义，样本稀疏时也会失去可比类别覆盖。

它可作为需要解决明确条件混杂时的后续候选；比 B 改动多，目前不建议为启动第一轮就加上。它同样只能处理已定义的 Z，不能证明剩余未知因素全部消失。

## 文献实际支持的边界

本地 CausalDRL 原文 PDF 第 8 页，式 (19)、(22)，用批内类别分布的平均标签约束 bias 分支预测；同页之后说明真实 SAR 数据含复杂耦合干扰。该训练目标不以“先证明每张真实图像背景类别独立”为前置数据资格。它可为 B 的经验类别抑制目标提供方法参照，但不是当前交替对抗 D、固定先验和三尺度局部监督的原样复现。

本地 GDOS 原文 PDF 第 5 页明确指出没有额外显式解耦监督：语义支路接受检测监督，扰动支路用于扰动生成和一致性学习。它支持通过任务分工学习门控的思路，不能替我们证明整图 Fs 已不含类别信息，也没有提供当前强受控资格的现成数据审核办法。

可复核文本：`literature_review_20261122/causal_drl.md`（PDF page 8）及 `literature_review_20261122/gdos.md`（PDF page 5）。本次未将论文的理论主张当作本数据已经满足的事实。

## 当前执行建议

继续完成数据来源恢复、训练 Q 扩充、确定性 recipient×donor 配对台账、同船/同场景隔离和运行接口。保持所有强受控标记为 false。把 A 与 B 的区别一次讲清楚，请用户批准 B 或继续坚持 A 的更强数据要求；不能用反复填表假装已经消除方法层面的缺口。

一旦方法协议明确，再固定三条比较的训练预算、初始化和验证选模规则，检查四项损失确实激活，最后运行既定的基线→解耦→H 对照。试验的作用是检验设计，而不是把尚未得到的有效性证明变成启动条件。
