# 放宽源任务组织后的32/64支持学习

日期：2026-10-15。用户授权推进上一轮清点出的可用材料。本轮B32覆盖五个旧源池，B64只覆盖同时有fit/selection配对的宁波与青岛。其他B64不扩；旧模型与Jebel B16局部候选保留，不扩公开集。

## 预先固定

1. 保持旧五池各自source_split，不跨池合并，fit/selection/对应target船只与采集仍隔离。
2. 保留far_ok、合法MMSI、同港不同采集、单采集支持；每任务查询固定8条不同船，按源标签分层，至少2类。source query labels用于源监督/采样，不进入推理特征。
3. 不再强制同采集对照、不取same/cross共同容量，不要求支持类别等于查询类别；支持可以缺查询类，也可含查询未出现的类，完整读出仍为八类闭集。
4. 使用所有合法有向query-acquisition/support-acquisition配对。每个查询采集的8条query在五次draw及所有support配对中固定；支持按自身类别容量的均衡顺序抽取32/64条不同船，保留嵌套前缀，排除query MMSI。不会复制一条船凑数。
5. B32预期fit/selection候选配对Jebel30/2、Ningbo17/6、Qingdao14/2、Shanghai33/4、Singapore15/6；B64宁波3/2、青岛3/2。实际有效监督仍需预测后统计，不用配对数冒充独立事件。
6. 每pool/budget独立拟合原18特征逻辑回归C=.1和二层树，阈值.5、叶节点约束不变；标准化仅fit，原BA分层权重不变。若缺少救回/误伤某一类，不训练二类选择器，报告NA与body回退。
7. 在对应源selection上只从body/logistic/tree选BA最优，平局body；所有选择落盘后才读取冻结目标缓存。目标任务、支持、模型端点和指标保持原样，因此没有通过放松测试变容易来获得涨点。

## 比较与诊断

- 在对应相同目标任务上比较新固定逻辑回归/树/源选策略、原B16训练方案、严格匹配已有方案；已有方案缺模型处标NA。
- 对照body、固定mix、half、同任务同切换数量随机期望。
- 报告OA/BA/NLL/Brier、逐港/采集/draw，以及source fit/selection事件排序和BA加权AUC；救回/误伤按船、采集及事件区分。
- 报告query类在support中缺失比例、实际源任务类别覆盖、唯一support集合数量。多配对和多draw不能作为独立船增量。
- 训练前后各条规则与split检查、新任务query标签扰动不影响输入、旧目标端点重放、风险权重归一化；不重复旧已通过的全量骨干审计。

这是源任务组织的放宽与预算匹配，不是对所有场景生成条件的完全匹配。不预设能涨点；若不生效先定位数据/学习/选择作用位置，不继续按目标表现调阈值。

## 有界纠错：只增加合法源查询覆盖

第一阶段已完成。源端B64宁波fit为0救回/5误伤、青岛1救回/0误伤，均缺一类监督；此时未读取新目标效果来选方案。确认每个任务固定8query仅用了对应采集的一小部分船，因此追加一次预先定义的coverage-only对照，不改参数或门控。

新阶段保存到query_coverage/：逐任务保持原支持ID及顺序、预算、采集配对、draw完全不变，只将query扩展为该split/同query采集所有far_ok且合法MMSI的不同船；排除该任务所有support MMSI，原8query必须仍在扩展集中。使用全部符合元数据规则的查询，不按预测是否出错筛选。fit/selection都相同处理，仍不相互借船。

比较源事件数量和不同船覆盖，以及对应目标模型效用。扩展后source class/任务权重按原规则重新计算；它检验固定8query的覆盖瓶颈，不宣称纯粹隔离了样本数量而完全不改变数据组成。第一阶段原始结果不覆盖，不改变目标支持或测试队列。
