# 下一步实验：分别保留船体与环带，检验条件化利用是否值得

日期：2026-10-15。原始状态：仅完成设计。执行更新：本方案已于同日完成30次小模块训练及六个冻结目标任务评价，见 `body_context/FINDINGS_ZH.md`。以下保留实验前的设计，不以事后结果改写假设。

## 1. 先说明为什么做

本轮不是预设“背景是噪声”，也不是预设“背景能校正散射”。要回答的是：

> 在保留船体及环带各自表示的情况下，环带能否帮助模型更有效地使用船体证据，并将收益兑现到完整分类流程？

现有证据来自 `LOCAL_CONTRAST_FINDINGS_ZH.md`，六个留出采集任务、642个查询、B16、五次配对支持抽样。完整 learned-class 模型的跨采集等折平均如下：

| 已完成方法 | OA (%) | BA (%) | 可以说明什么 |
| --- | ---: | ---: | --- |
| 原完整模型 | 52.392 | 46.378 | 比较起点 |
| 加入原始环带统计 | 52.516 | 46.569 | 环带表示有低成本、有限的完整模型收益 |
| 加入 stem 环带均值 | 52.654 | 46.554 | 浅层环带也存在候选信号 |
| 加入原始船体减环带统计 | 52.451 | 46.256 | 检索改善不自动转化为总体分类改善 |

原始差分的跨采集检索 MAP@R 为0.3673/0.3264（micro/macro），高于末层GAP的0.3413/0.3100；但总体完整模型BA下降。青岛有局部正收益，应保留，不能因总体混合结果抹去，也不能据此认定减法具有物理校正意义。

环带与样本的真实对应关系相对同采集内置乱有正信号，但尚未区分“环带本身提供类别相关线索”与“环带帮助解读船体”。下一轮只区分这两件事，不继续堆叠无关组件。

## 2. 两类信息各自做什么

- 船体表示 s：现有R18 stem框内逐通道峰值，经源端PCA及归一化得到64维。它保留框内局部强响应，不声称是纯船体结构；框内可能含水面，感受野也存在边界影响。
- 环带表示 b：首轮采用现有VV/VH环带均值、标准差四维统计，经源端变换及归一化。选择它是因为已有完整模型弱正信号且参数少，不是断言浅层环带无用。
- 两者均来自SAR chip和既有框信息。预测时不增加AIS、港口类别频率或外部环境标签。
- 环带不是经过验证的纯海水区域；可能包含尾迹、岸线或邻船。uint8裁片统计是处理后相对亮度，不等于定标后后向散射强度。
- 既有骨干本就看整张chip。本轮改变的是信息的显式读出与支持关系，不是第一次把背景提供给模型。
- “保留两类信息”是保留所提取的s和b，不是无损保存原图全部物理信息。

工作假设：某些船体响应的判别价值可能随其局部成像环境变化。若成立，按b调整s的部分坐标，比所有样本使用同一套坐标权重更有用。若不成立，直接保留s、b或固定加权可能已经足够。

## 3. 最小设计与数学含义

记N为逐样本L2归一化。s、b使用各自固定的源端变换，不为候选单独重新选PCA。

### A. 直接保留，先测加性证据

```
phi_add = [sqrt(0.5) * s, sqrt(0.5) * b]
K_add(i,j) = 0.5 * <s_i,s_j> + 0.5 * <b_i,b_j>
```

这个基线完整保留两组所提取的坐标，但点积核仅为两种相似度相加，不能把它称为条件交互。

### B. 环带驱动的小幅坐标重加权

```
g(b) = 1 + 0.25 * tanh(W b + c)
u = N(s * g(b))
phi_cond = [sqrt(0.25) * s, sqrt(0.5) * b, sqrt(0.25) * u]
```

W为64x4，c为64，总计320个可学习参数。逐坐标乘法作用在源端PCA坐标上，不将坐标命名为某个物理因素。g在0.75至1.25之间；归一化后只改变相对方向，统一缩放不会产生收益。原始s、b均保留，模块不能直接把原有船体分支删除。

W、c初始化为0时，u=s，条件核严格退化为加性核。因而直接融合是可恢复的起点，而不是额外强加一个完全不同的表示。

条件核中的船体项为 `<N(s_i*g(b_i)), N(s_j*g(b_j))>`：它允许各自的环带改变船体坐标的权重，但不预设“背景相似就是同类”，也不实施船体减背景。

### C. 固定加权对照

固定W=0，只学习c，其他结构与训练相同。它检验收益是否只需全体样本共用的船体坐标重加权，不需要输入相关调节。

这是借鉴FiLM条件调制思想的受限实现，不把乘法或FiLM本身作为首创。当前贡献假设在于：保留体内/体外独立证据，在原有支持残差求解中检验局部环境条件下的案例关系。成立与否由实验决定。

参考方向：Perez et al., FiLM: Visual Reasoning with a General Conditioning Layer, AAAI 2018。本方案仅借鉴条件输入驱动特征调制的思想；本轮网页工具未返回可用正文，不把本次检索记为完成精读，也不作新颖性定论。该方向的既有结果不能代替本SAR方案的验证。

## 4. 接到哪里，不改哪里

```
SAR chip
  ├─ 原C4第一路 → 原支持适配 → 第一组分数
  └─ 原G50 + 源域SSL R18 → 原第二路特征/先验
          └─ R18浅层框内s + 环带b
                → 加性 / 固定加权 / 条件加权
                → 替换原D18支持核的25%
                → 原类别关系核
                → 重新求解支持残差系数
                → 第二组分数
两组分数分别softmax → 原50%/50%全量融合
```

按现有实现使用 `K_new = K_original + 0.25 * (16*K_local - K_D18)`，其余核及常数项保持原约定。K_SS和K_QS都由同一显式phi生成，不能只改查询相似度而沿用旧支持系数。类别关系混合比例、ridge系数、温度和最终融合权重不同时搜索。

本轮改变的是第二路如何将支持标签的残差传给查询，不声称重训出跨场景不变骨干。

## 5. 数据使用与不泄漏的学习方案

沿用六个已归档目标任务：Jebel Ali、Ningbo-Zhoushan、Qingdao、Shanghai、Singapore两次采集。对应五个源模型池。目标查询、B16同/跨采集支持ID及五次抽样保持原样。现有目标结果已用于研发，所以仍称探索性验证，不称首次独立确认。

已核对的源验证池规模：

| 源模型对应留出港 | 验证chip | 独立MMSI | 采集数 |
| --- | ---: | ---: | ---: |
| Jebel Ali | 1840 | 1720 | 60 |
| Ningbo-Zhoushan | 2263 | 2109 | 69 |
| Qingdao | 2440 | 2182 | 68 |
| Shanghai | 2090 | 1898 | 72 |
| Singapore | 1830 | 1706 | 62 |

源训练集约2.1万至2.6万chip，但当前局部特征仅缓存980至1040张训练gallery；不能把未缓存行的零向量当有效数据。源验证池局部特征已有完整缓存，且与源训练无MMSI交集。

本轮选择一个清楚且成本有限的方案：

1. 底座拟合池A：仅原source_train。源先验、PCA、类别参照及其可学习权重均从A得到；需要选择的底座参数沿用既有源内过程，不使用下面的B/C。局部PCA沿用A中的已缓存gallery。确认A与B/C无采集重叠；若有，只从A剔除重叠采集，再共同重建所有对照的底座。
2. 将原source_validation按采集、固定种子划为约70%的模块学习池B与30%的选择池C。跨两池的同MMSI只留在C，从B去除；不把同船观测分开泄漏。只依据ID、类别覆盖和数量完成拆分，不看方法优劣。记录实际余量，尤其稀有类，不强制每个采集都有八类。
3. B内构造支持/查询任务，二者MMSI不交叠。同采集与跨采集任务各半，B16、至多32个查询；候选不足时记录实际查询数，不复制样本凑数。训练和选择任务清单先固定，各方法复用。
4. C仅选择固定加权/条件加权的训练检查点，不训练参数、不更新归一化/PCA。选择以跨采集等任务BA为主，同分取更早检查点；同采集与OA另行报告，不以“同采集也涨”否决。
5. 外部六任务仅在方案冻结后评价；已授权的目标支持标签只进入原支持求解，目标查询标签不选择W、c、倍率或检查点。

重要比较口径：**本轮所有新旧结构对照都在A-only共同底座上重跑**，包括无局部补充、船体、环带和加性基线。历史train+val底座原分数另列，不与新分数直接相减声称模块收益。

本轮先不把B/C重新并入底座。这样避免小模块训练时使用A-only先验，部署却换成A+B+C先验造成接口变化。若候选值得保留，再单列全源重拟合的部署实验，届时所有对照共同重拟合，不把两种协议混报。

## 6. 小规模训练与必要对照

冻结全部骨干。只学习固定加权c或条件W、c，损失通过原支持ridge求解、类别关系核和最终概率融合反向传播。

采用每任务对实际出现类别求平均的NLL：类内先平均、再类间平均。不是只拟合关系MSE或只追求同船距离缩小。支持数不足/缺类按原任务自然保留，不在训练时偷偷补全八类。

预设初始配置：Adam，lr=0.001，weight_decay=0.0001，600次更新，每次4个任务；仅检查0/200/400/600步，不做大网格。固定与条件两者用相同任务次序、训练预算、选择机会。首个种子用于可行性；候选在源C有信号后，保留比较双方并补齐三个真实训练种子，再做目标评价。无训练方法不伪造“训练种子”。

| 方法 | 本轮作用 |
| --- | --- |
| 无新局部项 | 判断完整系统净收益 |
| 仅船体 / 仅环带 | 判断联合是否超出单独信息；共同底座重跑 |
| s+b加性核 | 判断只是增加一种证据是否足够 |
| 固定加权 | 判断是否只是静态度量更好 |
| 环带条件加权 | 检验逐样本条件交互 |
| 条件输入置乱 | 检验训练好后是否依赖正确的体内/体外配对 |

原始船体减环带保留历史结果，不强行把64维s减4维b，也不再将差分当成默认主方案。

置乱仅作用于g的输入b，显式b分支和s均不变。分别在支持池/查询池的同采集内打乱，以免把查询集合变成支持模型的额外输入；同一样本在所有核块中使用一致的phi。三个置乱种子，记录无法置乱的单例。它检验匹配依赖，不单凭下降认定物理因果；如果要进一步区分有意义条件与额外非线性容量，再有针对性地增加同容量“训练时随机配对”对照，不默认展开。

## 7. 怎样判断学到了什么、是否有用

首先看机制：条件法相对固定法/加性法是否改变正确类支持的相对排序，以及这种变化是否在打乱条件输入后消失。记录门控坐标的实际变化、支持类相似度、支持残差贡献和正确类margin；权重图只能辅助说明，不能独立证明有效。

其次看任务收益：同一查询/支持抽样下报告完整模型OA、实际出现类别BA、NLL/Brier，以及检索MAP@R；概率转换保持不变。按采集、类别、支持缺类/覆盖情况报告成对差值、救回/误伤与独立船数。检索改善、概率改善、top-1改善是不同结论。

主表使用等目标任务平均；另列query加权结果，避免把多数类收益藏掉或反过来冒充类间均衡收益。五次支持抽样衡量支持敏感性，三个训练种子衡量训练变化，不合并为独立船数。六任务只有五个港口且共享部分训练数据，不能用30个任务×抽样值当独立跨港证据。

解释图只做两张：固定查询的“原关系/加性/条件关系”支持案例排序图；典型救回与误伤的chip、框/环带、门控与分数变化图。案例按预先规则选取，不只展示成功样本。

记录模块训练时间、额外读出延迟与特征缓存开销。冻结骨干不等于零成本，框/环带读取也计入。预测不增加第二次骨干前向。

## 8. 分阶段推进与结果如何改变下一步

第一阶段：冻结拆分，构造共同底座并跑无局部/单项/加性。它检验低成本独立证据是否足够。加性不涨不能单独否定交互，因此仍允许下一阶段的有限源端小试。

第二阶段：源B学习固定/条件两种小模型，源C选择并做条件输入置乱。若有可利用的净收益迹象，补齐三个种子及六目标任务；若只在特定类别/条件有收益，保留其明确范围，不要求每折全胜。源端无信号时先查看门控是否移动、损失/实现与接口是否正确，最多做一次有依据的小修正，不直接扩大数据集或继续堆模块。

第三阶段：目标配对评价与解释。结论按证据分支处理：

- 加性足够、条件无额外收益：保留独立证据融合，不包装动态机制。
- 固定加权有效、条件未超出：保留源端静态度量，说明不需要逐样本变化。
- 条件法有可重复净收益，且真实对应优于条件置乱：支持“环带条件帮助利用船体证据”；仍不等于找到纯因果因素。
- 只有检索改善：保留表征结果，检查是否救回对象本来已正确、支持系数是否抵消、最后融合是否稀释，不直接宣称完整模型涨点。
- 只有特定采集/多数类收益：作为边界内有效候选记录，报告其他类别代价；不能据此一票否决，也不能事后改称预设独立验证。
- 没有可重复净收益：保留现有环带弱正结果，不强推条件模块。优先判别是浅层船体读出不足、环带条件弱、学习不充分还是假设不成立，再决定是否值得下一次有区别的实验。

本轮不扩展F_0921、OSS1/OSS2，不重新训练骨干，不恢复5%交接，不搜索所有层/环带宽度/倍率。先用现有六任务把“增加证据”与“条件化使用证据”的区别做清楚；获得有价值信号后再讨论更广适用范围。
