# 类别对比关系模块：预算与采集覆盖验证

日期：2026-10-14。侧边实验已完成；未修改主线模型、论文、既有结果或长期记忆。

## 结论

**可以保留，而且现在有比最早五景更可靠的适用范围证据。** 最明确的是F_0921的64例跨采集支持适配：扩到105景后，相对固定类别参照，完整融合输出OA +0.713、BA +0.603个百分点；相对等权类别对比BA +0.552；相对等容量自由度量BA +0.393。后三项比较的五次支持抽样平均均为正，三个冻结训练种子的平均收益也均为正。

OSS2的64例也支持保留，但不能声称算子独有优势。原来OSS2低预算五景的正信号，在17景上没有形成可靠的top-1净收益。三港16/32例有可重复的BA改善；64例相对等权类别对比的新增学习收益很小。

这是对已定义任务的有效性判断，不要求每景、每类都赢；也不是在不同数据集上按测试结果挑选赢家、拼出新部署策略。

## 本轮冻结了什么

- 直接复用上一轮的三个类别对比学习模型、三个同容量自由度量模型。没有新增训练、目标梯度、检查点选择或强度调参。
- 源特征坐标、类别参照、源先验与源归一化均固定在已有validation_fit版本。关系学习与所有预测采用同一坐标，没有部署时重新拟合。
- 保持原特征核占0.75、关系核占0.25、支持残差ridge=8、基础/专家概率各占0.5。
- 对比原核、固定非线性类别参照、等权线性类别对比、学习类别对比、同类别信息的自由度量。
- 报告三个训练种子的结果平均，不是三模型集成。部署一次仅使用一个冻结模型。

类别对比学习只改变“用什么关系衡量支持案例是否相关”。它给28个源类别对比坐标学习非负权重，再通过实际支持残差求解与概率融合优化源任务风险。并未引入新的影像信息，也不是每张影像动态生成注意力。

F和OSS2纳入原元数据容量表中所有满足64例支持容量且保留至少两类支持的采集场景。不是看到模型表现后选景。三港为Jebel Ali、Port Klang和Singapore，不是整个23港结果。

每景三个预算16/32/64，五次支持抽样，同采集/异采集两种支持条件，共5100组支持条件、45900次专家求解。各比较使用相同查询和支持样本。每个任务查询船与支持船互斥，源拟合与目标已知船只/采集隔离。支持船每组不重复。

原16/64支持集原样保留，两者不是嵌套抽样；新增32例从对应64例中按配比分层抽取。F和三港的两种支持条件匹配类别数，OSS2额外匹配GRDH/SLC产品类型。**这是使用已有标签构造配比的诊断实验，预算是分类器使用标签数，不是完全盲选获取这些标签的总标注成本。** 所有预算均在同一批64例可行场景评价，结论不覆盖更稀疏的小场景。

模型仍为八输出闭集；单景不一定八类齐全，BA按查询实际存在类别计算。先逐场景计分，再同港平均、最后港口等权；外部数据按场景等权，不假定其实际港口已知。不同采集的重复船只不作为独立船只累加。

F64的收益不能只归于换了类别坐标，学习权重也有增量。三港64恰好相反：相对固定非线性参照的改善，大部分由等权线性对比已实现。

OSS2的64例相对自由度量OA -0.030、BA +0.101，BA去掉最好一次支持抽样后为-0.041。因此这里能说超过固定关系，不应说非负成对约束明显优于普通度量。相对无参照原核，OSS2 64的OA -0.092、BA +0.585，仍有指标取舍。F64相对无参照原核OA/BA均正，为+0.837/+0.914。

最后一列保持原任务权重，仅扣除最有利三艘船的净贡献，是集中度敏感性分析，不是重新划分训练/测试或重新标注。五次支持抽样与三个训练种子不能拼成15个独立采集实验，也不能用种子间很小的方差代替支持抽样不确定性。本轮不作统计显著性宣称。

- F64：105景中71景BA正、30景负、4景持平；按任务权重汇总后211艘船净贡献为正、111艘为负。不是由一两艘船撑起来。
- OSS2 64：17景中11景正、6景负；52艘船净正、32艘净负。
- 三港32：48景中29景正、17景负、2景持平；三港平均BA均正，Jebel Ali +0.825、Port Klang +0.184、Singapore +0.406。
- 三港64仍有Port Klang BA -0.132；该反例被保留，不否定其他有效范围。

### 原五景是否有代表性

- F64新增100景BA +0.601，与原五景+0.643同向；有效性不依赖原五景。
- F16原五景-1.233，新100景+0.178，全105景+0.111。原五景负结果不能代表全覆盖，但扩大后的收益仍偏小、波动较大。
- OSS2 16原五景+0.576，新12景-0.183，全17景+0.041。此前低预算正信号不能扩展成普遍优势。
- OSS2 64新增12景+0.754，与原五景+0.229同向。

## 数据层面的原因与边界

八类ID依次为散货船、渔船、杂货船、成品油/化学品船、集装箱船、原油轮、拖轮/拖带船、海工补给船。

- F64相对固定参照的BA净增量+0.603中，原油轮贡献+0.456，集装箱船+0.168；散货船-0.186、渔船-0.032抵消一部分。原油轮的决策变化涉及85艘船、59景，不能说仅靠一个稀有样本，但收益确实偏向某些类别。
- OSS2 64的主要正贡献来自集装箱船+0.554，涉及31艘船、11景；散货船贡献-0.260。这是明确的类别取舍，不是每一类都改善。
- F64相对自由度量的优势分布于成品油/化学品船+0.202、集装箱船+0.138、原油轮+0.131等，散货船-0.178。扩展后，并非仍仅由最早少数集装箱船决定算子对照。
- 三港64相对等权类别对比仅+0.028，不能把固定关系本身的收益都归给新增学习。
- 同采集也可能获益。F同采集64例BA +1.088，比其跨采集+0.603还大；OSS2同采集64例BA +0.085、OA -0.298。由此不能宣称本模块专门消除了跨采集漂移。
- 宏Brier在跨采集九个数据/预算条件下平均都改善，但OSS2 32的OA/BA退化。概率风险优化与top-1决策仍有差别，不把中间风险下降自动等同于识别率提高。

目前可以解释到：类别关系重加权改变了哪些样本和船型的支持修正，并通过匹配替换证明在特定范围有净收益。尚未唯一识别为何某个物理观测条件决定类别取舍；本轮没有新增物理因果证明，也没有因此继续堆模块。

## 成本

在缓存特征上，计入关系映射摊销、共同基础分支、核构造及支持求解，异采集64例任务的中位成本：

| 数据 | 固定类别参照 | 学习类别对比 | 配对额外时间中位数 |
|---|---:|---:|---:|
| F_0921 | 1.835 ms | 2.204 ms | +0.361 ms |
| OSS2 | 1.808 ms | 2.030 ms | +0.202 ms |
| 三港 | 2.198 ms | 2.530 ms | +0.311 ms |

这不是端到端图像推理、数据读取、标注或源训练成本；映射在批处理上计时后按任务行数摊销，不能当作单图在线延迟。原有学习仅28个标量，本轮复用已有权重；没有新增骨干或源分类器。完整预测程序约81秒，不含首次登记与分析时间。

因此，在已有特征管线下，相对于约0.2至0.4ms的额外缓存适配时间，F64的净收益值得保留。仍需在最终选定主模型版本上报告完整训练/推理成本，不能把本表称为整系统提速或零成本。

## 验证与下一步

- 源/目标身份与采集隔离、同/异采集支持角色、支持独立船只数和配比通过逐任务检查。
- 原440组支持任务的九个对照版本，最终分类决策全部复现一致。扩大编码批次后，浮点概率最大差2.42e-7；旧编码过程有float32分数转换。初次采用双精度级阈值时检查中止，随后按单精度概率容差加“最终决策必须完全相同”重跑，保留这一记录，不称概率逐元素完全相等。
- OA与BA各192项聚合增量均由逐船决策变化重新构成，误差低于6e-15，避免把重复暴露或类别不均衡当成增益。
- 已有求解器未修改；本轮不重复上一轮独立KRR/梯度测试。

建议：保留冻结的类别对比关系模块，以“跨采集、适量目标支持下的低成本关系改进”为核心证据，F64为较强证据，OSS2 64和三港16/32作范围补充。不要围绕本轮测试结果再加选择器、调幅度或按数据集挑模型。后续真正需要补的是与最终主模型版本的同协议接入比较，而不是再证明它处处获胜。

这是旧语料上的覆盖扩展，并非新独立数据确认；历史预训练与开发暴露不变。没有修改或自动推广主模型。
