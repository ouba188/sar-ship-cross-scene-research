# 类别参照度量学习：小规模收益验证

日期：2026-10-14。范围仅为自建源语料中的三港轮流留出验证，不改旧主模型，不开展外部数据集实验。

## 问题与候选

固定类别参照能够改善部分支持关系，但检索关系改善不保证最终分类改善。本轮验证：在保留完整视觉核的前提下，直接通过实际支持残差求解与最终融合训练参照关系，是否比固定关系和普通同类关系学习更有用。

候选为 K=.75 K_visual+.25 R(q) M R(s)^T，M=L L^T，再按源参照协方差约束平均核能量，使 tr(M C)=tr(C)。只训练8×8因子；参照中心、2752维视觉坐标、源先验、ridge=8、两路概率融合=.5全部冻结。不同训练种子的初始矩阵均为单位阵，变化来自任务抽样顺序，不是不同骨干训练。

## 对照与训练

- 原视觉核、固定类别参照、固定普通聚类参照。
- 类别参照与普通聚类参照分别进行两种训练：监督多正例余弦对比目标；经过类别平衡ridge重求解和最终概率融合后的宏平均NLL。
- 聚类对照预先采用已有三个初始化中的第一个，没有根据本轮表现选择。它仅是小验证，不代替多聚类初始化确认。
- 三个训练种子，各240步Adam、学习率.01；.01倍度量偏离单位阵的均方正则。每步从两个训练港各抽一个任务。最终固定240步，不按留出结果挑检查点。
- NLL是可微训练目标，不替代OA/BA、净救回及成本评价。对比目标不能使用支持中没有同类的查询；该条件单独报告，所有模型最终评价仍包含它们。

## 数据组织

复用源拟合已排除Jebel Ali、Port Klang、Singapore的公共模型：10,633条源观测、6,047艘源船构造参照。轮流用其中两个港训练小度量，第三港评价。

每个轮次额外从训练侧排除留出港全部已知船只与采集。训练查询沿用旧场景查询，过滤重叠船；所有训练查询船整体从训练支持池排除。评价不重抽，保留48个旧场景、每场景5次支持、同/异采集两种条件，共480个支持单元。

初版训练支持从另一采集随机抽64艘，每场景3次；评价支持沿用旧的类别配额。训练与评价的场景、船只、类别和支持构成都保存。统计以港内等场景、最后等港为主；3个训练种子和5次评价支持抽样分别统计，不当成15次独立训练，更不将重复查询曝光数当成独立船数。

## 唯一事后抽样对照

初版完成后，数据诊断发现自然比例训练支持与类别配额评价支持确有组成差异。例如留出Jebel Ali时，训练支持中成品/化学品船平均14.35例，评价约29.71例。这个差异尚不能直接认定为性能变化的根因。

`matched_training/`只改训练支持构造：按各个**训练场景自身**已有64例类别配额抽样。船只隔离后，全部96个轮次内训练场景均有足够容量，不需删场景或放宽配额。查询、学习率、步数、种子、模型及评价支持不变。该对照不是按留出结果挑超参数，不将其结果当作新的独立确认；不再追加抽样或参数搜索。

## 必要检查与解释

- 固定候选复现1440个旧概率数组，确认核/先验/融合未漂移。
- 与独立sklearn加权KernelRidge比较；方向有限差分检查实际反向传播。
- 训练与留出港船只、采集隔离；实际支持64艘及场景关系校验。
- 每类救回/损害还原宏BA，区别自己固定参照基线与原视觉核基线。
- 事后用标签计算训练/留出风险梯度及最终度量方向的局部风险导数，定位迁移和步幅问题。它仅用于解释，不能部署，也不冒充物理因果因素。

最初一次启动在训练前被采集编码断言阻断：新读取器误用了竖线分隔，旧任务使用下划线。统一为旧协议后才产生本轮训练结果；没有把该启动错误记为模型负结果。
