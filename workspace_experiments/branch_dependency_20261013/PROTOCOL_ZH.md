# 查询表征与支持适配的分离

2026-10-13。用户要求追到判别依据, 而不是只分解最终救回/误伤。

本轮先区分两个竞争解释: 几何处理主要改善查询表征, 还是通过改变支持集及重算分类规则才产生收益。已有研究同时处理两者, 不能区分。这里不预设任一解释成立。

固定既有源模型 fold2/3、全部 OSS2 原查询和五组 B64 支持、R/T 两臂、expert 读出。三种缓存输入为原图、正确轴几何、等面积错轴。支持输入与查询输入交叉为九格。仅新算下游系数和预测, 不训练编码器、重建器或源模型, 不选择新参数。支持的标签不变; 查询标签只用于完成预测后的解释。

原图/原图及两种对角处理逐一回放既有概率和预测。如果回放失败, 暂停解释并定位接口差异。保留完整、SLC、GRDH、同船同时间配对 SLC, 不以最有利子集替代全任务。错轴控制不消除所有插值/形状混杂。

支持单独变化包括支持表征、支持先验残差、核矩阵及求解系数的联合改变; 查询单独变化包括查询先验与查询-支持相似度。该分离首先定位计算路径, 不是物理语义根因的最终证明。支持/查询不同预处理的非对角格是机制诊断, 不是推荐部署方案。十个上下文不是独立训练种子。
