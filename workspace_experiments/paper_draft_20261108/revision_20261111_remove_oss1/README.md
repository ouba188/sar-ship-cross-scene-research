# Two-dataset manuscript revision

This is a scoped revision snapshot, not a standalone training or publishing package.
`source_snapshot/` contains the current controlling manuscript and the edited files
from the local `paper_draft_20261108/` workspace. Earlier root-level manuscript files
are retained as history rather than overwritten with unrelated prior revisions.

The local rendered deliverable is `manuscript_ieee_20261111_two_datasets.pdf`:
16 pages, 23 tables and 18 numbered equations. Figures, original datasets, model
weights, PDFs and pre-edit backups are not duplicated in this archive.
The existing shared figure assets and local pre-edit backup are required to rebuild
or rerun `verify.py` in the original manuscript workspace. The JSON files record
the completed local build and visual checks, not a claim of a fresh remote build.

OSS1 experiments are excluded from this manuscript. Historical experiments and
literature citations remain available. R50-Tuned is a no-module strong baseline;
no formal M1-M3 model or checkpoint was replaced in this revision.
