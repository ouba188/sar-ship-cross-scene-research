# 三数据集论文结果与救回图册

- `PAPER_RESULTS_ZH.md`：可用于论文的正向/负向结果、消融及正文段落。
- `index.html`：本地完整模型救回图库，OSS1 2例、OSS2 6例、24港2例。
- `RESCUE_CASEBOOK.pdf`：10页图册；`panels/`包含逐例PNG/PDF。
- `CASE_GUIDE_ZH.md`：人工原图观察、建议正文6例、图注和结论范围。
- `case_records.json`：精确输入来源、实际参考与每例分数，仅保留本地。
- `case_index.csv`：本地图件索引。
- `paired_outcomes.csv`：全部评价样本的救回/误伤统计，不是图册的抽样比例。
- `build_evidence.py`：从已有预测或案例归档生成图册，无训练/推理/调参。

模型、正式论文正文及既有实验文件均未修改。图像保持原有显示数值和native160裁剪/补零，不使用生成图代替真实SAR。

三个数据集的主表均采用最终存活算子的共同ImageNet起点与既定五阶段训练。Plain为普通骨干匹配训练，SE为两个匹配block的通道注意力对照；不能写成完整SE-ResNet或先进方法复现。论文正文使用CRFB/RGRP/RCEW时，对应M1/M2/M3。

OSS1/24港全量逐样本预测缓存的原C盘目录目前不可用；本册明确区分已归档单种子案例与OSS2三种子逐例复核。总体统计来自已完成的E盘归档表，未重新运行训练。Git只归档代码、聚合表和分析文档，不上传原图、图册或逐样本元数据。
