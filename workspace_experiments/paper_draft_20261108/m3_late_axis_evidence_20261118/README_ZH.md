# M3正反轴向证据延后融合

2026-11-18。实现候选、机制检查和2条真实chip前后向已完成；优化器更新0步，正式模型、论文结果和历史检查点不变。

## 借鉴与范围

参考Puny等，Frame Averaging for Invariant and Equivariant Network Design，ICLR 2022。核查原文第1–3页式(1)–(3)、Definition 1及Theorem 1：在等价坐标框架分别计算函数，再聚合输出。原文 https://arxiv.org/pdf/2110.03336 ，官方实现 https://github.com/omri1348/Frame-Averaging 。

本实现仅借鉴“保留等价框架至比较完成”的思想；不是复现其全部网络，也不直接套用论文定理为SAR分类增益作保证。只处理OBB轴正负标记的歧义，不识别真实船首，不保证真实雷达视角变化下响应不变。内容权重会随假设交换而交换，独立查询/参考重标记由代码测试核查。

## 实际接入

沿用m3_content_scale_20261118的原生layer1(40x40)、M1后layer2(20x20)、8粗父槽/20细子槽、完整逐对T以及layer3末端回写。M1/M2/PCEA、骨干参数共享、极化分开处理、其他类别uniform上下文均不变。不增加参数、不增加骨干前向，不恢复显式频域分支。

旧版在正反匹配混合后形成参考值、再形成类别原型，最后比较距离。新版在每个查询/参考/极化/槽位上，先计算两种方向的距离，再融合到类别证据。实际write_message只使用中心化类别证据；保留的prototype字段是诊断字段，不再用其均值计算新版距离。

令h为正反假设，T为完整逐对匹配，m_rhi=sum_j T_rhij，v_rhi=sum_j T_rhij v_rj / m_rhi。

- 保留原方向权重pi_rh，在三个区域间共享；它不是已确认的船首概率。
- 槽位有效权重alpha_rhi=pi_rh*m_rhi/sum_g(pi_rg*m_rgi)。Sinkhorn去掉dustbin后，不同假设的有效行质量可能不同，不能忽略这一项。
- 先计算d_rhi=sum_k w_c(r),k*(q_ik-v_rhik)^2。
- 每个参考先得到d_ri=sum_h alpha_rhi*d_rhi，再按原类内参考权重beta_rci求D_ci=sum_r beta_rci*d_ri。
- E_ci=-D_ci/0.1；按可用类别中心化，然后用原覆盖图回写，送入layer4及原分类头。

每艘参考的假设编号是独立的；禁止先把不同参考的h=0合成一个全类原型。否则只反转一艘参考的轴就可能改变结果。无可用极化、区域或参考时仍为空证据。

## 必须保留的四组对照

| comparison / weighting | 含义 |
| --- | --- |
| prototype / content | 原有完整逐对匹配、早融合类别原型距离，默认旧代码完全保持 |
| pair_mean / content | 每个参考内部先混合正反值再求距离，之后类内聚合距离 |
| late / content | 每个参考每个方向先求距离，再按内容与有效质量融合，本候选默认 |
| late / equal | 两个方向的先验pi均为1/2，其后仍按有效行质量归一化 |

重要：新版不仅推迟方向融合，也把类别原型距离改成了类内平均参考距离。因此late与prototype的全部差异不能都归于首尾处理。pair_mean是必需中间对照，late与pair_mean才隔离方向融合先后。equal不是无视有效质量对两项强制各半。

## 已完成检查

- 独立构造：查询0、两个参考值-1/+1。早融合距离0，先比较再融合距离1，消除该例的均值抵消。
- 原版控制回写重放误差0；之前内容尺度算子检查也重新通过。
- 分别只反转一个查询、或一艘参考的轴向槽位，内容/等权两种版本回写误差均约1e-16。保留细/粗身份及实际覆盖置换，不把整幅SAR旋转当成同一验证。
- 缺极化、局部空槽、全非法参考保持有限且零证据；匹配、value及方向强度梯度非零。
- 2真实chip、固定16源参考，固定全细推理隔离随机门控。late与pair_mean最终logit最大差0.135676；与prototype差1.502666，说明参考聚合顺序影响更大，不能混淆归因。
- 关闭M3时四组输出差0。软选择训练前后向：骨干/模块/门控梯度非零，无非有限梯度；没有optimizer.step。峰值显存约3.815GiB，仅是小批检查。

本轮2条案例一条持续正确、一条持续错误，没有新增救回。后一条相对旧路径正确类分差下降，原图与实际参考面板已复看，细节保留本地CASE_REVIEW_LOCAL.md。不是准确率实验，不据此选优或替换正式模型。
