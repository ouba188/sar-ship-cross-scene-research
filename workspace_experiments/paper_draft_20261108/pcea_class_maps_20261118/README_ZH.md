# 类别响应与区域取证可视化

2026-11-18。使用最新routed候选seed43最佳检查点及其16个合法源参考，重放三个既有验证案例；没有训练、选模、修改正式模型或写入论文。

## 图的含义

- `*_classes.svg/pdf/png`：同一输入的八类CCREL竞争响应，VV/VH分开；这是实际类别读出之前使用的有界竞争分数，不是原始M1响应、Grad-CAM或最终logit贡献。
- `*_regions.svg/pdf/png`：框内、轴端、侧向的实际CCREL空间权重。显示`log2(weight / uniform)`；0表示等于区域均值池化，正值表示相对增加、负值表示相对降低。末列为真实类与关闭PCEA时最强竞争类的密度对数差。显示范围固定为正负4，超出部分截色，原值完整保留。
- `*_maps.npz`保存输入像素、原始M1响应、竞争分数、实际权重、区域覆盖及开关PCEA分数；CSV保存非空区域网格的逐类别数值。
- SVG文字及网格为可编辑对象，底图仍为原始栅格图像。PDF文字嵌入字体。

底图使用实际推理输入，包含已恢复极化的覆盖，保持160像素输入及原有零填充。热图按20×20特征网格的真实中心零起点、步长8边界叠加，不用普通resize伪造精细定位。每格表示特征位置，不等同于该格像素独占的感受野或分割区域。

## 验证

- 开启可视化hook前后分类输出差异：0。
- 重建区域权重得到的CCREL读出与模型实际读出最大误差：0。
- 所有非空区域权重和为1，空区域为0，区域外权重为0，数值有限。
- 与原有缓存开/关预测最大误差分别为1.88e-6、2.03e-6，三个样本分类一致。
- 同一检查点开启/关闭PCEA不改变上游类别响应和CCREL权重；不能把这些图画成PCEA产生的新注意区域。

## 案例结论

| 案例 | 真实类 | PCEA关闭/开启分差 | 结果 |
|---|---|---|---|
| A | 原油轮 | -0.014990 / +0.001388 | 集装箱船改为原油轮 |
| B | 普通货船 | +0.020753 / +0.017891 | 保持正确，分差略降 |
| C | 散货船 | -0.904266 / -0.904695 | 仍误判集装箱船 |

三例均来自同港同一历史验证范围，不代表跨港覆盖。可以观察到不同类别与极化读出的位置分布不同；但部分中心/外围模式跨样本相似，不能仅凭热图认定学到了精细船体结构或稳定物理机制。案例A的上游权重差异与分支救回同时存在，尚不能证明某个热区就是救回原因；这需要进一步对所选局部证据做干预，而不是再美化热图。

## 复现与发布

在现有ClearSAR环境运行`python -B render.py --ids <既有验证样本ID> ...`。固定seed43，读取已有模型和输入缓存；默认不重训。

本地HTML、SVG/PDF/PNG、CSV、NPZ及report_local含原始输入或私人样本标识，不上传公共仓库。仅同步绘图代码与本说明。此次未实现Grad-CAM。
