## 指标与读图

### 条件效应

对原图联合诊断器固定最强错误类c0。某诊断器h的效应为：

`delta_m = [z_h,y(I(x)) - z_h,c0(I(x))] - [z_h,y(x) - z_h,c0(x)]`。

图中显示`delta_m × 1000`，不是概率或准确率百分点。先对同一船多次观测平均，再对船平均。正值说明本次削弱操作改善分差，不能解释成被削弱的原始成分有益；负值则表示削弱损害该分差。原图分差与干预分差使用同一竞争类。

细尺度为`I-G_sigma1(I)`，中尺度为`G_sigma1(I)-G_sigma2(I)`，sigma1=1、sigma2=2原生像素；这是空间尺度分量，不是电磁波段。预设剂量1.0不是全部去除。OSS1使用两极化共同区域及同观测匹配扰动L2；24港历史诊断使用各极化自身区域、极化内匹配L2，不能据此横向比较两个数据集效应绝对大小。

`n`为每类船数，†仅提醒少于20艘船，并非显著性标记。没有观测的类别不填零。完整操作和数据范围见`condition_data/README.md`及provenance.json。

图1中化学品/成品油轮框内细尺度削弱效应在VV为+5.48，在VH为−1.70（均为×1000显示值）。它直观支持当前诊断器对局部证据的利用依赖极化；不把图像干预直接升级为自然成像因素的因果定律。

### 混淆与场景图

三个训练种子为17、29、43。混淆矩阵先分别计算行归一化百分比，再对三个种子平均；不是模型集成，样本量不乘三。原始计数见`confusion_by_seed.csv`。

场景图为相同查询、相同种子的Full减Plain，再对三个种子取均值。BA对该组实际出现类别等权；不同组的类别组成不同，不能把场景间差别全归因于港口环境。误差线是训练种子标准差，不是置信区间。85个过境组保留原协议键，没有另行合并相邻产品。

主结果复核（OA / BA，百分数）：
- OSS2：Plain 55.9083 / 52.1760；Full 61.0229 / 55.6300。
- 24港：Plain 42.9268 / 40.1721；Full 48.4119 / 43.9019。

### 参考规模图的缺口

只绘制找到的同一历史候选下实测规模点；没有1/2/4/8/16全曲线，不添加未测点，不混入目标支持标注预算实验。每点只对应一个模型种子与参考配置，没有重复估计，所以没有误差条。OSS2现有各配置分类结果相同；延时没有匹配记录，不添加延迟曲线。

该页适合作为已有证据整理或补充材料底稿，不能作为当前完整RCEW规模敏感性的最终证据。

## 复现

1. `prepare_conditions.py`、`prepare_reference.py`：Python标准库，读取已有日志；`prepare_results.py`使用NumPy。
2. `build_editable.py`：python-pptx、openpyxl；读取聚合CSV/JSON生成PPTX、SVG和工作簿。
3. `export_figures.ps1`：本机PowerPoint导出PDF、PNG，关闭本次文档，不退出用户已有PowerPoint。
4. `check_exports.py`：PyMuPDF、Pillow，拆分PDF并检查9页与原生对象，生成缩略总览。

数据级样本/MMSI追溯表仅保存在本地；Git归档排除`round26_selected_observations.csv`和`reference_bank_membership.csv`。本轮没有新增模型实验，也不声称进行了新的原始chip机制核查。
