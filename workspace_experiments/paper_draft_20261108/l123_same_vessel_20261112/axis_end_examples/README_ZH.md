# 12457轴端干预示例

用户要求先制作同样本的轴端输入干预图。本轮仅生成像素变换与可编辑图，不训练、不运行分类预测，分差和预测字段为null；不能作为新增分类收益证据。旧八项实验及其图表未修改。

区域沿用历史joint_probe.py的轴端定义：检测船轴坐标u、v下，L/2 < |u| <= L/2+8，|v| <= W/2+2，并排除框内。单位为原生像素；同时处理两端，不确认真实船首/船尾。

VV/VH分别处理细尺度x-G1(x)、中尺度G1(x)-G2(x)，使用边界衰减的局部削弱。固定改变量L2=0.10454018589234293，与既有八项一致；本例缩放系数均不超过1。非选中极化、框内和轴端以外保持原样。均值对照匹配总灰度变化，而非像素L2。

核查区域外改动为零、四项L2一致、均值对照总变化一致及像素范围[0,1]。查看两页VV/VH原图、区域、处理后、差异和对照，未将可见结构命名为物理机制。原图与处理后统一灰度[0,1]，差异统一±0.03。保存精确浮点NPZ、8/16位PNG、HTML、两页原生可编辑PPT及PDF。

脚本在父目录make_end_examples.py。数据图像及身份元数据留本地；仅脚本与本文同步GitHub。
