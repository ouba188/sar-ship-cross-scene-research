## 数据恢复和验证

L2仅加载历史 `run_interventions.py` 的纯CPU函数 `changes_for`，复用原始chip与几何快照，重新生成当时的浮点像素变换。8项操作对历史记录的像素数、L2、对照L2和均值变化逐项核对，最大差异1.735e-18。分类分数直接读取历史 `predictions/12457.npz`，未对导出PNG重新预测。8项操作均保持正确；两个VV中尺度操作分差增加，其余下降。全流程L2缓存还包含历史显式频率描述重算，不把全部效果解释为纯像素路径。

显示固定[0,1]灰度，差异采用统一[-0.03,+0.03]；实际最大绝对像素变化0.024806。绿色只标操作区域，未送入模型。改后PNG量化用于展示，精确浮点数据另存。没有独立灰度拉伸，没有模拟物理散射。

L3直接复用历史N_level_pattern/seed17空间M3缓存。区域/参考移除固定T、beta与其他回写后计算下游，原始图像不改变。总回写幅度不等于带符号的类别贡献；分区域回写张量没有保留，不伪造。31512是同类不同船；13000是海工，不是化学品船。移除效应不可相加。

PowerPoint导出12页并检查图像页及新增结果页，无页面越界。复核8项干预图、真实查询/参考与缓存数值。不同历史模型明确标注，不把L1-L3作为同一模型的连续增益。
