# 两数据集主结果与混淆关系图

当前结果版：Full-Tuned，原始极化可用性。OSS2测试378条（369艘船），24港3075条（1950艘船）；训练种子17、29、43。仅复用已有预测，未重训或重新推理。

## 文件入口

- `index.html`：图表浏览与下载。
- `../figures/results_20261112/`：全部SVG（文字可编辑）、矢量PDF及PNG。
- `per_class.csv`：逐类召回、种子标准差、F1及测试支持数。
- `confusion_by_seed.csv`：每种子原始混淆计数、每类样本数及行归一化比例。
- `confusion_difference.csv`：Full-Tuned减各基线的平均行归一化差值，单位百分点。
- `summary.json`：按数据集、方法汇总的完整矩阵和OA/BA/F1。
- `build_figures.py`：直接从预测缓存重建上述产物的CPU脚本。
- `sources_local.json`：实际读取的预测文件路径，仅本地留存。

## 比较与阅读

主图对照为Plain（分阶段普通骨干），两个数据集一致。另附Full-Tuned减Full-Staged，用于观察追加微调变化；OSS2再附Full-Tuned减R50-Tuned强基线。24港没有新增或虚构R50-Tuned基线。

每个种子独立argmax，分别形成行归一化矩阵，然后取三种子均值。未平均logits后再分类，未将三种子当三倍独立测试样本。行是真实类别，列是预测类别；每行归一化为100%，差值每行合计为0（显示舍入除外）。差值图对角线为召回增量；非对角线负值是对应误判减少，正值是误判增加。红蓝表示增加/减少，不直接编码好坏。两个对Plain主图使用统一±22个百分点色标。

24港矩阵缩写BC、FV、GC、PT、CS、CT、TT、OS依次为散货船、渔船、普通货船、化学品／成品油轮、集装箱船、原油轮、拖轮／拖带船、海工补给船；CSV保留完整类名。

Full-Tuned与Plain/R50-Tuned是相同评价观测上的系统比较，训练历史和预算并不相同。配套删除重训仍使用论文既有分阶段模型，未把这些系统差值写成单模块因果效应。恢复查询/参考极化的成绩另在论文6.9节输入恢复段落报告，不混入主表和图。
