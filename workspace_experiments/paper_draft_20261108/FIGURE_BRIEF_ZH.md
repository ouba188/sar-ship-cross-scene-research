## 图3 当前模型整体结构

输入：VV、VH各一张原生裁剪/补零160×160图，OBB与有效掩膜。VV/VH共享一套ResNet-50参数，两个计算流，不画成两个独立训练骨干。

主干：stem → layer1 → layer2前三block → layer2[3].conv1 → conv2+BN+ReLU → M1 → conv3+BN → 原残差相加+ReLU → layer3前五block → layer3[5].conv1+BN+ReLU → M2区域池化回写 → conv2+BN+ReLU → conv3+BN → 原残差相加+ReLU → M3残差相加 → layer4。

旁路：layer2输出接M2浅层读出及M1响应引导；M3后的layer3输出接M2深层读出，经1024→512投影；每个区域对应项相加，三个区域拼接，与layer4有效平均2048维拼接；两极化各3584维再拼接，加两个可用性位，共7170维到四分类头。

参考：固定锚点layer1/layer2描述与32个源参考生成M3残差。当前M1/M2训练固定这个残差，不能把箭头画成“新M1输出实时重算M3匹配且三者联合反传”。无需画旧频域分支或layer2[2] M2。

## 图4 M1与M2接口

左侧M1：128通道局部输入 → 32维值投影、4个类别响应 → 有效均值与相对类别交叉统计 → 均值反馈/关系反馈 → 有界门控 → 乘原特征并残差相加。

右侧M2浅层：M1响应图与512通道layer2输出同20×20格；框内/轴端/侧向各自计算1个均值和4个类别加权摘要；每摘要32维，拼接160维 → 512维有界增量 → 原区域均值。这里不回写空间图。

下方单独小框：layer3内部M2的256通道输入 → 三区域均值 → 各自256→32→256变换 → 按本区域足迹回写 → 加回原输入。图区分读出与回写，不能把两者都画成下采样。

## 图5 M3横向细节

从左向右：

1. 查询与源参考的双极化、多层局部描述（layer1 256、layer2 512，固定锚点）。
2. 每极化投影，得到key和值value，各32维；保留框内8、侧向8、轴端4个槽位。
3. 合法船/过境及极化掩膜、类条件度量、相似度、带未匹配槽的传输T。
4. 由T得到行列边际及参考权重beta；值传递用边际外积，不使用精细T对应。
5. 类内聚合参考value得到P，查询value与P距离得到类别证据，类别中心化。
6. 依槽位空间权重回写4类证据图，1×1卷积4→1024，乘0.1并加layer3。

图中可以保留“比较分支”和“回写分支”，但两者共同属于M3，不再称“空间—频域双分支”。类条件度量/细槽等是实现内容，不在图中标注为已独立证实的增益。
