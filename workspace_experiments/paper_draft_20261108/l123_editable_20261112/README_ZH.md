# L1-L3 可编辑科研图

交付：`L1-L3_分层判别证据_可编辑.pptx`，4页；另有同内容PDF和逐页PNG预览。

1. L1-L3横向总览。
2. L1：Santos同船7032/7035，双极化自然观测与固定诊断器预测。
3. L2：24港来源7797样本的VV框内中尺度干预、匹配均值控制、实际改变量；配套按船汇总的条件效应矩阵。
4. L3：OSS2 002422 / Full-Tuned seed29，固定参考的内部路径替代及分差。

所有文字、标签、箭头、色块、热力图格子及条形都是原生PowerPoint对象。SAR图像为独立嵌入PNG，可以替换；不把SAR像素伪造为矢量证据。没有整页位图。
图表用形状绘制，修改数值时需对应调整条长或格子颜色，非自动联动Excel图表。精确数值另存figure_values.csv与heatmap_values.csv。

L1-L2为历史诊断器，不是当前完整模型；L3为当前固定模型内部计算图反事实，不是物理成像反事实，也不是配套重训消融。各层结果不可合并为一次实验。
L2案例干预后分差约0.000096，属于近边界救回；PPT中已说明。干预显示图由历史纯像素算子重建，6项统计与缓存一致；未训练或重跑模型。
L3黑边为原生160输入的补零，并非海面。各层图像没有额外灰度拉伸。

来源与精确值见l2.json、source_assets.json、各页演讲者备注，以及原实验目录。
制作脚本：prepare_l2.py、build_deck.py；PowerPoint导出：render_deck.py。
正式论文和模型未修改。含原始chip的PPT/PDF/PNG及逐记录路径只保留本地，不公开上传。
