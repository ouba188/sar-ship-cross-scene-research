# 双极化局部输入交互验证

2026-11-16。属于新架构 CCREL/PCEA/RCCEW 的开发诊断，不是新模块性能实验。

## 固定项

沿用 OSS2 228 条验证观测、三个 Full 检查点（17/29/43）、32 个源参考、原生 160 裁剪补零、检测框、极化可用性及现有区域掩膜。对照统计限定双极化均可用且所分析区域两侧均非空的共同样本；报告每组实际数量。旧实验的原图和单极化预测直接复用；仅新增两极化联合操作的 3 区域 × 3 种子预测。

## 四状态与交互

对框内、轴端、侧向分别操作。指定区域替换为 `0.5*x + 0.5*该极化该区域原图均值`，其他像素、另一极化及参考均保持原样。不改变灰度拉伸和归一化。

- 00：原图。
- 10：只操作 VV。
- 01：只操作 VH。
- 11：两极化均执行各自的同一操作。

每个种子、查询固定原图最强错误类 c0。四状态均用 `m = z_y - z_c0`，计算 `I = m11 - m10 - m01 + m00`。

`I>0` 仅表示联合操作下的分差高于加法预测，不能自动解释为有益的原始极化互补。准确率、操作后最强竞争类分差以及 `z_add = z10 + z01 - z00` 的预测另外报告。交互比较用 logits，不用 softmax 概率，避免把 softmax 自身的非线性当成证据。

按类别、过境与种子分层，同时报告平均有符号交互和平均绝对交互。置信区间按船 ID 聚类重采样，先平均固定三个种子；不是把重复前向作为独立样本，也不代表新港口总体。

## 检查及其决策作用

1. 联合图像每个极化必须等于对应单独操作，区域外逐像素不变、区域均值不变。失败则修复操作，不解释模型交互。
2. 每个检查点重放原图首批并与已有 FP32 缓存核对。失败则停止混用缓存。
3. 预测 ID/标签严格对应，单极化与联合比较同一船群。失败则修正配对。
4. 分析前以加法和显式乘积模型验证交互计算。随后回看原生 VV/VH、操作区和实际合法参考：救回、误伤、持续对/错均记录。

## 可以和不可以得出的结论

本轮能判断当前已训练分类函数在指定扰动基准附近是否存在跨极化非加性、哪些类别和区域更明显；不能据此识别电磁散射的物理因果机制，也不能证明非加性一定是泛化所需。新 PCEA 需与普通门控/拼接及配套训练对照比较，正式测试集不用于本轮调参。
