# CCREL / PCEA / RCCEW：据本轮证据修订的实验架构

2026-11-16。用户明确要求实质重设计，而非重命名旧架构。本文定义候选数据流、核心运算和下一轮训练对照。不是已训练完成的新模型声明。

## 1. 首要修正

原草案“极化联合使用改变局部证据作用”应拆成两件事：

- 已证实：当前双极化分类器中，不同极化、区域、类别的输入操作效应可异向。
- 当前没有：一侧输入改变另一侧在固定 logit 竞争关系中的效应。现有函数可加，本轮四状态验证为数值零。

新目标不是拟合旧模型已经存在的跨极化交互，而是**检验新增跨极化条件化能否改善旧模型无法区分的证据组合**。不能将旧教师的零交互作为新模块必须模仿的目标，否则恰好会压掉新增能力。

## 2. 新 M1：CCREL

职责：在单极化内部形成有类别含义、有区域身份的证据。保留共享 R50 和极化专属小参数，不新建两套骨干。

首轮位置沿用 layer2[3].conv2 后的类别响应和 layer3[5].conv1 后的区域取证候选，不同时搜索多个新位置。它可以跨层组成一个模块，不必把所有运算挤在同一层。

设 F_p 为当前特征、A_p,k 为所有候选类别响应、M_p,r 为框内/轴端/侧向软区域。用类别相对响应 `a_p,k=A_p,k-mean_{j!=k}(A_p,j)` 在每个区域内形成归一化读取权重。保留两个证据来源：

- 均值 token：`E_p,r,0 = sum(M_p,r V_p(F_p))/sum(M_p,r)`。
- 类别 token：`E_p,r,k = sum(softmax_region(a_p,k) V_p(F_p))`。

候选响应从较浅层传到内部读出时须与特征网格及有效范围一致；区域按原生 OBB 投影，不能直接对图像缩放改变尺度。无效区域给零 token 和显式有效标记。

实质变化是把类别条件读取放进内部区域反馈运算，保留均值路径，不只在最后分类向量上补一个响应摘要。类别响应受源标签辅助监督；推理时同时计算所有类别，不使用目标标签。

输出契约：`E: [B, 2, R=3, K+1, D=32]`，其中第0槽为均值，第1..K槽为所有候选类别。保留原极化/区域标识；独立 CCREL 可直接用自己的投影回写。

## 3. 新 M2：PCEA

职责：让两极化的区域证据相互条件化，而不把它们简单混成一张特征图。

先分别投影到学习得到的公共低维坐标：`u=tanh(U E_VV)`，`v=tanh(V E_VH)`。不同专属模块的原始通道不能直接被认定为语义对齐，因此 U/V 独立学习。

对于每个区域 r 和所有候选类别槽 k，联合条件 `q=[u,v,e_r,e_k]`，生成两路权重 `alpha=softmax(g(q)[:2])` 和交互系数 `beta=sigmoid(g(q)[2])`：

`H_r,k = alpha_VV u_r,k + alpha_VH v_r,k + beta (u_r,k * v_r,k)`。

乘积是明确的跨输入运算；但普通动态门控也能产生交互，所以比较时必须保留无乘积的相同门控对照。原草案 C+GD 只是加权融合重参数化，不作为独立创新。

用独立输出投影返回各自 token 空间：`E'_p = E_p + 0.1*rms(E_p)*tanh(O_p H)`。O_p 零初始化，保持起始函数不变；不要同时把外部残差系数也设成零，避免完全断开学习。门控第一步梯度为零、输出投影更新后第二步开放是预期行为，已测试。

若任一极化或该区域不可用，联合残差为零，单极化自身证据不被除以2或抹除。使用自己极化的 OBB 区域回写，不假定两张 chip 逐像素配准。初版在 layer3[5].conv1 后的 256×10×10 内部区域路径上使用一次；回写后继续 conv2/conv3/残差相加。

`pcea.py` 为已实现候选核心；`regional_writeback` 拼接全部 K+1 槽再投影至特征通道，用对应区域掩膜回写，重叠位置归一，框外未覆盖位置不更新。优先复用 CCREL 的回写投影，不平白重复一套大投影。

核心 3267 参数的数字不包含上游 CCREL 或回写投影。接口和梯度测试通过，尚未连接完整训练入口；不能报告 SAR 精度收益。

## 4. 新 M3：RCCEW

职责：引入源参考中的相对类别证据，而不是再次做极化融合或区域取证。

先保留目前有效的聚合版 RCEW。查询/参考使用一致的 CCREL/PCEA 特征版本；参考描述随编码器更新，不能混用旧缓存。保持源参考合法性，查询真值不参与参考选择。

首轮仍在 layer3 末端进行参考证据回写再送 layer4。需要重新决定参考描述取样接口：它必须实际读取 PCEA 之后的特征，而不是名字改为新参考模块却沿用 PCEA 之前的固定读出。可保持旧槽位几何，仅更新内容来源和投影。

先测试更新后的查询/参考证据是否使聚合回写获益，再研究精细匹配与参考可靠性。它们不与 PCEA 同轮叠加，以免无法归因。

## 5. 训练和配套对照

|顺序|比较|解决的问题|
|---|---|---|
|A|旧模型；类别无关内部区域读取；类别引导内部区域读取|CCREL 的实质连接改变有无收益|
|B|独立加性小分支；同 token 普通条件门控；门控加乘积 PCEA|额外容量、动态权重、乘积项分别有何作用|
|C|固定新前端，无参考回写；有聚合参考回写|RCCEW 是否仍提供额外净收益|
|D|确定候选后，新完整模型与旧完整模型|两数据集内跨场景总体效益、成本和原图案例|

首轮只用 OSS2 既有源训练和验证划分；参考库不变，输入160原生裁剪/补零不变，保持同一初始化、训练样本和训练步数。允许候选与简单对照同等调参机会，例如学习率两个值、固定训练时长，全部记录。不能只给新分支增加优化轮数。

短期先检查源端小训练的梯度、更新幅度与拟合是否正常，再作源端选优和验证比较；冻结旧干线可用于首个差异诊断，但确定候选后必须在相同全骨干微调预算下比较，不能把冻结诊断当最终模型。

干预选样与分差保护先沿用现有已核实流程，不自动追加“交互一致性损失”。它们与新 PCEA 的额外收益分开验证。当前正式微调继承干预训练历史，但本轮微调损失不等于每步重新执行教师选样；重设计报告必须区分两者。

成功标准：限定任务下，配对多种子有可重复净收益，且收益不被同预算简单门控完全解释；不要求每类/每港全赢。若只改善训练而验证退化，优先检查容量和优化协调。若三组都不增益，不继续无限搜索位置；回看具体样本是否缺乏可用的交互信息。

## 6. 文献依据及新颖性定位

本轮核查了用户所列 CMLG-Net 官方 README，其内容是模态内增强与跨模态集成，不能直接当作本方案的类别条件区域仲裁已获支持。README 的论文入口含占位 URL，不能据此声称已精读论文正文。其 BibTeX 给出的正式题名为 Robust and Accurate Hand Gesture Authentication With Cross-Modality Local-Global Behavior Analysis，TIFS2024，DOI 10.1109/TIFS.2024.3451367。

arXiv 官方记录核实 Hadamard Product for Low-rank Bilinear Pooling（1610.04325）的题名与摘要，说明低秩乘积融合已有研究基础；本轮未据此宣称新的双线性理论，也没有完成其全文消融核查。实现中的乘积本身不是创新。

本方案待证明的差异是：在目标相对区域和所有候选类别证据下进行极化条件化，并把结果写回中间特征用于后续参考比较；能否构成有意义的方法贡献取决于与普通门控、独立小分支及原参考回写的匹配训练比较。
