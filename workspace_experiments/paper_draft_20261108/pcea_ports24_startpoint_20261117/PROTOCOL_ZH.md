# 24港 PCEA 起点约束小验证

2026-11-17。目标：检验OSS2上未兑现的PCEA增量，在覆盖更广的24港训练材料中是否出现；区分PCEA与继续训练、起点约束的作用。不替换正式模型。

## 固定条件

- 起点：`ports24_recovered_training_20261113/selected_s17/best.pt`，八分类、全骨干已微调、已有跨极化几何恢复策略。
- 训练池20,653条，24港、601过境组、12,581艘船。相同随机排列的前5,760条进入每组240步，不重复抽样；覆盖24港、540过境组、4,834艘船，类别数1981/1022/1200/669/293/253/222/120。
- 验证160条、158艘船、3港/3过境组；类别数25/0/12/70/22/16/7/8。验证BA仅覆盖出现的七类，不能宣称八类均已验证。
- 验证港为Jebel Ali 69条、Port Klang 28条、Singapore 63条，均在训练港口集合中；这是不同过境的跨场景验证，不是留出未见港。恢复后151条双极化、9条单极化。
- 固定源参考16条、每类2条，训练中用当前共享骨干重新编码。训练与验证身份/过境隔离沿用现有协议。
- 使用相同几何恢复规则；仅恢复训练/验证/参考，不读取测试图像。恢复训练434条、验证6条、参考1条。所有组输入一致。
- 原生160裁剪/补零，配对旋转/翻转及区域掩膜重新积分；不缩放船体。

## 四组

| 模型 | 起点约束系数 |
|---|---:|
| 已训练Full继续训练 | 0 |
| Full + CCREL/均值PCEA | 0 |
| 已训练Full继续训练 | 0.1 |
| Full + CCREL/均值PCEA | 0.1 |

全骨干及原有有效模块训练，BN统计固定，仿射参数训练。旧骨干/旧模块学习率均为1e-5，新读出1e-4，PCEA为3e-4；AdamW衰减0.01，批量24/微批12，裁剪5，余弦下限0.1。每30步验证，共8段；不是8个全量epoch。

损失为原有类别/船只平衡CE、0.02类别响应辅助CE，加 `lambda/2 * SUM ||theta_old-theta_start||^2`。新参数不向零起点约束。保留既有干预训练历史，本轮不重新选样。

CCREL保留均值+八类响应共九个槽；同一算法由四类改为八类所需的维度变化，不新增机制。PCEA回写层零初始化，初始预测必须重放已训练Full；读出从已训练区域投影复制。模块保持原接入位置。

## 判断与归因

以验证BA、OA、负NLL顺序选检查点，允许保留起点。报告四组最优与最后一步结果，不把第0步称为新模块收益。

先比较PCEA与同约束Full，再比较各自约束开关及原起点。对最后一步PCEA作同权重开/关检验，区分直接回写和训练轨迹变化。使用逐类/逐港翻转及原始VV/VH、实际合法源参考案例解释范围。一个种子和160条开发验证不能证明独立泛化，不使用测试集选配置。

## 原训练背景

起点是恢复极化输入后训练的第7轮：训练OA62.194%、验证OA45.000%、BA39.661%。第15轮训练OA68.474%、验证OA35.000%、BA33.486%，触发连续8轮未刷新选点的停止条件；恢复的不是末轮权重。第13轮验证OA曾达到51.250%、BA38.968%，未超过BA优先规则下的第7轮。

这些记录支持后期泛化不足，但不单独证明参数漂移、纯粹记忆或某一场景因素为根因。增强训练累计OA与轮末固定模型验证OA不是严格同条件比较。验证拖轮仅7条，一次该类翻转即可改变总体BA约2.04个百分点；需同时看净正确数和逐类变化，不能只看BA选点。
