## 四个对照

1. Full：无新增PCEA，复用pcea_class_local_20261117的三个既有完整模型续训。
2. generic：原PCEA分类训练，复用同目录三个既有续训。
3. paired_ce：同一PCEA，0.5倍开启分类损失+0.5倍关闭分类损失，均含原0.02 M1辅助项。
4. guided：在paired_ce上增加配对纠错和固定起点保护。

新增后两组各17/29/43三种子，共6次240更新；已有两组不重跑。固定同一正式seed17起点、源fit15316、inner1000、每种子5760条唯一训练观测、样本顺序、增强代码、16参考、学习率和选模规则。三种子是续训顺序/增强重复，不是三个独立正式模型起点。配对训练计算量更高，步数和样本预算相同，不声称等计算量。

## 目标函数

正确类别分差m(z,y)=z_y-max_{c!=y}z_c，各路分别重找最强竞争类。

- z_off：当前模型关闭PCEA的预测，参与关闭支路分类监督；作为分差目标时detach。
- z_on：当前模型开启PCEA的预测。
- z_T：固定原正式模型对同一增强图像和同16参考的预测，全部停止梯度。
- hard = [m_T < 0.2]，safe = [m_T > 0]；训练真值只用于损失，不输入网络或推理门控。
- target = m_off + clip(0.2-m_off,0,0.1)。难例只要求最多0.1的适度改善，不强求一步纠错；若当前已达到0.2则不再提高目标。
- L_improve = hard * relu(target-m_on)。
- L_protect = safe * relu(min(m_T,0.2)-m_on)。保住正确性附近的优势，不强制复制原模型大置信度。
- L_guided = 0.5 L_on + 0.5 L_off + 0.2 weighted_mean(L_improve+L_protect)。沿用源训练类别/船只权重。

两个额外损失仅作用于PCEA实际active的样本（双极化且至少一个有效可回写区域）。单极化/没有有效区域时保持原分类监督，不要求一个未启用的分支产生增益，避免骨干被迫补偿不可能的分支目标。

上述三个常数本轮固定，不做外部调参。关路分类监督和固定教师保护限制通过恶化关路来获得表面相对收益，但不宣称完全排除共同退化；最终对Full及同检查点on/off分别比较。

## 实现与选模

原generic结构、scale=1、写入layer3[5].conv2前不变；骨干/原模块学习率1e-6，读出1e-5，PCEA3e-4；AdamW、wd0.01、clip5、batch24/micro12、余弦日程沿用。骨干继续解冻、BN运行统计固定。每次前向重新编码参考，不用旧缓存参考。微批关闭路径先反传，再开启路径反传，控制8GB显存；优化器每24张更新一次。

源inner按BA/OA/-NLL选最优步，step0可选；它与本轮训练/参考按船和过境隔离，但早期编码器见过。全部6次源端训练结束，才计算旧160和既有198；两者均历史分析过，198没有新增独立过境。不使用原3075测试图像和预测。

## 必须核验的证据

- smoke：原on/off/固定教师在零初始化时一致；合成样本确认纠错/保护梯度方向、off和teacher目标无梯度；真实微批确认解冻骨干、读出和PCEA能获得有限梯度。
