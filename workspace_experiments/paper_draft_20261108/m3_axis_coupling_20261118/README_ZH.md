# M3：让位置关系实际进入局部证据回写

2026-11-18。状态：候选实现及机制/完整模型前后向验证完成；未训练，未替换正式模型，未修改论文。

## 解决的问题

原aggregate分支把运输矩阵T替换为行边际与列边际的外积，保留两侧权重但去掉逐对耦合。本轮保留完整T，将对应参考内容输送到每个查询槽位，再形成该槽位的类别证据并回写。不是仅在相似度旁增加一个位置字段。

设计依据复用本轮CPEA精读与既有船轴槽位诊断；CPEA不等于已验证本方法。原图回看显示目标与参考的长轴、响应宽度和局部延伸不同，但没有可靠首尾标注。因此处理的是无向轴坐标的歧义，而不是从亮点推断船首。

## 算法与实际接入

保留VV/VH分开处理、20细槽、现有浅深特征与relation-context候选。名义槽位中心根据当前OBB划分定义：框内4x2、侧向4x2、轴端2x2；坐标相对目标长宽归一化，没有缩放原始像素，也没有新增首尾标注。

对每个查询q、参考r、极化p，考虑h=+1/-1两个整体轴向假设：

    C_h(i,j) = C_content(i,j) - softplus(a_p) * ||pos_i-h*pos_j||^2
    T_h = existing_masked_Sinkhorn(C_h, query_mass, reference_mass)

两个极化各有一个可学习位置强度，初始均为0.25，新增参数2个。位置仅作用于比较代价，不把位置向量当作散射内容回写。

按各有效区域匹配质量归一化的平均代价形成方向分数，再跨区域平均、温度0.1 softmax。每个q/r/p的两个软方向权重由整套区域共同决定，不逐patch独立选方向：

    T = sum_h weight_h * T_h
    aligned(q,r,i) = sum_j T(i,j)*value(r,j) / sum_j T(i,j)

随后只在同类参考之间平均，仍保留查询位置i：

    prototype(q,c,i) = sum_{r in c} beta(q,r,i)*aligned(q,r,i)
    evidence(q,c,i) = centered_class_score(-weighted_distance(value(q,i), prototype(q,c,i)))
    delta(q,u) = output_projection(sum_i write_mask(q,i,u)*evidence(q,:,i))

因此类别原型为[B,C,I,D]，没有把I提前平均；最终空间回写沿用原M3位置及投影，后续骨干继续计算。M1/M2/CCREL/PCEA保持原样。

## 四个配对开关

- none + aggregate：relation上下文加原边际聚合路径，回放控制；不是原论文等权上下文模型。
- none + paired：仅保留内容匹配的逐对关系。
- axis + aggregate：几何作用于匹配，但回写仍压成边际聚合。
- axis + paired：几何与完整逐对关系都进入实际回写，当前候选默认。

另有signed模式用于位置编码但不处理轴向歧义的后续对照，本轮没有分类训练比较。几何、coupling及上下文模式须随训练配置保存，不能仅靠state_dict判断模式。候选安装必须在优化器与CUDA graph建立前执行。

## 已通过的验证

verification.json保存机器可读结果。

1. 关闭新机制回放relation聚合路径：合成输入输出最大误差0。
2. 查询与参考分别独立反向重编号，连同质量和查询回写位置一起变换：合成双精度回写误差约1e-15。
3. 不改变局部内容集合，只交换非整体反向的局部排列：有位置时回写最大变化0.04630；无位置时约9e-16。这里输入为合成特征，不是实测准确率。
4. 保持运输矩阵行、列边际相同，只保留/去掉逐对耦合：合成回写最大变化0.90177，说明耦合没有被后续计算代数抵消。
5. 缺失极化、部分槽位、无合法参考的输出和反向有限；位置参数梯度非零。
6. 两张真实chip、16个原有合法源参考、相同已训练起点的完整前后向通过。骨干、M3、CCREL、PCEA及新增位置参数均收到有限非零分类梯度。

真实完整模型同权重诊断：

| 比较 | 最大绝对变化 |
| --- | ---: |
| axis paired vs axis aggregate，M3回写 | 0.001597 |
| axis paired vs axis aggregate，最终logit | 0.041925 |

## 审阅后明确的边界

- 当前是共享软方向先验，不是确定的首尾或硬方向选择。两方向真实匹配质量不同，混合后的各槽有效方向比例也可不同；先混合value再比较存在折中表示，后续需以配套训练判断作用，不称为已经消除首尾错位。
- 方向分数是匹配质量归一化的启发式评分，不是物理后验或完整OT目标；尚未验证高分低覆盖情况下是否偏置。
- 坐标是名义槽位中心，不是每个实例有效像素的真实质心。当前不新增尺寸自适应粒度。
- 重编号等变测试不等于真实跨观测旋转不变，也不表示船轴可作为船型依据。
- 真实验证只含两例，0优化步，不能推断准确率、跨场景收益或稳定性。
