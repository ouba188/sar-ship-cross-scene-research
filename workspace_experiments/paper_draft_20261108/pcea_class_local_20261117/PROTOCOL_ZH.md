# 类别响应组织局部细节：24港匹配续训

## 问题与改动

前轮当前冻结局部交互描述没有稳定超过同容量区域摘要；9574救回、7672误伤均被推向化学品/成品油轮。不能据此认定外围延伸就是原因，也不能继续仅归因于回写偏小。

本轮只改局部细节的类别组织：原式 `local = class_summary + detail`，候选为 `local = class_summary + gain(class_response, region) * detail`。CCREL既有类别空间权重除以区域均匀权重得到密度，经过 `1 + 0.5*tanh(log(density))` 后按区域面积归一化至均值1；无有效面积处设1。均值槽始终为1。没有新增参数，没有只选Top-1/Top-2，也不使用查询标签生成权重。

保留VV/VH、三区域、九槽身份；PCEA仍为cross_mean，20x20比较后面积降采样至10x10，在layer3[5].conv2输入处回写。类别权重、读出投影、PCEA和全骨干参与梯度更新，BN统计固定。原模型和历史代码不改动。

## 三组与训练

- full：正式完整模型匹配续训。
- generic：原通用局部细节+PCEA。
- class_detail：类别响应组织局部细节+同一PCEA。

共同初始点为正式24港 selected_s17/best.pt，不用退化末轮。17/29/43仅为续训样本顺序/增强种子，不能称三个独立训练起点或独立数据集。三组新增前向的零初始化回写确保初始logits一致，generic与class_detail参数量相同。

不追加学习率搜索。骨干/原模块1e-6、CCREL投影1e-5、PCEA3e-4，AdamW wd=.01，clip5，cosine底值.1。240次更新、batch24/micro12，5760个不同训练观测，每30步评价一次源内部留出。源类别/船只权重在本轮fit重新计算；CE+.02原类别响应辅助CE。保留原检查点干预训练历史，不声称重新执行干预选样。

复用前轮1000个源内部留出观测，从完整20653源池中排除这些船只和过境，训练及16个固定源参考均与内部留出船只/过境隔离。旧编码器见过这些源观测，因此此集仅为续训选择集，不能作为独立泛化证据。初始点参与BA/OA/-NLL选点。全部9次拟合完成并固定选点后才评价既有外部160验证；不读取3075测试像素/预测。

## 验证与解释

训练前检查初始logits一致、参数量一致、均值槽不变、加权面积均值1、uniform精确还原generic、分类损失对类别细节权重梯度非零。若失败先修接口，不训练错误版本。

选定模型比较三组完整性能，并对class_detail同权重关闭PCEA、改均匀权重、循环错配八类权重，区分普通微调、PCEA和类别组织的贡献。后两项是推理时依赖诊断，不冒充配套训练消融。
