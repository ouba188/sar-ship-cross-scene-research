# 类别响应组织局部细节：24港续训结果

## 结论

完成三组、三个续训种子共9次训练，2160次更新，拟合计时约2801秒。**新类别组织与旧通用局部细节版本在外部160张的三个种子上预测类别全部相同，没有获得新增分类收益。** 本轮不替换正式模型，不追加倍率或训练轮次搜索。

PCEA整体存在一个种子的真实单例补证，但不依赖新类别组织：原油轮21433在seed43关闭分支时分差-0.01616，开启+0.00106；均匀权重和错配类别权重后仍正确，旧PCEA也正确。保留这个有限正结果，不把它包装为新设计成功。

## 实施了什么

原 `local = class_summary + detail` 改为 `local = class_summary + class_gain * detail`。gain来自CCREL已存在的类别空间响应，按极化、区域、类别分别生成；相对均匀分布的密度先有界化，再令区域面积加权均值为1。均值槽不改变，不新增参数，不用查询真值生成gain。

三组为正式Full匹配续训、generic通用细节PCEA、class_detail类别组织PCEA。PCEA交互、参考组织、回写位置及限幅不变。全骨干和使用中的旧模块可训练，CCREL读出投影与PCEA联合更新；BN统计固定。骨干及旧模块LR1e-6、读出1e-5、PCEA3e-4，各240步、batch24/micro12。无本轮新干预教师，保留原模型干预训练历史。

三组都从正式 `ports24_recovered_training_20261113/selected_s17/best.pt` 出发，不使用前轮退化末轮。17/29/43是续训顺序及增强随机性，不是三个独立正式起点。

## 数据与选点

- 原源池20653；排除内部留出船只及合并过境后可训练15316，覆盖24港、467过境、10315艘船；13100双极化有效。
- 内部留出1000，23港、106过境、960艘船，八类均有；与本轮fit和16源参考无船只/过境交叉。旧编码器此前见过这些源观测，因此仅为续训选点集。
- 每个种子从fit无放回取5760张，三组相同顺序与增强。分别覆盖4815/4852/4834艘船、429/431/424过境，均24港。详细类别数见actual_training_scope.json。
- 16个合法源参考固定不变，当前编码器每次更新后重新编码，不使用旧神经特征缓存。保留既有地理配准OBB恢复，三组输入相同。
- 每30步按源内部BA/OA/-NLL选点，step0允许保留；九次拟合完成后才评价外部160。未读取3075张测试像素或预测。
- 外部160覆盖3港、3过境、158艘船，151双极化，7个有样本类别（没有渔船）。该集此前参与开发，结果不是全量独立测试结论。

## 新设计有没有真正参与

启动检查证明它已接入：初始三组logits一致；generic和class_detail参数量相同；均值槽为1，权重区域均值误差1.79e-7；分类损失对gain梯度非零；uniform精确还原generic计算。独立代码审阅未发现阻断性接入问题。

但“参与计算”不等于“形成有效增量”：

- class_detail对比独立训练的generic，三个种子均0预测类别变化，logit类中心化RMS仅4.61e-5至6.47e-5。
- 同权重将gain改为uniform，三个种子均0预测变化，类中心化RMS2.22e-5至2.82e-5，最大单logit改变不超过0.000133。
- 同权重循环错配八个类别gain，三个种子仍均0预测变化，类中心化RMS约2.23e-5至2.30e-5。
- 整个PCEA关闭，seed17/29无翻转；seed43损失21433这一个正确样本。PCEA整体依赖强于新增gain依赖，但规模很有限。

由此支持：**在本轮起点、表示、训练预算和验证范围内，这种类别加权细节未被利用为具有额外分类价值的证据。** 不支持“任何类别条件化无效”“极化交互无价值”，也不支持把问题简单归为代码未接通或骨干冻结。

源内部初始OA60.10、BA58.776，续训选点BA约60.82至61.70，而外部收益未同步。说明源端改善不能直接代表跨场景改善；本轮不能进一步断定唯一原因是数据量不足或过拟合，也没有证明更强gain/更多步数会改善。

## 原始chip与实际参考

gallery保留原始160裁剪/补零，不缩放船体；VV/VH分别显示，左右查询像素相同，仅模型不同。参考为实际固定源库中的同类/竞争类示例，不是最大影响归因。主代理查看04至10，独立代理查看00至03；具体图像事实与证据区分如下。

### 真正依赖PCEA、但不依赖新gain

- **21433，原油轮，Jebel Ali，seed43**：两极化均见近竖直细长亮体，VV外围细线状延伸较VH明显。同类原油轮29922较横向，竞争集装箱36308较小。关闭PCEA分差-0.01616，开启+0.00106；uniform为+0.00107，类别错配也为+0.00107。旧generic为+0.00120。可确认这一已训练模型的PCEA对边界翻转必要，不能确认特定可见延伸是原因，更不能归因于新类别gain。seed17/29该船仍错误，尚无跨种子重复救回。

### 续训共有救回与误伤

- **35666，原油轮，Singapore，seed17**：两极化有较宽、近横向亮体，VV另有明显纵向延伸；同类29922较小，集装箱36308更小更细。相对原正式点由集装箱救回，分差-0.39663至+0.12594。但Full续训已救回（+0.10856），关闭PCEA仍正确（+0.09908），不能记为新增模块救回。
- **29641，集装箱，Port Klang，seed17**：两极化为斜向细长亮体；同类36308更小，竞争散货34478偏横向。相对原点从正确变为散货，+0.20319至-0.10498，Full、generic均同样误伤。不能把这个损失单独归因于类别组织。

### 原设计动机样本没有解决

- **9574，化学品/成品油轮，Jebel Ali，seed17**：VV横向条纹状延伸明显，VH较紧凑。同类24527竖向较细，散货34478横向也有延伸。generic与class_detail均判散货，分差-0.47642至-0.47637；新增组织没有救回。注意前轮读出探针采用不同检查点/头，不能把其救回沿用为本轮结果。
- **7672，集装箱，Jebel Ali，seed17**：VV也有横向延伸，VH较紧凑；同类36308和竞争24527均小于查询。两版本均正确，+0.27965至+0.27969，没有形成有意义的判别差异。两例说明可见极化差异存在，但本轮没有把它转为新增可用证据；并不证明图中差异本身没有信息。

00至03的持续正确/错误案例保留在gallery及独立审阅补充中；无新gain导致的救回或误伤，不人为挑选历史案例替代。

## 处理决定

1. 保留正式模型，当前新gain版本不替换、不写作已获益模块。
2. 保存旧PCEA单例补证和全部负结果，承认单种子极小边界收益，不追求处处全胜也不扩大结论。
3. 对当前有界类别gain方案收口，不追加无依据倍率/轮次扫描。进一步实质改造需要新的证据利用路径，不能把相同加权换名后继续跑。
4. 本轮未扩大公开集或正式测试；论文与正式权重不变。代码、协议、聚合结果、曲线和报告同步Git；原图、权重、缓存、逐样本路径/预测不上传。
