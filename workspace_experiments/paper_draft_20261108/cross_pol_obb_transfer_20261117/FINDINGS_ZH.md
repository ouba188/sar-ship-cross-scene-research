# 跨极化OBB迁移：可实施，已有小幅净收益

2026-11-17。已完成OSS2固定权重三臂、三个训练种子检查点的配对验证，无重训、无新检测、无阈值调整。迁移可靠极化OBB可恢复另一极化的区域证据，扩围OA有小幅净收益；BA基本持平，不能称全面优于全图回退。保留为输入补全候选，正式模型及数据缓存未改。

## 1. 坐标与输入事实

228条验证样本中22条只有一个极化被接入，378条既有扩围样本中30条如此。52条均有原始双极化图像，属于同产品、同裁剪窗口；PNG与各自源TIFF逐像素相等，双路网格大小一致。全部可进行原始chip坐标的角点迁移，无样本因坐标核对失败而剔除。

验证22条中恢复VV16条/VH6条；扩围30条中恢复VV18条/VH12条。保持可靠极化原框不变，复制其原始chip四角到另一极化，随后调用原有native160裁剪/补零及几何生成。未按OBB重新缩放目标。供框置信度保留来源，不冒充被补全极化的检测置信度。

002912的关闭原因已核实：VV检测置信度0.16855低于0.25，VH为0.55240；两路69×69原图都存在。原始四角迁移后，native160左/上各补46像素，右/下各45像素。没有重复应用检测画布偏移，也没有将已平移框当原图框再次平移。完整来源链保留本地COORDINATE_AUDIT_ZH.md。

## 2. 控制变量

| 输入策略 | 恢复像素及有效范围 | 恢复OBB区域/槽位 | 对原可靠极化的改变 |
|---|---|---|---|
| 原整体关闭 | 否 | 否 | 无 |
| 全图回退 | 是 | 否 | 无 |
| 跨极化迁移框 | 是 | 是 | 无 |

全图回退与迁移框的图像、有效范围、availability逐值相同；前者区域掩膜、槽位质量和回写掩膜为零。它仍运行原有不依赖OBB的类别响应处理和全局读出，不是单独替换成一个新GAP分类器。

采用上一轮验证选定的affine_frozen种子17/29/43，PCEA关时恢复原完整模型，开时测试其额外贡献。源参考32条、源归一化统计及所有权重固定，仅补全查询输入。当前是输入策略的机制验证，尚非训练、参考端同步补全后的新模型。

仅重算受影响样本及每个集合3条双有效控制，其余复用相同权重已有预测，保持228/378全队列分母。原路径最大logit重放误差6.29e-6、top1一致；原可靠极化各输入字段严格不变；三种策略对双有效控制结果一致。扩围集有历史暴露，本轮固定方案，不据结果再选阈值、检查点或框形状。

补充末端可用标记分解：利用固定线性分类头的最后两个系数，扣除恢复availability标记直接增加的logit项后，全图回退与迁移框在两队列、三个种子的top1全部不变。单独加可用标记项而不恢复图像，在seed29扩围有1救回/1误伤，其他条件无翻转。这排除了本轮整体收益仅由末端可用标记偏置造成的解释；不等于去掉整个网络中的可用性门控。记录见availability_term.json，无新增网络前向或训练。

## 4. 为什么OA提高而BA变化小

扩围迁移框相对关闭的三种子累计类内净增：散货+4、普通货-2、化学品/成品油轮+3、集装箱+2。类别基数分别132、26、83、137，因此少数普通货类两次误伤的平均召回损失更大。

平均类召回变化分别约+1.0101、-2.5641、+1.2048、+0.4866个百分点。其均值约+0.0344，解释了BA近乎不变。这是类别构成及具体翻转的算术分解，不是关于物理散射的因果解释。

## 5. PCEA是否因此获得了额外收益

迁移后，22/30条的双极化区域激活条件全部恢复，开启PCEA也确实改变logits；但在这些被补全样本上，三个种子的top1均与关闭PCEA相同，没有新增救回或误伤。

全队列原有PCEA效果保留：验证seed17的000414救回来自原先双有效样本；扩围seed43的002306误伤也来自原先双有效样本。迁移后的PCEA全队列OA65.2557、BA59.3668%，相对迁移框原完整模型仍略低。不能把输入恢复的收益归给新增调制机制。

因此已证实“原门控舍弃了可用分类信息”，尚未证实“此前PCEA缺乏收益仅因缺框”。

## 6. 真实案例与边界

本轮生成10张原图/迁移框/区域/合法参考对照面板，原图保持自身网格，模型输入160裁剪/补零。SVG可编辑，入口gallery/index.html。画框只代表迁移位置，不是精确船体轮廓。

- 002912/seed29/散货：原错分集装箱，分差-0.0101；恢复VV全图后+0.3352已救回；迁移框进一步至+1.1575。新PCEA为+1.1556，并非救回必要条件。
- 002831/seed29/散货：关闭-1.0247，全图-1.1470仍错；迁移框+1.6214救回。原chip中的目标响应接近右边界，框部分超出图像，区域按有效像素截断；迁移不能恢复原chip之外的信息。
- 000260/seed43/油轮：两极化中央短横亮结构可对应，右上另有亮响应。全图仍误判普通货，迁移区域后由-3.2421到+0.8032。仅支持区域组织在此例有用，不将右上亮响应直接判为邻船或虚影。
- 000240/seed17/集装箱：持续正确，恢复区域将分差从+0.5203提高到+4.9592；不是新增救回。
- 000316/seed17/油轮：迁移框覆盖中央短横亮条，仍错，只改变竞争类别；框落在亮结构上不保证有效分类。

## 7. 当前取舍与下一步

保留“可靠极化OBB跨极化补全”为可执行输入策略，同时保留全图回退对照；不替换正式模型，不删除旧结果。不同极化散射形态是否需要小范围框调整尚未验证，本轮不依据评价结果反向修改框。
