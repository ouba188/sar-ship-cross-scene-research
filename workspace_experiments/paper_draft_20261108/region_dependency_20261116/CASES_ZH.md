## 选择与显示

事先限定 VV/VH 侧向区域均值保持衰减、VV/VH 框内像素置换四种条件，在各条件的救回与误伤中选绝对分差变化居中的例子；另列 VH 侧向条件下持续对、持续错各一例。共10组，不是全部翻转比例。

图像不做各自拉伸，保持原生像素；仅为显示裁掉补零。差分使用每例标明的对称色标。绿、橙、蓝分别表示框内、轴端、侧向的诊断掩膜。参考图来自该查询实际允许使用的同类和原竞争类参考库，按固定顺序展示，不声称它们是贡献最大的参考。模型输入和参考编码均未更新。

## 1. 同一种侧向操作，能够救回，也能够误伤

### 集装箱船 000414：VV 侧向结构减弱后救回

- 原图 VV 可见一列沿斜轴排列的明亮响应，侧向附近较暗；VH 也保留了沿轴的亮响应。
- 只将 VV 蓝色侧向区域向自身均值靠近50%，框内、VH 和远处背景不变。差分主要位于船体两侧，并非整图变暗；侧向均值严格不变。
- 预测由散货船转为集装箱船，最强竞争分差 **-0.0339 → +0.2500**。
- 同一模型关闭 M1 反馈后：**-0.3777 → -0.0594**；关闭 M2 内部回写后：**-0.9029 → -0.5986**，均仍误判。
- 但关闭 M3 后原图已正确：**+0.6788 → +0.9718**；均匀区域权重也使原图正确。因此，本例不能当作所有模块均有益的例子。

**可确认的解释：**该例原有 VV 侧向局部起伏影响了类别竞争，输入操作和 M1/M2 路径共同决定能否越过决策边界。需要进一步分清：操作本身带来的约0.28分提升，在关闭 M1/M2 后仍约0.30分；救回消失主要来自原始分差下移，不能据此声称 M1/M2 专门识别并去除了该侧向干扰。

### 散货船 003672：VV 同样操作反而误伤

- 原图 VV 的目标亮响应范围很小，VH 沿轴的响应更明显；侧向操作只改变小片近邻像素。
- VV 侧向均值保持不变，最强竞争分差 **+0.2153 → -0.3415**，由散货船误判为集装箱船。
- 关闭 M3 时原图已错：**-0.4039 → -0.9863**，说明 M3 对该例原图提供正向帮助；这不等于 M3 能抵消所有局部证据破坏。
- 关闭 M2 内部回写后：**+0.9472 → +0.4241**，仍然正确。与上一例方向不同，不能把 M2 回写固定解释为总是增强正确类别。

**共同结论：**不能把侧向区域统称为无用杂波并统一削弱；它在不同样本上可能帮助或妨碍当前模型的类别竞争。图像不能单独说明这些响应具体来自海面、目标散射延伸还是其他成像因素。

## 2. VH 例子：作用存在，但不一定属于某个专门模块

普通货船 **003340**：图中目标呈斜向、两段较强响应，附近另有较弱的纵向延伸。只衰减 VH 侧向局部起伏，分差 **-0.5691 → +0.4316**，由化学品/成品油轮救回为普通货船。

四种路径替换后同样可救回：M1 反馈关 **-0.8661 → +0.1599**，M2 内部回写关 **-0.6437 → +0.3483**，均匀权重 **-0.5436 → +0.4984**，M3 关 **-0.5129 → +0.6411**。

因此，本例支持“VH 侧向结构能够影响判别”，但**不足以把改善归因于任何一个新增模块的独特机制**。也不能凭图中延伸外观直接称其为尾迹或运动效应。

散货船 **000947** 则相反：同样 VH 侧向操作使分差 **+0.6020 → -0.0890**，误判为化学品/成品油轮。相同极化和区域仍不保证作用方向一致。

## 3. 没有翻转也需要记录

- 散货船 **003461**：VV 图像有较长的斜向亮响应，VH 中强响应更集中；VH 侧向衰减后 **+2.1561 → +2.1682**，持续正确。该例分类不依赖本次操作改变的侧向起伏越过边界。
- 集装箱船 **003264**：目标较短，呈两个较强局部响应，VH 侧向衰减后 **-6.5683 → -6.1783**，持续误判为普通货船。局部操作虽使分差向正确方向移动，但不能纠正较大的既有类别混淆。仅增强该操作不是充分方案。

## 4. 直方图不变的置换不是可部署增强

集装箱船 **003624** 的 VV 框内置换保留每个灰度值及其数量，却把原来的紧凑局部响应打散成不自然的点状排列；分差 **-0.4254 → +2.8523**，由普通货船变为集装箱船。

这个救回只能说明模型对空间排列敏感，不能证明置换后的图像恢复了真实船体结构，也不能据此把随机置换加入正式训练。本轮保留相应误伤例子（003539 的 VV 框内置换、000468 的 VH 框内置换），防止只展示人为扰动后偶然判对的样本。

## 对模型设计的直接意义

1. 区域与极化分开诊断有必要：同一类操作并不对应统一方向。
2. 仅展示救回不足以验证模块机制。应同时检查模块关闭前后的原图分差，以及输入操作效应的差分之差。
3. 这批图像支持继续保留“船体和邻域分别组织证据”的研究问题，不支持直接宣称识别出了特定物理散射原因。
4. 救回、误伤及持续对错均保留在本地。总体效应应以全部228条、三个种子的分析表为准。
