# CCREL 到 PCEA 的联合读出与浅层残差验证

2026-11-16。已实现并完成7组有界训练：OSS2四类、719训练观测、228既有验证观测、32合法源参考、seed17，各4轮，共28轮840次优化。没有读取独立测试集，没有改正式模型、论文或24港模型。

## 结论

区域证据已经明确传入PCEA，读出投影与PCEA确实共同训练，真实layer1细特征残差也进入了计算。**工程目标完成，但本轮没有形成分类净收益。** 不能把“接通了、梯度正常、能改变分数”当成模块有效。

本轮定位到可修正的优化现象：按新分支同等学习率更新预训练读出时，证据出现明显整体漂移，PCEA主要产生共同类别偏移。降低读出学习率显著减轻漂移及无残差组退化，但仍没有优于起点；新增细特征残差也没有独立净收益。保留接口、配对实现和诊断，不升级权重。

## 实际计算路径

```text
原有CRFB类别响应及更新后的layer2特征 F2 [512,20,20]
                    |
             可训练512->32读出投影 -----------+
                    |                       |
layer1真实F1[256,40,40]                       |
 -> LN -> 可训练256->32 -> tanh              |
 -> 40到20面积对齐 -> 有界残差 --------------相加
                                            |
       CCREL：框内/轴端/侧向；均值+全部四类相对响应读出
                                            |
          E [B,2,3,5,32]，不截断梯度，显式传入PCEA
                                            |
       极化专属32->16 -> 联合门控/可选乘积 -> 区域回写
                                            |
          layer3[5].conv2前 [256,10,10] -> 原后续分类路径
```

细支路不是把10x10插值放大，也没有缩放原始chip。它在池化前补充更早层的内容，但最终仍形成区域摘要，**没有完整保留40x40的局部布局**。

用已有CRFB产生类别响应；本轮仅开放CCREL读出投影、新浅层投影和PCEA，响应生成器、骨干、旧区域路径、参考路径及分类头固定。CCREL是复用已有类别响应并学习区域证据的候选实现，不是宣称所有新M1参数已经联合训练。原RCEW仍读原参考描述；新RCCEW尚未在本轮重构。原训练历史保留，本轮没有重新执行教师干预选样。

### 核心运算

对极化p，投影值图为 Vp=Wp LN(F2p)。细支路为 Dp=AvgPool2(tanh(Bp LN(F1p))*valid40)，在区域读出前使用 Vp+=0.1 RMS(Vp) Dp。Bp零初始化，输入保持初始模型函数。

CCREL输出每区域一个均值槽和四个类别相对响应加权槽；候选类别全部计算，不使用查询标签选择槽。原生OBB、padding有效范围和极化可用性保持不变。

PCEA将E按固定初始源统计标准化后得到u、v，学习H=alphaVV*u+alphaVH*v+beta*(u*v)。各极化输出投影独立，按各自区域回写；任一极化不可用时新增联合更新为零。当前不是四项锚定差分版本。

## 哪些问题已定位

### 1. 不是没有连上、没有梯度

四种结构初始预测等于原模型；第二步读出投影、细投影和门控均有非零有限梯度。新增路径关闭后恢复原模型。查询layer1特征覆盖参考提取的临时hook状态，未发现参考串扰。检查点预测重放误差小于3e-6，top1一致。

### 2. 联合读出确实发生不利整体漂移

1e-3细支路组，恢复初始读出投影而保留已训练的PCEA/细支路/归一化：OA67.544 -> 68.421，BA61.374 -> 62.755，净恢复2条正确预测。

原读出与训练读出的验证token均值差，按固定初始源尺度计，VV船体6.461、VH船体4.653；各区域约4–7。双极化有效206条中，平均类别偏移占中心化分数变化平方能量86.99%，能事后复现206/206条最终预测。此事后均值不是合法部署校准器，更不证明所有图像差异都无价值。

学习率改为1e-5后，无细支路的对应船体漂移降至VV0.300、VH0.325，末轮从2救回4误伤改善为2救回2误伤。说明更新幅度是实质影响因素，但修正尚未带来净收益，不能认定为唯一根因。

### 3. 细残差已参与，但尚未补出有效分类差异

1e-3组关闭细残差，228条预测不变，logit变化RMS0.000183。不能说从未参与，因为更新和梯度均非零。

低读出学习率组关闭细残差，logit变化RMS增至0.01818，恢复1例散货正确预测，没有损失正确预测。这说明它现在有更明显的实际作用，但作用不等于收益。末轮有细支路2救回4误伤，无细支路2救回2误伤；这是配套训练对照，与固定权重撤除分开报告。

低学习率细支路组的平均类别偏移仍解释有效样本84.30%的分数变化能量，事后平均偏移复现205/206预测；门控样本标准差约0.0377。门控在变化，但最终多数变化仍类似共同类别偏移。

### 4. 乘积不是目前救回的必要因素

首轮细支路组去掉乘积反而恢复1条散货；低学习率细支路组去掉乘积没有预测变化。配套训练的独立极化没有被联合极化稳定超越。不能将两例集装箱救回直接归为跨极化交互的独立增益。
