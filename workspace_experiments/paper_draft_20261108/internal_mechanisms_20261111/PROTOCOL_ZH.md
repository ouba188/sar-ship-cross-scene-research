# 当前分阶段模型的内部机制消融

2026-11-11。正式模型不改，旧结果不覆盖。沿用OSS2四分类：719条训练、228条验证、378条测试，32个固定合法源参考；种子17/29/43。直接复用已完成Full三种子，不重跑共同的前置阶段。

## 要回答的问题

原图证据表明，查询和不同类参考都可能有相近的细长/紧凑亮结构，且VV/VH局部形态不同。已有当前训练链Full优于Plain，但No-M1/No-M3的BA并不低于Full，因而不能把系统收益全归于这两个模块。需要区分具体反馈与度量设计是否有增量，而不是新增结构。

本轮只检验当前条件下的反馈、度量和偏置。它不再次检验纯物理因果因素，也不承诺所有组正向。

## M1四格

| 配置 | 均值反馈 | 类别关系反馈 | 处理 |
|---|---|---|---|
| Full | 有 | 有 | 复用当前配套完整组 |
| m1_mean_only | 有 | 无 | 从对应seed的reference阶段结束检查点开始 |
| m1_relation_only | 无 | 有 | 同上 |
| m1_no_feedback | 无 | 无 | 同上 |

只将两条反馈在共同tanh之前的输出分别置零。保留共同输入、reader、均值中心化、类别辅助监督和M2类别引导接口。因此这些名称是“反馈支路有无”，不是删除所有均值统计或所有类别信息；no_feedback不等于既往整个No-M1。

重训反馈180步和最终读出180步，所有组沿用相同源样本顺序、参考、学习率、源标签监督和训练阶段；M2保持相同结构并配套训练末端读出。M3在该实验中沿用对应种子的已完成参考阶段，并按原协议冻结残差。

## M3四格

| 配置 | 学习通道度量 | 类别竞争偏置 | 处理 |
|---|---|---|---|
| Full | 有 | 有 | 复用当前配套完整组 |
| m3_metric_only | 有 | 无 | 从对应seed的intervention结束检查点开始 |
| m3_bias_only | 无，固定单位权重 | 有 | 同上 |
| m3_neither | 无，固定单位权重 | 无 | 同上 |

无通道度量通过将metric logits置零得到w=1；保留投影、值路径、局部聚合与回写维度。无偏置只关闭cost_competition，保持aggregate路径。不得使用历史shared开关同时改变两项。单位权重对照不同于历史“共享但仍学习的度量”，两者不混称。

参考阶段训练4轮共120步，随后反馈180步、读出180步，按原日程重放后缀；不借用新分支不对应的旧最终读出。源难例加权继续按各臂当阶段初始分差生成，规则和样本顺序相同，但数值权重未强制相同；该结果属于现有完整训练规则下的机制替换，不是固定逐样本损失权重的纯局部扰动。

## 历史复用边界

历史M1去协方差已有配套训练；历史M3共享度量、去偏置也已有三种子训练且未显示独立优势。这些记录保留，不称过去完全没做。本轮不重复历史载体，而补当前统一分阶段链的对应机制证据；不把历史和新链混合平均。

没有新增学习率、位置、次数或选轮搜索。验证不触发追加调参；完成预先确定训练预算后评价测试。历史测试已有研发暴露，不称全新盲测。

使用独立run.py的前向钩子，不修改正式模块源码。先检查原Full重放、M1支路公式、M3单位权重及零偏置是否真正生效。预检查通过：Full验证子集最大误差0；三种M1公式误差0；M3对应开关及有限性通过。
