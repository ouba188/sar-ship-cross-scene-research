# M3固定模型个体反事实证据分析

2026-11-12。计算图内的证据替换，不是物理成像过程的反事实生成；不训练、不调参、不替换正式模型。

## 研究问题

同一张图、同一组参考和同一套权重下，M3提供的补充是否改变正确类别与竞争类的关系？如果撤除特定极化或区域补充、替换比较规则，已经出现的判对是否仍成立？

第一轮复用OSS2四分类Full-Tuned，固定种子17/29/43、378张测试图、32个源参考、原可用极化。三个训练种子是同一批测试船的重复模型，不是三个独立测试集。24港训练正在进行，本轮不占GPU、不修改其队列。

## 实际计算路径

当前staged.forward调用matcher(..., arm='aggregate')。先计算类条件通道度量、类别竞争、带空槽的运输及参考权重；回写时使用原运输行列质量的独立外积，而不是原精细槽位运输矩阵。因此不得把本轮解释为已经证明精细软匹配优于简单聚合。

事实路径为 x = h + delta，随后同时进入layer4全局读出与深层区域读出，再进入完整分类头。h为layer3最后block输出；delta是M3回写。M1响应、浅层区域描述、参考标签和可用性均保持不变。反事实将delta替换为明确的delta_cf，重新计算两个下游读出及分类头。

## 预先固定的操作

| 名称 | 操作 | 可支持的判断 |
|---|---|---|
| factual | 原始aggregate路径 | 事实预测 |
| no_m3 | 所有M3回写置零 | 个体判断是否依赖M3补充 |
| no_vv/no_vh | 仅撤除对应极化的M3回写，不删除图像极化 | 补充的极化依赖 |
| no_body/no_side/no_ends | 原消息按20个槽位的8/8/4身份分解，移除对应部分再回写 | 补充的区域依赖 |
| unit_metric | 度量网络输出设零，令通道权重为1；重新计算所有后继 | 学到的通道度量作用 |
| no_competition | 只将类别竞争代价项设零，保留度量及源类别 | 竞争代价作用 |
| simple_mean | 同编码器、参考和输出投影，区域内按原参考质量均值，再按类内合法参考等权均值，单位通道度量 | 整套条件组织相对简单类别均值的作用，不能单独归因于一个内部步骤 |

simple_mean对每类分别聚合，不用查询真值选参考。每个参考区域先归一化，避免大船及大区域自动拥有更多参考票数；缺失类别/区域/极化及身份、轨道合法性沿用原路径。该替代同时撤除度量、竞争与内容相关权重，因此必须与两项单独替代联合解释。

区域操作在类别消息进入1x1输出投影之前分解；不遮挡原图，不在重叠的最后特征图上画硬掩膜。三部分投影之和须恢复完整delta。无M3必须重算layer4、深层区域描述和最终头，不直接修改最终logit。零步同样本重放以及no_m3与原forward开关等价检查通过后才扩围。

## 评价与案例

全部测试图统一执行，不按结果挑选参数或模型。逐种子报告OA、BA、正确类别对最强错误类别的分差、救回和误伤；分离同权重no_m3到factual的翻转与独立Plain到Full的翻转。对M3救回集报告各替代操作撤除救回的数量；这个条件统计不当成总体收益。

案例覆盖救回、误伤、持续判对和持续判错。VV/VH分开展示，原生裁剪/补边保留尺度；查看实际合法同类及竞争类参考。图像可见事实、计算图操作的后果和物理解释分别记录。没有翻转或精细操作未优于简单方案的结果如实保留。

## 与因果层级的关系

本轮明确计算图和固定样本状态，对内部变量施加替代并重算后继，属于模型决策层面的个体反事实分析。仍是对同一模型开展的受控操作，不构成新的独立物理因果证据，也不等同于真实改变入射角、风浪或航速的成像反事实。归零可能偏离训练分布，故同时提供保留非零参考信息的简单均值替代；内部作用证据仍不能替代配套重训的模块消融。
