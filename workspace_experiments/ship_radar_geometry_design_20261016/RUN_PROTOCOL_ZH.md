# 本轮执行口径

2026-10-16，先于新增目标结果冻结。承接 NEXT_ROUND_PLAN_ZH.md。

- 使用现有五个独立留港源池，不合并。复用 ring_relaxed/query_coverage 的 B32 单跨采集支持与全部合法查询；源端 module_fit/selection 边界不变。
- 统一 B32 训练；目标 B16/B64 是支持预算迁移边界，不称匹配预算训练。无需为了三个预算分别拟合十五套任务定义。
- 每个区域在其可见包围范围内用图像坐标 4x4 网格划分，最多16个单元。实际非空数另存。每个单元存64通道冻结R18 stem均值、真实位置重心、面积；不是整圈四维统计，也不扩大裁片物理范围。
- 区域沿用框内、膨胀0-2、2-8、8-16。面积只用于区域内聚合，三个邻域分别摘要后等权；图像方向、坐标、像素与内容在 A/B/C 中一致。
- 局部模块64维、4头。A图像关系，B聚合后角度输入，C船轴/雷达轴内容位置交互。B/C得到完全相同的角度和有效标记。船轴180度对称处理。
- 实际恢复发现雷达缓存同样是无向轴：B使用两倍角正余弦，C使用保留距离的两倍相对角坐标 `(u^2-v^2,2uv)/sqrt(u^2+v^2)`，而非伪造有向距离/方位坐标。船轴仍做双向完整注意力对称聚合。A/B首次20步仅为接入试跑，其中B发生在此修正前；正式训练全部使用修正后的相同角度定义。
- 冻结全局表征、类别关系、源先验以及支持求解常数。保留船体64维与新邻域64维各半的局部核，SS/QS均重算，支持系数重解。
- 主试验种子0/1/2，每种方法每池200更新，AdamW(lr=0.001,weight_decay=0.0001)，每次2个源任务，任务内最多32个查询，随机抽样而非永久只取前8个查询，不保证有限步内每个样本都被抽到。源任务先等概率取港、再取查询采集、再取支持任务。各方法同种子共享采样序列。
- 检查点0/50/100/200。只按源selection等港等查询采集BA选择，平手依次按宏NLL和较早步数。目标不选检查点。另存末步模型和源曲线，区分学到与选中。
- 先做20步源端接入试跑，不作为效果结论。必要纠错保留记录；不依据目标反馈改结构或训练预算。
- 目标沿用490个现有任务，5次支持抽样；训练种子和支持抽样分开统计。body/multiring/half-body用相同任务对比，body重算核对已有缓存。
- 报告完整队列、几何有效配对子集、逐港/逐类、检索与概率风险、救回/误伤以及计算成本。历史研发队列不称独立确认，不要求同场景无收益。

本轮不重训QSRG，不扩公开集，不加入AIS速度/吃水等预测输入。坐标代理与缺失边界以 geometry_metadata.py 的实际恢复报告为准。
