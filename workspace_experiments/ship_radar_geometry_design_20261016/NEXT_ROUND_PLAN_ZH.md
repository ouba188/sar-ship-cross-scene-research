# 下一轮：面向跨采集分类的几何条件化局部读取

日期：2026-10-16。本文件保留训练前的设计方案；该轮现已实施并完成，实际执行口径见RUN_PROTOCOL_ZH.md，结果及机制诊断见FINDINGS_ZH.md。承接LITERATURE_AND_DESIGN_ZH.md，不自动开展全部候选因素。

## 1. 唯一主问题

在相同SAR内容、支持标签预算和完整分类流程下，把局部证据放在船体—雷达相对坐标中解释，是否比普通空间读取及角度直接输入更有利于跨采集船型识别？

待检验机制：跨采集变化使某些同类局部证据的位置与呈现难以直接对应；几何条件化读取可能改善同类支持关系，同时不牺牲异类区分。已有多区域收益只支持存在邻域信息价值，尚不证明这个几何机制。

本轮不做独立测速、吃水回归、尾迹检测或大气补偿，不扩大公开数据集，不重训旧QSRG，不追加第三个分类器。对这些字段有针对性的诊断可保留，不因能够恢复字段就增加学习任务。

## 2. 数据先行，但不重新全量审计

复用当前五港合法source pools、fit/selection边界和已有B16/B32/B64查询支持任务。先统计每个池实际可用于训练的不同船、采集、类别与几何覆盖，尤其注意当前有效相对方向少于入射角覆盖。不同held-port池不可混合训练，避免其他池源端包含本池留出目标。

对原有查询/支持建立统一sample_id关联，处理图像缩放、像元尺度及方向参考系；船轴沿用或改进SAR估计，不把AIS COG/真艏向作为预测必要输入。当前地距轴只能称雷达方向代理；只有完成更准确恢复后才更改命名。

角度可靠子集用于检验机制；同一完整队列用于报告实际覆盖下的效果。所有方法在相同子集配对，不以删除困难缺失样本制造收益。缺失提供mask并退回内容/图像关系，不能当0度。记录截断，缺少真实尺度时不伪造米制距离。

B32作为既有邻域正信号的研发主工作点，明确这是历史探索选择；B16/B64保留为预算边界，不将不同预算不同查询队列的均值差直接解释成预算因果效应。跨预算趋势以共有查询子集辅助比较。不根据本轮目标结果挑港口、角度阈值或模型版本。

## 3. 一个有明确职责的模块

### 3.1 保留局部内容

从同一冻结骨干的早期空间特征图读取船框内及贴框/近邻/较远邻域局部token。复用当前多区域可见范围作为受控实验范围，而不是宣称2/8/16膨胀是物理最优。每个token保留其局部内容、位置、区域归属与有效覆盖，不先整圈平均成4个数。

抽取网格对所有方法完全相同，不因为换坐标就改变采样像素。控制每区token数及有效面积权重，避免远区面积大便自动占更大权重。具体网格密度由有效船体空间单元和覆盖预检确定，随后在源端冻结；不得为目标结果调整。可缓存冻结浅层图，新增的是空间信息缓存，而不是从旧4维统计中重建位置。

### 3.2 几何交互，而非角度常数偏置

船体token作为attention query，邻域token作为key/value。对局部单元对(i,j)计算船轴坐标位移及雷达距离/方位坐标位移，再结合入射角与有效性形成关系向量r_ij。

候选注意力打分：

    e_ij = (q_i dot k_j + q_i dot r_ij) / sqrt(d)

r_ij由局部位移和角度条件的非线性映射产生。同一邻域响应在不同相对位置/几何条件下可被不同读取；不能仅对所有键加同一角度偏置。方法借鉴iRPE的content-relative-position交互，不宣称这种通用运算本身原创。

初始规模采用一层64维、4头交叉注意力和小型关系映射，目的是学习目标关系而非堆大型Transformer。所有学习对照采用相同内容投影、输出维度和训练机会；角度直接输入的映射容量尽量对齐，并报告剩余参数差异。固定船体token负责提供内容查询，避免仅学习“某个场景角度对应某类”。

船轴仅有180度无向信息时，对theta和theta+pi两种编码进行共享处理与对称聚合；低置信或缺失方向采用图像关系路径。不是强制所有真实观测变化不变，也不声称冻结CNN已严格旋转等变。

### 3.3 输出接现有local接口

每个区域先形成船体条件化的邻域摘要，再在区域层聚合成单位化的64维c_theta；保留原单位化64维船体向量b直通。第一轮桥接表示为：

    L_theta = concat(sqrt(0.5)*b, sqrt(0.5)*c_theta)

这是为了保持既有局部核的范数和船体/邻域剂量，不能把最后的拼接称为创新；真实改动在c_theta内部的内容—几何交互。仅拼接未交互的坐标与统计不属于本设计。失效/缺失区域使用有效mask及内容路径，不做无效向量单位化。

L_theta进入body_context_gate.py::readout，替换原local，SS/QS同步构造，重新求解支持残差。保留原局部替换比例0.25、设计尺度16、类别关系混合0.75/0.25、ridge8与基础/专家概率等权融合，先不把倍率调整和新表示同时优化。已有body_half对照复用，用于解释剂量变化。

## 4. 紧凑对照

| 方案 | 内容/位置/条件 | 回答的问题 |
| --- | --- | --- |
| 已有完整body与multiring | 复用冻结结果与同样本任务 | 是否超过真正已有方案，而非弱基线 |
| A 普通局部读取 | 同一空间token、图像相对位置；无物理角度 | 局部细节和可学习读取本身提供多少收益 |
| B 角度直接输入 | A的局部聚合后用角度及mask调制；不改变token关系 | 额外角度属性是否已经足够 |
| C 双坐标条件关系 | 相同token，几何作用于内容—位置交互 | 所提关系组织是否有超出A/B的价值 |

A/B/C必须共享像素范围、输出维数、支持任务、信息有效子集与源端优化机会。B和C使用同一角度信息；不能以B只能得到少量字段而C获得完整几何制造不公平优势。

若C相对B出现净收益，再增加一项有针对性的船轴单坐标替换或坐标扰动，定位雷达坐标附加贡献；不是一开始铺开大网格。基础RoPE可作为后续合理位置替换对照，不是本轮必须新增所有变体。

## 5. 按完整管线训练

源端合法跨采集episode：支持来自一采集、查询来自另一采集，船只身份互斥，尽量匹配目标支持组织。按支持预算分层采样；缺少合法材料的预算如实标明，不靠重复行数假装独立监督充足。

源端查询标签用于最终分类损失，目标查询标签不用来训练或挑参数。初轮沿用完整概率上的类别平衡交叉熵，并同时记录OA/BA和概率风险，不额外堆角度/对比/重建损失。先确认在既有完整求解器内有可利用收益，随后才考虑辅助目标。

梯度经过局部编码、SS/QS构造和支持线性求解；基础/专家全局编码、源先验、原类别关系项冻结。不要缓存旧专家支持系数来代替新表示求解，也不能用NumPy路径训练使梯度断开。

先完成一份源端端到端接入及短程训练，目的是发现梯度/容量/数据不足等实际问题。正式对照采用3个真实训练随机种子、同一源端选择规则；目标端再沿用五次配对支持抽样。这两种随机性分别报告。没有额外大规模源端调参或目标标签选优。

## 6. 评价闭环与后续决策

- 任务效果：完整模型跨采集OA/BA、逐港及逐类净贡献、不同支持预算/抽样波动、实际新增适配与推断开销。主要新增贡献对比C-B，同时报告对A和已有最佳合理基线。
- 信息效果：同一支持库的跨采集同类检索、真实类相对异类证据优势、支持核风险变化。支持缺类单列覆盖，不把不可定义检索指标填0或静默丢失。
- 机制效果：在几何可靠/不可靠、邻域截断/未截断、不同类对上追溯救回与误伤；正反例一起查看。坐标干预只检验模型依赖，不等于真实物理干预。几何相似不等于类别相似。

接受条件：明确跨场景范围内有可重复且值得成本的完整净收益，不要求各港/各类/每次抽样都赢，不因同场景也涨而否定。历史开发数据上的结果标为研发证据，不称独立确认。

结果分支：

1. C优于A/B且完整系统受益：保留几何关系候选，随后才在新端点上重建QSRG监督。
2. A有效、C无额外收益：保留局部内容改进，不包装几何创新；检查方向质量/坐标/梯度与监督后决定是否改进，不无限加因素。
3. C中间类别关系改善但最终持平：记录真实中间进展，定位核尺度、支持残差或融合造成的兑现问题；不直接宣称完整分类有效。
4. 只有运动证据可见且视野充分的一组有收益：可接受这一范围；只有该组证据支持时再设计偏移走廊，不自动启动测速/尾迹大项目。
