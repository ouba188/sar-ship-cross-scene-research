# 跨场景与跨数据集严格试点：补齐后的结论

2026-10-14。本报告以**第二路相对第一路的作用**为核心；补齐的是已冻结任务的小验证，不是23港全覆盖或论文完整模型的最终确认。详细协议见 [实验设计](EXPERIMENT_DESIGN_ZH.md)，逐样本及训练记录见各子目录。

所有单/双路在每个任务里共用查询和该抽样的支持。第一路为 G50 单骨干紧凑读出；第二路分别用普通 ImageNet R18 (`G18`) 和合法源 SAR 自监督 R18 (`D18`)。表内“加第二路”指 `0.5×G50单路 + 0.5×G50/R18联合头` 概率融合，且两者各自重新拟合源头和支持残差。**不含历史 C4、学习类别关系和完整预算交接模块。** BA 只平均该折实际出现的查询类，跨行分母不同，不将局部5类 BA 当八类 BA。

这批结果**不能**写成“G50负责同场景、R18负责跨场景”：同/异采集都可涨跌，OSS2 同采集甚至为负。它支持一个较窄的结论：第二路在部分任务有相对互补作用，且强度依赖目标支持组成和读出；不能仅以第二路单路是否超过G50判定其价值。F/24港查询很小且类别不全，五抽样仍复用同一批船；OSS2一类查询只有1张，局部BA会被单张翻转明显放大。OSS1虽有局部收益，但其源验证BA从初始26.57%降至所选正训练轮20.82%；如果允许“完全不继续SSL”作为源端选项，此折会选择普通R18，故**现有源端选模不能可靠选出这次目标收益**。OSS1异采集晚融合仅比普通R18晚融合高1.25点，远小于联合头改善。

新增的四场景支持抽样保留原第0次结果，新增1至4次时固定查询、支持类别顺序和两来源的逐类配额；`freeze_repeated_support.py` 冻结清单，`evaluate_pilot.py --repeated` 输出新指标。第0次与旧单抽样报告 OA/BA 逐项一致。原 [一抽样阶段报告](PILOT_FINDINGS_ZH.md) 留作研发记录，不再用其单次成绩概括五抽样结果。

## 真正跨数据集：统一24港源模型

统一24港源池28,854张，源SSL训练14,659、源验证5,829张；与两个外部队列的已知MMSI和完整采集均不交叉。目标0张进入SSL或源端选模。下表固定八类查询，B16/B64为五抽样均值，OA/BA均为百分比。

| 目标 | B | G50 OA/BA | +G18 OA/BA | +D18 OA/BA | D18相对G50 BA |
| --- | ---: | ---: | ---: | ---: | ---: |
| F_0921 | 0 | 33.71 / 24.13 | 33.69 / 23.42 | 35.00 / 21.35 | -2.78 |
| F_0921 | 16 | 32.31 / 20.59 | 34.42 / 20.50 | 34.31 / 20.51 | -0.08 |
| F_0921 | 64 | 32.78 / 23.00 | 34.36 / 23.37 | 35.11 / 23.58 | +0.58 (3/5) |
| OSS2 | 0 | 20.72 / 18.98 | 23.67 / 20.54 | 19.61 / 17.29 | -1.70 |
| OSS2 | 16 | 34.40 / 22.64 | 35.59 / 23.38 | 36.28 / 24.01 | +1.37 (5/5) |
| OSS2 | 64 | 38.42 / 26.95 | 41.33 / 28.84 | 40.62 / 28.63 | +1.68 (5/5) |

在统一24港→OSS2任务中，D18双路相对G50单路，B16/B64 的 OA 也分别+1.87/+2.20点；这符合“第二路提供互补”而非“第二路必须单独更强”。但是 B64 的普通R18双路 BA 28.84% 略高于源域SSL双路28.63%；**源域SSL这种第二路本身的必要性尚未立住**。F B64 OA+2.34点，BA仅+0.58：五抽样累计正确救回净数集中于类0与类4，而类1/2净受损，类别均衡收益被抵消。跨预算支持类别构成不同，不把 B64-B16 当纯数量效应。详细类别、救回/误伤和条件bootstrap见 [跨数据集报告](cross_dataset/FINDINGS_ZH.md)。

## 结论边界

当前小验证已补齐四个中低分辨率 SAR 队列的合法源端留采集试点、F/24港原定场景的五抽样，以及24港→F/OSS2的统一源模型。**确认的是有范围的相对互补收益，不是“任何场景双骨干都胜”或“SAR自监督必胜普通第二路”。** 对 F/24港局部折、OSS1单折和OSS2单折，不可把支持抽样当独立采集；当前只有一个源训练种子。完整C4/类别关系/预算交接和同成本强单骨干仍未在此新协议下重建，故本轮不能替代论文完整模型主表。旧开发语料重新分折也不等于从未接触的外部确认集。
