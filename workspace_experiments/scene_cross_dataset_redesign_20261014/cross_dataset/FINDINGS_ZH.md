# 统一24港源模型到F_0921/OSS2：严格源域自监督试点

2026-10-14。此项补齐 [总协议](../EXPERIMENT_DESIGN_ZH.md) 中的核心跨数据集方向，并把**第二路相对第一路的净增量**作为主要对照。查询及支持抽样复用 2026-10-13 已冻结的 `external_scene_transfer_20261013/ENROLLMENT.json`；这是研发语料上的新训练协议，不是全新独立外测。

## 训练与评价边界

- 统一24港源池 28,854 张，八类齐全；与 F_0921/OSS2 已知 MMSI、完整采集均无交叉。`train_source_r18.py` 再按完整采集划源训练14,659、源验证5,829张，跨两者重复 MMSI 从训练侧排除；源验证八类齐全。未进入源SSL的其余合法源行，仍可在选定骨干后参与共同源PCA/分类头拟合。
- R18 只用14,659张24港源裁片做两轮 SimCLR，源验证512维 ridge BA 从初始化44.57%升至所选第2轮47.87%。目标图像0张进入SSL；目标查询标签不参与选模。R50、普通R18、源域自监督R18均重提特征，PCA128和全部源分类头只由上述28,854张合法源池拟合；同一查询/支持在每种模型下重新求支持残差。
- 目标固定八类查询：F_0921 4,654张/船，OSS2 811张/船。每个数据集固定 B0、随机目标支持 B16/B64，各五次支持抽样；每个预算内 G50 单路、普通R18双路、源域自监督R18双路用**完全相同**的查询和支持。下表双路采用 `0.5×G50头 + 0.5×双路头` 的概率融合；这是紧凑 RGB/PCA/ridge 读出，不含 C4、学习类别关系和完整交接模块。
- 样本ID与三套像素缓存顺序已逐行核对。详情及重跑入口：`train_source_r18.py`、`evaluate_external.py`、`analyze_relative.py`，原始 `external_metrics.csv`、`external_predictions.csv` 与 `relative_*.csv`。

## 主要结果：第一路单独 vs 加第二路

OA/BA 单位为百分比；B16/B64 为同一批查询的五次支持抽样均值，不是五个独立训练/测试集。

| 目标 | 预算 | G50单路 OA/BA | +普通R18 OA/BA | +源域SSL R18 OA/BA | SSL双路-G50 BA |
| --- | ---: | ---: | ---: | ---: | ---: |
| F_0921 | 0 | 33.71 / 24.13 | 33.69 / 23.42 | 35.00 / 21.35 | -2.78 |
| F_0921 | 16 | 32.31 / 20.59 | 34.42 / 20.50 | 34.31 / 20.51 | -0.08 |
| F_0921 | 64 | 32.78 / 23.00 | 34.36 / 23.37 | 35.11 / 23.58 | +0.58 |
| OSS2 | 0 | 20.72 / 18.98 | 23.67 / 20.54 | 19.61 / 17.29 | -1.70 |
| OSS2 | 16 | 34.40 / 22.64 | 35.59 / 23.38 | 36.28 / 24.01 | +1.37 |
| OSS2 | 64 | 38.42 / 26.95 | 41.33 / 28.84 | 40.62 / 28.63 | +1.68 |

**相对第一路，第二路在有目标支持时有可测的互补作用，尤其OSS2。** OSS2 B16/B64 的 SSL 双路-单路 BA 在5/5次支持抽样均为正，平均分别+1.37/+1.68点，OA分别+1.87/+2.20点；相同查询上 B16 计救回192、误伤116次，B64计救回186、误伤97次。这里每张查询最多重复五次，不能把计数当独立船数。

**“第二路有用”与“源域SSL R18优于普通R18”不是一回事。** OSS2 B16 SSL双路BA比普通R18双路高0.63点，但B64反低0.21点；F B64仅高0.21点。F B16 SSL双路-单路 BA 五抽样仅3/5为正、均值-0.08；B64也是3/5为正、均值+0.58。零支持条件下 SSL 双路的BA在两数据集都低于G50单路，不能讲成无条件泛化优势。

## 数据层面的解释范围

- F 查询类计数 `[1865,87,383,719,788,481,282,49]`；B16随机支持五抽样中类7始终缺失，类6只有两抽样出现，其他类也不均衡。F B64 的 SSL 双路相对G50单路五次合计救回1335、误伤791，OA +2.34点；但救回净数主要在类0、4（分别+387、+164次），类1、2分别净损失14、28次，八类等权BA只+0.58点。**这证明了类别取舍的存在，不证明某个具体散射因素已经分离出来。**
- OSS2 查询类计数 `[189,138,75,154,188,35,18,14]`；B16随机支持也经常缺类7，B64有的抽样仍缺少类6/7。尽管如此，同预算配对的双路增量在五抽样均正，说明并非仅由某一次支持抽样偶然驱动；但固定的是一批查询船，不能把五次抽样当五个独立跨数据集复现。
- 按查询船在各类别内配对bootstrap、条件于**当前唯一源训练与固定五抽样**，SSL双路相对G50的 BA 增量区间：F B64约 `[+0.02,+1.16]` 点，OSS2 B16 `[+0.72,+2.10]`、B64 `[+0.82,+2.64]`。这只量化查询抽样不确定性，未覆盖换源训练种子、换采集或外部数据集的波动；F下界贴近零。
- B0→B16/B64 不是纯标签数量效应：支持类别组成也同时改变。跨预算不据此推断“64必然更合适”；本表的公平比较是**每一预算内部、同一支持下各模型的相对差**。

## 现阶段能写与不能写

可以写：在明确的24港→OSS2八类闭集迁移、目标有16或64个随机支持案例的范围内，第二路提供了相对G50单路可重复的**配对净收益**；24港→F的B64有小幅OA/BA收益，但BA不够稳。不能写：源域自监督R18普遍优于普通R18、第二路对应唯一物理机制、双骨干优于任何同成本强单骨干、或完整模型已在新协议下确认。后几项仍需同成本强单路、完整管线与独立源训练重复；本轮没有用目标结果选择模型或改超参。
