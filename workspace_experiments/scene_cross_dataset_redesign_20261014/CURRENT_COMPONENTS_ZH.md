# 当前值得保留的组件与论文主线

日期：2026-10-15。基于 OSS1/OSS2 各四个严格留采集折、24港语料六个严格留港/八个查询场景，以及此前的 F_0921 和类别关系专项实验。此文是**模型取舍记录**，不是新训练结果，也不修改历史预测或旧论文稿件。

## 结论先行

**当前默认完整模型：**SAR 裁片 -> 冻结 R50 的 C4 基础表示，以及原视图 R50 + 仅以合法源裁片自监督训练的 R18 专家表示 -> 源数据拟合的 PCA/分类先验 -> 两头使用同一组少量目标标注支持案例，以类平衡、源先验锚定的残差求解分别修正 -> 两头概率各 0.5、全量融合 -> 八类闭集输出。目标支持预算记为 `B`，不固定解释成64；本轮严格扩围的实测工作点是 `B=16`。无目标标签的查询不参与源预训练或模块选择。

**不再研发或宣传 5% 输出交接。** 它与支持标签预算是不同概念；两路先对全部查询提特征，5%只改变最终采用修正的比例，并无本轮总体准确率或算力优势。旧结果保留在主表作边界对照，不从数据文件或历史记录中删除。原论文若以“预算化专家交接”为题，需要把预算明确改指**目标标注/支持预算**，或调整标题与中心论点，不能沿用5%交接带来的效率叙事。

## 不进入后续主线

- **5%预算交接：**按用户决定停止后续研发，旧对照留档。六港相对学习关系全量融合的同/异采集 BA -2.01/-0.55；目标问题转向标签受限的支持适配，而非限制输出交接率。
- **基于置信度的自适应输出交接：**当前不进主线，也不主动追加实验；六港相对学习关系全量融合的同/异采集 BA -0.59/+0.00。目前缺乏稳定独立收益，但不把此结论扩大为所有可能的自适应方法均无效。
- **为凑模块而新增注意力、门控、纯因果因素分离：**此前没有形成足以支撑统一主表的独立净增益或可解释机制；不因为需要“三四个模块”就重启。
- **按目标测试结果拼接每个数据集最佳分支：**仅可作诊断上界，不是可部署模型。

## 论文可以立住的结构

目前能讲的不是“四个各自首创模块”，而是一条有证据的机制链：**跨场景时当前单路读出存在可补充的判别缺口 -> 合法源训练的第二路带来互补预测 -> 少量目标支持在保留源先验的条件下修正两路 -> 简单融合兑现系统收益；类别参照可能在跨采集支持时改善案例关系，但有数据边界。** 双路、PCA、岭回归、C4 或等权平均单项均不应被写成独立原创。论文贡献更适合围绕严格源/目标隔离下的组合问题、支持关系的条件性改进，以及逐港逐类/支持抽样的机制证据组织。

本轮能稳妥写的核心 Claim 是“该组合在指定严格跨场景任务中有相对单路的净收益”；不能写“任意第二路都不如 SAR-R18”“任何强单骨干都做不到”或“已经找到纯因果跨域不变量”。下一轮若只做一个关键对照，优先在同协议下训练计算预算相当的强单骨干，并按查询类别/支持覆盖检查双路救回与新增错误；这直接决定第二路的论文说服力。所有范围仍是开发性数据，五次支持抽样不等于五个神经网络种子。
