# 显式去偏子特征：当前统一候选

2026-11-19。用户授权依据CausalDRL改造代码。接入、单元测试及真实源图两步更新检查完成；没有执行正式训练或目标集评价，不能据此宣称获得因果表征或分类提升。正式论文模型/已报告权重不变。

## 1. 依据与改动

参考Zhang等，Causal Disentangled Representation Learning for SAR Target Classification With Spurious Correlations，TAES 62 (2026)，DOI 10.1109/TAES.2025.3642882，第6–8页。阅读与差异记录见`paper_draft_20261108/literature_intervention_supervision_20261118/CAUSALDRL_TRANSFER_ZH.md`。作者仓库目前没有完整模型实现，本实现是论文启发的任务适配，不是官方实现复现，也不单独主张此分离方法为原创。

保留既有原生40/20分辨率读出、M1/M2、CCREL/PCEA、28个粗细候选及新M3完整匹配/正反轴比较。在所有这些路径分叉前，即共享ResNet-50的layer1输出，加入每极化独立、跨样本及空间位置共享的通道掩码：

    F_c = F * M_p
    F_b = F * (1 - M_p)

输入F为B×2×256×40×40，默认每极化保留128通道。512个可训练mask score，以确定性top-k产生二值掩码，训练使用sigmoid直通梯度；训练和推理的前向均为硬掩码。比例可通过keep-ratio设置并随checkpoint保存。不是按OBB直接剪掉框外，也不预先把VV、VH、轴端、侧向定义为偏差。

为何放在这里：当前layer1直接进入浅层M3细节读出，layer2输出同时进入CCREL/PCEA及深层残差主干；若只分离末层，早期细节与全局旁路会绕过约束。此处是当前工程覆盖全部图像特征路径的最小公共截点，不是位置最优性结论。几何、有效范围、源参考标签等非图像输入依然使用；本改造不声称消除了这些信息可能产生的偏差。

## 2. 三条训练路径

所有路径使用同一个完整下游分类网络，不新增一个容易单独退化的弱bias分类头。

1. 判别路径：F_c进入所有后续模块，优化原真标签CE及原极化辅助CE（0.02）。最终推理仅走此路径。
2. 特征替换路径：保留当前样本F_c，加入另一样本F_b，要求预测分布接近当前F_c路径的停止梯度预测。只在VV/VH可用模式相同的样本间置换，排除无供体的单例；供体与接收者真实图像有效范围的交集之外不注入。供体选择不使用标签，不使用测试样本。
3. 偏差路径：仅F_b进入同一个下游网络，预测受源训练集有效类别先验约束。先验按实际分类权重汇总，而不是取当前小batch比例，避免单类batch把bias训练成真类别预测。

记完整分类器为f，源参考始终由当前F_c实时编码：

    L = L_cls(f(F_c), y) + lambda_cf MSE(softmax(f(F_c+F_b_donor)), stopgrad(softmax(f(F_c))))
        + lambda_b CE(prior_source, f(F_b))

上式省略有效范围交集和0.02极化辅助CE。默认lambda_cf=1、lambda_b=0.5，先30步分类热身，再30步线性引入辅助目标。不是已调优的权重。F_b供体及参考分支不停止梯度，三条路径共同训练骨干、模块和分离层；只是概率目标停止梯度。三次独立计算图反向后统一裁剪和更新，不在中间更新参数。

这只是特征空间替换，不是物理SAR图像合成，也没有宣称不同船姿的同网格位置已经物理配准。没有照搬论文含歧义的反向组合目标，不要求换入异类判别分量后仍预测原类别。

## 3. 参考路径与旧干预训练

- M3查询、key/value及PCEA source_raw均由经过分离的特征生成；每次前向重编码固定16张合法源参考，参数更新后不使用旧raw参考缓存。
- 候选偏差辅助路径也使用同一份因果参考编码规则，参考不因查询分支变为bias；它检验的是bias查询在固定参考系统中的可判别性，不等同无条件单向量探针。
- 旧输入干预选样、分差保护代码全部保留在matched_run.py，不沿用其旧教师bank给新掩码强行监督。
- 本候选首轮训练默认只增加上述分离/替换约束，目的是单独检验它；没有把旧干预监督也混入而掩盖贡献。后续若要联合旧选样，需要对训练后的新模型重新测量。

## 4. 文件与使用

- `causal_split.py`：互补掩码、供体组织、三类损失及源先验。
- `causal_model.py`：继承分离前统一模型，在layer1公共输出切入。
- `causal_run.py`：源端训练、热身/渐进约束、验证选模与checkpoint。
- `unified_run.py`：当前默认入口，转到causal_run；默认执行有界实现检查，不启动完整实验。
- `test_causal_split.py`：独立算子测试。
- `verify_causal.py`：真实源图全路径与两步更新检查、原图面板。
- `verify_causal_training.py`：实际训练入口检查，8源训练查询、4源验证查询，两步热身/联合优化，保存并在新实例加载。

在当前目录的ClearSAR环境中执行：

```powershell
python -B -X utf8 -m unittest test_causal_split -v
python -B -X utf8 unified_run.py --phase verify
python -B -X utf8 unified_run.py --phase train --arm baseline --seed 17
python -B -X utf8 unified_run.py --phase train --arm split_ce --seed 17
python -B -X utf8 unified_run.py --phase train --arm causal --seed 17
```

后三条本轮未执行。三组使用相同历史起点、源划分、源查询顺序、增强码、16参考及优化步数。baseline保留全部通道，只用分类训练；split_ce使用可学习分离但不加替换/先验损失；causal启用完整约束。辅助路径额外前向有计算成本，不宣称同FLOPs。所有组包含step0的源验证候选，按BA/OA/负NLL选模。测试集不参与调参或先验计算。

各组输出位于`causal_subfeatures_20261119/<arm>_s<seed>/`，已有目录不会覆盖。起点仍为已有routed_s17，seed表示续训随机性，不是从头独立初始化。

## 5. 已验证范围

8项单元测试通过：互补与固定容量、直通梯度、跨样本共同坐标、供体可用性/单例、有效范围限制、目标停止梯度、有效源先验、完整容量重放及保存容量。

真实4张非参考源图、16源参考，包含原图和旋转增强，执行两步更新检查：

- 全保留时与分离前统一候选输出完全重放（误差0）。
- 给被丢弃通道增加非零扰动，因果查询输出、M3参考描述、PCEA source_raw变化均为0；bias路径输出变化非零。这是计算依赖证据，不是统计独立/因果识别证明。
- 替换bias实际改变分类输出；不能把这一变化称作有益变化。
- train/eval一致，checkpoint恢复一致；分离层及骨干、模块、reader、exchange、selector六组均有有限非零梯度，分离参数发生更新。
- 峰值分配显存约4.13GiB。数值记录见`causal_subfeatures_20261119/verification.json`。

另对实际train入口执行有界检查：8张源训练图、4张不重叠源验证图，第一步热身、第二步联合，step0/step2选模及best/last保存通过；用不同保留比例创建新实例后加载checkpoint，恢复到保存的128通道。记录见`training_entry_verification.json`。不是完整队列实验，不报告其4张图指标作为性能证据。

只读独立复核确认公共截点覆盖各路径、实时参考及三次反向正确；发现的保留容量未持久化问题已通过extra_state及跨实例恢复测试修复。
