# 新M3作为统一模型：接入完成

2026-11-19更新：本文记录的是分离前统一候选，保留用于对照。当前`unified_run.py`已转到显式特征分离候选，见`CAUSAL_SUBFEATURES_ZH.md`。分离前版本使用`matched_run.py --model unified`；新旧结果分别保存，不覆盖历史模型或论文结果。

## 1. 统一了什么

`unified_model.Model`继承`m3_late_axis_evidence_20261118.Model`，包含原有骨干/M1/M2/CCREL/PCEA及新M3，不再叠加第二个旧匹配器。统一配置：

- layer1原生40×40与M1后的layer2原生20×20分别读出，再形成同一槽位的多尺度描述。
- 20个细槽与8个父槽构成28个计算候选；内容门控进入槽位质量与回写覆盖。
- M3采用完整逐对匹配，保持区域身份；正反轴假设在每张参考内分别比较，再融合距离证据。
- 保留既有M3回写位置、PCEA回写位置及分类读出。
- PCEA仍是cross_mean，CCREL仍使用20×20读出，不新增其40×40残差。原有三区域/20槽语义不替换为M3的28候选语义。
- 其他类别上下文仍用该新M3候选已有的uniform配置；本轮未顺带加入独立relation-context候选。

这是一套接入现有工程依赖的统一实验模型，不是脱离历史代码和权重的独立发行包。

## 2. 训练接口调整

1. 输入同时使用新M3的Inputs，包含read40、read20、fine_write、eligible等字段；干预只替换images，其余几何、有效范围、参考身份保持不变。
2. 教师、学生训练、验证全部固定soft选择。避免原auto模式的训练软/验证硬切换混入收益目标；硬选择的效率和性能不在本轮声明中。
3. 优化器分五组，所有可训练参数恰好覆盖一次：骨干1e-6、已有模块1e-6、CCREL1e-5、PCEA3e-4、选择器1e-4。沿用旧组学习率，选择器沿用内容尺度候选的初始设置，未调参。额外细槽预算损失权重保持0。
4. 原分类损失训练全部上述参数；干预辅助梯度仍只写入CCREL/PCEA。五种none/protect/fixed/measured/shuffled目标与旧实验一致。
5. on/off仅切换PCEA，M3保持同一配置。独立M3开关用于诊断，不把PCEA监督改称M3专属监督。
6. 每次学生前向重新编码16张固定源参考，保持实时、可微；教师测量使用同一冻结统一模型。
7. 新教师缓存独立存入unified_20261119；记录模型版本与相关测量/模型文件状态。训练显式拒绝旧模型缓存，不沿用旧干预收益。

起点为既有routed_s17已训练权重；新选择器和位置参数按候选初始化，尚未获得新的训练结果。不同续训seed共用这个历史起点，不能称作从头独立训练。

## 4. 原始chip复核与初始行为

复核保留原尺度和显示范围的VV/VH图，展示干预、亮度控制、差分及实际参考。对照旧16图测量缓存，身份与增强码相同：旧、新初始模型均判对10/16，1例由错变对、1例由对变错，另1例错误类别改变。该小队列是执行检查用样本，不能当泛化性能估计。

- 短小倾斜亮目标的一个样本由旧模型正确变为新模型错误；其VH主体细尺度干预仍能改善分差，但未救回。不能因增强后的分差提高就掩盖新匹配配置的误伤。
- 另一个短亮目标由旧模型错误变为新模型正确；新教师选中VH侧向细尺度，旧教师选中轴端细尺度。因此必须重新测量统一模型的干预目标，不能复用旧选择。
- 持续正确样本的修改局限在单极化主体；持续错误的较长目标在VH侧向中尺度修改后仍错误。仅凭外观无法把这些变化定性为真实物理噪声或因果船型成分。

私有ID、路径、分数和面板在`unified_20261119/review_local.json`及`review_*_local.png`，不公开上传。面板中参考是实际库内的类别例子，不代表已经识别出的最大贡献参考。所有初始预测变化均发生在0更新状态，不是训练收益。

## 5. 使用方式

在本目录、现有ClearSAR环境执行：

```powershell
python -B -X utf8 matched_run.py --model unified --phase verify
python -B -X utf8 verify_unified.py
python -B -X utf8 matched_run.py --model unified --phase prepare --seed 17 --steps 120
python -B -X utf8 matched_run.py --model unified --phase train --bank unified_20261119/bank_s17_n120.pt --mode measured
```

另外四种损失只改mode，共用同一bank。默认phase为verify，不会自动训练。验证/训练结果只写unified_20261119。旧入口仍可用`matched_run.py --model legacy`。

下一步可以在此统一入口上运行配套训练。当前交付是模型及训练管线合并，不是正式性能替换；线性hinge主要改变达标阈值的既有边界仍保留，后续需检查活跃关系与绝对on/off变化。
