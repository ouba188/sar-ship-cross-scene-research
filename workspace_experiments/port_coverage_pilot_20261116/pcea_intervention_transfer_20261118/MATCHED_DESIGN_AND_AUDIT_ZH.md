# 干预收益迁移：匹配对照实现与整条执行路径自检

日期：2026-11-19。状态：代码实现、9项单元测试、16张真实源图的五组前向/反向检查完成；0次参数更新。未替换正式模型，未访问目标评价图像。本报告中的“通过”指计算路径通过，不指分类收益通过。

## 1. 本轮实际改动

新增 matched_run.py、test_matched.py、review_matched.py；扩展 objective.py 与 run.py，保留旧实验入口和旧损失。五组使用同一起点、同一源训练顺序、相同几何增强、16张固定源参考、相同优化预算：

| 组别 | 辅助训练信号 | 能区分什么 |
|---|---|---|
| none | 无；保留相同 on/off 分类训练 | 额外监督是否必要 |
| protect | 原图正确分差保护 | 收益是否只是防退化 |
| fixed | 相同有效关系，固定0.1改善目标，加保护 | 测得的幅度是否优于通用纠错阈值 |
| measured | 当前图测得的类别关系改善，加保护 | 样本对应的实际测量是否有用 |
| shuffled | 同类别有效源样本之间交换完整收益向量，加保护 | 样本与收益向量的对应是否必要 |

none是配套的双路径分类控制，不是另起训练的普通单路径Baseline。shuffled在整个源训练队列内配对，而不是仅在小批次里临时交换；保持原始收益向量的分布，但不保证乘上接收样本竞争类权重后的监督强度相同。它同时改变收益幅度和正收益关系的对应，不能解释成只检验幅度。

某类只有一个有效困难样本时，在fixed/measured/shuffled中同时取消该样本的改善监督；分类训练及适用的保护仍保留。保护组不依赖是否找到交换对象。缓存保存全部12种干预及对照分数，包括负效应；选中正收益不是删除负结果。

6. 每次学生训练重新编码同一16张源参考，参考与查询使用当前版本的特征；没有训练骨干后继续使用旧特征缓存的问题。固定的是参考样本身份，不是学生参考特征数值。

## 3. 从SAR输入到训练监督，依据及边界

| 环节 | 实际操作 | 依据与合理性 | 尚不能声称 |
|---|---|---|---|
| 极化分开 | 每次只改VV或VH，另一极化保持原样 | 原图与已有测量显示不同极化的响应与判别作用不必相同 | 所有船型都需要不同参数 |
| 区域分开 | OBB相对的框内、轴端、侧向，排除补零 | 可明确定位修改位置，不把全部外围先当干扰 | 区域精确对应船首、尾迹或海杂波 |
| 尺度改变 | 有效chip内高斯差分，衰减细/中尺度，边缘渐变并限制数值范围 | 提供局部空间尺度操作，避免将补零边界作为尺度信号 | 独立改变真实雷达物理频段或观测角 |
| 亮度对照 | 相同区域、相同有符号像素总变化的强度对照 | 可区分部分整体亮度变化与空间分布变化 | 已匹配L2能量、频谱、纹理或所有预处理因素 |
| 冻结教师 | 同一模型、同一参考、12个候选与12个对照 | 测量差异不混入参数更新 | 教师永远正确、其偏好就是物理机制 |
| 有效性筛选 | 真类概率与重新找最强竞争类的分差均优于原图及对照 | 不把“真类分数上升但竞争类升得更多”当改善 | 原本判错的样本必须排除 |
| 原图学生 | 学生只接收原图，收益向量停止梯度 | 要学的是原图的可兑现判别改善，不是识别扰动痕迹 | 教师的每种改善都能从原图恢复 |
| 定向梯度 | 额外项只加到CCREL/PCEA；分类项训练既有可训练参数 | 将新增目标落实到读出与条件化路径，避免仅由分类头承担 | 梯度路由本身证明模块分类增益 |
| 结果核对 | on/off分差、on相对原教师、off相对训练起点同时记录 | 防止仅off退化就宣称on改善 | on-off差值等于跨场景泛化收益 |

本轮复核未发现干预/几何错位、缺失极化进入有效监督、陈旧学生参考特征或辅助梯度直接写入骨干的问题。同一次反传中，添加辅助梯度前后的非目标梯度差严格为0。全局梯度裁剪仍可能改变各组最终共同缩放系数，路由声明只针对裁剪前的直接辅助梯度贡献。

## 4. 公式对应

令 r_c(z)=z_y-z_c，m(z)=z_y-max_{c!=y}z_c。教师在原图及选中干预图上的差异给出 g_c=clip(r_c(T(xI))-r_c(T(x)),0,0.1)，只对通过筛选的样本启用。负效应保留在记录中，但不是正改善目标。

困难且路径有效、可配对的样本采用：L_gain=Σ_c w_c 1[g_c>0] [stopgrad(r_c(S_off(x)))+g_c-r_c(S_on(x))]_+。正确原图另有分差保护。u=0并不删除样本，仍有分类损失，并可有保护。

这不是识别非因果区域的监督，也没有要求所有干预前后特征一致。它迁移的是固定模型对可控输入操作的判别响应。使用源训练标签确定真类是监督学习；推理时不输入查询真类。

## 5. 自检发现的实际限制

### 5.1 实测幅度目前主要改变达标阈值

线性hinge在活跃区内对预测分差的导数不随g的大小变化。真实检查中fixed与measured均有24条活跃关系，reader额外梯度范数均约0.00934089，PCEA均约0.00316478，尽管辅助损失分别为0.05182622和0.05113195。

这是现有目标的数学行为，不是梯度断开；也意味着不能称“收益越大，当前梯度越强”。只有目标造成不同的活跃关系集合，训练轨迹才可能分化。本轮保留原先讨论的目标，不用未验证的新损失替换；新增逐步活跃关系计数。若训练后两者相当，先检查这项，而不是立即认定干预信息无价值。

### 5.2 兑现统计已修正

统一measured探针与实际模式请求分开：none/protect的实际改善请求为0；fixed/shuffled按自己的目标核算，未配对样本不进入实际兑现分母。原先统一探针不应被叫成所有组的实际监督兑现率。已补独立测试。

### 5.3 计算正确不替代效果验证

16图不是随机总体抽样，而是每类前两个合法非参考源样本，只用于执行覆盖。16图均有候选通过，但只有6图满足困难条件，4图可形成同类交换，2图因单例排除。不能把16/16推广成全数据有效率。

起点已在历史开发工作中选择，source-inner也已多次使用。本入口可以做匹配开发比较，不能冒充未触碰的独立确认。三个续训随机种子也不是三个从头独立训练的起点。

## 6. 原图证据

本地review_matched.py输出原图、干预图、匹配亮度对照、差分、实际同类与混淆类参考的VV/VH面板。统一160画布、0–1显示范围、nearest显示，不把参考船独立放大来伪装尺寸一致。参考图是实际库中的类别例子，不是已证明贡献最大的参考。

持续判对案例：细尺度改动只发生在一极化的主体附近，分差提高，但不触发困难样本改善监督。持续判错案例：侧向中尺度改变后，分差改善仍小于0；可见事实是局部像素改变及模型竞争变化，不足以命名真实物理噪声，也不算救回。另一持续判错案例的主体细尺度改变同样改善分差，说明不能给所有样本指定同一个固定框外掩膜。

具体ID、原图路径、原始数值及面板保留在matched_20261119/review_local.json，仅本地保存。旧case_02/03另由只读子代理核看，结论与上述边界一致。0更新的检查不能生成“新训练救回”案例。
