# 连续门控解耦：已替换半通道，完成配套短训练

2026-11-19。结论：代码和训练可落地，初始化不再发生硬切通道的大幅损伤；源内分类改善，但两组历史跨场景开发队列仍未整体超过未分解统一模型。保留为门控实验候选，不升级论文正式模型，不声称已识别纯因果子特征。

## 1. 改动及验证

依据GDOS第4-8页公式6-11、19-25，改为逐样本连续Sigmoid门控、互补完整通道、打乱互补分支、拼接后1x1可学习重组及停止梯度的熵加权KL。没有hard top-k、STE、固定一半容量或类别先验损失。VV/VH独立门控，保留共享骨干与M1/M2/CCREL/PCEA/新M3。

检测任务的海杂波概率、RPN和回归损失没有迁移。validGAP、layer1公共切点、每极化参数、约0.95门控和[I,I]重组初始化是本任务适配，不是原文复现。默认推理只有保留分支，重组只用于训练。原图输入频率干预指导未同时叠加。

六项单元测试通过；4张真实源chip+16参考+2步完整前后向通过：门控/重组有梯度，供体影响logit约0.550，全开重放误差0，全闭绕过影响约1.8e-35，同实例严格重载误差0。后续完整评价为新实例严格加载选中权重。独立只读审查未发现阻塞性接线问题。

## 2. 比较协议

- 两组各120步、batch8、seed17，相同960条源观测、933艘船、24港、303过境组，固定16源参考。
- gate_ce仅分类；gate_uwcl从首步加权KL。源243条选择集、30步评估一次，均选择step120。源剩余757不参与本轮选模，但不是全新未使用数据。
- 直接比对保存的实际查询/增强/参考列表，与上一轮baseline完全相同；复用baseline，不重训。baseline指未分解的新M3统一候选，不是论文历史Baseline。
- 匹配更新数、样本和既有分组学习率，不匹配FLOPs。门控组1e-3；其余分组不改。
- 两组历史开发队列160/198仅在选模后评价；198含已知过境中的新船，不称独立未见过境测试。没有读取3075正式测试，没有OSS2复现。
- 每组868个有效供体替换，其中864个跨过境；不是864个独立干预实验或跨港替换。

初始化源243 OA：不分解54.73，旧半通道30.86，新门控55.14。支持“本次初始化保护了已有能力”，但旧/新还有损失、门控形式、重组等多处差异，不能把最终全部改进归于单一因素。

完整门控相对未分解模型：160有7救回/13误伤，198有5救回/16误伤，总12/29。相对同结构门控CE：160有4救回/3误伤，198有2救回/2误伤，总6/5，仅净多1张。不能把门控整体源内收益全归于一致性学习。

## 4. 是否真的学到解耦

64张源选择样本、固定4次供体排列；四次重复不算256个独立样本。

| 诊断 | 门控CE | 门控+UWCL |
|---|---:|---:|
| 平均门值 | 0.9026 | 0.9055 |
| 门值范围 | 0.0888-0.9988 | 0.1310-0.9981 |
| 门值>0.99比例 | 14.85% | 11.59% |
| 平均跨样本门值标准差 | 0.00340 | 0.00329 |
| 互补/保留特征L2范数比 | 0.1426 | 0.1243 |
| 重组后平均KL | 0.06593 | 0.09462 |
| 重组后预测翻转数/64 | 9.50 | 13.25 |

不是全部通道开门，也不是互补分支完全为零；但跨样本门值变化仍小，本轮主要学到通道分配，尚无强样本自适应证据。供体排列改变预测，不能说完全忽略供体；这也不证明互补分支已是纯成像扰动。

**定位到一个可修正环节：**固定UWCL检查点、同样64样本和4个供体排列，只把重组卷积恢复到[I,I]，KL由0.09462降到0.05485，翻转由13.25降到8.00。正常分类路径不使用此卷积，因此这不是分类准确率提升实验；它说明当前学习到的重组映射增加了替换路径的预测偏移。不能把更低一致性归结为因果分离，也不能认为任意可学习重组必然优于加法。
