# 统一模型真实单样本流程重放

2026-11-19。运行`walkthrough.py`，不训练、不更新参数、不改正式模型。使用统一模型16张源图检查缓存中的第一张，固定原16张合法源参考。不是根据模块收益挑选案例。

## 流程与实际形状

原VV/VH裁片各64x64，输入画布各160x160。骨干接收完整画布，OBB用于组织区域，而不是先删除框外像素。

1. 共享骨干提取每极化layer1的256x40x40特征。
2. layer2末block在conv2后进行M1处理；类别响应各8x20x20，随后conv3与残差相加形成512x20x20特征。
3. 浅层M2读取框内、轴端、侧向区域。CCREL利用浅层特征及类别响应形成区域证据，PCEA在layer3末block的conv2之前更新256x10x10特征；内部M2也在该block参与计算。
4. M3将40x40和20x20特征分别按原生区域权重读出，每细槽得到768维描述。20个细槽加8个粗槽，实际查询输入为1x2x28x768，参考为16x2x28x768。soft选择不等同于已减少28候选的实际计算量。
5. 在区域内执行逐对匹配；两种整体轴向假设按参考分别比较。生成1x2x1024x10x10更新，在layer3输出处与原特征相加。
6. layer4后做有效范围全局读出；浅层及投影后的深层区域摘要相加，再与全局特征及极化有效标志拼接，进入现有分类读出。

## 单例结果及边界

正确类别为散货船。完整统一模型softmax输出约72.50%，普通货船23.44%，渔船4.06%。这些是模型输出，未校准为真实正确率。

与已保存教师分数重放最大差1.91e-6。关闭M3仍判散货船：正确类对最强竞争类分差从关闭时1.24466变为开启时1.12926。这不是M3救回例，不用于宣称收益。初始候选未追加训练。

原图可见细长斜向亮目标及周围弱纹理，VV/VH形态和响应存在差异。槽位随OBB方向组织。选择概率接近0.5，当前不能说选择器已学会可靠地按内容选择粒度。展示的同类参考来自实际参考库，但不是已确认的最大贡献参考。
