# 跨采集与采集条件受控跨港：补充验证

2026-10-13，已完成。原主模型、旧实验及稿件未改动；本轮没有新增骨干训练或源模型拟合。

## 结论先说

**两项都补上了：按采集隔离的支持迁移验证，以及同采集、进一步匹配类别与入射角区间的跨港验证。** 不需要推翻原跨港实验。

本轮更准确的结论是：

1. 同港不同采集的案例，平均不如本次采集的案例适用；同采集下换港也能出现损失。
2. **不如同场景支持，不等于没有用。** 即使支持来自另一港、另一采集，平均仍能明显提高本轮源读出的OA/BA；这里报告观测净增益，不声称已经做出统计显著性推断。
3. 在宁波—上海、类别与入射角区间配平的五次采集子集，跨港差距较小且受支持抽样影响。不能把旧一两次采集中的大幅损失推广成固定港口惩罚。
4. 本轮建立了更完整的迁移证据，不等于已经开发出解决该缺口的新模块，也不是原完整版的新主表。

## 1. 使用什么模型，隔离到了哪里

复用 `E:/临时会话/port_shift_matched_acquisition_20261013/fits/geometry.pkl` 的共同紧凑读出：冻结R50原图/C4与SAR-SSL R18特征，源端PCA、标准化、类平衡线性头，目标支持采用类平衡残差岭求解，正则固定8，基础头与专家概率各0.5。

对照为基础C4头、R50单骨干的双视图读出、R50+R18双骨干读出。这里“单骨干”不是一次前向的单视图网络；也没有对本轮缓存求解时间作端到端算力优势声明。

源端23687条数据在PCA、统计量和线性头拟合时，已排除五个共享采集港及其已知船只。本轮实际目标8790条被引用记录，与源端的港口、已知MMSI和采集键交集均为零。

**隔离边界：** 历史冻结骨干的训练暴露没有被重置，因此这是冻结表征上的港口/船只/采集隔离读出验证，不是重新端到端训练后的未见采集确认。已有数据参与过研发，也不因重新组织而成为全新独立数据。

与旧完整版不同，本读出不含其分频、稳定/漂移坐标及入射角辅助项。入射角本轮只用于配平与分层，未作为新模型输入。

## 2. 如何组织任务

同一批查询船，比较四种支持来源：

| 单元 | 支持与查询港口 | 支持与查询采集 |
|---|---|---|
| SS | 同港 | 同次采集 |
| OS | 指定另一港 | 同次采集 |
| SO | 同港 | 其他采集 |
| OO | 指定另一港 | 其他采集 |

SO/OO中，源端拟合和支持适配均不使用查询采集的样本。SS/OS故意允许查询采集中的其他标注船，作为“可获得同次采集支持”的对照，不把这两格冒充采集完全留出。

每格使用16或64个支持案例，五次支持抽样；支持内每船一例，排除全部查询船身份。四格每类数量完全相同。角度控制进一步保证每个类别×固定2度区间的数量相同，不插补缺失角度。

这属于标签已知后的匹配诊断，不声称只从未知池标B张就能取得相同配额。查询标签不进入分类器拟合或超参数选择；任务按类别覆盖与元数据容量入组。

每方向、每策略最多按日期均匀选择五个可行采集。先入组B64可行采集，再给同一查询补B16，因此有严格配对的预算子表。支持集合并非嵌套；跨预算配额和抽样随B改变。

| 策略 | B | 方向-采集上下文 | 实际采集 | 去重查询/已知船只 | 查询类别计数：散货/渔船/杂货 |
|---|---:|---:|---:|---:|---|
| 逐类配平，三港 | 16 | 30 | 12 | 1236 / 1139 | 204 / 957 / 75 |
| 逐类配平，三港 | 64 | 23 | 9 | 1144 / 1059 | 159 / 924 / 61 |
| 类别×角度配平，宁沪 | 16 | 10 | 5 | 701 / 645 | 103 / 571 / 27 |
| 类别×角度配平，宁沪 | 64 | 10 | 5 | 701 / 645 | 103 / 571 / 27 |

三港为宁波舟山、上海、青岛。模型输出八类，但实际查询仅散货船、渔船、杂货船三类，不称为八类均有查询的验证。部分景某类仅一条查询，因此场景宏平均对少数样本敏感；这也是同时保留OA与BA的原因。

先平均支持抽样，再平均每方向的采集，最后方向等权。六个有向关系不是六个独立港口；两预算、双向及反复观察的同船也不是新的独立数据。

## 3. 只换采集与只换港口

下表为普通逐类配平、紧凑双骨干读出。OA/BA为百分比，差值为百分点；BA按每个查询集合实际存在的类别计算。

| 支持条件 | B16 OA / BA | B64 OA / BA |
|---|---:|---:|
| 不用目标支持，仅源读出 | 77.483 / 62.463 | 79.628 / 62.128 |
| 同港同采集 SS | 86.824 / 76.448 | 89.819 / 77.859 |
| 异港同采集 OS | 83.260 / 72.423 | 85.849 / 72.864 |
| 同港其他采集 SO | 83.475 / 70.646 | 87.824 / 71.819 |
| 异港其他采集 OO | 82.144 / 69.074 | 85.784 / 71.145 |

| 配对变化 | B16 OA / BA变化 | B64 OA / BA变化 |
|---|---:|---:|
| 只换港 OS-SS | -3.563 / -4.025 | -3.970 / -4.994 |
| 只换采集 SO-SS | -3.348 / -5.802 | -1.995 / -6.040 |
| 港和采集都换 OO-SS | -4.679 / -7.374 | -4.035 / -6.713 |
| OO相对不适配源读出 | **+4.661 / +6.611** | **+6.157 / +9.017** |

普通对照的跨采集BA下降两个预算均为6/6方向；跨港BA下降为B16的6/6、B64的5/6方向。不要把两种损失相加解释为因果占比。

OO相对源读出的平均BA收益，在五个配对支持抽样汇总中均为正；均值/支持抽样标准差为B16 +6.611/0.992、B64 +9.017/1.406。它们是支持抽样变异，不是五个独立训练种子，也不作为总体置信区间。

## 4. 更接近“只换港”：类别与入射角区间匹配

这部分只覆盖宁波—上海2025-01-04至2025-04-10的五次采集。四格类别×2度区间配额相同，SS/OS实际支持平均入射角差最大0.429度。

| 配对变化 | B16 OA / BA变化 | B64 OA / BA变化 |
|---|---:|---:|
| 同采集换港 OS-SS | **-0.923 / -0.649** | **-1.269 / -1.963** |
| 同港换采集 SO-SS | -3.409 / -7.539 | -2.044 / -1.843 |
| 港和采集都换 OO-SS | -3.491 / -6.357 | -2.644 / -4.863 |

同采集换港的BA变化，在五个支持抽样汇总中两个预算均有2次为正、3次为负；标准差分别2.522、3.853个百分点。B16两方向一正一负，B64两方向平均均负。因此，本子集有平均残余损失，但不能说每次换港都下降。

**不能用普通三港表减去这个宁沪表，宣称角度解释了多少损失。** 目标港、日期、查询构成、配额和支持来源都可能不同；两表各自的配对比较有效，表间差异不是角度的独立因果效应。

同一次datatake不等于同一完整产品，也不等于完全相同入射角、船体状态或背景。现有跨港没有精确同一完整产品配对。因此“纯港口地理因果效应”仍超出本数据所能证明的范围。

## 5. 收益和损失由哪些样本贡献

类别贡献以完整查询BA分母计算；不存在的类贡献记零，三类贡献可精确加回总体变化，不混用按类子集准确率。

- 普通B64跨港损失-4.994：散货船贡献-2.458、渔船-0.882、杂货船-1.654个百分点。
- 普通B64跨采集损失-6.040：散货船贡献-1.824、渔船-0.143、杂货船-4.073。主要损失群与换港不完全相同。
- 角度匹配B64跨港损失-1.963：散货船-0.595、渔船+0.132、杂货船-1.500。杂货仍是主要负贡献，但该子集只有27条去重杂货查询，不把它推广为所有杂货船的固定规律。
- 普通B64的OO相对源读出+9.017：散货+5.797、渔船+1.184、杂货+2.036。说明跨港、跨采集支持仍有净任务价值，并非只能制造错误。

这些结果定位了损失/收益的人群及支持依赖，未唯一识别船体形态、运动或背景等物理根因。源读出到支持适配的变化也同时包括局部类别组成和判别修正，不能全部归为更好的物理表示。

## 6. 双路和支持预算是否还有价值

相对本轮匹配R50单骨干读出，普通对照的双骨干BA增益如下：

| 条件 | B16双路增益 | B64双路增益 |
|---|---:|---:|
| SS | +1.598 | +3.353 |
| OS | +2.265 | +2.062 |
| SO | +0.990 | +1.600 |
| OO | +1.473 | +2.365 |

这支持当前有限协议下双路仍有任务收益，不证明优于任意优化过的单骨干，也不证明双路对场景变化更不敏感。角度配平B16的OO双路BA反而比R50低1.550，OA高1.092，保留这个范围。

在完全相同查询上下文上的B64-B16比较，普通对照SS/OS/SO/OO的BA分别+2.318/+1.318/+2.222/+2.755；角度对照分别+0.061/-1.253/+5.757/+1.555。因此更多支持总体可带来收益，但具体条件下不保证单调改善，尤其OA与BA可不同向。

## 7. 为什么比旧角度子集更温和

旧实验先挑最多三景，再做角度可用性筛选，最终只留下B16一次、B64两次采集。本轮先按角度配平容量筛选，再选场景，并保持B16/B64查询可配对；不根据成绩选景。

独立元数据侧线确认：沿用旧查询规则，全部共享池可行范围其实有B16九次、B64六次采集。旧小范围主要来自选景顺序，并非只能找到一两次。新旧查询、配额和支持抽样规则也有差异，不能把数值变化只归于“多了几景”。

真正的覆盖边界仍存在：上海后期渔船与杂货船角度不可用，不能把有角度的早期多类子集推广到全年。详见 [METADATA_SCOPE_ZH.md](E:/临时会话/scene_port_supplement_20261013/METADATA_SCOPE_ZH.md)。
