## 结论

**指定范围内未发现错误流计算、样本配对、全局类别分母或原图/显示阶段颠倒的问题。** 独立结果与主表及旧 `arm_effects.csv` 一致。数据支持部分样本上的第二路互补性，以及这种作用对输入处理的依赖；不支持普遍的净抗扰动优势，更不能识别纯对比度或独占物理信息。

## 独立实现和核验范围

脚本 `verify_flows.py` 只借用 `context.frame` 读取 manifest，未调用主任务统计函数。范围为 MLP、expert、每个 draw 的原始查询；LA/fold2、OSS1/fold2、OSS1/fold3、Klang/fold3；T-R、P-R、T-P、PE-P；原图与 display。未将这四个上下文的通过扩展成全量审计认证。

- 四种输入的 sample ID/顺序、支持索引、逐 draw 查询掩码和 common-query 掩码在四个指定上下文完全匹配，共12组条件配对。支持与当次查询无交集，标签按 ID 对齐。
- 每个 draw 按查询中实际存在的 K 个类别计算 `w_i=1/(K*n_class)`；救回为基线错且候选对，误伤为基线对且候选错。BA百分点贡献为 `100*sum(w_i*(rescue_i-harm_i))`。
- 以 R 原图/显示正确性划分 lost、gained、stable_correct、stable_wrong。所有层始终使用全查询类分母，四层贡献之和回到总量，没有对子群重新归一化后求和。
- 独立160个总体效果、640个分层效果、1280个逐类效果、20个 lost 层 T 正确性转移。对应主表800个阶段分层读数和32个阶段任务均值全部一致；整数计数完全一致，主表净增益最大误差 `3.55e-15` 个百分点。
- 与旧 `arm_effects.csv` 的160行对账：BA最大误差 `1.07e-14` 个百分点；macro/micro Brier分别 `3.02e-16` / `2.78e-16`。并检查缓存 argmax 与使用的预测相符。

机器记录见 `VERIFICATION.json`；独立数据见 `independent_flows.csv`、`independent_strata.csv`、`independent_class_flows.csv`、`independent_persistence.csv`。

## 实际解释支持

以下为五个支持 draw 等权平均的净BA增益，单位百分点；箭头为原图到 display，所有负结果保留。

| 任务/折 | T-R | P-R | T-P | PE-P |
|---|---:|---:|---:|---:|
| Los Angeles/2 | 1.042700 → 1.166378 | 0.139159 → 0.476504 | 0.903541 → 0.689874 | 0.855078 → 0.571290 |
| OSS1/2 | 3.195578 → 1.067358 | 0.348835 → 0.258100 | 2.846743 → 0.809258 | 1.650626 → 1.138463 |
| OSS1/3 | 3.105475 → 0.663561 | 0.948105 → -0.481415 | 2.157370 → 1.144976 | 2.049207 → 1.021136 |
| Port Klang/3 | 0.913264 → 1.523337 | 0.396085 → 0.437808 | 0.517178 → 1.085528 | 0.215662 → 1.096021 |

1. **有互补性，但有误伤。** 例如LA的display T-R救回4.919320、误伤3.752942，净值仅1.166378。条件救回率没有扣除全查询误伤，不能代替净增益。
2. **lost层正贡献不等于净抗处理能力增强。** OSS1/2的lost层使T-R增益变化贡献+3.979482，但gained层为-4.352413、stable_wrong为-2.634821、stable_correct为+0.879532，合计-2.128220。OSS1/3同样总下降-2.441914。LA和Klang分别+0.123678、+0.610073，只是这些固定上下文的有限正结果。
3. **处理后T-R的gross rescue更多来自原本就困难的样本。** 在LA、OSS1/2、OSS1/3、Klang，stable_wrong层的贡献分别3.635533、1.580880、1.604659、1.398873；lost层分别1.283786、1.960554、0.927904、1.187101。OSS1/2是该逐上下文比较的反例，必须保留；OSS1两折等权后stable_wrong为1.592770，大于lost的1.444229。不能把聚合关系说成每折都成立。
4. **真实第二路仍优于当前重建替代，但不是独占信息证明。** 四上下文的display T-P均正；有限重建能力、域外推和几何差异仍可解释一部分差距。OSS1/3的P-R为负，不能概括为重建替代普遍有效。

## lost层：是否保持原有正确性

下表使用每个 draw 的全查询类别权重，先等权平均各项贡献再取比例；不是主表的逐draw条件率平均，也不是独立样本成功率。

| 任务/折 | display T救回中，T原图也正确的占比 | lost层原本T正确的质量中仍保持正确的占比 |
|---|---:|---:|
| Los Angeles/2 | 98.99% | 21.46% |
| OSS1/2 | 80.72% | 26.63% |
| OSS1/3 | 88.77% | 14.00% |
| Port Klang/3 | 99.52% | 12.03% |

两列回答不同问题：display救回的多数确实是T原图已正确的样本，但lost层原有T正确质量只有12%–27%保持正确。这支持“仍保有部分可用正确性”，不支持“第二路原有证据整体稳定保留”。lost按R结果事后选定，且display同时作用于支持和查询、支持系数已重新求解，因此不是纯查询扰动或纯物理因素的因果分离。

主汇总的方向与该审计相容：MLP expert T-R的全查询增益变化，OSS1 -2.285067、OSS2 -1.753717、三港 +0.214304；lost条件救回率约18.66%、10.63%、11.59%。这些条件率不能抵消前两个净优势下降。OSS2、Santos与三港总汇总在此仅作主表解释审阅，未逐原始缓存重算。
