# 类别参照关系校准：明确的数学含义与预测过程

## 1. 真正增加的是什么

给定冻结视觉坐标 z，以及源域同一船型集合的八个类别中心 mu_c。原模型直接用视觉坐标内积比较查询与支持船。新增部分先比较每条船相对于八类参照的响应，再计算这种响应模式是否相似。

参照数等于源任务类别数；本项目八类是任务设定，不是方法只能支持八类。源中心由每艘已知源船的一条观测构造，目标查询标签不参与中心、带宽或归一化统计拟合。

## 2. 八维坐标不是无法说明的黑箱

原始响应为：

    a_c(z) = exp(-||z-mu_c||^2 / tau2)
    r_c(z) = a_c(z) / sqrt(sum_j a_j(z)^2)

展开距离，令：

    h_c(z) = (2 z^T mu_c - ||mu_c||^2) / tau2
    p(z) = softmax(2 h(z))

则有精确恒等式：

    r_c(z) = sqrt(p_c(z))
    r(q)^T r(s) = sum_c sqrt(p_c(q) p_c(s))

也就是说，它比较两条船相对于同一组类别原型的响应分布。p只是一组原型诱导的相对权重，**不自动等于真实或已校准的船型后验概率**；r的每一维有源类别参照，但不等于某个独立物理部件或纯因果因素。

这是现有构造的代数解释，不是声称我们首创了平方根概率表示或其内积。

## 3. 本轮纠正了什么

旧实现先exp，再用max(L2范数,1e-15)作分母。当原始响应范数低于阈值时，结果并非单位向量。对参照整体距离大的样本，共同衰减未能被消去，原本要比较“相对类别偏好”的计算又混入了整体远近。

本轮对实际入组样本检查后发现：F_0921的4812条独特查询观测中552条触发阈值；2582条独特支持观测中329条触发。这里是本轮全局及场景任务的行ID并集，不是独特船只数，也不是所有F_0921样本比例。三港支持有1条、OSS2查询1条/支持2条也受到影响。

修正是先对每行log响应减去最大值，再exp并L2归一化。至少一个exp值为1，分母不再受固定下限控制，恢复上述代数恒等式。源端中心化和能量统计按同一稳定公式重算；参照中心、带宽、支持集及模型超参数不变。

这不是此前裁片管线问题，也不是新设计的异常值门控。它是当前关系模块内部的数值归一化纠正。原实验与修正实验分目录保留，修正不视为新独立验证。

## 4. 怎样进入分类决策

源端计算平均响应 m 和能量匹配系数 g，得到 R(z)=g(r(z)-m)。随后：

    K_new(q,s) = 0.75 K_original(q,s) + 0.25 R(q)^T R(s)

源中心化后，这一项是中心化的相对响应内积，不能把其每个值直接叫作概率或必定非负的相似度。

支持集内部K_SS和查询到支持K_QS都使用这个核。支持标签先减去源模型分数，以类别平衡的ridge求出残差系数A，最终专家分数为：

    expert(q) = source_score(q) + K_QS A

基础分支使用同一标注支持集进行自己的适配；两者经softmax后按0.5融合。每条查询独立预测，不需要读取其他查询或其标签。

## 5. 解释收益必须追到重求解后的决策

令旧核与系数为K0、A0，新核与系数为K1、A1，则：

    K1 A1 - K0 A0 = (K1-K0) A0 + K1(A1-A0)

第一项描述固定旧系数时的关系变化；第二项描述系数重新适配后的变化。两项可以方向相反，甚至大幅抵消。它们是指定代数路径的贡献分解，不是唯一因果归因；不能把中间分数幅度当作真实可部署增益。

本轮保存了真类对旧最强错误类的margin变化、各支持样本的带符号贡献、检索关系、救回与损害事件。支持样本即使与真类不同，也可能通过带符号的残差系数提供有用校正；只显示“最近同类样本”不足以解释这个读出。

## 6. 当前主张的适当范围

类别参照相对同数量普通聚类参照的优势，可以支持“按类别组织参照在所测任务中有用”。不能独立证明其收益全部来自抽象语义，因为类别覆盖、源样本密度和各类权重仍可能共同起作用。局部净收益值得保留，但不隐去不同预算、同采集或全局任务上的退化。
