# 类别参照核心：完整精简候选与等容量对照

2026-10-14，预测前冻结。承接已有原型，不开始新骨干训练。

## 问题与主张

有限支持案例跨采集错配时，源域类别参照是否提供比普通低维参照更有用的案例关系？新关系能否通过支持残差读出兑现为系统收益？

本轮建立独立的候选推理实现，复用源拟合几何/分类头与冻结视觉特征，保留C4基础预测、R50/SSL支持专家、支持适配、0.5概率融合。初稿关于“没有额外PCA补充模块”的判断不准确：实际2752维缓存包含192维保留坐标和2560维PCA余量。没有旧分频、稳定坐标或入射角分支。完整删除余量的192维版本另在lean192子目录验证；基础降维PCA仍保留。不是旧完整主模型已正式换版。

## 冻结对照

- 原始支持核。
- 0.75倍原始核：已有缩小更新对照。
- 0.75原始核+0.25类别参照核：8源类别中心，既有归一化/中心化/能量匹配不变。
- 0.75原始核+0.25普通参照核：8个源样本无标签KMeans中心；3个预定随机初始化种子，均报告，不按目标结果挑选。每个种子n_init=5。

类别和聚类参照使用完全相同的源样本、带宽、响应处理、核混合比例、读出和融合。聚类允许受源样本类别比例影响，故若类别中心获胜，结论是类别组织有用，不立即归因于抽象语义唯一性。

## 证据与检验

1. 新实现原始/类别参照两端与原缓存复现，捕捉接口、精度或索引错误；不一致先纠正再解释。
2. 用独立KernelRidge核查有权重的支持残差求解；候选逐查询与批量预测一致，防止意外引入查询批次拟合。
3. 等容量替换检验类别参照相对普通量化的价值，保存源聚类类别构成。
4. 支持检索MAP@R、真类对固定旧竞争类margin变化、救回/损害及分层OA/BA分别报告。查询标签仅在事后评价使用。
5. 分数变化拆为固定旧系数下的关系变化和重求解系数后的变化，两项精确相加；这是算法贡献分解，不是物理因果分离。
6. 测量已编码特征上的额外适配/推理时间，源参照拟合时间另报；不当作包含骨干的端到端成本。

若类别参照没有胜过普通参照，保留已有实际效用，同时修正关于类别语义必要性的解释；不预设一定能赢，也不无限换模块。
