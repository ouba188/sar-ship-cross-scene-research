# F_0921与OpenSARShip 2.0：跨采集、跨数据集补充验证

2026-10-13，已完成。28个上下文、260个支持条件、780次支持求解；没有训练新骨干，原完整版与旧结果未修改。

## 结论

**其他数据集有可用信息，本轮已经补上F_0921和OpenSARShip 2.0。** 完成三种互不混淆的实验：

1. 24港源模型到外部数据集：分别报告零目标标签及16/64例目标支持适配。
2. 外部数据集内部：固定查询和支持类别数量，比较同次采集与其他采集的支持；OSS2进一步匹配GRDH/SLC类型。
3. 支持案例跨数据集替换：保留同一个24港源先验，在同一查询上比较F_0921与OSS2支持，数量与类别组成相同。

结果支持：**本地少量标签有净任务价值；类别相同不保证案例可以跨采集、跨数据集等价替换。** F_0921的BA改善伴随类别取舍，不能说OA也同等提高。没有声称已经唯一定位物理原因，也没有为此增加新模块。

## 2. 模型与评价口径

沿用上一轮共同紧凑读出的方法：冻结R50原图/C4及e206 SAR-SSL R18特征，新拟合一套共同源PCA/标准化和三个源分类头，源拟合28854行、八类齐全。目标适配固定类平衡残差岭正则8；基础与专家各0.5概率融合。没有搜索超参数。

三种读出同时报告：C4基础头、R50单骨干双视图读出、R50+R18双骨干读出。它不包含旧完整版分频与港口辅助项，因此绝对成绩不能替换旧主表。

源端PCA/统计量/分类头拟合与外部已知船只、已知采集无重叠。**历史编码器与研发暴露仍在，尤其R18曾在F_0921语料自监督预训练。** 所以“零目标标签”不等于从未接触目标图像，也不称为全新独立确认。

全局查询按每类约30%已知且标签一致的船只留出，每船随机一例；两个预算查询完全相同。支持内船只唯一，排除两外部查询集合的全部身份。随机目标适配的16例是同次64例抽样的前16例，不强制各类齐全。

## 3. 24港到外部数据集：零标签与少量支持

下表为紧凑双路，五次支持抽样平均。OA/BA为百分比。

| 迁移方向 | 目标支持 | OA | BA |
|---|---:|---:|---:|
| 24港→F_0921 | 0 | 37.516 | 19.536 |
| 24港→F_0921 | 16 | 37.361 | 22.468 |
| 24港→F_0921 | 64 | 37.877 | 26.646 |
| 24港→OSS2 | 0 | 27.497 | 22.317 |
| 24港→OSS2 | 16 | 33.514 | 24.790 |
| 24港→OSS2 | 64 | 39.679 | 31.400 |

B64相对不适配源读出：F_0921 OA/BA为+0.361/+7.110个百分点；OSS2为+12.182/+9.083。两者BA五次抽样均正，支持抽样标准差分别2.238/1.701个百分点。这不是五次独立训练或五个独立数据集。

B16的F_0921 BA+2.933，五次均正但OA均值-0.155；OSS2 BA+2.473，四次为正，OA+6.017。

### F_0921为什么BA涨、OA基本不变

不是各类都受益。B64相对源读出的总体OA贡献：散货船-8.956个百分点；成品/化学品油轮+2.514、集装箱船+4.585、原油轮+2.067，其他类别合计约+0.151，最终净+0.361。

散货占固定查询1865/4654，约40.1%。平均每次适配，它救回22.2条原本错判的散货，却改错439.0条原本正确的散货；与此同时集装箱救回215.2、改错1.8，成品/化学品油轮救回118.6、改错1.6。

**这是已经量化的类别取舍，不是整体没有学到，也不是所有样本都更好。** 类平衡支持修正、原先验与目标类内分布共同作用，当前实验没有将其全部分离成唯一物理根因。

OSS2的B64收益主要由渔船和集装箱贡献OA+4.883/+5.425个百分点。固定支持下按查询产品分层，GRDH BA22.527→33.901，SLC16.526→27.590，两个产品子集都受益；不能把整体收益仅解释为GRDH/SLC比例变化。

## 4. 各数据集内部的跨采集验证

每个数据集按元数据容量选五次采集，不按成绩挑景；同一查询分别配置同采集和其他采集支持，预算及每类数量一致。OSS2在每个类别内部还匹配产品类型，GRDH/SLC同次采集不被拆成两次。

支持/查询船只隔离；每池先固定一例/船，避免同船GRDH与SLC重复计入支持。B16/B64使用相同查询，跨采集支持来自该数据集其他采集的混合池。

| 子集 | 查询/船只 | 实际查询类别 | 数据边界 |
|---|---:|---|---|
| F_0921五采集 | 166 / 164 | 散货13、杂货16、化学品油轮79、集装箱21、原油轮36、拖船1 | 无渔船/海工查询；选入可容纳B64的较密集采集 |
| OSS2五采集 | 314 / 310 | 八类 | 稀有类如原油轮仅4条；每景按实际类计算BA |

| 数据 | B | 同采集 OA / BA | 跨采集 OA / BA | 跨采集减同采集 OA / BA |
|---|---:|---:|---:|---:|
| F_0921 | 16 | 27.123 / 25.117 | 23.328 / 23.080 | -3.795 / -2.037 |
| F_0921 | 64 | 45.784 / 42.593 | 32.960 / 27.588 | -12.823 / -15.005 |
| OSS2 | 16 | 38.056 / 26.659 | 35.025 / 24.645 | -3.031 / -2.014 |
| OSS2 | 64 | 47.522 / 36.102 | 42.073 / 30.757 | -5.448 / -5.345 |

每个数据集/预算均有4/5个采集的平均BA差为负，也都保留一个正例。F_0921 B16支持抽样汇总还有2/5次差为正；B64以及OSS2两预算的五次汇总均负，不把平均负差解释为处处失败。

**F_0921的B64落差大，不表示加标签使跨采集模型更差。** 跨采集BA从16例的23.080升到64例的27.588；同采集则从25.117升到42.593，后者更充分兑现了新增案例的价值，才使相对差距拉大。

F_0921 B64跨采集BA损失-15.005中，集装箱贡献-6.236、散货-4.038，其他类合计-4.731。该子集和全局查询的类别组成不同，不能将此15点外推到所有F_0921样本。

即使跨采集，B64仍比同一查询上的不适配源读出BA高7.910（F）和11.408（OSS2）个百分点。问题是支持的适用性损失，不是跨采集案例完全无用。

这不是“同港跨采集”或纯成像因果实验：没有固定真实港口、船体状态、背景等全部条件。

## 5. 支持案例能否跨数据集直接替换

这部分保留共同24港源模型，只换支持案例。F与OSS2支持具有相同预算、相同逐类数量，查询与各支持池身份隔离。它不等于仅用F训练一个模型后直接迁移到OSS2；源模型仍由24港建立。

以下差值为“外部数据集支持减本数据集支持”：

| 查询数据 | 外部支持来源 | B16 OA / BA差 | B64 OA / BA差 |
|---|---|---:|---:|
| F_0921 | OSS2 | +1.543 / -5.139 | -1.135 / -9.163 |
| OSS2 | F_0921 | -4.562 / -5.428 | -15.166 / -11.124 |

四个设置的BA差在五次支持抽样中均为负。**在这个固定表示和校正方式下，即使标签类别和数量一致，另一数据集的支持也不能等价替代本地支持。** 这为“案例适用性不是标签一致性”提供直接证据，不证明所有跨数据集学习方式都失败。

B64下，OSS2支持替代F本地支持，对F渔船贡献BA-5.948、集装箱-2.110，但散货+1.275；不是所有类别同向。反过来，F支持替代OSS2支持，主要损失包括散货-2.884、渔船-2.083、集装箱-2.540和原油轮-1.714。

相对不适配源读出，OSS2支持用于F仍有BA+1.137的小幅均值收益；F支持用于OSS2则OA/BA为-5.524/-2.528。两方向不对称，不能把“跨数据集支持必然完全无效”作为结论。

本节使用逐类配平支持，与上一节全局随机支持配额不同。不要直接把两种本地支持成绩之差归因于数据集迁移；有效比较是本节每行内部的匹配替换。

## 6. 双路的范围

全局随机支持B64，双路相对匹配R50单骨干读出的OA/BA增益：F_0921 +1.590/+1.749，OSS2 +4.513/+2.832。两套数据上仍有当前配方下的互补任务价值，不证明优于所有可能单骨干。

范围也明确：F的五采集子集中，B64同采集/跨采集双路BA相对R50分别-0.126/-0.550；OSS2对应+0.387/+4.230。因此不把“双路有用”改写成“每种条件下都更稳定”。
