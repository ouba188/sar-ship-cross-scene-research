## 原图与模型证据

13372的VV/VH都为小而细长的近竖亮主体。M1响应分布在两极化中不同，但不能仅凭其外观确定船型；配置29真实类相对化学品船的基础分差0.43118，均值支路贡献1.03195、分布支路0.41947，M1后1.88261。这里说明分布支路确实参与并强化正确判断，不证明其他方法不可替代。

21151的VV是短斜亮主体，VH可见更分散及延伸响应。配置29的M1均值和分布支路分别使散货船对普通货船的分差降低2.49202、0.69768，持续错误加深；没有将延伸命名为尾迹或旁瓣，也不能凭热图判断哪块像素导致了错误。

2418的近横船体在VV中较连续，VH内部更分散。M2的VV侧向分布差与框内、轴端不一致，VH又有不同读出，说明区域分开后确实保留了不同的模型证据。完整M2将分差从-0.71597改善到-0.15618。16596为更小的近竖目标，其VV摘要偏向拖带船，VH有不同摘要；完整头仍只有有限改善。区域摘要并非最终贡献，不能按摘要正负直接解释头的输出。

M3的实际同类和混淆类参考由本次检索得到，并与历史参考ID核对。13372有益VH经调权进入而救回；26043则引入有害VH。具体矩阵、参考ID、极化增量及重构收据见 `m3_evidence_*.json` 和 `m3_validation.json`。已有历史固定频域输入中和正反例仍见原收口记录，本轮不将其冒充新干预。

## 图上的量应怎样理解

| 图中内容 | 实际含义 | 不应解释成 |
|---|---|---|
| 原始VV/VH | 训练协议下原生裁边/补零后的输入，或明确标注的原chip显示 | 定标后RCS或新增传感器数据 |
| M1响应热图 | 源类别读出器下的相对类别响应；补零区域不参与显示 | 某像素对分类的精确因果贡献 |
| M1两侧注意力 | 当前真实类的高/低响应位置权重，四旋转逆对齐平均 | 高/低频、船体左右侧或物理散射分类 |
| M2区域颜色 | 实际OBB软区域覆盖 | 物理目标分割或显著性热图 |
| M2摘要矩阵 | 每极化、区域、统计的类别响应差 | 非线性分类头的逐区域加性贡献 |
| M3 K/T | 当前前向的局部相似度与匹配质量分配 | 分类正确概率或物理对应真值 |
| 分差图 | 固定真实类与竞争类下的实际数值分解 | 全样本平均性能或因果机制全证明 |

## 验证与复现

M1重构的均值/高低侧摘要与正式SummaryReader最大差2.22e-16；支路分数记账误差不超过2.99e-8。M2输入分差+增量精确等于输出分差。M3在实际forward中截取K/T，重新聚合、极化读出和重构最终分数，结果见其收据；检索参考一致。PNG均已实际打开检查布局及原图。

从工程目录运行：

```powershell
python tools/visualize_m12_evidence.py
python tools/visualize_m3_evidence.py
```

图表脚本使用本机验证样本；M3展示源参考原图还需要原研究目录中的图像映射。这是解释材料的依赖，不是独立模型推理的依赖。Git保留少量组合证据图、脚本及数值，不上传原始数据集或权重。

## 结论

当前能够展示“看到了什么响应、如何组织、与谁比较、通过哪条支路改了多少分”，正反例均可追踪。M2逐区域的最终因果贡献，以及M3为什么在新样本上选对或选错权重，仍不能仅凭这些图下定论。本轮交付已足够作为方法讲解和案例证据，不需要为制作可视化另外重训整套模型。
