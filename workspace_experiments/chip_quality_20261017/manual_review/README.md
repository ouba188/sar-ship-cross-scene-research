# 24港数据人工核查

本页面只记录人工判断，不删除图片、不修改 AIS、不改训练或评价样本。

## 候选范围

- 8类全量 38,091 对 VV/VH 中，6,571 条进入人工核查队列。
- 默认显示近期 2,713 条实验样本中的 491 条候选，可在“范围”中切换全量。
- 候选取多目标、船长明显差异、AIS 静态尺寸冲突、极端尺寸或边界值形态的并集，按样本去重。没有把宽度偏大单独作为入队依据。
- 入队不等于错误。检测框不等于真实船体，历史标注目标也不是独立 AIS 定位真值。

## 核查与保存

1. 查看 VV/VH 原图、检测框、AIS 参考尺寸与参考来源，必要时打开原始 AIS 记录和同 MMSI 的其他候选观测。
2. 选择“保留”“剔除”或“待定”，填写原因与备注，点击保存图标或“保存并下一张”。只选择状态不算保存。
3. 对仅 AIS 尺寸有误、但图像目标和类别仍可信的样本，可选保留并记录 AIS 问题；无法确定身份对应关系时可先待定。
4. 右上角导出支持 CSV / JSON，可单独导出保留、剔除或待定清单。CSV 可用 Excel 打开。

每条判断仅作用于当前样本，不会自动扩展到同 MMSI 的其他观测。“剔除”只是一条人工结论，尚未执行数据删除或实验集过滤。

首次保存后，正式记录位于本目录 `state/reviews.json`。刷新或重启服务会重新读取这些记录。不要删除此文件；导出的清单可另作备份。请用一个页面进行编辑，避免多个标签页同时修改同一条记录。

快捷键：1/2/3 选择保留/剔除/待定，Ctrl+Enter 保存并下一张，左右方向键切换样本。输入备注时数字与方向键不会触发样本操作。

## 启动

在 PowerShell 运行：

```powershell
& 'D:/Program_documents/Anaconda_envs/envs/ClearSAR/python.exe' -X utf8 -B 'E:/临时会话/chip_quality_20261017/manual_review/server.py' --port 8765
```

浏览器访问 `http://127.0.0.1:8765`。端口被占用时可将 `--port` 改成其他空闲端口。只监听本机，不对局域网发布；运行仅需 Python 标准库，页面不需要联网。
