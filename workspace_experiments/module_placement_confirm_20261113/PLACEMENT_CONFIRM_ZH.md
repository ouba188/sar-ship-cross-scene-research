# OSS2：含干预指导训练历史的M1位置复核

2026-11-13。正式模型不改；两个位置固定为 `current=layer2[3]` 与 `m1_middle=layer2[2]`，均在conv2激活后。M2/M3、模块数量及读出端点不变。

## 起点与干预指导

两组分别从同种子既有 `full_s{seed}_lr1/reference/final.pt` 分支。该检查点完成carrier、intervention、reference三阶段，而M1尚未启用；因此可复用共同阶段，不必重复执行相同训练。既有干预阶段真实执行过原图交叉熵、教师原图判对样本KL保护和有效样本原图分差保护，并非仅把干预命名写入配置。

- 241条source_adapt；17/29/43三个种子各96步，选中126/128/127条。
- 源训练标签仅用于源端教师选样；验证/测试不生成干预训练目标。
- 所有适配样本参与CE，useful仅选择分差保护对象；不是仅用救回样本训练。
- 本轮不重新生成teacher、不把干预图直接当作训练增强；保存teacher、loss曲线、receipt追溯继承历史。

## 分支后的配对训练

1. feedback：各180步、batch24；只训练M1、分类头与同一 `layer2[3].conv3`。中段组不改成训练 `layer2[2].conv3`，避免同时改变更新范围。
2. readout：各180步、batch24连续抽样；复用正式guide训练。
3. 全骨干微调：复用正式 `full_finetune_20261111/train.py:fit`；最多30轮、至少12轮、patience8；AdamW、骨干/模块学习率1e-4、batch24/micro12、warmup2+cosine、固定BN运行统计；验证BA/OA/-NLL选模，epoch0可选。
4. 17/29/43配对种子；相同样本顺序与增强。前两阶段可缓存冻结前缀特征；全骨干微调必须使用实时查询和参考特征，不继承旧缓存。

数据：OSS2训练719（source_fit478+source_adapt241）、验证228、测试378、源参考32。保持原始160裁剪/填充和极化可用性；不增样、不修标签。测试仅在六组训练完成后对固定两方案统一预测，不用于选择轮次或重新调位置。

## 验证与结果解释

启动前重放既有reference验证预测，检查M1关闭时两个位置一致；验证阶段门控、对应位置特征和梯度、两组feedback可训练参数集合一致，检查全骨干微调梯度及真实显存。中段组额外传播经过一个残差块，不声称计算量相同。

本轮回答“继承实际干预指导后，中段M1收益是否延续”，不能单独证明干预本身的增益。单种子pilot结果不是本轮最终结果。完成后报告三种子配对净收益、按类别/场景分组，并回看原始VV/VH救回、误伤、持续对/错及实际源参考。自动面板生成与人工原图复核分别标记。
